# 11/1 중간 점검 직전 문서 보존

현재 계획과 현황을 실행 순서 중심으로 정리하기 전에 두 원문을 바이트 그대로 보존했다. [해시 목록](manifest.json). 과거 활동·실패·기술 보고서는 이동하거나 지우지 않았다.

- [이전 계획](DEVELOPMENT_PLAN.before.md)
- [이전 현황](PROJECT_CONTEXT.before.md)

보관본 안의 종료 지시·다음 작업은 당시 문맥이다. 현행 지시는 [현재 계획](../../DEVELOPMENT_PLAN.md)과 [ADR 0028](../../decisions/0028-speed-continuity-and-final-gearing.md)을 따른다. 원문 링크는 당시 `docs/` 위치를 기준으로 하므로 현재 자료 탐색에는 문서 안내를 사용한다.
