# 결정 0017: 충돌 검출 성능 비교 옵션

- 날짜: 2026-09-08
- 상태: 선택형 실험 도입. 기본 검출기 변경은 보류.

## 근거

GPU 전환만으로 약 0.11 RTF 실행이 개선되지 않아 계산 비용을 분리했습니다.
차량·ROS·카메라가 없는 공식 코스에서 물리 계산만으로 1 sim초당 5.47초가 걸렸습니다.
같은 DART 엔진의 ODE/Bullet 검출 비교는 5.16/2.34초였습니다.
실제 RGB-D·ToF6·짧은 주행 비교에서는 기본 0.10953, Bullet 0.14302 RTF로 약 31% 개선했고
각 센서·직진·조향·실제 정지·정상 종료를 통과했습니다.

## 결정

- 코스·차량·표면 물성·1 ms 시간 간격·DART 솔버는 유지합니다.
- `collision_detector:=bullet`을 명시적 비교 옵션으로 제공합니다. 기본은 `configured`입니다.
- 운영 파일을 수정하지 않고 임시 실행 사본의 검출기 설정만 바꿉니다.
- `scene_broadcaster:=false`는 headless 진단 옵션입니다. 실제 시험에서 추가 속도 이득은 확인하지 못했으며 기본 true를 유지합니다.
- 기존 모든 활동·원본·실패·ODE 기반 주행 결과를 보존합니다. GPU는 여전히 선택형입니다.

## 기본값 전환 조건

충돌 검출기는 같은 형상에서도 접촉점·법선·접촉 매니폴드가 달라질 수 있습니다.
이번 직진 거리는 0.23045→0.22452 m, 조향 yaw 변화는 0.18891→0.20098 rad로 동일하지 않았습니다.
짧은 통과만으로 과거 동역학·제동·방지턱·한 바퀴 검증과 동등하다고 하지 않습니다.
동일 명령의 궤적/바퀴·차체 접촉 비교와 턱·편측 접지·정지·본선 검증을 완료한 뒤 기본값을 재검토합니다.
