# 결정 기록 0005: 실험 트랙의 카메라 관측용 시설

- 날짜: 2026-08-31
- 상태: 사용자 요청에 따른 실험본에 적용. 공식 경기 사양 아님.

## 배경

사용자는 신호등의 횡단 방향 배치, 곡선 과속방지턱, 주행 방향에서 보이는 독립형 ArUco 표지판, 출발 표시 6개와 피니시 표시를 요청했습니다. 제공된 출력물은 신호등 가로대가 진행 방향으로 길게 놓이고, 방지턱의 길이·폭 축이 뒤바뀌며, 그리드 표시가 노면 아래에 묻히는 문제가 있습니다.

[2026-06-30 미팅](https://maddening-cause-ce7.notion.site/2026-06-30-38f99fd42e3080f6956fe5a5b90d0824)을 재조회했으나 이번에는 공개 페이지·연결 도구 모두 본문을 가져오지 못했습니다. 2026-08-30에 확인한 과거 기록만 유지하며 후속 규정 확인으로 취급하지 않습니다. 이번 시설 치수는 사용자가 허용한 실험 가정입니다.

## 결정

1. 받은 ZIP·압축 해제 자료·원본 재현용 월드는 그대로 둡니다. `experimental`에만 적용하고, `config/tracks/experimental.yaml`의 `facilities`와 `scripts/experimental_facilities.py`로 재생성합니다.
2. 차량 외형·축거·윤거·D435i 위치·시야각을 바꾸지 않습니다. 본선·지름길의 중심선, 경로 거리, 기존 출발 위치 6개와 마커 ID·경로상의 위치 `s`도 유지합니다.
3. 신호등 가로대를 도로 횡단 방향으로 놓고 렌즈는 접근 차량을 향하게 합니다. 가로대 높이 42 cm·등 중심 30 cm·렌즈 반지름 2.6 cm는 현재 카메라 시야에 맞춘 임시값입니다. 빨간 등만 켜지는 정적 모델이며, 동적 출발 신호 제어는 별도 작업입니다.
4. 방지턱은 진행 방향 길이 20 cm·노면 폭 45 cm·노면 위 높이 1 cm의 코사인 융기 형상으로 만듭니다. 시각 메시와 같은 표본을 사용하는 경사 상자 40개를 충돌체로 사용합니다. 설치된 DART/ODE 경로에서 메시 충돌이 종료 오류를 일으켜, 실제 통과가 검증된 기본 형상 조합을 선택했습니다.
5. 네 마커를 흰색 지지판·기둥이 있는 표지판으로 만들고 본선 중심선의 1.2 m 상류 지점을 향하게 합니다. ID 30은 결정 0003의 반대편 배치를 유지합니다. 마커 중심 높이는 20 cm입니다.
6. 마커 치수는 **검은 테두리 바깥 변 10 cm**로 명시하고 사방에 흰 여백 1.5 cm씩을 더합니다. 지지판은 13×13 cm입니다. 원본 PNG는 1,000 px 중 코드 영역이 700 px이므로, 전체 이미지를 10 cm 면에 대응시키면 코드 영역은 7 cm입니다. 따라서 이번 변경을 물리적 마커 크기까지 그대로 보존한 것으로 표현하지 않습니다. 결정 0003의 크기 보존 범위는 실험본에 한해 이 결정으로 변경합니다. 원본 PNG 파일 자체는 보존합니다.
7. 렌더러의 텍스처 매핑에 의존하지 않도록 `DICT_4X4_50`의 셀을 SDF 시각 형상으로 그립니다. 흰 여백 밖에 검은 장식 테두리를 두지 않습니다. 실제 RGB에서 검출 후보가 장식 테두리에 묶여 ID 30 검출이 실패했던 근거를 반영했습니다. 검출기 기본값을 완화해 실패를 숨기지 않습니다.
8. 출발 표시는 기존 위치에 U자 선과 앞쪽부터 1~6번을 그립니다. 피니시는 기존 출발·도착 위치에 체크무늬를 그립니다. 표시는 노면보다 위에 두되 충돌체를 만들지 않습니다.

## 검증과 한계

- 자동 검사 40개와 두 월드의 엄격한 SDF 검증, ZIP·압축 해제 파일 23개 보존 검사를 통과했습니다.
- 실제 D435i 모델의 RGB에서 출발 위치 6곳의 빨간 신호, 마커 4개의 각 1.5·1.0·0.75 m 접근 조건을 확인했습니다. 카메라를 유리하게 옮기거나 시야각을 넓히지 않았습니다.
- 저속 방지턱 통과와 별개로, 0.16 m/s 주행 후 정지 피드백이 흔들리는 현상을 발견했습니다. 평지 대조에서도 같은 속도 파형이 나타나므로 별도 차량 제어 과제로 남깁니다. 전체 실행 검사는 이 정지 안정성 미통과를 계속 실패로 보고합니다.
- 정지 영상의 검출은 고속 인식, 다른 차량의 가림, 출발 상태 머신 또는 분기 의사결정 구현의 완료를 뜻하지 않습니다.

치수·실행·검사 재현과 영상 근거는 [시설 안내](../track/FACILITIES.md)에 정리합니다.
