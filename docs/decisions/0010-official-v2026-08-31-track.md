## 결정

모든 실행에서 차량의 팀 설계 목표 외형은 20×15 cm로 유지합니다. 지름길을 통과시키기 위해 차량을 축소하거나 지도 전체를 확대하지 않습니다. 공식 매뉴얼의 높이 제한 없음과 현재 모델의 임시 높이·질량·CG는 별개입니다.

공식 파생 실행본의 입력은 [`config/tracks/official_v2026.08.31.yaml`](../../config/tracks/official_v2026.08.31.yaml), 생성기는 [`scripts/build_official_track.py`](../../scripts/build_official_track.py), 결과는 `src/arena_gazebo/worlds/it_arena_official/`입니다. 보존 ZIP을 해시 대조한 뒤 `build/official_track_generation/`의 임시 작업 공간에서 처리하고, 원본 자료나 다른 실행본에 덮어쓰지 않습니다.

### 공식 파일에서 직접 적용하는 것

- 행사장 11×14.5 m, 본선 45 cm·지름길 각각 20 cm, 중심선·경로상 누적 거리·분기 연결을 유지합니다. 한 바퀴는 약 46.6329 m입니다.
- 공식 `output_final`의 도로·지도·CSV와 합집합 벽 형상을 가져옵니다. 벽 높이 30 cm·두께 5 cm, 본선 양측 잔디 각 20 cm를 적용하며 지름길에 독립 잔디 띠를 새로 만들지 않습니다.
- 출발 슬롯 6개의 실제 자세와 25×17 cm 크기를 사용합니다. 요약의 엇갈림 간격과 실제 슬롯 자세가 다른 것은 원본 불일치로 기록하고, 요약에 맞추려고 그리드 위치를 이동하지 않습니다.
- 코스 ArUco는 `DICT_4X4_50`, ID 0/20/30/45입니다. 인쇄 시트 전체 10×10 cm, 검은 코드 7×7 cm, 각 흰 여백 1.5 cm, 판 하단 높이 5 cm·중심 10 cm와 벽 부착 안내를 적용합니다.
- 방지턱 1개, 명목 진행 길이 5 cm·높이 1 cm를 사용합니다. 최종 단면·색·접촉 특성까지 공식 확정된 것으로 해석하지 않습니다.

공식 원본의 최소 곡률 반경 약 0.2987 m는 주최 측도 의도적으로 유지한 예외입니다. 0.45 m 반경 검사는 실패 상태 그대로 남기며, 도로 폭 수정으로 급커브까지 해결됐다고 기록하지 않습니다.

### 공식 의도를 구현하기 위한 런타임 보정

공식 안내는 벽 부착을 지정하지만 생성된 마커 좌표는 실제 벽에서 떨어져 있고 ID 30은 두 번째 지름길 노면과 간섭합니다. 같은 설계 측면의 실제 벽면을 찾아 마커를 부착하고 방향을 벽면에 맞춥니다. ID·역할·경로상의 `s`·설계 측면·인쇄 크기는 유지합니다. 기존 `experimental`의 ID 30 반대편 이동이나 큰 독립형 판을 가져오지 않습니다.

마커 코드 셀은 전면에서 올바른 좌우·상하 배열이 보이도록 표현합니다. 보정된 자세가 원본 좌표와 같다는 의미는 아닙니다. 원래 좌표·보정 좌표·대상 벽·사유를 [`scene.json`](../../src/arena_gazebo/worlds/it_arena_official/scene.json)과 [`provenance.json`](../../src/arena_gazebo/worlds/it_arena_official/provenance.json)에 남깁니다. 렌더링·충돌·실제 RGB 검사는 각각 별도 근거로 기록합니다.

### 마찰값의 적용 경계

공식 벽 충돌체의 `mu=mu2=0.8`은 그대로 보존합니다. 공식 파일은 도로·지름길·잔디·바닥·방지턱에 별도 마찰계수를 지정하지 않으므로 새 값을 주입하지 않습니다. “미지정”은 마찰 0이라는 뜻이 아니라 물리 엔진의 기본 처리와 접촉 상대 물성이 적용되는 상태입니다.

생성기의 비활성 저마찰 구역용 함수·수치를 실제 잔디 영역의 물성으로 사용하지 않습니다. 차량 타이어의 기존 임시 접촉값은 별도 차량 모델에 남기며, 포맥스/EVA·잔디의 실측값으로 표현하지 않습니다. 향후 공식 수치 또는 실물 측정이 나오면 출처·접촉 조합·시험 조건을 함께 기록합니다.

## 검증과 남은 한계

생성기는 원본 ZIP의 무결성, 공식 폭·중심선 길이, 고정 20×15 cm와 설정된 조향 점유 영역의 보수적 직사각형에 대한 출발 위치·경로 표본 정적 간섭을 확인합니다. 변환 전후의 해당 형상을 비교하고 입력·출력 해시와 결과를 `provenance.json`에 남깁니다. 정적 검사는 지름길 연속 진입·합류, 본선 완주, 다중 차량 안전성이나 실차 성능의 증명이 아닙니다.

```bash
python3 scripts/build_official_track.py
python3 scripts/build_official_track.py --check
python3 -m pytest tests src/arena_vehicle_interface/test -q
colcon build --symlink-install
source install/setup.bash
ros2 launch arena_bringup simulation.launch.py track:=official
```

`--check`는 보존 ZIP·현재 입력·출력 해시가 기록과 일치하는지 확인하며 전체 재생성 또는 실제 주행을 수행하지 않습니다. 최신 실행 검사·RGB·주행·정지·종료 결과는 [당일 활동 기록](../activity/2026-08-31.md)의 해당 소스와 산출물로 확인합니다. 기존 `experimental`의 완주·18조건 가시성·20 cm 방지턱 통과를 공식 월드에 승계하지 않습니다. 자율주행 입력에 지도·정답 위치·신호 제어 상태를 추가하지 않습니다.

전체 확인 사진의 저장 위치는 [`official_track_overview.png`](../../artifacts/screenshots/2026-08-31/official_update/official_track_overview.png)입니다. 실제 Gazebo 화면에서 전체 코스를 확인하는 용도이며 주행·실물 동등성의 검증은 아닙니다.
