# 0022 — B0183·C1·별도 6축 IMU와 지역 Pure Pursuit 시험

- 날짜: 2026-09-21
- 상태: 기초 구현·재개 검증 완료. v7 슬롯 0 두 바퀴는 주행/정지 성공·종료 실패로 보존. 서비스 종료를 적용한 슬롯 3 한 바퀴는 주행/정지/종료 모두 통과. 실차 안전성/성능 확정 아님.
- 선행: [ADR 0020](0020-b0183-c1-procurement-baseline.md), [ADR 0021](0021-local-path-pure-pursuit.md).

## 결정

1. 사용자는 카메라 B0183과 C1을 확정했다. 깊이 카메라와 ToF는 새 구성에서 제외한다. LSM6DSOX는 우선 시뮬레이션에 넣을 6축 후보이며 최종 구매 확정이 아니다. 좌우 후륜 엔코더는 유지한다.
2. `autonomy_mode:=local_pursuit`를 추가한다. 기존 `lidar`·`stereo`, D435i·ToF 모델과 활동·실패 기록은 삭제하지 않는다.
3. 지역 경로는 C1의 연결된 관측 벽을 호길이 기준의 강건한 매개변수 3차 곡선 `x(s), y(s)`로 평활화하고 법선 방향으로 0.425 m 띄워 생성한다. 초기 `y=f(x)` 함수 적합은 급커브에서 실패했고, 짧은 이웃 접선만 사용하는 방식은 작은 돌출부를 과장해 교체했다. 우선 벽의 연결 구간을 얻지 못하면 반대 벽을 확인해 상한 1.2 m/s로 대체하며, 양쪽 모두 불확실하거나 전방 경로가 없으면 정지한다. 이는 본선 폭+양쪽 잔디가 일정한 현재 코스에 대한 **단순 단독 주행 기준선**이다. 일반 도로 인지, 상대차 분류·추월, 전역 경주선은 아니다. RGB는 출발 신호와 마커에 사용한다.
4. 후륜축 기준 Pure Pursuit로 조향한다. 기존 좌우 후륜 엔코더·자이로 기반 순차 스캔 내부/스캔 이후 결합 보정(`both`)을 사용한다. 지도·Gazebo 정답 위치는 제어 입력에 넣지 않는다.
5. ToF 대신 독립 `lidar_safety`가 `/drive`를 제한해 `/drive/safe`로 보낸다. 오래된 입력/부족한 보정 이력/전방 결측/후진 명령에서 정지한다. 후방 60도는 임시 사각으로 마스킹하고 자유 공간으로 채우지 않는다. 예측 차체와 라이다 점군의 간섭 거리로 감속한다. 센서보다 낮은 물체, 반사 손실, 측면으로 들어오는 차량은 이 보호층만으로 보장할 수 없다.
6. 방지턱은 `speed_bump:=false` 실행 사본에서만 제거한다. 공식 원본·팀 월드 파일과 기존 실행 기본값은 유지한다. 새 전용 실행 `local_pursuit.launch.py`는 임시로 방지턱을 끈다.

## 배치와 물성의 범위

`src/arena_description/config/b0183_c1.yaml`에 별도 기록한다. 카메라 광학 중심은 `(0.055, 0, 0.145)` m, C1은 `(0.060, 0, 0.095)` m, IMU는 `(0, 0, 0.060)` m이다. 모델 원점은 두 축 사이 지면이며 전방이 +x, 좌측이 +y이다. 실제 하드웨어 배치 승인은 아니다.

C1 측정면은 기존 차체 상단 8.5 cm 위에 둔다. 낮은 상대 차량 전체를 검출할 만큼 낮다고 주장하지 않는다. 4–6 cm로 더 낮추려면 차체·배터리·축·지지대의 실제 가림을 반영한 재배치가 필요하다. 카메라는 C1 몸체 위를 보도록 높인다. 후방 식별판은 원래대로 유지하고 후방 미관측을 보수적으로 가정한다.

B0183는 명목 720p60·수평 75도 핀홀 모델이다. 실제 해상도별 크롭/왜곡·롤링셔터·노출/통신 지연은 미구현이다. 독립 Gazebo IMU는 208 Hz·6축과 작은 임의 백색잡음을 사용한다. ±500 dps·±8 g는 실물 설정 후보이며 포화/양자화/FIFO/온도 바이어스를 실제 칩처럼 구현한 것은 아니다. 가상 orientation은 보정에 사용하지 않는다.

센서 가정 질량은 RGB 10 g, IMU 3 g, C1 110 g이며 제거한 D435i/ToF와의 차이 62 g을 차체에 보충해 총 2 kg을 유지한다. 실측 질량/관성/CG가 아니다.

## 속도와 검증

새 `local_fast`의 명령 상한은 2.5 m/s(9 km/h), 횡가속도 한도 3.5 m/s², 증속 한도 1.5 m/s²다. 코너 속도를 일정 비율로 과도하게 줄이던 기존 식 대신 `sqrt(횡가속도/곡률)`을 사용한다. 현재 조향뿐 아니라 전방 경로 곡률을 보고 감속하며, 실제 관측 경로가 짧으면 그 끝까지의 제동거리·스캔 나이로 속도를 제한한다. 독립 라이다 보호층의 점군 간섭 한도가 추가된다. 주행 성공이나 명령 상한 도달을 의미하지 않는다. 실측 결과는 [구현·시험 기록](../autonomy/LOCAL_PURE_PURSUIT_2026_09_21.md)에서 갱신한다.

실제 RGB/IMU 수신률이 요청 60/208 Hz와 달라 약 62.5/250 Hz로 측정됐다. 해당 칩의 정확한 주기 재현으로 표현하지 않으며 보정에는 명목값이 아니라 메시지 시각을 사용한다. 기본 인식 처리 약 10 Hz는 RGB 수신률과도 별개다. 외관·핀홀 광학·가정 잡음·명목 인터페이스 수준의 센서 모델이고 전송/노출/온도 특성까지 검증한 모델은 아니다.
