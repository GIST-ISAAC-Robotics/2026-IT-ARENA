# 결정 0021: 지역 경로 생성과 Pure Pursuit를 우선 개발한다

- 날짜: 2026-09-21
- 상태: 사용자 선택에 따른 개발 방향 확정. 신규 주행기 구현·실차 검증 전.
- 관계: ADR 0020의 견적 이력, ADR 0018의 LiDAR 운동 보정과 ADR 0009의 기존 ToF 안전층을 보존한다. 지도 기반 주행·다른 제어기는 후속 후보로 둔다.

## 배경

사용자는 매번 LiDAR로 벽을 갱신하며 지역 목표점을 만드는 주행을 의도했다. 기존 비교 문서의 단계 3은 지도 기반 경주선을 가정해 전역 위치 추정이 필요하다고 설명했으나, 이는 Pure Pursuit 자체의 요구사항이 아니다. 경로 생성과 경로 추종을 구분하고 현재 개발 방향을 명시한다.

## 결정

1. C1 관측에서 차량 기준의 짧은 지역 경로를 계속 생성하고 Pure Pursuit로 추종하는 방식부터 시작한다. RGB는 신호·마커와 노면 보조 정보에 활용한다. 경로의 차량 점유 영역·곡률·관측 범위를 검사하고 목표 속도를 정하는 기능을 함께 설계한다.
2. FTG나 지도 구축·SLAM·전역 자기 위치 추정을 선행 필수 작업으로 두지 않는다. 다른 제어기와 지도 기반 경주선은 여유가 있을 때 비교한다. 기존 벽 추종은 비교 기준으로 보존한다.
3. 엔코더·자이로의 이동량·회전량은 기존 순차 스캔 및 스캔 이후 운동 보정에 활용하는 정보다. 지역 경로 추종을 이유로 별도 전역 추정기를 추가하지 않는다. 실물 입력 시각·장착·교정 계약 확인은 여전히 필요하다. 이전 경로 유지나 상대차 추적은 별도 기능이며 보정 구현과 혼동하지 않는다.
4. 일반 RGB+C1 사용은 거의 확정이고 ToF는 아마 미사용이라는 사용자 설명을 신규 설계 전제로 삼는다. 엔코더는 있지만 구체 사양은 미정이다. IMU는 6축 장착을 검토하며 후보 모델이 있으나 사용자 확정품은 없다. 카메라 B0183의 과거 견적 선택을 임의로 교체하거나 이번에 새 모델을 확정하지 않는다.
5. 낮은 C1 설치, 후방 일부 가림, 전방 얇은 기둥/지지물 가능성을 고려하되 장착 수치·가림 각도를 확정하지 않는다. 실측 전에도 가림·유효 관측을 분리해 시험할 수 있도록 설계한다. 자기 반사 제거 후 그 뒤 공간을 자유 공간으로 채우지 않는다.
6. ToF 없는 실차용 독립 감속·정지층은 C1 관측·미관측·센서/명령 만료·제동거리를 반영해 별도 구현·검증한다. 기존 `/drive` → ToF 안전층 → `/drive/safe`와 과거 시험은 유지한다. 기존 안전층 비활성화나 내부 토픽 직접 발행만으로 새 안전 경로를 대신하지 않는다.
7. 동적 장애물 회피·추월은 지역 경로 후보 선택·상대차 시간축 관측·복귀/포기 판단을 확장하는 후속 기능이다. 전역 위치 추정 없이도 검토할 수 있으나, 가려진 측후방의 안전을 가정하지 않는다. Pure Pursuit 채택이 추월 구현 완료를 뜻하지 않는다.

## 미확정 항목과 검증 경계

- 엔코더 선정·분해능·수량·장착·시간 정보, IMU 모델·장착·시각·교정, C1 실물 시간 계약.
- LiDAR 높이·가림 범위·기둥 치수·상대차 가시성, 조향/제동 성능에 따른 경로·속도 한계.
- ToF 최종 미장착 여부, 새 독립 안전층과 실차 구동 연결, 상대차 추적·추월 범위.
- 기존 D435i·ToF 시뮬레이션 통과 결과를 신규 RGB+C1 실차 구성의 검증으로 승계하지 않는다. 대회용 주행 입력에 시뮬레이터 정답 위치를 사용하지 않는다.

사용자 요청에 따라 주차별 개발 일정이나 6주 우선순위를 정하지 않는다. 이번에는 문서만 갱신하며 코드·차량·센서 배치·운영 설정은 변경하지 않는다. 상세 구현 구상과 과거 비교 자료는 [알고리즘 노트](../autonomy/ALGORITHM_OPTIONS.md)에 둔다.
