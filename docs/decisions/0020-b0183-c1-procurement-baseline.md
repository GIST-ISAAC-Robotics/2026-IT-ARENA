# 결정 0020: B0183·C1 구매 검토 기준선

- 날짜: 2026-09-19
- 상태: 사용자 선택에 따른 현재 견적 기준. 실제 구매·설치·실물 성능 검증 전.

## 결정

1. RGB 카메라는 **Arducam B0183**, 회전식 LiDAR는 **SLAMTEC RPLIDAR C1**으로 고정해 다음 견적을 검토한다.
2. **Arducam B0410 ToF 깊이 카메라는 후속 연구 후보로 보류**한다. 현재 견적의 필수 품목이나 C1과 병행 구매할 품목으로 넣지 않는다. [기존 조사](../hardware/TOF_LIDAR_SPEED_AND_JETSON_REVIEW_2026_09_18.md)는 보존한다.
3. 다음 선정 대상은 별도 IMU다. [9/19 역할·요구 사양·국내 모듈 비교](../hardware/IMU_SELECTION_2026_09_19.md)의 LSM6DSOX 우선 의견은 어시스턴트의 추천이며 사용자 선택 확정은 아니다.
4. 총 40만 원은 사용자가 제시한 지원 30만 원+자체 10만 원의 견적 전제다. 모터·차체 부품은 하드웨어팀이 재검토할 수 있다. 이 결정을 공식 예산 집계 규정에 대한 새로운 판정으로 취급하지 않는다.

## 결정 범위

- B0183의 Jetson 사용 기준은 기존 조사에서 제조사로 확인한 1280×720 60fps다. 판매처의 720p180 표기를 Orin Nano·JetPack 6.2의 보장 모드로 승격하지 않는다. 세부 모드와 연결 구성은 [카메라 조사](../hardware/RGB_CAMERA_MODULE_RESEARCH_2026_09_18.md)에 남긴다.
- C1은 회전 중 순차 취득한다. 별도 IMU와 엔코더를 추가해도 새 거리 관측 주기가 빨라지지는 않으며, 실제 점별 취득 시각·순서·지연 확인은 남는다. 보정 구현 범위는 [ADR 0018](0018-sensor-based-lidar-motion-compensation.md)을 따른다.
- B0410 보류는 영상형 ToF에 대한 결정이다. 측면/차체 사각을 위한 개별 ToF 센서의 필요 여부·수량을 새로 확정한 것이 아니다.
- 기존 D435i·C1급·ToF 시뮬레이션 모델, 입력 토픽, 기본 실행과 과거 시험 결과는 이번 견적 선택으로 변경하지 않는다. 구매·실물 이식·새 주행 시험은 하지 않았다.

## 후속 작업

IMU 모델을 선정한 뒤 ESP32-S3에서 엔코더·IMU 취득 시각을 함께 관리하고 Jetson 시간 영역으로 변환하는 연결을 설계한다. 별도 IMU의 장착 회전·영점·온도·진동과 C1 시간 계약을 실제로 확인해야 한다. B0410은 예산 또는 깊이 주행 필요가 달라질 때 기존 기록부터 재검토한다.
