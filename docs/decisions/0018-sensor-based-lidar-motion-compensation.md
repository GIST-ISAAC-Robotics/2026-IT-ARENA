# 결정 0018: 엔코더·자이로 기반 평면 LiDAR 운동 보정

- 날짜: 2026-09-08
- 상태: 사용자 구현·시험 승인에 따른 선택형 개발. 실물 C1 적용·안전 속도 승인 아님.

## 결정

공통 계산 `arena_autonomy.lidar_motion`과 ROS 입력 어댑터 `lidar_motion_ros`를 사용한다.
기본 `none`과 원시 `/scan`은 보존하며 `deskew`, `shift`, `both`를 추가한다.

1. 양자화된 `/wheel_states`의 좌우 후륜 각속도 평균으로 전진 속도를 계산하고,
   `/camera/imu`의 각속도를 고정 장착 회전으로 차체 z축에 투영한다. 자세 quaternion,
   가속도, 조향 명령, `/odom`, `/sim/*`, 지도·정답 궤적은 보정 입력으로 사용하지 않는다.
2. 공통 시간 영역의 취득 시각으로 2초 이력을 저장한다. 현재까지 수신한 표본 중
   취득 시각도 현재 이하인 표본만 사용한다. 두 입력 시각의 합집합에서 구간별
   zero-order hold(직전값 유지) twist를 정확한 SE(2) 식으로 적분한다.
3. 후륜축 중심에서 차체 중심으로의 오프셋과 LiDAR 장착 x/y/yaw를 적용한다.
   평면 순수 구름 근사이며 바퀴 슬립·횡이동·방지턱 pitch/roll을 완전히 추정하지 않는다.
4. 스캔 기준 시각은 `stamp + (N-1)*time_increment`인 마지막 광선 시각이다.
   내부만은 점별 시각→마지막 광선 시각, 이후만은 전 점을 마지막 광선 시각으로
   간주→현재, 둘 다는 점별 시각→현재로 변환한다. 균일 각도 스캔으로 재표본화하지
   않고 기존 벽 추종기의 XY 점 배열에 연결한다.
5. 원시 관측 시각·최신/최오래 관측 나이·좌표 기준 시각·입력 나이·외삽·처리 시간을
   구분해 진단한다. 좌표를 현재로 옮겼다고 관측 타임아웃을 초기화하지 않는다.
6. 50 ms 초과 입력 공백, 30 ms 초과 마지막 값 외삽, 부족한 이력·시간 계약 오류는
   보정을 거부하고 제어기는 0 속도를 요청한다. 자동 무보정 전환은 하지 않는다.
   이 한계는 초기 소프트웨어 설정이지 실물 센서 사양이나 안전 보장값이 아니다.
7. 바이어스는 명시적 설정이며 시뮬레이션 기본 0이다. 주행 중 자동 영점 학습,
   칼만 필터 튜닝, 가속도 이중 적분은 첫 구현에 포함하지 않는다.

## 실행과 입력 계약

`demo.launch.py`·`simulation.launch.py`의 `lidar_compensation`은 기본 `none`이다.
보정이 켜진 일반 벽 추종기만 엔코더·IMU를 추가 구독한다. 독립 비교 시험기는
무보정에서도 같은 두 토픽을 구독·기록하여 입력 수신 부하를 맞춘다.
일반 `/drive`→ToF 보호→구동 경로는 유지하며, 기존 독립 시험의 ToF 해제만 유지한다.

실물 ROS 어댑터 기본 `motion_scan_timing_verified=false`는 임의 C1 드라이버의 시간
계약을 검증한 것으로 취급하지 않기 위한 장치다. 시뮬레이션 launch/시험에서만
이 값을 true로 명시한다. 실물 정렬·복제·반전·타임스탬프 및 frame을 확인한 뒤
사용해야 한다. 라이다 frame은 현재 `laser_frame` 계약이며 장착 roll/pitch는 0인
평면 모델이다. IMU의 장착 roll/pitch는 설정으로 회전시키지만 실제 차체 기울기까지
추정하는 SE(3) 보정기가 아니다.

## 검증 범위

공식 코스의 느린 오프라인 순차 실행에서 `sensor_wall_timeout_s`를 추가했다.
기본 3초는 유지하고 재검사/촬영만 30초를 명시한다. 측정 시각 기준의 스캔·엔코더·
자이로·ToF 만료와 외삽 한도는 그대로다. 이 실행 전용 벽시계 감시 유예를 실물
watchdog 권장값으로 승계하지 않는다. `autonomy_control_rate_hz`도 기본 20 Hz이며
고속 단독 촬영에서만 100 Hz를 명시한다. 비교용 독립 시험의 기존 100 Hz는 변경하지 않는다.

기하 단위 검사 → 5 km/h 스모크 → 같은 10 Hz/500점/500 Hz 원시 광선/100 Hz 제어의
순간 부하 일치 대조군과 순차 네 모드를 비교한다. 조향 이득·속도·물성·트랙은
모드별로 조정하지 않는다. 원시 입력 재생을 보정 형상 검사에 사용하되 폐루프
주행 성공을 대신하는 것으로 표현하지 않는다. 실패·조기 정지·프로세스 종료는
분리 기록한다. 실제 실행 결과는 [구현·시험 기록](../sensors/LIDAR_MOTION_IMPLEMENTATION.md)에 누적한다.
