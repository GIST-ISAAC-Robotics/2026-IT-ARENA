# ADR 0026: 확정 구동 부품과 단일 모터축 엔코더 기준선

- 날짜: 2026-10-02
- 상태: 사용자 결정에 따른 시뮬레이션 구성 변경. 실물 장착·폐루프 주행 검증은 별도다.
- 대체 범위: [ADR 0008](0008-single-motor-mechanical-differential.md)의 BLDC 임시 가정·좌우 후륜 엔코더 2개와 [ADR 0023](0023-mcu-actuation-contract-reference.md)의 해당 피드백 가정. 단일 모터·기계식 차동·Jetson/MCU 역할과 독립 보호 경계는 유지한다.

## 결정과 이유

1. **MB4266-24180 후면축형 브러시 DC 모터 + MD20A(PWM+DIR)**, 전체 감속비 **15:1**, 바퀴 바깥지름 **65 mm**를 기준으로 한다. 제품 선정과 팀 전달 사항의 출처·근사는 [구동 구성 검토](../hardware/DRIVETRAIN_GEARING_2026_10_02.md)에 모은다.
2. 하드웨어팀이 바퀴 쪽 장착 공간 부족을 우려하여, 사용자가 **PGE-213 하나를 모터축에 설치**하는 구성을 확정했다. 판매 사양 7 PPR·A/B 4체배, 즉 **모터 1회전당 28카운트**를 사용하되 납품품의 실제 펄스 수·출력 회로를 확인한다.
3. 시뮬레이션은 차동장치의 `모터각 = 15 × (왼쪽 바퀴각 + 오른쪽 바퀴각) / 2`를 **모터축에서 먼저 양자화**한다. 이 단일 관측으로부터 평균 바퀴 회전량만 환산하며, 좌우 독립 관측값 두 개를 만들어 낸 것처럼 표시하지 않는다. 기존 좌우 후륜 모드와 과거 기록의 해석은 명시적으로 구분한다.
4. 이동 보정은 이 평균 전진 속도와 기존 IMU 자이로를 사용한다. 차동 속도·한쪽 헛돎·기어 파손/유격·차체 실제 속도는 단일 모터축 엔코더로 관측되지 않는다. 정지 판단도 **모터축 저속 관측**이지 양쪽 바퀴 또는 차체 정지의 증명이 아니다. 반대 방향으로 도는 두 바퀴의 평균이 0일 수 있다.
5. 기존 임시 축거 145 mm에 65 mm 타이어를 넣으면 직진 길이가 210 mm다. 차량 목표 길이 200 mm를 유지하기 위해 **축거만 임시 135 mm**로 조정한다. 실차 축거 확정이 아니며 제작 공차 여유가 없다. 윤거 135 mm·폭 12 mm·총질량 약 2 kg·마찰/CG는 기존 임시 가정으로 남긴다.
6. 모터 이름·기어비·타이어와 센서 환산을 바꾸는 작업이지 전류·열·MD20A 단락 제동을 실측한 작업이 아니다. 임시 토크·PI·보호 시간과 주행 속도 정책을 성능 사양으로 승격하거나 최대 전류에 맞춰 무작정 올리지 않는다. `/drive` → 독립 보호층 → `/drive/safe` 경계를 유지한다.

## 채택하지 않은 대안

- 공간 문제가 있는 좌우 바퀴 엔코더 2개를 현행 하드웨어 결정과 무관하게 계속 기본값으로 두지 않는다. 과거 재현용으로만 남긴다.
- 모터 카운트를 좌우 측정값으로 복제하여 두 바퀴의 정지·회전 차이를 검증했다고 하지 않는다.
- 분해능 변경을 부드러운 정답 속도나 강한 필터로 숨기지 않는다. 저속 속도 추정의 개선은 새 양자화·누락·시간 조건을 시험한 뒤 선택한다.

## 검증 경계와 후속

최초 구성 반영 요청은 **시뮬레이션 실행 금지**였으므로 정적/단위 검사까지만 수행했다. 같은 날 후속 재개 지시로 [엔코더·고장·주행 검증](../autonomy/MOTOR_ENCODER_VALIDATION_2026_10_02.md)을 시작했다. 이전 하드웨어 값으로 얻은 완주·Jetson 재생 결과를 새 구성의 성공으로 승계하지 않는다.

다음 제어 검증에는 저속 양자화, 펄스 누락/잘못된 방향, 누적 카운트 재시작·오버플로, 표본 주기·지연, 단일 축으로 구분할 수 없는 헛돎·정지 조건을 포함한다. Gazebo 모터 내부 PI의 이상적 관절 피드백과 상위 양자화 센서 입력은 별개이므로, 양자화된 엔코더만 사용하는 실제 MCU 속도 루프의 검증도 남긴다. 기존 A4의 C1 무응답·IMU 이상치 대응을 삭제하거나 완료로 바꾸지 않는다.
