# 결정 0015: C1·D435i 선택형 단독 주행 프로토타입

- 날짜: 2026-09-03
- 상태: 2026-09-04 두 모드 완주·영상 확인. 스테레오 전달률/종료 실패는 남음. 팀 설계 결정은 아닙니다.
- 관계: 결정 0006의 LiDAR 벽 추종을 보존하고, 결정 0014의 D435i·최소 ToF
  후보를 실제 비교 가능한 시뮬레이션 모드로 확장합니다.

## 결정 권한과 범위

이 센서 구성은 **사용자가 개인적으로 제안한 임시 비교안**입니다. 다른 팀원이나
하드웨어 담당자와 아직 한 번도 협의하지 않았으며, 팀 합의·구매 승인·최종 장착
결정으로 기록하지 않습니다. 팀 회의에서는 비용, 전원·I²C, 브래킷, 실물 가림과
정후방 포기 여부를 다시 결정해야 합니다.

비교할 두 모드는 다음과 같습니다.

| 모드 | 조향 입력 | 독립 ToF 안전층 | 명목 관측 범위와 포기 기능 |
|---|---|---|---|
| `lidar` | 상부 C1급 2D LiDAR `/scan` | 기존 6개 `0/±60/±120/180°` | 360° 명목 배치. D435i 깊이는 끄고 RGB만 신호·마커에 사용 |
| `stereo` | 전방 D435i급 RGB·깊이 영상 | 좌우 전·후측 4개 `±60/±120°` | 카메라 전방과 양쪽 측면 호를 우선. 약 60° 정후방 호는 보지 않음 |

네 ToF의 수평 60° 시야는 각 측면에서 `30~90°`와 `90~150°`가 맞닿는
명목 기하입니다. 센서 광학 중심이 떨어져 있고 차체·바퀴·배선 가림과 시야 경계
결측이 있으므로, 이를 실물의 완전한 측면 무사각으로 표현하지 않습니다.

## 프로토타입 구현

- `autonomy_mode:=lidar|stereo`로 두 센서 모델과 제어 노드를 선택합니다.
- `lidar`는 기존 RGB 출발·ArUco 분기 규칙과 LiDAR 2차 벽 곡선 추종을
  그대로 사용합니다.
- `stereo`는 RGB의 회색 노면 후보를 깊이로 평지인지 확인하고, 가까운 노면
  중심 목표점을 기본 Pure Pursuit로 추종합니다. 한 경계만 보이는 표본은
  본선 명목 폭 0.45 m로 중심을 추정합니다. 목표점이 없을 때만 깊이의 열린
  통로·벽 거리 기반 조향을 최저속도로 사용합니다. 두 조향 명령을 더하지 않습니다.
  `/scan`, 지도, 정답 위치·자세는 구독하지 않습니다.
- RGB·깊이의 공통 원점/자세와 내부 파라미터는 현재 Gazebo 모델의 가정입니다.
  실제 D435i에서는 RGB-깊이 정렬·외부 파라미터 보정이 필요합니다. 녹색 잔디와
  회색 도로, 평지·명목 폭을 이용하므로 깊이만으로 도로를 인식하는 구현이 아닙니다.
- 네 개 또는 여섯 개의 활성 ToF 이름을 독립 안전층에 전달해, 선택하지 않은
  센서 토픽을 데이터 누락으로 오인하지 않게 했습니다.
- 녹화 전용 `chase_camera`는 차량을 따라가는 960×540 관찰 영상만 발행하며
  자율주행 입력이 아닙니다.
- 센서 제거에 따른 질량 혼선을 줄이기 위해 `stereo`에서는 0.111 kg을 차체에
  보충해 두 비교 모델의 합계를 2.000 kg으로 맞춥니다. 질량 중심·관성 분포까지
  같다는 뜻은 아니며, 실제 경량화 설계를 확정하거나 제품 간 성능을 비교한 것이 아닙니다.
- 상대 차량 인식·추적, 회피 경로, 추월, SLAM과 지름길 주행은 이번 범위에서
  구현하지 않습니다.

## 2026-09-03 중단 당시 기록

- 관련 패키지 빌드와 핵심 Python 검사 **43개**를 통과했습니다.
- 첫 `stereo` 2 m 시험은 RGB 빨강→초록 출발, 깊이·4-ToF 수신, 1.31986 m
  진행, 벽 접촉 0개까지 확인한 뒤 출발/피니시 부근에서 왼쪽 깊이 벽 추정이
  끊겨 정지하여 실패했습니다. 증거는
  `artifacts/tests/stereo_autonomy_tuning_01/`에 보존합니다.
- 얇은 시설에 의한 짧은 벽 가림을 직전 조향·최저속도로 최대 2초 통과하는
  복구를 추가하고 단위 검사를 다시 통과했지만, 사용량을 아끼기 위해 이 수정의
  실제 주행 재검증은 아직 시작하지 않았습니다.

## 2026-09-04 재개와 검증

- 깊이 통로·벽 거리·RGB 보조를 합산한 이전 방식은 25.016 m 시험을 통과했지만,
  다음 완주 녹화에서는 24.196 m에서 한쪽 뒷바퀴만 돌며 정지했습니다.
  벽 겹침이 없더라도 잔디 경계로 접근해 접지가 나빠질 수 있음을 확인했습니다.
  정확한 접촉력·원인 분리는 미완료이며 차동 모델이나 공식 트랙을 바꾸지 않았습니다.
- 62.95초 실패 영상도 보존했습니다. 영상 저장과 완주는 구분합니다.
- 이에 위의 RGB-D 가까운 목표점 추종으로 변경했습니다. C1은 새 선택형 실행에서
  48.6527 m·벽 겹침 0개·정상 정지/종료를 통과하고 86.65초 영상을 남겼습니다.
  스테레오 수정본도 `stereo_rgbd_target_one_lap_video_01`에서 48.6527 m·벽 겹침
  0개·정상 정지·130.1초 영상을 확인했습니다. 다만 깊이 전달률 23.975 Hz와
  Gazebo 종료 실패 때문에 종합 `passed`는 `false`입니다. 두 실패를 지우거나
  과거 헛돎 문제가 모든 조건에서 해결됐다고 확대하지 않습니다.
- [고정 검증 결과와 영상](../../artifacts/validation/2026-09-04/selectable_autonomy/README.md)에
