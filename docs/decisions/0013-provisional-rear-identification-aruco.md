# 결정 기록 0013: 후방 5×5 cm 식별 마커의 임시 시뮬레이션 표현

- 날짜: 2026-09-02
- 상태: 팀 시험용 임시안. 운영진의 팀별 모양·세부 장착 기준이 우선한다.

## 배경

공식 매뉴얼은 차량 후방에 5×5 cm 식별 마커를 의무 부착하고 팀별 모양을
9월 3주차까지 공유하도록 한다. 그러나 현재 자료에는 ArUco 사전과 ID,
5 cm가 코드·흰 여백·판 중 무엇을 뜻하는지, 높이·방향·외형 검차 포함
여부가 없다. 시뮬레이션에서는 다른 차량 인지 실험을 준비할 최소 표식이
필요하다.

## 결정

- 임시 표식은 `DICT_4X4_50`의 ID 10을 사용한다. 코스 ID 0·20·30·45와
  겹치지 않는 팀 내부 시험값일 뿐, 제출할 공식 팀 ID가 아니다.
- 흰 판 전체를 5×5 cm로 두고, 검은 코드는 3.5×3.5 cm, 사방 여백은
  7.5 mm로 둔다.
- 차체 후면 중앙에 수직으로 배치한다. 판 하단 6.5 cm, 상단 11.5 cm로
  두어 후방 ToF 중심 4 cm를 가리지 않고 상부 LiDAR 스캔면 12.5 cm보다
  낮게 둔다.
- 마커는 질량·충돌체가 없는 시각 요소로만 넣는다. 아직 실물 브래킷의
  질량, 외형, 진동과 가림을 모델링하지 않는다.

## 검증과 제한

생성된 6×6 셀 패턴을 OpenCV의 `DICT_4X4_50` ID 10과 대조하고, 치수,
후면 위치, 충돌체 부재, ToF·LiDAR 높이 경계를 자동 검사한다. 이는 구조와
표현만 확인하는 간단한 검증이다. 주행 중 다른 차량에서의 거리별 검출,
가림, 역광, 프린터 품질과 충돌 회피 입력 사용은 아직 검증하지 않았다.

운영진이 팀별 마커 모양 또는 장착 기준을 확정하면 이 임시값을 교체하고,
실차 브래킷과 차량 외형·센서 가림을 다시 검사한다.
