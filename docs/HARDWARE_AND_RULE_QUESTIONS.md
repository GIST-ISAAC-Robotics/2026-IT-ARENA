# 하드웨어 요구사항과 경기 규칙 확인

<a id="하드웨어경기-규칙-확인-질문"></a>

갱신: **2026-11-02 (KST)**. 구매 부품·구동 방식은 고정하고 센서 배치는 변경할 수 있다는 [사용자 결정](decisions/0027-completion-first-policy-and-placement.md)과 [새 공칭 감속비·속도 목표](decisions/0028-speed-continuity-and-final-gearing.md)를 적용한다. 팀 설계 입력과 남은 질문만 모으며, 질문이 외부에 게시됐다는 뜻은 아니다.

공식 자료는 main `17178293029d446fa603f3229556dd865bbddd38`·`v2026.11.01` 기준이다. [최종 회의·모델 검토](reports/OFFICIAL_UPDATE_2026_11_02.md), [고정 MANUAL](https://github.com/MOSW626/istech-it-arena/blob/17178293029d446fa603f3229556dd865bbddd38/MANUAL.md), [갱신 전 질문 보관본](archive/2026-11-02-plan/HARDWARE_AND_RULE_QUESTIONS.before.md)을 구분한다. 새 원본을 보존하고 11/3 코스 안 기둥만 제거한 팀 파생본을 적용했다.

신호등은 새 공식 모델에 2행×5열·15 mm 광원·명목 중심 419 mm·바닥 대비 60°·선두 칸 앞선 전방 300 mm가 반영됐다. 판 크기·광원 간격·마커 좌우 145 mm는 모델 근사다. ID45 왼쪽/ID0 오른쪽의 최종 배치를 따르고 과거 ID45 오른쪽 20 cm 팀 패치를 중복 적용하지 않는다. 실제 시공 사진·대표 그리드 시야만 후속 대조한다.

### 단면이라는 말의 의미

[하드웨어팀 전달 그림·C1 배치 비교](../artifacts/validation/2026-11-03/lidar_mount_study_v1/README.md): 낮은 C1·앞쪽 장착·뒤 보강·PDB 두 층을 함께 검토했다. 광축 75 mm·앞 50 mm의 JR은 제작 목업 후보이며 기존 95 mm·후방 60° 실행값을 대체하지 않는다. 지주·배선뿐 아니라 낮은 층의 뒤 타이어, 보드에 꽂은 플러그와 체결 여유를 확인한다.

라이다 레이저가 바닥에서 9.5 cm 높이를 지난다고 가정하면, **그 높이에서 자동차를 수평으로 잘랐을 때 어떤 부품이 걸리는지** 보는 것이다. 전체 차량을 위에서 본 그림과 다르다. CAD의 수평 절단 화면이나 간단한 배치 그림이면 된다. 아직 도면이 없으면 설계하면서 확인한다.

우리 차의 단면은 자체 가림을 알려 준다. 상대차가 그 높이에 실제 물체를 갖고 있는지는 별도 문제다. 모든 차량이 특정 높이에서 반드시 검출된다고 외형 높이 상한만으로 보장하지 않는다. 후방 마커판을 올리더라도 지지대·케이블이 같은 높이를 가릴 수 있으므로 함께 본다.

배치를 정하면 실제 위치·방향(`xyz/rpy`)과 좌표계/축, C1 운동 보정에 사용하는 센서 위치, 시뮬레이션의 센서 좌표·가림 마스크도 함께 갱신한다. 브래킷 위치만 옮기고 기존 보정 위치를 유지하지 않는다.

### 카메라 배치에서 확인할 장면

1. 자차만 있는 공식 6그리드에서 등 전체와 검출 ROI.
2. 앞차·옆줄 차량이 있는 그리드와 **빨강 가림→앞차 이동→초록만 보임**.
3. 코스 마커에 접근할 때의 검출 거리, 앞차가 마커를 가렸다가 드러내는 시점.
4. 차체 피치·롤 변화와 기판·브래킷·배선의 가림.

기존 수평 카메라의 시야 실패와 약40° 상향 비교는 [당시 M5 기하](autonomy/GRID_START_M5_2026_10_24.md)이며, 높은 임시 SDF를 사용한 결과다. [10/27 가로 배열·높이 비교](../artifacts/validation/2026-10-27/official_signal_orientation_v1/README.md)에서는 광원 중심.28/.40 m 가정일 때 수평 카메라도 영상 안에 들어왔고 앞차 가림이 주된 제한이었다. 뒤쪽 .30 m 높이는 .25 m 상자 차량 대비 유리했지만 .40 m 차량 가림은 남았다. 이는 정지 핀홀 표본 계산이므로 최종 배치·픽셀 검출 보증이 아니다. 큰 상향 피치를 그대로 제작값으로 전달하지 않고 실제 설치 사진과 마커 접근을 함께 확인한다.

현재 코드는 코스 마커가 검출되지 않으면 이전 기준 벽 선택을 유지한다. 전환 마커를 처음부터 끝까지 놓친 경우의 본선 선택은 별도 검증이 필요하다.

코스 마커를 항상 볼 수 있도록 기구만으로 해결하는 것을 필수 조건으로 두지 않는다. 소프트웨어의 마커 의존도 완화와 함께 [본선 유지 시험](DEVELOPMENT_PLAN.md#직접-시험할-최소-장면)으로 비교한다. 가림을 줄이는 배치와 가림이 남았을 때의 주행 대응은 서로 다른 확인 항목이다.

### 공식 질문 후보 — 11/2 정리, 미게시

- **지지 기둥 — 확인 종료(11/2 사용자 전달): 실제 트랙 안에는 기둥이 없다.** 11/3 팀 파생본에서 `tl_post` 시각·충돌을 함께 제거했다. 공식 원본·기둥 포함 실패 이력은 보존한다. [기하/주행 결과](../artifacts/validation/2026-11-03/post_free_facility_v1/README.md). 사용자 전달 확인과 공식 저장소 수정 여부는 구별하며 추가 기둥 질문은 하지 않는다.
- **설치 사진:** 신호 발광면·두 마커와 대표 그리드 방향의 실제 사진을 대조한다. 단색 LED 앞 확산판의 소등 색·반사와 점등 밝기는 사진/영상으로 확인할 사항이며, 코스 안 기둥 유무를 다시 묻지 않는다. 높이·광원 배열·기준점은 이미 답변돼 다시 묻지 않는다.
- **세이브포인트:** 본문 7곳과 그림의 표시 대응, 실제 배치 방향은 현장에서 확인한다. 즉시 재개 규정은 해소됐으며 지도 좌표를 받는 것이 소프트웨어 선행 조건은 아니다.
- **접촉·복귀:** 일반 접촉과 공격, 합류·피추월 때의 책임은 심판 판단이다. 사용자 전달의 로그 활용은 설명 자료 계획이며 공식 면책 기준으로 쓰지 않는다. 별도 구체 장면으로 질문할 필요가 생길 때만 초안을 준비한다.

## 하드웨어팀에 이어서 확인할 사항

- **전원·서보:** J01/M01 데이터시트는 [전원 사양](reports/OFFICIAL_UPDATE_2026_10_12.md)과 [구매 구성](hardware/ESP32_BUDGET_REVIEW_2026_10_02.md)에서 확인한다. 6S 직결 출력을 서보 허용 전압과 혼동하지 않는다. 채널별 연속/피크 부하·접지·커넥터 고정·실제 전원 투입 동작을 확인한다.
- **조향:** 현재 ST3215-HS는 버스 서보다. 과거 PWM 서보 문구를 그대로 배선 요구로 넘기지 않고 중립·각도 한계·응답·백래시를 실제 인터페이스로 확인한다.
- **모터·제동:** MD20A의 PWM 0은 단락 제동이다. 감속 램프만으로 전류 한도를 보장하지 않으며 실제 정지거리·슬립·뒤바퀴 잠김을 확인한다. [구동 구성과 계산](hardware/DRIVETRAIN_GEARING_2026_10_02.md)
- **감속비·속도:** [구매표](../assets/hardware/procurement/2026-11-01/README.md)의 61T/17T와 사용자 전달 내부 2.5로 새 시뮬레이션은 **8.9706:1**을 사용한다(이전 실행값 15:1). 정확한 기어 피치·피니언 축 구멍, one-way 베어링이 실제 후륜 동력 경로에 남는지, 조립 뒤 모터 한 회전당 이동량을 확인한다. 65 mm·28카운트 가정에서 1카운트당 약 0.813 mm다. 목표는 가능한 구간에서 2 m/s 이상, 이어 10 km/h이며 실제 도달 속도·제동은 측정해야 한다.
- **노면·현가:** 공식 방지턱 제거로 턱 인식/통과 속도 시험은 필수에서 제외한다. 59 mm 댐퍼 길이만으로 스트로크·강성·접지를 확정하지 않는다. 도로/잔디 경계의 편측 헛돎·음수 축 값·기울기 때의 센서 변화는 증상이 있을 때 분리해 확인한다. [과거 턱 기하](simulation/BUMP_GEOMETRY_2026_10_23.md)는 당시 자료로 보존한다.
- **출발 시설:** 새 공식 2×5 신호·ID45 왼쪽/ID0 오른쪽을 실행에 연결했다. [사양/근사 구분](reports/OFFICIAL_UPDATE_2026_11_02.md)과 실제 사진을 대조한다. 실제 시설과 시뮬레이션이 일치한다는 실물 검증은 아니다.
