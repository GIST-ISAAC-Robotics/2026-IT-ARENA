### 단면이라는 말의 의미

라이다 레이저가 바닥에서 9.5 cm 높이를 지난다고 가정하면, **그 높이에서 자동차를 수평으로 잘랐을 때 어떤 부품이 걸리는지** 보는 것이다. 전체 차량을 위에서 본 그림과 다르다. CAD의 수평 절단 화면이나 간단한 배치 그림이면 된다. 아직 도면이 없으면 설계하면서 확인한다.

우리 차의 단면은 자체 가림을 알려 준다. 상대차가 그 높이에 실제 물체를 갖고 있는지는 별도 문제다. 모든 차량이 특정 높이에서 반드시 검출된다고 외형 높이 상한만으로 보장하지 않는다. 후방 마커판을 올리더라도 지지대·케이블이 같은 높이를 가릴 수 있으므로 함께 본다.

### 카메라 배치에서 확인할 장면

1. 자차만 있는 공식 6그리드에서 등 전체와 검출 ROI.
2. 앞차·옆줄 차량이 있는 그리드와 **빨강 가림→앞차 이동→초록만 보임**.
3. 코스 마커에 접근할 때의 검출 거리, 앞차가 마커를 가렸다가 드러내는 시점.
4. 차체 피치·롤 변화와 기판·브래킷·배선의 가림.

현재 수평 카메라의 시야 실패와 약 40° 상향 피치 비교는 [M5 기하](autonomy/GRID_START_M5_2026_10_24.md)에 있다. 40°를 최종 장착각으로 고정하지 않는다. 카메라를 높이거나 뒤로 옮기는 후보도 함께 비교한다. 실물 설치가 확정되지 않은 항목은 가정 범위를 표시한다.

현재 코드는 코스 마커가 검출되지 않으면 이전 기준 벽 선택을 유지한다. 전환 마커를 처음부터 끝까지 놓친 경우의 본선 선택은 별도 검증이 필요하다.

## 하드웨어팀에 이어서 확인할 사항

- **전원·서보:** J01/M01 데이터시트는 [전원 사양](reports/OFFICIAL_UPDATE_2026_10_12.md)과 [구매 구성](hardware/ESP32_BUDGET_REVIEW_2026_10_02.md)에서 확인한다. 6S 직결 출력을 서보 허용 전압과 혼동하지 않는다. 채널별 연속/피크 부하·접지·커넥터 고정·실제 전원 투입 동작을 확인한다.
- **조향:** 현재 ST3215-HS는 버스 서보다. 과거 PWM 서보 문구를 그대로 배선 요구로 넘기지 않고 중립·각도 한계·응답·백래시를 실제 인터페이스로 확인한다.
- **모터·제동:** MD20A의 PWM 0은 단락 제동이다. 감속 램프만으로 전류 한도를 보장하지 않으며 실제 정지거리·슬립·뒤바퀴 잠김을 확인한다. [구동 구성과 계산](hardware/DRIVETRAIN_GEARING_2026_10_02.md)
- **속도:** 15 km/h는 팀 목표 상한이다. 현재 15:1·65 mm 계산의 공칭 무부하 약 13.6 km/h는 실측이 아니며, 완충·부하·발열에 따라 달라진다. 기어비 변경은 이번에 결정하지 않았다.
- **방지턱:** 카메라 인식을 필수로 추가하기 전에 저속 통과 범위를 확인한다. 기하상 통과 가능과 동적 통과·경로/센서 복구는 다르다. [현재 기하 결과](simulation/BUMP_GEOMETRY_2026_10_23.md)

## 구매품 인수와 입력 확인

구매 전 재선정 단계는 끝났다. 다음은 구매품을 실제 제어에 연결하는 확인 사항이다.

| 입력 | 남은 확인 | 기준 문서 |
|---|---|---|
| C1 | 원시 응답/무응답, 정렬·복제 전 점 순번과 시각, host batching, 실제 재질·거리·가림 | [C1 시간 계약](sensors/C1_DRIVER_TIME_CONTRACT_2026_10_23.md) |
| B0183 | CSI/Argus 출력 RGB/BGR·패딩·촬영 PTS·노출·수신 시각·실제 화각 | [영상 이관](sensors/B0183_INPUT_HANDOFF_2026_10_23.md) |
| LSM6DSOX | API 단위·장착 축·DRDY/FIFO·읽기 오류·센서/MCU 시계 | [입력 감사](hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md) |
| PGE-213·MCU | 실제 카운트·방향·시간·신호 레벨, 속도 PI·명령 감시·STOP | [ADR 0026](decisions/0026-motor-shaft-encoder-baseline.md), [구동 계약](hardware/ACTUATION_CONTRACT_2026_09_22.md) |

실물 자료가 아직 없는 부분은 현재 가정과 한계를 적고 연결 가능한 항목부터 진행한다. 보유 D435i·ToF 구성은 역사적 비교·회귀용이며 현재 구매안으로 되돌리지 않는다.
