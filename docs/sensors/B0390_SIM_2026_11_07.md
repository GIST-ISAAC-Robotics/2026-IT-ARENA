# B0390 교체와 시뮬레이션 가정

2026-11-07 사용자가 카메라를 **Arducam B0390**으로 변경했다. 현재 선택 프로필은 `src/arena_description/config/b0390_c1_jr60p20_sim.yaml`이다. B0183 프로필과 당시 시험은 재현용으로 보존한다.

## 확인한 사양과 적용값

[제조사 제품 페이지](https://www.arducam.com/90524.html)와 [제조사 설명서의 판매처 배포본](https://download.kamami.pl/p1178777-B0390_Manual.pdf)을 대조했다. 제조사 페이지 직접 조회는 403이었으며 검색 색인과 원문 설명서 PDF를 확인했다. 판매처 자체 재작성 스펙 대신 Arducam 명의 설명서를 근거로 삼았다.

| 항목 | 제조사 자료 | 시뮬 적용/남은 확인 |
|---|---|---|
| 센서·렌즈 | IMX219 3280×2464, 고정 초점 3.04 mm F2.0, 가시광 IR-cut | 색상 핀홀 모델. 렌즈 왜곡·초점/노출·롤링셔터 미재현 |
| 화각 | 수평 62.2°, 수직 48.8° | 1280×720에서 **수평 62.2° 유지·정사각 픽셀** 가정. 수직은 비율에서 약 37.5°로 계산되며 48.8°를 동시에 강제하지 않음 |
| 영상 | 설명서 1080p30·720p60·VGA60/90 | 1280×720·60 Hz. Jetson의 실제 센서 모드/크롭/출력률은 연결 후 확인. 제품명만으로 60 fps 실측을 주장하지 않음 |
| 모듈 | 25×24×9 mm, 3 g | 표시에 이 외형과 질량 사용. 질량 차이는 기존 비교용 차체 보정으로 총 질량 유지. 브래킷·케이블·실물 관성 별도 |
| 배치 | 실물 CAD 미확정 | 기존 JR60P20의 카메라 `[0.055,0,0.145]` m·수평, C1·IMU·지주·배선 예약과 ID49 높이 유지 |

수평 시야가 기존 75° 가정보다 좁아 같은 거리에서 작은 마커는 더 많은 픽셀을 차지하지만, 가까운 신호·마커가 화면 위/옆으로 나가기 쉬워진다. 이는 핀홀 기하의 예상이며 실제 인식 결과와 구별한다. Jetson 연결 때 센서 모드 목록·CameraInfo·인쇄 마커를 통해 유효 화각부터 확인한다. B0183용 입력 시각/PTS 이관 문서는 공통 처리 계약만 재사용하고, B0390 드라이버 호환을 이미 검증한 것으로 취급하지 않는다.

## 실행과 검증 위치

신규 단독 기준 명령은 `python3 scripts/run_current_solo.py <새 출력 경로> --track official_v2026_11_06 --local-sensor-config src/arena_description/config/b0390_c1_jr60p20_sim.yaml`이다. `--straight-budget`은 별도 선택 후보로 유지한다. 인자 생략은 옛 코스·B0183 재현이므로 신규 결과에는 반드시 트랙과 프로필을 명시한다.

제조사 PDF·설정 검사·새 코스 첫 주행 근거는 [카메라 이관 결과](../../artifacts/validation/2026-11-07/b0390_course_baseline_v1/README.md)에 남긴다. 초기 이관 시험 당시에는 새 코스 완주를 확인하지 못했다. 이후 [11/8 r25 단독 한 랩](../../artifacts/validation/2026-11-08/solo_gap_envelope_connected_v3/README.md)과 교통 한 랩을 이 프로필로 확인했다. **11/10 실물에서는 사용자 확인의 22↔22 FPC로 IMX219 mode 4·1280×720/60 fps를 인식했다.** 연속 수신·측정 한계는 [실물 보고서](B0390_HARDWARE_2026_11_10.md)를 따른다. 실제 유효 화각·왜곡·광학 교정은 미확인이다.

## 11/13 — CAD 추정 높이와 프린팅 전 가시성

현재 시설 비교에서는 선택형 `b0390_c1_cad_20261112_frontwire_4mm.yaml`의 광축198.363 mm·수평을 사용한다. 위145 mm 설명은11/7 JR60 이관 당시 값이다. 새 값도 구형 카메라 CAD에서 가져온 높이와 임시 X55 mm이며 실물 B0390 교정값은 아니다.

[6개 그리드 렌더·앞차 높이 비교r307](../../artifacts/validation/2026-11-13/camera_grid_r307_v1/README.md)에서 빈 배치와224 mm 앞차의 신호는6/6이지만, 뒤 두 자리의 마커는 가려졌다. 앞차230 mm부터 신호도 부분 가림으로 실패했다. 높이+20 mm/224 mm 상대, +40 mm/250 mm 상대의 신호·마커는 각각6/6이었다. **렌즈 중심 약220–240 mm 조정 범위를 권고**하며 프로필/CAD를 자동 변경하지 않았다. 화각 여유와 물체 가림은 구분한다. 전체 자기 차체, 실제 렌즈/FPC 브래킷, 교정·노출·실물 배경, B3 출발 주행은 별도다.

11/13 후속 사용자 확정의 구형610 연장 시설 [r326](../../artifacts/validation/2026-11-13/old_signal_610_r326_v1/README.md)에서도 빈 배치/224mm 앞차는6/6,230mm는5/6의 정상 신호 검출이었다. 224mm 뒤쪽0/3번 마커 가림은 유지되어 높이 조절 권고는 변하지 않는다. 렌더18사례는 완료했지만 Gazebo 종료 강제 정리로 전체 실행 정상 종료는 실패했다. 형상 적용과 검출 결과를 실물 장착 증명으로 쓰지 않는다.

## 11/13 실물 신호 시험 불가와 차량 마커 보조 검토

사용자는 시간·재료 제약으로 실제 신호등을 촬영해 HSV 등을 조정하는 시험이 어려우며, 준비 가능한 표적은 ArUco·체커보드 정도라고 전달했다. 실제 신호 노출/조명 교정을 완료한 것으로 쓰지 않는다. 신호 판독은 수 ms 반응보다 오출발 방지가 우선이다. 현행은 광원 배열·빨강 이력·서로 다른 초록3프레임을 검사한다. 이후 색/밝기 허용 범위, 신호 영역·점등 전후 변화·시간 확인을 함께 검토하고 저장 영상의 색조/노출/흐림/부분 가림/배경 반례로 비교한다. 색 범위만 무조건 넓히거나 연속 검출만으로 꺼진 유색 렌즈/옷의 오검출을 해결했다고 보지 않는다. 아직 새 검출 계수나 정책을 채택한 것은 아니다.

사용자는 C1 평면보다 낮은 앞차를 놓칠 가능성에 대해 후방 마커의 주행 중 활용을 제안했다. 기존 검출기를 재사용하되 먼저 참가 차량 ID와 코스 ID를 구분하고, 영상 위치·연속 관측·크기 변화로 앞차 후보를 기록하는 제한 기능을 검토한다. 감속 연결은 별도 대표에서 확인하며 마커 미검출/소실을 앞차 부재로 쓰지 않는다. 화면 중심과 주행 경로를 동일시하지 않고 커브/옆차 오촉발을 본다. 정밀 거리·상대속도·완전 추종/충돌 방지는 별도 범위다.

ID/2D 꼭짓점 검출과 현재 신호 색·배열 판독은 intrinsic 보정을 필수로 요구하지 않는다. 미터 단위 거리/자세 추정을 채택하려면 실제 사용 해상도/크롭의 intrinsic·왜곡과 실제 코드 변 길이(흰 여백 포함 판 크기와 구분)를 확인해야 한다. 체커보드 영상의 자동 수집/계산은 가능하나 현재 우선 필수 작업으로 추가하지 않는다. [OpenCV ArUco 검출·자세 추정](https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html), [카메라 보정](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html). 이는 설계/후속 조건이며 새 실물 시험 결과가 아니다.

**후속 사용자 결정:** 보정은 시간이 생기면 다른 담당자가 수행한다. 낮은 상대가 많을 때 현장에서 켤 수 있는 차량 마커 보조를 **기본 OFF 옵션**으로 준비한다. 현재 [r340 관측 옵션](../../artifacts/validation/2026-11-13/vehicle_marker_observer_r340_v1/README.md)은 기존 검출 결과의 위치·크기 변화·중복/소실을 기록하는 첫 단계이며 속도를 바꾸지 않는다. 참가 차량 ID를 명시해야 하고 관측값을 거리나 같은 차로로 단정하지 않는다. 감속 연결은 대표 반례 확인 뒤 별도로 이어간다.

사용자는 상부가 얇거나 듬성듬성한 상대 차량도 우려했다. 기존 옆면이 오목한 모델과220mm 불투명 상자는 이 조건을 충분히 대신하지 못한다. [r341](../../artifacts/validation/2026-11-13/sparse_upper_r341_v1/README.md)의4mm 판·8mm 지주4개는 하부/평가 외곽을 보존한 대표 가정이며, 라이다 높이 단면의 반환 감소부터 확인한다. 보이는 점 사이를 임의로 채우거나 평가 외곽을 줄여 통과시키지 않는다.

[r339 저장 광학 비교](../../artifacts/validation/2026-11-13/signal_tolerance_r339_v1/README.md)는 정상/늦은 출발 모두 원본17/18, 밝기0.60배0/18이며 다른 단일 변형은17/18이었다. 밝은 소등 초록 렌즈 가정에서 늦은 출발 후보가12건 오출발해 기본 채택하지 않았다. 실제 렌즈 값/현장 오출발률의 측정이 아니며, 색 임계값 완화만으로 해결할 수 없다는 제한 반례다.
