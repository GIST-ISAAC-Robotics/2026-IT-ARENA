# 현장 조정 시간이 불확실한 조건의 센서 구성 제안

작성: 2026-09-18. 구매 결정·실물 성능 검증이 아닌 사용자 논의용 제안이다.

**9/19 후속 결정:** 사용자 선택에 따라 현재 카메라·LiDAR 기준은 **B0183+C1**이며 B0410은 보류했다. [ADR 0020](../decisions/0020-b0183-c1-procurement-baseline.md)과 [IMU 포함 갱신 견적](IMU_SELECTION_2026_09_19.md)을 우선한다. 아래 OV2710 기준 가격과 추천은 9/18 논의 이력이다.

후속 상세 비교는 [저가 ToF·LiDAR 속도와 JetPack6.2 검토](TOF_LIDAR_SPEED_AND_JETSON_REVIEW_2026_09_18.md)를 확인한다. 사용자가 JetPack6.2 계열을 확인했고 B0410의 공식 지원 경로와 실제 동작 미검증을 구분했다. 현재 STL-27L은 배송/VAT 포함199,100원으로 STL-19P와2,200원 차이이며, 이 가격대의 비교 우선순위를 갱신했다. 추가로 사용자가 저가 스테레오의 후속 비교를 요청했으므로 고가 스테레오 제외를 모든 저가 후보의 자동 탈락으로 확대하지 않는다.

사용자 제시 GS130W와 추가 국내 후보의 [저가 스테레오 비교](LOW_COST_STEREO_REVIEW_2026_09_18.md)도 완료했다. 저가 영상 모듈의 연결·동기화·깊이 처리와 완성형 깊이 카메라를 구분했으며, 현재 확인 근거로는 아래 C1 기준안을 바꾸지 않았다.

## 이번 계산의 전제

- 사용자의 최종 설명은 **지원 30만원 + 자체 10만원 = 총 40만원**이며, 자체 예산으로 센서도 살 수 있을 것으로 보고 구성한다. 앞선 “주요 품목 30만원만으로 비교” 해석을 이번 제안에 강제하지 않는다.
- 공개 문서 확인과 견적 전제는 구분한다. 오늘 조회한 공식 main `4c8d3d34671dd5066ce96193365977aa4d1a7662`의 [MANUAL §3](https://github.com/MOSW626/istech-it-arena/blob/4c8d3d34671dd5066ce96193365977aa4d1a7662/MANUAL.md)은 주요 집계 품목 30만원·제외 항목 자체 부담 약10만원으로 적혀 있다. 자체10만원의 센서 구매를 집계에서 제외해도 된다는 명시는 확인하지 못했다. 총40만원 사용 가능성을 공식 집계 적합 판정으로 바꾸지 않는다.
- [#14 공식 답변](https://github.com/MOSW626/istech-it-arena/issues/14#issuecomment-5664162147)은 기보유품 별도 산입 없음·신규 구매만 집계라고 적혀 있다. 보유품 금지가 확정됐다고 기록하지 않는다. 다만 사용자가 원한 보수적 설계 검토를 위해 이번에는 보유 D435i 등 사용 없이 계산한다.
- 사용자는 실제 트랙 시험이 당일뿐이고 확보 가능한 시간이 불확실하다고 전달했다. 공개 매뉴얼은 경기1시간 전 프리랩·프리랩1랩을 명시하지만 팀별 조정 시간과 반복 시험을 보장하지 않는다. 상대 차량의 색상·세부 형상도 모르는 조건이다.
- 하드웨어팀은 일부 기성품을3D 프린팅으로 대체해 센서 예산을 확보할 수 있다고 전달했다. 모터·ESC·구동계의 확정 견적은 아직 없다.
- 사용자는 9/18 추가 설명에서 **9/14 회의 이후 모터 교체를 포함한 하드웨어 변경 가능성이 논의됐다**고 전달했다. BLDC가 필수가 아닐 수 있다는 이야기도 있으나 사용자도 확실히 확인한 내용은 아니다. 모터 변경 또는 BLDC 제한 해제가 확정됐다고 보지 않고 참고용으로만 남긴다. 현재 협의 방향은 센서 측에서 필요한 금액을 먼저 제안하고, 하드웨어팀이 그에 맞춰 최대한 비용을 줄이는 것이다. 이번 센서 검토의 선행 조건으로 모터 선정을 요구하지 않으며 기존 BLDC 구동 기준선과 ADR 0008은 유지한다.

## 권고

**OV2710 RGB + RPLIDAR C1을 첫 기준안으로 잡는다.** LiDAR 거리 형상을 주행의 주 입력으로, RGB는 신호등·코스 마커와 노면 경계 보조로 사용한다. 필요가 확인된 차체 사각만 ToF로 보완한다. 새로운 고가 스테레오·3D LiDAR·상급 회전 LiDAR 구매는 이번 예산의 우선순위에서 내린다.

이 권고의 이유는 “C1이 보정 없이 고속에서 충분해서”가 아니다. 현장 조정 시간을 확보하기 어렵다는 사용자의 우려를 반영하면, 차량 색상·조명·가림에 크게 의존하는 RGB 조향을 주행의 필수 입력으로 만드는 부담이 크기 때문이다. 회전 스캔 보정은 알려진 움직임·시간·장착 조건을 다루는 문제이고, 우리 차량과 모형 벽으로 사전 시험할 수 있다. RGB 환경 변화도 모의할 수 있지만 실제 행사장의 조명·반사·미지의 상대 차를 전부 확보하기는 어렵다. 이는 설계 판단이며 두 실차 방식의 성공률 비교 결과가 아니다.

## 역할별 차이

| 판단 항목 | RGB + C1 | RGB + ToF4 |
|---|---|---|
| 주행 방향·통로 | 여러 방향의 거리와 벽 형상, 이전 관측을 이용할 수 있음 | 기본적으로 RGB가 담당; ToF의 소수 방향으로는 가려진 도로를 복원하기 어려움 |
| 미지의 차량 색상 | 색상 분류 없이 관측된 물체를 점유 영역으로 유지 가능 | RGB에서 노면·차량 혼동 가능; ToF가 보는 범위의 근접 물체는 색상 분류 없이 검출 가능 |
| 시간 특성 | C1 8~12Hz; 한 바퀴 순차 취득, 이동/회전 보정 문제 있음 | 회전 스캔 왜곡 없음; 센서 측정·전송 지연과 다중센서 순차 처리/간섭은 별도 |
| 가림 | 벽과 차의 분리, 벽 가림·다른 차량 움직임 대응 필요 | 영상의 노면 가림이 주행 경로 판단에 직접 영향 |
| 사전 시험 | 우리 차·모형 벽·상자/모형차로 기하/시간/제동 시험 가능 | 모형 노면·다양한 조명·그림자·차량 모양/색상 변화까지 비교 필요 |
| 가까운 측면 | 센서 높이·차체/바퀴 가림에 따른 사각이 핵심 | 외곽 배치 가능하지만 제한 화각 사이의 사각이 핵심 |

LiDAR도 차량과 벽을 자동으로 구분하는 장치가 아니다. 짧은 근접 물체를 벽 피팅에서 제외해도 **충돌 판단에서는 보존**해야 한다. 벽이 가려지면 짧은 시간의 이전 경로와 자기 운동으로 연결하되 관측 신뢰도가 낮으면 감속한다. 다른 차를 가려진 영역까지 포함해 “삭제하고 빈 길로 간주”하지 않는다.

또한 이 코스는 벽 안쪽 전체가 주행 노면이 아니다. 일반 본선과 지름길·합류부의 벽–도로 관계가 다르므로 가장 넓은 빈 공간으로만 조향하면 잔디로 갈 수 있다. 알려진 구간 구조·마커·노면 경계 보조를 함께 쓴다. 세부 장착/도로 관계는 [기존 기하 검토](../sensors/SENSOR_PLACEMENT_GEOMETRY.md)의 버전별 한계를 유지한다.

## C1 보정 부담을 어떻게 볼 것인가

[현재 구현](../sensors/LIDAR_MOTION_IMPLEMENTATION.md)과 [ADR0018](../decisions/0018-sensor-based-lidar-motion-compensation.md)에 엔코더·자이로 기반 스캔 내부 보정과 스캔 이후 좌표 이동이 이미 있다. 전체 SLAM을 먼저 새로 만들어야 하는 상태는 아니다. 다만 실물 C1의 취득 순서/점별 시각, 전송 지연, 실제 자이로·엔코더 교정과 장착을 확인해야 하며 실물 이식 완료가 아니다. 기존 IMU 입력은 D435i였으므로 이를 사용하지 않는 새 차에는 별도 자이로 입력이 필요하다.

10Hz에서 같은 방향 재관측 간격은100ms다. 그동안5km/h에서약13.9cm,10km/h에서약27.8cm,20km/h에서약55.6cm 이동한다. 이 수치는 횡오차나 제동거리 자체가 아니다. 저속에서도 급회전·근접 상황에 따라 문제가 생길 수 있으므로 “몇 km/h 이하는 보정 불필요”라고 보장하지 않는다. 저속 기본 동작→취득 시각/회전 보정→속도 확대 순서로 시험할 수 있다는 의미다.

기존 독립 직선20km/h 결합 보정은2/2회 통과했지만 공식 코스 촬영은최고12.38km/h·최종 정지/종료 미통과였다. 실제 대회 속도·다중 차량·실물 안전의 근거로 확대하지 않는다. 상대 차량 운동과 가림은 자기 운동 보정만으로 해결되지 않는다.

## 하드웨어팀과 협의할 구체적인 방향

1. 카메라+C1의 162,360원을 센서 측 기본 요구 금액으로 먼저 제안하고, 하드웨어·제어부를 나머지 237,640원에서 맞추는 방향으로 재견적한다. 기존 모터 가격을 고정한 뒤 남은 금액만 센서에 배정하는 방식은 사용하지 않는다. 이 값은 실제 모터 가격이나 최종 구동 구성을 확정한 결과가 아니다.
2. 3D 프린팅을 활용할 때 센서 광학창과 차체/바퀴 가림, 낮은 관측 평면, 배선/전원 배치까지 함께 설계한다. C1을 너무 높게 달면 낮은 차를 놓치고, 낮게 달면 자체 바퀴/구동부 가림이 생길 수 있다. 출력품으로 바꾼 비용만큼 성능이 유지되는지는 부품별 확인이다.
3. 기존D435i를 쓰지 않으므로 엔코더·자이로를 포함한 제어부 비용을 빠뜨리지 않는다. ESP32-S3 후보는 유지하되USB RGB영상 처리는 지급 Jetson, MCU는 모터/센서 인터페이스 역할로 분리해 검토한다.
4. ToF2 추가는 기본 고정 수량이 아니다. 모형차를 차체 주변으로 이동시켜C1 사각을 확인하고, 막히는 방향을 메울 때만 제품/수량/위치를 정한다. 두 개로 전방·측후방 모든 사각을 동시에 없앤다고 가정하지 않는다.
5. 공식 매뉴얼의학교별폼지급을 활용해 직선·커브·벽 끊김·갈림길 일부를 미리 구성한다. 여러 색/높이의 모형차, 끼어들기·앞차 정지·시야 가림에서 주행과 실제 제동을 확인한다. 첫 단계에서는완주·감속·추종을우선하고공격적추월/20km/h는별도성능목표로둔다.

최종 센서 선택·장착 수량·안전 속도는 아직 결정하지 않았다. 기존 엑셀·시뮬레이션·ADR의 구현 상태는 변경하지 않는다. 오늘 공개 원문은 `outputs/01a07090-budget/sources_2026_09_18/`에 보존했다. 공식 main 조회는 예산/시험 안내 확인 범위이며 새 트랙/PDB 전체 감사나 실행본 갱신이 아니다.

## 후속 후보: 사용자 제시 Arducam B0410 ToF 깊이 카메라

사용자가 [디바이스마트 B0410](https://www.devicemart.co.kr/goods/view?no=14900560)을 제시했다. 금일 판매 페이지 직접 조회가는 VAT 포함 **88,000원**, 일반 기본 배송 무료, 해외 평균 준비 기간 2주다. 국내 판매처가 있다는 사실을 국내 즉시 재고로 해석하지 않는다. 앞선 비교에는 이 가격대의 영상형 ToF가 빠졌으므로 **전방 깊이 기반 주행의 추가 후보**로 재검토한다. C1 대체 확정이나 구매 결정은 아니다.

- [제조사 사양](https://docs.arducam.com/Raspberry-Pi-Camera/Tof-camera/TOF-Camera/): 깊이 240×180, 센서 원시 최대120fps와 4-phase 깊이 최대30fps를 구분한다. 후속 조회한 [제조사 판매 페이지](https://www.arducam.com/time-of-flight-camera-for-raspberry-pi.html)는 Raspberry Pi와Jetson 모두30fps이며 Orin Nano에서도 시험했다고 명시한다. 이는 우리JetPack6.2에서의 실측이 아니다. 근거리 모드 상한2m/원거리 모드 상한4m, 수평62.8°·수직37.9°(대각 약70°), 940nm 조명, 2-lane MIPI CSI-2다. 실제 최소 유효 거리와 대상별 측정 오차는 확인하지 않았다.
- 깊이와 적외선 반사 강도 영상이며 RGB 컬러 카메라를 대체하지 않는다. 깊이 화면의 색은 거리를 표현하는 표시다. 신호등 색과 마커 판독에는 별도 RGB를 유지한다.
- 8×8 ToF보다 전방 형상을 세밀하게 관측하므로 바닥 평면과 돌출한 차량을 높이로 나누는 접근에 적합한 후보라는 설계 판단이다. 자동 객체 분류 기능이 내장됐다는 뜻은 아니다. 바닥 평면 추정·장착 자세와 방지턱 피치 대응은 필요하며, 노면과 잔디가 비슷한 높이면 깊이만으로 주행 경계를 확정하기 어렵다.
- 전방 약 63°는 C1의 주변 관측과 다르다. 휠투휠 측면이나 급커브 안쪽 사각을 한 대로 해결하지 못하므로 별도 근접 센서 배치를 비교해야 한다. 단일영역 ToF 4개를 광시야 ToF 4개와 동등하게 취급하지 않는다.
- 4-phase 취득이므로 회전 스캔 왜곡이 없다는 이유로 움직임 영향까지 없다고 보지 않는다. 빠른 자기 운동과 상대 차 이동에서 깊이 경계/유효 픽셀을 확인한다. 반사·다중경로와 노출에 따른 운동 오차는 [ADI의 ToF 원리 설명](https://www.analog.com/en/resources/analog-dialogue/articles/adi-tof-depth-sensing-technology-enabling-new-and-emerging-applications-beyond-consumer.html)이 설명하는 일반적 검토 사항이며 B0410 실측 결과가 아니다.
- [Jetson 공식 연결 안내](https://docs.arducam.com/Nvidia-Jetson-Camera/Time-of-Flight-Camera/Getting-started/)에는 Orin Nano/NX도 있다. 다만 CSI 연결, 케이블, 제조사 드라이버/SDK가 필요하고 지급 Jetson의 정확한 JetPack·커널 조합에서 깊이 출력과 실제 FPS는 미확인이다. ESP32-S3에 직접 연결하는 센서로 예산을 잡지 않는다. RGB와 깊이를 픽셀 단위로 합치려면 별도 위치/시간 정렬도 필요하다.

동일한 9/18 RGB·ToF 단가로 계산하면 OV2710+B0410은 **151,360원**, 여기에 VL53L1X 4개를 더하면 **212,960원**, 대신 VL53L7CX 4개를 더하면 **292,160원**이다. 같은 판매처 일반 기본 배송 기준이며 임의 부자재/여유금은 추가하지 않았다. 전원·MCU·엔코더·별도 IMU 등은 종전 표와 같이 별도다. 저가 스테레오를 살 수 없다는 이유만으로 깊이 주행까지 배제하지 않고, Jetson 호환성과 실제 측면 관측 범위를 확인할 때까지 C1안과 병렬 후보로 유지한다.
