# 최종 구매안과 ESP32·인터페이스 검토

확인일: 2026-10-02. 상태: **사용자 확정 구매목록 반영, 문서 기반 핀/USB 검토**. 구매안 확정과 실제 주문·결제·수령·펌웨어 실행·실차 검증을 구분한다.

## 확정 구매안과 예산 구분

최종 기준은 사용자가 확정한 `IT-ARENA 구매물품 목록_로보틱스_ISAAC(GIST).xlsx`의 `Sheet1!A3:I12`다. **부품 293,419원 + 배송비 6,500원 = 299,919원**, 지원 30만 원의 잔액은 **81원**이다. 아래 금액은 확정 Excel의 VAT 포함 금액이며, 이후 판매가로 임의 갱신하지 않았다.

예산은 **모터·센서·구동 드라이버 등 주요 부품을 주최 측 지원 30만 원에 포함하고, 제외되는 기타 제작비는 자체 약 10만 원으로 준비**한다. IMU와 MD20A를 유지하고 **Bus Servo Adapter (A)도 지원 구매안에 포함**했다. 어댑터를 제작비로 제외하려던 이전 계획은 폐기했다. 엔코더 변환 IC·기판 등은 기존 팀 계획대로 기타 제작비 후보이며 이번 확정 Excel에는 없다.

[공식 MANUAL §3](https://github.com/MOSW626/istech-it-arena/blob/main/MANUAL.md#3-지원-물품--예산)은 지원 30만 원, 동일 품목 합산 3만 원 이상 집계, 모터·센서의 금액 무관 포함, 필라멘트·볼트/너트·전선 제외와 제외 항목 자체 부담 10만 원 이내를 명시한다. 서보 어댑터도 포함해야 한다는 주최 측 확인은 **사용자가 전달한 후속 설명과 최종 구매안**을 근거로 기록한다. 공개 규정에 어댑터의 개별 분류 답변이 추가됐다고 해석하지 않는다.

## 확정 보드와 연결 구성

최종 선택은 **VCC-GND Studio VND018, ESP32-S3-WROOM-1 N16R8**이다. [제조사 YD-ESP32-S3 자료](https://github.com/vcc-gnd/YD-ESP32-S3)와 [V1.4 회로도](https://github.com/vcc-gnd/YD-ESP32-S3/blob/main/5-public-YD-ESP32-S3-Hardware%20info/YD-ESP32-S3-SCH-V1.4.pdf)를 연결 검토 기준으로 삼았다. 납품 판본이 이 회로도와 일치하는지는 입고 후 대조한다. Waveshare·원메이커·VCTEC 보드는 이전 비교 후보로 남긴다.

구매 구성은 [10/2 구동 선정](DRIVETRAIN_GEARING_2026_10_02.md)의 모터축 A/B 엔코더 1개, MD20A PWM/DIR, 지급 ST3215-HS 직렬 서보를 전제로 한다. IMU Adafruit LSM6DSOX 4438은 ESP32에, 카메라 B0183과 C1 LiDAR는 Jetson에 연결한다. HW 정지는 보유한 차량 장착 물리 버튼, SW 정지는 PC 원격 접속으로 계획하므로 정지용 추가 ESP32·휴대 송신기·버튼은 구매 목록에 넣지 않는다.

S3 CPU와 내부 SRAM, PSRAM 8 MB는 이전 N8R8 후보와 같고 Flash는 8 MB에서 16 MB로 늘었다. 가격 절감을 CPU 성능 축소로 해석하지 않는다. 대신 보드별 USB·전원·LED 연결은 아래 기준으로 구분한다.

## 현재 구성의 핀 예산

VCC-GND Studio의 [헤더 표](https://github.com/vcc-gnd/YD-ESP32-S3#排针)와 V1.4 회로도를 기준으로 검토했다. 22핀 헤더 두 줄, 총 44개 물리 단자에 전원/GND/EN 등이 포함되므로 **44 GPIO가 아니다**. GPIO로 표기된 헤더 위치는 36개다.

GPIO35–37(Octal PSRAM), 0/3/45/46(부팅 설정), 19/20(직접 USB), 43/44(USB-UART), 48(RGB LED)을 제외한다. GPIO38도 입고 판본 확인 전에는 기존 보수적 예약을 유지하여 **23개**를 배치 후보로 계산한다. 제조사 V1.4의 RGB LED는 48이며, 실물이 일치하면 38은 추가 여유가 되지만 아래 6개에는 넣지 않았다. [Espressif GPIO 제약](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gpio.html)

| 기능 | GPIO 번호 | 개수 |
|---|---|---:|
| 모터축 엔코더 A/B, PCNT | 4, 5 | 2 |
| MD20A PWM / DIR | 15, 6 | 2 |
| IMU SPI SCLK / MOSI / MISO / CS | 12, 11, 13, 10 | 4 |
| IMU 데이터 준비 INT1 | 9 | 1 |
| ST3215 UART TX / RX, Bus Servo Adapter (A) 경유 | 17, 18 | 2 |
| 차량 물리 STOP 상태 | 8 | 1 |
| 외부 구동 허가 요청 / watchdog 진행 | 21, 47 | 2 |
| 배터리 ADC | 1 | 1 |
| 선택 외부 고장 / 정지 해제 요청 | 2, 14 | 2 |
| **배치 합계** | | **17** |
| **여유** | **7, 16, 39, 40, 41, 42** | **6** |

핀 집합 계산으로 중복·제외 핀과의 충돌이 없음을 확인했다. 선택한 Bus Servo Adapter (A)는 자동 방향 전환 회로가 있어 별도 방향 GPIO16을 사용하지 않는다. 여유 중 39–42는 외부 JTAG와 겸용이며 외부 JTAG 프로브와 일반 확장 용도로 동시에 쓰지 않는다. Jetson 통신용 43/44는 별도 예약했으므로 17개에 중복 산입하지 않았다. 이 표는 **문서상 배치 후보**이며 펌웨어 적용·배선 완료를 뜻하지 않는다.

STOP GPIO는 접점/정지 상태를 읽는 신호이며, 버튼을 GPIO에만 연결한 것으로 독립 정지 회로가 완성되지 않는다. 엔코더의 5 V → 3.3 V 수신 회로도 계속 필요하다. 전기적 조건은 [기존 핀 검토](ESP32_S3_PIN_REVIEW_2026_09_30.md#실제-연결-전-남은-조건)를 함께 따른다.

## CPU·메모리·주변장치 판단

[Espressif S3 데이터시트](https://www.espressif.com/sites/default/files/documentation/esp32-s3_datasheet_en.pdf) 기준 듀얼코어 LX7 최대 240 MHz, 내부 SRAM 512 KB, UART 3개, 일반 SPI 2개, PCNT 4유닛, 하드웨어 PWM이 있다. 현재 연결은 PCNT 1유닛, IMU용 SPI 1개, 호스트·서보용 UART 2개, MD20A PWM 1채널을 사용한다. 이번 대체 후보는 같은 칩이므로 이 자원을 줄이지 않는다.

MCU가 맡는 것은 엔코더 계수·IMU 취득·속도 제어·서보 통신·정지/통신 만료 관리다. 영상과 LiDAR 처리는 Jetson이 맡는다. [현재 구동 계약](ACTUATION_CONTRACT_2026_09_22.md)의 참조 시험은 제어 200 Hz, 엔코더 피드백 100 Hz, 호스트 명령 50 Hz, 프레임 payload 상한 1536바이트와 유한 큐를 사용한다. 이 정도 역할에 **S3의 하드웨어 사양을 낮출 이유는 없으며, 동일 사양 저가 보드로 충분히 검토를 진행할 수 있다**. 실제 펌웨어 메모리 사용량이나 CPU 점유율은 아직 측정하지 않았으므로 수치 여유나 마감 준수를 보장하지 않는다.

- Flash는 프로그램·설정 저장 공간이다. N16R8의 16 MB가 N8R8의 8 MB보다 커도 CPU가 빨라지는 것은 아니다.
- 내부 SRAM은 빠른 작업 메모리다. 제어 상태·중요 큐·인터럽트 관련 데이터를 우선 배치한다. 512 KB 전부가 애플리케이션의 빈 heap인 것은 아니다.
- PSRAM 8 MB는 별도 보조 작업 메모리이며 내부 SRAM과 접근 조건이 다르다. 핵심 정지/제어 경로가 PSRAM에 의존하지 않게 설계한다. Flash 접근으로 캐시가 비활성화되면 외부 RAM 접근도 제약될 수 있다. [공식 외부 RAM 문서](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-guides/external-ram.html)
- 실제 펌웨어에서는 메모리 인식, heap/stack 여유, PCNT 계수 손실, PWM·센서·UART 동시 실행 지연과 통신 단절/리셋 시 출력을 확인한다. 이번 확인은 문서와 핀·가격 계산까지다.

## USB 연결 검토 - 10/2 후속

**확정 VND018의 검토 기준은 YD-ESP32-S3의 USB-C 두 포트 구조**다. [제조사 자료](https://github.com/vcc-gnd/YD-ESP32-S3)는 한 포트를 CH343P USB-UART, 다른 포트를 S3 직접 USB로 설명한다. V1.4 회로도에서 UART0(GPIO43/44), 직접 USB(GPIO19/20), 자동 리셋 회로를 대조했다. 실제 보드와 Jetson에서 열거·통신을 시험한 결과는 아니다.

```text
Jetson USB 호스트 포트
  └─ 데이터 USB 케이블 → VND018의 USB-UART 포트
      └─ CH343P → ESP32 UART0 (GPIO43/44): 주행 명령·피드백 우선안

별도 개발용 USB 연결(필요할 때)
  └─ VND018의 S3 직접 USB 포트 → GPIO19/20: 업로드·디버깅 후보
```

- 주행용 UART 통신에는 첫 경로의 USB 케이블 한 개로 연결할 수 있다. 두 경로를 동시에 쓰려면 물리적으로 각각 연결한다. S3 직접 USB의 장치 노출은 펌웨어 설정과 절전 상태에 영향을 받는다.
- 앞선 **Waveshare** 후보는 USB-C 한 개 → CH334F 허브 → CH343P와 S3 USB의 구조였다. 이는 [Waveshare 설명과 회로도](https://docs.waveshare.com/ESP32-S3-DEV-KIT-N8R8)에 대한 이전 조사이며, **VND018에 내장 허브가 있다고 적용하지 않는다**.
- [CH343 제조사 WCH의 Linux 문서](https://github.com/WCHSoftGroup/ch343ser_linux)는 기본 `cdc_acm` 드라이버로 일반 직렬 통신이 가능하다고 명시한다. 일반 UART 때문에 처음부터 외부 커널 모듈을 설치할 이유는 없다. 제조사 전용 흐름 제어/GPIO 기능과 구분한다. CH343과 [S3 직접 USB](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-guides/usb-serial-jtag-console.html) 모두 `ttyACM*`로 보일 수 있으므로 번호만으로 구별하지 않는다.
- 실물에서 `lsusb -t`, `udevadm info`, `/dev/serial/by-id/` 또는 USB 경로로 식별하고 장치별 별칭을 부여한다. 고유 serial이 없는 경우 물리 경로도 함께 사용한다. 앞선 Jetson 원격 조회는 시간 초과했으므로 실제 드라이버 설정·장치 열거 확인으로 기록하지 않는다.
- CH343P의 DTR/RTS는 부팅/리셋 회로와 연결된다. 포트 열기·닫기와 업로드가 MCU를 리셋할 수 있어 호스트 설정을 검토하고, 리셋되더라도 출력 OFF·이전 명령 무효·새 ARM 필요라는 계약을 유지한다. [Espressif 자동 리셋 설명](https://docs.espressif.com/projects/esptool/en/latest/esp32s3/advanced-topics/boot-mode-selection.html)
- 직렬 속도를 예제 기본값 115200 bps로 고정하지 않는다. payload 상한 1536바이트와 헤더/CRC 8바이트를 매번 50 Hz로 보내면 한 방향에 `1544 × 50 × 10 = 772,000 bit/s`가 필요하다(8N1). 이는 상한 예시이며, 실제 프레임 크기·빈도로 속도를 정하고 유한 큐와 지연을 측정한다.
- 카메라·LiDAR는 Jetson에 연결한다. MCU에는 안정된 전원과 데이터 케이블을 준비하고 USB/외부 전원의 역급전 조건을 확인한다. 모터·서보 전력은 별도로 공급한다. 직접 USB 디버그 연결이 남아 있어도 주행 UART가 단절되면 구동 계약에 따라 정지해야 한다.

입고 후 확인 대상은 납품 판본/헤더 → USB 장치 구분 → 16 MB Flash·8 MB PSRAM 인식/업로드 → 명령·IMU·엔코더 동시 통신 → 포트 재개방/케이블 단절/보드 리셋 → 이전 명령 거부와 정지 유지다. 문서 검토가 이 실물 시험을 대신하지 않는다.

| ESP32의 TX/RX를 ST3215-HS의 단선 반이중 TTL 버스에 연결하고 응답을 수신 | [Waveshare Bus Servo Adapter (A), WVS-25514](https://eleparts.co.kr/goods/view?no=18619565), VAT 포함 **10,032원**, 1개 | **지원 30만 원에 포함 확정**. ESP32가 추가된 Servo Driver with ESP32와 다른 제품 |

서보 어댑터 금액은 확정 Excel 기준, IC 금액은 앞선 조회 당시 표시가다. 재고·납기는 확정하지 않았다. 확정안의 엘레파츠 배송 3,000원은 MD20A·서보 어댑터 주문에 배정되어 있다. IC의 추가 합배송 가능 여부와 별도 주문 배송비는 확정하지 않았다. 디바이스마트의 [같은 TI IC](https://www.devicemart.co.kr/goods/view?no=15673116)도 VAT 포함 495원/개, 최소 5개 2,475원으로 확인했다. IC 가격을 엔코더 인터페이스 완성 비용이라고 부르지 않는다.

### 서보 어댑터

`ESP32 UART → Bus Servo Adapter (A) → ST3215-HS` 경로다. MD20A는 주행 DC 모터용이므로 이 기능을 대신하지 않는다. [제조사 결선 안내](https://docs.waveshare.com/Bus_Servo_Adapter_A/Product-Wiring-Example)는 ESP32 UART 연결을 지원하며 **점퍼 A 위치, 컨트롤러 TX → 어댑터 TX, RX → RX**로 명시한다. 이 제품 단자의 표기 기준을 따라야 하며 일반 UART 관행으로 무조건 교차 배선하지 않는다. GND도 공통으로 연결한다.

[어댑터 회로도](https://files.waveshare.com/wiki/Bus_Servo_Adapter_A/Bus_Servo_Adapter_A.pdf)를 렌더링해 3.3 V 버퍼와 TX 신호에서 생성하는 내부 TXEN을 확인했다. 최종 선택한 이 어댑터는 MCU의 별도 방향 GPIO16을 사용하지 않으므로 위 핀 표에 17개 배치/6개 여유를 반영했다. 단선 버스의 응답 대기·송수신 순서는 소프트웨어에서 관리한다.

서보 전원은 통신과 별도다. [ST3215-HS의 6~12.6 V 범위](https://www.waveshare.com/product/modules/motors-servos/st3215-hs-servo-motor.htm)에 맞는 전원(예: 적정 용량의 12 V)을 어댑터 전원 단자에 공급한다. 어댑터가 6S 배터리 전압을 서보 전압으로 내려주는 제품은 아니며, 회로도상 서보 전원은 DC 입력에서 전달된다. ESP32 USB 전원으로 서보를 구동하지 않는다.

### 엔코더 수신 회로

`PGE-213 A/B → SN74LVC2G17 두 입력 → 3.3 V A/B → ESP32 PCNT` 경로다. [PGE-213 판매 회로](https://www.motorbank.kr/goods/goods_view.php?goodsNo=1000009561)는 A/B를 Vcc로 당기는 4.7 kΩ 저항과 5 V 예시를 제시한다. 엔코더를 5 V로 공급하는 현재 검토 조건에서 ESP32에 직접 넣지 않는다. 3.3 V로 낮추는 것은 엔코더의 전원 전체가 아니라 출력 A/B 신호다.

[TI 데이터시트](https://www.ti.com/lit/ds/symlink/sn74lvc2g17.pdf)는 입력 5.5 V 허용, 5 V → 3.3 V 하향 변환, 2채널 비반전 Schmitt 입력을 명시한다. IC 전원은 3.3 V로 공급하고 공통 GND를 사용한다. A/B 위상 관계를 유지하는 두 비반전 채널로 사용할 수 있다. **엔코더를 12/24 V로 공급해 해당 전압까지 올라가는 신호를 이 IC에 바로 넣는 구성은 해당하지 않는다.** 실제 납품 출력·회로·최대 회전수의 파형과 계수 손실은 별도로 확인한다. SOT-23-6 변환 기판을 사용할 수 있으며 패키지별 핀 번호를 확인한 뒤 조립한다.

### 남은 제작비 범위

서보 어댑터 **10,032원은 지원 구매안 299,919원에 이미 포함**되어 있으므로 제작비에 중복 산입하지 않는다. 기존 두 후보 합계 12,452원은 예산 분류 수정 전 이력이다. 자체 제작비 쪽에는 엔코더 변환 IC 최소 주문 5개 **2,420원**과 변환 기판·커패시터·필요 시 별도 배송비를 검토한다. 기구·배선 등 다른 제작비도 같은 약 10만 원에 들어가므로 IC 가격만으로 전체 제작비가 충분하다고 판정하지 않는다.

## ESP32 이름과 가격 차이를 읽는 방법

`ESP32-S3-WROOM-1-N8R8`과 `DevKitC`는 서로 다른 층위를 가리킨다.

1. **ESP32-S3: 칩 계열.** ESP32, S2, S3, C3, C6 등은 CPU·무선·USB·주변장치가 다른 제품군이다. 번호가 커질수록 모든 기능이 상위가 되는 순위표가 아니다. 예를 들어 C3는 단일코어 RISC-V 최대 160 MHz, S3는 듀얼코어 LX7 최대 240 MHz다. [Espressif 제품 비교](https://www.espressif.com/en/products/socs/esp32c3/overview)
2. **WROOM-1: 칩을 얹은 모듈.** 칩과 메모리·안테나 등을 작은 금속 실드 모듈로 묶은 제품이다. 이 모듈만 파는 저렴한 상품은 USB와 핀 헤더가 달린 완성 개발보드와 다르다.
3. **N8R8 / N16R8: 해당 모듈의 메모리 옵션.** 여기서 N8R8은 Flash 8 MB + PSRAM 8 MB, N16R8은 Flash 16 MB + PSRAM 8 MB다. R8을 생략한 N8과 동일시하지 않는다. [WROOM-1 데이터시트](https://www.espressif.com/sites/default/files/documentation/esp32-s3-wroom-1_wroom-1u_datasheet_en.pdf)
4. **DevKitC / DEV-KIT / 호환 보드: 모듈 주변의 기판.** USB 회로, 전원 레귤레이터, 리셋 회로, 외부로 꺼낸 GPIO, 핀 납땜 여부, 회로도 제공이 달라진다. 같은 S3 모듈을 써도 작은 보드에서 필요한 핀을 모두 꺼내 놓았다는 보장은 없다.
5. **판매처·유통 조건: 최종 가격.** 동일 사양이어도 제조사, 수입 경로, 유통 마진, VAT 표시, 배송비, 납기에 따라 결제액이 달라진다. 기존 43,450원 N8R8, Waveshare 22,990원 N8R8(헤더 옵션 제외), 최종 18,150원 N16R8은 모두 S3 CPU와 PSRAM 8 MB를 쓰며 최종 보드의 Flash는 16 MB다. 가격 비율을 CPU 성능 비율로 해석하면 안 된다. 개별 가격 차이의 정확한 원가 구성은 공개 자료로 확인하지 않았다.

현재 차량에는 **S3 + 필요한 GPIO 노출 + USB 연결 + 확인 가능한 회로도**가 구매 판단의 중심이다. Flash를 더 늘리는 것보다 현재 배치를 그대로 사용할 수 있는 보드를 고르는 편이 유용하다.
