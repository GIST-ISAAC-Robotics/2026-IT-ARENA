# IT ARENA 실차 전장 연결 기준 — 사용자 확정 구성

- 기준 커밋: f3a2f7c031a52a52b4166c2df91d4377066c3654
- 기준일: 2026-11-12 (전원·GPIO 배치 유지, 엔코더 제조사 답변·CF 칩 식별 전달 반영)
- 목적: 이미 선정·구매한 부품을 우선 사용하고, 사용자가 승인한 전원·장치 배치만 연결한다.
- **이 문서는 승인되지 않은 U1/U2, 버퍼, 추가 저항 네트워크, 추가 퓨즈·스위치, 별도 안정화 회로를 설계에 추가하지 않는다.** 과거 임시 회로 기록은 현행 설계 근거로 사용하지 않는다. 사용자가 희망한 임시 IC 선택은 TXS0108E 계열이며 TXB0108 계열은 선택 대상이 아니다. 이는 CF-0108 실물 확인 전의 잠정 부품 방향이지 별도 임시 회로를 만들라는 뜻이 아니다.

**핀별 조립 기준:** [ESP32 통합 배선도 v1](ESP32_GPIO_WIRING_2026_11_11.md) · [그림 두 장과 연결표](schematics/esp32_gpio_wiring_v1.html). 아래 VND018은 구매 기록의 모델명이다. 11/11 실측 보드는 ESP32-S3·Flash16 MB/PSRAM8 MB 호환품이며 PCB 제조사/판본과 USB 브리지 세부 형번은 미확인이다. YD 보드 물리 핀 배열을 실물로 확정하지 않는다.

### 전원 관련 금지 사항
- ESP32는 Jetson USB로 전원 공급한다. VND018의 다른 USB-C 포트에 외부 5 V를 동시에 공급하지 않는다.
- IMU는 ESP32 3V3를 사용한다. IMU의 3Vo는 전원 입력이 아니다.
- 엔코더 전원은 **J01 CH4 5 V / 0.5 A**에서 공급한다. J01 출력은 XT30 암 커넥터이므로 보유 XT30 수 케이블을 사용한다. 기존 MCU 전용으로 표기된 CH4는 ESP32가 Jetson USB로 전원을 받으므로 비어 있다. Jetson J12와 VND018 5Vin은 사용하지 않는다.
- 서보는 M01의 12 V / 2 A 단일 채널만 사용한다. CH5/CH6은 각 독립 출력이며, 제조사가 병렬 운전/전류 공유를 명시적으로 허용하기 전에는 출력끼리 연결하지 않는다.
- 별도 DC-DC, 추가 전원 분배기, 대용량 콘덴서, U1/U2 버퍼 회로는 현재 승인 구성에 포함하지 않는다.

## 4. PGE-213 엔코더와 CF-0108

**11/12 근거와 후속 정정:** 모터뱅크의 **NPN 오픈 컬렉터·출력 풀업 내장** 답변은 사용자 전달문 근거이며 답변 원문은 미열람이다. 이후 사용자가 사진 두 장과 함께 기존 검토 대상은 **이미 핀헤더가 납땜된 별도 보드**였다고 정정했다. 앞서 그 보드의 `69KG4/CHQ7`과 B채널 인쇄 문제를 신규 CF-0108에 귀속한 기록을 바로잡는다. 아래 §4.4는 두 사진을 직접 판독한 구분이며 전압·파형 시험 결과는 아니다. 전달문의 과거 계획·작업 지침은 새 지시로 채택하지 않는다.

### 4.1 사용자가 제공한 PGE-213 제조사 상세자료에서 확인된 내용

| 항목 | 자료 표기 |
|---|---:|
| 모델 | PGE-213, 42파이 모터용 케이스 일체형 마그네틱 엔코더 |
| 채널 | 2채널 |
| 펄스 | 7 PPR / 모터 1회전 |
| 공급 전압 | DC 4.5–24 V |
| 입력 전류 | 14–20 mA |
| 출력 전류 | 최대 20 mA |
| 출력 누설 전류 | 최대 10 µA |
| 출력 상승/하강 시간 | 기준 조건에서 0.5 µs / 0.2 µs, 최대 1.5 µs |
| 커넥터 | XHP-4, 피치 2.5 mm |
| 커넥터 핀 | 1=VCC, 2=GND, 3=HA, 4=HB |
| 모터 단자 | 5=모터 −, 6=모터 + |

엔코더 전원은 **J01 CH4의 5 V / 0.5 A 출력**에서 공급한다. J01 출력 커넥터는 XT30 암이므로 보유한 XT30 수 리드를 사용한다. PGE-213 소비전류 14–20 mA는 CH4 0.5 A 한도 이내다. Jetson J12와 VND018 5Vin은 사용하지 않는다.

### 4.2 제조사 출력 회로도에서 읽히는 사항

사용자가 제공한 상세자료의 출력 회로도에는 다음 부품/연결이 그려져 있다.

- VCC 입력선에 10 Ω 직렬 저항
- VCC와 GND 사이 100 nF
- HA/HB 각 출력단에 4.7 kΩ 저항이 VCC 레일 쪽으로 연결된 형태
- 각 출력선에 470 Ω 직렬 저항
- 각 출력선에서 GND로 연결된 SMAJ26A 보호소자 및 10 nF 커패시터

11/12 전달 문서와 후속 사용자 제공 문의/답변 캡처를 직접 대조해, 모터뱅크 답변의 출력 방식 **NPN 오픈 컬렉터**·출력 풀업 **내장**을 확인했다. [상세 이미지 재검토와 원인 분석](../sensors/PGE213_ENCODER_HARDWARE_2026_11_12.md#상품-원문-재검토--원인-분석)에 근거와 한계를 모았다. 저항·커패시터 값과 VCC 연결은 위 기존 회로도 판독 근거이며 답변 자체가 그 값을 모두 재확인했다는 뜻은 아니다. 오픈 컬렉터는 출력 트랜지스터가 LOW로 당기는 방식이며 HIGH 전압은 풀업에 의해 결정된다. 기존 회로도와 답변을 함께 보면 엔코더 VCC=5 V일 때 HA/HB HIGH가 5 V 쪽으로 올라갈 것으로 예상되므로 ESP32에 직접 연결하지 않는다.

**GPIO 직접 입력 대신 기존 5 V→3.3 V 변환 경로를 유지한다.** 후속 손 회전/모터 시험에서는 LOW 부근 사용자 측정과 회전 중 입력 미검출을 확인했으며, 정상 HIGH/LOW 전환·출력 파형은 미검증이다. 내부 풀업을 제거하는 기판 개조는 이번 범위에 없다.

### 4.3 출력 방식과 변환 필요성

- 현재 PGE-213은 제조사 답변 전달에 따라 NPN open-collector·내부 풀업형으로 기록한다. push-pull 여부를 다시 미정으로 두지 않는다.
- 5 V 전원과 VCC 방향 내부 풀업 때문에 출력 HIGH가 5 V가 될 수 있으므로 ESP32-S3 GPIO에 직접 연결하지 않는다.
- 3.3 V pull-up을 사용해 직접 읽을 수 있는 경우는 출력단이 open-collector/open-drain이고, 5 V로 연결된 내부 pull-up이 없거나 제조사가 3.3 V pull-up 사용을 명시적으로 허용한 경우에 한한다. 현재 자료만으로 이 조건을 확정할 수 없다.
- PGE-213은 출력 전류 최대 20 mA로 표기되어 있지만, 이는 3.3 V 직접 연결 허용 여부나 내부 pull-up 제거 가능성을 뜻하지 않는다.

### 4.4 신규 CF-0108과 기존 헤더 보드의 구분

| 실물 | 사용자 설명 / 사진에서 읽힌 표시 | 식별 범위 |
|---|---|---|
| 사진 1, 헤더 미납땜 | 이번에 주문한 CF-0108. 칩 `YF08E / 21KG4 / C2VN`, TI 로고. 상단 `VB B1 B2 B3 B4 B5 B6 B7 B8 GND`, 하단 `VA A1 A2 A3 A4 A5 A6 A7 A8 OE` | TXS0108E 마킹·TSSOP-20 외형과 일치. 판매 모델 CF-0108은 사용자 구매 설명 근거이며 PCB 제조사/판본은 사진으로 확정하지 않음 |
| 사진 2, 헤더 납땜됨 | 앞선 웹 검토 대상. 칩 `YF08E / 69KG4 / CHQ7`, TI 로고. 상단 `VB B1 B3 B4 B4 B5 B6 B7 B8 GND`, 하단 `VA A1 A2 A3 A4 A5 A6 A7 A8 OE`. C1/C2 표시 | 동일 TXS0108E 마킹·TSSOP-20 외형과 일치하나 판매 모델/제조사/판본 미확인. CF-0108이라는 이름을 붙이지 않음 |

- 두 PCB는 인쇄·패턴이 다르며 같은 보드 모델/동일 내부 연결이라고 단정하지 않는다. 다만 **두 칩 모두 YF08E로 읽혀 TXS0108E 계열로 식별**된다. [TI 공식 마킹표](https://www.ti.com/lit/ds/symlink/txs0108e.pdf)의 TSSOP-20 PW 항목과 대조했다. 다른 하단 문자열은 부품 형번 차이의 증거가 아니며 TI는 추가 마킹에 로트 추적/환경 분류 등이 포함될 수 있다고 설명한다. 각 문자열의 상세 의미·정품성·동작은 미확인이다.
- 사진 2의 `B2` 누락·`B4` 중복은 **실크 오인쇄로 의심**한다. 사진만으로 B2 전기 채널이 없거나 특정 패드가 B2라고 확정하지 않는다. 이 문제를 정상 순번이 보이는 사진 1에 적용하지 않는다.
- 두 사진 모두 칩 옆 세라믹 부품 두 개가 보이지만 정확한 값/접속은 미측정이다. 추가 커패시터 구매를 지정하지 않는다. 패드 단락·채널 도통·OE와 전기적 정상 동작은 후속 확인이다.
- 원본 두 사진은 비공개 `build/encoder_board_identity_20261112/`에 바이트 그대로 보존하고 해시를 [배선 JSON](schematics/esp32_gpio_v1.json)의 `evidence_update.photo_sha256`에 기록했다.
- 엔코더의 10 nF 출력 부하에서 TXS0108E의 펄스 품질은 여전히 미검증이다. 칩 마킹 일치와 실제 결합 적합성을 구분한다.

### 4.5 CF 수령 후 남은 확인

부품 미수령·칩 후보 선택 단계는 끝났고, **패드/채널·전원/OE 확인 → 변환 파형 → PCNT 계수**가 남는다. 무전원 상태에서 패드 단락과 채널 대응을 확인하고, MCU GPIO를 분리한 상태에서 VA=3.3 V/VB=5 V와 A측 HIGH/LOW·펄스 품질을 확인한 뒤 연결한다. 엔코더 출력의 10 nF는 신호 부하이며 CF의 전원 디커플링 C1/C2와 다른 항목이다. 별도의 U1/U2·저항 네트워크를 추가하지 않는다.

### 4.6 핀 배정 상태

- 엔코더 전원: J01 CH4 5 V / 0.5 A → PGE-213 XHP-4 pin 1 VCC, pin 2 GND. 엔코더 신호 GND는 ESP32/CF-0108과 공통 기준을 가져야 한다.
- 엔코더 커넥터의 논리 핀은 제조사 자료 기준 1=VCC, 2=GND, 3=HA, 4=HB로 확인됐다.
- ESP32 쪽 GPIO4/5는 프로젝트의 엔코더 A/B 후보 할당으로만 남겨 둔다.
- **VND018 P1/P2 물리 헤더 번호와 CF-0108 모듈의 실제 패드 번호는 아직 최종 매칭하지 않았다.**
- 현재 v1의 1번/2번 채널 설계는 신규 CF-0108의 A1/B1·A2/B2 실크와 맞으므로 유지한다. 실제 도통·파형 확인은 별도다. 앞선 1번/7번 대안은 기존 헤더 보드의 실크 문제에 대한 웹 세션 후보였으며 신규 CF의 배선 변경 근거로 사용하지 않는다. 어느 보드든 대응하는 Bn→An 한 쌍을 쓰면 GPIO4/5 배정은 바꿀 필요가 없다.

### Bus Servo Adapter (A) / ST3215-HS
- M01의 12 V / 2 A 단일 채널을 Adapter A의 DC 5.5×2.1 입력 또는 해당 전원 단자에 연결한다.
- Adapter A 서보 포트에 ST3215-HS 한 개를 연결한다.
- ESP32 GPIO17(TX)→Adapter A H2 TX/TXD, GPIO18(RX)←H2 RX/RXD, GND↔GND로 연결한다. 이 제품은 일반 UART처럼 TX/RX를 교차하지 않는다.
- Waveshare UART 안내에 따라 점퍼는 A 위치로 둔다. 어댑터 H2 핀 실크와 공식 배선 예시를 대조해 연결한다.
- **11/12 제한 실측:** [서보 보고서](../sensors/ST3215_HS_HARDWARE_2026_11_12.md)에서 GPIO17/18·점퍼 두 개 A·ID1/1 Mbps와 서보혼/링크 없는 약±10° 왕복·토크 해제를 확인했다. 전원은 서보 보고12.1–12.2 V였으며 실제 조향 부하/구속 전류와 외부 각도 정확도는 미검증이다.
- ST3215-HS의 stall 전류 2.4 A와 정상 조향 전류는 다르다. 기계적 끝단 구속을 하지 않고 실제 조향 전류·전압강하를 측정한다. M01 CH5/CH6 두 채널을 병렬 연결해 4 A를 얻는 방법은 제조사 병렬 운전 허용이 확인되지 않아 사용하지 않는다.

## 6. 카메라와 LiDAR

- 납품된 B0390은 **카메라 자체가 22핀**이며, 사용자가 2026-11-10 **22↔22 FPC로 Jetson에 연결**했다고 확인했다. 판매처 본문의 15핀 표기를 현물에 적용하지 않는다. 실제 CSI 포트는 소프트웨어 감지 결과와 대조하며, 별도 전원선을 카메라 FPC에 연결하지 않는다.
- FPC 접점 방향은 양쪽 커넥터 실물을 확인하고 잠금쇠를 연 상태에서 삽입한다.
- RPLIDAR C1 USB 어댑터를 Jetson USB-A에 연결한다. ESP32와 다른 USB 스택을 우선 사용한다.

## 7. 정격상 주의 — 승인된 배치를 변경하라는 뜻은 아님

1. J01 CH1은 19 V / 2.3 A다. 2.3 A는 공급 한도이지 Jetson 상시 소비전류가 아니다. 실제 부하에서 전압 강하와 재부팅 여부를 확인한다.
2. 공식 M01 입력 표기는 24–36 V다. 6S 배터리는 만충 25.2 V, 공칭 22.2 V이므로 운용 중 24 V 아래로 내려갈 수 있다. 지급 구성을 바꾸지 않되 팩 전압별 M01 동작과 출력 안정성을 시험하고 불안정하면 부하 운전을 중단한다.
3. MD20A는 6–30 V 입력이며 역극성 보호가 없다. VB+/VB− 극성을 확인한다.
4. 서보는 M01 12 V / 2 A 한 채널로 우선 운용한다. 2 A 한도에 걸리면 기계적 구속·링크 간섭·서보 설정을 먼저 점검한다. 별도 전원부는 실측 후에만 검토한다.

## 8. 구매 원칙

현재 구매 목록과 이미 선정된 부품을 우선 사용한다. 이 문서만으로 새 전자회로 부품의 추가 구매를 확정하지 않는다.

현재 추가 구매를 지정하지 않는 항목:
- U1/U2 버퍼 IC 및 변환 기판
- 별도 DC-DC 모듈
- 추가 레벨시프터
- 임의의 저항 네트워크
- 추가 콘덴서/대용량 커패시터
- 별도 전원 분배 PCB

먼저 기존 케이블·점퍼선·동봉품·CF-0108 실물을 확인한다. 추가 부품은 실제 연결 방식과 정격이 확인된 뒤 필요한 최소 수량만 구매 목록에 추가한다.

## 9. 근거와 미확인 범위

- PGE-213의 NPN 오픈 컬렉터·내부 풀업은 11/12 제조사 답변 전달로 확인했다. 공급·핀·저항/커패시터 값은 기존 상세자료 근거다. 5 V 공급 때 실제 HIGH/LOW와 파형은 미측정이다.
- 신규 CF-0108과 모델 미상 기존 헤더 보드를 사진으로 분리했고, 두 칩의 `YF08E`를 공식 표와 대조해 TXS0108E로 마킹 식별했다. 패드/채널·OE·정상 동작과 PGE 출력 10 nF 부하에서의 펄스 품질은 후속이다. 근거 범위와 구조 영향은 §4에 모았다.
- ESP32-S3 GPIO 절대 최대 입력 전압은 3.6 V다. 5 V push-pull 엔코더 출력을 직접 연결하지 않는다.
- J01 CH4는 5 V / 0.5 A 출력이며 현재 ESP32는 Jetson USB에서 전원을 받으므로 CH4를 엔코더 전용으로 재배정한다. J01의 출력 커넥터는 XT30 암이다. Jetson Orin Nano Developer Kit USB-A 포트 스택의 VBUS 한도는 3 A로 안내되어 있다.
- NVIDIA의 15→22 변환 FPC 안내는 카메라 쪽이 15핀일 때 해당한다. 현재 B0390 실물은 사용자 확인에 따라 22↔22 FPC를 사용한다. 상세 근거는 [케이블 대조 §3.1](PROCUREMENT_AND_CABLES_2026_11_08.md#31-b0390-ffc--어느-동봉-케이블을-쓰는가)을 따른다.
