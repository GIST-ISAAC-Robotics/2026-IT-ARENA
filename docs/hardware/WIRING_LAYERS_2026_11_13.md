## 1. 배치 기준

원본은 `11.12 RC카_패키징_작업본 확인용.step`, SHA-256 `37890b25fc69c5c56e400b6236872ab480dc96016211055842722d52769a98a4`다. 이번 작업에서 원본 해시를 재확인하고 기존 변환 좌표·형상 경계를 대조했다. 원본 STEP, 시뮬레이션 모델, 실제 배선을 변경하지 않았다.

| 구역 | 부품 | STEP 기준 높이·취급 |
|---|---|---|
| 상부 2단 | M01, 카메라 | M01 Z193~224 mm. 카메라는 구형 B0183 대체 형상의 장착층에 B0390을 배정한다. 실물 광학 중심·FPC 출구는 별도 확인한다. |
| 상부 1단 | Jetson, J01, 배터리 Y 분기 | Jetson Z153~188 mm, J01 Z153~184 mm. Y 분기는 사용자 지정 추가 배치안이다. |
| 중간 LiDAR 층 | C1 | 본체 Z104.8~146.1 mm, 광축 추정 Z134.6 mm. 기본 리드까지 포함한 부품 경계와 본체 경계를 구분한다. |
| 하부 공간 | 배터리, MD20A, 서보 어댑터, 모터·엔코더, 서보, ESP32, IMU | 높이가 다른 받침을 포함한다. MD20A Z97~119 mm, 서보 어댑터 Z91~106 mm, 배터리 Z68~102 mm, ESP32 Z14~26 mm, IMU Z37~42 mm이며 모두 광축 아래다. |

위 높이는 CAD 경계이며 설치 실측이 아니다. 그림은 층을 펼쳐 그린 개념도이므로 그림의 길이나 위치에서 전선 길이를 재면 안 된다.

### 이번에 층을 배정한 부품

- **CF-0108:** 하부 ESP32 인근의 절연된 고정면. ESP32와 엔코더 신호선을 하부에서 정리한다. 기존 STEP의 좁은 간격 때문에 정확한 XY 위치·고정 공간은 현물로 확인한다.
- **STOP 스위치:** 하부 차체 측면. GPIO8·TGND 두 선을 하부 안에서 연결한다. 바퀴·기어·조향 링크를 피하고 손이 닿는 방향으로 장착한다. 상층부로 올리는 선은 없다.
- **C1 USB 어댑터:** STEP에 없던 부품이다. **기본 리드 끝 근처의 광축 아래**에 고정하는 안으로 그렸다. C1 리드는 아래에서 정리하고 USB만 Jetson으로 올린다. 리드 길이·어댑터 외형·고정 공간은 아직 실물로 검증하지 않았다.
- **T3V3/T5V/TGND:** 하부. TGND의 기존 5접점과 ESP32 GND 4핀 배정은 유지한다.
- **배터리 Y 분기:** 상부 1단 J01 근처. 하부 배터리에서 공통 +/− 한 쌍을 올린 뒤 J01 CN1과 M01 CN1로 갈라진다. 각 가지는 +/− 2심이며, +끼리·−끼리 연결한다. 분기 전 공통 구간은 두 PDB의 합계 입력 전류가 흐르므로 기존 전력 케이블을 사용하며 센서용 점퍼선으로 대체하지 않는다. 케이블 길이·고정은 조립 확인 대상이다.

## 2. LiDAR 광축 높이를 지나는 연결

| 번호 | 연결 | 위아래 이동 | 통과량 |
|---|---|---|---|
| P1 | 배터리 → 상부 Y 분기 | 하부 → 상부 1단 | 전원 +/− 1쌍 |
| P3 | M01 CN2(CH1) → MD20A VB+/VB− | 상부 2단 → 하부 | 전원 +/− 1쌍 |
| P4 | M01 CN6(CH5) → Servo Adapter 전원 | 상부 2단 → 하부 | 12 V +/− 1쌍 |
| P5 | J01 CN5(CH4) → T5V/TGND | 상부 1단 → 하부 | 5 V/GND 1쌍 |
| U1 | Jetson ↔ ESP32 | 상부 1단 ↔ 하부 | USB 케이블 1개 |
| U2 | Jetson ↔ C1 USB 어댑터 | 상부 1단 ↔ 광축 아래 | USB 케이블 1개 |

**전원 4쌍 = 전력 도체 8가닥, 여기에 USB 완성 케이블 2개다.** 전원쌍을 각각 한 묶음으로 셀 때 총 **6개 연결 묶음**이다. USB 내부 도체까지 풀어 센 값이 아니며, 6묶음의 외경·단면적이 같다는 뜻도 아니다. CF·STOP의 하부 배치로 추가되는 층간 연결은 **0개**다.

Y→J01은 상부 1단 안에서 끝나고, **P2(Y→M01)는 상부 1단→2단만 연결하므로 광축 높이를 지나지 않는다.** 이전 하부 Y 분기안의 5쌍·USB2개에서 전원 한 쌍이 줄었다. 전기적 목적지와 극성은 그대로다. C1 어댑터를 위층으로 바꾸면 U2 구간은 USB 대신 C1 기본 리드가 통과한다. 이는 현재 그림과 다른 배치안이다.

## 3. 같은 구역에서 끝나는 케이블

- **Y 분기 → 두 PDB:** J01 CN1에는 같은 상부 1단에서, M01 CN1에는 P2로 상부 2단까지 연결한다. 모두 광축 위에서 끝난다.
- **J01 → Jetson:** CN2(CH1)의 두 도체가 **배럴 전원 케이블 1개**로 이어진다. 두 부품은 같은 상부 1단이며 광축 높이를 지나지 않는다. 중앙 +, 외곽 − 연결을 유지한다.
- **B0390 → Jetson:** 실제 연결 이력의 **22↔22핀 FPC 1개**. 상부 카메라 브래킷에서 Jetson CSI로 이어지며 광축 높이를 지나지 않는다. 별도 카메라 전원선은 없다.
- **ESP32 ↔ IMU/CF/STOP/MD20A/Servo Adapter:** 하부에서 끝난다. MD20A→모터 2선과 Adapter→서보 전용 3선 케이블도 하부 내부다.
- **C1 → USB 어댑터:** 이 배치안에서는 기본 리드를 광축 아래로 고정한다.

회로도의 굵은 선은 다심 케이블을 한 선으로 표현한 것이다. Jetson 전원 +/−나 서보 D/V+/GND를 서로 연결하라는 뜻이 아니다. 개별 핀 관계는 [연결표](schematics/esp32_gpio_pin_table_v1.md)를 따른다.

## 4. 기둥별 배선 분산안

좌우는 차량 전방을 바라보는 기준이다. 기존 [STEP 검토 §5](PACKAGING_STEP_REVIEW_2026_11_12.md#5-실제로-기둥을-오르내릴-배선)의 제안을 현재 확정 채널과 C1 어댑터 배치안에 맞췄다.

| 기둥의 앞/안쪽 면 | 연결 묶음 | 양 |
|---|---|---|
| 후방 왼쪽 | U1 + U2 | USB 2개 |
| 후방 오른쪽 | P1 + P5 | 전원 2쌍, 4가닥 |
| 전방 오른쪽 | P3 | 전원 1쌍, 2가닥 |
| 전방 왼쪽 | P4 | 전원 1쌍, 2가닥 |

각 전원의 +/−는 함께 붙여 배선하고 USB 두 개는 겹쳐 감기보다 나란히 고정한다. 후방 기둥의 앞/안쪽 면을 사용하며 뒤·외측으로 감아 차량 외형을 늘리지 않는다. **STEP의 뒤쪽 4×4.2 mm 홈에 USB 두 개나 전원 네 가닥이 전부 들어간다고 판정한 것은 아니다.** 케이블 외경·단자·타이 머리·스트레인 릴리프까지 확인해야 한다.

광축을 가로지르는 긴 수평선을 만들지 않도록, 상판 아래 횡단 구간은 광축보다 위로 고정하고 C1 몸체·회전부와 Jetson 팬을 피한다. 기존 상판 틈 약6.8~7 mm나 슬롯10×3 mm는 완성 USB 플러그 통과를 보증하지 않는다. 이번 그림은 필요한 연결량과 임시 경로를 보여 주며 새로운 가림각·주행 성능·통전 안정성을 검증하지 않는다.

## 5. 생성과 검증

`python scripts/render_esp32_wiring.py`와 `python scripts/render_vehicle_wiring_layers.py`로 SVG·HTML·연결표를 생성한다. PNG는 동일 SVG의 브라우저 렌더 사본이다. 원본 해시·기존 전기적 연결 보존·통과 케이블 수·문서 링크·렌더를 확인한다. 층별 그림은 전체 결선도와 별개로 한 장이며, 실물 조작이나 펌웨어 변경은 없다.

[현재 Y 분기·간격 조정 검증](../../artifacts/validation/2026-11-13/wiring_upper_y_balance_v1/validation.json): 기존 결선 필드 동일, STEP 해시 일치, 통과량·문서 링크 확인, 두 그림의 글자 겹침·영역 이탈 0건 및 PNG 육안 검토 완료. 실제 통로 수용 여부는 미검증이다.

이전 [하부 Y 배치안 검증](../../artifacts/validation/2026-11-13/wiring_cable_layers_v1/validation.json)은 당시 결과로 보존한다. 이후 사용자 지정으로 Y 위치와 광축 통과량이 바뀌었으며, 이전 5쌍 판정은 현재 배치에 적용하지 않는다.
