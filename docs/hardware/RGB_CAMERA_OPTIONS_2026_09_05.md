# 별도 RGB 카메라 후보

후속 조사: 현재의 국내 배송 포함 가격·신규 후보·공급 조건은 [2026-09-08 RGB·LiDAR 재조사](RGB_LIDAR_DOMESTIC_RESEARCH_2026_09_08.md)를 먼저 확인한다. 아래는 9월5일 견적 이력이며 엑셀은 이번 조사에서 수정하지 않았다.

2026-09-05 사용자 후속 요청 반영. 로지텍은 제외하고 Arducam 같은 비전용 카메라를 검토한다.
크기 최소화는 우선 선정 기준에서 제외하되 차량 외형 설계 목표를 변경한 것은 아니다.
MCU는 ESP32-S3 잠정 후보이며 정확한 개발보드·가격·담당 예산은 미정이다.

## 권고

**국내 구매 저가 후보는 Voltly OV2710 VLT-CAM014, 글로벌 셔터 비교 후보는 Arducam B0385다.**
사용자는 B0385에서 직접120fps 동작을 확인했다고 밝혔다. 당시 해상도·코덱은 미확인이므로
문서의100fps 프로필을 사용자 실물의 최대값으로 단정하지 않는다.

## 연결과 사용 난이도

카메라는 **USB로 Jetson에 연결하여 영상을 처리하는 구조**를 기준으로 한다. 저가 모듈의 케이블 동봉 여부는 별도 확인한다.
ESP32-S3를 카메라 영상 중계기로 추가하지 않는다. ESP32-S3의 ToF 수집·구동 제어 역할은
정확한 보드와 기존 제어 구조에 맞춰 추후 결정한다.

B0385는 Linux 표준 UVC를 지원하며 제조사에
[Linux 영상 형식·노출 설정 안내](https://docs.arducam.com/UVC-Camera/Appilcation-Note/External-Trigger-Mode/OV9782-Global-Shutter/)가 있다.
일반 연속 촬영은 USB 연결이 기준이며 해당 문서의 외부 트리거용 납땜은 선택 기능이다.
[Jetson 안내](https://blog.arducam.com/camera-solutions-for-nvidia-jetson/)에도 B0385가
Orin Nano용 USB 후보로 기재되어 있다. 현재 팀 JetPack에서 실제 동작을 시험했다는 뜻은 아니다.
수동 초점은 렌즈를 돌려 필요한 거리에서 맞추는 작업이며 초점·노출과 ROS 영상 입력은 실물에서 설정해야 한다.

Arducam이라는 브랜드만으로 모든 제품의 연결 방법이 같지는 않다. Arducam 비교 후보는 USB UVC 완성 모듈이며 저가 OV2710의 실제 출력 프로필은 추가 확인한다.
별도 CSI 드라이버가 필요한 제품이나 USB 전용 SDK 평가 키트를 같은 후보로 섞지 않았다.
기존 FIT1022도 UVC 가격 표본이었으므로 연결 자체가 반드시 더 어렵다고 단정할 근거는 없다.
기존 선정의 부족은 우리 신호·마커·주행 요구에 맞춘 이유를 제시하지 못한 점이다.

## 반드시 구분할 성능 조건

- B0385는 사용자 실사용120fps를 확인 근거로 추가했다. 해상도·코덱은 미확인이다.
  제조사 문서의 별도 프로필은 **MJPEG 1280×800 100fps**다. 해당 문서가120fps 불가능의 근거는 아니다.
  같은 해상도의 **YUY2는 10fps**이므로 출력 형식을 빼고 고속 카메라라고 계산하지 않는다.
- 글로벌 셔터는 줄별 시간차에 의한 왜곡을 줄인다. 긴 노출의 모션 블러까지 자동으로 제거하지 않는다.
  MJPEG 디코딩·ROS 전달·인식 처리 후 지연과 실제 프레임률을 측정해야 한다.
- B0385 판매처의 IR 민감 표기와 제조사의 가시광 IR 필터 표기가 다르므로 납품 버전의 필터 유무를 확인한다.
  신호등 색 분류·화이트밸런스·ToF 동시 구동 조건을 실물에서 시험한다.
- USB RGB 카메라 한 개로 스테레오 깊이를 얻는 것은 아니다. C1/S3 기반 안의 신호등·마커용이다.
  D435i·OAK-D Lite 등 RGB 포함 스테레오 안에는 별도 RGB 구매를 자동으로 추가하지 않는다.

## 예산 반영

모든 센서 조합을 ToF 2개·4개로 통일해 비교한다. 1개·5개안은 현재 표에서 제외한다.

B0385는 품절 상태의 **비교용 단가**로만 주 예산표에 반영했다.

| 구성 | ToF 2개 센서 합계 | ToF 4개 센서 합계 |
|---|---:|---:|
| C1 + OV2710† | 232,760원 | 303,160원 |
| C1 + B0385* | 265,760원 | 336,160원 |
| S3 20 Hz + OV2710† | 872,960원 | 943,360원 |
| S3 20 Hz + B0385* | 905,960원 | 976,360원 |

B020101로 교체하면 각 합계에 **8,140원**을 더한다. 품절 후보 재고 확보 및 세부 촬영
조건을 확정한 뒤 실제 주문 목록을 만든다. ESP32-S3·배선·브래킷·배송·예비비는 위 합계 밖이다.
기존 임의 연결·장착비와 여유비를 빼며, 실제 필요한 별도 부품이 생기면 품명·수량·단가로 산정한다.
