ESP32 없는 Jetson 직접 제어 배선안

2026-11-14 · 기존 배선도와 같은 부품 배치·색상 · J12 BOARD 물리 핀 번호

설계안 / 그대로 통전하지 마십시오. 조향 USB 경로와 물리 STOP 제외를 반영했습니다. 엔코더 입력 정합, pinmux와 PWM 종료는 미검증입니다. 발열 ESP32와 그 USB·전원·신호는 완전히 분리하는 구성입니다.

공식 자료 대조: 조향은 Jetson USB-C→데이터 C-to-C→Adapter(A), 점퍼캡 2개 B로 연결합니다. CF의 TXS→Jetson TXB 경로는 입력 구동 요구 충족 근거가 없어 직결 보류입니다. 물리 STOP은 사용자 지시로 제외했고 나머지 기능은 모두 유지합니다. 공식 근거와 판단

유지

J01/M01 전원, MD20A, 기존 서보 어댑터, 엔코더/CF, CSI 카메라와 USB 라이다

변경

ESP32 연결 제거. 조향 USB 및 Jetson PWM/GPIO 사용. IMU는 SPI에서 I2C로 변경하며 물리 STOP은 제외합니다.

미확정

점선은 엔코더 입력 정합 미완료 경로입니다. 27/28 우회도 미채택이며 Jetson 전원 OFF로 실물 검증은 하지 않았습니다.

확인 범위와 근거

  • 발열 ESP32는 USB·전원·신호에서 완전히 분리; 기존 외부 배선 이상 미확정
  • 서보는USB 경로 채택; J12 UART 미사용으로TX 풀업 조건 문제 회피. USB 등록·직접 통신 구현/시험은 별도
  • CF TXS→Jetson TXB 입력 구동 요구 충족 근거 없음; 전압3.3V만으로 직결 승인 불가
  • J12 I2C 이외 신호의 외부 pull-up/down은 >50 kΩ 조건; 10kΩ을 임의 추가하지 않음
  • J12 3.3V와 PDB 3.3V/5V를 병렬 연결하지 않음; 총부하100mA와 전원 순서 확인
  • 물리STOP은 사용자 지시로 제외. 명령 시간 만료·실행 오류 시 PWM0 처리는 구현/검증 대상
  • 27/28 엔코더 우회안 미채택: USB-C/전력감시 I2C 공유와 LOW 여유 문제
  • Jetson 전원OFF 사용자 확인: 이번 자료 검토 뒤 새 실물 통신·GPIO/PWM 출력 검증 없음

IMU 하단 CS→3.3V, DO 미연결로 기존 주소 선택을 유지하고0x6A/0x6B를 확인합니다. 주소 SJ1이 닫힌 보드에서 DO를 GND에 연결하면3.3V 단락 위험이 있습니다. 3Vo와 보조 핀은 사용하지 않습니다. 핀배정·문서 검토 결과이며 실제 통신·구동 성공이 아닙니다.
