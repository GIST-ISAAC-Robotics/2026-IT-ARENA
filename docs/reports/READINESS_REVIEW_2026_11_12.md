## 이번에 다시 확인한 누락·과설계 위험

1. **센서가 들어온다는 사실과 대회 제어기가 그 입력을 쓴다는 사실이 섞이기 쉽다.** C1 원시 형식과 IMU 시계 분석은 상당 부분 끝났지만 실물 운영 발행/입력 유효성·세대 전환은 아직 연결해야 한다. 실제 취득시각으로 승인하지 않은 추정값은 표시와 오차 범위를 보존한 채 연결한다. 모르는 시각을 정확한 값이라고 넣거나, 완벽한 시계 교정 전에는 아무 개발도 못 한다고 묶지 않는다.
2. **제한 시험의 실행 경로가 기본 launch와 다르다.** `g1_decision_execution` 기본은 `inline`이고, 최근 주행은 `process_candidate`와 여러 보존 후보 모듈을 명시적으로 연결했다. 과거 결과를 `ros2 launch` 기본 실행의 성능으로 설명할 수 없다. 검증된 구성 한 개와 실제 실행 명령·소스 해시를 묶는 작업이 필수다. 이 검토에서 기본값을 일괄 켜지는 않는다.
3. **관측 거절 하나를 고쳐도 상태/래치/명령 만료 때문에 계속 정지한다.** r155는 GUARD 재진입 조건만 바꾸는 가설을 뒷받침하지 못했다. r156의 범위 끝 실제 이웃 조회는20개 새 검사 포함134검사를 통과했지만, 전체 저장469판단에서는 정지→진행0·진행→정지1이었다. 후보·원본·출력은 보존하고 실행 코드를 이전 상태로 돌렸다. 작은 예외를 연속 추가하기보다 현재 경로의 허가, 옆차 상태, 기억의 갱신, 출력 적용 시각을 한 흐름에서 대조해야 한다.
4. **계산량이 늘어난 위험 후보를 이전 지연 하한에서만 평가했다.** r152는 기능 비교이고 새 Jetson 비용 재현은 아니다. r150의 이미 동결한 묶음으로 실제 비용을 먼저 회수한다. 중복 증명 재사용 r154는 전체 비용 개선이 없어 미채택했다. 순수 미세 최적화를 끝없이 이어가지 않는다.
5. **STOP 통과는 짧은 제동거리를 뜻하지 않는다.** 단독에서 약1 m의 정지 변위와 후륜 슬립이 남았다. 정지 선언/로그/안정 도달과 물리 제동거리의 기준을 구분한다. 현재 회로와 바퀴가 연결되면 저속에서 먼저 측정하며, 노면 마찰이나 보호 수치를 임의 조정해 해결했다고 만들지 않는다.
6. **필요 기능과 추가 성능을 구분한다.** 느린 앞차 추종·정지차 우회·피추월 중 코스 유지·운영 재개는 필수다. 더 빠른 상대를 적극적으로 추월하거나 P21으로 기록을 줄이는 것은 그 뒤다. 개발용 속도 상한/짧은 수동 조작은 실물 준비에 필요하지만 자율 모드에 주기 입력·통신 대기를 추가하지 않는다.
7. **실행 소스 확인과 저장소의 변경 이력 검사가 어긋났다.** 넓힌 회귀에서939개 통과 뒤 출처 검사5개가 실패했다. 최근 네 소스 변경이 선형 검사 목록에 빠졌고, 누적 실행 등록r134/r138에는 부모 해시 불일치가 있었다. 당시 실행 파일과 그 해시 검증 결과를 삭제하거나 다시 성공으로 쓰지 않는다. 원 등록을 보존하고 r126 ZIP의 네 소스 및 r114 ZIP의 평가 스크립트 이전 바이트를 새 `review_checkpoint_r157_sha256.json`으로 연결했다. r123의 완성 배열 진단 추가도 이력 목록에서 빠져 있었다. 이는 실행 알고리즘 변경이 아니라 추적 기록 정정이다. [게시 전 검사](../../artifacts/validation/2026-11-12/review_checkpoint_r157_v1/README.md)에 최초 실패와 수정 후 결과를 분리한다.

## 바로 이어갈 순서와 작업 방식

1. 재부팅 전 미완료 r156 비교는 이번에 완료했다. 실행 코드 미채택 복원·증거 보존·현재 변경 회귀와 게시 검토를 마친다.
2. 중간 점검/계획과 검토된 로컬 저장소를 main에 반영한다. 원시 센서 bag·상세 JSONL·자격 증명은 기존 제외 정책을 유지한다. 공개 원시 로그와 소스 보존본을 혼동하지 않는다.
3. 이미 준비된 r150 Jetson 비용 비교를 수행한다. 결과를 보고 같은 실패 구간의 단일 경로 승인/상태 갱신을 수정할지, 실행 비용과 결과 적용 구조를 먼저 정리할지 선택한다.
4. 선정 구성이 한 대표에서 성립하면 실물 입력 연결·최초 구동 준비로 옮긴다. 실물 정지 입력으로 바로 확인할 수 있는 연결은 병행해서 준비하되 센서 이동/환경 변경/부품 조립이 필요한 검증은 [제작 전달 목록](../HARDWARE_AND_RULE_QUESTIONS.md)에 모은다.

사용자가 중단을 요청할 때까지 GPT가 직접 설계·구현·실행·분석한다. 어드바이저/워커 사용 금지는 유지한다. 이전 계획의 시점별 ‘다음’ 지시들은 [원문 보관본](../archive/2026-11-12-midproject/DEVELOPMENT_PLAN.before.md)에 남겼으며 새 실행 지시가 아니다.
