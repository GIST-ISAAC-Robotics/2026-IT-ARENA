# 대회 준비 개발 계획: 다중 차량 대응과 실물 이관

> **2026-10-23 대체:** 현행 작업 순서는 [10/23 계획](DEVELOPMENT_PLAN_2026_10_23.md)을 따른다. 이 문서는 10/4 작성분과 10/23까지의 갱신을 이력으로 보존하며, 본문의 "현재"·"다음" 표현은 당시 기준이다.

설계 기준일: 2026-10-04. **2026-10-23 공식 자료 재확인**: main/릴리스 변화는 없지만 방지턱 50 mm의 길이를 150 mm 또는 100 mm로 늘리는 제안은 미확정으로 반영했다. 신호 시퀀스·마커 결정은 유지한다. 이 문서 갱신으로 새 기능을 구현/활성화하지 않는다. 현재 구현·시험 상태는 [프로젝트 현황](../PROJECT_CONTEXT.md), 공식 원문과 남은 충돌은 [최신 조사](OFFICIAL_UPDATE_2026_10_12.md#7-1023-재조회--방지턱-길이는-아직-논의-중)를 따른다.

이 문서는 현재 작업 순서의 기준이며 [9/22 계획](DEVELOPMENT_PLAN_2026_09_22.md)을 대체한다. 과거 계획·시험·실패를 삭제하거나 완료 판정을 바꾸지 않는다. 알고리즘 선택·입출력·관측 한계·시험 설계의 상세 기준은 [다중 차량 설계](../autonomy/MULTI_VEHICLE_DESIGN_2026_10_04.md) 한 곳에 둔다.

## 1. 목표와 바뀐 전제

- **사용자 일정:** 10/5부터 시험기간, 10/24부터 적극적인 작업 참여 가능. 시험기간에도 에이전트 작업은 가능하지만 반복적인 사용자 판단·실물 조작을 전제로 하지 않는다. 이 계획 작성은 미래 자동 실행이나 상시 모니터링을 예약하는 지시가 아니다.
- **하드웨어:** 10/4 사용자 전달로 부품은 구매했지만 설계는 시작하지 않았다. 수령·조립·실제 사양/응답 확인 완료와 구분한다. 현재 코드의 B0183 + C1 + LSM6DSOX, 단일 모터/차동·모터축 엔코더·65 mm·15:1 기준을 임의 변경하지 않는다.
- **전략:** 프리랩 성능과 안전 완주를 우선하되, 이동 차량 추월을 영구 제외하지 않는다. 추종/정지부터 별개 코드를 누적하는 대신 **같은 인지·지역 계획 구조에서 우회/추월을 선택적으로 허용**하는 방향을 검토한다.
- **시간:** 확인한 공식 대회일은 11/14다. 10/24 이후 약 3주가 있어도 차량 완성일과 실차 시험 시간이 보장되지는 않는다. 공식 문구는 경기 시작 1시간 전 프리랩 허용이며 팀별 연습 점유 시간이 보장된 것은 아니다. 현장을 최초 통합 시험으로 쓰는 계획은 피한다. [공식 일정·규정](https://github.com/MOSW626/istech-it-arena/blob/3a9ada035f77305390217795edaa73c495687b6e/MANUAL.md).

성공 목표는 단독 랩타임만이 아니다. **관측 가능한 상대차와 함께 진행하고, 통과 불가능하거나 관측이 부족하면 올바르게 멈추며, 조건이 회복되면 허용 절차에 따라 다시 진행하는 것**이다. 가려진/측정면 아래 차량과 악의적 충돌까지 소프트웨어만으로 해결했다고 선언하지 않는다.

## 3. 우선순위와 기능 허가

아래 단계는 달력 날짜가 아니라 **통과 조건**이다. 하위 단계에 실패했는데 일정이 지났다는 이유로 다음 기능을 활성화하지 않는다. G는 다중 차량 설계의 단계 이름이며 기존 A/B/C 작업 분류와 별개다.

| 우선순위 / 기존 분류 | 작업 묶음 | 통과 근거와 범위 제한 |
|---|---|---|
| **P0 / B0·C1** | **G0 관측·기하와 시험기부터** | 상대차/도로/측정면/가림을 바꾸는 유한한 시험 목록, 가능한 통과와 불가능한 통과의 계산, 평가용 정답 분리, 실패/정지/진행성 판정. 소프트웨어가 풀 수 없는 장착 문제를 먼저 드러냄 |
| **P1 / B1** | **G1 공통 기반의 최소 추종/대기** | 상대차를 벽으로 채택하지 않기, 짧은 경계 기억과 점유 분리, 상대 속도의 이득을 가정하지 않는 간격 제어, 등속/정지/재출발과 피추월. 현행 R0와 비교하며 단독 회귀·독립 보호 유지 |
| **P1 / B3·A1** | 경기/고장 상태 계약·공개된 출발 시퀀스 시험 | 빨강 4 순차 점등→빨강 소등+초록 점등의 직접 시각 판정. 출발 허가와 추종 행동 분리, 임시 보호 후 재개와 고정 고장 후 명시 해제 구분. 초록 5 s 후 소등·가림·재시작 오출발 검사. 설치 높이/방향·광원 크기 단위와 실물 성능은 미확정으로 분리 |
| **P2 / B2** | **G2 제한 정지차 우회** | 통로가 실제로 있는 가장자리 표적만. 전체 회전 외곽·관측 범위·중도 포기/복귀 검사. 중앙 완전 봉쇄 사례에서는 거절이 정답 |
| **P2 조건부 / B2+** | **G3 제한 이동 추월** | G2와 시간축 점유·측후방 관측·상대 운동 불확실성·취소 정책 검증 후. 실험 기능으로 시작하고 기본 활성화는 별도 판단 |
| **P1 병행 / A3** | 새 기능의 Jetson 처리 비교 | PC 기능 회귀가 성립한 입력으로 기존 기록/재생을 재사용. 입력 나이·큐·최대 지연·정지·종료 확인. 새 부하만 측정하고 무관한 최적화는 보류 |
| **P1 병행 / C1·C2** | 하드웨어 전달·실물 입력 준비 | 아래 최소 요구사항과 교정/드라이버/통신 검사 틀. 부품을 기다리며 없는 계수를 합성값으로 확정하지 않음 |
| **출전 전 필수 / C3·D** | **G4 실차 이관과 경기 통합** | 실제 STOP·시간/축·구동 응답·낮은 표적부터 단독→복수 표적→경기 절차. 방지턱·조명·그리드·5랩·열/전원 포함 |

**필수와 조건부를 구분한다.** 관측성, 추종/정지/정상 재개, 시간·정지 계약, 실물 점검은 필수다. 실제 여유가 있는 정지차 우회는 높은 우선순위 목표지만 관측이 성립하지 않으면 출전 기능에서 제외할 수 있다. 이동 추월은 같은 기반을 쓰는 확장 후보이며 개발 일정이나 희망만으로 필수 성공 약속을 하지 않는다.

### 최초 구현 묶음의 범위: G0 + G1 인터페이스 고정

아래는 10/4에 정한 출발점과 보존할 수용 조건이다. G0부터 다시 시작하라는 지시가 아니며, 현재 다음 실행은 [현황의 작업 범위](../PROJECT_CONTEXT.md#다음-작업과-진행-범위)를 따른다. 10/13~15 [실제 벽 조각 증거 후보](../autonomy/G1_FRAGMENTED_BOUNDARY_2026_10_13.md)는 좌/우 가림·초기 대기/재출발·첫 U자와 잔여 시작 위치를 확인했다. C1 ±30 mm의 최초 진행 실패를 보존하고 점별 시각 후보의 기존 세 스트레스·정지 앞차 편향·G1 ROS 고장 40조건을 제한 마감했다. 옛 HOLD 감사와 정지 완료 의미를 구별하고 STOP에는 밀집 pose를 요구한다. **10/15 단독 한 바퀴는 여전히 미완료**다. [급커브 거리 후보](../autonomy/G1_CORNER_BOUNDARY_2026_10_15.md)는 첫 실패 코너를 통과했지만 다음 코너에서 실패했고, 짧은 관측과 시간축 증거의 계약 재설계가 남았다. 관측 길이·기억 TTL·보호 기준 완화나 기본값 승격은 하지 않는다. 같은 위치를 성공할 때까지 반복하지 않고 짧은 물체/가림/여러 표적 반례와 후보 근거를 먼저 확보한다.

10/15 오후 사용자 승인 후 [회랑 비교 후보](../autonomy/G1_CORNER_BOUNDARY_2026_10_15.md#510-사용자-승인-후--의미-미확정-표면을-유지하는-회랑-shadow)를 별도로 설계했다. 짧은 안쪽 면을 벽이라고 확정하지 않고 전점 점유를 유지하며, 긴 바깥 관측·현재 실제점 경로 지지·스캔 간 확인을 사용한다. 고정 입력·정적 반례·광선 깊이와 작은 운동학 모형의 미래 입력/전환을 대조했다. 기본 false 연결·사전 회귀 뒤 중단했던 **승인된 공식 단독 1회는 10/16에 수행했으며 43.113530 m·완주 0회로 실패**했다. 기존 급커브 정지 지점은 통과했고 밀집 STOP·정상 종료를 확인했으나, 긴 직선을 향한 측방 무응답과 기존 ±100° 관측 게이트가 충돌했다. 새 입력 PC 비용과 이전 GC 긴 호출은 별도 측정이며 ROS/Jetson 마감 통과가 아니다. 기본 경계 기억/보호/TTL/물성은 유지한다. [상세 결과](../autonomy/G1_CORNER_BOUNDARY_2026_10_15.md#7-1016-승인된-공식-단독-1회와-후속-진단).

**10/21~23 정리: 관측 개선에 필요한 실물 전제를 남기고 병행 A1의 이관 후보를 검토했다.** 10/17 공식 단독 1회는 여전히 43.093540 m 실패다. 깊이/외곽 동일 출력 최적화·원점 경계 정정·ROS 연결 검사를 마쳤다. 차량 전체 폭만으로 최소 단면/반사율을 보장할 수 없어 유한 표적 비교를 보호 완화에 사용하지 않는다. A1은 C++ 송수신·ARM 관문·출력 비활성 연결부와 ESP32-S3 검사 앱 링크를 확인했다. compact 호스트 보관·원천 시각·요청 상관 후보, 단일 모터 PI와 출력 없는 제어 주기 결합, 출력 비활성 UART 주기 어댑터와 ESP-IDF 연결 앱의 목표 빌드까지 PC에서 대조했다. 보드 없이 할 수 있는 이관 묶음은 여기서 멈추고 실물 판본·콘솔/핀 확인을 기다린다. 모든 후보는 운영 미연결이며 실제 시간/지연 측정·구동 허가가 아니다. 실제 UART 타이밍·독립 출력 감시·실물 보드 측정은 남는다. 새 실물 자료 없이 같은 공식 실패를 반복하지 않으며 기본 활성화·앞차 후속·G2/고속화는 보류한다. [G1 근거·한계](../autonomy/G1_OBSERVATION_CONTRACT_2026_10_21.md), [A1 송신 이후 결과](../hardware/ACTUATION_CONTRACT_2026_09_22.md#19-1022-후속--구동-출력-없는-송신-정책-후보), [UART 어댑터](../hardware/ACTUATION_CONTRACT_2026_09_22.md#29-1023-후속--출력-비활성-uart-주기-어댑터), [하드웨어 질문](../HARDWARE_AND_RULE_QUESTIONS.md).

차량/코스 마커 역할·[PC 비용/최소 이관](../simulation/G1_DECISION_PROFILE_2026_10_13.md)·[C2 기록 및 왕복 시각/신선도 구간](../hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md)은 제한 준비를 마감했다. 10/15 C2의 host/ROS 동시 읽기는 PC 독립 시계와 설치 rclpy 합성 사건까지 확인했으며 [MCU 포팅 대조 벡터](../hardware/ACTUATION_CONTRACT_2026_09_22.md#9-1015-후속--단일-모터축-계약의-mcu-포팅용-대조-벡터)도 PC 참조용으로 준비했다. **실제 드라이버 시계 연결·실물 취득·MCU 펌웨어·Jetson 후보 실행은 별도**다. 시계 준비를 실제 부품 없이 무기한 확대하지 않는다. [G2 사전 분석](../autonomy/G2_PREPARATION_2026_10_13.md)은 기하·관측 조각·다대다 연관을 준비했지만 저장 입력의 모호함으로 운영 미연결이다. 기존 0.15 m 간격/정지 경계를 줄이지 않으며 우회/경기 활성화·고속화 허가와 구분한다. 독립 필수 [B3 출발 계약](../autonomy/RACE_START_CONTRACT_2026_10_13.md)은 제한 검증을 마감했고 설치 시야·실물/Jetson·렌더러 종료가 남는다. 같은 solver/시뮬 반복을 무기한 선행 조건으로 두지 않고 구체적인 미검증 조건을 줄인다.

처음부터 추월 제어기를 완성하려 하지 않고, 다음 범위에서 설계가 성립하는지 확인한다.

1. 새 기능을 끈 단독 기준선의 소스/설정·실행 경로를 고정하고 기존 실패를 보존한다. 현행 보호층은 경로 계산 모듈의 일부 함수/운동 입력을 공유하므로 리팩터링 전에 동작 고정 회귀를 둔다. 새 기능은 플래그/모드로 구별해 코드나 사용자 변경을 되돌리지 않고 기준선과 비교할 수 있어야 한다. 현재 변경을 무조건 전부 Git에 올리는 뜻이 아니다.
2. 표적 사례는 중앙 정지차, 가장자리 정지차, 등속 앞차, 급정지/재출발, 벽 가림, 낮은 차·측후방 사각으로 시작한다. 짧은 분기 벽을 차로 오인하는 반대 사례도 넣고 R0와 비교한다. 모든 조합을 무작정 곱하지 않는다. 방지턱은 현재 기본에서 제외를 유지하며 별도 선택 시험의 관측 위험을 정의한다.
3. 상대차의 실제 렌더링·순차 광선 취득과 평가용 차체 점유를 연결한다. 완성 스캔에 점을 덧붙인 합성 검사는 단위 시험이지 동체 취득/물리 검증이 아니다.
4. 도로 경계·관측/점유·시간/프레임·실행 가능한 제동 후보·시험 결과의 계약을 고정한다. 임계값/관측 이력 길이와 판정선은 현행 시간 계약과 오차 예산을 보고 시험 전에 기록한다. 보호층이 사용하는 경로 모듈의 공통 함수를 리팩터링하기 전에 기존 동작 고정 회귀를 둔다. 전방 결측의 정지 원인과 실제 주행 경로의 관계는 먼저 기록 전용으로 분석한다.
5. 가능한 틈에서도 현 보호/관측 조건 때문에 전부 멈추는지, 반대로 보이지 않는 차를 지나가는지 확인한다. 성공할 수 없는 구성을 발견하면 기능/기구 변경 제안에서 멈춘다.

산출물은 작은 시나리오 정의·재현 명령·소스/설정 해시·가능/불가능 표·주행/정지/진행성/종료의 별도 판정·후속 G1 범위다. 이 첫 작업에서 알고리즘 전체 교체·센서 추가 구매·고속화·새 물성 확정은 하지 않는다.

G0 가능/불가능 표는 **표적 높이×거리×피치**, **도로 침범량×차체/yaw×오차 여유**, **센서 위치×가림 형상×복귀 궤적**으로 나누어 필요한 조합만 분석한다. 일부 광선/외곽을 보았다는 사실과 그 뒤의 안전한 대응 시간이 있다는 사실을 별도 판정한다.

## 4. 시험기간의 작업 경계와 점검 시점

아래 날짜는 작업시간/성공률 추정이 아니라 **범위 확대를 재고할 점검 시점**이다. 실제 진행은 별도 작업 요청 때 시작한다. 사람이 답하지 않는다고 승인으로 취급하지 않는다.

**10/23 일정 정정:** 사용자에 따르면 새 설계와 도착한 부품이 없고, 연결 가능한 시점 및 차량 설계 수령은 다음 주 주말쯤으로 예상된다. 아래의 10/24 팀 검토는 최초 점검 목표이지 차량/부품 준비 완료일이 아니다. 실물 C2/C3 착수는 실제 준비 확인 뒤로 이동하고, 그 사이에는 아래의 PC 작업만 진행한다. 예측 납기를 확정 날짜나 장치 접근 승인으로 바꾸지 않는다.

| 시기 | 우선 목표 | 미달 시 선택 |
|---|---|---|
| 10/5–10/11 | G0, G1 최소 수직 구현, 하드웨어 관측 요구사항 정리 | G0부터 관측 불가능하면 사유와 축소안 기록. 대형 대체 알고리즘을 몰래 시작하지 않음 |
| 10/12–10/18 | G1 회귀·Jetson 비교·경기 상태 설계, 가능하면 G2 | G1이 불안정하면 추월 구현을 넓히지 않고 추종/정지의 최초 실패에 집중 |
| 10/19–10/23 | 안정된 G1/G2 증거와 운용 초안, 조건부 G3 타당성/제한 실험 | 새 아키텍처보다 재현·복귀·실차 인수인계 우선. 미완성 기능은 비활성화 |

일정의 사용자 의존성도 분리한다. **하드웨어 요구사항 전달은 가능하면 설계 착수 전**, Jetson 재생은 전원/접속이 가능할 때 수행한다. 불가능하면 PC 입력·검사 틀을 먼저 준비하고 Jetson 실측은 10/24 이후로 이월하며 완료로 표시하지 않는다. 10/24에는 직선·코너·가능하면 분기 일부를 포함한 실물 시험 공간/벽·노면 재현물, 원격 STOP 통신 운용도 함께 결정한다. 공식 무선 채널 배정은 10/6 폐기됐지만 STOP 통신 검증은 남는다.

장기 작업을 시작하기 전 소스/설정 스냅샷과 해시를 남긴다. 누적 개발과 원격 문서는 10/11 사용자 승인으로 main에 통합됐으며, 이후 커밋/푸시 권한은 각 요청에서 확인한다. 10/12의 현재 요청은 공식 자료의 문서 반영·푸시까지다. 승인 전에도 기존 파일·활동/실패 기록을 보존하며, 자동 `reset`/checkout으로 다른 작업을 지우지 않는다.

시험기간에 이어서 맡길 수 있는 범위는 승인된 묶음의 구현·단위 시험·합성/시뮬 회귀·문서화다. 기존 부품/계약을 유지하는 제한된 수정과 미리 명시한 축소안은 제안 범위 안이다. **구매/기구·센서 교체, 전역 지도 의존성 도입, 안전 임계값 완화, 고속화, 외부 게시/푸시, 실물 위험 시험, 경기 추월 활성화**는 별도 판단을 요청한다.

각 묶음 종료 시 한 번만 다음을 남긴다: 무엇을 확인했는지, 첫 실패와 원인, 바꾼 것/유지한 것, 통과한 조건과 미검증, 다음 묶음·중단 조건. 실행/대기를 별도 담당에게 맡겼다면 부모가 같은 상태 조회를 반복하지 않고 결과와 판정 근거를 독립 검토한다. 필요한 검토 시간을 보장하되 의미 없는 반복 실험이나 성공할 때까지의 임계값 변경은 하지 않는다.

동일한 원인으로 수정이 반복되면 기능 범위를 더 넓히지 않고 원인·대안을 보고한다. 자동 코드 되돌리기 대신 보존된 기준선 모드를 선택한다. 관측 전제 불성립, 비의도 구동/정지 실패, 반복 보호 정지·누적 큐·MCU 마감 실패는 선행 문제로 돌리고, 안전 한도를 완화해 다음 단계에 진입하지 않는다.

10/23에는 [명령 없는 PC 원시 바이트 기록](../hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md#7-1023--명령-없는-pc-원시-바이트-기록)을 준비했다. 파일/이미 연결된 pipe만 받으며 실제 포트·장치·ROS는 열지 않는다. 기록 무결성과 패킷 형식·취득 시각·상류 손실은 별도다. 원시 기록 준비를 실제 드라이버 통합 완료로 표시하지 않는다.

**C1 이관 선행 조건:** [제조사 드라이버 원문 감사](../sensors/C1_DRIVER_TIME_CONTRACT_2026_10_23.md)에서 각도 정렬/반전·반환 복제·호스트 대기 시간 기반 메시지를 확인했다. 실물 보정을 켜기 전 원본 순번/각도/시각 보존과 SDK 추정 clock의 연계를 확인한다. `angle_compensate`를 운동 보정으로 해석하거나 시간 관문만 true로 바꾸지 않는다. 독립 가속도 기록 v2는 준비됐지만 중력 제거/자세 추정은 미구현이다.

**나머지 입력 이관:** [B0183](../sensors/B0183_INPUT_HANDOFF_2026_10_23.md)는 CSI/ISP 출력 형식·촬영/PTS/수신 시각을, [LSM6DSOX](../hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md#9-1023--lsm6dsox-입력을-연결하기-전)는 실제 라이브러리 단위·data-ready/FIFO·버스 오류와 센서/MCU 시계를 확인한다. IMU 명시 frame 검사 옵션은 입력 이름의 불일치를 막는 준비이며 실제 축 보정이나 새 드라이버 구현 완료가 아니다. 같은 합성 시험을 늘리기보다 연결 가능한 실물과 원시 기록을 확보한 뒤 필요한 어댑터를 확정한다.

- **지금 준비:** 드라이버 축/단위/부호·시각 계약, 원시/보정값 기록, 정지/재시작 검사, 잡음/지연/포화 주입 틀, C1/RGB 장착별 관측 시나리오, 교정 데이터 수집 절차.
- **실물로 확정:** C1 취득 순서·시각·무반사 의미, IMU 영점/온도/내장 필터, 엔코더 펄스·유효 둘레, B0183 FPS/노출/지연, MCU 시간 변환, 조향/제동/열·전원. 시뮬의 임시 계수는 교정값이 아니다.
- **필터 선택:** 기존 A4 입력 보호는 유지한다. 새 추적의 평활화는 지연과 오차를 함께 비교한다. IMU/엔코더에 LPF/EKF를 일괄 추가하지 않으며 실측/주입 시험에서 개선 필요성이 확인될 때만 추가한다. 독립 정보 없이 그럴듯한 슬립/고착을 항상 판별할 수는 없다.

## 6. 경기 준비에서 빠뜨리지 않을 것

- **출발:** 공식 빨강 4세트·초록 1세트/랜덤 1~3 s 구간으로 상태 시험을 준비한다. 10/6의 전체 소등 모델은 대체됐다. 앞차 움직임·타이머·UDP로 출발을 대체하지 않는다. 팀 임시 초록 인식과 출발 색은 같아도 광원 크기·배열·그리드 시야·STOP 후 재무장 적합성은 별도 검증한다. 공식 SDF는 정적 표시여서 카메라 시험에는 발광 연동도 필요하다.
- **복구:** 일시 센서 보호·행동 대기·비상정지·MCU 고장의 해제 조건을 구별한다. 공식 허용 개입 이후 재출발 때 신호/주행 상태를 어떻게 복구할지 팀 운용 절차로 고정한다.
- **주행 방향/분기:** 기본은 본선. 코스 ID와 차량 ID의 역할을 분리하고, 다른 차의 후방 마커가 경로 선택을 바꾸지 않게 회귀에 포함한다. 사전 통일은 권고이므로 power-on의 7×7 ID 91과 ROD 11/14 미확정을 고려한다. 미검출은 차량 부재의 증거가 아니다. 지름길 합류는 별도 기능이며 폭이 좁다는 이유로 차량 축소/미관측 진행을 허용하지 않는다.
- **방지턱:** 현재 새 모드의 임시 제거는 유지하지만 출전 준비 완료 조건에서는 되돌려야 한다. 공개 파일은 450×50×10 mm이고 길이 100/150 mm 확대안은 미확정이다. 먼저 유한 바퀴/축거의 제한 기하 비교와 실제 최저지상고·최종 제작 사양을 구별한다. 후속 선택 시험에서는 기존 공식 박스/팀 임시 곡면과의 차이, 접지·피치에 따른 2D 관측/영상 복귀·통과/재개를 확인한다. 인식/감속 방법과 실물 안전 속도는 미채택이며 제작 지침의 마찰 예시를 주행 물성으로 쓰지 않는다.
- **반복/운영:** 단독 및 다중 차량의 5랩, 여러 그리드의 시야, 정지/복구, 통신·노드 종료, 로그 용량·부팅·설정 복구·열/전원. 모든 조합 전수 대신 위험 기반 대표 조건을 사전 고정한다.
- **공식 변경:** 다음 작업 시작 시 필요한 규정/릴리스만 대조하고 변경이 있을 때 차이를 정리한다. 질문/댓글은 초안을 만들 수 있으나 승인 없이 게시하지 않는다.
- **규정·운영:** 잔디 2바퀴까지 무벌점이어도 현재 차체 외형 기준과 잔디 전술 보류는 유지한다. 프리랩 이탈은 본경기에 누적되므로 단독 랩타임만 최적화하지 않는다. 결산안 11/13 제출·열람 제한, 지급품 반납, 높이/비상정지/마커 검차를 운영 목록에 포함한다. 3차 최종 회의는 10월 말~11월 초 예정이며 일자는 미정이다.
