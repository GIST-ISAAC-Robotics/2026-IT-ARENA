**출력 없는 ROS 센서 기록과 이관 도구를 보충했다.** writer 종료 재호출/추가 예외 누락을 재현·수정했고 입력 형식 관찰·선택형 세션 감독을 추가했다. 정상 종료+CDR 감사만 성공이며 강제 종료/취소/실행 실패는 실패로 보존한다. [결과·한계](hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md#107-실제-writer의-쓰기종료-예외-주입), [최신 휴대 묶음 v6](../artifacts/validation/2026-10-23/sensor_probe_bundle_v6/README.md)는 관련 350·분리 236회귀 및 추출본 ROS 2초 기록/감사를 통과했다. [설치본 대조](../artifacts/validation/2026-10-23/installed_source_v1/README.md)도 통과했고 누락은 발견하지 않았다. 이는 최신 전체 4,656회귀 뒤의 별도 보충이며 합산하지 않는다. 실제 디스크 장애·Humble/Jetson·취득 시각/교정·운영 적합성은 남는다. sensor_probe schema는 기존 제어기 재생기가 거절한다.

**큰 영상 기본 전송은 아직 무손실이 아니다.** 720p 포함 5토픽 시험의 Image는 기본 전송 17/20·낮은 빈도 대조 10/20이었다. 기록기 없는 SHM 크기 대조 뒤 명시 16 MiB의 제한 기록은 전부 20/20·정상 종료했지만 기본값으로 채택하지 않았다. CameraInfo의 전달 끝 정렬과 실제 내용·recorder 내부 무결성을 분리했다. 60 fps/장시간/Jetson·센서 취득 지연은 미검증이다. [실패→대조·한계](hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md#105-큰-rgb와-단일-모터축까지-연결한-결과).

G1은 10/21 상태를 유지한다: ON 3,001/OFF 2,837판단 일치, ON total 최대 24.764 ms·20 ms 초과 4건. 10/17 공식 단독은 **43.093540 m·완주 0회 실패**(5회 중 최고는 10/16의 43.113530 m)이며 측후방 관측 공백·Gazebo 종료 SIGSEGV가 남는다. 새 공식 주행·보호 완화·기본 활성화는 없다. [G1 결과·한계](autonomy/G1_OBSERVATION_CONTRACT_2026_10_21.md), [기존 실패](autonomy/G1_OBSERVATION_ENVELOPE_2026_10_16.md#16-1019-마감과-재개-순서).

별도 [방지턱 기하·LiDAR 비교](simulation/BUMP_GEOMETRY_2026_10_23.md)는 유한 바퀴 계산 뒤 정지 자세의 바닥/벽 반환을 진단했다. 앞 숙임 바닥 거리 3 cm 대조와 첫 종료는 실패했으며, 렌더링 픽셀 근사로 거리 차이를 설명했다. 후속 정지 벽 장면은 정상 종료했고 저장 입력의 지역 경로 대조에서 유효 12쌍의 조향 차이는 최대 약 0.008°였다(6쌍은 양쪽 모두 경로 미성립). 이 제한 비교로 G1/실물/방지턱 통과가 해결됐다고 보지 않는다. 기본 센서·월드와 원래 실패를 유지한다.

재출발 ROS v5 `invalid_encoder`·v6 `command_expired`를 분리하고 시험 판정/시작 그래프 경쟁을 고친 뒤 **v8·v9 각각 43/43**이 통과했다. 10/21 최종 관측 계산·진단 정정본도 **별도 ROS 43/43·정상 종료·소스 불변·잔존 0**을 확인했다. v6는 유효 DRIVE 갱신 없이 산정 만료를 넘긴 것까지 확인했지만 정확한 공백 단계와 v5 거절 인수는 미확정이다. v8에서도 임계 미만 동시 정지가 관측돼 간헐 원인은 해결로 보지 않는다. 후보 기본 false·단일 모터축·센서/물성·독립 보호·STOP과 실패를 보존한다. 커밋/푸시·Jetson 변경 없음. 10/19 Windows/Armoury Crate 터보 전환은 사용자 승인으로 수행했으며 이번에는 변경/재측정하지 않았다. [재출발 고장 분리](autonomy/PIPELINE_FAULT_VALIDATION_2026_10_04.md#7-1019-제어기-재시작-중-mcu-고정--v5v6-원인-분리와-시험기-수정).

병행 A1은 [제한 송신 후보](hardware/ACTUATION_CONTRACT_2026_09_22.md#19-1022-후속--구동-출력-없는-송신-정책-후보)까지 진행했다. compact offer와 ACK/상태/진단을 분리하고 유한 큐·부분 쓰기·포화/재연결을 검사했다. 460800·8N1 합성 선로의 DRIVE 50 Hz에서 MCU→host **65,818→17,662 B/s**, 부하 **1.428→0.383**이며 115200 실패·230400 진단 기아는 보존한다. 최악 문자열·실제 하드웨어/마감 보장이 아니다. ESP-IDF v6.1·Xtensa 15.2.0 검사 앱 링크는 확인했으나 실제 실행·시간/할당·전기 STOP은 미검증이다. ARM 관문의 준비값은 호출마다 명시하며 기본 거절, STOP/CLEAR는 유지한다. 운영 Python/ROS·CH343P USB-UART 우선안·baud/timeout은 유지하고 [실물 이관 순서](hardware/ACTUATION_CONTRACT_2026_09_22.md#155-실물-연결-전-인수인계-순서)·C2·G1 실패는 보존한다.

기본 `connected`/`oldest`·G1/회랑/공식 출발 미활성, 임시 3등·service/GC native·명령 예약 적용 꺼짐·구동식/1 ms 월드·모터축 28카운트·15:1·65 mm·센서·물성·보호 한도는 유지한다. PGS 미정지·스캔 `unknown`·실물 제동·MCU 간헐 지연은 남는다. 10/23의 별도 정지 센서 장면과 PC 검사 프로세스는 종료했으며 G1 주행을 반복하지 않았다. 커밋·푸시·외부 게시·Jetson·전원 변경 없음. [전체 계획](reports/DEVELOPMENT_PLAN_2026_10_23.md), [문서 안내](README.md), [10/23 활동](activity/2026-10-23.md). 게시 상태는 Git/PR을 기준으로 확인한다.

## 다음 작업과 진행 범위

**10/24 다음 재개점:** 바퀴 노면 평가를 완료하고 M3 측방 의도 후보의 오프라인 검토를 진행한다. 두 바퀴 잔디·횡간격 축소 승인은 반영했으며, 경로·관측·무효 전이의 기술 수용 조건은 개발자가 검증한다. B3 운영/CLI는 제한 ROS까지 완료된 별도 기능이며 M3 해결로 세지 않는다. 상세 상태는 상단과 [E3 §8.6](autonomy/MULTI_ACTOR_E3_2026_10_24.md#86-1024-오후-전략-변경과-측방-후보-검토)을 따른다.

1. **D·H — 전제 결정 자료와 팀 설계 전 전달(10/24–26).** 기존 증거로 결정 자료를 만들고 10/27에 관측 전제를 점검한다. O1·O2·O2-국소 가설·기구 변경은 미채택·미구현이며 `unknown`을 자유 공간으로 바꾸지 않는다. 미결정이면 M1을 "현재 시험 조건에서 진전 미달"로 두고 M2/M3를 계속한다. 같은 자세 리셋은 해결책이 아니며, 동일 실패 주행·임계값 조정은 반복하지 않는다. 실행 기하·C1 높이/가림·카메라 시야/출발등·최저 지상고·STOP 배선·MCU 콘솔·엔코더 1축은 [팀 설계 전 우선 목록](HARDWARE_AND_RULE_QUESTIONS.md#팀-설계-전-우선-전달-목록--1023-재계획)으로 전달하고, 공식 질문은 초안까지만 만든다.
2. **E1/E2 마감.** 현재 R0 단독 1회는 상단의 공통 무응답 정지·미완주로 분류했다. 명시 STOP 미수행·제동 후 이동을 구분하고 반복하지 않는다. E2의 세 정적 자세 12/8/6 m 표도 완료했다. 관측 전제는 D에서 다루며 같은 실패 주행으로 확인을 늘리지 않는다.
3. **E3 — 핵심 선별 마감, 측방 후보 개발 중.** 기존 정지·재개 제한 통과와 도로 내 옆차 두 후보 실패를 보존한다. 선택형 M3의 관측 기반 복귀(run17/run21)는 좌우 피추월 뒤 복귀까지 진행했지만 측방 약 70 mm로 실패다. 정지·재개는 run19 실패 뒤 작은 중앙 보정 생략(기본 false)으로 같은 조건 run27 1회를 통과했다. 주행 중 곡선 명령의 후방 마스크 꼬리 띠 거절, 후방 가능 영역 미해제, 0.35 m/s 시험 상한은 남는다. 다른 seed·장면 적용은 등록과 GPT 검토 뒤에만 하며 같은 실패 주행 반복은 하지 않는다. [§8.16](autonomy/MULTI_ACTOR_E3_2026_10_24.md#816-1025-오전--작은-중앙-보정-생략과-정지재개-run27).
4. **E4 — 선택 모드 고정 회귀 묶음(11/7 마감).** 결합 교통·좌우 피추월·앞차 급정지/가림·센서 이상/지연(현행 단일 모터축 구성에 종전 사례 이식)·출발/재개·방지턱/5랩을 대표 조건으로 묶고, 선택 직후 Jetson A3 재생을 1회 수행한다. 실물 첫 주행용 최소 구성의 10/31 설정 동결은 목표일이며 안전 검증 완료가 아니다. R0는 통제된 단독 비교 기준이지 다중 차량 경기의 자동 폴백이 아니다. 실차 주간에는 실측 교정·필수 결함 수정·확인을 우선한다.
5. **A1·차체 전 벤치 — 장비 연결 즉시 병행.** RGB·IMU·C1·MCU를 차체 없이 하나씩 원본 입력/시각 → 실제 어댑터 → 신선도/STOP 순으로 연결한다. 마지막 주에 드라이버부터 시작하지 않는다. A1은 보드 전 이관 묶음을 마감했고 실물 확인을 기다린다. [PI·제어 주기 결합](hardware/ACTUATION_CONTRACT_2026_09_22.md#28-1023-후속--출력-없는-제어-주기-결합)과 [출력 비활성 UART 주기 어댑터](hardware/ACTUATION_CONTRACT_2026_09_22.md#29-1023-후속--출력-비활성-uart-주기-어댑터)까지 PC 반례·목표 빌드를 마쳤다.
   - 다음 단계: 납품 판본·콘솔/부팅 출력·핀 배정을 확인한다(CH343P→UART0가 기본 콘솔과 같은 포트라는 문제 포함). 그 뒤 사람이 승인한 계획으로 출력 없는 수신/송신·tick 실측과 포트/리셋/단절 고장 시험을 한다.

   - Gazebo 모터 제어·센서/물성/보호 한도는 유지한다. 독립 출력 준비 감시와 전기 STOP이 남는다.
   - [C2](hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md#62-1015-호스트-단조-시각과-ros-시각의-동시-읽기-준비)는 실제 드라이버 연결 전이며 기록 도구 확장은 보류한다.

[새 전략·검토 결과](autonomy/MULTI_ACTOR_E3_2026_10_24.md#86-1024-오후-전략-변경과-측방-후보-검토), [노면 체크포인트와 승인 이력](reports/OFFICIAL_UPDATE_2026_10_06.md#후속-메모-잔디-판정을-이용한-주행-여유--미채택).
8. `ros_v2`·v5·v6의 재시작 중 MCU 고정은 공통 기전이 미확정이다. 새 시험기는 `/actuation/diagnostics`·호스트 전달 판단·MCU 전환 문맥·느린 발행을 종료 전에 회수한다. 운영 구조(영상 작업자 시작 순서·DDS 설정) 변경은 근거 전까지 보류한다. 입력 자동 복구와 영상/MCU 고정 고장·경기 재출발 정책은 B3 선택형 감독에서 통일했으나 기본 경로는 아직 기존 정책이다. 신선한 고착/그럴듯한 IMU 오측정·단일 모터축의 슬립/펄스 손실 한계는 [C1/IMU](autonomy/SENSOR_INPUT_GUARDS_2026_10_04.md), [모터축](autonomy/MOTOR_ENCODER_VALIDATION_2026_10_02.md), [프로세스 고장](autonomy/PIPELINE_FAULT_VALIDATION_2026_10_04.md)에 남는다. 조향 명령을 실제 운동의 정답으로 쓰지 않는다.
9. 낮은 차량/측후방 사각·실물 센서/MCU 시간 계약·기구/전원·조향/제동, 공식 LED/재출발·원격 STOP·5랩/방지턱은 계속 필수 확인 항목이다. **C1은 원본 점 순번/시각과 SDK 추정 clock의 연결을 먼저 확인**한다. 점별 오프라인 후보만으로 실제 드라이버 관문을 켜지 않는다. 독립 가속도 기록은 준비됐으나 자세/중력 제거·피치 보정은 미구현이다. **B3는 선택형 ROS·정적 픽셀·가상 시간축 묶음과 10/24 선택형 운영 연결까지 마쳤고** 기본 채택 검토·실물 MCU 중계·설치 시야/실물/렌더러 종료가 남는다. 기본 전환·추가 동일 Gazebo 반복은 보류한다. 방지턱은 제한 기하/정적 센서 비교까지이며 관측/통과 합격은 남는다. 하드웨어팀 전달 항목은 [팀 설계 전 우선 목록](HARDWARE_AND_RULE_QUESTIONS.md#팀-설계-전-우선-전달-목록--1023-재계획)과 [10/4 계획의 최소 요구사항](reports/DEVELOPMENT_PLAN_2026_10_04.md#5-하드웨어팀에-먼저-전달할-최소-요구사항), 차체 전 벤치·실차 주간 순서는 [10/23 계획](reports/DEVELOPMENT_PLAN_2026_10_23.md#8-실물-경로--차체-전-벤치와-실차-주간)을 따른다.

사용자는 **10/5부터 시험기간이며 10/24부터 적극 참여 가능**하다. 10/5 요청에 따라 **센서·배치는 기존 설정을 유지**한다(B0183·C1·LSM6DSOX, C1 임시 측정면 9.5 cm·전방 6 cm·후방 60° 마스크). 대체 카메라/ToF 구매와 개방층 기구 제안은 채택하지 않았다. 이 유지 결정이 실차 장착 확정·관측 안전 보장은 아니다. 기본 역할은 [작업 규칙](../AGENTS.md)을 따른다. 10/11 후속 사용자 지정에 따라 Claude 워커 없이 GPT가 작업할 때에는 별도 지시가 없어도 GPT-6 Luna가 시뮬레이션 실행·대기·결과 회수를 맡고, 주 에이전트가 설계·구현·분석·최종 검토를 맡는다. 이전 역할 이력은 [활동 기록](activity/)에 보존했다. 10/12 공식 자료 갱신·팀 저장소 게시와 뒤이은 제동 노면 대조는 별도 작업이다. 제동 대조에서 공식 시설·Jetson·전원 변경·게시를 하지 않았다.

[10/23 전체 개발 계획](reports/DEVELOPMENT_PLAN_2026_10_23.md)이 현재 작업 순서의 근거이며 10/4·9/22 계획은 이력으로 보존한다. A3 집중 최적화 보류와 A4 제한 시험은 모든 지연·센서 고장의 해결이나 실차 안전 보증이 아니다. G1은 상단에 연결한 부분 시나리오·위치·입력 조건의 선택형 검증 단계이며 우회/추월은 운영 미연결이다. 작업 범위는 사용자의 현재 요청을 따르고 이전 세션의 게시·중단 지시를 누적하지 않는다.
