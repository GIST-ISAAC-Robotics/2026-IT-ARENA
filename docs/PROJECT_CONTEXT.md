# 현재 현황과 다음 작업

공식 자료 확인: **2026-10-12**. 신호등 실물 시퀀스·방지턱 제작안·차량 마커 정정을 [최신 공식 자료 요약](reports/OFFICIAL_UPDATE_2026_10_12.md)에 반영했다. 이번에는 문서·계획만 갱신했으며 아래 개발 기준선과 실행 입력은 유지한다.

개발 상태 기준: **2026-10-11**. 평가 전용 **20 ms 예약 적용·수신/적용 ACK**를 구현하고 기본 경로 1회·예약 경로 2회에서 입력·STOP·실제 정지·정상 종료를 확인했다. 예약 두 실행은 비교 구간 741개 정상 적용과 367개 운동 진단이 일치했고 주 제동 지표 7개 차이는 0이었다. **이 제한 조건의 적용/물리 반복은 확인했으나, 0목표 후 바퀴–차체 차이 0.404 m/s는 남아 있다.** 일반적인 결정성·물리 수렴·실차 타당성은 미확보다. 다음은 같은 예약 적용 조건에서 분할 노면/단일 평면의 접촉·슬립을 대조하는 것이다. 초기 배치/적용 반복을 더 늘리지 않는다. 기존 실패는 보존하고 기본 service·GC native·예약 꺼짐과 공통 구동/보호 계약을 유지한다. [상세 결과·후속](autonomy/LOCAL_FOLLOW_G1B_2026_10_07.md#1011-예약-적용-마감--같은-명령의-적용-시점과-제동-반복-확인), [전체 계획](reports/DEVELOPMENT_PLAN_2026_10_04.md)을 따른다. **왼쪽 잔디 차량 가림 실패·오른쪽 미실행·전체 G1/고속/실차 미완료**는 유지한다. 기본 G1 꺼짐·기본 구동식/1 ms 월드·모터축 단일 28카운트·15:1·65 mm·센서·물성·보호 한도는 그대로다. 과거 R0 접촉·이상적 내부 모터 PI·MCU 간헐 지연 한계도 남는다. 읽기 경로는 [문서 안내](README.md), 게시 상태는 Git/PR을 기준으로 확인한다.

기록·재생/Jetson 작업을 처음 인계받거나 다시 조사할 때는 [통합 인수인계 보고서](reports/RECORD_REPLAY_JETSON_HANDOFF_2026_09_29.md)를 먼저 읽습니다. 최초 목표·실패→수정 흐름·채택/미채택·남은 문제·원시 입력 위치·재현 조건을 모았으며, 상세 시험 근거는 기존 A2/A3 보고서에 보존했습니다. 9/29 문서 정리는 로컬 회수본으로 수행했고 꺼 둔 Jetson에 추가 접속하지 않았습니다.

## 다음 작업과 진행 범위

1. **같은 예약 출력·1 ms step에서 분할 노면/단일 평면의 제동·접촉을 대조한다.** 초기 배치와 예약 적용 두 실행 확인은 완료했으며 추가 단순 반복은 계획하지 않는다. 적용 순번/값/step과 입력 유효성부터 확인한 뒤 0목표 후 좌우 접촉/바퀴–차체 차이를 비교한다. 이번 20 ms 추가 대기는 평가 조건이며 실물 지연 개선/MD20A 제동 재현이 아니다. 기본 service·GC native·예약 꺼짐·공식 원본·차량 물성·벽시계 watchdog·`AppliedGuard` 정책을 유지한다. 마찰/토크/보호선을 완화하지 않으며 0.25 ms 확대·왼쪽 가림 재대조·오른쪽/G2/고속과 기본 모델 채택은 보류한다. 실제 카운트 기반 MCU PI·MD20A 출력/제동 매핑은 별도 필수 과제다. [이번 결과·후속](autonomy/LOCAL_FOLLOW_G1B_2026_10_07.md#1011-예약-적용-마감--같은-명령의-적용-시점과-제동-반복-확인), [상세 설계](autonomy/MULTI_VEHICLE_DESIGN_2026_10_04.md).
