# 현재 현황과 다음 작업

갱신: **2026-11-05, 사용자 요청으로 작업 정리·중단.** 현행 JR60P20·Ø20 배선 단독 선택형 속도 후보는 한 랩 **31.850초·최고 2.854 m/s(10.27 km/h)**를 기록했다. 10 km/h 이상은 0.663초이며 마지막 코너의 실제 정지 0.138초가 남는다. 저속차 추월·복귀(r12)와 상대 가속 시 양보·뒤 합류(r14)는 각각 대표 직선 1회 확인했다. 복귀 때 불필요하게 멈추는 전이 수정(r16)은 적용·재생·회귀·등록까지만 했고 새 주행은 시작하지 않았다. 실행 월드는 v2026.11.01 팀 파생본이다.

목표는 **빠른 완주·꾸준한 속도·불필요한 급정거 최소화**, 직선 최고 2 m/s급에서 **10 km/h**로 개선하는 것이다. **필수 기능을 각각 대회에 쓸 수준까지 완성하고, 전체가 그 수준을 갖추면 다시 성능을 높인다.** 단독 속도·다중 차량·운영·실물 준비의 완성도와 경기 영향으로 우선순위를 정하며 고정 시간·분야 순서로 교대하지 않는다. [현행 계획](DEVELOPMENT_PLAN.md)·[사용자 결정 ADR 0028](decisions/0028-speed-continuity-and-final-gearing.md)·[직전 상세 현황 원문](archive/2026-11-02-plan/PROJECT_CONTEXT.before.md)을 구분해 읽는다.

**코스 개편 전 보존:** 11/5 사용자 예고에 따라 현행 코드·실행 월드·검증 자료를 [보관 릴리스](releases/PRE_TRACK_REDESIGN_2026_11_05.md)로 고정한다. 새 공식 코스는 아직 공용 실행 월드에 적용하지 않았다. 별도 직각 코너 가정 시험은 해당 보고서의 실패·격리 범위를 유지한다.

- **기존 교통·운영:** 11/3 기둥 없는 300초 시험은 이미 실행됐고 5랩 미달·183 m 부근 정체 및 실행기 판정 실패다. 다시 미실행으로 취급하지 않는다. 원본과 다음 분석은 [해당 보고서](../artifacts/validation/2026-11-03/post_free_race_distance_v1/README.md)에 보존한다. 앞차 신호 가림·늦은 출발, 일반 STOP→START, 공용망/실물 검증 등 나머지 과제는 계획의 분모표를 따른다.

**다음 재개 순서:** [현행 계획](DEVELOPMENT_PLAN.md#영상에서-마친-일과-이전-계획에서-이어갈-일)의 순서를 따른다. 우선 등록된 r16의 대표 양보 장면 1회에서 전이 정지·접촉·진행을 확인한다. 이후 단독 코너의 짧은 실제 정지와 중속 이동차 추월 중 경기 손실·필수 기능 완성도를 보고 이어간다. 아직 확인하지 않은 후보를 기본 활성화하지 않는다.

**신규 시뮬 기준:** 단독은 `python3 scripts/run_current_solo.py <새 경로>`, 교통은 `validate_g1_traffic.py`에 `--local-sensor-config <저장소>/src/arena_description/config/b0183_c1_jr60p20_sim.yaml --pilot-marker-z 0.140`을 함께 지정한다([정확한 인자](../artifacts/validation/2026-11-04/lidar_jr60_adoption_v1/README.md#4-앞으로의-실행-인자)). 구동 물성·독립 보호·STOP 경계는 유지한다. 11/5 사용자 요청으로 Windows 전원 계획을 Silent에서 Turbo로 바꿨으며 첫 기준 주행은 변경 전에 끝났다. 펌웨어 팬 모드를 따로 확인한 것은 아니다. Jetson·주최 측 게시·커밋/푸시는 이번에 수행하지 않았다.
