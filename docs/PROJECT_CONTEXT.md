# 현재 현황과 다음 작업

개발 상태 기준: **2026-09-29**. 59.53초 정상 입력의 Jetson 계측 비용 ABBA 비교를 완료했습니다. 기존 `topic` 두 회는 운영 통과, 새 `buffered` 두 회는 보호 0명령 2/4개로 운영 실패하여 개선안으로 채택하지 않습니다. 기존 시험 방식과 재현 근거를 유지하고, **A3 집중 최적화를 보류한 뒤 A4 제한된 이상치/고착 대응으로 진행**할 것을 권고합니다. IMU 누락·간헐적 지연은 남아 있으며 실차 준비 완료를 뜻하지 않습니다. 기본 `system`/`legacy`·QoS·MCU 수신 한도·보호 시간은 유지합니다. 읽기 경로는 [문서 안내](README.md), 문서 정리 이전 현황 전체는 [보관본](archive/2026-09-27/PROJECT_CONTEXT.before.md)에서 확인합니다. 게시 상태는 Git/PR을 기준으로 확인합니다.

기록·재생/Jetson 작업을 처음 인계받거나 다시 조사할 때는 [통합 인수인계 보고서](reports/RECORD_REPLAY_JETSON_HANDOFF_2026_09_29.md)를 먼저 읽습니다. 최초 목표·실패→수정 흐름·채택/미채택·남은 문제·원시 입력 위치·재현 조건을 모았으며, 상세 시험 근거는 기존 A2/A3 보고서에 보존했습니다. 9/29 문서 정리는 로컬 회수본으로 수행했고 꺼 둔 Jetson에 추가 접속하지 않았습니다.

1. **다음 구현은 A4 제한된 이상치·고착 대응**으로 한다. IMU/엔코더의 순간 튐·NaN/Inf·고착/단절과 거절·정지·복구를 검증하고 필요한 곳만 보완한다. **10/1 재현된 C1 부분 무응답 `+Inf`의 보호층 통과 위험**도 A4 필수 사례로 추가했다.
