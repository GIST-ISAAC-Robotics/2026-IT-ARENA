# 현재 현황과 다음 작업

개발 상태 기준: **2026-10-05**. [다중 차량 설계](autonomy/MULTI_VEHICLE_DESIGN_2026_10_04.md)와 [전체 개발 계획](reports/DEVELOPMENT_PLAN_2026_10_04.md)의 **G0-a 관측 계약·단면 기하·고정 센서 시험 기반을 검증 완료**했습니다. 관련 회귀 239개와 Gazebo 개별 8사례를 확인했으며, G0 전체나 G1 추종/우회 제어 완료는 아닙니다. [결과·최초 실패·한계·재현](autonomy/MULTI_VEHICLE_G0_2026_10_05.md)에 기록했습니다. 기존 지역 Pure Pursuit와 독립 보호 경계는 유지합니다. 사용자 적극 참여는 10/24부터, 하드웨어는 부품 구매 후 설계 전입니다. 앞선 A4 제한 검증과 `control_deadline_missed` 원인 미해결, 신선한 오측정·실물/전체 랩 미검증은 아래 결과와 관련 보고서에 보존했습니다. A3 `topic` 유지·`buffered` 미채택·집중 최적화 보류, 기본 `system`/`legacy`·QoS·보호 시간도 그대로입니다. 읽기 경로는 [문서 안내](README.md), 정리 이전 현황은 [보관본](archive/2026-09-27/PROJECT_CONTEXT.before.md), 게시 상태는 Git/PR을 기준으로 확인합니다.

기록·재생/Jetson 작업을 처음 인계받거나 다시 조사할 때는 [통합 인수인계 보고서](reports/RECORD_REPLAY_JETSON_HANDOFF_2026_09_29.md)를 먼저 읽습니다. 최초 목표·실패→수정 흐름·채택/미채택·남은 문제·원시 입력 위치·재현 조건을 모았으며, 상세 시험 근거는 기존 A2/A3 보고서에 보존했습니다. 9/29 문서 정리는 로컬 회수본으로 수행했고 꺼 둔 Jetson에 추가 접속하지 않았습니다.

[10/4 전체 개발 계획](reports/DEVELOPMENT_PLAN_2026_10_04.md)이 현재 작업 순서의 근거이며 9/22 계획은 이력으로 보존한다. A3 집중 최적화 보류와 A4 제한 시험은 모든 지연·센서 고장의 해결이나 실차 안전 보증이 아니다. 다중 차량 관측 기반은 구현했으나 실제 추종/우회 주행 제어는 아직 설계 단계다. 작업 범위는 사용자의 현재 요청을 따르고 이전 세션의 게시·중단 지시를 누적하지 않는다.
