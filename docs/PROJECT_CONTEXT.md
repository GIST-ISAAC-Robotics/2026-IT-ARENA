## 검증 상태

각 행은 해당 시험 범위의 결론입니다. 전체 회귀 개수는 시험 당시 소스에 해당하며 서로 합산하지 않습니다. 조건·수치·실패 경위는 연결한 보고서가 기준입니다.

| 항목 | 확인한 결과 | 남은 한계·근거 |
|---|---|---|
| 지역 주행 | v7 두 바퀴는 주행/정지 성공·종료 실패. 서비스 종료를 적용한 슬롯 3 한 바퀴와 후속 녹화는 주행/정지/종료 통과 | 이전 실패 보존. GUI의 모든 종료 경로·실차·다중 차량 성공은 아님. [주행 기록](autonomy/LOCAL_PURE_PURSUIT_2026_09_21.md) |
| LiDAR 거리·지연 | v8의 ±3 cm + 50±20 ms 조건 두 바퀴·정지·종료·벽/노면 표본 검사 통과 | 300 ms 조건은 보호층 출발 거부이며 원래 완주 실패를 보존. 주행 중 지연 급증 제동은 별도. [결과](autonomy/LIDAR_ROBUSTNESS_2026_09_22.md) |
| IMU·엔코더 | 편향·배율·지연·시간 차이·일시 누락·복합 조건 11/11회 통과 | 자동 교정·장기 드리프트·고착·실제 펄스 손실/MCU 피드백·실차 제동 검증 아님. [결과](autonomy/MOTION_SENSOR_ROBUSTNESS_2026_09_22.md) |
| A1 구동 계약 | PC 참조와 선택형 `actuation_mode:=virtual_mcu`의 ROS 연결·명시 ARM/STOP/CLEAR·고장 경계 검증 완료 | 기본값은 `legacy`. 실물 펌웨어/ESC·무선 STOP 미구현, Gazebo 모터 PI는 이상적 관절 피드백. 상위 센서 복구와 MCU 정지 고정의 재출발 정책은 완전히 통일되지 않음. [ROS 결과](hardware/ACTUATION_ROS_2026_09_22.md) |
| A2 기록·재생 | 12 m 기록 주행·파일/CDR 무결성, 최종 회귀 **395개**, 미완료 기록 거절 **7조건** 통과. 0.5배속은 기능/스케줄 통과 | 기록기/평가기 RGB 개수 차이와 0.5배속 IMU 15개·RGB 1개 부족이 남음. **1배속은 스케줄 통과·제어 기능 실패**: IMU 1,563개·RGB 245개 부족과 `MOTION_STOP` 반복. 두 최종 재생의 EOF 0명령·정상 종료는 확인. [A2 결과](simulation/RECORD_REPLAY_2026_09_24.md) |

A2는 기록·재생 검증까지 마쳤으며 1배속 제어기의 원인 함수별 비용은 미계측입니다. 원시 bag/수신 로그는 로컬·Git 제외, 계측은 기본 비활성입니다. 재생에는 센서만 공급하고 저장된 구동 명령·정답 자료를 제어 입력으로 넣지 않습니다. Jetson/실차 검증 완료로 해석하지 않습니다. [ADR 0024](decisions/0024-isolated-sensor-record-replay.md)

## 공식 입력과 팀 임시 요소

- 실행 트랙은 `config/tracks/official_v2026.09.14.yaml`과 보존한 `v2026.09.14` ZIP 기준이다. 9/15 릴리스는 문서만 갱신됐고 ZIP의 README 외 22파일은 동일하다. 이후 9/22 계획은 공식 main `3a9ada035f77305390217795edaa73c495687b6e`의 규정/마커 공유 내용을 대조했다. [9/15 반영](track/OFFICIAL_V2026_09_15_DOC_UPDATE.md), [9/22 계획의 규정 점검](reports/DEVELOPMENT_PLAN_2026_09_22.md)
- 공식 본선 45 cm·지름길 각각 20 cm, 벽 40 cm. 코스 마커는 갠트리형 `DICT_4X4_50` ID 0/20/30/45, 판 10 cm·코드 7 cm·중심 40 cm·하단 35 cm다. 공식 PNG/SDF를 보존하며 옛 벽 부착·기울임/셀 보완을 현재 기본값으로 되돌리지 않는다. 신호등·방지턱·체크무늬·별도 지지는 팀 임시 요소다. 공식 벽의 `mu=mu2=0.8`과 미지정 도로/잔디 마찰, 실물 실측 물성을 구분한다. [재감사](track/OFFICIAL_V2026_09_14_REAUDIT.md), [ADR 0019](decisions/0019-official-v2026-09-14-gantry-markers.md)
- 본 경기 5랩·프리랩 1랩, 카메라로 직접 출발 신호 인식, HW/SW 원격 비상정지 각각 1개 이상 등의 규정은 확인했으나 경기 상태기계·실물 정지 기능 완료를 뜻하지 않는다. 지급 Jetson/배터리/서보/PDB의 상세와 패널티는 [규정·지원품 기록](reports/OFFICIAL_UPDATE_2026_09_15.md)에서 확인한다.
- 공식 #14는 기보유품 별도 산입 제외·새 구매 집계이며 지원/집계 30만 원이다. 사용자 총 40만 원 견적 전제와 공식 집계 예외를 혼동하지 않는다. [센서 예산 검토](hardware/SENSOR_RECOMMENDATION_2026_09_18.md)
- 후방 5×5 cm 마커는 의무이며 모양은 자유다. `DICT_4X4_50`을 쓰면 코스 ID와 겹치지 않게 사전/ID를 공유·조정한다. 시뮬 임시 ID 10의 등록 완료나 세부 장착 승인을 가정하지 않는다. UNIST 등록 그림은 표준 ArUco 검출 실패, 일부 `tag16h5` 조건에서만 2비트 보정 ID 8 반환이므로 정상 ID/규정 위반을 단정하지 않는다. [검출 근거](../artifacts/validation/2026-09-21/unist_marker_audit/README.md)
- 주최 측 #7~#11·#13의 기존 수정과 #12 회신·9/15 반영은 완료 이력이다. 같은 문제를 재게시하지 않는다. 새 공식판 변경은 원문·출처·실제 산출물을 대조한 뒤 적용한다. [게시 기록](track/ISSUE_12_REPLY_DRAFT_2026_09_15.md)

4. C1 관측 사각·실물 센서/MCU 시간 계약, ESC/엔코더/전원/PDB·조향/제동 응답, 공식 LED/재출발·원격 STOP·5랩/방지턱·지름길 검증은 계속 남아 있다. 9/22 확인 당시 가용 실기는 Jetson뿐이었으며, 하드웨어 설계 착수 예상과 부품 도착/차량 완성 시점을 구분한다.
