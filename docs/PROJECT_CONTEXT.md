갱신: **2026-11-02, 공식 자료·계획 정리**. 최신 공식 v2026.11.01 원본과 main 문서를 보존하고 [회의/모델 검토](reports/OFFICIAL_UPDATE_2026_11_02.md)를 마쳤다. **이번에는 실행 월드·코드·설정을 바꾸거나 시뮬레이션을 돌리지 않았다.** 기존 11/1 주행 실적은 그대로이며 새 공식 월드의 실적이 아니다.

## 주요 미해결 사항

1. **속도:** 10 km/h 미달. 42–44 m 구간은 2.96초, 부분 관측 상한 1.70초가 집중된다. 실제 무반환/가림과 경로 근거 전환을 아직 분리하지 않았다. 이전 네 종류의 근거 연결로 모든 미관측이 해소된 것은 아니다.
2. **교통:** 빠른 앞차·끼어들기·급정지, 오른쪽 재접근, 지속 코너 병렬, 비스듬한 정지차/개방형 차체의 복귀·편측 헛돎, 갈림길 마커와 벽 동시 가림이 남는다. 제한 피추월·5랩 결과를 전체 본선 완료로 올리지 않는다.
3. **신호·재개:** 공식 0/45와 2×5 새 모델은 아직 실행 연결 전이다. 높은 앞차 가림도 남는다. 현 legacy_reset은 새 경기로 돌아가므로 세이브포인트의 같은 경기 복구와 구분해야 한다. 심판 배치 후 추가 10초 대기는 규정이 아니다.
4. **실물·연산:** 실제 배치·전원/STOP·조향·제동·C1 시각·IMU 축·RGB 입력과 최신 Jetson 처리 여유 미검증. [4 cm 검사 묶음 계산](../artifacts/validation/2026-11-01/sweep_batch_v1/README.md)은 PC 중앙 비용 7.488→6.533 ms, [77파일 이관 묶음](../artifacts/validation/2026-11-01/follow_bundle_refresh_v1/README.md)은 당시 소스까지만 포함한다. 최신 후보 이관 때 갱신한다.
5. **제거/후순위:** 방지턱 통과·전용 인식·정밀 현가는 공식 제거로 필수에서 뺐다. 유효 음수 축 값은 현재 부호만으로 전진을 막지 않는다. 일반적인 도로/잔디 접지·헛돎·피치/롤 관측 한계는 남긴다. [과거 턱 실패](../artifacts/validation/2026-10-31/g2_bump_edge_diagnosis_v1/README.md)는 보존한다.

## 다음 작업과 종료 상태

**이번 작업은 자료·계획 정리까지이며, 사용자 요청에 따라 GitHub main 반영 후 종료한다.** Claude는 호출하지 않았고 새 주행·Jetson·전원 변경·주최 측 게시도 하지 않았다. 과거의 무기한 실행/예약 문구를 이번 종료 조건으로 승계하지 않는다.

다음 개발 재개는 [순환표](DEVELOPMENT_PLAN.md#다음-순환의-구체적인-순서)를 따른다.

1. **공식 시설 연결 한 묶음:** 새 원본으로 팀 파생본 생성, 방지턱 제거·공식 신호/0/45·검정 그리드, 점등 연결/대표 RGB/선정 단독 1랩. 아직 미실행.
2. **A 단독 속도:** 기존 **42–44 m 무반환 진단** 재개점 유지. 한 원인 비교를 마치면 10 km/h 미달이어도 B로 이동.
3. **B 다중 차량 → C 최소 운영 → A**, 장비/새 지연 근거가 있으면 D 실물·Jetson도 배정. 한 축에 머무르지 않도록 약 60–90분 점검·2시간 전환 검토를 적용한다.
4. 사용자 예상은 부품까지 약 1주일·실차 시험은 마지막 약 1주일이다. 확정 납기로 쓰지 않고 그동안 시뮬과 운영 준비를 병행한다. 공식 대회는 11/14, 결산은 11/13.
