# 현재 현황과 다음 작업

갱신: **2026-11-09 사용자 요청으로 작업 정리·중단.** 신호등 양옆과 갈림길 마커 지주 설치는 확정이며, 단면·발판·위치는 일부 임시다. 신호/마커 지주와 ID20/30 미검출을 함께 넣은 E1은 **46.65 m·29.917초·접촉 0**으로 본선 한 랩을 확인했다. 지주 근처 정지차 우회는 C1–C4 실패 뒤 r59/C5에서 **11.993 m·본선 복귀·최종 FOLLOW·최장 정체 0.508초·신호 지주 통과**를 확인했다. 접촉 0·최대 두 바퀴 잔디·STOP/정상 종료·소스 불변이며, 원 추종 report 실패와 기존 별도 경기 목표/시설 평가 통과를 구분해 보존했다. 관련 87회귀·156출처검사·저장 1,029명령/이유 일치·현재 장애물/미관측 반례를 확인했다. 고속 STOP 변위 약 0.94 m는 미해결이다. **다음은 준비만 한 두 앞차+전체 지주+마커 누락 통합 대표**이며 이번에는 실행하지 않았다. P22 개발은 제외하고 P21만 후속 검토한다. 시험 프로세스는 종료했다. 게시 상태는 Git 이력을 따른다. [상세 결과·실행 근거·재개점](../artifacts/validation/2026-11-09/signal_posts_markers_v1/README.md).

기존 성과·미완료는 아래 표와 [활성 작업표](track/V2026_11_06_MIGRATION_2026_11_07.md#현재-재개-지점)를 따른다. 이 시설 묶음의 대표가 확보되면 **지속 코너 병렬·빠른 추월·단독 속도 유지·P21·Jetson/실물**의 남은 작업으로 돌아간다. 과거 예약·종료 기록은 현재 작업 지시를 덮지 않는다.

목표는 **빠른 완주·꾸준한 속도·불필요한 급정거 최소화**, 직선 최고 2 m/s급에서 **10 km/h**로 개선하는 것이다. **필수 기능을 각각 대회에 쓸 수준까지 완성하고, 전체가 그 수준을 갖추면 다시 성능을 높인다.** 단독 속도·다중 차량·운영·실물 준비의 완성도와 경기 영향으로 우선순위를 정하며 고정 시간·분야 순서로 교대하지 않는다. [현행 계획](DEVELOPMENT_PLAN.md)·[사용자 결정 ADR 0028](decisions/0028-speed-continuity-and-final-gearing.md)을 따른다.

## 주요 미해결 사항

1. **속도:** 새 공식 코스 [r25 1랩](../artifacts/validation/2026-11-08/solo_gap_envelope_connected_v3/README.md)은 46.67 m·29.228초·최고 2.862 m/s(10.30 km/h)로 마쳤다. 고속 유지 표본 합계는 약1.153초이며 모든 코너의 속도를 뜻하지 않는다. 후반42.75 m에서 약0.138초의 낮은 속도 후 계속 전진했다. 더 긴 고속 유지·랩 시간 단축과 실제 제동(이번 STOP 정착 변위0.945 m)은 남는다. [r19 42.66 m 미완주](../artifacts/validation/2026-11-08/solo_corner_approach_connected_v1/README.md)와 예전 코스 실패는 그대로 보존한다. 동일 한 랩 반복보다 아직 성립하지 않은 경기 거리·더 빠른 교통 대표를 우선한다.
