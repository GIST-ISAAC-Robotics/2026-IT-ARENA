# 현재 현황 — 경기 종료와 저장소 보존

갱신: **2026-11-15 경기 종료 자료 정리**. 현장과 PC 작업의 자세한 진행 문구는 [정리 전 보관본](archive/2026-11-14-closeout/PROJECT_CONTEXT.before.md)에 원래 바이트로 남겼다.

## 실제 결과

경기 시작 시 사용 가능한 MCU가 없었고 Jetson에도 운용 장치가 연결되지 않아 차량은 움직이지 못했다. 이는 사용자의 현장 보고이며 공식 순위·점수·DNS/DNF 판정은 전달되지 않았다. 세부 원인·책임·후기는 추측하지 않고 [경기 종료 보고](reports/COMPETITION_RESULT_2026_11_14.md)에 추가한다.

| UNO Q·Jetson 직접 제어 | **미사용 대체안**. [UNO Q 코드·오프라인 빌드](hardware/UNO_Q_DEPLOYMENT_2026_11_14.md)와 회로를 보존하지만 경기 최종 버전에서 제외한다. |
| 원본과 산출물 | [공개 목록·로컬 보존 경계](reports/ARTIFACT_CATALOG_2026_11_14.md). 공식 원본·과거 실패·실측 기록은 덮어쓰거나 삭제하지 않는다. |

## 남겨둘 실물 사실

- [장착 서보](hardware/MOUNTED_SERVO_SETUP_2026_11_14.md): 수동 중앙2811·왼쪽3031·오른쪽2550 counts. 전동 시험 실제2606–2976, 내부 목표2600–2980. 바퀴각 실측·접지 주행과 구분한다.
- [DC·ESP32](hardware/MOUNTED_DC_TEST_2026_11_14.md): 조립 후 저출력 무회전, 손 회전은 사용자 정정에 따라 후진 +690 counts. 모터 무전원 15% 보호 검사는 수행했으나 재연결 후 15% 실제 구동은 통신 단절로 시작하지 못했다. [사건 증거 정리](hardware/ESP32_FAILURE_REVIEW_2026_11_15.md)에 회수 파일과 미확보 로그를 구분했다. LED 소등·발열과 기술자의 보드 단독 단락 의심이 보고됐으나 고장 원인은 확정하지 않는다.
- 센서별 수신·부품 단독 시험, Jetson 저장 입력 계산 시간은 해당 날짜 보고서의 제한된 근거다. 전체 센서·제어·구동 동시 운용 또는 경기 주행 검증으로 확대하지 않는다.
- UNO Q 자동 IMU 보정과26×21cm 자체 영역 제외는 PC 구현/검사만 완료했고 현장에서 사용하지 못했다. ESP32 최종 기준에 적용된 실측 보정으로 간주하지 않는다.

## 이후 작업

실물 장치 시험과 새 주행 개발은 중단 상태다. [성공 시뮬레이션 영상 8편](reports/SIMULATION_RECORDINGS_2026_11_15.md)과 README 전시 정리를 완료했다. 코스별 속도 대표·시설물/센서 오차 조건의 완주·기능 시연을 구분하며 실패 기록은 분석 문서에 보존한다. 영상은 저장 자세 재렌더이고 Jetson 연산 지연을 반영한 성공 완주로 주장하지 않는다. [종료 후 보류 작업](DEVELOPMENT_PLAN.md)은 미완료 항목을 찾기 위한 목록이며 자동 재개 지시가 아니다. 세부 후기는 사용자 추가 자료를 기다린다.
