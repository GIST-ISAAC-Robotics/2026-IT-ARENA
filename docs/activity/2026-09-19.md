# 2026-09-19 활동 기록

- **활동:** 사용자가 B0183 RGB와 C1을 견적 기준으로 선택하고 B0410은 후속 후보로 보류했다. 엔코더 속도·자이로 각속도 기반 보정에 필요한 IMU를 비교했다.
- **결과:** 6축·200/208 Hz·취득 시각/교정을 우선하고 LSM6DSOX를 추천했다. 당시 합배송 기준 세 센서 약 18만 원 견적과 대안/재고 조건을 정리했다.
- **한계·후속:** IMU 최종 선정·구매·설치·실물 성능은 미확정이다. 절대 자세·가속도 이중 적분·동적 3차원 보정이 구현됐다고 해석하지 않는다.
