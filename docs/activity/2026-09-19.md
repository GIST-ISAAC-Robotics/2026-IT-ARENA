# 2026-09-19 활동 기록

## B0183·C1 선택과 B0410 보류

- 사용자가 카메라 B0183과 LiDAR C1을 현재 견적 기준으로 선택하고 B0410 ToF 카메라는 기록만 남기도록 요청했다. [ADR 0020](../decisions/0020-b0183-c1-procurement-baseline.md)을 추가하고 기존 카메라·ToF 조사에 후속 결정 링크를 붙였다.
- B0410의 조사·시뮬레이션 검토 기록은 보존했다. 이번 선택은 실제 구매나 실물 성능 검증이 아니며 개별 근접 ToF의 필요/수량을 새로 확정하지 않았다. 기존 D435i 시뮬레이션과 실행 소스는 유지했다.

## IMU 목적·요구 사양·국내 모듈 조사

- ADR 0018과 현재 보정 코드를 확인했다. 직접 입력은 엔코더 전진 속도와 고정 장착 회전을 반영한 자이로 각속도다. 절대 자세·가속도 이중 적분·동적 pitch/roll 보정을 현재 구현으로 표현하지 않았다.
- [IMU 비교](../hardware/IMU_SELECTION_2026_09_19.md)에 6축·200/208Hz·SPI/취득 시각·영점 교정 중심 요구를 정리했다. 최소 100Hz, 초기 범위 ±500°/s·±8g, 시각/바이어스 목표는 설계 제안이며 실물 검증값과 구분했다.
- 제조사 자료와 실제 브라우저 판매 화면을 대조했다. 배송/VAT 포함 LSM6DSOX 24,249원, BMI270 37,350원(품절), ISM330DHCX 42,520원, BNO085 56,501원, ICM-42688-P Click 57,180원이다. 검색 캐시와 다른 가격을 현재 화면 값으로 정정했다.
- LSM6DSOX를 우선 추천하되 IMU 최종 선정으로 기록하지 않았다. BNO085는 제조사의 ESP32-S3 I²C 문제를 반영했고, 산업용/9축/높은 명목 Hz가 현재 목적에서 무조건 우수하다는 해석을 피했다.
- B0183+C1+LSM6DSOX는 같은 판매처 기본 합배송 175,549원, 각각 단독 주문 시 180,949원이다. 센서 세 품목 약18만 원의 협의안을 제시하며 MCU·엔코더·전원·구동계는 별도라고 명시했다.
- 문서와 계산/연결 근거를 확인했다. 새 하드웨어·ROS 어댑터 구현, 시뮬레이션 실행, 구매, 엑셀 수정, 외부 게시를 하지 않았다.
