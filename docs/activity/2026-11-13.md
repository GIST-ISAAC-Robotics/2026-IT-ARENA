# 2026-11-13 활동 기록

## 구형 신호등 가로대 연장 시안

- **활동:** 공식 저장소의 현재 파일·이슈 댓글·릴리스 첨부를 대조하고 10/9 제작측 공유 STL이 확인 가능한 가장 최근 구형임을 정리했다. 공유 링크를 다시 받아 11/9 보관본과 바이트/해시 일치를 확인했다. 10/29은 치수·이미지 보충, 11/12은 보강 형상이 추가된 신형이다.
- **결과:** 구형 가로대에 도로 폭 증가분160 mm를 더하고 양쪽 지주/발판을80 mm씩 옮긴 별도 STL을 만들었다. 가로대600→760 mm·전체 폭625→785 mm이며 높이465 mm·중앙 모듈7,033면·지주/발판 크기는 유지했다. 좌표·면 위상·원본 해시·렌더를 확인했다.
- **한계·후속:** 사용자 요청의 형상 시안이다. 강도·출력 적합성·실물 채택은 검토하지 않았으며 운영 월드/제어/공식 원본을 바꾸지 않았다.
- **근거:** [출처·치수·결과 STL·비교 그림](../../outputs/traffic_light_610_concept_2026_11_13/README.md), [기하 검증](../../outputs/traffic_light_610_concept_2026_11_13/validation.json).

## ESP32 전원 헤더·PDB 조립 배선 인계

- **활동:** 3V3 2핀·GND 4핀에 맞춰 CF VA/OE 분기와 센서 공통 GND를 지정했다. PDB CN/CH 대응·정격과 서보 전용 케이블을 도면에 반영했다.
- **결과:** 배럴잭·서보 전용선·C1 USB·B0390 FPC를 케이블 단위로 표시했다. 별도 [층별 배치도](../hardware/WIRING_LAYERS_2026_11_13.md)는 STEP 해시를 재확인하고 기존 층을 유지하고 후속 사용자 지정으로 Y 분기를 상부 1단 J01 근처에 두어 광축 통과 전원4쌍(8가닥)·USB2개를 구분했다. 두 그림에 공통 2심 뒤 두 갈래 Y 케이블을 표시했고, 전체 회로도를 일정한 부품 열·배선 간격으로 재정렬해 STOP을 ESP32 아래로 옮겼다. CF·STOP은 하부, C1 USB 어댑터는 광축 아래 배치안이다. 사용자 요청에 따라 신호·전원·분기를 부품별 한 장으로 다시 배치했다. 각 부품은 한 번만 표시하고 교차/접속점을 구분했다. 결선은 그대로 유지했다. CN1 입력, CH1~6↔CN2~7을 제조사 PDF로 확인하고 서보는 M01 CH5(CN6), 어댑터↔서보는 보유 3선 전용 케이블 1개로 지정했다. GPIO/헤더/분기 정적 검사와 렌더 검토를 수행했다.
- **한계·후속:** 추가 STOP 스위치는 2선 I/O 유지형·정격 표시 없음으로 확인했다. 공식 규정은 HW/SW 각 1개와 시연을 요구하지만 독립 전원 차단을 명시하지 않는다. GPIO 처리 방식의 HW 인정과 원격 범위는 미확인이나, 후속 사용자 지시로 GPIO8↔스위치↔TGND를 실선 결선으로 반영했다. GPIO12개·GND 헤더4개·TGND5접점과 O/개방 정지·복귀 시 자동 출발 금지를 명시했다. 이번 작업은 문서·도면 갱신이다. 장치를 조작하지 않았으며 헤더 재분배 후 전체 조립·부하 전류·장착 교정은 별도 확인한다.

## 조향 CAD 운동과 시뮬레이션 인계

- **활동:** Fusion의 서보·링크·킹핀·바퀴 조인트를 조사하고 양 방향을 작은 간격으로 구동해 바퀴축 방향을 계산했다.
- **결과:** 서보 입력 설정−23.6~+23.4°의96행과 양 끝 내륜 약30°·외륜 약23.3°를 기록했다. 조인트각과 바퀴 방향을 대조하고 비정상 자세와 첫 복귀 판정 실패를 보존했다. 좌우 조향 차이는 대칭 너클과 비대칭 서보 링크 배치를 구분하고, 독립 평면 링크 계산·혼 중립 오프셋 가상 비교로 검토했다.
- **한계·후속:** CAD의 조인트 제한이며 간섭·실물 최대각·장착 교정과 Gazebo 재현은 미검증이다. 기존 시뮬 설정은 유지했다. Fusion 자세를 중립으로 돌렸으나 열린 문서에는 미저장 표시가 남았다.
- **근거:** [조향 CAD 인계](../hardware/STEERING_FUSION_2026_11_13.md), [원 측정·표·감사](../../artifacts/validation/2026-11-13/steering_cad_fusion_v1/README.md).


## 실물 입력·확정 기구와 실행 지연 통합

- **활동:** 사용 가능해진 Jetson에서 센서/시계·구동 없는 운용 연결과 계산 비용을 확인했다. 카메라 그리드/구형610신호 시설, 마커 기본OFF 관측·희소 상대 형상을 준비했다. 확정 STEP를 별도 보존하고 새 지주/배선 여유·실장 자기 반환 보정 후보·최종 축거/윤거·차체를 모델/계획/보호/평가에 연결했다. 잔디3mm는 별도 강체 민감도만 두고 기본 주행은 평탄 조건을 유지했다. 관측 경로·같은 조향 저속 재검사와 C++ 분류 계산 공유를 구현/대조했다.
- **결과:** 최종 기하 연결136+실제 ROS1검사와 부분 주행을 수행했다. 새 계산 공유는 PC253/Jetson101관련 검사·각 플랫폼220판단 전후 전체 동일이었다. Jetson 현재 검사 중앙57.40→51.03ms·p9597.75→85.34ms, 두 계산 프로세스31초 비교에서 명령 만료 뒤 누적 공백 평균6.726→5.489초를 확인했다. 마지막 PC/Jetson10개 자식 정상 종료·752파일 불변·자기 시험 잔여 없음으로 정리했다.
- **한계·후속:** 기존 기하36.15m, 새 기하18.58m 뒤 정체 실패와 플랫폼별 표본 수 차이를 보존했다. 실시간10Hz·새 기하 전체 랩·운용 펌웨어 구동 연결은 미완료다. 신호 소등 오검출·기본OFF 마커 감속/희소 상대 주행과 조립 후 교정도 남는다. 다음은 MCU/센서 운용 연결과 명령 수명 계약이며 수치 미세 검사를 계속 반복하지 않는다. 사용자 정리 요청으로 중단했고 커밋/푸시는 하지 않았다.

## 조립 전 무인 작업 큐·실물 최소 시험 계획 정리

- **활동:** 사용자 재지시에 따라 시간대별 일정과 수면·휴식 블록을 삭제하고, Jetson 지연·실센서 통합 shadow·운용 MCU 코드·최종 형상 시뮬의 순환 우선순위를 정리했다. 이미 검증한 엔코더 손 회전·센서 단독 수신을 반복 항목에서 제외했다.
- **결과:** 차량 조립 후는 짧은 4방향 벽 이동과 바퀴 공중 모터·서보·엔코더 확인만 남기고, 자체 트랙 주행은 계획에서 제외해 공식 현장 연습으로 이관했다. 마커 보조 기본 OFF·실물 무인 구동 금지·기존 성능 개발 유지 원칙을 보존했다.
- **한계·후속:** 이번 작업은 문서·계획만 변경한다. PC/Jetson/ESP32의 신규 실행이나 센서·모터 시험을 실시했다고 주장하지 않는다. [현행 계획](../DEVELOPMENT_PLAN.md)과 [실물 인계](../hardware/PHYSICAL_HANDOVER_APPROVED_LAYOUT.md)를 따른다.
