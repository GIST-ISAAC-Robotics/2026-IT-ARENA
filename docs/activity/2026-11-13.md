## ESP32 전원 헤더·PDB 조립 배선 인계

- **활동:** 3V3 2핀·GND 4핀에 맞춰 CF VA/OE 분기와 센서 공통 GND를 지정했다. PDB CN/CH 대응·정격과 서보 전용 케이블을 도면에 반영했다.
- **결과:** 배럴잭·서보 전용선·C1 USB·B0390 FPC를 케이블 단위로 표시했다. 별도 [층별 배치도](../hardware/WIRING_LAYERS_2026_11_13.md)는 STEP 해시를 재확인하고 기존 층을 유지하고 후속 사용자 지정으로 Y 분기를 상부 1단 J01 근처에 두어 광축 통과 전원4쌍(8가닥)·USB2개를 구분했다. 두 그림에 공통 2심 뒤 두 갈래 Y 케이블을 표시했고, 전체 회로도를 일정한 부품 열·배선 간격으로 재정렬해 STOP을 ESP32 아래로 옮겼다. CF·STOP은 하부, C1 USB 어댑터는 광축 아래 배치안이다. 사용자 요청에 따라 신호·전원·분기를 부품별 한 장으로 다시 배치했다. 각 부품은 한 번만 표시하고 교차/접속점을 구분했다. 결선은 그대로 유지했다. CN1 입력, CH1~6↔CN2~7을 제조사 PDF로 확인하고 서보는 M01 CH5(CN6), 어댑터↔서보는 보유 3선 전용 케이블 1개로 지정했다. GPIO/헤더/분기 정적 검사와 렌더 검토를 수행했다.
- **한계·후속:** 추가 STOP 스위치는 2선 I/O 유지형·정격 표시 없음으로 확인했다. 공식 규정은 HW/SW 각 1개와 시연을 요구하지만 독립 전원 차단을 명시하지 않는다. GPIO 처리 방식의 HW 인정과 원격 범위는 미확인이나, 후속 사용자 지시로 GPIO8↔스위치↔TGND를 실선 결선으로 반영했다. GPIO12개·GND 헤더4개·TGND5접점과 O/개방 정지·복귀 시 자동 출발 금지를 명시했다. 이번 작업은 문서·도면 갱신이다. 장치를 조작하지 않았으며 헤더 재분배 후 전체 조립·부하 전류·장착 교정은 별도 확인한다.

## 최종 24시간 작업 우선순위 조정

- **사용자 지시:** 차량은 11/13 저녁 완성 예상, 11/14 05:00 출발로 실물 시험 시간이 제한된다. 별도 트랙은 재료·장소·시간·인력 부족으로 제작하지 않는다. 차량 도착 전 Jetson·ESP32·C1·IMU·카메라와 시뮬레이션으로 사람 없이 가능한 작업을 우선한다.
- **계획 변경:** Jetson 처리 지연을 최우선으로 두고, 현재 연결 센서 동시 입력→ROS 판단/보호→명령 생성의 비구동 통합을 진행한다. 이미 완료한 센서별 단독 수신, 엔코더 손 회전, 배선 확인을 반복하지 않는다. 시뮬레이션은 단독 완주→긴 저속/정체→추종·우회·재출발→피추월/코너→신호·마커 보조 순으로 최소 기준을 확인하고, 기준을 만족하면 다음 작업으로 이동한 뒤 전체 순환에서 다시 개선한다. 10Hz 목표는 우선 유지하며 8/6/5Hz는 비교 후보로 남긴다.
- **실물 최소 확인:** 차량 도착 뒤 작은 4방향 벽 공간에서 C1 벽 반환과 IMU yaw/엔코더 방향을 짧게 대조한다. 모터는 바퀴를 띄운 상태에서 저출력부터 단계적으로 올려 출력 여유를 확인하고, 고속 시험도 바퀴를 띄워 별도로 한다. 서보는 장착 후 중립·실제 바퀴 조향각·기구 간섭만 다시 확인한다. 여건이 되면 짧은 저속 직진/회전/정지만 확인한다. 공식 트랙은 대회장 연습 시간에만 확인한다.
- **범위:** 이번 조정은 계획·인수인계 문서 변경이다. 새 시뮬/장치 시험, 배터리 연결, 센서 보정, 모터/서보 구동을 수행한 결과가 아니다.
