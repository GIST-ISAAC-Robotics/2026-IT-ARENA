# 2026-10-21 활동 기록

- **활동:** GPT가 설계·구현·검토하고 GPT-6 Luna가 실행·대기·회수를 담당했다. G1 깊이 각도 창·외곽 묶음 계산을 동등성 대조 후 반영하고 원점 방향 모호함은 보수적으로 정정했다. 점형/유한 표적·속도·중심·최근 관측 결합을 비교하되 실물 전제 없는 보호 완화는 채택하지 않았다. 이어 A1 분할 프레임→만료/STOP 대조와 실제 인코딩 링크 예산을 준비하고 C++ 프레임 코어를 제한 이관했다.
- **결과:** 관측 수정 후 ON 3,001/OFF 2,837판단 일치, ROS 고장 43/43·정상 종료·잔존 0. A1 추가 뒤 전체 3,570회귀 통과. 전송 대조 12사례·828이벤트, C++ 추가 뒤 관련 184회귀·243사례/2,294연산 및 JSON 경계 2,039회 차이 0·ASan/UBSan 오류 보고 없음. 모든 실행 소스/입력·앞선 실패를 보존했다. 검사 수는 시점/범위가 달라 합산하지 않는다.
- **한계·후속:** G1 완주 0·측후방 공백·간헐 지연·종료 SIGSEGV는 남고 최종 ON 재생은 최대 24.764 ms·20 ms 초과 4건이다. 손상 길이가 STOP 해석을 지연시키는 기존 한계를 재현했으며 명령 만료와 실제 차체 정지를 구분했다. 현행 50 Hz 메시지의 8N1 예산은 115200/230400에서 전체 offer가 포화지만 baud/형식은 변경하지 않았다. C++는 프레임만이며 JSON/상태기계·부분 조립 만료·실물은 미이관/미검증이다. 사용자 마감 요청 뒤 작성 중인 C++ 검사만 마쳤고 새 작업은 시작하지 않는다. 커밋·푸시·외부 게시·Jetson/전원 변경 없음. 다음은 부분 조립 만료/재연결 정책과 엄격한 계약 이관이다.
