# 2026-09-18 활동 기록

- **활동:** 총 40만 원 견적 전제에서 RGB/C1·저가 ToF/스테레오 후보와 JetPack 6.2 호환성을 조사했다. 원격 HW/SW 비상정지·노트북 모니터링과 현장 시험 제약을 검토했다.
- **결과:** B0410의 원시 120fps와 깊이 30fps, 명목 지원과 실제 지속 처리량을 구분했다. 가격/출처, 무선 STOP 경로와 MCU 공유 한계를 문서화했다.
- **한계·후속:** 구매·실물 성능·배선·새 제어 구현은 없다. 하드웨어팀 모터 변경 이야기는 미확정이고 사용자 예산 전제를 공식 집계 예외로 확정하지 않았다.
