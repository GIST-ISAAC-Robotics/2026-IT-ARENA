- **활동:** 기존 실물 무부하 시험의 격리 펌웨어를 재사용하고, 토크 OFF 중립 읽기·기존 프로필 형식 저장·한 번에 최대 12 counts 미동 도구를 마련했다. Jetson에 도구와 시험 앱을 배치하고 앱 백업·복구와 실제 실행 순서를 연결했다.
- **결과:** Jetson ARM 가상 시리얼에서 관련 6검사, Windows 기존 조향 교정 18검사를 통과했다. 중립 저장의 서보 쓰기 0, 명령 전 현재 위치 고정, 정상/오류 후 토크 OFF readback을 확인했다. 진단 앱은 기존 실물 시험 이미지와 SHA-256이 같다.
- **한계·후속:** 실제 ESP32 플래시·장착 중립·좌우 부호·부하·링크 여유는 확인하지 않았다. ESP32 연결 뒤 모터 전원을 분리한 상태로 시작한다.
- **근거:** [중립·미동 실행 절차](../hardware/MOUNTED_SERVO_SETUP_2026_11_14.md).

### 조향 수동 3점 측정 추가

- **활동:** Jetson 서보 도구에 토크 OFF에서 손으로 직진·좌측 최대·우측 최대를 맞추고 저장하는 `measure`를 추가했다. 서보 축 환산값과 각도계로 잰 양쪽 바퀴각을 별도 기록한다.
- **결과:** Jetson ARM 가상 시리얼 관련 7검사 통과 후 같은 파일을 배치했다. 세 위치 기록에 ARM/서보 쓰기가 없고 토크 ON이면 중단한다. count wrap·같은 쪽 끝점·서보 명령 범위 밖의 기록은 운영 후보로 내지 않는다.
- **한계·후속:** 실제 ESP32·차량으로는 미시험이다. 손으로 확인한 끝점은 측정치로 보존하며 경기용 운용 범위는 여유를 두고 별도 확정한다.
- **근거:** [수동 3점 실행 절차](../hardware/MOUNTED_SERVO_SETUP_2026_11_14.md#2-토크-해제--손으로-직진왼쪽-최대오른쪽-최대-기록).
