# 2026-10-07 활동 기록

## 시뮬레이션 개발·검증

23시대 추가 작업으로 잔디 좌우 차량 가림 사례를 사전 등록하고 시험기·평가기를 확장했다. 왼쪽 실행의 진행 실패·큰 휠–차체 차이를 보존했으며, 자정을 넘긴 분석·마감은 [10/8 기록](2026-10-08.md)과 [산출물](../../artifacts/validation/2026-10-07/g1b_side_v1/README.md)에 정리했다.

- **활동:** 선택형 G1-b Gazebo 앞차 시험기를 연결하고 signed 음수 피드백의 경계 reset과 입력 무효를 분리했다. 사전 행동 수치는 유지하며 coverage·비유한/누락 거절·소스 보존·접촉 계측/사후 상태 감사를 보강했다. Claude 한도 뒤 사용자 지정 GPT 모델 역할로 이관했고, 등속 실패 기록 뒤 잠시 중단했다. 재개에서는 보존 scan·MCU 피드백 open-loop 재생으로 등속 정체 원인을 규명하고 `local_follow.py`의 경계 후보 선택만 고쳤다(돌출점 2차 정제, 같은 스캔 긴 반대 벽 기준 선호 벽 재선택). 이어 STOP 시각 비교 평가기만 v3→v4로 고쳐 seed 1 등속과 R0 비교를 실행했다. 재개는 GPT 설계/검토, Claude Opus 5.5 분석·수정·문서, Claude Sonnet 5.5 실행·회수로 진행했다. 저녁 후속은 사용자 지시로 GPT 주 에이전트가 직접 수행했다. 기본 파생 코스의 임시 신호등 바닥 기둥과 마커 지지대를 제거하고, 이전 월드/설정/생성기를 보존했다. 기둥 전후 G1 비교와 R0 정지 앞차 제동 조사·원천 휠/토크 진단을 추가했다. 이어 최근 실행의 단일 모터축 설정을 감사하고 평가용 휠 접촉 계측·고정 명령의 분할/단일 노면 대조를 구현했다. 이어 가까운 앞차 초기 가림과 첫 U자 코너의 평가 조건을 별도 등록하고, GPT 주 에이전트가 평가기·회귀를 확장했으며 GPT-6 Luna가 두 Gazebo 실행과 마감 검사를 수행했다.
- **결과:** 원인은 벽면 안쪽 약 7.8 cm의 팀 임시 신호등 기둥 모서리 1점이 지원 허용치 안에 남아 벽 연결을 끊고, TTL 만료 뒤 무기억 재획득이 교착한 것이다. 같은 최종 제어기(`fddc808b…`)로 사전 등록 G1 3사례×3seed 모두 통과 실행을 얻었다. seed 1 등속은 평가기 v2의 동시각 float 비교로 STOP 전 고정 1건이 집계되어 실패했고, 평가기만 정수 시각 비교로 고친 뒤 다시 통과했다. 그 과정에서 v3의 요청 시각이 0.113~0.118초 오래된 결함을 찾아 v4(요청 직전 새 `/clock`)로 고쳤다. 당시 회귀 472개, R0 비교 3개 실행 유효. GPT 주 에이전트의 최종 독립 검토(SHA·판정 대조, 별도 pytest 72/66 통과, 잔존 0)를 마쳤다. 저녁에는 정확히 5링크·29충돌체 외 형상과 공식 원본 보존을 확인했고, 등속 전후·새 코스 정지 앞차 G1 세 실행이 행동/정지/종료를 통과했다(정지 앞차 최소 0.386 m). R0 두 회는 무접촉이나 간격 0.101/0.089 m로 G1 기준 미달, 반복에서 좌우 휠·차체 운동 불일치를 포착했다. 후속 최종 회귀 517개·5실행 소스/정지/종료 감사 통과, 기존 검사와 합산하지 않는다. 추가로 단일 28카운트·15:1·65 mm와 MCU 3,483표본을 확인했다. 고정 명령 두 대조와 기록 종료 보완 R0는 기능/STOP/정상 종료 통과, 마감 회귀 575개 통과(이전 개수와 합산하지 않음). 같은 G1 제어기로 초기 부분 가림/재출발과 첫 U자 추종 각 1회가 통과했다(최소 간격 0.350/0.581 m, 재출발 0.874초, 코너 12.998 m·180.52°). 두 실행의 STOP·종료·사후/출처/단일 엔코더 감사 및 마감 회귀 583개 통과.
- **한계·후속:** R0는 G1 판정선을 정지/재출발(최소 0.069 m)·정지 앞차(앞차 접촉 19 메시지)에서 충족하지 못했고 v3 R0와 실행 간 차이가 컸다. 후속으로 바퀴/차체 불일치까지 확인했지만 접촉 하중·차동/PI·물리 엔진 중 최종 원인은 미확정이므로 짧은 물리 제동 대조가 다음 과제다. 실물 시공 사진 공개 후 지지 구조를 재검토한다. seed 1 v2 실패, v3 오래된 요청 시각, 1차 수정판의 0.404초 일시 경계 상실, 오전 등속 실패를 보존했다. 사후 coverage 감사의 경계/HOLD 검사는 G1 전용이다. 곡선/옆차·실물 C1 잡음·전체 G1/실차는 미검증. 제어기·보호층·센서·물성을 후속에서 바꾸지 않았다. 커밋/푸시·외부 게시·전원 변경 없음. 접촉 계측 R0 첫 실행의 종료 actor coverage 실패와 고정 시험기 타임스탬프 누락 실패를 보존하고 수정했다. 후속 R0 간격 0.101 m·휠–차체 차이 0.219 m/s, 불균형 하중/우측 접촉 기록 공백을 관측했으나 과거 접촉 원인은 미해결이다. 계측을 유지해 저속 G1 다음 단계로 진행하되 재발 시 제동 조사를 우선한다. Gazebo 내부 PI는 여전히 이상적 관절 피드백이다. 새 시험은 부분 가림·첫 코너 각 1회에 한정하며 제어기 수정은 없었다. 코너 실행 초기 가속에서 휠–차체 차이 최대 0.290 m/s가 남았다. 다음은 옆차 가림의 경로 유지·정지·회복이며 전체 G1·실차 완료로 확대하지 않는다.
