# 2026-10-02 활동 기록

- **활동:** 사용자가 MB4266-24180 + PGE-213을 최종 선정하고 MD20A·65 mm·초기 전체 15:1을 확정했다. Claude의 PR #5를 GPT가 검토·보완한 뒤, 같은 날 후속 요청으로 Claude 워커와 함께 시뮬레이션을 모터축 엔코더 하나로 변경했다. 치수 충돌 때문에 축거는 임시 135 mm로 조정했다.
- **결과:** PR 계산 재현·원본 해시를 확인하고 무부하/제동 근사의 한계를 바로잡았다. 단일 모터 카운트·평균 바퀴 환산, 제어/보호·가상 MCU 연결, 과거 기록 호환을 구현하고 관련 회귀 542개·C++ 방정식/컴파일을 통과했다. 약 0.486 mm/카운트와 관측 한계를 기록했다. 실행 월드의 차량 설정 해시만 갱신되고 공식 원본/트랙 형상은 불변임을 확인했다.
- **한계·후속:** 사용자의 지시에 따라 Gazebo 주행·ROS 실행·Jetson 재생은 하지 않았다. 새 구성의 주행·저속 양자화·펄스 손실/지연·모터축만의 정지 판단은 후속 검증이다. 실물 장착·핀 배치·전류/열·MD20A 제동과 양자화된 엔코더만 쓰는 MCU 내부 속도 루프도 미검증이다. 과거 시험 원본은 보존했다.

## 모터축 엔코더 실행 검증

- **활동:** 후속 재개 지시에 따라 양자화·메시지/펄스 누락·지연·카운터 초기화/래핑·고착을 검사했다. 분석/수정은 GPT, 빌드·ROS/Gazebo 실행·대기는 GPT 6 Luna가 담당했으며 이번 실행 작업에는 Claude를 사용하지 않았다.
- **결과:** 큰 유한 속도·카운트 격자/범위 거절, 선택형 MCU의 500 ms 무진행 정지, 단일 평균 속도 PI 입력을 추가했다. 숫자/PI 시험·ROS 16조건·확장 회귀 579개를 통과했다. 최초 한 바퀴 시도는 느린 실행의 실제 시간 감시로 0 m 실패했으나 기존 오프라인 GPU/30초 감시 조건으로 공식 코스 12.02 m·최고 8.10 km/h, 충돌 표본 없이 명시 정지·정상 종료를 통과했다.
- **한계·후속:** 전체 랩·실물 MCU/제동·새 Jetson 재생은 미검증이다. 정지 요청 후 약 0.79 m는 임시 물리 결과다. 10% 펄스 손실은 검출되지 않았으며 별도 PI 모형에서 과속 편향을 만들었다. 기동 지연은 팀에서도 미측정으로 500 ms는 시험 가정이다. IMU 이상치·C1 부분 무응답 대응은 다음 A4에 남겼다. 최초 반영/실행 실패와 당시 소스는 보존했다.
