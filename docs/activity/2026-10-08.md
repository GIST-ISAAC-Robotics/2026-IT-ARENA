# 2026-10-08 활동 기록

- **활동:** 전날 시작한 G1 잔디 옆차 가림 시험을 마감했다. 이어 동일 표본화 요청·초기 자세로 분할 노면/단일 평면 제동 대조 A→B→B→A를 수행했다. 새벽(04시 재개)에는 정상 감속·0속도 대기·명시 STOP의 의미를 정리하고, 기존 동력 로그의 토크/속도 시점 차이를 정정했으며, 평가용 영점 처리 네 모드와 동시각 동력 계측을 구현해 5회 대조했다(GPT-6 Astra 구현·분석, GPT-6 Luna 실행·회귀). 오후에는 수동 제동 근사의 물리 step 민감도를 확인했다. 평가 전용 `evaluation_physics_step`(0.5/0.25 ms, 증거 경로 필수)·실행기 선택 인자·분석기·후속 소스 계약을 만들고, 지표·허용치·G1 관문을 먼저 등록한 뒤 새 Gazebo 8회를 실행했다(GPT 주 에이전트 범위·검토, Claude Opus 5.5 구현·분석·문서, Claude Sonnet 5.5 실행·회수). 제어기·센서·보호 한도·기본 물성/월드는 유지했다. 저녁에는 정수 sim 시각 격자 발행과 1/0.25 ms·위상 0/10 ms 행렬 6회를 수행했다(Claude Opus 5.5 구현, 사용자 확인대로 Sonnet 5.5 실행). 사용량 한도 뒤 GPT-6 Astra가 분석·실패 전파 검사·기록 마감을 직접 맡았다.
- **결과:** 왼쪽 가림은 최소 간격 0.169 m·정지 후 재진행을 확인했지만, 진행 2.080 m·옆차 미통과로 실패다. 제동 A/B 4회에서는 두 노면의 평균 바퀴–차체 차이 약 0.775/0.708 m/s가 재현됐다(회귀 608개). 새벽 단일 평면 대조는 기존 0.708→적분 초기화 0.660→지연 제거 0.443→수동 근사 0.415 m/s였다(최초 685통과/1실패는 옛 launch 해시 참조로 보존, 후속 계약 연결 뒤 686개 통과). 오후 step 시험에서 단일 평면 수동 근사는 1/0.5/0.25 ms가 허용치 안이었다(0.415/0.408/0.380 m/s). 분할 노면은 허용치 분류상 미수렴이었다. 같은 1 ms 재실행에서는 새벽 시험 당시의 0명령 전 0.593 m/s 불일치가 0.019 m/s로 재현되지 않았고, 반복 사이에 출력과 명령 발행 위상이 함께 달랐다. 모든 step 비교에 요청/safe/MCU 정렬 불일치 표본이 있어 step 단독 효과는 식별되지 않았다. 8회 중 7회 유효, 기존식 0.25 ms 1회는 gz 종료 코드 255로 정상 종료에 실패해 보존했다(재시도 통과). 회귀는 716개 통과했고, 검토 보완 뒤 단위 106개가 통과했다. 저녁 6회는 정지·정상 종료했고 스케줄 포함 4회가 유효했다. 같은 위상의 요청·safe·MCU 전환 시각은 맞았지만 1 ms 반복의 0명령 후 차이는 0.411/0.601 m/s로 달라 재현성은 확보하지 못했다. 실행기의 격자 감사 판정 누락을 수정하고 원본을 보존했다. 전체 1176개, 최종 검토 보완 뒤 관련 190개 회귀 통과.
- **한계·후속:** 새벽 시험 당시에는 분할 노면 0명령 전 0.593 m/s 차이를 근거로 step 민감도 확인을 다음 작업으로 두었다. 오후 결과로 이 값과 모드별 크기는 1 ms 한 위상의 단일 관측으로 낮춰 해석한다. 위상은 후보 원인일 뿐 원인 분리는 미완료이고, 0.25 ms 반복이 2회뿐이며 기존식 0.25 ms 두 실행도 서로 달라 안정성을 확정하지 않는다. 관문 미충족으로 왼쪽 가림 G1 선택형 대조는 실행하지 않았다. 다음은 시뮬레이션 시계 격자에 맞춘 고정 요청 발행과 등록 위상 오프셋에서의 분포 비교다. 평가 근사는 기본 미채택이며 실물 회로 재현이 아니다. 오른쪽/G2·실물 제동은 미검증이고 gz 종료 255 원인은 미확정이다. 모터축 단일 28카운트·15:1·65 mm와 원시 기록 보존을 유지했고, 커밋·푸시·외부 게시·Jetson·전원 변경은 없었다. 저녁 시험 뒤에는 요청 전환 정렬만으로 물리 반복 차이가 없어지지 않는 점을 확인했다. R4·R6의 발행 지연 실패와 배치 미중단은 별도로 보존하며, 수정 실행판의 Gazebo 재시험은 아직 없다. 다음은 수정판의 지연·실패 전파 확인 후 플러그인 전환 계측이다. 수동 근사/0.25 ms는 기본 미채택이며 G1 확장은 계속 보류한다.
