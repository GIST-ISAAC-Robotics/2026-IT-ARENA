# 2026년 10월 27일 활동 기록

- **활동:** 전날의 공식 트랙 적용을 마무리하며 누적 코드 전체를 검사했다. 기록·재생 및 Jetson 이관 목록의 새 모듈 7개 누락, 과거 소스와 최신 변경의 연결 기록을 보완하고 실행 안내의 버전·방지턱 설명을 갱신했다. 원시 로그 제외와 증거의 원래 줄바꿈 보존을 점검했다. 이후 사용자와 저장소 방향을 재검토하고 구매 고정·배치 변경 허용, 잔디 활용·충돌 임박 시 추가 이탈 선호, 무반환/간격 재검토·15 km/h 목표를 ADR 0027에 정리했다. 현황·계획·하드웨어 목록의 중복과 오래된 제한을 정리했다.
- **결과:** 앞선 코드 마감에서 전체 5,668회귀·실패/skip 0·소스 불변을 확인했다. 안내 문구 수정 이후 관련 242회귀도 통과했다. 사용자 요청대로 10/24–26의 누적 구현·문서·실패 기록·공식 원본·트랙 사진을 main 반영 대상으로 정리했다. 이번 문서 정리는 실행 코드·시험 결과를 변경하지 않았으며 새 주행을 실행하지 않았다. 최종 게시 상태는 Git을 기준으로 확인한다.
- **한계·후속:** 기존 M1 전체 랩·M3 측후방 가림/간격·M5 실제 밀집 출발·계산 마감 문제는 남는다. 고정 카메라의 앞차 가림·빨강을 놓친 출발·방지턱 통과와 새 정책의 구현이 남는다. 100/150 mm 방지턱 완화안은 미확정이며 실제 차량·Jetson·전원 설정을 변경하지 않았다.
