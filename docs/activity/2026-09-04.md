- 깊이 명목 형상/내부 파라미터 검사와 실제 전달률을 분리했다. 단기 26.7 Hz를 형상 불일치로 부르지 않고, 요청 30 Hz 대비 25~33 Hz의 개발용 전달률 기준을 별도로 기록한다. 실물 최소 요구 Hz나 안전 기준이 아니다.
- RGB 보조와 질량 보정 뒤 `stereo_brisk_25m_02_rgb_center`는 25.01610 m, 최대 중심선 거리 0.29336 m, 벽 겹침 0개, 깊이 27.2384 Hz, 실제 정지·정상 종료를 통과했다. 노면 밖 잔디 진입은 이 검사에서 실패 조건이 아니므로 도로 경계 준수를 의미하지 않는다.
- 같은 소스의 한 바퀴 녹화 `stereo_brisk_one_lap_02_rgb_center_video`는 24.19619 m에서 다시 한쪽 헛돎으로 실패했다. 명령 0.47165 m/s, 실제 차체 약 0.0000029 m/s, 오른쪽 37.7337 rad/s·왼쪽 거의 0이며 ToF는 CLEAR였다. 62.95초·1,259프레임 영상 재디코드와 정상 종료는 통과했다. **영상이 저장됐다는 사실과 한 바퀴 완주는 별개**이다.
- 기존 회색 노면 중심 보조는 정지 발생을 줄였으나 재현성 있게 해소하지 못했다. 차체가 노면 경계에 접근한 원인과 경계 단차/접지 상태를 더 분리해야 한다. 공식 트랙 파일이나 차동 모델을 몰래 바꾸어 성공시키지 않는다.
- 현재 핵심 Python 검사 50개와 관련 패키지 빌드는 통과했다. 전체 회귀 검사와 최종 결과 요약은 후속에 기록한다.

  조기 출발 없음, 마커 0/20/30/45, 센서만 입력·실제 정지·정상 종료를 통과했다.
