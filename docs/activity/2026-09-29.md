# 2026-09-29 활동 기록

- **활동:** 독립 진단 수집·색상 판정 최적화 뒤 영상 프로세스 분리와 시각/reset/고장 정지를 구현했다. 영상 분리 Jetson 4회·PC 12 m, executor 교차 Jetson 4회·PC 1회, DDS 방식 Jetson 8회, SHM 반복 6회·IMU 발행 계측 2회, 최소 IMU 수신자 대조 4회를 수행했다. 새 70 m 기록 확보 중 조향 float32 반올림 오류를 찾아 송신 상한 표현을 수정했다. 기록기 조기 종료 감시·명시적 자원 한도를 추가하고, 승인 후 정상 59.53초 입력을 Jetson으로 옮겨 1배속 재생 2회·입력/소스/설치본/회수 해시를 검증했다. 이어 진단 topic/지연 저장 ABBA 4회와 0명령 원인 분석, 배포 의존성 보완을 수행했다. 실행·회수·대기는 GPT-6 Luna 담당. SSH 조회 차이는 기존 키 검증을 유지한 주소 선택으로 대응했고 일반 호스트명도 복구됐다. 마무리에는 A2 최초 목표부터 현재 A3까지의 실패·수정·채택/미채택·미해결·재현 절차를 통합 인수인계 보고서로 정리하고 문서 진입점을 연결했다.
- **결과:** 영상 분리는 218장 판정 일치·PC 12.018 m 정지/종료·제어 시작 간격 최대 약 53→28~36 ms. 각 단계 회귀는 보고서에 보존했다. SHM 16 MiB의 앞선 10회 운영 통과 후 최소 수신자 대조에서는 3/4회 운영 통과했다. 최소 수신자는 두 회 모두 IMU 5,242개 전량, 지역 제어는 83/11개 누락. 대조 단계 PC 47개·Jetson 27개, 조향 수정 회귀 100개 통과. 후속 기록기 관련 회귀 193개와 v3 70.069 m 주행·정지·종료·기록 감사를 통과했다. 59.53초 Jetson 재생 2회도 기능/스케줄/계측/운영/EOF/종료 통과, 비교 구간 안전 0명령 0/2,430개씩. 계측 비교 네 회는 기능/스케줄/계측/EOF/종료 통과, 기존 topic 두 회만 운영 통과했다. PC 90개·구간 분석 4개·배포 목록 2개, Jetson 89개 검사 통과(집합 차이 명시). 잔존 없음, 수신 한도/보호 시간 유지. 인수인계 문서 6개의 상대 링크 198개·앵커 29개, 최신 실행 소스 24개·회수 결과 96개·비공개 입력 7개 해시를 대조했다. 게시 시 기록성 파일의 바이트가 변하지 않도록 기존 원문 보존 속성을 이번 산출물 경로에도 적용했다.
- **한계·후속:** 과거 실패 보존. 최소 수신자 대조 D의 안전 0명령 2개, 긴 기록 v1 조향 오류·v2 시간/6 GiB 한도 실패를 후속 성공으로 취소하지 않았다. 긴 입력 첫 두 회의 IMU 338/293개·초기 RGB 4장 누락도 보존했다. 후속 buffered는 IMU 누락/CPU가 줄었지만 엔코더 순간 지연으로 보호 0명령 2/4개가 발생해 미채택했다. 기존 방식의 기준선과 남은 누락을 기록하고 A3 집중 최적화를 보류, 다음은 A4 제한된 이상치/고착 대응이다. 10월 Claude 협업·구조 변경 시 재비교 계획 반영. 기본 system/legacy·QoS 유지, 무손실/매 주기 마감·열 안정성·실차 검증 미완료. 문서 정리는 로컬 회수 자료만 사용해 꺼 둔 Jetson에 접속하거나 새 시험을 하지 않았다. 요청에 따라 누적 구현·검증 근거와 보고서를 main 반영 대상으로 정리하며 원시 bag/receipt/ready·자격 증명은 제외한다. 실제 게시 상태는 Git 이력으로 확인한다.
