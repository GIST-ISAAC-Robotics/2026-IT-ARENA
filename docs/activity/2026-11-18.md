# 2026-11-18 활동 기록

- **활동** 팀 차량 Fusion v34를 별도 허브에 복제해 홍보용 배선·외관을 모델링했다. 원본 v34와 홍보용 v6·v7을 각 참조 부품 22개가 포함된 F3Z로 내보내 SHA-256과 압축 무결성을 확인했다.
- **결과** M01 CH1~4 전원을 한 쌍으로 합치고 MD20A 단자의 적·흑·적·흑 순서를 확인했다. 카메라 상단 FPC를 Jetson CSI 슬롯으로 연결했다. Jetson·LiDAR 재질, 검정 배터리 R6, MD20A 신호선 곡률, 흰색 휠과 후면 ArUco ID 49를 반영했다. v7에서는 전원·USB·LiDAR 배선 21가닥의 굴곡을 다듬었다. 렌더 추출에 솔리드 2,870개와 표면 792개를 포함해 모터·엔코더 및 서보 어댑터 형상을 복원했다. 야외 서킷의 정차·후면·주행 콘셉트를 2.4:1 화면과 자연광으로 렌더링하고, 최신 CAD 이미지 7장과 공식 610 mm 코스 컷 3장을 함께 게시했다. README 대표 캡션은 IT ARENA · 야외 서킷 콘셉트 샷으로 표기했다. 대표 컷은 카메라를 높인 전면 구도로 바꿨다. 두 시안의 중간 방향에서 들어오는 햇빛의 세기를 약 20% 높였다.
- **한계·후속** 새 FPC와 보강 탭은 CAD 정적 검사에서 기판·프레임 겹침이 없었다. 상부 Y에서 M01·J01 CN1로 들어가는 두 전원 쌍은 공간 제약으로 기존 경로를 유지했다. 기존 배선의 작은 겹침이 남아 있으며 실차 배선 길이와 조립 공차는 미검증이다.
