# 2026-11-18 활동 기록

- **활동** 팀 차량 Fusion v34를 별도 허브에 복제해 홍보용 배선·외관을 모델링했다. 원본 v34와 홍보용 v6·v7을 각 참조 부품 22개가 포함된 F3Z로 내보내 SHA-256과 압축 무결성을 확인했다.
- **결과** M01 CH1~4 전원을 한 쌍으로 합치고 MD20A 단자의 적·흑·적·흑 순서를 확인했다. 카메라 상단 FPC를 Jetson CSI 슬롯으로 연결했다. Jetson·LiDAR 재질, 검정 배터리 R6, MD20A 신호선 곡률, 흰색 휠과 후면 ArUco ID 49를 반영했다. v7에서는 전원·USB·LiDAR 배선 21가닥의 굴곡을 다듬었다. 렌더 추출에 솔리드 2,870개와 표면 792개를 포함해 모터·엔코더 및 서보 어댑터 형상을 복원했다. 야외 서킷의 정차·후면·주행 콘셉트를 2.4:1 화면과 자연광으로 렌더링하고, 최신 CAD 이미지 7장과 공식 610 mm 코스 컷 3장을 함께 게시했다. README 대표 캡션은 IT ARENA · 야외 서킷 콘셉트 샷으로 표기했다. 대표 컷은 카메라를 높인 전면 구도로 바꿨다. 두 시안의 중간 방향에서 들어오는 햇빛의 세기를 약 20% 높였다. README의 CAD 상세 첫 줄에 전면과 후면 대각 이미지를 나란히 배치했다. 홍보용 Blender 장면 3개와 차량 없는 배경, 재질, 재생성 스크립트를 보관했다. 장면을 별도 폴더에서 다시 열어 게시 이미지와 대조했다. r475 벽 코스 10초 단독 주행을 홍보용 모델로 재렌더했다. 당시 LiDAR·발행 경로·모터축 속도·CAD 전륜 목표각을 동기화한 시안을 편집본과 함께 로컬에 보관했다. 별도 35.58초 홍보 영상에는 LiDAR가 기록된 실행 5개에서 단독 출발·코너·결승, 이동차 추월, 정지차 우회, 두 앞차 전경 1.75초와 마커 20·30 인식을 편집했다. 1080p 24 fps 영상 854프레임의 센서·바퀴 상태를 대조하고, 34.86초에 노면 체크선을 통과하는 것을 확인했다. 영상·재렌더링 입력·검증 결과를 로컬 CAD 보관 폴더의 `rendering/feature-showcase`에 보관했다. 후속 편집은 마커 확대 컷을 P22·P21 본선 통과로 바꾸고 연속 곡선 단독 주행을 추가했다. 갈림길의 지주는 검증한 원래 위치에 고정하고 표지판 외형을 가로대에 붙였다. 수정본 43.13초의 1,035프레임에서 센서 기록을 확인했다. 이전 편집본은 같은 보관 폴더의 별도 버전으로 남겼다. 46초 최종 영상에는 휠·배선·전원 보드 클로즈업, 적색·녹색 신호와 단독 출발, 낮은 대각 구도의 체크선 통과를 넣었다. 결승 뒤 차체를 반속으로 보여주고 화면과 센서 뷰를 함께 페이드아웃했다. 1,104프레임의 실제 센서 기록과 43.40초 결승선 통과, 검은 종료 프레임을 검사했다. 추월 컷을 2초 앞당겨 본선 중앙에서 왼쪽으로 빠져 앞서 나간 뒤 중앙으로 복귀하는 전 과정을 한 카메라로 담았다. 차량을 가린 출발 신호 구조물은 해당 컷의 렌더에서 숨겼다. 48초 영상의 1,152프레임에 해당 시점의 LiDAR 기록을 확인했다. 도입은 후면 대각과 항공 구도를 각각 2.125초간 천천히 당긴 뒤 신호등으로 연결했다. 결승은 낮은 대각에서 체크선을 통과하는 모습과 차량 전체를 담았다. 49.5초 편집본의 1,188프레임과 마지막 페이드아웃을 확인했다. 54초 편집본은 휠 높이의 이동 컷, 센서와 상판, 출발 그리드 전경으로 도입부를 다시 구성했다. 옛 코스의 연속 굴곡을 따라가는 4.5초를 더했고, 결승선 통과 직후부터 마지막 페이드아웃까지 한 카메라 움직임으로 이었다. 1,296프레임의 센서 기록을 확인했다. 54초 원본의 1,296프레임을 다시 디코딩했고, 49.5초 이후와 결승을 포함한 9개 지점에서 탐색 재생을 확인한 별도 H.264 MP4를 만들었다. 공개본은 녹색등 뒤 센서 패널을 페이드인하고 결승 카메라 전환 전에 페이드아웃하도록 편집했다. 패널을 숨긴 컷의 좌우 구도를 중앙에 맞췄다. 54초 MP4를 GitHub 릴리스에 올리고 main README 첫 화면에 썸네일과 링크를 배치했다. 후속 공개본은 첫 컷의 차체를 중앙으로 옮기고 좌측 워드마크에 크림슨을 넣었다. README는 서킷 콘셉트 사진 다음에 영상이 나오도록 정렬했다. 기록된 주행 속도에 연동한 합성 모터음과 출발·결승 효과음을 로컬 MP4 시안에 붙여 영상·음성 길이와 디코딩을 확인했다. 최종 공개본은 좌측 워드마크의 끝 점만 빨간색인 기존 디자인으로 돌렸고, 무음 54초 파일과 썸네일을 갱신했다.
