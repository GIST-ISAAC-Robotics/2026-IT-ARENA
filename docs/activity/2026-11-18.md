# 2026-11-18 활동 기록

- **활동** 팀 차량 Fusion v34를 별도 허브에 복제해 홍보용 배선·외관을 모델링했다. 원본 v34와 홍보용 v6를 각 참조 부품 22개가 포함된 F3Z로 내보내 SHA-256과 압축 무결성을 확인했다.
- **결과** M01 CH1~4 전원을 한 쌍으로 합치고 MD20A 단자의 적·흑·적·흑 순서를 확인했다. 카메라 상단 FPC를 Jetson CSI 슬롯으로 연결했다. Jetson·LiDAR 재질, 검정 배터리 R6, MD20A 신호선 곡률, 흰색 휠과 후면 ArUco ID 49를 반영했다. CAD 이미지 7장과 공식 610 mm 코스의 정차·후면·코너 주행 콘셉트 렌더 3장을 README에 연결했다.
- **한계·후속** 새 FPC와 보강 탭은 CAD 정적 검사에서 기판·프레임 겹침이 없었다. 하부의 기존 배선에는 작은 겹침이 남으며 실차의 배선 길이와 조립 공차는 미검증이다.
