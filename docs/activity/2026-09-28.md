## 후방 마커 선택·등록·모델 반영

- **활동:** 별도 세션에서 공식 생성기/규정과 ID 중복을 확인해 `DICT_4X4_50` ID 49를 생성하고, 사용자 승인으로 ISAAC (GIST) 등록 댓글을 게시했다. 이후 요청에 따라 차량 임시 ID 10도 ID 49로 바꾸고 후방 사진을 촬영했다.
- **결과:** 생성기 재검출·36칸 정렬과 게시 본문/이미지 확인 완료. PNG·50 mm SVG를 보존하고 모델은 판 50 mm·코드 34.8 mm로 맞췄다. 마커 회귀 2개와 정면/사선 사진 모두 ID 49 검출을 확인했으며 질량·충돌체는 유지했다.
- **한계·후속:** 실물 시험은 미실시다. 촬영 성공과 별개로 브리지 종료 지연·Gazebo 종료 오류가 발생해 로그를 보존했다. 잔존 프로세스는 없고 원인 분석은 후속이다. 오늘은 활동 정리까지 마쳤으며 다음 우선순위는 Jetson 시험이다.

## Jetson 기준 재생 시험

- **활동:** 초기 승인 장애가 해소된 뒤 접속 정보를 Git 밖에 암호화 저장하고, 사용자 승인으로 기존 JetPack을 유지한 채 Humble 시험 환경을 설치했다. GPT-6 Luna에 실행·대기를 맡겼으며, 원본을 보존하는 Jazzy MCAP/Humble 읽기 호환 처리를 추가했다.
- **결과:** ARM64 두 패키지 빌드·선택 회귀 94개 통과(자료 의존 2개 제외), 원시 기록 해시/CDR 감사 통과. 0.5배속 1회·1배속 2회에서 기능·스케줄·EOF 0명령·정상 종료를 확인하고 자원 기록과 소스/결과를 회수했다. 주행 비교 구간 정지 명령은 0/500개였다.
- **한계·후속:** 1배속 지역 IMU 약 4%·RGB 3장씩과 별도 진단 로그 누락이 남았다. 추가 수집 개선 검증은 승인 502 재발로 전송 전 중단하고 미검증 변경을 기본 코드에 남기지 않았다. 진단 수집·입력 처리 개선과 장시간 시험이 후속이다. 실차 시험·GitHub 게시·전원 종료는 하지 않았다.

## Jetson 후속 개선 착수

- **활동:** 승인 경로가 복구된 뒤 진단 수집과 센서 발행을 분리하고, 수신 일련번호 완전성 검사와 양방향 준비 확인을 추가했다. 영상 처리의 스레드 수와 신호 색상 연산 비용도 비교했다.
- **결과:** 동일 프로세스 수집 스레드는 실제 재생에서 실패해 폐기했고, 별도 프로세스 수집기는 1배속 두 회의 기능·스케줄·진단 수집·정상 종료를 통과했다. IMU 누락 위치를 특정할 수 있게 됐고 영상 콜백 시간대와의 상관을 확인했다.
- **한계·후속:** 제어기 입력 누락은 여전히 남았다. OpenCV 1스레드 축소는 더 느려 채택하지 않았다. 신호 영상 최적화는 출력 비교 도구의 자료형 불일치를 수정하며 다음 날 검증을 이어갔다. 실패 원자료와 이전 결과는 보존했다.
