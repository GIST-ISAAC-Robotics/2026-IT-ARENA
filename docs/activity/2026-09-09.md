# 2026-09-09 전체 저장소 반영

- 사용자는 보고서만이 아니라 전체 작업 내용을 GitHub main에 반영하도록 범위를 명확히 했다.
  이전 보고서 한정 게시 기록은 당시 이력으로 보존하며, 누적 소스·시험·활동·결정 문서·센서
  예산 자료·생성 결과·영상과 실패 기록을 이번 게시 범위에 포함한다.
- 미추적 파일 검사에서 문서 생성용 node_modules 설치 의존성이 발견돼 .gitignore에 추가했다.
  로컬 파일은 삭제하지 않는다. 기존 build/install/log, Python 캐시, 반복 실행용 artifacts/tests와
  Gazebo 캐시는 기존 제외 정책을 유지한다. 고정 검증 자료인 artifacts/validation은 포함한다.
- 보고서와 프로젝트 현황의 '일부만 게시' 설명을 후속 전체 반영 범위에 맞췄다.
  새로운 주행 실험이나 알고리즘 변경 없이 게시 전 상태·용량·민감정보 패턴·형식을 확인한다.
- 게시 전 WSL에서 Python/ROS 전체 회귀 검사를 재실행해 208개 통과(12.71초)를 확인했다.
  일반 비밀키 패턴 검사에서 검출 없음, diff 형식 검사 통과, 원격 main과 분기 없음도 확인했다.
  이 검사는 실차 검증이나 이전 공식 주행의 실패 판정을 변경하지 않는다.
- README에 최신 보고서·보정·영상 색인을 연결하고, GPU 효과가 부하별로 달랐다는 후속 결과를 반영했다.
- 전체 새 파일을 포함한 형식 검사에서는 저장 웹 원문·로그의 후행 공백과 과거 활동 문서의
  마지막 빈 줄 경고가 나왔다. 앞의 통과는 기존 변경 파일 검사이며 전체 새 기록의 무경고를
  뜻하지 않는다. 소스 코드에는 경고가 없고, 기록성 원문은 불필요한 재포맷 없이 보존한다.
- 최신 구현과 검증의 자세한 내용은 [9월 8일 활동](2026-09-08.md)과
  [프로젝트 현황](../PROJECT_CONTEXT.md)을 확인한다. 이전 실패를 재시험 성공으로 변경하지 않는다.
