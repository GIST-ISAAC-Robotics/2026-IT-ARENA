# 2026-09-21 활동 기록

## 지역 경로 생성 + Pure Pursuit 선택과 센서 전제 갱신

- 사용자 결정에 따라 지역 경로 생성 + Pure Pursuit부터 개발하고, 다른 제어기·지도 기반 주행은 여유가 있을 때 검토하도록 [ADR 0021](../decisions/0021-local-path-pure-pursuit.md), [알고리즘 노트](../autonomy/ALGORITHM_OPTIONS.md)와 프로젝트 현황을 갱신했다. 기존 단계 번호는 필수 구현 순서가 아니라 과거 후보 구분임을 명시했다.
- Pure Pursuit 자체에 전역 위치 추정이 필수라는 앞선 설명을 정정했다. 차량 기준 지역 경로에는 상대 목표점이 필요하며, 기존 엔코더·자이로 운동 보정의 이동량·회전량과 지도상의 자기 위치 추정을 구분했다.
- 일반 RGB+C1은 거의 확정, ToF는 아마 미사용, 엔코더는 있으나 구체 사양 미정, IMU는 후보가 있는 6축 검토안이라는 사용자 설명을 기록했다. B0183 견적 이력은 보존하고 새 모델 선정이나 구매 완료를 선언하지 않았다.
- 낮은 LiDAR 설치·후방 일부 가림·전방 얇은 기둥 가능성을 미확정 배치 조건으로 기록했다. 자기 반사 제거와 가림 뒤 미관측을 구분하고, ToF 없는 신규 감속·정지층의 구현·검증 필요를 명시했다. 기존 ToF 안전층·모델·검증 결과는 보존했다.
- 사용자 요청에 따라 주차별 일정이나 6주 우선순위는 작성하지 않았다. 문서 갱신만 수행했으며 실행 코드·트랙·차량·센서 장착 변경, 새 시뮬레이션·실차 시험, 외부 게시를 하지 않았다.
