## 새 관찰과 보류

- 공식 벽 부착 마커는 정면 진단 카메라에서는 모두 검출됐지만 차량 전방 카메라의 정지 표본에서는 접근각에 따라 검출 구간이 짧았다. 기본 표본은 12개 중 6개, 촘촘한 표본은 37개 중 9개가 해당 ID를 검출했다. 저속 한 바퀴에서는 네 ID 모두 검출됐으므로 “사용 불가”가 아니라 고속·가림·실물에서 확인할 위험으로 기록했다.
- 위 관찰은 게시하지 않았다. 운영진 확인 요청 형식의 초안만 갱신했으며, 실제 D435i·인쇄 마커·속도/각도 시험 후 사용자의 별도 승인을 받아야 게시할 수 있다.
- ROS OpenCV 4.6의 ArUco API 차이, ZIP에 포함된 `.pyc`, 장시간 검사 중 발생한 bridge 종료 오류와 Gazebo 종료 지연은 내부 환경·포장 관찰로 남겼다. 독립 실행이 정상 종료했으므로 공식 트랙 오류로 단정하지 않았다.
