# 2026-09-07 활동 기록

- **활동:** Windows/WSL 장치와 Gazebo 렌더러를 조사하고 선택형 D3D12/NVIDIA 실행 경로를 추가했다. 같은 조건에서 CPU/GPU를 비교하고 종료 문제를 진단했다.
- **결과:** GPU 인식과 실제 렌더러 사용을 구분해 확인했으며 실행 옵션·복구 방법과 비교 근거를 남겼다. 드라이버/OS·전역 셸 설정은 변경하지 않았다.
- **한계·후속:** 처리량 이득은 부하에 따라 다르고 간헐적 GPU 종료 실패가 남아 기본 `system`을 유지했다. 정상 종료 한 번으로 문제 해결을 확정하지 않는다.
