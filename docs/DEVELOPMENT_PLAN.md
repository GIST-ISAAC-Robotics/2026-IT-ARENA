# 현행 개발 계획: 빠른 완주와 주행 지속성

갱신: **2026-11-03**. [11/1 중간 점검](reports/MIDPROJECT_REVIEW_2026_11_01.md)과 [최종 회의·공식 배포 검토](reports/OFFICIAL_UPDATE_2026_11_02.md)를 함께 반영한다. **직접적인 충돌 위험이 없으면 급정거나 큰 폭의 감속을 줄이고 속도를 꾸준히 유지한다.** 단독 속도와 다중 차량 대응은 계속 핵심이며 새 운영 화면 때문에 뒤로 밀지 않는다. 사용자 결정은 [ADR 0028](decisions/0028-speed-continuity-and-final-gearing.md), 적용 상태는 [현재 현황](PROJECT_CONTEXT.md), 정리 전 계획은 [보관본](archive/2026-11-02-plan/DEVELOPMENT_PLAN.before.md)에 있다.

**직선 차체 최고속도 2 m/s급은 제한 시뮬에서 확인했고 다음 목표는 10 km/h(2.78 m/s)다.** 모든 코너의 목표속도가 아니다. 단발 최고속도보다 랩 시간·불필요 정지·앞차가 움직일 때의 진행을 함께 본다. 드문 오류 조합 전수 검증이나 보호 조건의 누적을 완주의 선행 조건으로 만들지 않는다. 실제 앞길 점유·명시 STOP·지속 입력 고장은 지키되, 개별 감속/정지 조건은 경기 손실과 관측 근거에 따라 단순화·개선한다.

## 기능 완성도에 따른 작업 전환과 보강

**사용자 정정(11/2): 각 필수 기능을 대회 주행에 쓸 수 있는 수준까지 구현·확인한 뒤 다음 기능으로 넘어간다. 전체 필수 기능이 그 수준을 갖추면 다시 돌아와 속도·성능·대응 범위를 높인다.** 목적은 전체 완성도의 균형이다. 초안의 고정 시간·A→B→C/D 교대·연속 작업 횟수 기준은 이 의도를 잘못 해석한 것이므로 폐기한다.

- 작업 시작 때 **이번 기능이 대회에서 해야 할 동작과 필요한 완성 수준**을 정한다. 구현·연결·대표 주행에서 그 동작을 확인하는 것이 기준이다. 원인만 찾았거나 합성 시험 하나가 끝났다고 기능이 완성된 것은 아니다.
- 대표 상황에서 완주·진행·재개를 막는 결함이 남으면 필요한 수정을 계속한다. 시간을 많이 썼다는 이유로 미완성을 완료 처리하거나 다른 기능으로 돌리지 않는다. 같은 분야에서 여러 묶음을 이어가는 것도 필요하면 자연스러운 진행이다.
- 필요한 동작이 성립하고 남은 문제가 드문 예외·미세 성능·확장 기능이라면, **아직 대회에 쓸 수준이 안 된 다른 필수 기능을 우선**한다. 다음 기능은 경기 영향·의존관계·현재 완성도·남은 일정으로 고르며 분야별 고정 순서는 두지 않는다.
- 필수 기능들이 어느 정도 완성되면 전체 구성의 주행을 확인하고, 다시 속도 유지·랩 시간·교통 대응 등 경기 손실이 큰 부분부터 보강한다. 단독 최고속도만 계속 올리면서 기본 추종이나 재개 기능이 비어 있게 두지 않는다.
- 실제 부품·자료가 없어 해결할 수 없는 항목은 **미완성/외부 의존**으로 남기고 가능한 다른 필수 작업을 진행한다. 임시 대응을 채택하면 그 운용 범위와 한계를 밝힌다. 의존성이 해소되면 우선순위를 다시 판단한다.
- 실패한 시험을 원인 변화 없이 반복하거나, 기능이 갖춰진 뒤 새 반례를 끝없이 추가하지 않는다. 더 조사할 가치가 있는지는 줄일 수 있는 경기 손실로 판단한다. 미성립 장면은 미검증으로 남기며 보강 항목에는 실패·현재 가설·재개 조건을 기록한다.

이 기준은 기능을 대충 만들고 넘기라는 뜻도, 모든 상황을 보장해야 넘어간다는 뜻도 아니다. 필요한 완성 수준은 해당 기능의 역할에 맞춰 판단한다. 통과만을 위해 보호 조건·물성·판정선을 낮추지 않으며, 과거 실험 수치를 영구 금지선으로 고집하지도 않는다.

### 직접 시험할 최소 장면

- **단독:** 긴 직선 가속→급커브→마커 기준 벽 전환을 포함한 한 랩. 최고·1초 평균 최고·유지 시간/거리와 랩 시간을 따로 기록한다.
- **전방:** 느린 차 추종→급정지→재출발, 다른 차 끼어들기. 별도로 우회 중 상대 재출발 후 뒤 합류. 상대 위치 정답은 제어 입력으로 쓰지 않는다.
- **측방·가림:** 좁은 코너 피추월/복귀, 오른쪽 재접근 또는 갈림길 ID30+벽 가림 중 하나. 두 바퀴 잔디를 활용한다. 고정 150/97 mm 비교선을 실물 최소 간격으로 강제하지 않는다.
- **운영:** 최초 시각 출발·앞차 신호 가림과 제자리 `STOP→START`를 구별한다. START는 현재 입력/경로와 MCU 재ARM을 확인한다. RESET은 정지를 유지하며 상태만 먼저 초기화할 때 쓴다. 일반 명시 STOP 뒤에는 재배치해도 START가 새 입력을 확인하므로 별도 RESET 버튼은 필수가 아니다. 같은 경기 출발 사실은 보존한다. 준비 중 새 STOP·연결 상실 취소와 늦은 이전 입력 제외를 유지한다. 일반 시험은 자동 HTTP/CLI로 수행하고 화면 기능을 확인할 때만 브라우저를 연다.
- **표적:** 박스 외형만으로 완료하지 않는다. 비스듬한 차·개방형 또는 돌출 윤곽의 대표 하나를 교통 묶음에 포함하되 모든 차체를 전수 탐색하지 않는다.
