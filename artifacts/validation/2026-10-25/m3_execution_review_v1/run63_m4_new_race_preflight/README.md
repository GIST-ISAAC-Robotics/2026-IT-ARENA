# M4 새 경기 시험 사전 검사

[M4 새 경기 시험](../M4_NEW_RACE_PLAN.md)의 명시 옵션과 상태 전이를 구현하고 143회귀를 통과했다. 같은 경기 run61 입력을 재평가한 결과도 그대로 유지됐다. 이후 GPT 최종 검토에서 새 경기 명령 응답이 저빈도 상태 메시지보다 먼저 도착할 경우를 보완했다. 이 폴더의 `source_before_review.zip`은 그 보완 전 소스와 출처 계약을 보존한다.

다음 v2는 허가 전이가 아니라 **옛 상태를 기다리는 처리**를 추가한다. 새 세대 상태가 실제로 도착하기 전에는 후속 MCU STOP 순서로 넘어가지 않으며, MCU 고장/새 개입/기한은 그대로 검사한다. 사용자 정리 요청에 따라 현재 묶음 이후 새 작업은 시작하지 않는다.
