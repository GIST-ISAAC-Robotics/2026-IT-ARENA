# run25 — 작은 중앙 보정과 현재 방향 직진의 선택 비교 (저장 입력, 개루프)

Claude Opus 5.5가 분석·구현했다. Gazebo/ROS 주행은 없다. 센서·속도·장면은 원래 주행 그대로이며, 후보 출력대로 차량이 움직인 결과가 아니다.

## 출발 상태

`start_state/`에 09:01 KST 착수 시점의 Git HEAD(`4096314`), 변경·미추적 파일 86개와 코드 트리 700개 해시, 수정 전 원본 소스(`source_before/`)를 보존했다. 현재 `m3_execution_trial.py` 등은 run17/19/21/24 실행 사본과 같은 바이트(`4e1395c7…`)에서 출발했다.

## run19 원인 분해 (기록 출력 그대로)

위협 소멸(12.62 s) 뒤 측방 시험은 0.35 m/s 상한으로 남았다. 중앙 후보가 d0 약 0.4 mm에서 0이 아닌 미세 조향(0.0001–0.0013 rad)을 냈고, 다음 판단에서는 그 이전각 원호가 후방 마스크 꼬리 띠 질의 때문에 미지지가 되어 직진을 포함한 전 후보가 거절됐다(13.22·17.02·17.04 s, 18.52 s는 0.0189 rad 유지 후보 뒤). 17.02 s의 두 원호각은 −5.95e−5/+5.27e−5 rad였다. 거절 뒤에는 HOLD·역방향 펄스·두 fresh 재개 대기가 이어졌다. 시험 상한 0.35 m/s가 앞차 속도와 같아 손실한 거리를 회복할 수 없다. 이 연결은 판단 기록에서 확인한 사실이며, 최종 간격 1.255 m의 정량 원인 분배는 아니다.

## 비교 변형 (`compare_small_center.py`)

| 변형 | 내용 |
|---|---|
| `recorded_off/on` | 기록된 이전 조향 입력. OFF는 원래 출력과 전체 동일해야 한다 |
| `self_off/on` | 이전 조향만 이 제어기의 직전 출력으로 바꾼 반사실(노드 `last_steering`과 같은 연결) |
| `self_naive` | 반례 대조. 현재 후륜축 횡오차만 22 mm 이내면 직진을 먼저 둔다(방향·곡률·예측 편차 무시) |

- 기록 OFF는 run19 791/791·run17 648/648·run21 649/649·run24 1,790/1,790 원래 출력과 같다. 입력 4개 해시 불변.
- 모든 기록·변형에서 복귀 관문(`release_gate`)과 측방 위협 출력의 ON/OFF 차이는 0이다. 위협 기억·가능 영역 판정은 바뀌지 않았다.
- run19 self_on의 직진 우선 220판단은 |d0| ≤ 0.53 mm, 예측 편차 ≤ 1.47 mm, |psi| ≤ 1.45 mrad였다. 남은 18.52 s 거절은 기준 경로가 곡선 판정(`curved`)이어서 직진 우선이 적용되지 않은 구간(18.42–18.50 s, d0 6.6 mm·psi 5.7–10.4 mrad)이다.
- run17/run21의 중앙 단계 35/40판단은 약 90 mm 복귀가 필요해 직진 우선이 한 번도 적용되지 않았다.
- `recorded_on`은 거절 횟수가 OFF와 같다. 기록된 이전 조향이 여전히 0이 아니기 때문이며, 개선의 근거는 자기 조향 반사실뿐이다.
- `self_naive`는 이 기록에서 더 많이 진행하지만 곡선 판정·방향 오차 16 mrad에서도 직진을 고른다. 합성 반례(방향 0.03 rad, 반경 1.2/4 m 곡선)에서 같은 deadband는 통과하고 본 후보는 거절한다. 채택하지 않는다.
- run21 self_off는 복귀 뒤 기본 G1 5판단(7.22–7.30 s)에서 기록과 달랐다. 노드의 이전 조향 입력이 제어기 직전 출력과 다른 구간이며 옵션 적용 구간이 아니다.

## 실행 기록과 한계

`compare.sh`가 실행했고 종료 코드 0이다. 실행 중 `tests/test_m3_small_center_straight.py`를 보강해 전후 해시 목록에서 그 파일 하나만 바뀌었다(`replay_sha256_before/after.txt`). 비교 스크립트·제어 모듈·입력 기록은 불변이다. 디버그 스크립트(`dbg_*.py`)는 시험 구성 확인에 쓴 보조 도구다.

이 결과는 고정 센서 입력의 반사실이다. 정지 반복이 실제 주행에서 줄어드는지, 최종 간격이 바뀌는지는 폐루프로만 판단한다.
