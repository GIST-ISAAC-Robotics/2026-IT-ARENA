# 같은 측면 위협 기록 진단 v1

실행 exit 0·소스 불변, 해제 0회다. 그러나 `history(end=8)`이 보관 5초를 넘겨 초기 시각 이력을 버렸으므로 처음 20개 기록 갱신의 `motion_unavailable`를 객체 연관 실패의 근거로 쓰지 않는다. 두 번째 상자도 벽 근처 반환과 분리되지 않아 `present`가 기대대로 켜지지 않았다. 시험 입력의 한계이며 제어기의 잘못된 해제를 재현하지 못했다.

원본 `probe_same_side_replacement.py`와 result/stdout/stderr를 유지한다. v2는 현재 시각까지의 이력과 `poses` 성공을 검사하고 벽에서 분리된 두 상자·각각 단독 조건을 대조한다. v1 성공으로 소급하지 않는다.
