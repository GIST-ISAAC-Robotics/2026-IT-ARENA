# 같은 측면 재관측의 기록 소실 재현

현재 시각을 포함하는 운동 이력을 매 단계 구성하고 `poses([t−0.2,t], t)` 성공을 확인했다. 세 조건 모두 `motion_unavailable` 0회, Python exit 0·stderr 없음·소스 SHA-256 불변이다. 결과는 스캔마다 정적 광선을 만든 합성 상태 검사이며 동역학/회전 취득·접촉 시험이 아니다.

| 조건 | 해제 | 해석 |
|---|---|---|
| A 단독 | 없음 | 후방에 남은 A는 새 관측 없이 해제되지 않음 |
| B 단독 | 4.7 s | B가 전진한 뒤 관문 해제 |
| A+B | 4.7 s | A가 숨은 상태에서도 B 단독과 같은 해제 |

A는 x=0.30 m에서 상대속도 −0.4 m/s로 이동해 −0.65 m에 정지한다. B는 다른 횡위치에서 +0.30 m까지 접근했다가 +0.4 m/s로 전진한다. 두 몸체는 0.20×0.10 m이며 횡면 사이 0.06 m로 겹치지 않는다. 반환 정답 식별은 결과 설명에만 사용했고 제어기에는 센서 광선만 전달했다.

A+B에서 3.2–3.8 s에는 A 반환 0·이전 관문 거절 상태인데 B의 새 반환으로 위협 기록을 교체한다. 4.6 s 관문 확인 후 4.7 s에 해제되어,A 단독에서 유지되던 미확인 가능 영역을 잃는다. **기록 덮어쓰기 결함을 재현했으나 실제 충돌을 재현한 것은 아니다.** 10/25 오전 재관측 진단의 한 반례 통과만으로 일반 객체 연관을 검증할 수 없었다는 후속 근거다.

`result.json`과 `probe_source.py`가 원본이다. 수정 전에 `source_sha256`에 해당하는 소스는 run34/run35 보관본과 같다. 이후 수정 결과는 별도 폴더에 남긴다.
