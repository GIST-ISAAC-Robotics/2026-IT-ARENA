# M2 감속 시험에 기존 C1 오차·지연 주입 연결

run55의 첫 0.50 m/s 앞차 급정지 조건을 기준으로, 기존 `config/tests/lidar_uniform30_delay50_jitter20.json` 한 조건을 추가한다. 균등 ±0.03 m 거리 오차, 추가 발행 지연 0.05±0.02 s, seed 23이다. 제조사 실제 오차 분포·실측 통신 지연이라고 하지 않는다. 회전 순차 취득 시각과 원시 무응답/가림은 그대로이며 제어기와 독립 보호층이 모두 같은 오차가 들어간 `/scan`을 받는다.

기존 시험기는 `--lidar-test-profile`을 G1 모드에만 허용한다. M3도 같은 G1 실행 경로·취득기·무결성/재생 경계를 사용하므로 명시 모드와 판단 기록을 요구한 채 이 시험 옵션을 연결한다. R0/R0+에는 확대하지 않는다. 주행 알고리즘·기본값·물성·간격/노면/STOP 판정은 바꾸지 않는다. 수정 전후 평가기 소스와 변경 근거를 보존한다.

run56은 옵션 수용/거절과 기존 주입 무결성·source 계약 회귀다. run55 결과를 검토하고 run56을 통과하면 run57 한 번을 실행한다. 원본 주행 기준 외에 실제 오차/지연이 지정 조건으로 주입되었고 제어기·보호층에 도달했는지 기존 감사를 요구한다. 실패 시 최초 실패 판단을 저장 입력으로 분석하며 기본값 변경이나 성공할 때까지 반복하지 않는다.

주입 전후의 실제 정지 전 자차 속도와 간격·정지/재개 지연을 함께 본다. 결과가 달라도 센서열이 달라지는 폐루프이므로 같은 입력의 인과 대조로 부르지 않는다. 하나의 합성 조건은 실차·모든 오차·실시간 마감·M3 측방 복귀 또는 전체 랩 증명이 아니다.
