# 예약 적용 고정 노면 대조 — 사전 등록

- 목적: 1 ms·동일 예약 출력에서 분할 노면과 단일 평면의 제동/접촉 차이를 분리한다. 10/11 적용 반복 시험을 다시 늘리는 작업이 아니다.
- 새 실행은 `s1_official` → `f1_flat` 각 1회다. 입력·종료 실패나 잔존 프로세스가 있으면 다음 실행을 중단하며 자동 재시도하지 않는다. 추가 실행이 필요하면 실패를 보존하고 별도 이유/계획을 등록한다.
- 실행 구현은 `config/tests/scheduled_command_r7_sha256.json`과 10/11 등록 소스/플러그인 그대로다. 기본 모델 변경·빌드·Jetson·전원 설정 변경은 없다.
- 공통: `passive_damping`, `sim_grid`, 위상 10 ms, `embedded_paused`, GC `defer`, 예약 적용 20 ms, 물리 step 1 ms. 요청은 10/8 `braking_ab_v1/command_profile.json`이다. 정상 `/drive`·독립 보호·MCU·AppliedGuard를 모두 통과한다.
- 유일한 조작: 기존 시험기의 `--surface flat`. 도로/잔디/바닥 collision을 제거하고 상면 z=0.003 m인 40×40×0.1 m 판을 넣는다. 벽·시각 메시·차량/센서·마찰/토크 값은 바꾸지 않는다. 공식 원본/기본 실행 월드를 덮어쓰지 않는다.

## 비교 관문

1. 각 실행의 원시 해시·소스 사본·r7 계약·바이너리·구독 그래프·단일 모터축·요청 격자·수신/적용 ACK·STOP·실제 정지·정상 종료·잔존 0을 기존 분석기로 재검사한다.
2. 차량/메시/입력/출처·최초 물리 step·명령 시작 시각이 같아야 한다. 시작부터 프로필 종료+0.2초까지 정상 적용의 순번·원래 시각·예정/실제 step·속도·조향 전체가 같아야 한다. 끝의 비동기 STOP은 별도 검사한다.
3. 노면을 제외한 월드가 같고, 평면의 위치/크기/정적 속성·별도 물성 미지정이 시험기 정의와 같아야 한다. 다른 변경이 섞이면 노면 효과를 주장하지 않는다.
4. 기존 주 제동 지표 7개와 허용치(속도 max(0.05 m/s,10%), 거리 max(0.01 m,20%), 시간 max(0.05 s,20%))는 유지한다. 허용치 이내가 실차 안전 합격을 뜻하지 않는다.
5. 실제 예약 ACK의 마지막 양수 후 첫 0 적용 시점을 기준으로 제동 창(시작+1.75~2.85초)의 전/후를 분리한다. 평균 바퀴–차체 차이·좌우 차이·정지 변위/시간과 네 바퀴 접촉 상대물/하중·기록 공백을 대조한다. 접촉 미수신을 0하중/공중 상태로 보간하지 않는다.

## 해석 경계

두 노면 모두 불일치가 남으면 분할 경계를 유일 원인으로 지목하지 않는다. 노면 변경은 접촉 형상과 초기 지지 평형을 함께 바꾸므로 차이가 나도 개별 이음매의 원인을 확정하지 않는다. 한 쌍은 통계적 안정성/step 수렴/전체 G1 검증이 아니다. 수동 제동 근사는 실물 MD20A 회로가 아니며 기본 채택하지 않는다. 기존 실패·오른쪽 미실행·G2/고속 보류를 유지한다.
