# 저속 G1 초기 가림·첫 코너 제한 시험

2026-10-07. 기존 G1 제어기·독립 보호층·차량 물성을 그대로 두고 시험 범위만 확장한다. 기술적 결론은 [G1-b 기준 보고서](../../../../docs/autonomy/LOCAL_FOLLOW_G1B_2026_10_07.md)에 모은다.

## 실행 전에 고정한 조건

- 설정: `config/tests/g1_traffic_extensions_v1.json`. 원래 직선 3사례 설정은 보존한다.
- `initial_occlusion`: 앞차 중심 간격 0.55 m(차체 간격 약 0.35 m), 처음 3초 정지 후 0.35 m/s 출발. 초기 연속 HOLD 1초, 앞차 출발 뒤 2.5초 안 재출발, 이후 1 m 이상 진행을 요구한다. 가까운 중앙 앞차의 부분 가림 사례이지 양쪽 벽·신호가 완전히 가려진 출발 상황은 아니다.
- `first_curve`: 0.35 m/s 앞차를 35초 동안 추종한다. 자차가 코스 진행좌표 `s=9.8 m`를 지나고 시작 대비 150° 이상 방향을 바꿔야 한다. 앞차 최종 범위는 `s≤12.1 m`, 실제 차체의 도로/벽 중첩을 1 cm 간격으로 사전 검사한다. 이 진행좌표와 정답은 평가기만 사용한다.
- 두 사례 모두 최대 명령 1 m/s, 순차 C1 10 Hz·운동 보정, 단일 모터축 28카운트·15:1·65 mm, 가상 MCU, 독립 보호층을 유지한다. 기존 최소 차체 간격 0.15 m·노면 이탈 0·접촉 0·실제 STOP·정상 종료 판정선을 유지한다.
- 앞차는 정적 모델을 `set_pose`로 옮기는 시험용 상자다. 상대차 구동·접촉 물리, 가려지는 모든 차량 높이, 전체 코스, 고속, 실물 안전을 검증하는 것이 아니다.
- 바퀴 접촉·구동 진단을 추가 수집한다. 첫 실행의 큰 바퀴/차체 속도 차이(조사용 기준 0.35 m/s 이상) 또는 접촉/정지 실패가 나오면 코너 실행 전에 원인을 확인한다. 기존 합격선을 바꾸는 조건이 아니다.

## 재현

WSL Ubuntu-24.04에서 저장소 루트를 작업 디렉터리로 한다. 실행 스크립트는 ROS Jazzy/작업공간과 소스 `PYTHONPATH`를 설정하며, 기존 결과를 덮어쓰지 않는다.

```bash
bash artifacts/validation/2026-10-07/g1b_extensions_v1/run_checks.sh
bash artifacts/validation/2026-10-07/g1b_extensions_v1/run_case.sh initial_occlusion
bash artifacts/validation/2026-10-07/g1b_extensions_v1/run_case.sh first_curve
```

소스 ZIP에 실행 설정을 함께 보존한다. 센서·상태·접촉 원시 로그는 기존 Git 제외 정책을 적용한다. 사전 회귀는 `pytest_preflight.log`의 140개 통과이며, 실행/사후 검사 결과와 별개다. 실행 중인 시험이나 미확정 결과는 통과로 기록하지 않는다.

## 마감 결과와 산출물

두 실행 모두 `run_valid=true`, `passed=true`, STOP·정상 종료 통과이며 시험 잔존 프로세스는 없다. 마감 `run_final_checks.sh` 결과는 `pytest_final.log`의 **583개 통과(57.33초)**다. 제어기를 변경하지 않고 실행기·평가/회귀만 확장했다.

- [summary.json](summary.json): 원래 실행 판정을 모은 결과. 초기 가림 최소 간격 0.349760 m, HOLD 2.627초·재출발 0.874초·2.140 m 진행. 첫 코너 최소 간격 0.581390 m·12.998 m 진행·방향 변화 180.52°.
- `initial_occlusion_s0/`, `first_curve_s0/`: 보고서·실행 소스 ZIP·실행 모델/월드. 원시 센서/자세/접촉/MCU는 로컬·Git 제외한다.
- `*_postcoverage.json`: 상태 원문·정지 차체 위치·경계 시각 대조. 두 감사 통과.
- `*_source_audit.json`: 실행 소스 44파일·설정·ZIP·원시 해시·제어 입력 경계 대조. 두 감사 통과. 감사용 `source_freeze.json`은 첫 실행 중에 고정한 기준이며 실제 실행 시작 사본은 각 소스 ZIP이다.
- `*_encoder.json`: 두 실행의 모터축 단일 28카운트·15:1·65 mm와 제어 구독·MCU 상태 대조. 두 감사 통과.
- [diagnostics_summary.json](diagnostics_summary.json), 생성기 [analyze.py](analyze.py): 전체 구간 바퀴/차체 차이 최대 0.102/0.290 m/s와 원시 SHA, 초기 스캔의 앞차 외곽 일치 반환 29개. 평면 사후 근사이며 완전 가림/실차 센서 성능의 증명이 아니다. 코너 시험 최대 속도 차이는 `t=4.852 s` 초기 가속 때다. 기존 R0 물리 원인은 미해결로 유지한다.

보고서의 STOP 이동량 0.0240/0.0225 m는 해당 시뮬레이션의 요청 후 이동이다. MD20A 실물 제동 거리로 쓰지 않는다. 여기서 통과한 범위를 양측 벽 완전 가림·옆차·분기·고속·전체 랩으로 확대하지 않는다. 커밋/푸시·외부 게시·Jetson 접속·전원 변경은 하지 않았다.
