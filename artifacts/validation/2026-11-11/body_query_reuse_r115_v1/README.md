# 동일 차체 외곽 질의의 재사용 후보

2026-11-11. r102의 긴 판단 프로파일에서`motion_queries/body_queries`의 외곽 생성이 반복됐다. r103의 정렬 미세 개선만으로는Jetson 마감이 충분히 줄지 않았다. 이번에는 같은 장면·자세 배열·조향 배열·전체 설정이 **바이트까지 같은 호출**만 재사용하는 저장 입력 후보를 준비했다.

후보는`probe.py` 프로세스 안에서만 연결한다. 한 장면 최대8개 결과를 보관하고 장면 객체가 달라지면 버린다. 배열을 수정하는 호출자가 다음 결과를 오염시키지 않도록 반환은 복사한다. 원시`unknown`·마스크·광선/시간·질의점·판정은 생략하거나 반올림하지 않는다. 실제 실행 소스와 기본값에는 미연결이다.

다음은r109 저장607판단의 baseline 재현·후보 전체 출력 동등성과 적중률/복사비용을 한 번 비교하는 것이다. r114 주행의 실행시간 계측에 부하를 섞지 않도록 그 주행이 끝난 뒤 수행한다. 적중이나 비용 이득이 작으면 채택하지 않고 다른 원인을 우선한다. PC 저장 비용만으로Jetson 개선이나 실차 마감 달성을 주장하지 않는다.
