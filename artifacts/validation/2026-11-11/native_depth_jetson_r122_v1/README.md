# C++ 관측 연산의 Jetson 저장 비교

2026-11-11. r121 PC에서281회귀·466개 전체 출력 동일, 전체p95 약25→20ms를 확인했다. 운영 미연결 후보를 Jetson에서 한 번 비교한다. C++ 빌드와 Python 원본/후보 두 조건은 같은 격리 소스·저장 궤적을 사용하며, 원격 기존 작업/설정·센서·구동장치를 변경하지 않는다.

`prepare.py`의SHA manifest로 전송·실행 전후를 확인하고, `measure.py`가 두 조건의전체 출력 차이와 비용을 남긴다. 컴파일은 `-std=c++17 -O3 -fPIC -shared -ffp-contract=off`이며 fast-math는 금지한다. 결과는 새 결과 폴더에서만 생성한다. 실시간 ROS 처리/실주행 증명이 아니며 총 비용이 큰 경우 작은 연산 개선을 더 반복하지 않고 추종 구조/주기를 재검토한다.

## 결과

격리 소스161파일의 SHA가 실행 전후 일치했고, 원 입력도 보존됐다. Jetson의 NumPy1.21.5·g++11.4에서 두 조건466회 전체 출력 차이는0개였다. C++ 함수4,883호출·2,422,639행·NumPy fallback0회이며, 종료 후 측정 프로세스가 남지 않았다.

| 저장 입력의 현재 추종 후보 | 중앙값 | p95 | 최대 |
|---|---:|---:|---:|
| Python 기준 | 58.484 ms | 95.721 ms | 144.808 ms |
| C++ 관측 연산 후보 | 46.410 ms | 69.581 ms | 121.595 ms |

[비교](jetson_comparison.json)·[소스 보존](jetson_integrity.json)에 원 결과를 둔다. 중앙값 약21%, p95 약27% 감소했으나50Hz/20ms에는 미달한다. 현재 관측을 중복 검사하는 추종 후보의 비용이며 전체 제어기/독립 보호/ROS 동시 실행의 비용으로 확대하지 않는다. 운영 연결이나 기본 채택은 하지 않았다. 다음 판단은 작은 연산을 더 줄이는 대신 경로 생성·현재 추종·독립 보호의 역할과 주기를 분리하는 것이다.
