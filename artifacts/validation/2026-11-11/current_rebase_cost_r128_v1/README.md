# r126 현재 재계산의 실제 Jetson 비용

2026-11-11. r126의30.69m 지연 주행 결과에서 실제 실행된316개 현재 재계산만 분리한다. 무거운 전체 경로 계산기와 별개로 부모 노드에 더한 비용이므로, PC의4~5ms만 보고 Jetson50Hz에 들어간다고 판단하지 않는다.

동결 소스·원 입력의 해시를 실행 전후 확인한다. 저장 자료 복원은 따로 측정하고, 실제 부모 콜백에 대응하는 snapshot 생성·운동 투영·현재 재계산·결과 동결을 함께 측정한다. 전체출력과 snapshot을 원 기록에 대조한다. 시계가 다른 플랫폼 차이는 단순 명령 차이와 구분한다.

격리 폴더의 저장 시뮬 입력으로만 실행하며 운영 ROS·실제 센서·차량 모터/서보·전력 설정은 건드리지 않았다. 이것은 전체 ROS 실시간 시험이나 실차 주행 검증이 아니다.

## 결과

[PC](pc/result.json)와 [Jetson](jetson/result.json) 모두316개 snapshot/전체출력 차이0,156개 동결 파일의 실행 전후 불변을 확인했다. 원격 파일3개를 회수해 SHA를 대조했고 자기 측정 프로세스도 종료됐다.

| 비용 | PC 중앙/p95 | Jetson 중앙/p95 |
|---|---:|---:|
| snapshot·투영·재계산·결과 동결 합계 | 3.55 / 3.98ms | 16.15 / 17.23ms |
| snapshot 생성 | 1.03 / 1.09ms | 6.07 / 6.18ms |
| 현재 장면 투영 | 1.54 / 1.70ms | 6.14 / 6.29ms |
| 재계산·결과 동결 | 0.96 / 1.21ms | 3.97 / 4.94ms |

Jetson 합계 최대98.98ms·20ms 초과3/316개다. 이 예외의 비용은 주로 장면 투영에서 발생했으며 GC·스케줄링 등 세부 원인은 이 측정으로 분리하지 않았다. 저장 입력 복원 약1.93ms는 실제 콜백의 기존 운동 이력을 쓰는 과정과 다르므로 표 합계에서 분리했다. 단계별 p95를 더한 값이 합계 p95와 같을 필요는 없다.

기존의 확장 추종 후보보다 훨씬 작지만 **현재 값만으로 부모50Hz의 여유가 확보됐다고 할 수 없다.** 다른 센서 콜백·보호·발행 비용을 제외한 수치다. 운영 기본 채택이나 새 고속 시험 대신, 먼저 r126의 남은 경계 재획득/명령 공백을 분리한다. 중복 장면/기록 생성의 개선은 실제 통합 비용이 필요해지는 단계에서 다룬다.
