# r80 유효한 운송 경로의 현재 측방 접근 재검사 후보

현재는 **사본 후보·15검사·고정 입력 비교까지**이며 실제 제어기에 연결하지 않았다. r79 native 교통 결과와 대조한 뒤 반영 여부를 정한다.

r78 첫 측방 정지에서는 G1 경로의 나이0.257초가 기존0.30초 한도 안이고 차량의 예상 이동영역과 우측 추가 접근99/99표본이 현재 관측됐다. 하지만 GUARD는 그 경로의 출처가 이전 스캔이라는 이유로 이 검사를 수행하기 전에 정지했다. 후보는 경로의 출처/나이/유효시간을 그대로 보존하고, 기존 현재 이동영역·점유·마스크·접근 검사를 받을 자격만 허용한다. 통과/측방 해제 이력이나 새로운 자유 공간을 만들지 않는다. 목표는 기존0.35m/s 상한 이하이며 예상 이동영역에는 더 큰 실제 측정 속도를 사용한다.

[고정 입력 비교](saved_compare.json)는 이미 원 판단과 일치한 r78 보존 소스를 바탕으로3,039판단을 재생했다. 명령 변경은32.46–32.50초의3회0→0.35m/s이며 양수→0은0회다. 경로 재검사는16회 시도되어3회만 허용됐고 나머지는 기존 현재 관측 검사에서 거절됐다. 새로운 정지 사유·외부 모듈 로드는0이며 입력/후보 소스 불변을 확인했다. 미래 센서·차체 운동은 원 실패 궤적에 고정된 비교이므로 실제 정체 해결을 증명하지 않는다.

기존 유효시간 만료/불일치·미관측/측방 마스크·기능 비활성·G1 정지 반례를 포함한 [15검사](checks.json), [첫 프레임 비교](single_frame.json), [사본과 재생 소스](prototype_sources.zip)를 보존한다. 새 주행은 아직 없다. 당시 함수 진단 준비 중 ROS 환경 스크립트와 읽기 전용 속성 대입 오류는 build의 v1/v2 실패 로그로 보존했고 v3에서 원 출력을 확인했다. 해당 오류는 주행 실패가 아니다.
