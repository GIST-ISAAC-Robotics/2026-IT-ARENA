# 현재 센서로 다시 계산하는 경로 추종 후보

2026-11-11 준비. r114에서 제출 정렬 뒤에도 명령 만료로 인한 출력 공백이 남았고, r115 외곽 캐시는 유효하지 않았다. 과거 명령 timestamp 갱신 대신 **도착한 경로를 운동 이력으로 현재 차체 좌표에 옮기고 현재 스캔으로 다시 판단하는 최소 구성**을 저장 입력에서 비교한다.

현재 범위는 G1/G2의 FOLLOW 안에서 실제 선택한 baseline/parallel 경로다. `normal.path_points`는 parallel 선택 시에도 실제 선택 경로로 교체되는 것을 확인했다. 우회/추월의 경로와 모드 변경은 지원하지 않는다. 도착하지 않았거나 폐기된 결과, 0명령, 명시 reset 뒤 계획을 사용하지 않는다. 이전 계획 기준시각300ms 이내만 조사하며, 이는 새 운영 허용값이 아니다.

현재 스캔의 기존300ms·운동/센서 세대·벽 선택을 확인하고 Pure Pursuit·현재/직전 조향의 점유·제동/차간거리·같은 관측 외곽 검사를 수행한다. 새 경로를 무관측 영역으로 늘리지 않고 속도는 이전 계획 상한 이하다. 원천 시각을 보존한다. 센서 정답 외 평가 자세·지도·상대차 위치는 입력하지 않는다.

**ROS/명령 발행에는 미연결이다.** 현재 노면·측방 모드 전이, 계획 중 실제 이전 조향 변화와 planner 상태의 정합, 고장/STOP 인터페이스가 아직 부족하므로 `eligible`은 실차/운영 허가가 아니다. 먼저 필요한 공간의 현재 관측과 계산 비용이 성립하는지 한 번 비교하며, 불필요한 보호 완화로 통과시키지 않는다. r114 원 궤적에서의 가능성이지 새로운 주행 결과가 아니다.

## 저장 입력 결과

10경계검사와 원 입력 SHA 불변을 확인했다. [comparison.json](comparison.json)의466호출 중420회에서 후보가 성립했다. 나머지는 양수 FOLLOW 계획 없음41회·계획 기준시각 만료1회·현재 관측/가림4회다. 새로운 정면 장애물·정면 미관측·운동/센서 세대 변경·벽 선택 변경은 과거 계획으로 덮지 않았다.

현재 투영·기하를 포함한PC 비용 중앙15.34ms·p95 25.22ms·최대48.59ms다(입력 복원 제외). 이미PC에서도20ms 간격을 넘는다. 상태/노면 계약을 더하기 전에 [r118 Jetson 비용](../tracking_cost_r118_v1/README.md)으로 최소안의 비용을 확인한다. `eligible420`을 실제 새 명령의420회 안전 통과나 완주 개선으로 확대하지 않는다.
