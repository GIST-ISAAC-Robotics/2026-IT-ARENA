# r84 마지막 관측 소실의 구조 사각·잡음 분리

2026-11-11. r85 CPU 동일 판정 최적화 뒤 r84의60.36초 정체를 분석하고 구조 기억 이관 후보를 구현·회귀·재생했다. **새 주행은 하지 않았고, 마지막 정지 해결에는 아직 부족하다.**

## 첫 분리 결과

[원 r84](../guard_masked_speed_r84_v1/README.md)의7개 유지점 중5개는 현재 설명 가능한122.83° 차체 구조 그림자 안에 있다. 해당 그림자는 원천 번호81–90의10개 광선을 가리고 있다. 나머지2개는 그림자 밖이다. 따라서 모두 거리 잡음으로 재관측에 실패했다고 단정하지 않는다. 현재 반환이 실제로 없는 구조 사각과, 반환이 있어도 정밀한 표면 대응이 실패하는 경우가 섞였다.

[센서 기하 그림](r86_surface_geometry.png)은 이전 점을 엔코더·IMU로 현재 차체 기준에 옮긴 값과 현재 반환만 그렸다. 지도·정답 자세가 아니다. 작은9점 묶음을 직선으로 적합해도 사각 내부의 옛 점까지 실제 관측된 유한 범위가 늘어나지 않았다. 이 방식만으로 재관측 허가를 주는 후보는 채택하지 않는다.

## 기억 이관과 저장 비교

[호출 상태](structure_capture.json)에서 일반 기억은 source60.003/ref60.18, 구조 기억은 source60.203/ref60.36이었다. 중간 스캔의 저속/관측 거절로 일반 기억 갱신이 늦어졌다. 후방의 설명된 차체 사각 안에 있는 옛 반환 자체를 구조 기억에 추가하고, 현재/직전 조향의 이동 외곽 검사를 다시 수행하도록 `known_structure.py`를 수정했다. 기억의 정지 물체 가정은 그대로이며 움직이는 사각 물체의 신원을 증명하지 않는다.

기억 용량512·거리3m·일반 기억0.3초·기존2cm 대응은 유지했다. 앞쪽 점·다른 방향·설명 불가 사각·만료/출처 없는 기억·용량 초과는 이관하지 않는다. 이관 후 충돌 속도 제한도 검사했다. 수정 전 소스는 [ZIP](before_r86.zip), 변경은 [계약](../../../../config/tests/retained_structure_r86_sha256.json)에 보존했다.

직접 관련27검사와 부분 관측/소스 계보244검사를 통과했다. [r84 전체 저장 비교](saved_comparison.json)는3,037회 명령이 전부 동일하고, 전체 출력2,636회 일치/401회 진단 변화다. 첫 래치에서5개를 구조 기억으로 옮겨 위협7→2개로 감소했으나 **0→양수0회, 정지는 계속**됐다. 입력·소스 해시 불변이다. 과거 주행의 실패를 성공으로 바꾸지 않았으며 이 상태로 같은 폐루프 시험을 반복하지 않았다.

남은 점은 현재 반환과20.56mm·26.62mm 떨어져 있어2cm 점 대응을 통과하지 못한다. 3점 현의 방향 일관성도 성립하지 않는다. 이것이 같은 실제 표면인지는 별도 판단이며, 모두 잡음이라고 단정하지 않는다. [유한 잡음 패치 진단](noise_patch_probe.json)은 두 점 중 한 점에서만 가설 조건이 성립했다. 임의 직선 연장이나 고정 TTL 삭제는 채택하지 않았다.

[3cm 민감도 비교](noise_sensitivity_30mm.json)는 실행 코드 파일을 바꾸지 않고 별도 Python 프로세스의 두 점 대응 비교식만2→3cm로 바꿨다.3,037판단 중 명령9개가 달라졌고60.56–60.60초의3호출에서0→0.35m/s가 나왔다. 그러나60.76초에 새로운 옛 점과 현재 반환의31.11mm 차이로 다시 래치됐다. 입력·소스는 불변이며 실제 주행은 하지 않았다. **허용치를3cm로 올리는 후보는 미채택**이고, 성공할 때까지 수치를 늘리는 식으로 이어가지 않는다. 다음 원인 구분은 [실물 반복성 진단](../c1_repeatability_v1/README.md)과 추가 잡음/지연 없는 native 교통 기준이다. 원±30mm 스트레스 실패는 남긴다.

진단 스크립트는 `build/`에서 실행한 사본을 보존했다. 저장소 상대 경로는 실행 위치를 기준으로 하므로 이 폴더의 사본을 그대로 실행하는 용도는 아니다. 원 입력과 r84 실패는 수정하지 않았다.
