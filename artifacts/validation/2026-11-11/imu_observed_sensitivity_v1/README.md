# 11/11 실측 IMU 조건의 선택형 민감도 시험

## 사전 등록

- 입력: 미장착 LSM6DSOX 5분 성공 기록. gyro 59,721개를 현재 `MotionInput.on_imu`에 MCU 읽기 시각 기준으로 입력해 전부 수용했다. 실제 ROS 통신·취득 시각 검증은 아니다.
- 조건: 요청 199.068509 Hz, 축별 독립 Gaussian 표준편차 gyro 0.0011 rad/s·accel 0.0103 m/s², gyro z 평균을 오차로 가정한 −0.015615217 rad/s. `sensor.yaml`·`motion.json`으로 명시 선택한다.
- 센서가 정지해 있었는지와 장착 축이 확인되지 않았으므로 평균을 실물 교정값으로 채택하지 않는다. 호스트 수신 공백을 센서 지연으로 바꾸어 주입하지 않는다.
- 기존 B0390/C1/JR60P20·v2026.11.06 단독 프리셋의 속도/물성/보호/STOP/종료 기준을 유지해 한 번 실행한다. 영상은 생성하지 않는다. 과거 r25와 엄격한 단일변수 A/B가 아니다.
- 실제 발생 IMU 주기, 주입 전후 bias, 제어기/독립 보호층의 연결, 입력 무결성, 진행·접촉·노면·STOP·정상 종료를 확인한다. 실패 시 원본을 보존하고 성공할 때까지 반복하지 않는다.
- 115개 관련 단위 검사 통과. 기본 센서 설정·운영 제어/보호 정책·실물 펌웨어는 변경하지 않았다.

`run_once.py`가 최종 인자·입력 해시를 `registered.json`에 남긴다. 실행 결과는 `solo_run1/report.json`, 최종 해석은 [실측 보고서](../../../../docs/sensors/ESP32_LSM6DSOX_HARDWARE_2026_11_11.md)에 기록한다. 실행 중 이 등록 본문과 입력 파일은 변경하지 않는다.
