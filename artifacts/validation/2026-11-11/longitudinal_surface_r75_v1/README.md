# r75 감속 중 앞뒤 이동 잔차의 표면 대응

상태: 관련155회귀·저장 입력 대조 통과. 81T native 단독 후속1회는42.06m 정체로 **실패**했다.

## 근거와 범위

[81T r73 원 실패](../gearing_81t_r73_v1/README.md)의 첫 latch에서 모터/IMU 이동 추정과 평가 차체 이동이 약55.9mm 달랐다. 현재 스캔의 여러 방향 벽을 대조하면 앞뒤 약63.4mm·옆3.6mm의 공통 잔차로 맞았지만 기존6cm 제한 때문에 거절됐다. 정답 차체 정보는 **진단에만** 사용했다. 실행 입력·[fixture](sensor_fixture.json)에는 기존 센서 대응 정보만 넣었다.

기존8cm 점 대응 검색 반경 안에서 앞뒤 잔차만 최대8cm까지 허용한다. 총6cm를 넘으면 측방 성분2cm 이하, 최종 대응 비율85% 이상, 두 방향 관측을 나타내는 normal eigen ratio0.1 이상, 잔차 RMS8mm 이하를 추가로 요구한다. 원6cm 이내의 기준은 유지한다. 이 수치는 실측 센서 사양이 아니라 제한 대응 정책이다.

이 수정은 이전 장애물이 현재의 어느 표면인지 대응하는 범위를 넓힌다. 현재 점군·경로·차량 위치 추정·충돌 간격·unknown을 바꾸지 않는다. 현재 점과 대응하지 않는 별도 장애물은 남긴다. 고정 배경이 충분하다는 기존 가정과 여러 물체가 함께 움직일 때의 모호성은 해결하지 못한다. 따라서 실차 안전이나 보편적인 슬립 보정으로 부르지 않는다.

변경 전 소스는 [before_r75.zip](before_r75.zip), 초기 민감도 진단은 [원 결과](../gearing_81t_r73_v1/latch_diagnosis.json)이며 단순히 제한을8cm/10cm로 바꿨던 진단 자체를 운영 적용한 것은 아니다. [저장 비교 코드](compare_saved.py)는 r73 고정 센서 입력을 r74/r75 이전과 현재로 대조한다.

## 최초 검사 실패와 수치 경계 수정

최초 회귀는154통과·합성1실패였다. 실제 r73 fixture·사라진 독립 장애물 검사는 통과했지만, 합성 공간의 앞뒤+7cm 이동에서 첫 정합 뒤 대응점이205→121개로 줄었다. 관측 현의 정확한 끝점이 부동소수 오차로 `[0,1]` 밖으로 계산되면 제외되는 문제다. fraction에만1e-9 오차를 허용했다(최대12cm 현에서0.12nm). 현재 관측 밖의 의미 있는 연장이나8cm 검색 폭 확장은 없다.

실패 소스·당시 계약·검사·로그는 [first_attempt.zip](first_attempt.zip), 최초 집계는 [checks.json](checks.json), 작은 함수 진단은 [failed_synthetic_fit.json](failed_synthetic_fit.json)에 보존한다. 수정 뒤 재검사와 저장 입력 비교는 별도 파일로 남기며 최초 실패를 덮어쓰지 않는다.

## 저장 입력 대조

[재검사](checks_v2.json)는 관련155개 통과다. [r73 고정 입력1,815판단](saved_compare.json)에서 변경 전 baseline 불일치는0건이고, 변경 후 최초 latch 시점 이후374판단이0→0.2m/s 진행 명령으로 바뀌었다. latch374→0, 입력/소스3개 해시 불변이다. 새 차량 이동을 계산한 결과는 아니므로 실제42.09m 정체 해소는 다음 단독1회에서 확인한다.

## 실제 단독 후속1회

[원 보고서](solo_run1/report.json)·[회수 집계](execution_sidecar.json)·[입력 불변](run_integrity.json)을 보존한다. **42.06m/46.64m·0랩·최고2.842m/s**, `FOLLOW_KNOWN_OBSTACLE_LATCHED`로 실패했다. 접촉 샘플0·software STOP/ESTOP·정지 후 dense pose 정착·정상 종료를 확인했다. 등록552입력은 실행 담당과 GPT 주 에이전트가 각각 해시 대조했다. 이미 정체한 상태에서의 정리 STOP이므로 고속 제동거리 통과가 아니다.

이번 첫 latch는34.82초·진행약41.99m다. **공통 표면 정합은 이미 성공했고 잔차 약1.5mm**로, r73의6cm 제한 거절과 원인이 다르다. 남은 과거 점6개는 현재 좌표로 뒤쪽 x −31~−28cm·왼쪽 y 약53cm이고, 현재 반환과2.7~4.8cm 떨어졌다. 약0.2초 이전 관측을2m/s 이동 가능 물체로 확장한 판단이 남아 정지했다. 현재 관측에 대한 별도 물체 신원은 아직 판명하지 않았다.

[첫 latch 요약](latch_context.json)과 [센서 좌표](latch_context_arrays.json)를 기준으로 다음에 시야 경계·현재 표면/이전 위협 대응을 분석한다. 이번 결과를 이유로 표면 이동 한도를 다시 넓히거나 과거 점을 시간 만료만으로 삭제하지 않는다. 새 주행은 반복하지 않고 준비한 시설+C1 대표를 먼저 확인한다. 저장 입력 성공을 실제 랩 성공으로 소급하지 않는다.
