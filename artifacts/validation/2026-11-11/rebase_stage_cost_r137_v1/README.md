# ROS 동시 실행의 현재 재계산 단계 비용

2026-11-11 실행 전 등록. r128 CPU 전용 중앙16 ms와 r134 ROS 동시 진단36 ms는 조건이 다르므로 단순히 ROS가20 ms를 더 썼다고 결론내리지 않는다. 같은 동결316입력·200 Hz 진단 발행·단일 executor·큐64에서 snapshot/투영/재계산+기록 변환의 벽시계 시간, 프로세스 CPU 시간, 읽기 전용 CPU 주파수, GC 발생을 구분한다.

동결 소스·출력 동일성·정상 종료와 실제 수신 보존은 따로 판정한다. 실물 센서/차량 토픽은 접근하지 않으며 localhost/domain199에서 수행한다. 전력·클럭·CPU affinity·GC 설정을 바꾸지 않는다. 이 계측 자체의 비용과 미포함 전체ROS/영상/보호 비용이 남는다. 대표 원인을 좁히는 진단이며 최적화 완료나 실시간 인증이 아니다.
