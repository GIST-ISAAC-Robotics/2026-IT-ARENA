# 분리 판단 주행의 코너 경로 소실 조사

2026-11-11. r104는 결과607개를 모두 적용했으나34.61m에서 정체했다. 동일 입력607개의 전체 판단을 재생해 **불일치0**으로 원 현상을 확인했다. 보완 뒤 제한 주행1회도20.14m에서 별도 정체로 실패했으며 아래에 구분한다.

## 원인

[전환 그림](corner_transition.png)에서 회색은 현재 반환점, 초록은 연결된 벽의 재표본점, 빨강은 현재 적합 경로, 파란 점선은 이전 경로를 센서 운동으로 현재 좌표로 옮긴 것이다. Gazebo 정답 위치를 경로 계산에 넣지 않았다.

- 49.96초: 오른쪽 실제 긴 벽의 직각 적합과 기존 경로가 일치한다.
- 50.06초: 재표본 꼭짓점이4개가 됐다. 두 긴 면 사이41.3mm의 짧은 사선이 생겨 기존 `len(vertices)==3` 조건에 걸렸고, 전체 구간 잡음도 작아 잡음용 분할 보완에는 들어가지 않았다. 일반 cubic 적합으로 돌아간 경로는 거의 직선이 됐다. 가까운 x 구간은 기존 경로와 일치한다고 판정돼 이 경로로 기억을 갱신했다.
- 50.16초: 정상 직각 적합이 다시 나왔지만 직전에 저장한 직선과 달라 거절됐다. 50.26초부터는 그 기억도 만료돼 `follow_boundary_unconfirmed`가 지속됐다.

따라서 새 계산 프로세스의 결과 폐기 때문이 아니다. 이 주행에서 적용 지연20ms는 있었지만, 폐기0·양수 적용100ms 간격이었다. 궤적 차이로 기존 적합 취약점이 드러난 것으로 해석하며, 적용 지연의 모든 영향을 배제했다는 뜻은 아니다.

## 보완 범위

선택형 직각 적합에서 **두 긴 면 사이 같은 방향의 단일 짧은 사선**만 기존 두 직선 검사로 다시 제안한다. 사선 길이는 기존 최대 잔차3cm의2배 이내로 한정한다. 모든 관측점의3cm 잔차·최소 면15cm·회전각40–135°·최소 회전반경 검사는 그대로다. 실제 긴 제3면·여러 모서리·반대 방향 돌출은 이 제안에서 합치지 않는다. 미관측 채움·보호층/물성/속도 변경은 없다.

원 소스는 [before.zip](before.zip), 대표 관측은 [fixture.json](fixture.json), 원 재현은 [summary.json](summary.json), 적합 세부는 [geometry.json](geometry.json)에 보존했다. 최초 진단 스크립트의 import·키 오류는 실행 로그에 남기고 수정했다. 원 입력은 변하지 않았다. WSL 호출 실패는 제어기 결과와 구별한다.

## 저장 검증과 실제 제한 주행

관련9파일 **80개 검사 통과**. [후보 저장 비교](comparison.json)는 r104 607판단 중 전체 진단/명령26개 변경·명령16개 변경·0→양수3개·양수→0개0, r91 성공 입력610판단은 전체21개·명령12개 변경·정지/주행 전환0이었다. 양쪽 원 입력 해시는 불변이다. 새 명령은 기존 속도·조향 제한 안에서 달라졌으며 새 궤적 증명은 아니다.

관련 계보1검사·빌드·설치본 해시 일치 뒤 [제한 주행](two_actor_run1/combined_assessment.json)은 **20.14m·최장저속32.716초로 미완주**였다. 결과607개 모두 적용·폐기0, 양수 적용100ms 간격이었다. 현재 관측 경로는 남아 있었으나 `parallel_hold_reference_not_straight`와 `guard_curve_rejected_toward_left`가 계속됐다. 이전r104의34.61m 경계 소실과 같은 실패라고 합치지 않는다.

접촉/노면이탈0·STOP 정착·기록/스냅샷/소스 불변을 확인했다. 원 report는 `harness_valid=true`, `shutdown_clean=true`, 자식 종료0×5다. 추가 프로세스 조회는WSL 오류 뒤 배포판을 재시작해서 수행했으므로 자발 종료의 독립 재확인으로 쓰지 않는다([복구 기록](two_actor_run1/postflight_recovery.json)).

[시각 대조](../scan_start_phase_r107_v1/phase_audit.json)에서r104는스캔 발행→제출8ms였으나r105는58ms가 계속됐다. 최초 회전 위상이 달라졌는데100ms 제출 일정이 신호 허가 시각에 고정되어 다음 회전에서도 늦게 시작했다. 이는 관측한 결함이며 정체의 유일 원인이라는 증거는 아니다. 초기 제출을 다음 새 스캔에 맞춘r107로 먼저 분리하고, 젯슨 비용 주입r106은 준비 상태로 남긴다. 전체랩·실시간 개선은 아직 주장하지 않는다.
