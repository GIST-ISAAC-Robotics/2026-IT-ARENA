# B0390 Argus→ROS 입력 연결 진단

2026-11-11. 기존720p60 Argus 취득 이후, 실내 장면을 이동시키지 않고 별도 ROS 수신 프로세스까지 영상 본문/형식·처리량을 확인한다. 장착 높이·신호/마커 인식·카메라 보정은 범위 밖이다.

- [`probe_ros_image.py`](probe_ros_image.py)는 기존mode4·1280×720/60 NV12→BGR 변환을 유지한다. appsink는 최신 영상 선택을 위해 queue2/drop=true이며 전체 원천 프레임 보존 시험이 아니다.
- ROS_DOMAIN_ID73·localhost 전용의 `/diagnostics/b0390/image_raw`만 발행한다. 대회 제어기·모터/서보·IMU/C1 드라이버를 실행하지 않는다. 영상 본문은 저장하지 않고 전달 전후 CRC32·바이트 수·시각만 비교한다. 상세 시각열도 Git 제외 build에 보관한다.
- **header는 appsink에 도착한 system 시각이며 촬영 시각이 아니다.** frame 이름에도 `receive_time_unverified`를 표시한다. Gst PTS를 별도로 남기고 이 진단을 `/camera/color/image_raw` 운영 드라이버로 채택하지 않는다.
- 처음3초 준비 뒤20초만 검사한다. 기존 reliable/depth2 수신으로 ROS 형식·본문 일치와 전달량을 보고, 60fps 유지·긴 수신 간격은 별도 수치로 남긴다. 샘플 부족/누락을 완전 취득으로 표시하지 않는다.
- 정상 NULL 종료와 자식 수신기 종료를 확인한다. 모터·서보 구동, OS·전력·드라이버 변경은 없다.

첫 원격 모듈 확인은 ROS 환경 미설정으로 `rclpy`를 찾지 못했다. 설치된 Humble setup을 읽은 후 GI·GStreamer1.20.3·ROS Image 사용 가능을 확인했다. 새 패키지를 설치하지 않았다. 기존 카메라 점유 프로세스는 발견되지 않았고 `/dev/video0`을 확인했다.

run1은 진단용 domain237의 Fast DDS 포트 계산이 범위를 넘어서 ROS 초기화 때 실패했다. 카메라 시작 전이며 취득/영상 검증0이다. 원 소스 `probe_ros_image_v1.py`·로그를 보존하고 domain73으로 수정했다. 기존 시스템의 ROS domain 설정은 변경하지 않는다.

두 실행 모두 준비3초 이후20초 측정, BGR720p60·reliable depth2·별도 수신 프로세스·원래 전력/설치 구성을 사용했다. NumPy·GPU 커널을 추가한 최적화가 아니다. 설치된 Humble `Image.data` setter는 bytes 대입 때 모든 값의 타입/범위를 Python으로 순회했다. `array('B').frombytes()`로 같은 본문을 전달하면 공개 setter의 타입 확인 후 배열 경로를 쓰며, 타입 검사를 비활성화하거나 private field에 넣지 않는다. 원 실행 소스v2/v3와 상세 시각열은 보존했다. 현재 파일은v3의 주석만 한국어로 정리했다.

run3 수신 간격의 원천 PTS 중앙은16.666ms, 최대19.854ms이고 본문 전달 최대12.940ms·수신 나이 최대32.621ms다. **카메라 원천의 모든 프레임 보존이나 노출→ROS 지연 수치가 아니다.** appsink drop은 허용된 진단 설정이다. [행별 대조](delivery_audit.json)에서 수신1,200장의 길이·CRC가 전부 발행과 일치했고 중복/시각 역전/음수 수신 나이는 없었다. 발행index323(측정5.381초)의1장 미수신으로 `plumbing_passed=false`를 유지한다. 중간1장 누락 원인은 이번에 특정하지 못했으며 보존/기록 용도의 무손실 운용으로 채택하지 않는다.

카메라 NULL·수신기exit0을 확인했다. 실내 영상은 저장하지 않았다. 원격 실행 파일v3 SHA-256은 `38e9689377810c8f3071d8504984f784cab12d209a0b2b72dcee2dfebf269660`이다. 제어/보호 코드는 변경하지 않았다. 실물 인식 동시부하·노출 시각·CameraInfo·최종 장착을 후속으로 남긴다. 이1장만을 없애기 위한 반복 시험은 진행하지 않는다.
