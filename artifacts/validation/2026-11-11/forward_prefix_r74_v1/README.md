# r74 현재 관측 경로의 앞부분 절단과 횡 이탈 구분

시설+C1 거리·지연 결합의 약20m 정체를 저장 입력에서 분석했다. 현재 긴 벽에서 만든 경로의 첫 점이 차량 앞14–20cm에 놓였고, 원점까지의 직선거리를 횡 이탈처럼 검사해 기존12cm 앵커 조건에서 거절했다. 해당 거리 전체가 옆으로 벗어난 양은 아니다. [분리 진단](../facility_noise_diagnosis_v1/README.md)을 따른다.

## 변경

기존 `junction_continuity`·`piecewise_wall_trial` 연결에서만, 같은 벽의 유효한 이전 경로와 현재 긴 직각 경로가 공통 구간에서 일치할 때 전방 시작점을 구분한다. 첫 점은 기존 최소 추종 목표 거리30cm 이내이고 전방을 향해야 하며, 접선 수직 오차는 기존12cm 이내여야 한다. 공통 구간25cm·5점·80% 거리8cm, 관측 길이65cm·기존 TTL은 유지한다.

경로를 뒤로 연장하지 않으며 미관측 공간을 자유 공간으로 표시하지 않는다. 초기 경로 획득·TTL 만료 후의 새 획득에는 사용하지 않는다. 실제 점유·부분 관측·독립 보호 검사도 그대로다. [구현 전 소스](before_r74.zip)와 [기하 fixture](fixture.json)를 보존했다. fixture의 두 경로는 형상 검사용이며 서로의 저장 시각 차이를 유효 TTL이라고 주장하지 않는다.

## 확인과 한계

- 관련 회귀·출처 체인 **182개 통과**. 기록은 [checks.json](checks.json).
- 원 시설+C1 입력3,040판단에서 변경 전 재현 불일치0. 후보 적용 시 명령 변경297회, 0→양수72회, 양수→0도6회 있었다. 후보 직접 호출14회. 입력/소스 해시 불변. [대조 결과](saved_compare.json)·[재생 코드](compare_saved.py).
- 새 0명령6회는41.56–41.60초,42.66–42.70초의 두 묶음이며 `parallel_hold_short_reference`였다. 경로가 바뀌어도 측방 제어기의 짧은 기준 경로 검사가 유지된 결과다. 이 짧은 전이를 없애려고 해당 검사를 해제하지 않았다.
- 저장 입력 비교는 새 궤적이나 전체 랩 통과가 아니다. **이 변경의 새 Gazebo 주행은 아직 하지 않았다.** 원 시설+C1 실패는 그대로 유지한다. 81T 변경과 동시에 진행 중인 표면 대응 수정은 별도 r75로 구분한다.
