# r70 native 입력 구독 평가 수정

r69 단독 주행은1랩을 완료했지만 평가기가 `/scan`을 고정 요구하여 원 `passed=false`가 되었다. 현재 선택한 원천 입력은 `/scan/native`이며, 제어기와 독립 보호층의 실제 구독 목록에 모두 기록되어 있다.

평가기에서 legacy/native 선택에 따른 정확한 구독 집합을 검사하도록 수정했다. 다른 LiDAR 토픽의 동시 구독, 필요한 IMU·모터축 피드백·보호층 `/drive` 누락, 지도/정답 등 추가 입력은 계속 실패한다. stereo/ToF의 기존 계약도 유지한다. 대회 제어기·보호 로직·주행 판정선은 변경하지 않았다.

관련19회귀와 출처 계보1검사를 통과했다. [저장 graph 재감사](r69_saved_graph_reaudit.json)의 입력 계약 두 항목은 통과하며, 원 report SHA-256과 `passed=false`가 유지됐음을 확인했다. 이는 **저장된 구독 목록의 재감사**이고 새로운 주행·전체 판정의 소급 성공이 아니다. `before_r70.zip`에 변경 전 평가기를 보존한다.
