# 같은 관측 질의의 묶음 계산 후보

2026-11-11. r119에서 466개 고정 입력의 현재 관측 후보는 약242만 질의를 만들었다. 128점씩 수행한 광선 지지 계산과 자세별 작은 행렬 곱을 더 크게 묶는 후보를 비교한다. 질의 표본·원시 광선·선택 조건·판정선은 바꾸지 않는다.

원 구현/512점/1024점/512점+차체 외곽 행렬 묶음을 같은 PC 저장 입력에서 각각 한 번 실행한다. 전체 출력 동일성과 무응답·가림·원점 근접·미세 회전의 기하 회귀를 확인한다. `variants.py`는 검토할 차이만 분리한 연구 스크립트이며 공용 소스·기본값·ROS 실행은 변경하지 않는다. PC 결과가 충분하면 그 후보만 Jetson에서 확인하고, 효과가 작으면 채택하지 않는다.

## 결과 — 운영 미채택

24개 경계검사를 통과했고, 네 구성 모두466호출·420적격·전체 출력 동일·원 입력 불변이다. [비교 결과](comparison.json)의 비용은 다음과 같다.

| 구성 | 중앙 | p95 | 최대 |
|---|---:|---:|---:|
| 기존128점 |15.895ms|24.952ms|47.099ms|
| 512점 |13.651ms|21.298ms|44.529ms|
| 1024점 |13.694ms|21.384ms|44.489ms|
| 512점+외곽 행렬 |13.892ms|21.503ms|43.828ms|

512점은 약14% 개선했지만PC에서도20ms를 넘고, 다른 두 후보는 추가 이득이 없다. 이 작은 변경만 따로 배포하거나 Jetson에서 반복 계측하지 않는다. [r121 C++ 내부 계산](../native_depth_r121_v1/README.md) 후보의 묶음 크기로만512를 사용하고, 충분한 총 개선이 있는지를 별도로 본다. 원래 배열과 모든 검사점은 유지한다.
