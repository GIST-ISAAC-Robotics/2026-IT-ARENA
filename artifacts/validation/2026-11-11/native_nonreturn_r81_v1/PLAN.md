# r81 native 전송에서 결측 원값 구분 보존

입력 codec만 수정해 **연결135검사·두 패키지 빌드·설치본 송수신 구분 확인을 통과**했다. 같은 조건의 새 주행은 **20.21m·최장저속7.278초·앞차 이동 중 정체7.176초로 실패**했다. r80 운송 경로 후보는 도입하지 않아 r78의 제어/보호 판단을 유지한다. 완주·최종 간격·영구 정체 기준은 미달이며, 접촉/추가 상대 접촉0·노면 평가34,136표본 이탈0·STOP·정상 종료와 소스 불변을 확인했다. [실행 회수](two_actor_run1/execution_sidecar.json).

**기록 해석 정정:** 수신 평가기의 `native_received_row`는 +inf를 null로 합쳐 기록했다. 따라서 sidecar의 +inf0은 **실제 제어 입력에 +inf가 없었다는 뜻이 아니다**. 원 sidecar는 보존하며 [판단 입력 별도 감사](trace_nonfinite_audit.json)를 기준으로 구분한다. r81의 +inf 포함 고유 scan은121개·606판단, r79는0개다. NaN도 별도로 남았다. 후방 후보의 활성 횟수와 정체 감소의 인과는 이 집계만으로 입증하지 않는다. 평가 기록 함수도 +inf/-inf/null을 구분하도록 후속 수정했고 관련53검사를 통과했다. 기존 null 로그를 추정 복원하거나 주행 결과를 소급 변경하지 않았다.

r79의 C1 가변 점/각도 입력은 형식·시각/수신 감사에는 통과했지만16.86m 정체로 실패했다. 기존 전송 함수가 +inf와 NaN을 모두 JSON null로 바꿨고 수신기는 null을 NaN으로 해석했다. 기존 후방 제한 결측 정책은 둘을 구별하므로 같은 원 광선에서도 전송 전후 판단이 달라졌다. [수정 전12검사](before_checks.json)의2실패가 이를 재현했다.

원본 `+inf`는 명시 문자열 `"+inf"`, `-inf`는 기존 `"-inf"`, NaN은 기존 null로 전송한다. 거리/각도/취득 순서/시각/점 수·유한한0/최소거리 미만 값은 그대로 유지한다. 두 입력 모두 일반 관측에서는 계속 unknown이며 자유 공간이나 가짜 거리 반환을 만들지 않는다. 기존 null은 출처를 복구할 수 없으므로 NaN으로 유지한다. 실제 C1의 거리0/품질0을 +inf로 치환하는 수정이 아니다.

[변경 전 소스](before_r81.zip)와 출처 계보206을 보존했다. 수신기·발행기를 함께 빌드하며 기존 수신기는 새 태그를 지원하지 않으므로 일부만 배포하지 않는다. 연결 회귀 뒤 같은 시설/상대/native 조건1회로 정체와 실제 분기 활성 여부를 확인한다. 실패 원인을 숨기거나 같은 조건을 성공할 때까지 반복하지 않는다. 실물 취득 시각·동적 가림·IMU 장착 검증은 별도다.

## 후속 정체 분리

[원 소스 관찰 재생](diagnosis_summary.json)은3,039판단이 모두 같았고 snapshot990파일과 원 입력이 불변이었다. 20.36/20.46초에는 G1이 현재 경로·0.6m/s를 만들었지만 측방 선택기가 미관측 이동 때문에 최종0을 냈다. 첫 프레임의 미관측407표본은 차체 왼쪽 후반의 외곽 약0.27–4.24mm 띠에 있다. 이를 자유 공간으로 바꾸지는 않았다. 반면44.76/45.00초에는 G1부터 `follow_boundary_unconfirmed`였고, 앞 시각의 벽 후보는 `wall_segment_short`였다. 48초에는 오른쪽 벽으로 경로가 돌아와0.35m/s 후보를 허용했다. 경로 생성 실패와 측방 이동 검사 실패를 같은 원인으로 취급하지 않는다.

후방 허용 진단 flag는5호출에서 true였지만, r78에서 새로 연결한 재검토 분기와 이전 RELEASED 분기를 합친 수치이므로 새 분기만의 효과로 쓰지 않는다. 다음은 원시 반환에서 벽 사슬이 끊기는 이유와 미관측 표본의 실제 원인을 분리하는 것이다. 장면/마스크/물성이나 판정선을 바꾸지 않은 저장 입력 조사다.

[단일 프레임 기하](geometry_probe.json)에서20.36초의 무반환은 원천 광선76–80번과 그 다음 장착 마스크81번 사이였다. 스캔 배열의 시작/끝 연결 문제가 아니다. 실제 반환 쪽 마지막 점은약12m이고 반대쪽은 마스크라서 양옆 반환 조건을 만족하지 않았다. 가장 가까운 점유 여유까지 약0.281m 남지만, 이 값으로 가린 물체가 없다고 결론내리지 않는다. 44.76초 오른쪽은 가까운105점 벽과2점 돌출물, 앞쪽156점 벽으로 나뉘었고 가까운0.338m 후보가 선택됐다. 이 부분은 벽 후보 선택·잡음 적합의 후속 자문/조사 대상이다.
