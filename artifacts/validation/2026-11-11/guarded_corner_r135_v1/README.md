# GUARD 코너 정체 좌표 분석

2026-11-11. 원r133의465판단을 소스 변경 없이 모두 동일 재생했다. 대표seq790은62.020초, 실제 모터축 환산속도0, 현재 조향0.275 rad에서403개 추가 이동 표본이 미관측이었다. 위치는 차체 중심 기준x=13.8~22.4 mm, y=75.8~84.3 mm로 옆면 밖 최대9.3 mm였다.

초기에는 `partial_observation.reason=fully_observed`와 구조 정책의 승인 보고를 보고 구조 가림 근거 전달 누락을 의심했다. 그러나 원시 좌표 대조 결과 실제 미반환은90~93번 광선, 약116~119도이며 설명된 구조 가림은 약119.55~126.18도였다. **서로 인접하지만 같은 영역이 아니다.** 기본 부분 관측의 전방100도 범위 밖 무반환이므로 기본 경로는 승인됐고, 회전 외곽을 다시 검사하는 GUARD가 막았다. `fully_observed`를 전 방향이 관측됐다는 뜻으로 해석해서는 안 된다.

구조 가림 근거를 동일 시각/조향/속도의 작은 이동에만 연결한 `candidate.py`는 저장465개에서 명령 변경0·승인0이었다. 범위를 임의로 늘리지 않았으며 이 후보는 **미채택**이다. 실제 미관측 영역에 대한 별도 저속 후보와 명령 만료 문제를 후속으로 분리한다. raw/기하/원 결과와 실패 가설을 모두 보존한다. `diagnose.py`의 출력 그룹은 최상위 상태 키를 잘못 골라 빈 값이지만465회 동일 재생·대표 좌표 수집은 정상이며, 후속 `comparison_details.jsonl`에 판단별 결과가 있다.
