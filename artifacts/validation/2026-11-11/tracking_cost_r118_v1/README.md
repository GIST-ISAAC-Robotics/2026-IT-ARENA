# 현재 관측 추종 후보의 Jetson 비용

2026-11-11. r117 저장 후보가PC에서 p95 25.22ms를 사용해, 실행 연결 전에Jetson에서 최소 비용을 확인한다. 경로 운송·Pure Pursuit·점유·현재 관측 외곽을 구분해 계측한다. 느린 계획과 빠른 추종 분리를 성립시키려면 이 최소 구성도 목표 주기 안에 들어와야 한다.

입력은r114 원 실패 궤적과r117의동결 소스/기대 출력466개다. [묶음 명세](bundle_manifest.json)로 원격 전송과 실행 전후SHA를 검사한다. 새 격리 폴더만 사용하며 센서/구동장치·전원·OS·운영ROS 설정을 변경하지 않는다. 후보 명령값과 상세 진단의 플랫폼 차이를 따로 비교하고, 입력 복원과 투영의 비용을 분리한다. 단계 wrapper 비용은 포함한다.

실물 저장CPU 재생이며 실제 주행/동시ROS 처리/센서 취득시각/50Hz 실시간의 증명이 아니다. 원 지연 주행 실패는 그대로 보존한다. 결과 전 채택하지 않는다.

## 계측 결과

Jetson `/usr/bin/python3`·NumPy1.21.5·Humble 환경에서 한 번 실행했다. 158개 동결 파일과 원 입력의 실행 전후SHA가 일치했다. 466호출 중420개가 후보 적격이며, PC와 자격·이유·속도·조향 차이는0개다. 상세 진단34호출 차이는 주로 질의/가림 표본 개수에서 관측했으며 명령 차이와 구분한다. 플랫폼별 작은 좌표 차이가 중복 제거 개수에 영향을 주었을 가능성이 있으나 원인을 확정하지 않았다.
