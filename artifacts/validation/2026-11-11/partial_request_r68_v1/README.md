# r68 부분 관측 요청 속도 교착 수정

## 근거와 변경 범위

앞선 [r67 native 시험](../c1_native_sampling_v1/README.md)은42.06m에서 대기했다. 측정속도0·경로요청약0.994m/s인 상황에서 약5° 결측의 검사 속도가 높아져 기존 숨은 폭/속도 조건을 거절했다. 요청0인 출발 대기 호출은 통과하고 다음 양수 요청은 거절하는 순환이었다.

운영 수정 전 `probe_partial_requested_speed.py` 저장 입력 비교는1,733판단의 기존 출력이 전부 일치했다. 요청만0.2m/s로 먼저 제한하는 후보는 원0→양수364회, 원양수→0은0회였다. 마지막 요청은0.2m/s·`bounded_lateral_metric_missing`이었다. 원 차량의 궤적을 그대로 넣은 반사실 비교이며 실제 완주 증명이 아니다. 상세 입력/출력은 Git 제외 `build/c1_native_sampling_2026_11_11/partial_requested_speed_compare.json`에 보존한다.

구현은 `PartialObservationPolicy.requested_speed`로 상태·거리값을 바꾸지 않는 요청 후보를 만들고, 기존 `_partial_command`가 **max(줄인 요청, abs(측정속도))**로 기존 관측 정책을 한 번만 평가한다. 측정속도는 자르지 않으며, 정면 결측·가까운 반환·사라진 장애물·구조 그림자·시각 무결성·독립 보호층은 그대로다. 3°를 넘는 결측의 기존 측방 운용 후보에만 요청 상한을 적용한다. 모든 결측을 허용하는 조건이 아니다.

기존 v4 선택 조건 안의 수정이며 새 옵션/상태기를 늘리지 않는다. 이전 소스 두 파일은 `before_r68.zip`, 계보는 [`partial_request_r68_sha256.json`](../../../../config/tests/partial_request_r68_sha256.json)에 보존한다. 기어비는 기존8.970588235:1이며81T 변경은 후속 대기다.

## 검증 순서

1. 균일·CW·CCW 입력과 실제속도0/.25/.61m/s, 정면/근거리/전체결측/장애물 소실 반례 및 관련 회귀.
2. 기존 영점0 균일 입력의 판단 재생 비교. 차이가 있으면 이유를 분석하고 통과로 바꾸지 않는다.
3. 위 결과를 검토한 뒤 같은 native 단독 프리셋으로 제한 주행1회. 44.64m 코스의 기존 종료 진행목표46.64m·접촉·노면·STOP/정상종료·입력해시 판정은 유지한다.

관련206회귀·r68 출처 계보1검사가 통과했다. 기존 균일 입력1,586판단의 속도·조향·기존 진단은 모두 동일했다. 전체 객체 비교는1,585/1,586 일치였으며 seq1776에 요청 전후 속도 진단키2개가 추가되어 원 검사 `passed=false`로 보존했다. [별도 차이 감사](legacy_diagnostic_delta.json)에서 기존 필드 전체의 동일성을 확인했다. 판정선을 바꾸거나 원 실패를 통과로 덮지 않았다.

## 제한 주행 결과와 남은 정지

`run_once.py`의1회 결과는 **42.63m/0랩·최고2.867917m/s·접촉0**, 종료 목표46.64m 미달이다. 횡오차RMSE0.0431m·p95 0.0975m다. 원천 취득504/508/512점과 순차 취득 감사가 통과했고 입력551개가 불변이다. 소프트웨어 STOP 응답·MCU software_stop·pose 정착·Gazebo 정상종료·잔류0을 확인했다. 이전42.06m 정지보다 조금 더 진행했지만, 비결정적 시뮬1회끼리의 거리 차이를 일반적인 성능 향상으로 확대하지 않는다.

이번 마지막 정지는 속도가 아니라 **고정 각도 구분**이다. 45.2초 기록의 실제속도0·무반환약4.97°에서 추정 숨은 현32.7mm는기존50mm 안이지만, 무반환7개가28.9~33.2°라30° 경계를 넘었다. 인접 반환은약9.7~10.6m이며 경로는좌전방으로계속관측됐다. 직전 회전 중에는운동 보정 뒤 정면으로 들어와 `forward_gap_too_wide`도 발생했다. 먼 평행 벽 사이 도로 방향에서 최대거리 밖으로 나간 광선이라는 해석이 기하와 부합하지만, 실제 C1의 무반환을 자유공간이라고 단정하는 근거는 아니다.

후속 저장 대조는 단일 연속 결측에 **같은50mm 숨은 폭·최대속도·인접반환1m·이전 장애물 기억·0.2m/s 요청 상한**을 적용하면서 고정30° 구분을 없애는 후보다. 작은 저반사 물체를 놓칠 잔여 위험과 저속 한계를 명시하며, 아직 운영 반영/새 주행은 하지 않았다. 원 실패·판정은 보존한다.

실행 시작UTC부터 report 파일시각까지약514초, sim44.54초의 비는약0.087이다. 시작·STOP/cleanup·보고서작성도 포함한 외부 근사이며,5000광선 센서 생성만의 비용이나 주행 중 정밀RTF가 아니다. Jetson 제어 판단 비용과 구분한다.
