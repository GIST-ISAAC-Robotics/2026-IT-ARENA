# 현재 추종 후보의 원 경로 수명

2026-11-11. r117은 계획을 계산한 기준시각에서300ms를 허용했지만, 기준시각 이전에 이미 관측한 경로의 실제 나이가 더 크다. 현재 스캔이 새롭다는 이유만으로 과거 도로 경계가 갱신되지는 않는다. 이 차이를 그대로 두고 ROS 연결하지 않는다.

`normal.path_source_s`를 FOLLOW 실제 선택 경로와 함께 보존하고 기존 `memory_ttl_s`·운동 이력/최대 이송·경로 끝 제동 계산에 반영한다. 출처가 없는 경로의 시각은 최신 스캔으로 추측하지 않는다. r117 원 후보/결과는 덮어쓰지 않으며 같은 저장 입력의 후보 수 차이를 기록한다.

이 단계는 운영 미연결 연구 후보의 오류 수정이다. 현재 관측·독립 보호·상태 전이/실제 이전 명령 환류가 완성됐다는 뜻이 아니다. 기준시각, 원 경로 관측시각, 현재 명령 생성시각은 다음 실행 설계에서도 분리한다.

## 결과

13검사를 통과했다. 같은 저장466호출에서 기존420후보 중105개가 실제 원 경로 수명을 넘긴 것으로 거절되어 **315후보**만 남았다. 전체 경로 만료106개에는 기존에도 기준시각 만료였던1개가 포함된다. [수명 대조](contract_comparison.json)·[전체 집계](comparison.json)를 보존했다. 원 입력 SHA도 같다.

현재 추종을 추가하는 것만으로 지연 문제가 해결되지 않으며, 원 관측을 실제로 갱신하지 않고 시각만 다시 붙이는 초안은 채택하지 않는다. 다음에는 이미 선택된 경로와 현재 관측의 필요한 대조를 기존 보호층과 분담하고, 느린 판단이 진행되는 동안 실제 이전 출력이 변하는 계약을 설계한다. 기본 구현/명령 발행은 아직 바꾸지 않았다. 최초 WSL 서비스 오류 뒤 승인된 Ubuntu-24.04만 재시작해 검사를 수행했다.
