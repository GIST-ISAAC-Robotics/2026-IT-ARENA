# 현재 관측 외곽 계산의 비용 분해

2026-11-11. r118 Jetson 저장 재생에서 `motion_region`이 중앙49.01ms·p95 85.35ms를 차지했다. 50Hz 추종에 연결하기 전 원인을 분리한다. r117 후보와 r114 원 실패 입력을 그대로 사용하고, 질의 생성·미관측 교차·광선 지지·가림 분류의 시간을 측정한다. 같은 검사 기준·공간 표본·판정값을 보존하며 런타임에는 연결하지 않는다.

`profile_saved.py`는 계측/프로파일 오버헤드를 포함하므로 절대 성능 대신 비용 비율과 출력 동일성을 판단한다. 입력과 기존 결과는 덮어쓰지 않는다. 최적화가 필요하면 해당 연산만 별도 후보로 대조한 뒤 채택 여부를 결정한다.

## 결과

466호출·420후보와 전체 출력이 r117에 일치했다. 원 입력SHA도 동일하다. `motion_queries` 합계3.452초, `depth_support` 3.074초, `masked_only` 0.536초였고, 해당 관측 외곽 전체는 약7.120초였다. 질의 생성과 광선 지지가 각각 주요 비용이며 일부 다각형 교차만 고쳐서는 충분하지 않다. 광선 지지에 전달된 질의는 합계2,422,633개, 한 호출 최대9,740개다. [상세 프로파일](profile.json).

다음은 [r120 묶음 계산](../tracking_batch_r120_v1/README.md) 비교다. 검사점이나 관측 조건을 줄이지 않는다. 첫 실행은 Python 진입 전 WSL `E_UNEXPECTED`로 실패했고, 승인 범위의 Ubuntu-24.04만 복구한 뒤 최초 실제 계측을 완료했다. 각각 `build/r119_geometry_profile.log`·`build/r119_geometry_profile_v2.log`에 남겼다.
