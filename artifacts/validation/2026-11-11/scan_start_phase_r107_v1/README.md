# 첫 판단 제출을 센서 회전에 맞추기

2026-11-11. [r105](../async_corner_r105_v1/README.md)는 코너 적합을 보완했지만20.14m에서 측방 GUARD로 정체했다. [보존 시각 감사](phase_audit.json)는r104/r105의 실제 완성 스캔→제출이 각각8/58ms임을 보인다. 첫 회전 위상이0.052/0.002초로 달라도 신호 뒤 첫제출은7.66초였다. 100ms 제출 간격이 그 처음의 불필요한 대기를 계속 유지했다.

선택형 `process_candidate`에서만 신호/STOP·세대 경계 직후 이미 받은 스캔의ID를 기억하고, **다음 새 스캔을 받은 첫50Hz 콜백**에서 최초 계산을 시작한다. 이후 진행1건·스캔당1회·100ms 판단과 양수 결과 적용 간격, 원 참조시각과300/200ms 만료·명시STOP을 유지한다. 내부 계산의`dt=.1`과 누적 이동/조향 예산을 바꾸지 않는다. 기본 동기 실행은 그대로다.

첫 출발/재정렬 때 최대 한 회전과 수신 콜백 간격만큼 기다릴 수 있다. 수신 분리/스캔 기반 일반 스케줄러 완성이나 가변RPM 해결로 설명하지 않는다. 장시간 계산 뒤 재정렬은 별도이며, 늦은 계산 취소가 경로 기억을 잃는 문제도 남는다. 이 변경만으로GUARD정체가 해결된다고 가정하지 않는다.

변경 전2파일은 [before.zip](before.zip), 계보는 [등록](../../../../config/tests/scan_start_phase_r107_sha256.json)에 보존했다. 초기위상5개·STOP/세대·실제ROS노드 등을 포함한40회귀와 계보1검사·빌드·설치본 해시 검사를 통과한 뒤 같은 시설·두앞차·nativeC1 조건1회를 수행했다.

## 제한 주행 결과

[통합 판정](two_actor_run1/combined_assessment.json)은 **42.63m·최장저속3.842초로 미완주**다. r105의20m 정체 지점은 통과했으나, 첫 제출 시점 변화에 따라 궤적도 달라져 GUARD 문제가 일반적으로 해결됐다고 보지 않는다. 첫 원천 정렬·683취득/수신·607결과 적용·폐기0과 양수 적용 간격을 확인했다. 원천 첫 광선→판단 기준시각 중앙117ms, 적용시각 중앙137ms다. 실제 계산 wall-clock 중앙31.80ms/p95 83.03ms는 이PC의 느린 시뮬 시계에서 얻은 값으로 Jetson 실시간 처리 검증이 아니다.

접촉/노면이탈·벌점0, STOP 정착0.5초·변위0.0232mm, 정상종료·자식5개 exit0·잔여PID0·스냅샷/소스 불변을 확인했다. 원 report의 `no_permanent_stall`, `final_gap`, `full_lap` 실패를 보존한다. 마지막 정지는 전방 무반환 분류 `forward_gap_too_wide`가 주로 발생했으며 측방 GUARD 정체와 별도다. 다음은 해당 무반환들의 실제 각도·폭·이동 중 방향을 저장 입력에서 분리한다. Jetson 비용 지연 주행은 아직 보류다.

## r105 정체의 별도 저장 입력 진단

[guard_probe.json](guard_probe.json)은 원 607판단을 변경 없이 재생하면서 정체 전후 5개 판단의 현재 경로·측방 예측·관측 질의를 회수했다. 출력 불일치는 0이다. seq645에서는 경로가 있고 전체 이동 질의의 일반 미관측은 0이지만, GUARD 진입 기준 대비 왼쪽 접근 예측이 14.20mm라 기존 10mm 제한을 넘었다. 추가 접근 영역 1,073개 표본 중 현재 자유 관측은 267개이고, 나머지 806개는 장착 가림 영역이어서 별도의 현재 관측 대안도 거절됐다. 이를 실제 장애물 806개나 라이다 고장으로 해석하지 않는다.

[guard_caps.json](guard_caps.json)은 원 판단을 유지하고 선택한 7개 시점에서 같은 전체 검사를 더 낮은 기존 목표속도 후보로 별도 대조한 결과다. 0.25m/s는 1/7개, 0.15m/s는 7/7개에서 허용됐다. 측정속도를 낮춰 가정하거나 간격·가림·누적 접근 제한을 늘리지 않았다. 다만 원 궤적을 고정한 진단이며, 계속 진행했을 때 누적 접근이나 다른 정체가 생기지 않는다는 증거는 아니다. 실제 실행 코드는 아직 이 추가 재검사를 사용하지 않는다. 첫 제출 위상을 정렬한 r107 주행 결과를 먼저 보고, 필요하면 기존 저속 후보의 재검사 범위를 넓힐지 판단한다.
