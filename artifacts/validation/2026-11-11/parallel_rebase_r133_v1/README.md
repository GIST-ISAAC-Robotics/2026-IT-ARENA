# 선택된 직선 차로 유지 경로의 현재 재계산 후보

2026-11-11. r130의 가장 긴 저속 구간은 양수 평행 명령이 계속 나왔지만 현재 재계산 대상이 아니어서 보호층 명령 만료가 반복됐다. FOLLOW 안에서 실제 선택된 `parallel_hold_follow`/SOLO·GUARD의 직선 경로를 현재 센서로 대조하는 명시 시험 후보를 마련한다. 우회/추월 모드·0명령은 대상이 아니다.

현재 차체 중심으로 경로를 다시 옮겨 옆차 쪽으로 복귀하지 않고, **당시 선택된 경로 그대로** IMU/엔코더 이력으로 운반한다. 원 경로 원천300ms·같은 세대/벽/직전 발행각, 현재 점유·제동·원 속도 상한·기존1cm 반응/제동 횡이동 한도를 유지한다. 현재 속도도 잘라내지 않는다. 원 부분 관측 허가나 특별 측방 이탈 예외를 추가로 넓히지 않는다. 기존 독립 보호층을 통과해야 한다.

현재 재계산의 Jetson 수신 경합이 해결된 것은 아니므로 운영 기본 연결과 별개다. 원 실패·r126/r130 후보는 보존하고, 관련 검사와 저장 입력의 제한된 계산부터 확인한다.

## 실행 전 검증과 제한

관련61검사(기존 baseline·배송·평행·연결 포함)를 통과했다. [저장 대조](comparison.json)는 원r130의 현재 baseline148개가 그대로 같고, 선택된 평행 경로179개가 같은 입력 및 명시20ms ZOH 조건에서 양수였다. 속도/원천 수명/횡이동 위반0이다. **20ms 대조는 실제 도착 시각의 센서 기록이 아니며**, 더 긴 계산 지연을 이 결과로 검증했다고 보지 않는다.

이 근거로r130과 같은60초·두 상대·시설·측정 지연 조건을1회 실행한다. 원시각/원 경로 수명·TTL·현재 점유·보호·노면/접촉·STOP/종료 기준을 그대로 둔다. r126의 baseline 모듈도 원시 소스 목록에 함께 동결한다. 초기 연결 검사 호출의Windows CRLF 셸 오류는 실행 전에 바로잡았으며 최초57검사와 최종61검사를 구분한다.
