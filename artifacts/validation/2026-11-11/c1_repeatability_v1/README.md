# C1 짧은 원시 기록의 반복성 진단

2026-11-11. [11/10 실측](../../../../docs/sensors/C1_HARDWARE_2026_11_10.md)의 Standard 10Hz 원시 기록 두 개를 다시 읽었다. 센서를 움직이거나 새 취득을 하지 않았다. 기울어진 실내·가림 환경이며 거리 정답이 없으므로 **정확도 교정이나 일반적인 잡음 모델 식별이 아니다.**

[제조사](https://www.slamtec.com/en/c1/spec)는 Range Accuracy ±30mm, Ranging Resolution 15mm를 표기한다(11/11 확인). 이 표기만으로 매 측정에 서로 독립인 ±30mm 균등 잡음이 발생한다고 해석할 수는 없다. 현재 `lidar_uniform30_delay50_jitter20.json`은 해당 분포와50±20ms 추가 지연을 적용한 **별도 스트레스 가정**이다. 실패를 없애기 위해 이 프로필을 바꾸지 않았다.

## 방법과 결과

[`audit_c1_repeatability.py`](../../../../scripts/audit_c1_repeatability.py)는1° 간격 목표 방위에 가장 가까운 **원래 광선**을 고른다. 먼저 최근접 광선을 선택하고 무효 거리를 거절하므로, 무반환을 옆 유효점으로 채우지 않는다. 0.15–3m·전체 스캔40% 이상 관측된 방위를 비교했다. 최근접 각도 허용0.1/0.2/0.3°를 모두 보존했고, 아래는0.2°다. 연속 차이는 실제 각도 차이0.08° 이하인 연속 스캔 쌍만 사용한다.

| 기록/선택 | 방위 칸 | 중앙값 대비 절대 잔차 p50/p95 | 연속 거리 차이 p50/p95 |
|---|---:|---:|---:|
| 초기 Standard10 / 관측률만 |181|1.25 /22.25mm|0.75 /4.75mm|
| 초기 Standard10 / 완만한 중앙 형상 |108|1.00 /15.00mm|0.75 /3.00mm|
| 최종10Hz 복원 / 관측률만 |182|0.75 /4.25mm|0.75 /3.00mm|
| 최종10Hz 복원 / 완만한 중앙 형상 |119|0.75 /2.625mm|0.50 /2.00mm|

각각102스캔·51,924/51,936측정이며 원시 CSV 네 파일 해시가 전후 동일했다. [초기 결과](standard10.json)·[최종 결과](final10.json)에 선택 조건·전체 통계를 보존했다. 완만한 형상은 스캔별 잔차가 아니라 방위별 중앙 거리의 이웃 차이≤20mm로 선별했지만, 이 선별 역시 모서리/가림을 제외하므로 전체 장면의 대표값은 아니다. 0.1°에서는 관측률 조건을 만족한 방위가 거의 없어 유효한 광범위 대조가 되지 않는다.

관측률만 선별한0.2° 집합의 연속 비교 수는2,069/1,999쌍이다. 최대 차이는 초기2,384mm·최종16.5mm로, 초기 기록에는 큰 거리 전환도 남아 있다. 따라서95백분위를 오차 상한으로 쓰지 않는다.0.3°에서는 각각3,446/3,303쌍·95백분위5.0/3.5mm였으며 선택 각도에 따른 차이도 보존했다.

독립 균등 ±30mm의 이론 표준편차는17.32mm, 연속 두 값의 절대 차이95백분위는46.58mm다. 위 제한 기록의 연속 산포는 이보다 작았다. 초기 기록의 장시간 잔차가 연속 차이보다 큰 이유에는 장면/센서 미세 이동·각도 표본 차이·저주파 변화가 섞일 수 있으며, 이번 자료만으로 원인을 확정하지 않는다. 절대 거리 편향·검은 표면·주행 진동·각도 오차·실제 트랙 재질은 여전히 미측정이다.

## 적용 범위

시뮬 잡음 상수나2cm 재관측 기준은 변경하지 않았다. [r86](../retained_structure_r86_v1/README.md)의3cm 민감도 비교도 정지를 뒤로 미뤘을 뿐 해결하지 못했으므로 채택하지 않았다. 다음은 같은 시설/두 상대/native 입력에서 추가 스트레스 주입을 제외한 기준 주행이다. 이는 원천 입력 연결의 기능 대조이며, 실측 잡음 모델이나 실제 C1 성능 검증으로 부르지 않는다. 강한 잡음/지연에서의 실패는 별도로 유지한다.
