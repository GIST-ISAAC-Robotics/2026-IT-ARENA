# 시설+C1 잡음 정체의 경로·측방 중재 분리

[11/10 원 실패](../../2026-11-10/combined_c1_facility_v1/README.md)는20.21m·최장저속10.464초로 끝났다. 원시 결과와 당시61T 감속비를 보존한다. 새81T 주행과 혼합해 단일 변수 대조로 해석하지 않는다.

## 분석 순서

기록된36–54초901판단 중 정지838개다. 그중722개는 `follow_boundary_unconfirmed`로 기초 경로를 확보하지 못했고,76개는 경로 재확인 대기,40개는 `guard_curve_rejected_toward_left`였다. 따라서 측방 감속상한부터 풀어도 주된 실패를 해결하지 못한다.

현재 센서 기하의 제한 샘플에서 오른쪽 벽2.5m 이상은 보이나 경로 원점 거리0.143–0.160m가 기존0.12m 앵커 조건을 넘었다. 간헐적으로 다른 적합 경로는 조건을 만족했다. 이 차이가 실제 차량의 중심 이탈인지, 잡음/가림에 따른 경로 표현 변화인지 아직 분리하지 않았으므로 허용오차를 바로 늘리지 않는다.

1. 저장 센서4개에 대한 실제 반환·좌우 경로 후보를 도식화한다. 새 자유 공간이나 지도 입력을 생성하지 않는다.
2. 실패 당시 `source_snapshot.zip`199파일을 별도 폴더에서 읽고 저장 판단 일치를 확인하며, G1 기초 경로와 측방 중재 직전 출력을 분리한다.
3. 원인이 확인되면 관측 경로의 연속성과 실제 점유/측방 여유를 유지하는 수정부터 검토한다. 과거 실패한 광범위 `traffic_boundary_refresh_trial` 옵션은 단순히 켜지 않는다.

## 저장 분석 결과

[센서 그림](sensor_geometry.png)·[기하](geometry.json)4개를 확인했다. 경로가 오른쪽/왼쪽으로14cm 벗어난 것이 아니라, 일부 후보의 **첫 점이 차량 앞 약14–15cm에서 시작**하여 원점과의 최소거리가0.12m를 넘었다. 그림의 원점 연결 점선은 거리 진단이며 주행 경로/미관측 보간이 아니다. 잘린 앞부분과 잡음 적합의 관계를 추가 분리한다.

[원 판단 재생](internal_summary.json)은3,040판단 모두 일치했고36–54초의 새로운 스캔180개에서 내부 단계를 수집했다. 보관199파일/ZIP은 불변이다. `queued_log`·`drive_feedback` 두 모듈은 원ZIP에 없어 현재 소스에서 읽었으므로 **완전히 독립된 과거 소스 복원은 아니다.** 재생 불일치0과 이 의존 한계를 함께 기록한다. 상세 입력/경로 열은 로컬 `internal_details.json`에 보존한다.

아직 새 교통 주행이나 제어기 변경은 수행하지 않았다.
