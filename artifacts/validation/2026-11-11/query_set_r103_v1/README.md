# 외곽 질의점의 같은 집합 정렬

2026-11-11 실행 전 등록. r102에서 긴33판단의 정렬 자체가0.384초였으며, 그중 약0.365초는 `np.unique(axis=0)` 내부 structured 정렬이었다. 큰 이동 외곽 질의점 생성의 세 호출만 같은 사전식 순서의 lexsort+동일값 제거로 바꾼다. 시간 계측은 PC 프로파일 값이며 Jetson 성능 향상 수치가 아니다.

유한 float64 2열에만 빠른 경로를 적용한다. 반올림·샘플 수 축소·인접점 병합을 하지 않고, 음의0/비유한 값/다른dtype는 원 NumPy 경로로 처리해 대표 원소를 보존한다. 관측·점유·보호·TTL·차체/노면 설정은 바꾸지 않는다. 변경 전3파일은 `before.zip`에 보존했다.

수용 조건은 좌표/순서/바이트 대조, 관련 관측·이동영역 회귀, r98의610판단 전체 동일, 같은 입력의 한 번 CPU 대조다. 효과가 작더라도 이 자료를 남기고 여러 미세 최적화를 끝없이 추가하지 않는다. 비동기 결과의 운영 적용은 별도 미완료다.

## 결과

관련9파일700검사와 출처 successor1검사가 통과했다. 최초 WSL `E_UNEXPECTED`는 원 로그로 보존하고 Ubuntu-24.04만 재시작한 뒤 새 로그에서 검사를 마쳤다. PC는610전체 출력 동일이다. Jetson은610명령 동일·541전체 출력 동일이며, 나머지69개 진단 불일치 순번은 r98과 같다. trace·입력·동결 소스는 불변이고 회수 파일 해시도 일치했다. 원격 계측 프로세스는 남지 않았다.

| 같은 입력의 전체 판단 비용 | 중앙 | p95 | 최대 |
|---|---:|---:|---:|
| r98 Jetson | 82.31ms | 181.84ms | 396.20ms |
| [r103 Jetson](jetson_stages.json) | 82.44ms | 177.74ms | 374.24ms |
| [r103 PC](pc_stages.json) | 20.41ms | 45.97ms | 103.66ms |

중앙값의 개선은 없고 긴 구간 비용도 소폭 감소에 그쳤다. 단일 대조의 실행 변동까지 제거한 인과 추정은 아니다. 변경은 집합/순서 동등성을 확인한 범위로 유지하되, **이 미세 최적화 묶음은 종료하고 수신 분리의 실제 연결로 이동한다.** 100ms 마감·실시간 주행·GPU 사용을 증명한 결과가 아니다. 원시 상세 판단은 기존 정책대로 로컬에만 보존한다.
