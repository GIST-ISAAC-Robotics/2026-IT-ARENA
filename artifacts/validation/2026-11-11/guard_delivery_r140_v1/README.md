# GUARD/RELEASED의 판단과 명령 수명 분리

2026-11-11 완료한 r136/r139 저장 기록만 읽었다. 제어기 변경·새 주행은 아니다. 각 trace의 footer·순서·무손실 종료와 원본 SHA 불변을 확인했다.

| 기록 | 적용된 양수 GUARD | 도착 후 명령 수명 중앙/최소 | 명령 나이만 초과한 양수 GUARD 표본 | 같은 RELEASED 표본 |
|---|---:|---:|---:|---:|
| r136 | 14 | 100/40 ms | 12 | 38 |
| r139 | 37 | 60/20 ms | 38 | 26 |

r139의 원천 만료 폐기는 5개다. 도착 자체가 허용된 결과도 원 기준시각부터 200 ms를 적용하므로 다음 판단 전 명령이 만료될 수 있다. 이는 현재 재계산이 SOLO 기본/선택된 평행 경로에만 적용되고, GUARD 기본/RELEASED 기본 경로에는 적용되지 않는 것과 일치한다. 그래도 코너 자체의 미관측 거절이 많으므로 모든 정체를 배송 지연 탓으로 설명하지 않는다.

분석은 적용 후보 시각과 스캔 발행 시각을 재구성한다. 보호 콜백의 실제 수신 시각·그 순간의 최신 입력을 직접 기록한 것이 아니며 미해명 표본을 강제로 명령 만료로 분류하지 않는다. 현재 재계산된 명령은 새 기준시각을 사용해 분리했다. 원시 판단/주행 결과는 변경하지 않는다.

다음은 같은 원 경로를 현재 센서/IMU·엔코더로 다시 검사하는 저장 후보다. 이전 GUARD의 측방 기억과 접근 기준, 원 경로 수명, 현재 점유·미관측·마스크 이동을 보존해야 한다. 새로운 측방 위협이나 상태 경계를 확인하지 않고 SOLO로 바꿔 처리하거나 timestamp만 새로 붙이는 방식은 채택하지 않는다. 공백 허용 폭 확대와 새 실제 주행은 이 분석에 포함되지 않는다.
