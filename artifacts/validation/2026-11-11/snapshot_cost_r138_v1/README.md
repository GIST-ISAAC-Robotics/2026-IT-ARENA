# 기록 입력 복사의 비용 비교

2026-11-11 실행 전 등록. r137 실제 ROS 진단에서 현재 입력 snapshot에 중앙14.39 ms가 들었다. `MeasurementScan`의 불변 데이터에 `asdict` 중간 deep copy와 최종 freeze 복사를 겹쳐 수행하고, 수천 개 내장 숫자에도 일반 Real 타입 검사를 반복한다.

후보는 내장 숫자 직접 처리와 불변 측정 객체의 최종 복사 한 번만 사용한다. 원시 배열·NaN/±Inf 구분·역회전 부호·시각·모든 이력·기록 형식·소유권을 그대로 유지한다. 배열을 줄이거나 이력을 삭제하지 않고, 기록을 끄거나 비동기 손실로 옮기지 않는다. 운영 소스는 아직 바꾸지 않는다.

원r128의316개 현재 입력·출력과 source 불변을 동일 ROS 격리 조건에서 비교한다. 전력/클럭/GC 설정은 그대로이며 실제 취득 시각·전체ROS 실시간과 구분한다.
