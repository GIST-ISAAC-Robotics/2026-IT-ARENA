# 판단 만료 시 계산 직전 상태 복원 재대조

2026-11-11. r139 최초 만료 seq581(31.82초 제출) 직전에는 양쪽 `passed=true`였다. 만료 뒤 reset으로 양쪽 `unknown/passed=false`가 됐고 왼쪽은 코너에서 다시 해제되지 않았다. 새로운 측방 반환 없이 생긴 전이를 원 입력으로 비교한다.

r113에서 같은 전상태 복원 방식은 명령 개선 0으로 미채택이었다. 이번에는 다른 원인 전이가 관측된 r139 저장 입력으로만 다시 비교한다. 기준선은 r139 그대로, 후보는 계산 직전 전체 상태 복원, 계산 후 상태 유지는 경위 확인용이다. 만료된 출력은 세 방식 모두 발행하지 않는 것으로 처리하며 STOP/센서/세대 경계 reset은 유지한다. 아직 ROS 연결·새 주행·운영 채택은 없다.

## 결과와 판단

r139 기준선 468판단을 모두 동일 재생했다. 계산 직전 전체 상태 복원은 원래 적용 후보 463개 중 정지 224→256개, 양수 239→207개였다. 정지→진행 1개보다 진행→정지 33개가 많았다. 계산 후 상태 유지도 진행→정지 33개로 개선 근거가 없었다. 복사 비용은 WSL 중앙 5.15 ms·p95 5.72 ms·최대 54.88 ms다. 원 trace SHA는 불변이며 만료 명령 5개는 계속 미적용으로 취급했다.

**복원 후보는 이번에도 미채택한다.** 최초 초기화 전이가 있었음은 확인됐지만, 그것만 없애도 실제 주행이 좋아진다고 볼 수 없다. 저장 입력의 향후 측정속도·조향은 원 주행 결과이므로 이 비교를 새 주행 성능으로 확대하지 않는다. 이 경로로 같은 실험을 반복하거나 실행기 복원 프로토콜을 추가하지 않는다. 이후 현재 유효 입력으로 선택 경로를 재검사하는 후보는 별도로 비교한다.
