# GUARD 코너의 저속·작은 차체 외곽 무반환 후보

2026-11-11 실행 전 범위. r135 좌표 분석 결과 실제로는 구조물 가림 밖의 후측방 무반환이었다. 구조물 가림으로 바꿔 부르지 않는다. 현재/직전 조향의 전체 반응·제동 외곽에서 미관측으로 남은 표본이 차체 옆면 밖1 cm 이내이고 앞/뒤 범퍼 사이일 때, 실제 속도와 목표가 모두0.35 m/s 이하인 별도 후보를 비교한다.

원시 +inf, 양옆 실제 반환0.6 m 이상, 가까운 점유/팽창 부재, 개별/총 공백6도 이하와 질의 위치에서 팽창을 포함한 공백 폭5 cm 이하를 요구한다. 전방100도 안 결측, 구조 마스크/NaN/짧은 반환, 실제 측방 위협이 보이는 경우는 이 후보에서 제외한다. 부분 관측 기본 허가와 GUARD 누적 접근·같은 명령의 전체 이동 검사·마스크 꼬리 검사를 유지하며 GUARD/통과 기억을 지우지 않는다.

기존 후반1 mm/3도 조건을 단순히 넓히는 기본값 변경이 아니라, 원 정체의 물리적 위치/속도에 맞춘 **명시 시험 후보**다. 1 cm·저속·6도/5 cm는 기존 운용 위험 선례의 조합이며 실물 안전 인증값이 아니다. 숨어 있는 가는 돌출물·반사 실패·동적 접근·차체/운동 오차는 남는다. 관측 수와 unknown 상태를 자유 공간으로 변경하지 않는다.

먼저 회귀와 저장 입력에서 실제 변화·반례를 확인하며, 근거가 없으면 주행을 반복하지 않는다. r135의 구조 가림 연결 후보는 이 후보에 포함하지 않는다.
