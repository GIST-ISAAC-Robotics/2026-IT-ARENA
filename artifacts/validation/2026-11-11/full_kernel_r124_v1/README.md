# 전체 판단에서의 C++ 후보 비용

2026-11-11. r122의 결과는 새 현재 추종 후보 비용이므로 기존 실제 판단기의 개선율로 그대로 사용할 수 없다. 구조 분리 전에 같은 r114 원 입력466개를 실제 판단기로 한 번씩 재생해 Python 기준과 C++ 관측 연산 후보를 대조한다. 추가 연산 튜닝은 하지 않는다.

상태 reset·원 순서·파라미터와 원천 입력을 보존하고 명령뿐 아니라 전체 출력을 비교한다. 입력 복원/투영/판단을 포함하지만 ROS·영상·독립 보호 동시 비용은 포함하지 않는다. 운영 미연결이며 실패 기준·TTL·센서·물성을 바꾸지 않는다. 같은 함수 참조만 격리 프로세스에서 바꾸며 설치 파일을 수정하지 않는다.

기존의 확장 추종 후보와 실제 판단기의 병목이 같은지 확인해 다음 설계 범위를 정한다. 기대보다 개선이 작으면 작은 최적화를 반복하지 않고 현재 추종과 느린 경로 계산의 인터페이스로 이동한다.

## 결과

PC와Jetson 각각466판단에서 Python/C++ 전체출력·명령 차이0개를 확인했다. PC는 당시 기록과도 모두 같았고, Jetson은 두 조건 모두 기존 sequence757/758/763 차이가 남았다. 이 차이는 후보 때문에 새로 생긴 것이 아니지만 전체 플랫폼 동일이라고 하지는 않는다. 원 입력·격리161소스 해시는 보존했고 측정 프로세스가 종료됐다.
