# 광선 지지 내부 연산의 C++ 대조

2026-11-11. r120 배열 묶음만으로는 약14% 개선에 그쳤다. 상태 전이·공간 검사 범위를 바꾸지 않고, 가장 큰 단일 계산인 `depth_support` 안의 후보 광선 각도/거리 연산만 C++로 비교한다. 입력 후보 창·원래 인덱스 순서·반환/가림 구분·인접성·원점 중첩과 여유 조건은 그대로다.

명시 빌드: `g++ -std=c++17 -O3 -fPIC -shared -ffp-contract=off evaluate.cpp -o <새 build 경로>/libdepth.so`. fast-math·GPU·추가 Python 패키지는 사용하지 않는다. 숫자 판정선 또는 동률에 가까운 질의는 원래 NumPy 계산으로 되돌린다. 이 fallback 여유는 통과 판정선 변경이 아니다.

기존 독립 광선/순환/결측·운동 경계 회귀와 r117의466개 저장 입력 전체 출력을 비교한다. 표본을 줄이거나 결과를 대충 반올림하지 않는다. 격리 연구 사본이며 운영 코드·기본 설정·ROS 연결은 변경하지 않는다. 충분한 비용 이득과 정확성 근거가 없으면 채택하지 않는다.
