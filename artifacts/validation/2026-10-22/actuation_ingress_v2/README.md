# 수신 연결부 v2 — 검사 앱 공유 사례 추가

v1과 같은 수신 연결부에 ESP-IDF/호스트가 공유하는 연결부 사례 10개를 추가했다. 기존 공유 코어 사례 20개와 별도 마스크로 보고한다. 호스트 sanitizer·크기 최적화 및 기존 정책/envelope/API 회귀 **52 passed**, exit 0, 해시 불변. 개수가 v1과 같아도 검사 앱 내용은 다르며 둘을 합산하지 않는다.

공유 10개는 연결·ARM·DRIVE·단절 STOP·재연결 상태 유지·옛 DRIVE 거절·CLEAR·별도 ARM·입력 한도 고장·링크 복구만으로 재무장하지 않음을 확인한다. `tests.log`, 소스 스냅샷·해시를 보존했다. 대상 빌드는 [IDF v4](../actuation_idf_smoke_v4/README.md)이고, 대상에서 실행한 것은 아니다.
