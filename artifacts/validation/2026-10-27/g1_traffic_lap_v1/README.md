## 최초 분리된 원인과 다음 순서

전체7,789판단에서 부분 관측 상태는 `fully_observed`였다. 새 관측–GUARD 결합의 효과를 이 주행으로 입증하지 않는다. 후반 정지에서는 기본 경로가 `follow_boundary_unconfirmed`, 회랑 후보가 `long_outer_reference_unavailable`이고, 선택기는 `parallel_hold_baseline_unavailable`로 멈춘다. 지속 정체 표본에서 독립 보호층은 대부분 `clear`다. 이는 무반환 허용이나 보호 간격을 먼저 바꿀 근거가 아니다.

정지 직전/정지 후 입력을 복원해 양측 실제 벽 후보·관측 길이·앵커·기억 경로를 분리한다. 왜 경계가 재확정되지 않는지 확인한 뒤 수정 범위를 정하며, 같은155초 주행을 이유 없이 반복하지 않는다. 별도 M5 밀집 출발 입력 비교는 계획대로 진행한다. 원래 실패와 시험 당시 소스는 그대로 보존한다.
