# 공식 신호 연결의 다음 시험

2026-10-27. 정지 영상 시제품을 실제 출발로 오인하지 않기 위한 초기 설계. 실행 제어기는 아직 변경하지 않았다.

**후속 정정:** 사용자 지적 후 공식 자료를 재확인하니 제작 설명은 가로 빨강4세트·초록1세트이고, 아래의 세로 겹침은 SDF의 도로 방향 배열에서 발생했다. 따라서 아래의 방향 추적 시제품 연결을 보류하고, [가로 배열 정정본](../official_signal_orientation_v1/README.md)에서 기존 검출기를 먼저 확인한다. 아래 내용은 원인 확인 전 설계 기록이며 현재 구현 순서가 아니다.

## 확인된 실패

공식 배치에서 빨강 네 등이 하나의 세로 성분으로 합쳐진다. `OfficialStartSignal`의 개별 원형/가로4열 가정이 맞지 않으며, 단순히 카메라를 높여도 검출기 가정은 남는다. 같은 정지 영상을 반복한 `GrowthProbe`는 단계별 새 픽셀 위치로 방향을 복원하지만 `array_equal` 확인 때문에 작은 영상 이동/경계 변화에 취약하다.

## 첫 연결 후보

1. 영상 시각·최소 서로 다른 프레임 확인·단일 작업 큐·새 경기 reset은 기존 계약을 유지한다.
2. 적색 연결 성분의 시간적 변화로 배열 축을 구한다. 신호판이 화면에서 가로/세로인지 미리 고정하지 않는다. 단계 확인에 입력 영상의 작은 평행 이동/픽셀 경계 변화는 허용하되, 실제로 늘어난 부분의 면적·중심 이동 방향/간격·기존 점등 영역 유지 조건을 함께 검사한다.
3. 첫 광원→총4개까지 단계가 검출되면 다음 위치의 초록만 확인한다. 다른 위치의 초록·빨강 잔존·단일 깜박임·단계 건너뜀·프레임 만료/되감기·밝기 팽창을 반례로 둔다. 정지 영상만으로 실물 노출/흔들림 강건성을 주장하지 않는다.
4. `official_4red_candidate`를 조용히 덮어쓰지 않고 명시 새 후보로 분리한다. 기본 임시 신호와 기존 후보의 판단은 유지한다. 새 후보는 현재 단계에서 `green-only` 출발을 허용하지 않으며 이 한계를 표시한다.

## 실제 전환 확인

현재 공식 위치/방향의 신호와 뒤쪽 .20/.30 m 카메라 후보에서, 동일 Gazebo 실행 중 OFF→빨강1→2→3→4→초록으로 렌즈 재질을 바꾼다. 제어기는 RGB와 촬영 시각만 읽는다. 적용 신호/시각은 평가기에만 저장하고 신호 변경 실패·프레임 누락·촬영과 적용 간격을 따로 기록한다. 실시간 영상 처리와 차량 실제 출발은 후속 단계로 구별한다.

처음에는 자차 정지·각본 상대 높이 .25 m 조건에서 영상 전환만 확인한다. 정상 연결 뒤 가림·경기 운영 reset·명시STOP과 차량 출발을 이어간다. 공식 자료의 설치 방향을 실제 제작품 확정으로 쓰거나 카메라 높이를 기구 확정값으로 채택하지 않는다. 전체 신호를 놓친 뒤 초록만 노출된 경우는 신호판 형태/위치의 추가 관측 근거를 따로 설계해야 한다.
