# 부분 관측과 GUARD 연결 대조

2026-10-27. 최신 원격 main `6c3706a`의 [현행 계획](../../../../docs/DEVELOPMENT_PLAN.md)에 따라 시작했다. 아래는 기본 비활성 후보의 고정 입력 비교이며 폐루프 주행·실차 안전 검증이 아니다.

## 재현과 수정

[probe](probe_coupling.py)는 정지한 자차의 벽·옆차·전방 상자에서 실제 각도별 첫 반환을 합성한다. 지도/물체 정답은 광선 생성에만 사용하고 제어기에는 스캔과 정지 운동 입력만 준다. 25호출 중 뒤 17호출에 결측을 넣으며 계산된 명령대로 자차를 움직이지 않는다.

| 입력 | 기존 선택기 OFF | 기존 선택기 ON | 수정 선택기 ON |
|---|---:|---:|---:|
| 벽만, 결측 없음 | 17 양수 | 17 양수 | 17 양수 |
| 옆차, 결측 없음 | 17 양수 | 17 양수 | 17 양수 |
| 단일 측방 결측 | 17 양수 | 17 양수 | 17 양수 |
| 옆차 + 반대쪽 단일 결측 | 17 양수 | **0 양수** | **17 양수, 0.35 m/s 이하** |
| 옆차 + 넓은 결측 | 0 양수 | 0 양수 | 0 양수 |
| 옆차 + 단일 결측 + 가까운 전방 상자 | 0 양수 | 0 양수 | 0 양수 |

원본: [수정 전](coupling_before.json), [수정 후](coupling_after_trigger.json). 기본 G1의 `bounded_side_missing` 승인은 참인데, 선택기의 평행 후보가 `fully_observed`만 받기 때문에 GUARD에서 정지했다. 이는 문서에서 예상한 결합 공백의 고정 입력 재현이다.

`pass_release_trial.py`의 GUARD 후보 진입 분기만 확장했다. G1이 이미 허용한 부분 관측·정상 양수 출력·정책 속도 상한을 확인한 뒤 **같은 G1 경로와 조향**을 기존 GUARD 검사로 보낸다. 평행 이동한 경로에 기존 관측 승인을 복사하지 않는다. 기존 0.35 m/s 제한, 측정 속도가 더 크면 그 속도로 예측하는 조건, 누적 측방 접근, 현재/직전 조향의 실제 이동 영역, 가까운 점유·미관측/마스크 검사를 유지한다. 부분 관측은 자유 공간 측정으로 바꾸지 않으며 통과 기록·GUARD 상태도 유지한다.

수정 후 `side_gap` 마지막 판단은 `GUARD/guard_baseline/guard_curve_observed_motion`이며 실제 이동 영역426표본에서 미관측0, 원시 결측1개는 그대로다. 이를 결측 일반 허용이나 후방 위험 해결로 확대하지 않는다. 전방 소수 결측이 G1에서 허용되어도 GUARD 이동 영역이 미관측이면 여전히 정지한다.

## 검사와 출처

- 관련 [회귀](related_v1.log): 160통과. 새 실제 광선 좌우 대칭·기본OFF·전방 장애물·넓은 공백·실제 이동 영역 미관측·입력 오류·알려진 소실 장애물 래치·판단 기록 재생을 포함한다.
- 런타임 변경은 선택기 1개다. `config/tests/partial_observation_r0_sha256.json`의 해당 의존 해시와 후속 계약의 부모 해시만 갱신했다. 변경 전 전체 상태는 Git `6c3706a`, 입력/결과 소스 해시는 각 JSON에 남긴다.
- 최신 제어 후보의 [전체 회귀](full_regression_v1.log): **5,937통과·19건 건너뜀**. 전후 `src/scripts/tests/config` 964파일 해시에서 변경0이다. 이후 전체 랩 평가기 확장은 별도 묶음이며 이 숫자로 그 새 평가기까지 검증했다고 하지 않는다.

## M5 입력 어댑터의 첫 실패

기존 [10/26 정지 배치](../../2026-10-26/m5_grid_follow_v1/README.md)의 `ranges`는 마스크 전 값이다. 이전 진단은 `scene_from_scan` 안에서 후방60도를 가렸지만 새 raw 계약은 `/scan`에 이미 가려진 후방 값이 들어와야 한다. 첫 [현재 구성 비교](m5_current.json)는 전부 `follow_partial_scan_scene_mismatch`로 거절됐다. 차량/경로 실패로 해석하지 않는다.

첫 스크립트는 [사본](probe_m5_saved_before_mask.py)에 보존했다. [수정 어댑터](probe_m5_saved.py)는 기존 센서의 같은 후방60도 마스크만 raw에 `+inf`로 표현한다. 원본 거리를 덮어쓰거나 미관측을 유효점으로 만들지 않는다.

[수정 결과](m5_current_masked.json)는 16배치×2구성×20호출이다. 단독6칸은 양쪽 구성 모두10/20 양수였다. 2·3·5대의 나머지10개 위치는 모두0/20 양수다. 첫 칸2는 G1의 `follow_gap_hold`/선택기의 `parallel_hold_unchanged_gap_hold`, 다른 칸은 `follow_boundary_unconfirmed`다. 현 후보의 일반 결측 처리가 밀집 배치의 기하 간격과 경계 미확인까지 해결하지는 않았다.
