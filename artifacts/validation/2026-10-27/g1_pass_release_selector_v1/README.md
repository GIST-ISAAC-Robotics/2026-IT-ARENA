# 옆차 통과 뒤 기존 G1 복귀: 저장 입력과 상태 선택 비교

2026-10-27. 센서 장면·G1 출력·현재 위치 유지 후보·속도/직전 조향을 사용한다. `actor` 위치는 아래 재생 요약의 사후 평가 주석에만 사용하며 선택기의 입력이 아니다. 여기서 만든 명령으로 차량을 움직인 결과는 아니다. 선택형 운영 연결·새 주행은 [후속 기록](../g1_pass_release_integration_v1/README.md)으로 구분한다.

## 처음 확인한 문제와 변경

Claude의 [인계](HANDOFF.md) 당시 시제품은 전방 통과와 후방 소실을 구분하는 상태가 있었으나, 실제 해제에서는 그 구분을 사용하지 않았다. 뒤로 사라진 위협과 시간 단절 뒤 `unknown`도 빈 옆 띠 두 번만으로 해제됐다. 비정상 속도/출력 수치도 일부 통과했다. GPT가 추가한 최초 상태 검사에서 **7통과·11실패**를 확인했다. 원본은 `claude_handoff_source.zip`과 [실패 로그](state_contract_before.log)에 보존한다. 운영 노드에 연결된 적은 없다.

1. `benign` 전방 통과만 해제 가능하도록 바꾸고 수치·시간 검사를 추가했다. 빈 표본이나 양의 자유 관측이 전혀 없는 띠를 허용하지 않는다. 상태 검사29개는 통과했지만 좌우 저장 입력에서는 **해제가 0회**였다([run1](run1_replay/summary.json)).
2. 원인은 제동 중 유한 음수 모터축 속도 −0.04862 m/s까지 시간 단절처럼 처리해 양쪽에 영구 `unknown`을 만들었기 때문이다. 해당 순간의 정지 출력은 유지하되, 같은 센서 시각 계열의 관측 기억은 보존하도록 분리했다. **31상태 검사 통과**, 좌우 각각6.72초에 해제로 전환했다([run2](run2_replay/summary.json)).
3. 큰 복귀 이동의 마스크 표본을 과거 통과 여부로 허용하지 않게 했다. 기존 원호 표본과 얇은 미관측 방향 교차에 더해 차체 모서리 x/y 극점 자세도 포함했다. **38상태 검사 통과**, 좌우 해제 시각은 같지만 일부 큰 복귀 출력을 평행 후보로 돌렸다([run3](run3_replay/summary.json)). 자세 표본 사이 연속 영역의 증명은 아니다. 인계의 “2 cm 표본이 mm 흔들림을 놓칠 수 있다”는 우려를 확정된 누락 원인으로 쓰지 않는다.

각 수정 전 소스는 `run1_source.zip`·`run2_source.zip`·`run3_source.zip`, 실행 전후 해시는 `run*_input_hashes.json`에 보존했다. 단위 검사 첫 재실행은 Python `-I`의 `PYTHONPATH` 무시 때문에 수집 오류였으며 별도 [로그](state_contract_after_bootstrap_error.log)로 남겼다. 테스트 실패 수에 합산하지 않는다.

## 순차 광선 합성 장면

[run1 합성 결과](run1_sensor_scenarios/summary.json)는 500광선·0.1초 순차 취득·후방60° 마스크·고정 직선 운동의 **7장면 통과**다. 벽만 있을 때 SOLO, 좌우 전방 통과 후 RELEASED, 2물체 중 하나 잔류·뒤로 사라짐·옆 잔류에서는 GUARD를 확인했다. 경로 후보 출력은 상태 선택을 격리하려고 고정했고, 실제 선택 출력에 따라 물체나 자차가 움직이지 않았다. 차량 동역학이나 충돌 회피 성공의 증거가 아니다.

## 남은 한계

- `rear`·`unknown` 기록은 다른 물체의 통과로 지우지 않는다. 시간 단절 뒤 재관측/세션 재시작 정책과 곡선에서의 진행성은 후속 과제다.
- 통과 확인의10 cm·옆 띠15 cm·fresh2회·작은 횡이동1 cm·2 m/s² 제동은 개발 시험값이다. 실물 거리 오차·물체 급변·제동 보장은 아니다.
- 동일한 측방의 여러 물체와 재접근 반례는 제한 합성·상태 검사다. 후방 가림에 새로 들어온 차의 부재를 증명하지 않으며, 실차 안전·전체 다중 차량1랩 완료로 확대하지 않는다.
- 다음 단계는 기본 OFF 선택형 연결을 검사한 뒤 기존 좌우 일정에서 실제 복귀·앞차 간격을 비교하는 것이다. 기존 점유 여유·15 cm 평가선·원시 실패를 소급 변경하지 않는다.
