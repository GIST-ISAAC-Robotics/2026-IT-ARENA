# 현행 G1 밀집 출발 — 실행 전 등록

2026-10-27. [직전 정지 비교](../g1_observation_guard_v1/README.md)에서 나타난 정지가 상대차 출발 뒤에도 유지되는지 분리하는6초 이상 운동 비교다. run1을1회 실행했다. 공식 신호 영상은 입력하지 않고 출발 허가 이후의 움직임만 비교한다.

## 고정 조건

현재 G1·v4·corner-distance·per-ray·회랑·평행/통과/GUARD 설정은 `g1_guard_curve_v1/run2_corner/follow_decisions.jsonl`의 설정 헤더에서 가져온다. 모터축28카운트·15:1·65 mm, C1순차500점/10 Hz, IMU208 Hz, 모터100 Hz와2 ms 전송을 유지한다. 제어기는 현재 소스를 사용하므로 전체 랩 시행 당시 변경/동결 기록과 함께 읽는다.

| 이름 | 자차/배치 | 상대 각본 |
|---|---|---|
| front_wait | 2번, 2대 | 앞에 있는 차만 출발; 옆줄의 해당 상대는 정지 |
| front_neighbor_depart | 2번, 2대 | 앞 또는 다른 줄의 상대가 .5초부터 .5 m/s |
| rear_neighbor_depart | 5번, 2대 | 같은 규칙으로 앞/옆 상대가 먼저 출발 |
| middle_five_depart | 1번, 5대 | 앞/다른 줄은 출발, 같은 줄 뒤 상대는 정지 |

최대6초,5.6초부터 명시0명령이다. 자차는 이상 bicycle로 즉시 속도/조향을 따르므로 실제 가속·서보·슬립·차체 제동을 검증하지 않는다. 모든 광선은 취득 시각별 자차/상대 위치에서 첫 교차를 합성하고, 제어기에는 지도/칸번호/상대 정답을 전달하지 않는다. 기존 보호층의 실제 계산을 별도 운동 이력·독립 partial-policy 상태로 호출한다. ROS 프로세스/통신 독립성 증명은 아니다.

## 판정과 출처

원시 각도별 거리·호출 입력/출력·모터 카운트·소스 사본/해시를 보존한다. 전방 이력과 raw scan에 동일 후방60도 마스크를 사용한다. 기존 M3 옵션은 섞지 않고 기존 함수/파일을 monkeypatch하지 않는다. 시험 전용 `probe.py`는 기존 시험기의 사건 순서·광선·기구 계산을 재사용한 별도 G1 루프다.

진행량과 첫 진행 시각은 탐색 결과로 보고하고 미리 정한 진행 성공을 강요하지 않는다. 정지 상대 대조의 대기는 실패로 단정하지 않는다. 무결성은270호출·원시 소스 불변·명시0·기존1 ms 연속기하 감사로 분리한다. 실제 겹침·벽 접촉·세 바퀴 이상 표본이 나오면 그 사례를 종료해 실패를 보존한다. 바퀴 패치 기반 기하 감사는 전체 랩의 바퀴 중심 감사와 다르며 공식 벌점 판정을 대신하지 않는다.

이 결과로 실제 M5 출발이나 전체 교통 주행이 완료되는 것은 아니다. 시야가 열린 뒤에도 같은 제어기가 막히는 경우 해당 원인부터 분석한다.

## 실제 물리 출발로 연결할 때의 조건

10/27 [신호 방향 재확인](../official_signal_orientation_v1/README.md)에 따라 빨강4세트·초록1세트의 가로 배열을 사용한다. 기본 임시3등을 공식 신호 성공으로 세지 않는다. 현재 출발 검출기는 RGB·촬영 시각만 받고, 신호 발생기의 적용 상태는 각본/평가기에만 전달한다.

첫 물리 시험은 현재 G1의 같은 경로/독립 보호·단일 모터축 구성을 유지하면서 제한된 출발 장면으로 만든다. 앞/옆 상대의 정지 대조와 먼저 움직이는 대조를 구분하고, 출발 전 이동·첫 진행 시각·실제 진행·접촉·바퀴별 노면·명시STOP·정상 종료를 따로 기록한다. 약3 cm의 초기 그리드 간격은 이미 합성 비교에 포함되므로 임의의15 cm 성공선을 붙여 출발 자체를 불가능하다고 판단하지 않는다. 반대로 초기 간격이 존재한다는 이유로 실물 오차 여유가 확보되었다고 주장하지 않는다.

신호 높이는 회의록의40 cm가 어느 지점 기준인지 미확정이다. 따라서 기존1.2 m 모델의 상향 카메라를 그대로 연결하지 않고, 광원 높이 가정·수평 카메라 높이/위치를 명시한 시험본을 사용한다. 가림으로 빨강 전체를 보지 못한 사례와 정상 순차 점등을 본 사례를 분리한다. 현재 정책에서 초록만 본 경우의 대기는 정상적인 보수적 결과이며, 이를 출발 규정 자체가 요구하는 의무로 쓰지 않는다. 높이·배치는 실물 제작 확정안이 아니다.
