# 관측된 옆차 통과 뒤 G1 복귀 — 선택형 연결 시험

2026-10-27. 기본 `g1_pass_release_trial=false`다. `g1_parallel_hold_trial`·부분 관측 v4·corner-distance·점별 점유·판단 기록·시뮬레이션 G1을 명시한 구성에서만 연결한다. 독립 보호층·차량 크기·물성·센서/모터축 설정·원래 판정선을 바꾸지 않는다.

## 초기 실행 전 설계와 판정

- 측방 반환을 본 적 없는 `SOLO`는 기존 G1 출력을 쓴다. 위협이 보이면 `GUARD`에서 현재 위치를 유지하는 직선 후보를 선택한다. 어느 물체인지 분류하거나 정답 actor를 입력하지 않는다.
- 마지막 위협 반환의 최후단이 자차 앞면보다 10 cm 이상 앞에 있었고 이후 서로 다른 두 스캔에서 옆면 띠의 마스크 외 영역이 양의 자유 관측이면 `RELEASED`가 된다. 뒤·옆으로 사라진 위협이나 시간 연결을 잃은 기록은 빈 띠만으로 해제하지 않는다.
- 해제 뒤에도 현재/직전 조향의 반응·제동 구간을 검사한다. 모서리 횡이동 1 cm 이내의 작은 움직임과 더 큰 움직임을 구분한다. 초기run1/2에서는 큰 움직임의 차체·바퀴 외곽과 차체 모서리 좌표 극점을 포함한 표본 중 현재 차체 밖의 미관측·마스크를 모두 거절했다. 거절 시 평행 후보로 돌아간다. 아래run4에서는 작은 가림 뒤 모서리의 분류를 변경한다.
- 유한 음수 엔코더 속도에서는 정지 명령을 유지하지만 그 사실만으로 관측 시계가 끊겼다고 처리하지 않는다. 시각 역행·세대 변경·비정상 수치·센서 중단은 별도로 취급한다.
- 후방 가림 뒤 새 차량의 접근, 물체 모양·물성·실제 제동, 표본 자세 사이 연속 영역은 미입증이다. 과거 통과 기록은 현재 자유 공간 관측의 대체물이 아니다.

먼저 관련 회귀·선택 OFF 기존 판단 동일성·빌드·고정 소스를 확인한다. 새 주행은 기존 왼쪽 피추월과 같은 일정으로 **1회** 수행한다. 같은 실패를 그대로 반복하지 않는다.

비교 대상은 [이전 좌우 직선 시험](../g1_parallel_lane_v1/README.md)이다. 12초 진행·최장 정지·접촉·측방 최소 간격·바퀴 중심 노면·명시 STOP·정상 종료·판단 동일 재생을 각각 기록한다. 기존 150 mm 측방 및 앞차 최종 1.2 m 기준을 보존한다. 새 관측 전환이 실제로 선택됐는지, 지나간 뒤 기존 G1로 따라붙는지 확인하며 전체 랩·곡선 병렬주행·실차 검증으로 확대하지 않는다.

저장 입력의 RELEASED 구간에서는 baseline/parallel/fault 선택이 좌99·우187번 전환됐다. 실제 선택대로 움직인 입력이 아니므로 주행 진동으로 단정하지 않는다. 새 주행에서 조향 전환·입력 나이·중단 이유를 함께 확인한다. 관측되지 않은 큰 이동을 승인하는 유지 지연은 추가하지 않는다.

### run1: 정지 중 조향과 복귀 후보의 교착

[첫 주행](run1_left/report.json)은 진행 **0.23998 m**, 앞차 이동 중 최장 정지 **10.526초**, 최종 앞차 간격 **5.33924 m**로 실패했다. [전후 요약](run1_summary.json). 센서/시험 유효성·기록636판단 동일 재생·명시STOP·14개 정상 종료·소스959파일 불변은 통과했다. 벽/앞차/옆차 접촉 메시지0, 옆차 표본 최소70.185 mm·swept70.171 mm로 기존150 mm 비교선은 실패다. 바퀴 중심8,228표본은 모두 도로 안이었다.

측방 GUARD3.92초→RELEASED6.72초 전환은 정상적으로 발생했다. 그러나 6.82–6.90초 G1이 재개 확인 대기 중 속도0으로 조향을0→0.2801 rad까지 먼저 돌렸다. 7.02초부터 복귀 명령의 뒤 모서리 영역이 가려져 거절되었고, 대안 평행 후보도 **직전 조향0.2472 rad에서0.35 m/s를 명령할 때** 예측 횡이동이1 cm를 넘으므로 거절했다. HOLD가 직전 조향을 유지하여 빠져나오지 못했다. 이전 저장 입력에서는 자차의 직전 조향이 계속 직진 근처였으므로 드러나지 않은 폐루프 전이 문제다. 단순 판정선 때문에 실패한 것으로 해석하지 않는다.

### run2 전 변경과 확인할 것

- RELEASED에서 기존 G1이 정지를 요구하면 속도0을 유지하면서 직전 조향도 유지한다. 실행하지 못할 중앙 복귀를 대기 중 먼저 조향하지 않는다.
- 선택기 전용 평행 fallback은 현재/직전 조향의 같은1 cm 횡이동 제한을 만족하도록 목표 속도를 낮출 수 있다. 현재 측정 속도 자체가 이미 제한을 넘으면 감속 완료를 가정하지 않고 HOLD한다. 점유·제동·재개2회·간격 조건은 그대로다. 기존 선택기OFF 평행 옵션은 바꾸지 않는다.
- 정지 조향 고착·실제 속도를 무시한 재개 반례를 추가했다. 관련330회귀·선택OFF648판단 동일 재생·2패키지 빌드 뒤 같은 왼쪽 일정으로1회 재확인했다. run1 실패는 보존한다.

### run2: 도로 방향과 차체 방향의 혼동

[두 번째 주행](run2_left/report.json)은 **0.640 m 진행·7.086초 정체·최종 앞차 간격4.943 m로 실패**했다. [요약](run2_summary.json). 정지 중 선행 조향 고착은 해소됐지만, 복귀 중 차체가 비스듬해진 뒤 직선 후보의 도로–차체 상대각5° 조건에 걸렸다. 8.22초 이후 직선 적합 잔차는 약0.14 mm인데도 `reference_not_straight`가 반복됐다. 동시에 기존 G1의 복귀는 가려진 뒤 모서리 표본 때문에 거절되어 정지했다.

기록636판단 동일 재생·소스959파일 불변·명시STOP·14개 정상 종료·잔존0을 확인했다. 접촉0, 바퀴 중심8,231표본 도로 안, 측방 표본70.179 mm·swept70.159 mm였으며 원래150 mm 비교선은 실패다. 앞차가 계속 움직이는 동안 자차가 정체했으므로 단순히 최종 간격 판정이 엄격해서 실패한 결과가 아니다.

### run4 전 변경: 곧은 도로의 방향과 작은 뒤 모서리 이동 분리

- RELEASED에서 큰 전방 복귀를 검사할 때 가려진 **뒤 모서리 표본의 현재 차체 밖 침범량**을 따로 계산한다. 차체 둘레1 cm 이내·전면 가림0·일반 미관측0일 때만 제한 위험으로 허용한다. 마스크 표본은 관측된 자유로 바꾸지 않으며, 뒤/옆으로 소실된 기존 위협이나 시간 단절은 여전히 해제하지 않는다. 이는 ADR0027의 작은 후방 이동 재검토에 따른 개발 후보이며 새 뒤차 부재를 증명하지 않는다.

### run4: 왼쪽 교착 해소와 남은 원래 실패

프로파일러/최소 묶음22회귀,2패키지 빌드 뒤 [왼쪽run4](run4_left/report.json)를 실행했다. 진행 **3.879600 m**, 최장 정지 **2.122초**로 진행·정체 판정은 통과했다.
