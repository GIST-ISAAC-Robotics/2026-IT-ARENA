# 코너 진입 시점·이력·정면 사전 조건 대조

실제 구동/운영 변경 없이, 보존 월드의 벽 시각 메시와 노면 충돌체로 가상 LiDAR 관측을 만들었다. 센서 배치·500광선·12 m·후방 마스크·실제 저장 입력의 취득 나이·0.2 m/s 목표·기존 보호 조건을 유지했다. 지도는 생성기와 사후 노면 평가에만 사용했다.

| 단계 | 근거 | 결과 |
|---|---|---|
| 정지 단일 스캔 | [정지 격자](../g1_visibility_grid_v1/run/report.json) | 126위치/방향, 756조향 조건. 관측과 표본 노면을 함께 통과한 91조건은 모두 직진 |
| 일정 원호 이동 이력 | [이 폴더 보고서](run/report.json) | 42위치×6조향. 0.2 m/s의 이상적 과거 원호에서 최근 2스캔을 순차 취득·완전 투영. 과거 노면 거절 0, 미래 노면 거절 22. 회전도 통과하지만 중간 3개 진행거리의 54조건은 모두 정면 사전 거절 |
| 정면 사전 거절 분리 | [shadow 보고서](../g1_front_gate_shadow_v1/run/report.json) | 해당 54조건에서 이 if-return만 제외한 독립 함수로 대조. 53건 실제 외곽 관측 불충분, 1건 현재 반환 장애물. 새 통과 0, 원본 출력 재현 차이 0 |

- [관련 34회귀](pytest.log), [shadow 18회귀](../g1_front_gate_shadow_v1/pytest.log), 각 스크립트 종료 코드 0·입력/소스 전후 hash 일치.
- 이동 v1은 계산 뒤 보고서의 `sources` 변수명 충돌로 실패했다. [오류](../g1_visibility_moving_v1/probe.log)와 소스를 보존하고 hash 사전 이름을 분리해 v2를 실행했다. 시험 통과선/운영 조건은 바꾸지 않았다.
- 0기준 자세 대조의 유한 273반환 차이는 중앙 .88 mm, p95 74.68 mm, 최대 523.94 mm다. 무응답 4인덱스는 기록과 일치한다. 가까운 정답 자세/최종 z, 양면 정적 시각 메시와 GPU/순차 취득의 차이가 있으므로 정밀 센서 재현으로 해석하지 않는다.
- 이동 이력은 각 위치/각도에 **이미 해당 곡률로 이동해 왔다고 가정**한다. 정지에서 그 상태에 도달할 수 있는지, 위치별 후보끼리 연결되는지, 실제 운동 보정 오차/차량 동역학/다중 차량 안전은 검증하지 않았다.
- 미래/과거 차체 외곽은 1 cm 거리 표본, 기존 노면 면적 1 cm²·벽 겹침 1 mm² 보고 기준이다. 연속 안전 증명이 아니다. 제한 격자에서 통과 후보를 찾지 못했다고 모든 가능한 경로가 불가능하다고 결론내리지 않는다.

운영 기본값·프런트 조건·무응답 데이터·독립 보호층은 유지한다. 상세 해석은 [G1 보고서 §14](../../../../docs/autonomy/G1_OBSERVATION_ENVELOPE_2026_10_16.md#14-1019-진입-위치와-이동-이력--정면-거절의-분리)를 따른다.
