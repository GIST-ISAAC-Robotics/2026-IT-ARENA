# 로컬 정리와 저장소 삭제 대비 사본

이 문서는 첫 정리 당시 기록이다. 후속 [GitHub 보존·로컬 대용량 정리](../../../../docs/reports/ARCHIVE_AND_CLEANUP_2026_11_15.md)에서 보존 원문을 원격으로 이관하고 로컬 사본/미선정 상세로그를 정리했다. 아래 로컬 경로의 현재 존재를 보증하지 않는다.

[정리 결과와 보관 묶음 해시](summary.json). Git에 추적되는 자료나 독립 원본 시험 기록은 삭제하지 않았다.

| 정리 대상 | 파일 수 | 용량 |
|---|---:|---:|
| Python·시험 캐시 | 1,261 | 25.5 MB |
| 영상 합성용 중간 JPEG | 13,731 | 1,069.6 MB |
| 보존 tar.gz의 멤버와 바이트가 같은 압축 해제 사본 | 527 | 618.5 MB |
| 합계 | 15,519 | 1,713.6 MB |

파일별로 Git 미추적 여부, 작업 폴더 내부 경로, 재분석 지점이 아닌 일반 파일, 검사 후 크기·수정 시각 불변을 확인했다. 압축 해제 사본은 멤버별 SHA-256이 일치하는 경우에만 제거했다. 중간 JPEG를 지우기 전에 완성 영상 8편과 재렌더 입력 묶음의 해시를 확인했다.

저장소의 상위 폴더에 **`IT ARENA evidence backup 2026-11-15`**를 별도로 만들었다. 그 안에 Jetson에서 회수한 시험 폴더·커널 시간창과 노트북의 `stage-path.txt`·빌드 로그·실물 시험 기록, CAD/미사용 UNO Q 배포본, 선정 시뮬레이션 7개와 r544 실패의 실행 자료, 중복 삭제 대상의 보존 tar.gz 6개를 두었다. 압축 묶음의 각 멤버 또는 tar.gz의 SHA-256을 대조했다. 삭제 목록·원래 경로·검사 결과는 해당 폴더의 `manifest.json`과 `cleanup-receipt.json`에 있다.

이 사본은 같은 디스크에 있는 **체크아웃 삭제 대비**이며, 모든 로컬 전용 데이터를 복제한 것은 아니다. 선정 범위 밖의 원시 센서 bag·상세 수신 로그·실험 원본은 Git 제외 경로에 남아 있다. 원격 공개는 [회수된 사건의 진단 증거](../esp32_jetson_recovery_v1/README.md)와 [영상 재렌더 입력·대표 소스](../replay_preservation_v1/README.md)로 한정했다.
