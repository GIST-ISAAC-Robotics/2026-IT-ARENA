# GitHub 보존 완료 후 로컬 정리

[보존·복원 안내](../../../../docs/reports/ARCHIVE_AND_CLEANUP_2026_11_15.md) · [삭제 집계와 원격 해시 확인](summary.json). 원문9묶음을 비공개 GitHub 릴리스에서 다시 다운로드하여 전체 SHA-256을 대조한 뒤 로컬 사본을 정리했다.

Git 제외 파일65,146개, 77,465,561,102 bytes를 제거했다. 저장소 밖 공용 런타임 캐시를 가리키는 junction은 연결만 해제했고 대상 파일은 삭제하지 않았다. 상세 삭제 목록은 비공개 증거 저장소에 보존한다. 이 정리는 새 실차/시뮬레이션 시험이 아니다.
