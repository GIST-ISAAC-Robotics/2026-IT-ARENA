# 영상 재렌더 입력과 대표 소스 보존

- [영상 재렌더 입력 ZIP](showcase_render_inputs.zip): 영상 8편에 사용한 7개 실행의 파일 57개. Gazebo 평가 자세와 신호 상태, 차량·월드 SDF, 시각용 지형 OBJ를 당시 파일 바이트·경로 그대로 보존했다. 센서 bag·수신 로그·제어 판단 전체는 포함하지 않았다.
- 시설물 포함 완주 **r475**: [동결 소스 묶음](r475_sources.zip) · [원 결과 JSON](r475_report.json).
- 실측 조향 적용 후 정체 **r544 attempt2**: [동결 소스 묶음](r544_attempt2_sources.zip) · [원 결과 JSON](r544_attempt2_report.json). 공개 영상과 다른 시험이며 당시 실패 판정을 그대로 보존한다.
- [파일 목록과 SHA-256](manifest.json): ZIP 멤버 전수를 당시 촬영 메타데이터 또는 소스 대조에 기록된 해시와 확인했다. 동결 소스 ZIP 두 개에는 당시 스냅샷에 들어 있던 자체 수치 커널 ELF 사본이 포함된다.

재렌더할 때는 별도 체크아웃에서 원 경로를 유지해 압축을 푼다. [영상 제작 절차](../../../videos/2026-11-15/README.md)의 Gazebo·렌더 플러그인·텍스처 경로 등 환경 조건도 필요하다. 이번 정리는 자료 복원과 무결성 확인까지 했으며 새 폐루프 주행이나 GPU 재렌더는 실행하지 않았다.
