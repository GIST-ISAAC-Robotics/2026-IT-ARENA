# 출력 없는 ROS 센서 기록 제한 검사

WSL Jazzy localhost 전용 도메인의 합성 IMU/scan만 발행했다. MCU/제어기/Gazebo/장치 없음. `system/`은 `/clock` 없이 각 80개·32,320 B CDR를 기록하고 원본 바이트/헤더를 대조했다. 각 센서 header 0은 20개, 역전은 39회였다. 이를 수신 시각으로 덮어쓰지 않았다. `sim_no_clock/`은 simulation 시계를 선택했으나 `/clock`이 없으므로 미완료·exit 1·저장 표본 0으로 남았다. 양쪽 모두 기존 제어기 재생기에서 거절한다.

각 `report.json`에 구독 목록·실행 명령·종료 코드·각 판정을 기록했다. 원시 bag/receipt는 로컬 보존·Git 제외다. 완료는 기록기 내부 무결성이지 센서 시각·값·실물 안전 승인 아님. 소스는 `sources/`에 보존했고 전후 불변이다. 앞선 v1 환경·v2 시험기 준비 실패는 별도 보존했다.
