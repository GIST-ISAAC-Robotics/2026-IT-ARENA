# 출력 없는 제어 주기 결합 — 1차 검사

**188통과·실패/건너뜀 0, exit 0**, 실행 전후 소스 해시 차이 0 B. 제어 주기 20사례를 ASan/UBSan과 크기 최적화에서 검사하고 기존 PI/계약/공유 검사를 함께 실행했다.

수신기와 PI의 같은 주기 검사, STOP/세대/0목표 초기화, 명령/피드백 만료, 주기 누락/중복/역행, 준비 상실·산술 고장 고정, 명시 CLEAR→ARM, 허가 관측을 건너뛴 ACTIVE 거절을 확인했다. 모든 시각/엔코더/준비값은 합성이며 출력 드라이버·실제 MCU·Gazebo·Jetson은 실행하지 않았다.

[스크립트](run_checks.sh), [검사 로그](tests.log), [종료값](checks_exit.txt), 원시 소스/해시를 보존한다. 이후 추가한 실제 환산값 사용·감속 등 5사례와 변이체 검사는 이 실행에 포함되지 않는다.
