# 10/23 계획 재검토·누적 main 게시 점검

- 이번 신규 개발 범위는 GPT·Claude의 토의와 계획/현황 문서 갱신이다. 새 주행·빌드·코드 회귀를 실행한 결과가 아니며, 함께 게시하는 누적 코드의 결과는 각 날짜의 보고서/원시 근거를 따른다.
- 공식 `MANUAL.md`와 main/latest를 GitHub API로 읽기 전용 재확인했다. main=`b27f94730b869837a804a3088447103d6b35b87e`, latest=`v2026.10.10`으로 기존 확인과 동일했다. 웹 도구는 접근 실패여서 API를 사용했다. 이슈 댓글 전체를 이번에 다시 감사했다는 뜻은 아니다.
- `local_only_manifest.json`: 새 게시 후보 중 소스 압축·생성 실행 바이너리·배치 메시 **455파일, 약 301.08 MiB**의 경로·크기·SHA-256. 파일은 삭제하지 않고 로컬에 보존한다. 기존 추적 원본·실패 기록·사진·활동 기록은 제거하지 않았다. 원시 센서 bag/상세 수신 기록도 기존 제외 정책을 따른다.
- `.gitattributes`에 빠져 있던 10/17·19·21·22·23 증거 경로의 줄바꿈 자동 변환 제외를 추가했다. 실행 당시 바이트/해시를 Git 게시 과정에서 바꾸지 않기 위한 조치다.
- 공개 후보의 토큰/개인키 고정 패턴을 파일명만 출력하도록 검색했으며 일치가 없었다. 모든 종류의 비밀을 검출하는 보증은 아니다. 실물 접속 자격 증명은 게시 대상에 포함하지 않는다.
- 크기·원시 기록·ELF·로컬 보존 확인은 `audit_publication.ps1`과 그 출력, 문서 링크/최종 diff는 별도 게시 전 검사로 확인한다. 파일 존재·정적 검사를 실제 차량 안전이나 전체 코스 합격으로 확대하지 않는다.
- 최종 계획·현황·질문·활동·검토 안내 9문서의 상대 링크/앵커 423개를 확인했다(`doc_links.json`). 기존 HTML 명시 앵커도 검사에 포함했다. 독립 검토 이력과 반려안은 [검토 묶음](../planning_review_v1/README.md)에 보존했다.
