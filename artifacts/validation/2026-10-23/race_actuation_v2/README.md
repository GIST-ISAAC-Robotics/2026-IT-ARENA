# B3/A1 결합 사건 계약 — 제한 검증 완료

- 관련 **131개 통과(3.92 s)**: 새 결합 시험 13개와 기존 출발 허가·공식 픽셀·영상 처리·A1 수신기 시험 118개. 실행 전후 `src/scripts/tests/config` 해시는 동일하다. 최신 전체 회귀를 다시 실행한 결과는 아니다.
- 실제 `RacePermission`, `VisionPipeline`/픽셀 인식, Python 참조 `ActuationReceiver`를 한 시험기에 연결했다. 별도 영상 프로세스 대신 동기 처리 작업자를 사용했고, 카메라 촬영→수신은 합성 1 ms·프레임 간격 100 ms·MCU tick 10 ms다. 실측 지연/처리율 검증이 아니다.
- 단일 모터축 28카운트·15:1·65 mm와 기존 TTL/고장 조건을 유지했다. 엔코더는 신선한 고정 0카운트이며 물리 차량을 계산하지 않는다. `target_speed`는 요청 상태이지 실제 속도/정지 측정이 아니다.
- ARM/시각 출발의 두 순서, 센서/교통 일시 대기, 상위 해제/MCU CLEAR·ARM의 두 순서, 이전 양수 명령/해제 거절, STOP 배송 누락, 엔코더 고장 복구, 물리 정지 입력 해제, 영상 고장과 새 경기 초기화의 결합을 확인했다.
- **반례:** `RacePermission.new_race()`만 호출하면 영상 검출기에 남은 `started=true` 때문에 새 경기의 전체 소등 영상도 출발로 전달될 수 있다. 잘못된 시험용 조합을 재현한 것이며 운영 경로 결함을 재현한 것은 아니다. 별도 사례에서 STOP→허가/영상 동시 초기화→이전 영상 결과 거절→새 빨강/초록 요구를 확인했다.
- STOP을 MCU에 전달하지 않은 경우 상위 허가만 false가 되고 MCU의 이전 양수 목표는 만료 전까지 남았다. 이후 `command_expired` 고정과 목표 0을 확인했으나 물리 제동을 입증하지 않는다.
- 최초 [v1](../race_actuation_v1/README.md)은 영 지연 합성 시각의 부동소수점 차이로 13개가 실패했다. 시험 촬영 시각만 1 ms 앞당겼으며 운영 미래 시각 거절/보호 조건은 변경하지 않았다.
- **운영 연결 없음:** ROS 명령, `/drive/safe` 발행, 독립 LiDAR 보호, Gazebo, Jetson, 실제 MCU/C++ 펌웨어·구동 출력은 이번 범위가 아니다. 새 경기/명시 재개 정책을 자동 채택하지 않았다.

재현은 `run.sh`, 검사는 `tests.log`·`junit.xml`, 소스 보존은 해시 목록과 Git 제외 `source_snapshot.tar.gz`다. 상세 해석과 다음 연결 조건은 [B3 보고서 §7](../../../../docs/autonomy/RACE_START_CONTRACT_2026_10_13.md#7-1023--출발대기정지재허가와-a1-수신기의-결합)을 따른다.
