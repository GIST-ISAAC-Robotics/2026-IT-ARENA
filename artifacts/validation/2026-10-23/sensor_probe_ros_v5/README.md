# 기록기 수신 시계 역전의 자체 종료

v4의 시험기 SIGINT 간섭을 제거하고 **역전 조건만** 다시 실행했다. 동일 센서/기록기·보호 수치이며 `/clock`을 약 10초에서 2초로 되돌린 뒤 센서 callback이 이를 읽도록 했다. 외부 종료 신호 없이 `clock_regressions=1`, `complete=false`, **exit 1**로 자체 종료했다. 이전 IMU/scan 각 80개는 보존했고 기존 재생기는 거절한다. 모든 판정은 `report.json`, 당시 소스는 `sources/`에 있으며 해시는 전후 동일하다.

실물 시스템 시계의 NTP 조정/모든 clock fault 검증이나 구동 정지 검증은 아니다. 제어기/MCU/장치를 실행하지 않았다. v4 실패를 성공으로 소급하지 않는다.
