# 휴대 묶음 v5 준비 실패

관련 회귀에서 **349 통과·1 실패**로 중단했고 archive 생성은 수행되지 않았다. 실패는 세션 감독에 실행 전 취소 경계를 추가한 뒤 기존 `uninterruptible` fixture가 처음부터 취소를 반환해 자식을 만들지 않았기 때문이다. 따라서 이 실행은 OS가 KILL을 무시하는 시험 조건에 도달하지 못했다.

당시 감독/시험 소스를 `sources/`에 보존했다. 후속은 fixture가 자식 생성 뒤 취소되도록 수정하고 `process_started=true`를 요구한다. KILL 이후에도 살아 있는 자식을 성공으로 판정하도록 제품 코드를 완화하지 않는다. 이 실패를 삭제하거나 기존 파일을 성공 결과로 덮어쓰지 않는다.
