# 낮은 빈도 5입력 기록 검사

120회귀 통과. ROS v8은 Image 10/20·CameraInfo 송수신 끝 정렬 차이로 원래 판정 false, runner exit 1이었다. 성공 후 경로의 추가 hash/시간 진단은 실행되지 않았으며 ROS v8 자체의 소스 불변/종료 검사는 통과했다. 후속 읽기 전용 진단은 ROS v8의 README와 별도 JSON을 따른다.

검증 기준을 낮추거나 실패 보고서를 성공으로 바꾸지 않는다. 0.2 s·2 s 대조는 기존 v7의 0.05 s·0.25 s와 다른 조건이며 실물 카메라 FPS/Jetson 처리량 시험이 아니다.
