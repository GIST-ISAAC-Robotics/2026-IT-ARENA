# 10/23 개발 계획의 독립 재검토와 재토의

계획 1차안을 만든 뒤 GPT와 별도 Claude Opus 5.5 세션이 상대의 재검토 의견을 먼저 읽지 않고 검토했다. GPT 검토를 파일로 고정한 뒤 Claude 결과를 수신·보존하고, 그 다음 서로의 의견을 공개하여 반론을 교환했다. 현재 결정은 [최종 계획](../../../../docs/reports/DEVELOPMENT_PLAN_2026_10_23.md)을 따른다. 아래 파일은 **당시 제안과 오류도 그대로 보존한 검토 이력**이며 현행 지시나 검증 결과가 아니다.

## 최종 정리에서 수정한 부분

- 기본 G1만 비교하지 않고, 기존 근거로 고른 하나의 고정 후보를 비교한다. 현재 R0의 단독 기준 시험과 좁은 교통 사례를 병행하며, 단독 완주를 교통 시험의 선행 관문으로 두지 않는다.
- 같은 자세 리셋은 관측 교착의 해결이 아니다. 필요한 전제·반례와 위험 수용 판단을 앞당기되, 무응답을 자유 공간으로 바꾸거나 새로운 표적 단면 가정을 자동 채택하지 않는다.
- O3의 초기 설명은 검증된 해법이 아니다. 측방 이동 표적에만 단면 가정을 두는 국소 O2 가설로 다시 정리했지만, 기존 전체 원판 분석이 이 가설을 검증한 것은 아니다. 정지와 이동의 위험 비교도 새 반례로 확인해야 한다.
- 전체 랩을 먼저 통과해야 교통 시험을 시작한다는 제안, 일정만 보고 C1 보정을 대체하는 제안, 측면 차량 때문에 정지하는 것을 일률 금지하는 제안은 채택하지 않았다.
- 토의 회신의 정체 예산 `86~125 s`는 선두 평균 2~3 m/s일 때의 범위다. 표 전체인 선두 1~3 m/s를 적용하면 약 `86~242 s`다. 둘 다 가정에 따른 계산이며 실제 경기 허용 정체 시간을 보장하지 않는다.
- GPT가 토의 메시지에 입력한 해시 일부에 오타가 있었으나, 파일과 위 SHA-256은 변경하지 않았다.
- 독립 검토 후 사용자가 추가한 일정은 **다음 주 부품·설계 수령 예상, 설계 후 제작 약 1주, 실차 주행 가능 기간은 마지막 약 1주**다. 확정 납기가 아니다. 최종 계획은 차량 완성 전 시뮬레이션과 개별 센서/MCU 벤치를 병행하고 마지막 주는 실제 차량 검증에 배정하도록 바꿨다.
- GPT 최종 검토에서는 R0를 다중 차량 경기의 자동 폴백으로 쓰지 않도록 하고, 반복 랩은 선택 모드에 모았다. 저장 입력 재생 일치를 새 폐루프 증명으로 쓰지 않으며, 이전 오차 사례는 현행 단일 모터축 구성으로 이식한다. 마지막 실차 주간의 필수 결함 수정은 허용하고 Jetson 성능을 맞추려고 보호·신선도 기준을 낮추지 않도록 명시했다.

이번 묶음은 계획·정적 검토이며, 새 주행·센서 측정·보호 정책 구현·실차 검증을 수행하지 않았다. 문서상의 합의가 주행 성공을 의미하지 않는다.
