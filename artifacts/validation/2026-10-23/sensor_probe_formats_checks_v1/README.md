# 센서 형식 검사 v1 — 시험기 CDR 비교 전제 실패

관련 회귀 **115통과·5실패**, exit 1. 사전 검사 실패로 ROS 기록 시험은 시작하지 않았다. 실패한 소스와 hashes/log/junit을 보존했다.

720p Image를 직렬화→역직렬화→재직렬화했을 때 전체 바이트가 같아야 한다고 가정한 시험이 실패했다. 각 사례의 차이는 index 62/63에서 나왔으며 이 Image의 `is_bigendian` 뒤 `step` 앞 CDR 정렬 padding에 해당한다. 메시지 필드가 같아도 재직렬화 바이트 전체가 같다는 계약은 없다. 실제 기록 손상으로 해석하지 않는다.

기존 시험기의 전송 전 hash와 객체 발행도 별도 직렬화였으므로 같은 전제에 의존했다. 후속에서는 한 번 직렬화한 정확한 bytes를 hash하고 설치 rclpy의 `Publisher.publish(bytes)`→`publish_raw`로 발행한다. 수신 CDR은 그 송신 바이트와 엄격히 비교하며 padding을 삭제/수정하여 통과시키지 않는다. 순수 round-trip 검사는 모든 메시지 필드 동등성을 확인한다. 기록기 운영 코드는 변경하지 않는다.
