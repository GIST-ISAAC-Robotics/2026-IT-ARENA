# 저장 센서 입력의 정적 형식 관찰

관련 **279회귀·1.32 s**, 저장된 ROS v9의 5토픽 각 20표본을 설치 Jazzy에서 읽었다. source/input SHA-256 불변, ROS 초기화와 노드 생성은 금지한 채 파일만 읽었다.

- RGB/BGR·행 패딩과 단일 모터축 이름/유한 각속도를 보존해 확인했다.
- CameraInfo 20개의 미교정 표시, scan 20개 `+Inf`, 명시 `laser_frame`과 다른 합성 frame 20개를 관찰했다.
- header 0·미지 공분산은 그대로 별도 표시한다. 값/단위/시각을 추측으로 고치거나 허용값으로 채우지 않는다.
- 마지막 CDR digest 실패 시 부분 진단 파일을 만들지 않는 회귀와 observer가 receipt/raw CDR을 바꾸지 않는 검사를 포함했다.

`report.json.passed`는 위 진단 시험의 통과일 뿐 입력 전체가 제어기에 적합하다는 뜻이 아니다. 동적 운동 이력·관측 구역·실물 축/단위·촬영 지연·주행 준비는 미검증이다.
