# 정지 C1 전방 바닥 교점 — 실패 보존

- 관련 순수 검사 50/50 통과, 각 자세 3 scan 수집, 소스 해시 차이 없음.
- 수평/앞 들림의 전방 ±10° 각 81광선은 no-return 예상과 일치했다. 앞 숙임은 81광선 모두 계산 허용치 0.03 m를 벗어나 **거리 비교 실패**다. 최대 차이 약 0.1246914 m.
- 정면 예상 약 1.288 m, 측정 약 1.165265 m. 허용치는 장면 비교용이며 C1 정확도/독립 보호 기준이 아니다.
- 종료 서비스 응답은 있었으나 서버가 사라지지 않았고, launch의 SIGINT/SIGTERM 뒤 SIGKILL로 종료됐다. `shutdown_audit.clean=false`, 서버 exit -9. 보고서의 잔존은 0이고 후속 실행 담당 조회에서도 자기 시험 잔존 없음.
- 원시 `result/scan_frames.json`은 로컬/Git 제외. 보고서·정적 SDF·로그·실행 시점 소스·해시는 보존한다. 차량·주행 제어기·공식 월드는 포함하지 않았다.
- [픽셀 표본 사후 대조](../bump_lidar_raster_audit_v1/README.md)는 별도 분석이며 이 실패를 통과로 바꾸지 않는다.
