# 시뮬레이션 시계 선택·역전 검사와 종료 경쟁

정상 `/clock`을 공급한 sensor_probe는 원시 CDR·원본 헤더를 보존하고 정상 종료했다. 시계 역전은 기록기에서 1회 검출됐고, 이전 IMU/scan 각 80개를 보존한 `complete=false` manifest를 남겼다. 하지만 시험기가 자동 종료 중인 자식에게 SIGINT를 보내 최종 코드가 `-2`였으므로 해당 시나리오의 종료 판정은 **실패**다. `report.json`과 `sim_regression/`을 그대로 보존한다.

기록기 수치를 바꾸지 않고 **역전 시나리오에서는 외부 SIGINT 없이 자체 종료를 기다리는 방식**으로 시험기만 고쳤다. 원문 로그만으로 rclpy 내부 종료의 정확한 신호 처리 시점을 입증한 것은 아니며, 외부 신호 간섭을 없앤 새 v5에서 exit 1을 확인한다. 정상 시계 시나리오는 근거 없이 반복하지 않는다.
