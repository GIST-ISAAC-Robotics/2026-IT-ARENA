# C1 시간 오프셋의 형상 식별 한계

2026-10-23. [앞 시험](../c1_motion_pipeline_v1/README.md)의 저장된 합성 입력만 읽었다. 새로운 C++/SDK 실행·Gazebo/장치·운영 코드 변경 없음.

- [analyze.py](analyze.py): 직진/좌·우 정속 회전에 시각 오프셋 0/−10/+10 ms를 적용한 9조건. 원래 대응점에 대한 최적 강체 정렬과 벽별 TLS 잔차를 구별한다. 평가용 원본/벽 ID를 사용하므로 실제 자동 연관/교정기가 아니다.
- [report.json](report.json): 9조건 검사 통과·입력/소스 불변·해시. 알려진 강체변환 제거/비강체 변형 잔존의 양·음성 대조도 먼저 실행했다.
- **핵심:** +10 ms일 때 실제 기준 점과 약 10.12 mm(직진)·38.98/39.01 mm(회전) 다르지만, 0오프셋 결과와 최적 강체 정렬 뒤 차이 및 벽 RMS 변화는 1e−11 m 미만이다. 벽이 반듯한지만 봐서는 이 오프셋을 알아낼 수 없다.
- 상수 twist·단일 scan이라는 조건의 한계다. 실제 시계 오프셋을 추정하지 않았고 값 10 ms를 허용/교정값으로 채택하지 않았다.

재현은 새 출력 경로의 분석기에서 `PYTHONPATH=src/arena_autonomy:scripts python3 analyze.py`로 수행한다. 참조하는 기존 v1의 `.npz`와 소스 snapshot을 함께 보존한다. 기존 `source/`가 있으면 덮어쓰지 않고 거절한다.

자세한 해석과 실물 시험 보완은 [C1 시각 계약 §6.4](../../../../docs/sensors/C1_DRIVER_TIME_CONTRACT_2026_10_23.md#64-벽이-반듯하다는-것만으로-시각을-교정할-수-없는-경우)를 참조한다.
