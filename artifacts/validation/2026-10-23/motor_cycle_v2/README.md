# 출력 없는 제어 주기 결합 — 확장 및 변이 검사

**198통과·실패/건너뜀 0, exit 0**, 정상 대조 통과·결함 변이 **8/8 검출**, 실행 전후 소스 해시 차이 0 B다. 종료 후 검사 프로세스는 남지 않았다.

제어 주기 25사례를 ASan/UBSan과 크기 최적화에서 실행하고 기존 PI/계약/공유 검사를 포함했다. v1의 정지/만료/준비/허가 세대 사례에 모터축 **28카운트·15:1·65 mm** 환산값 사용, 정상 음수 감속 요청, 외부 수신기 tick이 실제 PI 공백을 가리는 경우, 새 ARM 관측 누락, 오래된 피드백으로 CLEAR 거절을 추가했다.

변이체는 별도 소스 사본에서 준비 검사·receiver tick·고장 고정·ARM 관측·실제 dt·피드백 사용·고장 적분 초기화·0목표 초기화를 하나씩 제거했다. 모두 컴파일 성공 뒤 제어 주기 검사 자체에서 실패했다. 컴파일 오류나 충돌을 검출 성공으로 세지 않았다. 정상 코어/수신 연결부/TX/벤치/PI 공유 검사는 변이체에서도 통과했다.

출력 없는 합성 사건 검사다. 실제 제어 task 중단을 전기적으로 차단하거나 보드·차체 정지를 검증한 것이 아니다. 운영 기본값·ROS/Gazebo 모터 루프·센서/물성/보호 한도는 바꾸지 않았다.
