# writer 고장 주입 v2

`run.sh` exit 0, 두 조건 통과·검사한 소스 해시 불변이다. 기록기 자식은 각각 exit 1로 종료했다.

| 주입 | 보존 표본 | 결과 |
|---|---|---|
| 세 표본 뒤 write 예외 | IMU 2·scan 1 | 미완료·쓰기 오류 보존·감사 거절 |
| 실제 close 완료 직후 예외 | IMU 80·scan 80 | 미완료·종료 오류 보존·감사 거절 |

v1의 시험 래퍼 반환값 누락만 수정했고 기록기 본체/판정은 유지했다. 후자는 실제 파일 종료를 먼저 수행하므로 손상된 MCAP·물리 디스크 고장·강제 전원 차단 재현이 아니다. close 래퍼가 두 번째 호출을 무시하는 조건의 결과이며 실제 종료 재호출 허용 보증이 아니다. ROS 제어 구독/매개변수 요청 없이 합성 센서만 사용했고 구동기·Gazebo·Jetson은 실행하지 않았다. 원시 bag/receipt는 Git 제외다.
