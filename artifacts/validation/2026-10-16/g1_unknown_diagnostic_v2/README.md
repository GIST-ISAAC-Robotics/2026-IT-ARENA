# 무응답 고유 스캔 전체의 후속 형상 대조

v1의 마지막 정상·첫 무응답·마지막 무응답 예시를 보존하고, 같은 기록에서 무응답 고유 스캔 77개 각각의 최초 호출을 추가 대조한다. 최대 128스캔의 고정 예산이며 새 Gazebo 실행은 없다.

각 광선 취득 근사 구간 양 끝의 기록 자세에서, 실행 SDF 충돌 상자/visual 양면/앞면 거리가 기록의 range_max보다 큰지 확인한다. 미관측을 free로 바꾸지 않는다. 수평·마지막 안정 높이 가정과 렌더러 미재현 한계는 v1과 같으며, 일반 반환 거리의 정밀 보정이나 실제 C1의 무응답 원인 증명이 아니다. v1의 소스 snapshot·결과는 그대로 보존한다.
