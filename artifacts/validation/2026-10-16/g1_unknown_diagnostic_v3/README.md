# 고유 스캔 전체 대조: 평가 불가 표본 분리

v2는 11회귀 통과 후 일부 광선의 취득 근사 구간을 둘러싼 dense pose를 확보하지 못해 중단했다. `v2/audit.log`와 실패 직후 회수한 직접 실행 소스 ZIP을 보존했다(동시 실행 소스 snapshot이 아니라 사후 회수본).

v3는 같은 2.1 ms 취득 근사·6 ms 진단 기록 구간 상한을 유지한다. 부족한 광선은 보간하거나 성공으로 세지 않고 `unavailable`에 시각·범위를 남긴다. 예상/평가한 무응답 광선 표본 수를 나누고, 분석 전에 의존 소스 snapshot을 보존한다. 원시 입력·제어/보호·주행 실패 판정은 변경하지 않는다.
