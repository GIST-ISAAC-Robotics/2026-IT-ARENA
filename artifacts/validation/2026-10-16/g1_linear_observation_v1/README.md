# 저속 직진 관측 후보: 순수 계약과 저장 입력 대조

전체 곡률 외곽 비교에서 기존 회전 명령은 실제 측방 unknown과 겹쳤다. 따라서 회전 상태에서 무응답을 무시하지 않는다. `linear_observation`은 정면으로 새로 진입하는 띠를 2도 각 셀 상계/원래 시각의 유한 반환으로 검사하고, 모터 환산 속도와 0.2 m/s 중 큰 값을 기존 제동식에 넣는다. 현재 차체 측면/후방은 free로 변경하지 않는다. 관측 과거 여유·거리 여유와 제한 자이로 가정의 측방 오차를 전면 띠에 반영한다.

운영 후보는 추후 명시 옵션으로 연결할 경우에도 자이로 0.1초 조용함(≤0.05 rad/s), 거의 0인 직전 조향 명령, 현재 경로와 8 cm 이내의 짧은 직진 일치, 기존 fresh 확인/점유/독립 보호를 요구할 예정이다. 목표 상한은 0.2 m/s다. 이는 자차 횡슬립·실제 정지·새 측방 cut-in을 보장하지 않는다. 현재는 운영 미연결이다.

단위 시험과 기존 실패 77고유 스캔의 가능/거절 사유를 한 번 회수한다. 주행/마찰/센서/보호 기본값은 변경하지 않는다.
