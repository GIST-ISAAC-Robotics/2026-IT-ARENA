# 기록된 실제 조향 상한으로 관측영역 대조

[v1](../g1_observation_envelope_v1/README.md)은 13회귀 뒤 기존 감사 함수의 0.37 rad 고정 경계에서 실패했다. 실제 기록의 Ackermann 상한은 0.3710583448410034 rad다. 로그/시도 당시 source snapshot을 보존하며 운영 한도를 수정하지 않는다.

새 평가 함수는 기록된 config의 상한을 직접 사용해 궤적을 생성한다. 기존 깊이 감사의 0.37 rad 범위 밖 비교는 미평가로 표시하고 clamp하지 않는다. 실제 직전각/직진의 깊이 대조와 모든 각도의 미관측 부채꼴 교차는 각각 구분한다. 실제 값의 회귀를 추가하고 기존 v1과 같은 저장 입력 분석을 다시 수행한다.
