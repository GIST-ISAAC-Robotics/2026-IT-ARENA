# 짧은 직진 회복 후보의 저장 입력 선행조건

회귀 55개 통과. 77개 고유 스캔 중 75개는 전면 띠 관측 조건을 만족했고, 2개는 투영 후 방위 순서/원주 끝 간격 조건으로 거절했다. 이 검사는 이전 v1에 없던 원주 끝 간격 검사를 포함한다. 현재 속도 비음수·모터/자이로 0.2초 조용함·직전 조향 0·짧은 경로 일치까지 포함한 후보 선행조건은 72개에서 성립했다. 첫 대상 seq 3021은 60.42초, 모터 환산 속도 0.04862 m/s다.

관측 요구 거리 0.2736 m에는 기존 정지 간격을 유지한다. 경로와 비교하는 실제 pulse+여유/반응/제동 길이는 0.1636 m다. 한 번만 최대 0.25초·모터축 환산 0.05 m 허용하며 재무장은 운영 미설계/미연결이다. 모터 적분은 지면 이동의 상계가 아니고 조용한 피드백도 차체 정지 증명이 아니다. 기존 모든 선행조건(긴 직진 일치 포함)은 여전히 0개다. 과거 실패를 성공으로 바꾸지 않는다.

분석 출력은 `audit/report.json`, 회귀 로그는 `tests.log`다. 입력·소스 불변. 후속 [정적 시점 대조](../g1_recovery_viewpoint_v1/report.json)에서 0/2.5/5/10 cm 이동해도 전방 무응답이 모두 4개로 유지되어 **이 후보를 운영에 연결하지 않는다**. 단순히 움직일 수 있는 조건과 문제를 해결하는 동작은 다르다.
