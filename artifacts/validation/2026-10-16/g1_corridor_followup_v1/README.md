# 새 궤적의 입력 복구 계약과 PC 비용

공식 단독 1회의 실패는 유지한다. 운영 소스/설정 변경이나 추가 Gazebo 주행 없이 다음 두 미검증 범위를 확인한다.

1. 실제 회랑 선택이 성립한 합성 관측 뒤 정면/좌우 86.4°에 +Inf/−Inf/NaN/범위 밖 값을 넣어, 보호 입력 검사와 선택형 제어기가 정지하고 확인 이력을 지우는지 확인한다. 복구 뒤 같은 스캔 재사용을 fresh로 세지 않고 새 스캔 확인을 다시 요구한다. 실제 ROS 전달/제동 증거가 아니다.
2. 새 공식 기록 2,837판단에서 기존 프로파일러로 기본 회랑 연결을 포함한 실제 코드 경로의 PC 비용을 1회 계측한다. native GC, warmup 0, 고정 입력/출력 대조. 기존 관측기를 또 호출해 비용을 이중 계산하지 않는다. ROS 50 Hz 마감·Jetson 검증으로 부르지 않는다.

계수·보호·12 m 센서 범위·물성·기본값은 변경하지 않는다. 실패 시 원시 로그를 보존하고 같은 실행을 자동 반복하지 않는다.
