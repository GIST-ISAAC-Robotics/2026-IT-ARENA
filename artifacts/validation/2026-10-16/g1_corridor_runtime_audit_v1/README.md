# 실제 회랑 선택 기록의 사후 감사

공식 단독 1회가 종료된 뒤에만 수행한다. 주행 원본·판정·운영 소스를 변경하지 않는다.

- 새 도구 `audit_corridor_runtime.py`는 기존 판단 재생과 별개로 실제 선택 호출의 보고 계약, 기준/회랑 간 마지막 양수 경로의 운동 이송 후 일치, 선택 호출의 이전/새 조향 외곽에서 필요한 정지거리까지 인접 광선 깊이를 대조한다.
- 실제 반환 전체를 사용하는지는 별도 기존 점유 감사로 검증한다. 본 도구에서 계약 필드 일치는 구현의 독립 검증을 대체하지 않는다.
- 경로 일치 실패에는 경로 차이뿐 아니라 공통 구간 부족이 포함된다. 만료·세대 변경·이송 불가를 성공으로 세지 않는다.
- 깊이는 4 cm 외곽 표본과 조향 양 끝값의 검사다. 연속 공간·표본 사이 장애물 부재·실제 제동·공식 완주 판정이 아니다.
- 입력 hash와 도구 의존 소스 snapshot을 보존한다. 이전 후보의 새 궤적이며 과거 저장 입력 378호출 결과를 재사용하지 않는다.
