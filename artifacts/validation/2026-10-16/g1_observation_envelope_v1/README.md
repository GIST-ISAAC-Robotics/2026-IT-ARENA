# 미관측 방향과 필요한 이동 영역의 첫 대조

사용자가 10/16 오후 문제 해결 방향과 후속 작업을 위임했다. 새벽 예약 문구의 보호 변경 제한을 사용자가 직접 정한 영구 금지로 취급하지 않는다. 안전 판단의 개선은 작업 범위지만, 미관측 채움이나 정답 입력/보호 우회는 하지 않는다.

우선 기존 실패 기록에서 고유 무응답 스캔마다 직전 조향·직진·좌우 한계 조향의 제동 외곽을 비교한다. 목표 0.2/1.0 m/s와 현재 모터축 환산 속도 중 큰 값, 기존 제동식·차체·기어/바퀴/센서 범위를 유지한다. 순차 취득 원점/방향과 원래 각 셀 폭을 유지하며, 무응답/후방 마스크를 거리 상한으로 바꾸지 않는다.

정곡률 명목 차체 외곽의 조밀 표본 합집합과 표본 사이 운동을 포함하는 상계 둘 다 기록한다. 현재 명목 차체만 제외하고 안전 여유까지 임의로 제외하지 않는다. nominal 및 기존 거리/취득 여유 팽창을 대조한다. 교차가 있어도 실제 물체 충돌 증명이 아니라 미관측 영역과의 중첩이다. 상계만의 교차와 실제 이산 명목 자세의 교차도 구분한다.

단위 회귀 후 기존 77 고유 스캔/직전 정상 장면을 한 번 조사한다. 추가 Gazebo 주행·운영 코드 변경은 없으며 실패를 보존한다. 실행 담당은 GPT-6 Luna, 설계·구현·분석은 GPT 주 에이전트다.
