# 공식 단독 1회 실패의 전방 무응답 진단

43.113530 m에서 멈춘 기록을 읽는 오프라인 분석이다. Gazebo를 재실행하거나 무응답을 보간/채움/허용하지 않는다. 알려진 전방 100° 관측 기준도 바꾸지 않는다.

- 판단 기록의 무응답 시작/종료·취득 시각·원시 nonfinite 종류를 보존한다. 마지막 정상, 첫 실패, 마지막 실패 호출에서 문제 광선과 인접 광선을 비교한다.
- 실행 SDF의 `walls` 충돌 상자와 함께 보존한 batched visual OBJ 삼각형을 각각 교차한다. 시각 모델은 양면/앞면 교차를 나눈다. GPU 재질·센서 재현이 아닌 수학적 비교다.
- 평가용 dense pose의 취득 근사 구간(최대 2.1 ms 이전)을 둘러싼 기록 양 끝을 사용한다. 마지막 안정 높이 + 고정 센서 위치의 수평 모델이며 roll/pitch·구간 중간 운동/광학을 보장하지 않는다. 정답은 제어기에 전달하지 않는다.
- 처음 감사가 실패하면 실패 로그를 보존하고 원인을 분리한다. 제어기/보호/트랙/물성을 수정하거나 자동 재주행하지 않는다.
