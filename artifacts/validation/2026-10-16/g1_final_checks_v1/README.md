# 10/16 마감 회귀

추가 Gazebo/ROS 주행 없이 전체 pytest를 한 번 실행한다. 기존 승인 단독 주행과 10/15 실패의 소스·판정은 바꾸지 않는다. 이번에 추가한 평가 도구와 입력 복구 회귀가 기존 시험들과 함께 실행되는지 확인한다.

`check.py before`는 실행 전 소스 묶음·manifest를 보존하고 10/15 사전 및 10/16 주행의 소스/설정과 대조한다. 과거 manifest의 `.gitignore`·`.gitattributes` 변경은 기록하되 실행 소스 변경으로 취급하지 않는다. `check.py after`는 현재 시험 중 소스 불변성을 확인한다. 문서는 최종 결과 기록 때문에 이 소스 묶음 밖에 둔다.

명령: 저장소 루트에서 `bash artifacts/validation/2026-10-16/g1_final_checks_v1/run.sh`.

단위 시험 통과는 공식 코스 완주·실차 제동·Jetson 실시간 마감 확인이 아니다. 실패 시 로그를 보존하고 자동 반복하지 않는다.
