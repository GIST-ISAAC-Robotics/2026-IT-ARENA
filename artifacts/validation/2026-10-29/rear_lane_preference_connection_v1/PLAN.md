# 현재 직선 차선 선호의 선택형 연결 계획

오프라인 v3의 후방 재접근·오차 비교 결과를 검토한 뒤 연결 여부를 결정한다. 이 문서 작성만으로 연결/기본 채택/실차 확인이 완료된 것은 아니다.

## 연결 범위

- 기존 `rear_lane_keep_trial`의2초 정책과 새정책을 구분한다. 새정책을 선택하지 않은 기존설정/기록은 같은 결과여야한다.
- ROS에서명시선택하고판단기록헤더에정책을남긴다. 시험용 monkeypatch가 실제노드와재생기를서로다르게바꾸는구조는사용하지않는다.
- 목표속도의20 ms 한카운트여유는개발가정임을명시한다.측정값을클리핑하거나기존관측/제동공간을복사해서승인하지않는다.
- 기존소스·설정·실패기록은새계약의이전사본으로보존하고,이관/검증묶음은새모듈을빠짐없이포함한다.

## 수용과 실행

1. 정책선택/잘못된조합거부·기존기본값·상태전이/속도증분반례, 관련선택기/입출력/출처검사를수행한다.
2. 기존OFF및2초ON의판단기록649/653개를동일하게재생한다. 새정책으로바뀐기록을과거기록일치라고하지않는다.
3. 빌드·설치모듈일치·실제헤더에서명시정책확인후Gazebo v2와동일12초후방재접근을1회수행한다. 원래지표와등록진행/정체/STOP/종료·소스불변을분리한다.
4. 근거없이실패를반복하지않는다. 제한실행에서이득이없거나새문제가있으면원시증거를보존하고기본값은그대로둔다. 아직새정책의전체랩/실물성공을뜻하지않는다.
