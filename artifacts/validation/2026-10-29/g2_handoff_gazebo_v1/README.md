# G1/G2 자동 선택·복귀 제한 Gazebo 시험

2026-10-29. [합성 후보/연결 기록](../g2_handoff_v1/README.md)의 전환을 실제 ROS 센서·독립 보호·가상 MCU·차량 동역학에 연결한다. 기본 실행은 바꾸지 않는다.

## 실행 전 등록

- 기존 오른쪽 가장자리 G2 배치를 유지한다. 자차는 공식 출발 직선 중심, 표적20×15×12 cm 상자는 전방1.2 m/오른쪽149 mm, 주행12초 뒤 명시 STOP이다. 지도/표적 자세는 센서 생산·평가 전용이다.
- `g1_g2_handoff_trial`와 `g1_g2_simulation_trial=true`를 명시한다. G1은 v4·corner-distance·per-ray·회랑·평행/통과·GUARD·회복, 최근 관측/short-prefix는OFF다. G2는 기존 두 벽 확인·관측 경로·외벽 재정합·복귀를 사용한다. 임의의 움직이는 차량 추월 기능으로 부르지 않는다.
- 기존 비교의 신호 v2/뒤쪽30 cm 카메라·방지턱OFF·노면·마찰·차동·단일 모터축28카운트/15:1/65 mm·C1 순차10 Hz를 유지한다. 신호 제작측10/29 최신 형상은 별도 확인본이며, 이 시험에서 재배치하지 않는다.
- FOLLOW 출력은 기존1 m/s 이하, 우회/복귀는0.35 m/s 이하로 따로 확인한다. 출발/초록·조기 출발0·센서 전용 입력·`/drive`→독립 보호→`/drive/safe`·실제 STOP/MCU 래치·정상 종료를 검사한다.
- 기존 G2 평가의 표적 통과·반대쪽 우회·주행 창 안 중앙 복귀(50 mm/0.10 rad/1초 유지), 접촉0·겹침0·도로 밖 바퀴≤2·벽 바퀴0·표본 연속성을 유지한다. 최소 차체 간격은 기록하며 과거150 mm를 새 고정 규정으로 쓰지 않는다.
- schema5 전체 판단 동일 재생, FOLLOW→BYPASS→REACQUIRE→FOLLOW의 실제 전환을 추가한다. 기존 G1의 정지/뒤에 머무름 판정은 원래 결과로 보존한다.
- 먼저 빌드/설치·정적 배치·평가 반례·소스 보존을 확인한다. 근거가 갖춰지면1회 실행하며 실패 시 증거를 회수한다. 동일 조건을 성공할 때까지 반복하지 않는다.

`g2_eval_core.py`와 `g2_eval_v2.py`는 기존 좌우 대조 평가의 **별도 사본**이며 원본은 변경하지 않았다. 수치 판정은 그대로, 상태 모드/schema 계약과 전환 확인만 확장한다. `g2_decisions.jsonl` 이름은 하네스 호환용이며 내용은 schema5다.

낮은 이동의 반환 조각은 정지/차량 ID의 증명이 아니고, 매우 느린 차량·가림 교체·후방 사각·실물 센서 시간/기구 오차는 남는다. 이전 편측 헛돎과 중앙 정체가 해결됐다고 보지 않는다.

## run1 결과: 우회 진입·통과, 복귀 실패

[등록 평가](run1_g2_evaluation.json)는 실패다. 초록 후1.105초에 자동 우회로 진입하고4.704초에 표적을 지났으나, 주행 창 진행1.790 m·횡위치 약164.5 mm에서 차체가 멈춰 중앙 복귀에 실패했다. 출력은 계속0.35 m/s였고 보호 이유는 `clear`였다. 초록 후6초 이후 왼쪽 후륜은 약21 rad/s, 오른쪽은 거의0 rad/s·차체도 거의0 m/s여서 이전 편측 헛돎과 같은 형태다. G1↔G2 연결이 정지를 명령했다는 근거는 없다.

접촉/차체 겹침0·도로 밖 바퀴≤2·실제 STOP·14개 정상 종료·소스 불변·schema5의641/641판단 동일 재생은 통과했다. 기존 G1의 뒤에 머무름/도로 안 판정은 원래 실패로 보존한다. 합성 우회·복귀 성공이 Gazebo 동역학의 복귀 성공으로 이어지지 않았다.

## run2 접촉 진단 등록

`run_contact.py`는 run1에서 **바퀴 접촉 센서·기록만 추가**한 사본이다([차이](contact_only_adapter.diff)). 같은12초 창·출발/차량/노면/마찰/열린 차동·제어 소스·판정을 유지하며1회만 실행한다. 성공을 얻기 위한 반복이 아니라, run1에 없었던 접촉 쌍·바퀴별 하중을 얻는 진단이다. 미수신을 무하중으로 보간하지 않고 차량/월드 형상 동일성을 함께 확인한다. 재현되지 않으면 복귀 실패의 접촉 원인은 미확인으로 남기며, 계측 때문에 고쳐졌다고 쓰지 않는다. 실행은 GPT-6 Luna가 맡고 설계·분석은 GPT가 직접 수행한다.

### run2 결과

[run2 등록 평가](run2_g2_evaluation.json)도 복귀에 실패했다. 자동 진입1.057초·표적 통과·접촉/겹침0·도로 밖 바퀴≤2·명령 계약·실제 STOP/정상 종료·656판단 동일 재생은 통과했다. 복귀 경로 생성 뒤에도 차체는 정체하고 왼쪽 뒷바퀴만 헛돌았다. 접촉 기록73,389개와 원래 G1 실패를 보존했다. [접촉 쌍·원시 힘의 부호 한계·다음 범위](../g2_handoff_dynamics_v1/README.md)에 상세 근거를 모았으며 같은 실패의 추가 반복은 하지 않는다.
