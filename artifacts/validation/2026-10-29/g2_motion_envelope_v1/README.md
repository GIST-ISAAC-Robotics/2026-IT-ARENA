[기존531판단 재구성](../g2_tracking_preview_v1/prototype2_stop_diagnosis.json)에서 중앙 정체를 다시 확인했다. 최초3.16 s의 표적 모서리 점은 취득 후121.6 ms가 지났고 기본55 mm+0.5 m/s×시간=115.8 mm로 팽창했다. 현재/직전 조향 모두0.08 m 앞 원호 표본에 겹쳐4 cm 차감 뒤 제동 가능거리가0.04 m가 됐다.3.20 s 새 스캔에서는85.5 mm로 줄어 진행했다가3.28 s에다시125.9 mm로 커져 정지했다. 외벽 분류는210개 이상 유지됐고 해당 이동 영역의 일반 미관측은0이었다. 평가용 정답으로 대조한 점 위치는 표적 모서리 근처였다.

## 바꾸지 않는 것과 비교할 해석

현재 원호 검사는 차체의 각 축에 전체 여유를 더한 직사각형을 쓴다. 이때 취득 후 이동 반경을x/y 양쪽 끝에 동시에 적용하면 대각선에서sqrt(2)배 이동까지 포함한다. 이번 후보는 **기본25 mm·거리오차30 mm의 직사각 여유는 유지**하고, 그 바깥의 취득 후 이동만 **총 이동거리0.5 m/s×나이인 원판**으로 해석한다. 총 이동거리 상한과 축별 속도 상한은 서로 다른 가정이다. 기존 구현과 완전히 같은 보장이라고 부르지 않는다. 원래0.5 m/s 자체도 실측 속도 보증이 아닌 시험 가정이다.

`rounded_swept_limit`은 확대된 직사각 차체와 점 사이 Euclidean 거리를 계산한다. 각2 cm 원호 구간의 중간에서 검사하되, 후륜축으로부터 최대 차체 꼭짓점 반경을r, 곡률을κ라 할 때 `(1+|κ|r)×구간길이/2`를 추가해 표본 사이 회전을 덮는다. 그 구간의 가능한 첫 간섭부터 거절하며 현재/직전 조향을 계속 대조한다. 현재 시각까지의 물체 운동 가정이며 미래 상대차 운동이나 노면/전체 우회를 인증하지 않는다.

가까운 실제 점유·같은55 mm 기본여유·취득시각·누락/사각·반응/제동·STOP·독립 보호는 바꾸지 않는다. 현재 판단 도형만 고정 저장 입력에서 먼저 비교하고, 생산 코드·운영 기본값에는 연결하지 않는다. 직선 해·반사 대칭·조밀한 원호 대조·잘못된 입력을 포함한6검사를 먼저 수행한다. 변경된 도형을 통과율 향상으로만 정당화하지 않는다.

## 저장 대조 결과와 분리 시험 등록

첫6검사와 도형/연속 하한 분리 뒤7검사를 통과했다. 중간의 잘못된 unittest module 실행은 import 경로에서 실패했으며 Python 파일 직접 실행으로 복구했다. [0.1 mm 조밀 대조](saved_dense_comparison.json)에서 기존4 cm 차감값은 확인한10원호 모두 조밀 첫 접촉보다 앞이었다. 새 연속 하한이 더 작았던 것은 실제 간섭을 새로 발견해서가 아니라 구간 움직임 상계가 보수적이었기 때문이다. 기존 방식의 모든 경우를 인증한 결과는 아니다.

순수 도형 효과를 확인하기 위해 `disk1`은 **기존4 cm 표본/차감까지 유지**하고, 취득 후 이동 사각형만 원판으로 바꾼다. 기본55 mm 직사각 여유는 그대로다. 최초 후보의 순위·경로·독립 보호·반응/제동·10초+STOP을 유지한 중앙 정지 표적 복합 오차seed17 조건1회다. 앞의 비싼 추종 예측은 쓰지 않는다.8검사에서 동일 표본의axis형이 기존 수식과 같고disk형의 점유가axis형보다 커지지 않는지를 대조한 뒤 실행한다. 생산 코드/기본값에는 연결하지 않는다. 결과가 달라지면 실제 처음 선택·제어/보호·접촉/노면·재개 여부를 분석하며 자동 반복하지 않는다.
