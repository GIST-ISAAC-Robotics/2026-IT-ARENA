# M3 개방형 옆차 동적 비교

[사전 계획](DRIVE_PLAN.md)에 따라 기존측방상자비교와동일한주행에서옆차의스캔단면만희소해지는영향을확인한다. 신호v2는이번형상차이분리를위해유지한다. 아래 준비 기록에 이어 좌우 각 1회의 실행 결과를 기록한다.

## 왼쪽 결과와 오른쪽 실행 결정

계약6검사통과후왼쪽Gazebo1회를실행했다. 실제6부품/6접촉토픽·G1설정/공식v2신호계약·입력/소스보존은통과했다. 진행3.8796m·최장정체2.123초·옆차뒤→옆→앞전이·접촉이벤트0·바퀴중심도로밖0(10,470표본)·STOP17.38mm·14/14정상종료·655판단동일재생이었다. 바퀴검사는평면중심의도로이탈이며접촉센서/타이어전체의접지증명이아니다.

원래G1종합판정은최종주앞차간격1.703m로실패하고, 옆차최소70.40mm/swept하한70.33mm도등록150mm미달이다. 기존상자왼쪽과같은유형의실패를보존한다. 새로운접촉/구조적정체는관측되지않아오른쪽대칭조건도같은정책으로12초1회실행한다. 실제실패나인프라문제가생기면자동반복하지않는다.


## 최종 결과 — 좌우 각 1회, 추가 실행 없이 종료

오른쪽도 입력·소스 무결성과 실행 계약을 통과했다. 원래 평가기의 `passed=false`는 그대로 보존한다. 측방 150 mm와 최초 주앞차의 최종 1.2 m 상한은 기존 비교선이며, 이번 결과에 맞추어 낮추지 않았다. 현재 경로에서 가까운 차량을 따로 확인한 진단은 각 `drive_*_front_target.json`에 있으며 원래 판정을 덮어쓰지 않는다.

기존 상자 옆차에서 개방형으로 바꿔도 두 제한 장면에서 통과와 진행은 유지됐다. 오른쪽 최소 간격은 상자 조건의 약 69.2 mm보다 작아졌으므로 형상에 무관한 같은 여유나 일반 안전성을 주장하지 않는다. 두 실행 모두 원래 주앞차 최종 간격 및 옆차 150 mm 판정은 실패했다. 접촉 이벤트 0과 표본 사이 기하 간격을 함께 확인했으며, 이벤트가 없다는 사실만으로 연속 물리 무접촉을 증명하지 않는다.

옆차는 20×15×14 cm의 판·기둥 6부품이고 평면 충돌 평가는 전체 20×15 cm 외곽을 유지한다. 주앞차는 기존 상자이며 두 상대차 모두 정해진 속도/경로의 평가 자극이다. 실제 서로 판단하는 자율차, 모든 불규칙 차체, 후방 사각 재접근, 코너 병렬주행, 실차 시험은 아니다. 방지턱 OFF·이전 공식 신호 v2·30 cm 카메라 조건을 그대로 사용하여 형상 차이를 분리했다. G2의 새 희소 반환 준비 후보는 이 M3 실행에 연결하지 않았다.

원시 센서·판단·자세 로그와 소스 ZIP은 로컬에 보존하고, Git에는 실행/형상 스크립트·설정·판정·해시·재생 요약을 남긴다. [요약 JSON](results_summary.json), [왼쪽 원래 판정](drive_left/report.json), [오른쪽 원래 판정](drive_right/report.json)을 기준으로 재개한다. 사용자의 정리 요청에 따라 여기서 새 주행 묶음을 시작하지 않았다. 다음 검토 대상은 계획에 남은 옆→뒤→후방 사각 소실과 재접근이며, 이번 피추월 결과와 구분한다.
