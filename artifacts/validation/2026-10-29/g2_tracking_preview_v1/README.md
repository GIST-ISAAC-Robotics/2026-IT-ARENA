# G2 중앙 정지차: 목표 곡선과 추종 예측 대조

2026-10-29. 가장자리 상자/개방형의 Gazebo 편측 헛돎과 별개로, 기존 중앙 정지차의 합성 주행 정체를 분석한다. 제어/보호 기본값과 운영 노드는 바꾸지 않는다.

## 고정 초기 관측 진단

초기 비교 (`initial_comparison.json`, 로컬 보존)는 이상/복합 오차 중앙과 복합 오차 좌우 가장자리의 초기 정지 관측을 재구성한다. 복합 오차는 기존±30 mm·라이다−0.5°·gyro+1°/s 및σ0.02 rad/s·단일 모터축28카운트/15:1/65 mm 양자화(seed17)다. 현재 후보 순위는 이상 곡선 위 차체와 현재 반환점의 여유를 쓴다. 별도 진단은 같은 경로를 기존 Pure Pursuit·조향 변화율3 rad/s·상한0.35 m/s·이상 가감속으로 추종한 위치를 대조한다.

중앙의 원래 선택은 편이+0.24 m/전이1.2 m였다. 고정 초기 관측에서는 예측 궤적도 간섭하지 않았다(이상 최소16.98 mm/복합12 mm 여유). 따라서 '목표 곡선은 가능하지만 추종 오차만으로 이미 불가능'이라는 설명은 입증되지 않았다. 다만+0.24 m/0.9 m 후보는 복합 조건의 이상 경로 평가에서는 간섭했는데 추종 예측에서는18 mm 여유가 남아 순위가 다를 수 있었다. 이는 아직 수정 근거가 아닌 비교 가설이다.

예측은 미래 물체 운동·새 광선·독립 보호의 감속·실제 구동을 재현하지 않는다. 현재 점유 여유를 제거하거나 미래 관측 승인으로 사용하지 않는다. 후보당약18 ms이므로 모든 후보의 매 제어주기 계산을 운영 구현으로 채택하지 않는다.

## prototype1 등록

- 생산 파일을 수정하지 않고 진단 프로세스 안에서 초기 후보의 순위만 바꾼다. 기존 현재 명령의 관측/점유·조향 한계를 통과한 후보 중에서만 선택하며, 이후 경로 유지·재관측·복귀·독립 보호·STOP은 동일하다.
- 예측 진행2 cm·점 여유5 mm의 순위, 이후 작은 편이/긴 전이의 기존 동률 규칙을 사용한다. 적분 끝의 최대1스텝 초과로 순위를 바꾸지 않도록 동일 관측 지평에 자른다.
- 기존 중앙 정지·좌우 가장자리·중앙 재출발의 네 조건, 복합 오차seed17·10초+STOP만1회 비교한다. 실제 주행이나 운영 노드 연결은 하지 않는다. 같은 실패를 수치만 바꿔 반복하지 않는다.
- 좌표 반사 대칭·직선 해·거절 후보 재선택 금지의3검사를 먼저 확인한다. [실행기](run_prototype.py)는 소스 ZIP/해시·상세 실패·초기 선택·계산 비용을 보존한다.

중앙 정체가 남으면 최초 거절 시점의 현재 취득 나이/팽창과 실제 명령 원호를 분리한다. 초기 예측 순위만 바꾸면 해결된다고 전제하지 않는다. 비교 기준은 [combined21_fixed2](../g2_entry_shadow_v1/combined21_fixed2/report.json)의 원래 실패이며, 현재 핵심 제어/센서 생산자 소스는 같고 실행 등록·판단 직렬화 연결 파일이 달라진 사실은 구별한다.

## prototype1 결과와 prototype2 등록

3검사는 통과했고 Python 실행/소스 보존도 정상이다. 검사 래퍼의 종료값 인용 오류로 `tests.exit`이 비고 셸 오류가 난 사실은 검사 로그와 구별해 보존한다. 중앙은0.8365 m에서 정체했고 가장자리3.4052/3.4079 m·복귀, 재출발2.9405 m였다. 모두접촉0·두 바퀴 이하·STOP/최종0이었다.

다만 초기 후보 순위만 바꾸었으므로 뒤의 `EntryIntent`가 **원래 이상 경로 점수로 우회 이득을 다시 비교**했다. 0.9 m 후보는 선택되지 않고 직진하다가0.70 s에원래1.2 m 후보를 확정했다. 따라서 결과를0.9 m 전이의 정체나 추종 예측 방식의 효과로 해석하지 않는다. 당시 소스/실패는 `prototype1`에 보존했다. 초기 순위 비용은 약350–410 ms였다.

`prototype2`는 동일 진단에서 후보 순위와 우회 시작 이득을 **동일한 추종 예측 진행량**으로 대조한다. 기존4 cm 이득·현재 후보의 관측/점유 통과·입력 시각/epoch 검사·이후 모든 보호는 유지한다. 두 단계 연결/이득 없는 직진 대조를 추가한5검사를 먼저 확인한 뒤, 같은4조건10초+STOP을1회 비교한다. 이 역시 생산 코드 변경이나 운영 연결이 아니다.

## prototype2 결과: 초기 예측 계산은 미채택

5검사·실행·소스 보존은 통과했다. 실제 첫 우회 선택은 시뮬레이션0.60 s, 차체 진행0 m에서+0.24 m/0.9 m였으므로 이번에는 짧은 전이를 적용했다. 중앙 정지는0.8464 m·횡234.3 mm에서 여전히 막혔다. 가장자리 두 조건은3.4052/3.4079 m·중앙 복귀, 중앙 재출발은2.9404 m·복귀 없음이었다. 모두접촉0·두 바퀴 이하·STOP/최종속도0이다. [원본](prototype2/report.json).

순위 변경만으로 중앙 정체를 해결하지 못했고 계산비용도 커서 생산 제어기에 추가하지 않는다. 원래1.2 m 경로와 새로운0.9 m 경로의 실패를 둘 다 보존한다.

[저장 적용 운동 재구성](prototype2_stop_diagnosis.json)은531/531판단과 당시 소스를 일치시켰다. 최초3.16 s에는 표적 모서리 반환의 시차 팽창115.8 mm가 명령 원호에 걸렸다. 새 스캔 직후3.20 s에는여유85.5 mm로 진행하다3.28 s에125.9 mm로 커져 다시 정지했다. 외벽 분류는210개 이상이고 해당 일반 미관측은0이었다. 첫 진단 출력은 NumPy bool 직렬화에서 실패해 오류 로그를 보존했고 기존 freeze 변환으로 고친 재구성이 정상 종료했다. 새로운 주행 결과가 아니다.

다음 [팽창 도형 대조](../g2_motion_envelope_v1/README.md)는 기본 여유를 유지하면서 취득 후 이동의 축별 사각형/총거리 원판 해석을 분리한다. 실제 표적을 정지로 확정하거나 취득 나이를 줄이는 방식은 쓰지 않는다.
