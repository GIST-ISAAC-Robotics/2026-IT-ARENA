# 개방형 상대차의 자동 우회 진입 관측 비교

2026-10-29. [기존 개방형 시험](../g2_openframe_v1/README.md)은 수동 G2에서 실제 기둥 반환으로 표적을 통과했지만, 자동 G1/G2 진입은 확인하지 않았다. 먼저 같은 상자/개방형의 저장 실제 센서·운동 입력에서 연속 반환 조각과0.8초 누적이 성립하는지 비교한다. 평가 actor 정답은 진입 판단에 넣지 않는다.

첫 비교는 과거 수동 G2 궤적의 관측 진단이다. 자동 제어 출력 적용·새 폐루프·영구 정체의 증명이 아니다. 원본 물성/형상/기록은 보존하며 같은 편측 헛돎 Gazebo 시험을 반복하지 않는다. 이후 결과에 따라 센서 합성의 형상만 바꾼 제한 자동 주행으로 영향을 확인한다. GPT가 설계·분석·구현, GPT-6 Luna가 실행·대기·회수를 담당한다.

첫 실행은 셸 파일의 CRLF 때문에 분석 전 종료했다. 줄바꿈만 LF로 고친 뒤 같은 진단을 실행한다. 입력/제어 코드/판정 변경은 없다.

## 저장 입력 결과와 다음 비교

저장된 수동G2 입력의 처음0.8초/9스캔에서 상자는8회, 개방형은1회만 연속 전방 조각이 성립했다. 첫 성립은0/0.58초, 누적ready는 양쪽2.48초였다. 이미 수동으로 움직인 궤적이므로 자동 정체의 증명이 아니다. 상세는[saved1](saved1/report.json)에 보존한다.

다음은 같은 순차10Hz·이상bicycle·독립 보호 함수에서 센서용 표적만 기존6부품 형상으로 바꾼다. 충돌 평가는 상하판의 전체20×15cm 외형을 유지한다. 오른쪽ideal/오른쪽combined/왼쪽combined를12초+STOP으로 각각1회, 명시space/window/reserve/known_hold 후보에서 비교한다. 정답은 센서 생산/평가에만 쓰며 ROS/Gazebo/실물 증명이 아니다. 접촉·최대 두 바퀴 잔디·실제 진행·진입/복귀·STOP·schema5 재생을 기록하고 같은 실패를 자동 반복하지 않는다.

## 자동 주행 기존 결과와 희소 반환 후보

`closed1`의 오른쪽ideal/왼쪽combined는5.235/5.311 m·복귀를 확인했지만 오른쪽combined는1.183 m에서 복귀에 실패했다. 세 조건 모두 접촉0·두 바퀴 이하·STOP·각600판단 동일이었다. 오른쪽combined는 조각 준비가1.7초에 시작되고3.0초/차체간격0.510 m에 진입하여 모서리 부근에서 진행/정지를 반복했다. 물리 헛돎이 없는 이상bicycle에서도 가까운 진입 문제가 남았다.

명시 `front_patch_policy=sparse_returns_v1` 후보는 기존 연속3광선 대신 전방ROI의 실제 반환3개 이상을 본다. 가장 가까운 반환부터깊이0.20 m·측방폭0.24 m 안의 조각만 사용한다. 이 값은 시험용 관측 창이며 물체 크기·같은 강체·빈틈의 점유/자유를 주장하지 않는다. 원래0.8초/서로 다른6스캔·60 mm 이동 비교와 G2 경로/점유 검사는 유지한다. 진입 공간 계산에는 뒷기둥 중앙값이 아닌 가장 가까운 반환을 사용한다. 기본은 `contiguous_three_v0`로 보존하며 ROS 선택에는 아직 연결하지 않는다.

기본/명시값·부족한 점·넓은 분포·원거리 점으로 보충하지 않음·정지/이동/중복스캔과 기존 연결 회귀를 확인한 뒤 같은3조건을1회 비교한다. 관측 창 통과는 차량/정지/실물 증명이 아니다. 두 물체가 같은 창에 있으면 모두 점유로 남고, 합성 그림자나 외형을 만들어 경로를 허가하지 않는다.

## 희소 후보 결과와 제한 후속

관련145검사 뒤 같은3조건에서 접촉0·최대두바퀴·STOP·각600판단 동일·소스 불변을 확인했다. 오른쪽ideal은1.4초/간격1.0 m 진입·복귀, 왼쪽combined는2.7초/간격1.0 m 진입·복귀였다. 오른쪽combined는4.8초/간격1.0 m 진입으로 늦었지만 우회 중 점유 정지는0회였고2.638 m를 진행했다. 12초 주행 창 내 G1복귀는 실패했다. 종료 직전에도0.35 m/s로 복귀 중이었고 중심y6.6 mm·yaw−0.0965 rad이므로, 정체와 관측 창 부족을 분리하기 위해 이 조건만16초로1회 확인한다. 기존12초 실패는 유지한다.

이와 별도로 이동/이동후정지 개방형을 각12초1회 비교하여 이동 앞차 오우회와 진입 공간 유지 비용을 확인한다. 다음은 기존 교통1랩7,801호출 저장 입력의 준비 감속/우회 제안을 관찰한다. 제안 직후G2만 비우고 G1이력은 유지하며 출력은 적용하지 않는다. 새 전체 랩이나 자유 공간 증명이 아니다. 기존G1상세/입력무결성·변경소스와 처리비용을 함께 기록한다.

## 최종 제한 결과·후속 선택

- [오른쪽16초](extended1/report.json)는4.8초 진입·12.9초G1복귀·5.222 m·접촉0·최대두바퀴·STOP·800판단 동일이었다. 12초미복귀는 관측 창 안 실패로 보존한다. 희소 반환 중앙값이 흔들려 준비 누적이 초기화되는 지연은 남으며, [1.3→1.4초 진단](initial_delay_diagnosis.json)의68.9 mm 차이가 근거다. 이를 실제 상대차 이동이나 실차잡음분포로 해석하지 않는다.
- [이동/멈춤 개방형](traffic1/report.json)은 각각2.689/2.669 m·접촉0·최대0/2바퀴·STOP·각600판단 동일이었다. 이동 앞차는 우회 없이추종했다. 멈춤은6초/간격1.061 m에진입해표적을지났지만12초내G1복귀는미완료이며, 종료직전0.35m/s로복귀중이었다. 이를완료로올려쓰거나같은조건을자동반복하지않는다.
- [기존1랩 입력 비교](shadow1/report.json)는G1상세7,801/7,801일치·진입제안0·소스불변이었다. 새공간보존/희소반환후보전체의감속제안1,485회중1,467회가0명령이었다. 전부공간보존상한이작용했고, 그중1,392회는이동증거가있는조각이었다. 이는기존짧은추종간격궤적에서계산한제안이며새주행정지횟수/랩시간증명이아니다. 이전26회는공간보존OFF조건이므로1,485회를희소반환단독효과로비교하지않는다. 판단비용median15.02/p9530.63/max146.47ms도해당PC저장입력값이며Jetson50Hz증명이아니다.

**선택:** 희소반환후보는명시시뮬설정으로만보존하며ROS선택·운영기본에는아직추가하지않는다. 현재별도실행의기본`contiguous_three_v0`와일반G1기본은그대로다. 조각자체의노이즈지연·추종공간비용·중앙정지차·숨은뒤차·Gazebo접지문제·실물은미해결이다. 같은정체를완벽히없앨때까지반복하는대신, 다음에는기존M3도로내측방주행의상대차형상만개방형으로바꿔동적희소반환영향을본다.
