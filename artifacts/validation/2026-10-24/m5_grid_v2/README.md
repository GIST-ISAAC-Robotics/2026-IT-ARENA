# M5 공식 그리드 정지 기하·촬영 v2

범위·판정은 [v1](../m5_grid_v1/README.md)과 같다. v1 사전 회귀 실패를 보존하고 grid paint의 병합 링크/visual pose 표현만 지원한다. 공식/실행본의 실제 합성 pose·치수 일치를 그대로 요구하며 중복과 잘못된 visual pose 반례를 추가한다. 물성·센서·시설·차체 위치·간격 문턱은 바꾸지 않는다. 한 묶음 1회 실행한다.

## 결과

- 회귀 20/20, SDF 검사 `Valid.`, 실행 exit 0. [기하·시야 보고서](preflight/report.json)의 registry는 공식 입력과 현재 실행본의 합성 pose/치수가 일치했다.
- 2/3/5대 모두 명목 차체의 겹침·도로 이탈·낮은 벽 겹침은 없으나 최소 간격은 **0.0299833 m**로 현재 0.15 m 교통 시험 비교 기준에 못 미친다. 조향·출발 중 간격을 확인한 결과가 아니다.
- 공식 신호등 배열은 현재 카메라의 여섯 그리드 시야 모두 위로 벗어난다. 지면 기준과 현재 시뮬 초기 spawn 높이 0.01 m 대조에서도 동일하다.
- [정지 렌더링](preflight/capture/report.json)은 3개 시점별 서로 다른 시각의 3프레임, 1280×720 RGB를 받았다. 5대는 정지 상자이며 제어기·MCU는 실행하지 않았다. 실제 주행·출발 신호 인식의 통과가 아니다.
- 정상 종료(launch exit 0, 자식 2/2), 강제 정리·잔존 0, 소스 불변. 주 에이전트가 사진 3장을 확인했다. 원래 실패 [v1](../m5_grid_v1/README.md)은 보존한다.
- 상세 해석·재개 조건: [M5 보고서](../../../../docs/autonomy/GRID_START_M5_2026_10_24.md).
