# M5 카메라 피치 기하 — 사전 등록

현재 B0183 높이·좌우방향·화각과 고정 공식 램프 위치/크기는 유지하고 상향 피치의 수직 포함 구간만 계산한다. 여섯 공식 칸·명목 지면/초기 spawn 0.01 m를 비교한다. 전체 영상과 현 검출기 상부 58% 영역을 구분하며, 구체 중심의 포함 필요조건과 보수적 cube 전체 포함을 구별한다.

전체 영상 공통 구간이 있으면 그 중앙값 한 개만 전체 핀홀 투영으로 대조한다. 가림·빛·검출 성능은 검사하지 않는다. 같은 피치에서 평지 전방 바닥과 높이 .35~.45 m인 10 cm 판의 정면 .5/1/2 m 시야를 보조 계산한다. 후자는 실제 코스 마커 접근/검출 시험이 아니다. 운영 카메라·공식 월드·검출기·시설을 변경하지 않고 Gazebo도 실행하지 않는다. 계산·관련 회귀 1회만 수행한다.

## 결과

- 단일 실행 exit 0, 관련 **25통과·실패/skip 0**. [시험 로그](tests.log), [JUnit](junit.xml), [기하 계산](result/report.json), [실행 명령](run.sh), [소스 대조](source_check.txt). 입력 6개 불변, 시험 자식 잔존 없음. GPT 구현·검토, GPT-6 Luna 실행·회수.
- 전체 영상의 보수적 수직 포함 공통 구간은 지면 z=0에서 상향 31.479–48.234°, spawn z=0.01 m에서 31.191–47.998°다. 중앙값 39.857°/39.594°의 전체 투영에서는 각각 6/6칸이 화면 안에 들어온다. 이 각도를 운영값으로 채택하지 않았다.
- 현 검출기 상부 58%에는 중심점만으로도 공통 각도가 없다. 명목 높이에서 필요한 하한 30.959°가 상한 29.098°보다 크다(spawn에서도 동일한 불가능 판정).
- 중앙값 대조의 상부 58% 포함은 2/6, 적색→녹색 좌→우 순서는 3/6이다. 수직 시야에 넣는 것만으로 현 검출기/배열 문제가 해결되지는 않는다.
- 중앙값 각도에서는 수평 지면의 전방 바닥이 화면 아래 밖이다. 높이 0.35–0.45 m 판은 정면 0.5 m에서 전체 포함되나 1 m에서는 아래 일부가, 2 m에서는 전부가 아래 밖이다. 실제 마커 배치·가림·인식 성공률이나 장착 권고를 뜻하지 않는다.
