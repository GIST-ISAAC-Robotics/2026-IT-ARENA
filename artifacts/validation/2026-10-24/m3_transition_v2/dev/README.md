# dev — 동결 전 탐색 산출물(판정 근거 아님)

`m3_execution_trial.py`를 만들면서 저장 입력으로 돌려 본 중간 결과다. 실행 사이에 소스가 바뀌었으므로
어떤 수치도 동결 결과로 인용하지 않는다. 동결 판정은 상위 폴더의 `run3_execution_replay`를 따른다.

| 폴더/파일 | 당시 소스 상태 | 확인한 것 |
|---|---|---|
| `probe1` | 시작 자세 고정·한 주기 실행+정지 원호·이력 지지·직진 출발 첫 판 | 기록 조향에서 측방 선택 뒤 양수 46/100/0(G1/R0+/정지·재개). 정지·재개는 앞차 근처 계획 관측 거절이 남음 |
| `probe2` | + 계획 관측을 앞 물체 접촉 진행까지만(포함 비교 ≤) | probe1과 같음. 접촉 자세 자체의 앞면 질의가 남아 효과 없음을 확인 |
| `probe3`, `probe3_self` | + 접촉 자세 제외(<), 기록 조향/자기 조향 반사실 | 정지·재개 기록의 기준 대비 양수 손실은 기록 조향 11, 자기 조향 반사실 1(직진 출발 양수 10판단) |
| `probe4_self` | + 결과 불변 최적화(측방 반환 없을 때 격자 생략·후보 순차 평가·질의 역변환) | probe3_self와 3기록 출력·이유 차이 0, 중앙값 약 5–6 ms |
| `smoke5` | 동결 직전 | 동결 run17 판본 재호출이 run17 정지·재개 수치(548/564, 동일 727)를 재현 |
| `profile_probe.py`, `patch_perf.py` | 비용 분해·일회성 편집 스크립트 | 실행 증거가 아님 |

모든 행은 원래 G1/R0+ 기록의 센서·자세를 쓰는 개루프 재호출이며 주행·안전 결과가 아니다.
