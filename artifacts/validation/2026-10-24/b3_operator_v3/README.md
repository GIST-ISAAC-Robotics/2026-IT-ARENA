# B3 명시 운영 도구 v3 — 사전 등록

[v2](../b3_operator_v2/README.md)의 전송 전 시간 초과를 보존한다. 응답 유실 시험만 기존 도구 기본 5초를 사용하고, timeout endpoint 수·서버 수신 명령 수로 전송과 응답 유실을 구분한다. 기본 도구 시간값·제어/보호 값은 바꾸지 않는다. 관련 검사 묶음 1회, MCU/센서/Gazebo/실물 없음.

## 결과

84통과·실패 0·skip 0, exit 0(30.96초). 새 도구 관련 32개와 기존 B3 52개가 함께 통과했으며 이전 전체 4,769개와 합산하지 않는다. 소스 6개 불변, 격리 domain 123 실행 전후 노드 없음·자기 시험 프로세스 잔존 없음.

- 실제 `LocalPursuit`와 도구가 상태 조회→해제→새 경기→옛 번호 미전송 거절→STOP을 처리했다. 센서/MCU 없음·끝까지 0목표였다.
- 응답 유실에서는 서버 명령 수 정확히 +1, 클라이언트 `unknown_after_send`, 자동 재전송 없음, 서버 래치 유지가 확인됐다. 응답 없는 서버는 실제 timeout으로 `not_sent`다.
- 명시 executor로 바꾼 뒤 v1의 executor 소멸 경고는 재발하지 않았다. ROS_LOCALHOST_ONLY 지원 중단 예정 경고는 도메인 조회에서만 남았다.
- v2의 1.5초 discovery 실패는 보존한다. 기본 5초 성공만으로 모든 환경의 연결 시간을 보장하거나 v2 실패를 소급 통과로 바꾸지 않는다.
