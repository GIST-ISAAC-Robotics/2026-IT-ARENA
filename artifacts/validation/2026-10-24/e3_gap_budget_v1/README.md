# E3 정지 자세의 횡간격 손실 분해

기존 G1 도로 내 옆차 실행의 최소 간격 판단 시점을 이용한다. 자차 중심 이동과 yaw가 도로 횡축에 투영된 차체 폭에 주는 영향을 따로 계산한다. 옆차는 등록된 직선 일정의 횡위치·도로 정렬 자세, 차체는 기존 20×15 cm 명목 사각형이다.

0조향으로 버텼으면 성공했을 것이라는 반사실 주행 주장이 아니다. 네 정적 조합은 실제 도달 가능한 경로인지 검사하지 않으며, 양의 투영 간격은 분리 하한이다. 음의 투영 간격도 곧바로 실제 접촉을 뜻하지 않는다. 판단선·제어기·센서·물성·이전 결과는 바꾸지 않는다.

## 결과

- [기하 결과](report.json), [표준 출력](stdout.json). t=5.44 s에서 중심 이동은 0.0399445 m, yaw 약 10.50°의 추가 반폭은 0.0169659 m로 합계 0.0569104 m의 횡여유를 사용했다.
- 초기 평행 0.0700007 m → 이동만 0.0300563 m / yaw만 0.0530348 m → 실제 자세 조합의 투영 간격 0.0130903 m. 저장된 원래 다각형 최소 간격 0.0130900 m와 이 직선 장면에서는 근접한다. 일반적인 다각형 거리 동치로 확대하지 않는다.
- 보고서 생성까지 7개 기하 항등식·입력 5개 전후 해시 대조를 완료했다. 제어기·기존 주행·판정은 변경하지 않았고 GPT-6 Luna가 단일 계산을 실행했다.
- **실행 기록 한계:** PowerShell→bash의 종료 코드 변수 인용 오류로 계산 뒤 wrapper가 `numeric argument required`와 exit 1을 반환했다. `exit.txt`는 빈 파일이다. 본체는 보고서와 stdout 생성까지 확인했으나 별도 Python exit code는 확보하지 못했으므로 전체 실행 정상 종료로 표시하지 않는다. 다시 실행하지 않았다. 다음 실행은 인라인 변수 보간 대신 저장된 bash 파일을 사용한다.
