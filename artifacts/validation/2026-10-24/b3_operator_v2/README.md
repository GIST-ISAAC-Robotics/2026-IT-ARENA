# B3 명시 운영 도구 v2 — 사전 등록

[v1](../b3_operator_v1/README.md)의 실행 범위와 판정을 유지한다. 도구의 전용 ROS Context에 맞는 명시 executor를 사용하고 수명을 정리한다. 시험의 빈 endpoint 전제를 복구하고 전송 전 실패 본문·실제 timeout을 검사한다. 센서·MCU·Gazebo·실물은 실행하지 않는다. 제어기·보호 계약·기본값을 바꾸지 않으며 같은 묶음 1회 실행한다.

## 결과

83통과·1실패·skip 0, exit 1. 소스 6개 불변, domain 및 자기 자식 프로세스 잔존 없음. v1 endpoint 전제·기본 executor 소멸 경고는 재발하지 않았다.

응답 유실 검사는 `not_sent / timeout`으로 실패했다. 전송 후 응답을 잃은 상황 자체에 도달하지 못했다. 이 검사는 도구 기본 5초보다 짧은 1.5초 안에 ROS discovery까지 마치도록 구성돼 있었다. 정확한 endpoint 발견 시간은 v2에 없으므로 원인을 그 수치만으로 확정하지 않는다. [v3](../b3_operator_v3/README.md)는 도구 기본 대기값으로 검사하며 시간 초과의 endpoint 수와 실제 서버 명령 수를 남긴다. 실패를 정상 응답 유실 결과로 바꾸지 않는다.
