# E3 옆차 실패의 저장 자료 분석

- `analyze.py`: 실제 판단 시각에 가까운 평가 자세를 결합해 조향·횡이동·간격을 요약한다. `g1.json`, `r0plus.json`은 새 제어기 재생/반사실 주행이 아니다.
- `hit_audit.py`: 초기 접근 구간 3.6–6.6 s의 순차 광선 끝점을 취득 시각의 actor 사각형 주변 15 mm와 대조한다. 실제 상대차 검출기·정체 식별·실측 정확도 검사가 아니다. 최초 실행의 Python 패키지 검색 경로 누락을 수정한 뒤 계산했으며 원시 자료는 바꾸지 않았다. 출력에 원시 입력 해시를 보존한다.
- 두 실행의 최초 간격 미달 시점과 최소 간격, R0+의 14.997 s 최초 접촉을 구별한다. 초기 광선 진단의 시간 창은 R0+ 후반 접촉 시각을 포함하지 않는다.
- 결론·설계 검토는 [E3 보고서](../../../../docs/autonomy/MULTI_ACTOR_E3_2026_10_24.md#72-시간축-분석-단순-미검출만의-문제는-아님)에만 둔다.

마감 때 두 실행의 소스 63개를 원본 판정 해시와 대조해 [별도 보존](../e3_onroad_v1/preservation.json)했다. 변경한 문서 10개의 로컬 링크 대상 375개는 모두 존재했고 `git diff --check`를 통과했다. 이는 Markdown 앵커 전체/외부 사이트의 실시간 검사는 아니다. 새로운 주행·기준 변경·커밋·푸시는 하지 않았다.
