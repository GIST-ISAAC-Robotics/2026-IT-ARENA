# 최소 IMU 수신자 대조

해석 기준은 [A3 보고서](../../../../docs/simulation/JETSON_REPLAY_2026_09_28.md)에 둡니다. 이 자료는 수신 경계를 좁히기 위한 진단이며 실제 센서·모터 시험이 아닙니다.

## 고정 조건

- 정상 `capture_v2`의 원본 CDR·1배속·`legacy`·SHM 단독 16 MiB를 유지합니다. IMU/엔코더 발행 추적과 콜백 진단을 켭니다. 일반 실행 기본값은 `system`/`legacy` 그대로입니다.
- A는 기존 두 제어기, B는 동일 제어기에 최소 IMU 수신자 하나를 추가합니다. 순서는 **A–B–B–A**입니다. 추가 구독/프로세스의 부하 때문에 완전히 같은 실행 부하는 아니며, 누락 개수 차이를 곧바로 개선 효과로 해석하지 않습니다.
- 최소 수신자는 기존 IMU와 같은 `BEST_EFFORT·KEEP_LAST·depth 5`, 같은 legacy `spin_once`를 사용합니다. 제어·영상 계산·시계 입력 없이 header 시각과 같은 호스트의 단조 콜백 진입 시각만 메모리에 저장하고 종료 후 파일로 기록합니다. 250,000개 상한 초과는 실패이며 조용히 버리지 않습니다.
- 기존 제어기는 콜백별 진단 메시지도 발행하지만 최소 수신자는 발행하지 않습니다. 따라서 차이는 제어 계산 하나만이 아니라 다른 구독·타이머·시계·계측까지 포함하는 **전체 수신 경로의 차이**입니다. 기존 `duration_ms`는 진단 JSON 작성/발행 이전에 끝나므로 IMU 콜백 본문 시간만으로 계측 비용까지 작다고 단정하지 않습니다.
- 추가 수신자는 제어 명령을 발행하지 않습니다. 수신 QoS·센서율·보호 기준을 바꾸지 않습니다. A는 4개, B는 5개 participant의 실제 전송 설정을 확인합니다.

## 적용 및 검증 근거

- `tools_manifest_v1.json`: 재생기·실행기·최소 수신자·신규 단위 검사 **4파일만** 적용하는 묶음. 원시 기록·제어기 소스/설치본·환경 설정은 제외합니다. archive 17,592 bytes, SHA-256 `5bd0804a7c483205a390ec170e541610cd8615f12ad3ab7f9995a6b2aa36a55c`.
- `pc_tests_v1.log`: 관련 PC 검사 **47개 통과**. Windows 임시 폴더 쓰기 권한으로 실행되지 않은 파일 검사는 WSL에서 수행했으며, 그 권한 오류를 코드 검사 성공으로 계산하지 않았습니다.
- 정상 종료/파일 해시·행 수 일치와 센서 전량 수신은 별개입니다. 분석기는 원본 시각·발행 추적·양쪽 완전한 진단·최소 수신자 결과를 대조합니다. 중복 또는 예상 밖 시각, 불완전 기록은 분석에서 거절합니다.

## 실행 결과와 보존

- `jetson_tests_v1.log`: Jetson 관련 검사 **27개 통과**.
- `jetson_results/imu_probe_v1_{a_control,b_probe,c_probe,d_control}/`: ABBA 순서의 원자료. 모두 기능·스케줄·계측·EOF 정지·정상 종료 통과, D만 주행 비교 구간 안전 0명령 2개로 운영 실패입니다. 성공한 세 회로 D의 실패를 덮지 않습니다.
- `comparison_v1.json`: 4/5개 실제 participant, 입력 수신·엔코더 지연·운영 판정·자원 사용 비교.

- 네 회의 공통 실행 소스 23파일 해시가 동일하고 적용한 도구 4파일과 원본 센서 입력 5파일 해시 검증이 통과했습니다. 최소 수신자 `samples.jsonl`의 행 수·SHA와 정상 종료를 함께 확인했습니다.
- 원시 bag가 없는 결과 archive는 `build/jetson_imu_probe_results_v1.tar.gz`에 보존합니다. 원격/로컬 SHA-256 `a7c2cada7a1cec83f26a0343f842a2c59221219c98a041ceef9b218b99510da2` 일치, 잔존 시험 프로세스 없음 확인.

DDS 내부 도착 시각·실제 큐 점유·버림 이벤트는 직접 계측하지 않았습니다. 최소 수신자 추가를 생산용 개선으로 채택하지 않았고 일반 DDS·executor·QoS·보호 기준은 유지합니다.
