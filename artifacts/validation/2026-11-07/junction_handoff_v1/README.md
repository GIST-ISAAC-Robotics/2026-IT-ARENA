# 갈림길 앞 현재 선호 벽 재획득

2026-11-07. r10은 C6를 돌아(평가 좌표x4.288,y3.978) P22 출구 전에26.35 m에서 정지했다. 현재 선호 벽은1.403 m까지 관측되고 벽 거리는0.489 m로0.505±0.12 m 범위 안이다. 반대 벽은0.297 m로 짧아진 뒤 `wall_segment_short`가 된다. 현재 경계 경로가 없는 것이 아니라, 이전 회랑 경로는 기본 경계 기억으로 이어지지 않고 새 기본 경계는 두 긴 벽을 요구하는 상태였다. 이 좌표는 진단 전용이다.

명령 불변 진단1365/1365를 확인했다. 이미 운영 재개에 쓰던 `standing_wall_reacquire`를 켠 저장 입력에서는491명령이 변하고28초 이후377회 양수 명령이 나온다. 최초 변경25.72초 이전 명령은 같았다. **고정 입력 재생이므로 실제 완주 증거가 아니다.**

새 경계 메모리/보호 조건을 추가하기 전에 기존 옵션을 단독 CLI에서 명시 선택하도록 연결했다. 낮은 모터 환산 속도≤0.10 m/s·현재 선호 벽의 길이≥0.65 m·앵커·서로 다른 스캔 확인을 사용한다. 상대를 무시하거나 기억만으로 달리지 않으며 현재 점유·부분 관측·독립 보호·STOP은 그대로다. 즉 이미 감속한 뒤 다시 이어가는 후보이며 불필요한 감속 자체를 모두 해결하지 않는다.

관련 회귀가 통과하면 원래1 mm 단차·B0390·C1·같은 속도/구동의 본선1회를 실행한다. 통과하면 미세 정지 단축보다 출발 가림/기존 증속 후보·빠른 상대 등 미완성 기능으로 이어간다. 실패하면 최초 주요 원인과 기존 제한 결과를 남긴다.
