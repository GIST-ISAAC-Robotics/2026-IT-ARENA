# 새 코스 잔디 단차·헛돎 대조

2026-11-07, 작업 중. [원본 실패](../traffic_course_migration_v1/r6/straight_moving_lead/run2/report.json)와 [명령/모터/차체 대조](baseline_slip.json)를 먼저 보존했다.

## 질문과 변경 범위

새 코스 오른쪽 앞차 추월→양보 장면에서 차체가 정지했지만 양의 구동 명령·모터축 회전이 계속됐다. 사용자가 이전에 허용한 ‘헛돎이 있으면 도로·잔디 단차 제거 대조’를 적용한다. 단차가 원인이라는 결론은 아직 아니다.

`--grass-alignment road_level`은 v2026.11.06 **실행 사본**의 잔디 collision/visual 952개 z만 +1 mm 옮겨 상면을 도로와 같은3 mm로 만든다. 기본 `original`, 공식/팀 원본·도로·벽·마커·마찰·물리 step·차량/차동·제어기·상대 각본·출발 위치·판정은 유지한다. 기록된 local_pursuit에서만 실행하며 `grass_alignment.json`으로 실제 적용을 남긴다. 고정2 mm 잔디 box와 다르면 실행 전에 거부한다.

r7 계약은 r6 뒤에 연결한다. 단일 같은 장면을 새 경로에서 1회 대조한다. 제한 대조의 결과를 실물 접지나 전체 코스 완료로 확대하지 않는다. 바퀴별 접촉/미끄럼 센서의 직접 측정은 아직 없다.

## 현재 상태

구현·기본 출력 보존/형상 변경 범위 관련194회귀를 통과하고 동일 장면1회 대조를 끝냈다. 다음 작업은 결과 기록 후 본선 남은 코너의 관측 경계 연결이며, 지름길 전략·단독 속도·교통/운영 과제를 잊지 않는다.

## 복귀 경로 거절의 범위 진단

`guide_diagnosis.py`는 출력 변경 없이 저장 입력525/525를 재현했다. 현재 벽 검사407회 중201회가 `_wall_covers_guide`에서 거부됐다. 첫 거절14.06초에는 앞쪽 끝1.844 m·실제 반환129개로 긴 벽이 보였지만, 경로 시작x가+0.0010 m였다. 거절 전체의 시작 범위는+0.00055～+0.03072 m, 끝은1.844～1.946 m였다. 복귀 중 보완의 ‘시작x≤차체중심0’ 조건을 조금 벗어난 경우다. [기계 결과](guide_extent_summary.json).

앞서 ‘현재 복귀 벽이 짧다’는 오류 이름만으로 벽 전체가 짧았다고 읽으면 부정확하다. 앞쪽 길이는 충분하고, 후방/차체 중심까지 기준 경로가 걸쳐야 한다는 조건 때문에 멈췄다. 후속 후보는 진입·현재 상대 확인·외벽 재확인·실제 이동 영역 검사는 유지하고, 이미 복귀 중일 때 관측 시작이 현재 차체 앞부분 안에 있는 경우를 별도로 검토한다. 공용 제어기에는 아직 이 수정이 없다. 본선 후보 실행 중에는 런타임을 바꾸지 않는다.
