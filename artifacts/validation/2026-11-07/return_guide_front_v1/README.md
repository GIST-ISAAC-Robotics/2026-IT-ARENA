# 앞차 가속 후 복귀 경로의 관측 시작 조건

2026-11-07. 이전 [평탄 대조](../traffic_surface_alignment_v1/README.md)의 정지는 현재 벽 경로 시작점이 차량 중심보다0.5～31 mm 앞이어서 생겼다. 전방 길이는1.84 m 이상이었다.

현재 선택형 `moving_pass_trial`에서 이미 복귀 중이고 현재 상대의 앞/뒤 여유가 확인된 경우, 기준 경로 시작을 차체 앞부분 안까지 허용한다. 차체 길이20 cm에서 시작x≤10 cm이며 관측한 경로를 뒤로 늘리지 않는다. 진입에는 적용하지 않는다. 현재 연속 외벽·반환12개·전방65 cm·현재 상대 확인·벽 일치·실제 이동 외곽 관측/점유 검사를 유지한다. 이 기준선 확인은 미관측 공간을 자유 공간으로 판정하는 단계가 아니다.

저장 입력525호출에서14.06초 전 명령 변화0, 이후17.6초까지0→양수173호출이었다. 첫14.06초0.353 m/s. 저장 차량 위치는 고정이므로 실제 복귀 완료로 해석하지 않는다. r9 실제 연결·관련 회귀 뒤 r7과 같은 평탄 교통 장면1회를 대조한다. r8 본선 직각 옵션은 이 교통 시험에서 OFF다. 기본 월드의 잔디 높이는 바꾸지 않는다.

원시 실패·등록 소스·명령·해시·STOP/종료를 별도로 보존한다. 대표 복귀 결과 후 본선 경계 확인과 지름길 전략 검토로 진행하며, 빠른 상대·단독 속도·출발/운영을 전체 계획에 유지한다.

## 연결 확인

관련343회귀 통과, 실제 연결525/525명령이 사전 shadow와 일치했다. 최초 두 실행은 Bash 시작 전 `Wsl/Service/E_UNEXPECTED`로 미실행이었다. 같은 오류가 `/bin/true`에서도 발생했으며, 자기 시험이 종료된 Ubuntu-24.04를 다시 시작한 뒤 정상 실행했다. 최초 오류와 `recovered` 결과를 구별해 보존한다. WSL 내부 오류 원인 자체는 미확정이다.

같은 평탄 장면으로 소스 등록 후 폐루프1회를 실행한다. 소스/설정이 바뀌면 등록한 실행을 그대로 강행하지 않는다.

## 실제 대조 결과

같은 평탄 조건에서 진행3.21→4.75 m, 첫 출발 뒤0.05 m/s 미만 최장3.136→0초로 개선됐다. 초록 뒤8.719초에 양보 후 추종 복귀가 완료됐고, 이후0.916 m 진행했다. 현재 센서로 미리 준비한 G1에 인계하는 r16 연결도 이 장면에서 확인했다. 상대 가속에 양보해 뒤로 돌아온 결과다.

원래 평가표는 **최종 간격1.262 m(1.2 m 상한)와 차체 전체 도로 안 조건 실패**로 `passed=false`, harness exit1이다. 현행 두 바퀴 잔디·대표 양보/복귀/후속 진행의 보충 판정은 통과다. 앞차가 움직이는 동안 양의 진행을 유지한 제한1회이며 모든 추월/교통/실차 완료가 아니다. 잔디 평탄 조건도 명시 선택 시험에만 적용됐다.

최고 차체1.194 m/s, 출발 뒤 평균0.515 m/s, 명시STOP·차체 실제 정지·정상 종료·잔여 프로세스0·877개 등록 해시 불변을 확인했다. 센서 로그는 모터축 단일 환산값이며 좌우 바퀴 센서를 따로 측정한 결과가 아니다. 원시 `run2/report.json`, `assessment_run2.json`, `surface_run2.json`, `run2.exit`를 보존한다. 다음은 본선 관측 경로 표본 간격 문제를 보완하고, 지름길 비교/대표 정상 추월/출발·운영으로 이어가는 것이다.
