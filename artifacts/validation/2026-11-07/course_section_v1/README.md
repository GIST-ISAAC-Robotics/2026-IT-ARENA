# 본선 단면 이관 대조

2026-11-07. [첫 B0390 주행](../b0390_course_baseline_v1/README.md)은 실제 RGB 신호를 확인했지만 0 m 진행 후 `follow_boundary_unconfirmed`로 종료했다. 접촉은 없었으며 STOP/종료는 정상이다.

## 수정 범위

- 옛 45 cm 본선의 경로 오프셋 .425와 반폭 .225를 기본값으로 보존한다. 새 61 cm 코스 선택에서 .505/.305만 전달한다.
- `FollowConfig.road_half_m`으로 본선 반폭을 전달하고 M3·측방 위협 공통 구성도 같은 단면을 사용한다. 잘못된 경로/측방 단면 조합은 기존과 마찬가지로 거부한다.
- 단면 사양은 지도 위치·주행 순서가 아니며 자유 공간 근거가 아니다. 근거리 점유·미관측 처리·거리 오차·제동·STOP은 변경하지 않는다. 지름길은 별도 단면·정책 평가 대상이다.
- 동일한 센서 정지 기록의 구/신 단면 비교는 원인 진단용이며 실제 진행 증거는 아니다. 같은 새 코스·B0390·속도 프로필로 제한 주행 1회를 준비한다.

## 결과

- 영향 회귀 **297 통과**(91.68 s). 구/신 본선 단면의 경로·측방 일치, 반대 벽 미관측, 기존 기본값·재생·출처 계약을 포함한다.
- 같은 정지 입력 380호출의 구 단면 양수 명령은 **0회**, 신 단면은 **371회**였다. 최초 양수 명령은 t=8.42 s. 이는 원인 분리용 개루프이며 진행 증명이 아니다.
- 같은 조건 실제 주행 1회는 **9.0 m·최고 2.5515 m/s(9.19 km/h)**까지 진행했다. 첫 직각 코너 약 0.6 m 앞에서 `follow_boundary_unconfirmed`로 대기해 실패했다. 출발 직선의 단면 불일치는 해소됐고 코너 경로 문제는 남았다.
- 접촉 0, 정리 STOP 수락·조밀 자세 정지 통과, 정상 종료·자식 종료 `[0,0]`·잔여 시험 프로세스 없음. 실제 반환코드 1·벽시계 240 s, 등록 **851개 입력 변경 0**.
- [주행 보고서](run1/report.json)·[정지 입력 비교](replay_width.json)·[실행 반환코드](run1.exit)·[무결성](postflight_integrity.json). 코너 저장 입력 진단을 이어가며 같은 주행을 변화 없이 반복하지 않는다.

기존 첫 주행 실패와 당시 소스는 그대로 보존한다. 새 코스 한 랩·갈림길·교통·실차 성공으로 확대하지 않는다.
