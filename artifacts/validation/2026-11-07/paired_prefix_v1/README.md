# 새 직각 코스의 긴 선호 벽·짧은 반대 벽 공통 구간

2026-11-07 설계 탐색 후 기존 선택형 직각 후보에 연결했다. 관련227회귀 통과·OFF643명령 동일·연결ON1221명령이 shadow와 일치했다. 등록한 소스857개로 단독1회를 마쳤다. **26.27 m 진행 후 경계 재확인 대기로 미완주**다. 원본 실패와 당시 입력은 보존한다.

## 문제와 최소 변경 방향

직각 경로 후보 주행은25.72 m에서 멈췄다. 끝 입력31.82초에서 선호 왼쪽 벽은 길지만 반대 오른쪽 관측은약0.478 m다. 두 경로는 가까운 구간에서 일치한다. 기존 짧은 경로 보완은 선호벽이 짧고 반대벽이 긴 경우만 허용하여 역할이 반대인 이 경우에는 쓰이지 않는다.

새 후보는 **선호 경로를 그대로 조향 기준으로 두고 양쪽 경로가 공통으로 관측된 첫 구간 끝까지만 자른다**. 짧은 반대쪽을 따라가도록 강제하지 않는다. 기존 공통거리8 cm·최소공통길이25 cm·편측 시작길이차체1대분·앵커12 cm 조건, 현재 점유·관측·정지 예산을 유지한다. 새 조합의 정지 예산은 짧은 벽의 실제 관측 길이도 상한으로 사용한다. 미관측 공간을 자유로 채우지 않는다.

`probe.py`는 공용 함수를 메모리에서만 변형해 저장 반올림 점군과 대표 반례를 조사했다. 최종 정지 입력과 좌우 반전에서 기하 지지가 나왔다.25.02초의 앵커 불일치는 계속 거부된다. 일곱 대표 대조 중 공통 구간만 승인하며 먼 시작·횡방향 불일치·반대 앵커 불일치·둘다 긴 경우·원점 이탈·중간 분리 뒤 재진입을 거부했다. 첫 인공 polyline 반례의 입력 오류와 수정 근거는 `counterexample_fixture_note.md`에 보존했다.

이는 경로 기하 탐색일 뿐, 제동/관측을 합친 출력 또는 실제 진행 증거가 아니다. 현재 실행 중인 잔디 평탄 대조 소스는 수정하지 않았다. 그 실행 완료 후 기존 선택형 직각 후보에 한정하여 연결·회귀·저장 입력 대조하고, 의미 있는 출력 개선이 확인될 때 단독 주행1회로 이어간다. 기본 활성화·물성·속도 상한·독립 보호 경계는 이 변경에 포함하지 않는다.

## 저장 입력 결과와 연결 범위

공용 코드 변경 전 shadow에서 기존 직각 OFF 입력643/643 동일·명령 변화0, 직각 ON 원본1221/1221 재현을 먼저 확인했다. 후보는 ON 원본의355개 명령을 바꿨으며 최초0→양수는25.62초의0.35 m/s다.31초 이후86호출에서 양수 명령이 나왔다. 저장된 차량 움직임은 그대로여서 실제 진행/완주 증거는 아니다.

r8은 `short_prefix_evidence(..., allow_long_preferred=False)`의 명시 인자를 추가하고, 기존 `piecewise_wall_trial`을 켰을 때에만 이를 허용한다. 새 조합은 짧은 반대 관측길이를 `base_observed_ahead_m`에 남겨 기존 정지 예산의 상한으로도 사용한다. 기본 OFF·기존 짧은 선호벽 경로는 유지한다. 기존 raw 관측·점유를 지우거나 반대벽 긴 끝까지 경로를 연장하지 않는다.

r7 뒤 `paired_prefix_r8_sha256.json`으로2파일 변경을 등록했다. 정적 회귀와 `replay_connected.py`에서검토한 shadow와 명령 일치를 확인한 뒤 이전 단독과 동일 인자/원래1 mm 잔디의1회 주행으로 이어간다. `replay_shadow.py`/`probe.py`는 당시 r7 함수 소스 기반 탐색용이며 r8 이후 그 파일을 그대로 실행해 처음 실험을 재현했다고 주장하지 않는다. 당시 결과·before.zip으로 구분한다.

### 시간상 확인의 후속 원인 분리

`diagnose_confirmation.py`에서1327/1327명령을 그대로 재현하고 관측기 내부를 기록했다.27.62초에 이전/현재 경로는 각각 전방 창의x길이0.280/0.274 m였고 좌표 차이는 최대4.7 mm였다.27.82초에는 차이가0.73 mm에 불과했다. 그런데 공통 끝점으로 양쪽 표본을 다시 자르면 각 경로의 끝 표본 하나가 빠져0.25 m 요건을 못 채운다. 같은 경로를 서로 다른 간격으로 샘플링한 효과가 재확인을 계속1회로 되돌린다. 시간/센서 세대 오류나 큰 경로 변화로 확인된 것은 아니다.

후속은 확인 횟수를 낮추는 대신, 이미 계산된 관측 구간 안에서 경로 선분의 공통 길이를 비교하는 방안을 검토한다. 원시 LiDAR 결측을 메우거나 경로 끝을 외삽하지 않는다. 현재 후보를 무조건 승인하지 않도록 최소 공통길이·원래 표본 수·형상 오차·전방 진행 방향을 함께 확인한다. 공용 코드에는 아직 연결하지 않았다.
