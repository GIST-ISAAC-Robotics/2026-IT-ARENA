# 분리 경계 후보: 고정 관측 오차·정지 계약

관련 회귀 **117개**, 후보 35사례의 필수 판정 충족. 깨끗한 입력 2사례는 양수 명령을 확인했고, 정지 조건 21사례는 해당 조건 활성 구간에서 모두 0명령이었다(일부 사례의 고장 주입 전 양수 명령은 정상). 탐색 12사례에는 진행 합격선을 두지 않았다. 모든 사례에서 유한 출력·점유 검사 시 원래 반환 수 유지 조건을 확인했다.

탐색 입력은 3 seed × 무작위 ±3 cm·일정 −3 cm·일정 +3 cm·무작위 ±3 cm와 +3 cm의 조합이다. 각 8회 호출 중 후보는 6회 양수, connected 기준은 0회 양수였다. 이 숫자는 고정 장면의 정책 출력 횟수이지 진행 거리/완주율이나 실측 C1 정확도 보증이 아니다.

21개 정지 조건은 오차를 넣은 중앙 봉쇄 12개, 전방 미관측·갑작스러운 가까운 장애물·낡은 입력·음수 피드백의 시작 전/허가 후 각 2개, 확인 전 동일 스캔 재사용 1개다. 양수 제안 후 실제 차량을 이동시키지 않았으며 운동 이력은 0으로 고정했다. 단일 모터축 환산·실물 센서/물리·독립 ROS 보호층·제동 거리는 여기서 실행하지 않았다.

500 광선/10 Hz 취득 시각, 최근접 가림·후방 60° 마스크를 유지한다. 정답 상자 라벨은 거리 생성기에만 존재하고 제어기에는 전달하지 않는다. `results/report.json`과 `source_snapshot.zip`에 설계 조건·시험 소스 해시·결과를 보존했고 `source_unchanged=true`다. 원시 외부 파일을 입력한 시험이 아니므로 외부 입력 해시는 없다.
