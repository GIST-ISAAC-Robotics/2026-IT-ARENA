# 공식 신호등·그리드 기하: 회전 부호 대조

v1에 보존한 고정 공식 `scene.json`/`world.sdf`를 그대로 재사용했다. `run.sh` exit 0, 회귀 6개 통과다. `result/geometry.json`은 모든 원래 조건과 새 −90°/높이 0.30 m 좌표 조건을 포함한다. 입력·분석 소스 해시와 `result/analysis_source.zip`을 보존했다.

−90°와 높이 0.30 m를 함께 쓴 **진단 좌표**는 6/6그리드에서 5광원이 화면 안이며 빨강→초록이 왼쪽→오른쪽이다. +90°의 반대 순서와 원위치의 상단 이탈은 그대로 남는다. 기하 조건 확인이지 검출 성공/전체 가림 해소가 아니며 높이·카메라/램프 설치 변경을 채택하지 않았다.
