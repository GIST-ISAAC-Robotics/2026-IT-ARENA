# G2 준비: 간격을 유지한 정지차 우회 기하

2026-10-13 실행 전 등록. 운영 주행/보호/물성/센서를 변경하지 않는 정답 기반 기하 분석이다. G0 단면 폭만으로 G2 우회 가능성을 선언하지 않기 위해 기존 G1 간격 0.15 m와 G0 양옆 여유 0.025 m를 유지한 경로족을 검사한다. 서로 다른 여유 조건임을 구분하며 같은 오차를 중복 추정한 안전 모델이라고 부르지 않는다.

- 직선 도로 폭 0.45 m, 차체 0.20×0.15 m, 축거 0.135 m, 조향 상한 0.37 rad 유지.
- 정지 상자 x=1.5 m·폭 0.15 m. 중심 y=0/±0.10/±0.15/±0.20/±0.24 m, y=0.20 m의 ±30° 회전, 낮은 0.06 m 표적 포함. 도로 안/일부 잔디/관측 불가능 표적을 구분한다.
- 후륜축 기준 5차 횡이동–평행 구간–복귀. 편이 0/±0.075/±0.10/±0.125/±0.15 m × 전이 길이 0.6/0.9/1.2 m의 유한 경로족이다.
- 5 mm 이하 x 표본마다 차체 다각형 간격을 계산하고, 경로의 해석적 기울기·곡률 상한에서 구한 구간 강체 이동 상한을 빼서 보수 하한을 낸다. 표본 간 틈을 검사 없이 통과시키지 않는다. 조향 통과도 표본 최대가 아니라 해석적 상한으로 판정한다.
- 기하 조건 충족은 실제 추종·가시성·동적 물체·제동·복귀 허가가 아니다. 모든 결과에 `driving_authorized=false`를 유지한다. 후보가 없다는 결과도 모든 가능한 곡선의 부재 증명은 아니다.
- 도로/표적 정답은 평가 도구에만 있으며 제어기로 전달하지 않는다. 새 시뮬레이션 주행·Jetson·외부 게시 없음. 최초 실패/원시 결과 보존, 기준 완화 없음.

## 결과

`run.sh` exit 0, 회귀 50개 통과, 12조건 × 27경로 = 324개 분석·소스 불변이다. 기하 조건을 충족한 12개는 표적 중심 y=±0.24 m에서 각 6개였다. 반대 방향 편이 0.075/0.10 m × 전이 길이 0.6/0.9/1.2 m다. 이는 표적 폭 일부만 도로에 걸치는 조건이다.

나머지 유한 후보는 도로 여유/차체 간격/조향 상한 중 하나 이상을 만족하지 않았다. G0 단면 폭만 충분한 것과 실제 전이 곡선의 조건 충족은 달랐다. 낮은 표적(y=0.20 m)은 평면 기하 후보도 0이며 스캔면 미교차도 별도 한계다. 높이는 기하 후보 판정에 사용하지 않았으므로 미검출 때문에 후보를 거절했다고 해석하지 않는다.
