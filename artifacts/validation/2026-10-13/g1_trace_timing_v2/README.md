# G1 trace 시각 대조 — 원천과 pose 기준 분리

처음 저속으로 표시된 값은 해당 pose 시각의 순간 속도가 아니다. 6.059 s 부근에는 이미 0.01 m/s를 넘는 실제 자세 변화가 있었다. 따라서 **두 표본에서 안정 정지한 뒤 중간에서 움직였다고 단정할 수 없다.** 밀집 구간의 1.055 mm 이동·최대 0.014158 m/s·0.01 m/s 초과 64 ms와 원래 사후 감사 실패는 유효하다. 동시 토크/적분만으로 기계적 원인을 확정하지 않는다.

trace의 `t`는 수신 시계가 아니라 최신 pose 원천 시각이다. 구동 진단은 pose보다 0~21 ms 이전, safe command는 1~19 ms 이전, MCU 상태는 4 ms 이전~1 ms 이후였다. MCU의 +1 ms 3건은 비동기 채널 시각 차이이지 미래 취득/시계 고장의 증거가 아니다. v1의 오분류를 이 의미에 맞게 고쳤다.

`freshness_certified=false`, `continuous_stop_certified=false`, `original_verdict_changed=false`. callback 수신/발행 큐 지연을 직접 측정하지 않았고 pose 차분은 표본 구간 평균이다. trace 채널 전체를 하나의 동시각 상태처럼 사용하지 않으며 제어 입력에 정답 속도/자세를 넣지 않는다.
