# 오른쪽 벽 가림 후보의 제한 회귀

2026-10-13 실행 전 등록. 왼쪽 가림·초기 대기·첫 U자 코너의 후보 1회씩과 마커 역할 검사를 마감한 뒤, 아직 미실행인 오른쪽 조건만 확인한다.

- `config/tests/g1_side_occlusion_v1.json`의 `side_right`, seed 0, `fragmented_candidate`. 기존 6.5 sim s·최소 진행 3.2 m·정렬 후 횡오차 최대 0.06 m·옆차 앞 0.3 m·간격 0.15 m·STOP/정상 종료 조건을 유지한다.
- 명령 상한 1.0 m/s, C1 순차 10 Hz·모터축 28카운트/15:1/65 mm·임시 신호·독립 보호·기본 물성 유지. 도로 밖 잔디의 평가용 상자이며 실제 병렬 경주/우회가 아니다.
- 한 번 실행하고 판단 재생·관측 감사를 한다. 실패를 숨기거나 판정선을 조정하지 않는다. 새 안전/정지 실패가 있으면 후속 실행보다 첫 원인을 우선한다. 성공해도 기본 프로필을 바꾸거나 전체 G1 합격으로 선언하지 않는다.
- 이전 실행의 원시 기록/실패/소스는 보존한다. 선언한 source list만 해시 확인하며 전체 런타임 의존성 재현을 보장하지 않는다. 이벤트 접촉 0만으로 연속 무접촉을 증명하지 않는다.

`run.sh`가 실행·재생·사후 감사를 수행한다. G2는 별도 기하/관측 설계만 검토하며 이번 실행에 우회 동작은 없다.

STOP 후 안정 정지 0.966 sim s·차체 변위 0.169055 m, 정상 종료·상위 4개 exit 0·최종 잔존 0·선언 소스 불변을 확인했다. `replay.json`은 374/374 일치·입력 불변이다. `postcoverage.json`은 상태/trace 65표본·최대 공백 0.220 s·최대 상태 나이 0.205 s, STOP 마지막 0.5초 249구간에서 pose 속도 최대 0.009425 m/s로 필수 관측 검사를 통과했다. 지속 HOLD 비교 구간은 없어 비적용이다.

왼쪽·오른쪽이 각각 한 번 통과했다는 결과이지 동일 조건 반복 신뢰성이나 실제 병렬 경주/우회 성공은 아니다. 개별 drivetrain/safe-drive timestamp 신선도와 연속 물리 무접촉, 실차 정지는 미검증이다. 기본 후보 채택·물성·보호선 변경 없이 이 묶음을 마감하고 G2 사전 기하/관측 검토로 이동한다.
