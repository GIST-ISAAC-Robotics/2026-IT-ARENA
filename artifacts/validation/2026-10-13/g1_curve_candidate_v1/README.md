# 분리 경계 후보의 첫 U자 코너 회귀

2026-10-13 실행 전 등록. 왼쪽 가림·앞차 초기 대기/재진행과 C2 입력 감사/PC 비용 준비를 마감한 뒤 이어지는 **별도 제한 회귀**다. 직선의 실제 벽 조각 활용이 곡률이 있는 기존 코너 추종을 해치지 않는지 확인한다.

- 기존 `config/tests/g1_traffic_extensions_v1.json`, `first_curve`, seed 0을 그대로 사용한다. 후보 `fragmented_candidate`와 판단 기록만 명시한다.
- 최대 명령 1.0 m/s, C1 10 Hz 순차 취득·모터축 28카운트/15:1/65 mm, 독립 보호·물성·서비스 종료·기본 GC를 유지한다. 기존 출구 s=9.8 m, 방향 변화 150°, 진행 11.7 m, 최소 간격 0.15 m·벽/도로·정지·정상 종료 조건을 완화하지 않는다.
- 기준은 10/7 첫 코너 제한 실행이며 같은 물리 입력의 solver 성능 비교가 아니다. 지도/정답 자세는 평가 전용이고 앞차는 평가기가 옮기는 정적 상자다. 임시 3등 신호는 실행 트리거일 뿐 공식 출발 검증이 아니다.
- **한 번 실행** 후 첫 실패 또는 통과 근거를 검토한다. 자동 seed 증식·동일 solver 반복·오른쪽/G2/고속화·기본 후보 채택은 하지 않는다. 실패를 성공할 때까지 재실행하지 않는다.
- 실행 전후 소스 SHA, 정지/자식 종료/잔존, 판단 재생 일치를 확인한다. 이벤트성 접촉 0개를 연속 물리 무접촉으로 해석하지 않는다.

`run.sh`가 실행/재생을 담당한다. 결과는 완료 후 이 문서에 추가한다.
