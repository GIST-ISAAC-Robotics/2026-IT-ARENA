# 차량·코스 마커 역할 분리 검사

2026-10-13. 운영 코드는 수정하지 않고 합성 RGB 픽셀 → 현행 `recognize` → `VisionPipeline` 채택 → 실제 `LocalPursuit.control` 분기 선택을 검사했다. ROS 노드/토픽/구동/시뮬레이션은 만들지 않는다. 하위 구동 함수만 테스트 더블로 대체한다.

`run.sh`: 회귀 **85개 통과**, `pixels/report.json`: 32장면 × 임시/공식 후보 신호 모드 = **64사례 통과**, 선언한 소스 불변. OpenCV 4.6.0. 소스는 `pixels/source_snapshot.zip`에 보존했다.

- `DICT_4X4_50` 차량 ID 1/7/11/14/49는 기존 좌/우 분기 선택을 유지한다. 11/14는 공식 기록의 불일치 때문에 둘 다 검사했으며 새 공식 상태 조회는 아니다.
- `DICT_7X7_100` ID 91은 3종 크기 × 4회전에서 현행 4x4 검출기에 검출되지 않으며 분기도 바꾸지 않는다. **미검출은 차량 부재가 아니다.** 7x7 차량 인식을 추가했다는 의미가 아니다.
- 코스 0/20/30/45와 차량 마커 동시 노출에서 기존 코스 선택, 무마커의 이전 선택 유지, 20/30 동시 노출의 기존 right 우선순위를 확인했다.
- 회귀에는 ID 49 중복 제거와 코스 ID 30을 차량이 쓸 경우 ID-only 방식으로 구별할 수 없다는 한계도 포함한다. 새로운 우선순위·소유자 인식 규칙은 만들지 않았다.

앞선 [v1 시험기 타입 오류](../marker_roles_v1/README.md)는 보존했다. 노드를 초기화하지 않은 실제 파생 타입으로 시험기만 고쳤다. 실제 조명·거리·흔들림·가림·임의 오검출·주행/출발 기능의 실물 보장은 하지 않는다.
