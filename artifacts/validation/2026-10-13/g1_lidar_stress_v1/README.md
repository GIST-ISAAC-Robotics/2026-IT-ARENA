# G1 C1 거리 오차/추가 지연 — 첫 조건 실패 보존

시작 위치 행렬과 별도다. 위치 묶음 마감 후 실행했으며, 첫 왼쪽 가림 조건의 진행 실패로 예정된 나머지 두 조건은 실행하지 않았다. 아래 준비 경위와 실패 원시 증거는 그대로 보존한다.

## 범위

기존 순차 취득 어댑터의 시험용 `lidar_test_profile`을 재사용한다. 첫 점/점별 취득 시각은 그대로 두며 방사 오차와 발행 지연만 추가한다. 제어/독립 보호가 동일한 `/scan`을 받도록 유지한다. ±3 cm는 여기서 시험용 경계이며 제조사 오차 확률분포·실측 교정값으로 주장하지 않는다. 지연 또한 스트레스 가정이다. 9/22의 양쪽 바퀴 엔코더 조건을 이번 모터축 구성의 성공으로 재사용하지 않는다.

예정 대표 조건은 무오차 위치 묶음이 끝난 뒤 **왼쪽 가림의 균일 ±3 cm**, **앞차 초기 대기의 +3 cm 편향**, **첫 U자의 ±3 cm + 50±20 ms 추가 지연** 각 최대 1회다. 기존 1 m/s·간격/도로/STOP/종료·v6 사후 감사를 요구하고 첫 실패에서 후속 주행은 보류한다. 운영 기본/물성/보호 임계값을 바꾸지 않는다. 300 ms 출발 거부나 모든 seed 조합으로 범위를 무작정 늘리지 않는다.

## 주입 증거 검사

`g1_lidar_stress.py`는 요청 설정과 실제 취득 기록, 순차 500점/100 ms 시각, 추가 발행 지연, 누적 오차 통계 및 수신 스캔 header를 대조한다. 설정 파일이 있다고 주입 성공으로 간주하지 않는다. 누락/시간 재작성/설정 불일치/무오차/초과 오차/역전·중복 반례를 둔다. 수신 대조는 모든 제어 콜백 처리나 Jetson 실시간성을 증명하지 않는다.

최초 회귀는 18통과·1실패였다. 실패는 합성 0.051의 부동소수점 표현을 테스트가 정확한 등호로 비교한 문제였으며 허용 오차 비교로 고쳤다. 실제 주행·판정선을 바꾼 것이 아니다.

후속 준비 회귀 `unit_tests.log` 35개, `unit_tests_v2.log` 42개가 통과했다. 후자는 +3 cm 고정 편향의 부호/크기, 선택형 설정의 저장소 경로·값 검사, 제어/보호의 공통 `/scan` 요구, 기존 실패를 성공으로 덮지 않는 추가 무결성 판정을 포함한다. 두 개의 인라인 셸 시도에서는 ROS Python 경로 전달이 끊겨 `sensor_msgs` import가 실패했으며, ROS와 workspace 환경을 명시적으로 불러오는 `.sh` 실행으로 확인했다. 설치/센서/주행 장애로 해석하지 않는다. 아직 평가기 연결·폐루프 스트레스는 실행하지 않았다.

## 평가기 연결과 실행 전 확인

위치 행렬 7조건이 모두 완료된 뒤에만 평가기를 수정했다. `--lidar-test-profile` 생략 시 무주입이며, 명시하면 저장소 내부 설정을 검사하고 정규화한 실행 사본·해시를 보존한다. 기존 순차 어댑터에만 설정을 넘기고 제어/독립 보호는 같은 `/scan`을 받는다. 종료 후 실제 발행/오차 통계와 수신 시각을 대조해 주입 무결성을 추가 요구한다. 기존 실패를 성공으로 바꾸지 않는다.

실제 주입 큐를 포함한 준비 45회귀가 통과했고, 연결 후 최초 검사는 **179통과·1실패**였다. 예전 STOP 소스 해시만 현재 파일과 비교하던 시험에 새 후속 계약 연결이 빠져 발생했다. 옛 계약은 보존하고 `lidar_stress_eval_r0_sha256.json`으로 변경 이력을 연결했으며 관련 **180회귀**, 전체 **1,976회귀**가 통과했다. `check_source_snapshot.zip`과 로그를 보존했다. 제어/센서 모델 기본값·차량/물성·보호 한도는 변경하지 않았다.

## 실제 첫 조건 결과

`side_left_uniform_s0`는 validator 1, 재생 0, 사후 감사 2로 종료했다. 실패 gate는 `progress`와 `clears_side_actor`뿐이다. 진행 2.01981 m(<3.2 m), 최종 앞선 거리 -0.7981 m(<0.3 m)였으며, swept 차체 간격 하한 0.249252 m와 밀집 STOP·정상 종료·소스 보존은 통과했다. STOP 마지막 0.5초는 243구간·최대 간격 3 ms·최대 구간속도 0.009592 m/s였다.

실제 주입 110스캔/55,000점과 수신 110스캔을 대조했다. 최대 절대 오차 0.0299994 m·RMS 0.0173384 m, 추가 지연 0, 무효화 0으로 주입 무결성은 통과했다. 판단 재생 363/363도 일치했다. v6의 실패는 원래 주행 실패를 그대로 반영하며 옛 희소 HOLD 모순 표시는 진단으로만 보존했다.

예정된 초기 대기 +3 cm 편향과 첫 U자 오차/지연은 **미실행**이다. 성공까지 재시도하지 않고 [점별 시각 후보](../g1_per_ray_v1/README.md)를 별도 소스·등록 조건에서 준비했다. 원 실행은 새 결과로 덮어쓰지 않는다.
