# G1 기록 판단의 PC 비용 분해 v1

회귀 32개 통과. 두 성공 입력 각각의 원래 판단을 먼저 재생 대조하고 워밍업 1회 후 3회 계측했다. 출력은 모두 같고 입력/소스 해시 불변이다. 파일 읽기/JSON/출력 대조는 비용에서 제외, 기록 복원·운동 투영·G1 판단은 포함한다. ROS·영상·보호층·구동·입력 도착을 함께 실행하지 않았다.

| 입력 | 계측 호출 | 전체 p50 / p99 / 최대 ms | 20 ms 초과 |
|---|---:|---:|---:|
| 왼쪽 가림 | 1,122 | 4.474 / 18.773 / 25.453 | 4 |
| 앞차 초기 대기 | 1,656 | 3.561 / 23.089 / 28.336 | 18 |

20 ms는 기존 50 Hz 주기의 참고선일 뿐 여기서 실시간 마감이 보장된 것은 아니다. 긴 호출은 운동 투영 단계에 많이 겹치지만, v1은 벽시계만 재어 CPU 계산/스케줄 대기/메모리 회수를 구분하지 못한다. 후속 v2는 native GC 설정을 유지한 채 관측과 스레드 CPU 시각만 추가하며, 이 결과를 근거 없이 알고리즘 복잡도 문제로 단정하거나 GC를 끄지 않는다. 각 소스 스냅샷/세부 분포는 `side/`, `initial/`에 있다.
