# C2 실물 입력 감사기 준비 — 합성 파일 검증

관련 회귀 **89개 통과**, 예시 CLI 종료 코드 0이다. `example_report.json`의 입력 해시·변경 없음과 감사기/환산 모듈 해시를 기록했다. 예시는 **합성 엔코더 5개·IMU 5개**이며 실물 취득 기록이 아니다.

파일 무결성 판정은 true, 420카운트/평균 바퀴 회전·0.48620 mm/카운트 환산을 확인했다. 외부 고정으로 지정한 합성 구간의 bias 후보는 `[0.01,-0.02,0.03]` rad/s지만 **미적용**이며 차체 정지 확인도 false다. `ready_to_drive=false`, 절대 지연 미측정·자동 시계 매핑/교정 없음이 유지된다.

파일 단위·순서·새 부팅 분리·기존 출력/입력 덮어쓰기 거절 등의 검사다. 센서 전기/온도/축 실측·PCNT 확장 펌웨어·실제 통신·MCU 구동·제동을 검증하지 않았다. [파일 계약·운용 경계](../../../../../docs/hardware/HARDWARE_CAPTURE_AUDIT_2026_10_13.md).
