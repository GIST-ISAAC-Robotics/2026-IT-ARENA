# G1 판단 단계 스냅샷·재생

2026-10-13. 판단 단계 재생은 완료했고, 왼쪽 가림 주행은 여전히 실패했다. 기록/재생 통과와 주행 성공을 구분한다.

## 목적과 경계

외부 `/autonomy/status`의 저주기 요약만으로는 내부 경계 기억을 정확히 복원할 수 없었다. 선택형 `g1_trace_path`는 **LocalPursuit.command가 G1을 실제 호출한 순서**에 따라 입력 스캔, 그때의 환산 후 엔코더·자이로 이력, 기준 시각·세대·선호 벽·직전 조향·설정과 G1 반환값을 기록한다. 외부 센서 콜백 원문 전체나 RGB 인식·WallFollow 증속 제한·보호층·MCU·물리까지 재생하는 것은 아니다.

- 기본 경로는 빈 문자열이라 파일/스레드를 만들지 않는다.
- 활성화 시 기존 파일을 덮어쓰지 않는다. 기록 큐는 유한하며 디스크 쓰기는 별도 스레드다. 호출 스레드가 입력을 복사하고 writer가 JSON 직렬화/I/O를 담당한다.
- NaN·±Inf와 마스크를 구별한다. 미관측을 임의 거리/0으로 채우지 않는다.
- 정상 종료 footer·연속 sequence·큐 수락/쓰기·누락/오류 수를 검사한다. 누락된 기록을 재생 합격으로 세지 않는다.
- 재생은 입력 스냅샷에서 변환된 m/s·rad/s를 그대로 복원한다. 기어비·바퀴 반지름·gyro bias를 다시 적용하지 않는다.
- 판단 결과 수치 비교 허용치는 `1e-10`이다. 주행 안전 판정선의 변경이 아니다.

## 실행/증거

- `test.sh` → `tests.log`: 관련 회귀 **111개 통과**. 실제 command 경로의 기록 on/off 동등성, reset/예외 경로, 파일 보존, 누락/변조 거절을 포함한다.
- `run.sh` → `build.log`: 최초 colcon 탐색이 `artifacts/.../source_before`까지 찾아 중복 패키지로 **주행 전에 실패**. 원본 실패 보존.
- `run2.sh`: `--base-paths src`로 탐색만 제한. 빌드→사전 회귀→기존 `side_left` seed 0 한 번→STOP/종료→기록 재생. 기존 물성·제어 판단·센서·최고속도·판정선은 그대로다. 과거 원시 바퀴 접촉 조사용 센서는 이번 판단 기록 목적에는 추가하지 않는다.
- `analyze.sh`: 기본 재생 일치를 먼저 요구한 뒤 원래 경계 함수 반환을 유지하며 후보/형상 검사 경위를 오프라인 계측한다.

새 주행의 합격·정지·종료는 `side_left_s0/report.json`, 입력 기록 재생은 `replay.json`으로 따로 판정한다. 후처리 분석을 실제 주행 성공으로 확대하지 않는다. 원시 상세 JSONL은 로컬 보존/Git 제외, 소스 ZIP·해시·요약·실패는 추적한다.
