# 공식 신호등·그리드 기하 1차

`run.sh` exit 0, 좌표/시야 회귀 5개 통과. `result/scene.json`과 `result/world.sdf`는 공식 고정 커밋 `b27f94730b869837a804a3088447103d6b35b87e`의 읽기 전용 원문이며 URL·SHA-256은 `result/geometry.json`에 있다. 기존 공식 ZIP/운영 월드를 덮어쓰지 않았다.

| 좌표 조건 | 5광원 모두 화면 안인 그리드 | 빨강→초록이 왼쪽→오른쪽인 그리드 |
|---|---:|---:|
| 공식 원위치 | 0/6 | 3/6 |
| +90° 회전만 | 0/6 | 0/6 |
| z=0.30 m만 | 6/6 | 3/6 |
| +90°와 z=0.30 m | 6/6 | 0/6 |

공식은 30광원 모두 화면 위쪽이다. 좌우 순서만 맞는다고 열 분리나 검출 성공을 뜻하지 않는다. +90°는 초록을 왼쪽으로 보내므로 후속에서는 반대 회전 부호를 별도로 확인한다. 어느 진단 좌표도 실물 권장 높이/배치 또는 운영 설정으로 채택하지 않았다.

분석 당시 소스/카메라/회귀/실행 래퍼는 `source_snapshot.zip`에 있다(SHA-256 `553b54837c2abf64160f1819d44418f60bfc2fcefe4a0e6457d0a5dd60beecf4`). 구체를 감싼 직육면체 투영 범위를 보수적으로 사용하며 가림·렌더링·광학·실물 검증이 아니다. [해석/남은 설치 조건](../../../../docs/autonomy/RACE_START_CONTRACT_2026_10_13.md#5-공식-sdf의-그리드-시야-별도-기하-제약).
