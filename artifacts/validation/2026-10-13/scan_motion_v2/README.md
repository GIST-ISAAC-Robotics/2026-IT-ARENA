# 미보정 스캔/모터 이동 일치성 — 기록 전용 후보

- `run.sh`, `tests.log`, `run.log`, `result/report.json`: 단위 회귀 13개, 합성 15개 기대 판정 일치. 기존 G1 왼쪽 기록 128쌍은 전부 `unknown`이다. 새 Gazebo 실행은 없다.
- `source_snapshot.zip`: 당시 진단기·검증기·회귀 소스. 입력/소스 해시는 보고서에 있다. 원시 스캔/구동 기록은 기존 로컬 보존 정책을 유지한다.
- 앞선 `../scan_motion_v1/` 실패를 보존한다. 최초 3개 정상/불일치 사례는 초기 정합 보정량을 바로 거절해 실패했다. v2는 반복당 이동을 제한하는 방식으로 수정했으며 최종 채택 기준을 느슨하게 바꾸지 않았다.
- ±30 mm 균등 잡음은 제조사 표준편차가 아닌 스트레스 조건이다. 작은 앞차는 스캔 사이에서 위치가 바뀌며 각 스캔 중에는 정지한 단순 모델이다. 자차 광선은 순차 취득한다. 실제 동적 차량 전체 재현이 아니다.
- 일치 판정은 정적 장면/취득 왜곡 예산 가정 아래의 잔차 판정일 뿐이다. 정지 확인·SLAM·속도 대체·보호 해제에 사용하지 않는다. 정합이 어려운 기록의 판정선을 바꿔 성공시킬 계획은 없다.
