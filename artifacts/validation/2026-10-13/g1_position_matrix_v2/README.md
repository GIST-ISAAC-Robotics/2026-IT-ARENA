# G1 고정 시작 위치 잔여 7조건 — 실행 전 등록

2026-10-13. v1의 첫 `side_left_s1` 주행 gate·STOP·종료는 통과했지만 별도 감사가 실패해 일곱 실행을 보류했다. 그 감사는 서로 다른 시각의 저속 두 표본을 정지 완료로 취급했다. [원천 시각](../g1_trace_timing_v2/README.md)과 [요청/적용/실제 정지](../g1_hold_evidence_v1/README.md)를 확인했으며 v6는 원래 사례별 밀집 정지 요구로 잘못된 추론을 대체한다. 실제 이동과 구판 실패는 보존한다. v1 자체를 통과로 바꾸지 않는다.

## 조건과 중단 기준

- 선행: v6 관련 회귀·저장 입력 6개 감사 통과. 제어/물리 모델은 기존 후보 그대로며 새 STOP 종료 판정은 밀집 자료 완비를 추가 요구한다.
- **새 실행은 총 최대 7회**: seed 1의 오른쪽 가림·초기 대기·첫 U자, seed 2의 왼쪽·오른쪽 가림·초기 대기·첫 U자. 이전 seed 1 왼쪽을 다시 실행하지 않는다.
- 기존 `g1_side_occlusion_v1.json`, `g1_traffic_extensions_v1.json`의 모든 시간/속도/간격/도로·접촉·입력/STOP/종료 gate를 그대로 유지한다. 새 v6 사후 감사·판단 재생·소스 불변도 요구한다.
- 모든 단계의 첫 실패에서 나머지를 중단한다. 실행/계측 문제도 유효 주행으로 치지 않으며 성공할 때까지 같은 조건을 반복하지 않는다. 실패 기록·동일 조건 재시도 제한은 v1과 같다.
- 단일 모터축 28카운트·15:1·65 mm, C1 순차 10 Hz·최대 1 m/s·기본 G1 비활성/connected, 실험만 fragmented_candidate, service/GC native/예약 꺼짐을 유지한다. 센서·물성·보호 임계값·기둥/시설·Jetson/전원 변경 없음.
- 통과하더라도 3개 고정 시작 위치에 대한 제한 증거다. 잡음/지연 폐루프·전체 코스/경기·실물 안전을 뜻하지 않으며 기본 활성화나 G2 우회 채택은 하지 않는다.

종료 후 결과와 다음 우선순위를 기록한다. 커밋/푸시·외부 게시 없음.

## 결과 — 묶음 마감

등록한 7회 모두 validator·판단 재생·v6 사후 감사 exit 0이다. 기존 행동 gate·입력/하네스·STOP·종료를 모두 충족했다. 주 에이전트도 사례별 입력 8개 해시, 결과/정지 증거와 재생 일치를 확인했다. 아래 간격은 표본 최소값이 아닌 **표본 사이 swept 하한**이다.

최종 STOP 0.5초 창의 실제 표본 간격은 모두 최대 3 ms, 구간 평균속도 최대는 0.002609~0.009898 m/s였다. 모든 실행이 정상 종료·잔존 0·소스 불변이며 5,785개 판단이 일치했다. 초기 대기의 재진행 지연은 seed 1/2 각각 1.180/0.576초, 첫 U자의 방향 변화는 180.501/180.542°다. 이는 기존 시뮬 판정선의 결과이며 실차 정지거리·연속 무접촉이나 전체 코스 합격이 아니다.

이 묶음은 추가 반복 없이 마감한다. v1의 실패를 지우거나 v1 전체를 성공으로 수정하지 않는다. 다음은 [대표 C1 오차·발행 지연 3조건](../g1_lidar_stress_v1/README.md)이며 기본 활성화·G2 우회/고속화는 하지 않는다.
