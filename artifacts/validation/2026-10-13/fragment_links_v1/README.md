# 관측 조각 연관 후보 — 단일 ID를 강제하지 않음

2026-10-13 실행 전 등록. 정지 물체의 관측 중심이 이동하는 진단 이후, 중심점 최근접/차분 속도를 바로 사용하는 대신 기존 모터축·자이로 이력으로 이전 반환을 이송하고 조건부 후보 연결을 보존한다. 운영 코드와 연결하지 않는다.

- 각 점 쌍의 거리 상한: 물체 지름 + 속도 상한 × 두 점의 실제 취득 시차 + 양쪽 거리 오차 + 자차 이송 오차. 같은 물체일 **가능성이 있는 조각 쌍**을 전부 남긴다. 연결이 유일해도 identity 확정이 아니다.
- 물체 지름 0.25 m·속도 1 m/s·거리 오차 각각 3 cm·자차 이송 오차 3 cm는 평가 가정이다. 실물 오차의 확률적/절대적 보장이나 상대차 공식 속도 제한이 아니다.
- 분할/합침의 다대다 연결, unmatched, 세대 변경/이력 공백·시각 미진행·0.3초 source age·계산 용량 초과를 구분한다. 후보가 없거나 만료된 물체를 사라졌다고 판단하지 않는다.
- 입력/운영 점유는 변경하지 않고 차량 분류·완전 외곽·속도/정지·빈 공간·우회 허가는 만들지 않는다. 512반환·128조각을 넘으면 downsample로 숨기지 않고 분석 불가를 반환한다.
- 기존 좌/우/커브 저장 입력에 한 번 적용해 출처·기록 무결성·모호함/비용을 회수한다. 실제 물체 label이 없는 기록이므로 연관 정확도 수치를 만들지 않는다.

## 결과

회귀 51개 통과·선언 소스/세 입력 불변. 좌/우/커브 각각 74/74/357쌍을 모두 평가했고, 모든 쌍에서 여러 연결 가능성이 남았다. 최대 링크 수는 51/49/48, PC 단일 호출 최대 비용은 12.207/12.791/10.855 ms, 평균 8.958/9.103/8.343 ms였다. JSON 읽기/기록·ROS·센서/Jetson 지연을 포함하는 실시간 시험은 아니다.

모호함을 드러내는 데는 유효하지만 실제 물체 추적·속도 추정으로 바로 연결할 만큼 선택적이지 않다. 현재 제어 루프에 이 비용을 추가하지 않고 평가 기반으로 보존한다. 연결이 모호하다고 점을 삭제하거나, 가능한 여러 연결 중 가장 가까운 하나를 정답이라고 강제하지 않았다.
