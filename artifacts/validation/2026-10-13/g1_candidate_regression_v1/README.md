# 분리 경계 후보의 기존 기능 회귀

기존 왼쪽 가림 조건에서 후보 1회 통과와 고정 관측 오차 시험 뒤 시행하는 별도 회귀다. `run_tests.sh`로 전체 단위/회귀를 한 번 확인하고, 통과하면 `run_initial.sh`로 앞차가 가까이 정지해 있는 출발→대기→앞차 출발 후 재진행을 한 번 실행한다.

설정은 기존 `config/tests/g1_traffic_extensions_v1.json`의 `initial_occlusion`, seed 0을 그대로 쓴다. 단, 이번은 명시적 `fragmented_candidate`와 판단 기록을 활성화한다. 기존 진행/간격/정지/정상 종료 판정은 유지하며 기본 모드나 물성·단일 모터축·보호 경계를 바꾸지 않는다. 상대차는 평가기가 옮기는 정적 상자이고 공식 출발 신호를 검증하는 시험이 아니다. 임시 3등 신호만 실행 트리거로 쓴다.

전체 회귀는 **1,610개 통과 / 실패 0개**, 71.85초, 래퍼 종료 코드 0이다. `tests.log`에 보존한다. B3 소스 manifest의 정적 import 누락 방지 회귀도 포함한다.

폐루프 `initial_occlusion`, seed 0은 **passed/harness_valid/run_valid 모두 true**, 기존 12개 gate 통과다. 대기 구간 2.628 s, 앞차 출발 후 재진행 지연 0.874 s(상태 평가 해상도 0.1 s), 재진행 후 진행 2.140 m, 최소 swept 간격 하한 0.34976 m였다. 종료 시 앞차 뒤 간격은 0.6461 m다.

명시 STOP 안정 정지 확인까지 1.030 sim s·차체 변위 0.01371 m, 벽 충돌 표본 0. 자식 정상 종료·상위 프로세스 코드 0·잔존 0·소스 불변을 확인했다. 이벤트성 접촉 채널 0메시지는 연속 물리 무접촉 증명이 아니며 기하 간격 판정과 분리한다. `replay.json`은 **552/552개 일치**, 원시 판단 SHA-256은 `020a26d88a4c1c981b455d2b28edb5a08b5fd8d2c4dcf7cef9736cd84189d220`이다.

이번은 이전 기능을 후보에서 유지하는지 확인한 1회다. 다른 코너/오른쪽·전체 G1/실차로 확대하지 않는다. 기존 실패를 삭제하지 않으며, 추가 같은 시험 반복 대신 C2 실물 입력 준비로 이동한다.
