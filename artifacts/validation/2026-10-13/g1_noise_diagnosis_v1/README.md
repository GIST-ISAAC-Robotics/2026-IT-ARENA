# C1 오차 조건의 G1 진행 실패 분석

대상은 `../g1_lidar_stress_v1/side_left_uniform_s0` 원시 판단 기록이다. `analysis.json`은 363개 출력을 그대로 재현했고 `occupancy_probe.json`도 계측 전후 출력·입력 해시가 일치했다. 원시 입력과 실패를 수정하지 않았다.

간격 HOLD 7회는 모두 스캔 첫 점 나이 약 0.198초에서 발생했다. 해당 반환점은 대략 전방 0.29–0.48 m·측방 0.21–0.24 m였으며, 기본 여유 25 mm + 거리 오차 30 mm + 0.5 m/s × 0.198초가 합쳐져 0.154 m 팽창을 받았다. 새 스캔을 받으면 팽창이 줄어 다시 출발할 수 있었다. 5.72초의 경계 공통 관측 길이 부족과 역방향 속도 정지는 별도 원인이다.

고정 여유만 쓴 진단은 시간 성분의 영향을 분리하기 위한 비교일 뿐 제어안이 아니다. 실제 후보는 모든 반환점·같은 운동 상한을 보존한 [점별 취득 시각 계산](../g1_per_ray_v1/README.md)이다. 독립 보호층이나 물성을 수정하지 않으며, 저장 입력 분석을 실제 주행 결과로 취급하지 않는다.
