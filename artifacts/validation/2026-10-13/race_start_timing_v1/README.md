# B3 영상 큐 시간축 검증

`run.sh` 1회, exit 0. `tests.log` 관련 회귀 56개 통과, `run/report.json` 30사례·필수 25개 통과·탐색 5개. 조기 출발 없음, 입력/소스 해시 일치. 소스와 재사용 PNG는 `run/source_input_snapshot.zip`에 보존했다.

실제 VisionPipeline과 recognize를 호출하지만 결과 배송 시각을 가상으로 늦춘다. ROS/DDS·Gazebo·MCU를 구동하거나 Jetson 처리 성능을 측정하지 않는다. 공식 랜덤 구간은 각각 1/2/3초만 샘플링했다. 캡처 영상은 render v2의 진단 배열이며 red1~3은 미촬영이므로 소등으로 대체한다.

20/80/150 ms 합성 지연에서 출발했으며 250 ms 탐색도 출발했다. 300/400 ms 탐색은 미출발했다. 캡처 grid 2/3은 각각 20/150 ms 출발·300 ms 미출발이다. 섬광·누락·초록만·새 초기화·시각 고정은 미출발, 중복·역순은 출발을 앞당기지 않았다. 1.1초 지연은 watchdog 고장이다. 탐색 `passed=null`을 합격으로 세지 않는다.
