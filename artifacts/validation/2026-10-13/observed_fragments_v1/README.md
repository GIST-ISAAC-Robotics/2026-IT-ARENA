# 관측 조각의 출처 보존 감사

2026-10-13 실행 전 등록. 운영 제어에 연결하지 않은 `observed_fragments`를 이전 왼쪽·오른쪽·첫 U자 주행의 저장 입력에 적용한다. 첫 source epoch/frame/stamp 조합만 처리하고 같은 스캔의 재사용을 새 관측으로 세지 않는다.

- 모든 반환의 원점·끝점·방향·취득시각·인덱스를 그대로 보존하고 결측/마스크도 따로 보존한다. 작은 조각이나 오래된 조각을 버리지 않는다.
- 분리 기준 0.10 m + 가까운 거리 × 0.035, 취득 간격 2.1 ms는 탐색용 조각화 설정이다. 같은 조각은 같은 차량이라는 뜻이 아니고, 다른 조각도 다른 차량이라는 뜻이 아니다.
- 취득 순서 공백·결측·마스크·거리 급변에서 분리하며 스캔 이음매를 연결하지 않는다. 오래된 조각은 `fresh=false`, 외곽은 관측 끝점의 범위일 뿐 완전한 차체 외곽이 아니다.
- 기존 motion_scene은 모터축/자이로 이력으로 변환하며 정답 자세를 쓰지 않는다. 변환 실패는 별도 기록하고 삭제해 성공으로 표시하지 않는다. 기록 footer/순서 검사를 하되 판단 출력 재생은 이 감사의 범위가 아니다.
- 소스/입력 해시·결과 보존, 차량 분류·추적·자유 공간·우회/구동 허가 없음.
