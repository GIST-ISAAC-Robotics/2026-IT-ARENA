# 우회 진입 수정 후 새 공식 코스 경기 거리

[첫 300초 시도](../official_race_distance_v1/README.md)의 기둥 앞 교착을 분석하여 [진입 선택](../entry_obstruction_v1/README.md)을 수정했고, [같은 초기 배치 30초](../entry_obstruction_closed_loop_v1/README.md)에서 16.278 m 진행·정체 3.857초·STOP/정상 종료를 확인했다. 이 근거로 같은 경기 거리 시험을 한 번 수행했다.

월드·센서·물성·속도·앞차 및 오른쪽 옆차 각본과 [판정](trial_plan.json)은 첫 시도와 같다. 원인 변화 없는 재시도가 아니며 기둥을 제거하지 않았다. 원래 HOLD/15 cm/앞차 뒤 유지 판정은 보존하고 거리 5랩·접촉/노면·지속성·정상 종료와 구분한다. 기본 옵션 활성화·Jetson 실행은 하지 않는다.

[실행기](run.py)는 등록된 소스와 초기 30초 결과를 확인하고, 별도 로그와 원시 증거를 남긴다. 실행 결과는 아래와 같다.


## 결과

[독립 평가](independent_review.json)의 사전 경기 목표를 통과했다. 각본 상대 두 대와의 1회 실행이며 독립적인 다섯 차량 경기나 실차 증명은 아니다.

| 항목 | 결과 |
|---|---|
| 거리 기준 5랩 도달 | 실제 초록 뒤 **293.576초** |
| 각 랩 거리 통과 시간 | 68.729 / 56.290 / 55.430 / 57.544 / 55.584초 |
| 300초 뒤 명시 STOP까지 진행 | 238.384 m (초록 뒤 300.398초까지의 고밀도 자세) |
| 5 cm 범위 안 최장 정체 | **3.859초**, 최초 초록 뒤 앞차 대기 구간 |
| 차체 최고 표본 속도 | 1.576 m/s |
| 전방 상대 최소 간격 | 표본 0.778682 m / 표본 사이 보수 하한 0.777475 m |
| 우측 상대 최소 간격 | 표본 **0.079558 m** / 표본 사이 보수 하한 0.079556 m |
| 자차 접촉·겹침·벽 바퀴·도로 밖 차체 표본 | 0 |
| 바퀴 노면 | 152,512표본, `any/center/full` 모두 도로 밖 바퀴 최대 0 |
| 명시 STOP | 차체 정지·고밀도 자세·MCU STOP·사전 고장 래치 없음·마감 진단 없음·벽 충돌 없음 모두 통과 |
| 종료·입력 | `run_valid/harness_valid/source_unchanged/shutdown_clean=true`, 소스 ZIP 불일치 0, 프로세스 5개 종료 코드 0·잔여 없음 |

원시 `report.json`의 **`passed=false`와 실행 종료 코드 1은 보존**한다. 기존 `hold`·`final_gap` 조건이 실패했으며, 추가 옆차의 원래 150 mm 간격 검사도 실패다. 이 시험 전에 별도 등록한 경기 목표는 간격 표본·표본 사이의 비겹침, 유효한 접촉 관찰, 두 바퀴 이내 노면, 10초 미만 정체, 5랩·STOP·정상 종료를 함께 본다. 결과를 보고 원래 판정선을 바꾼 것이 아니다. 접촉 이벤트 0만으로 무충돌을 주장하지 않으며 표본 간 보수 간격 계산과 관찰 연결/기록 무결성도 함께 확인했다.

노면 계산에서 Shapely `unary_union` 수치 경고가 나왔다. [추가 기하 확인](surface_geometry_audit.json)에서 도로/잔디/벽 합집합과 **152,512개** 차체+바퀴 외곽이 모두 유효·유한·비어 있지 않음을 확인했다. 경고가 재현된 t=210.419초 외곽도 면적 0.0301056 m²의 유효 다각형이었다. 경고 원인을 단정하거나 원시 경고를 지우지 않았고, 주행이나 전체 노면 판정을 재실행하지 않았다.

처음 감시기의 정체 알림은 초록 전 `WAIT_GREEN`을 포함한 오탐이었다. `run1/stall_watch_evidence.json`은 보존하고, 그 알림으로 차량을 멈추지 않았다. 실제 최종 정체 평가는 관측 초록 7.401초부터 명시 STOP 307.799초까지만 사용한다.

## 다음 선택

기둥 앞 교착 수정은 같은 초기 30초와 이번 전체 거리에서 진행을 이어갔다. 이 대표 기능이 연결됐으므로 같은 장면을 더 반복하지 않고 [단독 속도 조합](../solo_ray_combination_v1/README.md)의 실주행 손익을 확인한다. 코너 병렬·오른쪽 재접근·비스듬한/개방형 상대·갈림길 동시 가림 등 미완성 교통 범위는 현행 계획에 남긴다. 기본 옵션을 자동 활성화하거나 모든 교통 상황을 완료 처리하지 않는다.
