# 단독 조합 후보 1랩 계획

- 기준은 같은 공식 v2026.11.01 월드의 [34.451초 단독 구성](../solo_alternative_speed_v1/README.md)이다. 후보는 기존 `ray_wall_continuity`만 추가하며 부모 증속률 1.5 m/s², 물성, 센서, 독립 보호, 무반환 정책, 출발·정지·노면 판정은 유지한다.
- 명시 시험 프로필 `g1_open_10kmh_solo_gap05_arc_preview_bridge_ray`로만 연결한다. 기존 프로필·기본 설정은 변경하지 않는다.
- 경기 거리 시험이 끝나 소스 고정이 해제된 뒤에만 launch/CLI에 프로필을 추가하고 소스·실행 인자를 등록한다. 실제 실행은 새 출력 폴더1회다. 실패의 원인 변화 없이 재시도하지 않는다.
- 우선 확인은 1랩 완주·접촉/벽/노면 표본·명시 STOP·정상 종료·입력 무결성이다. 접촉이나 미완주는 최고속도가 높아도 선정 근거가 아니다.
- 성능은 기준 랩 34.451초, 0속도 계획 명령 0.46초, 차체 최고 2.3977 m/s 및 빠른 속도 유지 시간과 함께 비교한다. 한 번씩의 실행으로 통계적 우위를 주장하지 않는다. 랩이 더 느려지면 최고속도만으로 기존 선정 구성을 대체하지 않는다.
- 기존 단독 시험과 같은 3인칭 영상을 기록한다. 영상만 실패하면 원래 주행 증거를 버리고 재주행하지 않는다. 원시 대용량 자료는 로컬 보존한다.

구현 시 CLI의 프로필 선택뿐 아니라 제작측 신호 시험 허용 목록과 `turn_preview.py` 입력 보존 목록에도 새 이름을 함께 넣는다. 기존 ray/bridge 시험의 명시 프로필 목록에는 두 후보만 허용하도록 갱신한다. 현재 경기 거리 시험이 끝나기 전에는 이 런타임 변경을 적용하지 않는다.
