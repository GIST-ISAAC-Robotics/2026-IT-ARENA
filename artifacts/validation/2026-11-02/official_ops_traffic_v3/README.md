# 같은 경기 복구와 정지차량 우회 결합

실행 전 조건은 [PLAN.md](PLAN.md), 원본은 `e1/`, 계산은 [analyze.py](analyze.py)와 [e1_analysis.json](e1_analysis.json)에 있다. 새 공식 월드, 단일 정적 상대, 가상 MCU, 선택형 교통·재획득 후보 ON이다.

## 결과

최초 RGB 출발 뒤 STOP·RESET, s=1.0 m로 심판 배치를 대역하고 START 한 번을 보냈다. 약 1.138초 뒤 주행이 허가됐고 앞의 정지차를 우회해 s=6.519 m로 복귀했다. 판단 482회 중 BYPASS 317회, REACQUIRE 5회, FOLLOW 160회였다. 새 입력 경계 검사 148회에 위반은 없었다.

- 최소 형상 간격: 표본 0.128693 m, 표본 사이 스윕 0.128671 m. 겹침·누락 0.
- 접촉 토픽에서 자차 접촉 0. 바퀴 노면 해석 3종 모두 최대 두 바퀴 잔디, 벽 바퀴 표본 0.
- 도로 밖 차체 표본은 우회 중 존재한다. 최종 복귀 꼬리 구간에서는 0이다. 도로 밖 차체가 없었다는 뜻이 아니다.
- 소스 불변, 모든 노드 정상 종료, 강제 종료·잔여 시험 프로세스 없음.

**실행 전체는 실패로 보존한다.** 실제 브라우저 STOP을 기다리는 알림이 버퍼링된 실행 출력 때문에 늦게 전달됐고, 180초 뒤 평가기의 API STOP으로 정리됐다. 주행·우회 결과는 확보했으나 화면 조작으로 정상 종료까지 끝낸 회차가 아니다. [브라우저 분리 시험](../official_ops_browser_v4/README.md)도 구별한다.

평가의 pose 시각은 중첩 `pose.header`에 있다. 처음 분석에서 이를 잘못 읽어 표본이 빠진 결과는 `e1_analysis_before_pose_parser_fix.json`에 보존하고, 원시 기록을 다시 읽어 수정했다. 주행을 재실행하거나 기준을 낮추지 않았다. 조향 노면 계산은 기록한 목표 조향이며 실제 관절각은 아니다.

전체 본선, 독립적으로 움직이는 상대, 실차·공용 Wi-Fi 검증은 아니다. 입력 정답은 평가 전용이다.
