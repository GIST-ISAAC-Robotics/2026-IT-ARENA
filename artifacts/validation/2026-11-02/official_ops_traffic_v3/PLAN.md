## 장면

0.20×0.15×0.12 m 정지 상대를 본선 s=2.1 m 중앙에 둔다(평가 전용 정적 actor). 최초 RGB 출발 뒤 s=0.5 m에 도달하면 운영 API의 STOP→RESET을 수행하고 심판 대역이 자차를 s=1.0 m 중앙으로 옮긴다. 같은 경기 START를 한 번만 보내고, 통로가 있으면 우회·복귀해 s=6.5 m 이상으로 진행하는지 본다. 지름길·정답 자세·actor 일정·그리드 번호를 제어기에 넣지 않는다. 정상 시 UI STOP은 실제 브라우저 버튼을 누른다.

## 판정

- 같은 경기·출발 사실 유지, START 1회 수락과 주행 허가 구별, 준비 구간에 경계 전 스캔 사용 없음.
- 실제 최종 BYPASS 출력이 존재하며 상대를 지나 FOLLOW 복귀, 본선 s≥6.5 m. 단순 내부 우회 제안이나 양수 속도를 우회 성공으로 세지 않는다.
- 표본 차체 겹침·관측된 접촉 0, 최소 간격 ≥0.08 m(기존 대표 교통 시험값), 최대 두 바퀴 잔디, 바퀴-벽 표본 0. 실제 간격과 표본 간격은 함께 기록하며 실측 안전 기준으로 부르지 않는다.
- 실제 브라우저 STOP 수락·MCU 정지 상태·평가 차체 정지, 소스 불변·정상 종료·잔존 프로세스 없음. UI의 실제 정지 표시는 계속 `미확인`이며 평가 정답을 UI에 넣지 않는다.
