# 선두 신호 미검출: 영상 밖과 검출 영역 제한의 분리

상태: **검출 영역 제한은 소프트웨어로 해소했다. 기본 수평 카메라의 선두 2칸 출발은 여전히 미완료다.** 광원이 영상 밖이므로 수평 설정에서 index 2·5는 볼 수 없고, 이 부분은 복원하거나 판독한 것으로 치지 않는다. 가상 상향 시점 20°·25°에서는 여섯 칸 모두 시험 초록을 거부하고 빨강 4 뒤 실제 초록에서 출발 판정을 냈다. 이것은 렌더 시점 후보이며 차량 설정 변경, 실제 장착, 상향 카메라 주행이 아니다. 이전 기록 [공식 시설 연결](../official_facility_v1/README.md)의 후속이다.

## 두 문제의 분리

| 문제 | 근거 | 성격 |
|---|---|---|
| 수평 index 2·5의 광원이 영상 밖 | 수직 반화각 23.3° < 올려본각 24.5–37.5°. 렌더 [slot2](../official_facility_v1/render_v1/slot2_red4.png) | 물리 시야. 소프트웨어로 해결 불가 |
| 고정 상단 58% 빨강 판독 | 진단 15°의 index 3에서 광원이 그 아래로 내려가 `waiting_red4` | 수평 장착 전제의 코드 제한 |
| 초록 탐색 사각형 전체가 영상과 상단 58% 안이어야 함 | 진단 15°의 index 2: 빨강 4 확인 뒤 `green_roi_outside`. 위쪽 탐색 여유만 영상 밖이었고 광원은 영상 안 | 코드 제한 |

## 수정

[`race_start.py`](../../../../src/arena_autonomy/arena_autonomy/race_start.py)만 판단이 바뀌었다.

- **빨강:** 배열을 아직 모르면 전체 영상을 본다. 전체 빨강이 온전한 배열 하나로 설명될 때만 상단 밖 위치를 인정하고, 아니면 기존 상단 58% 판독과 같다. 일부 조각을 골라 배열을 만들지 않는다.
- **확인 뒤:** 판독 범위를 그 배열 창까지만 넓힌다. 낮은 위치의 남은 빨강이 소등으로 잘못 보이지 않는다.
- **초록:** 예상 위치·간격·개수·크기 검사는 그대로다. 예상 광원 원판 전체가 영상 안일 때만 판독하고, 잘리는 부분이 있으면 `green_roi_outside`다. 영상 밖으로 나간 탐색 여유는 비교에서 빠질 뿐 채우지 않는다. 사각형 비율이 아니라 광원 개수·크기를 세므로 잘린 영역 때문에 비율이 커지는 경로가 없다.

11/2 수평 주행의 첫 검출은 약 3.2 m였다. 상향 후보는 먼 쪽 첫 검출이 늦어질 수 있고 가까운 쪽은 오래 보인다. 3 m 미검출의 원인은 조사하지 않았다. 기준 벽 전환 시점이 달라졌을 때의 주행 영향은 미검증이다.

## 다음 기구 판단에 전달할 후보

- **검토 후보:** 고정 상향 약 20°. 시험한 값 중 여섯 칸 판독과 광원 여유가 함께 성립했다. 25°도 신호는 성립한다. 확정값이 아니며 실제 720p 크롭·렌즈 왜곡·브래킷 공차·차체 가림은 미측정이다.
- **필요 확인:** 실제 사용 화각, 상향 장착에서 ID20/30 전환 시점의 폐루프 주행, 천장 조명·노출, 앞차가 있는 밀집 출발.
- **밀집 출발 한계:** 20°에서 index 4·0·3의 광원은 상단 58% 아래다. 이 경우 영상의 다른 곳에 광원 모양의 빨강이 있으면 배열을 확정하지 않아 **출발하지 않는다.** 안전한 쪽의 실패이지만 시도되지 않은 장면이며 앞차 가림과 함께 M5 확인 대상이다. 광원 모양이 아닌 빨간 차체는 지역 검출기가 분리한다.
- **기본 수평 유지 시:** 선두 2칸은 출발 불가다. 이 경우 운영 대안은 자동 출발이 아니라 규정 확인 대상이다.

## 검증

- **기본 수평 실제 출발:** [`start_run.py`](start_run.py)로 그리드 3, 6 m 1회. 실제 초록 8.050초, 출발 8.287초, [보고](start1/report.json) 통과, 접촉 0, 실제 정지·정상 종료. 영상 없는 출발 확인이며 랩 시간 근거가 아니다. [35.606초 run1](../official_facility_v1/README.md)은 수정 전 검출기 결과로 그대로 둔다. 이번 수정 뒤 전체 랩은 재실행하지 않았다.
- **회귀:** [영향권](tests_focus3.log) 221 통과·1 실패(종료 코드 1). 실패 `test_official_start_ros_fixture`는 이번 변경 전부터 같은 항목으로 실패하는 [기존 13건](../official_facility_v1/baseline_failed.log) 중 하나다. [새 시험](../../../../tests/test_official_start_region.py)은 낮은 배열의 전체 순서, 부분 소등 불인정, 추가 광원 시 축소 판독, 위치가 다른 초록, 한쪽만 켜진 초록, 잘린 광원 거부, 빨간 차체 분리를 본다. 전체 회귀는 새 근거가 없어 반복하지 않았다.
- **소스:** [수정 전 바이트](before.zip), [계약](../../../../config/tests/official_start_region_r1_sha256.json). `simulation.launch.py`는 저장소 줄바꿈으로 복원했고 run1 당시 LF 바이트는 before.zip과 run1 기록에 보존했다.
