# 현재 반대 벽 경로의 단독 속도 상한 시험

11/2 새 공식 월드의 35.606초 단독 결과와 같은 차량·물성·센서·점등·그리드 3·선택 고속 프로필로 한 랩을 한 번 실행한다. `solo_route_only`에서 이미 승인된 현재 반대 벽 경로에 고속 상한을 열고, 기존 길이·곡률·점유·독립 보호·부분 관측 상한을 유지한다. 기본값과 교통 구성에는 적용하지 않는다.

저장 입력 1,900판단은 기존 출력과 모두 일치했고 별도 후보의 명령은 209회 바뀌었다. 최대 증가 1.593 m/s, 조향 변경 0, 0명령에서 전진으로 바뀐 경우 0이다. 42–44 m 무반환 상한을 완화한 것이 아니다. [비교](../solo_observation_diagnosis_v1/alternative.json).

수용 조건은 본선 1랩, 접촉/벽/노면 기존 판정, 명시 STOP·정상 종료·소스 불변이다. 최고 속도·1초 평균 최고·랩 시간·같은 위치 2 m 구간·0명령 시간을 비교한다. 성공을 위해 재시도하지 않는다. 실패하면 원인과 경계를 남기고 변경 근거가 있을 때만 후속을 정한다. 한 번의 기록 단축을 모든 코스/실차 성능으로 확대하지 않는다.

실행: `bash artifacts/validation/2026-11-02/solo_alternative_speed_v1/run_once.sh run1`. 결과 수집까지 수행하고 원본 영상을 보존한다. 실시간 입력·원시 상세 로그는 기존 Git 제외 정책을 유지한다.
