# P22 관측 출구·본선 복귀 후보 r50

## 근거와 범위

r49는 입구 통과 후 경로가 끝나 정지했다. 같은 입력의 출구 제안 18개 중 가장 이른 23.22초 제안만 정적 노면검사에서 세 바퀴 이탈했다. 아직 입구 회전 조향이 -0.18 rad 남아 있었다. 다른 17개는 최대 두 바퀴 이탈이며, 이는 실제 추종 성능이 아니다.

현재 센서에서 통로 끝·맞은편 긴 벽을 찾고 반경 0.36 m/.65 m/s 경로를 만든다. 기존 입구 경로 끝 방향과 현재 차체 방향 차이가 8° 이내, 현재 조향이 ±0.14 rad 이내인 뒤에만 두 개의 서로 다른 스캔을 비교한다. 측정 운동으로 이송한 종점 차이 8 cm/방향 차이 8° 이내일 때 출구 후보를 연결한다. 이 수치는 실물 교정값이 아닌 제한 후보의 임시값이다. 모든 반환은 기존 점유·운동영역 검사에 남는다.

출구 말기에는 두 현재 스캔에서 기존 본선 주행기의 양수 명령을 확인한 뒤 복귀한다. 판단에 지도·정답 위치/자세·진행 구간을 넣지 않는다. 단독 명시 선택 `--p22-entry-trial --p22-route-trial`, 기본 false. schema7로 r49 입구만 기록(schema6)과 구분한다. 자동 리셋 중 활성 경로 중단은 기존처럼 래치하며 명시 RESET만 해제한다.

## 한 묶음

1. 관련 단위 검사, r49 833판단 불변 재생, 저장 센서의 첫 출구 전환 확인.
2. 소스·명령·평가를 고정하고 새 공식 단독 1회. 같은 물성/기어비/속도/보호층. 입구~출구 .65 m/s, 본선은 기존 설정.
3. 평가용 정답으로 입구와 출구 전체 차체 통과, 복귀 후 실제 진행 1 m, 접촉0·최대 두 바퀴 도로 밖·활성 구간 0.05 m/s 미만 연속 0.5초 이내·STOP/정상 종료를 확인한다. 제어기의 센서 운동 누적 1.2 m에서 시험 종료하여 평가용 1 m와 구별한다. 출구는 x≈4.8, y≈4.5에서 북향 본선으로 이어지며, 차체 전체가 x=3.81..4.81/y>4.8에 들고 북향±20°인지 확인한다. 완료는 최종 좌표의 조건만으로 결정하지 않고 실제 전이 기록과 함께 확인한다.
4. 원 본선100m/G1 검증기 실패는 유지하고 별도 제한 결과로 판정한다. 실패 시 원인을 분석하되 같은 조건 무변경 반복 금지. 본선/지름길 시간 비교·교통 합류·경기 자동 채택은 이 실행의 범위가 아니다.
