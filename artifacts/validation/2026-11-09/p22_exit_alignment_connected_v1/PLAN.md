# r51 입구 경로를 보존한 출구 정렬

r50은 출구 전환 때 현재 차체 방향의 직선을 새로 만들며 통로 한쪽으로 치우쳤고, 실제3.563초 저속·본선복귀실패를 남겼다. 당시 현재 관측 중심과 이송해 온 입구 경로 말단의 차이는 약49mm였다.

입구 경로 전체를 갑자기 교체하지 않고, 현재 위치/접선에서 남은 꼬리까지 quintic 횡이동으로 관측 중심에 맞춘 뒤 출구 회전을 잇는다. 센서로 관측한 양쪽 벽과 일치하는 말단 방향(5°)·최대10cm 오프셋·잔여25cm 이상일 때만 검토하고, 미래 부분의 최대조향.37rad·3rad/s 변화율을 직접 확인한다. 이 범위는 임시 단독 후보이며 실물 교정값이 아니다. 기존 두스캔 비교·점유/운동영역·독립 보호·STOP·물성은 그대로다.
