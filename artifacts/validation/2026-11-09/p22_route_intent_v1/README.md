# ID20부터 P22 입구 검토까지: 잘못된 출구 선택을 막는 미연결 비교

[입구 관측](../p22_sensor_preview_v1/README.md)·[조향 기하](../p22_entry_arc_probe_v1/README.md) 다음 단계다. 지도나 본선 진행 좌표 없이 **실제 ID20 영상 → 자이로의 좌회전 → 두 연속 라이다 스캔의 오른쪽 간극** 순서를 확인한다. 두 간극은 바퀴·자이로 이동 보정 후 양 끝이 맞아야 한다. 이 상태기는 조향을 발행하지 않으며, 기존 제어기를 감속시키거나 정지시키지도 않는다.

| 기록·입력 | 입구 검토 후보 | ID20 제거 | 입구 반환만 제거하고 원 출구 유지 |
|---|---:|---:|---:|
| r11 실제 영상 취득 시각 + 원 센서 | 21.92초 1회 | 0 | 0 |
| r27 원 영상 시각 누락을 그대로 반영 | 0 | 0 | 0 |
| r27 상태 시각을 영상 시각으로 가정한 별도 진단 | 33.42초 1회 | 0 | 0 |

입구를 놓쳤을 때는 다음 우회전이 관측되면 마커 의도를 소모하므로, 이후 같은 모양의 출구를 재선택하지 않았다. 원 입력은 각각 334/610개 스캔이다. 입구 제거는 사후 평가에서 식별한 시험 입력 교란이며, 정상 판단의 입력에 장소 정보를 주지 않았다. r27 가정 비교는 원 영상 취득 시각을 검증한 결과로 쓰지 않는다.

세 기능 검사에서 같은 스캔/영상의 중복, 이동한 두 관측의 불일치, 다음 코너, 누락된 운동 이력, 경기 세대·리셋 이전 시각을 다뤘다. [실행](run.sh)·[3검사](test_intent.py)·[결과](summary.json) 종료코드0. 현재 등록된 60° 좌회전·다음 35° 우회전은 이 간단한 코스 순서 후보의 조건이며 모든 배치에 적용할 규칙이 아니다. ID20을 늦게 처음 보거나 회전 구간에 재배치된다면 본선 유지로 남을 수 있다. 준비를 놓치면 지름길을 포기하면 되며, 이를 이유로 본선 주행을 정지시키지 않는다.

**여기까지는 준비 판단만이다.** 생산 연결·현재 점유/미관측 검사와의 접속·실제 좁은 통로 추종·출구 합류·앞차 가림 변형·시간 이득은 미실시다. 본선 유지 전략은 바꾸지 않는다. 다음에 지름길로 돌아오면 이 준비 후보와 반경0.36m 경로를 합쳐 현재 관측으로 허용되는 명령을 비교한 뒤 제한 실제 주행을 검토한다. 같은 저장 랩의 감지 검사만 반복하지 않는다.
