# P22 제한 진입 후보 연결·주행

**별도 선택한 단독 시험에서 차체 전체가 P22 입구를 통과했다.** 입구만 다룬 결과이며 출구 합류·전체 지름길·본선보다 빠른 완주는 아직 확인하지 않았다. 본선 유지 기본값은 바꾸지 않았다.

## 구현과 검사

실제 ID20 영상 취득 시각, 엔코더·자이로 이동, 두 연속 스캔의 오른쪽 간극으로 입구를 고른다. 지도·평가용 입구 좌표는 제어기에 넣지 않는다. 마커를 못 보거나 준비가 성립하지 않으면 기존 본선 명령을 반환한다. 진입 뒤에는 경로를 센서 이동에 따라 옮기며 매 명령의 현재 점유·제동/관측 영역을 검사한다. 목표 상한은 0.65 m/s이며 현재 측정 속도도 반영한다.

추종기가 전방 경로 0.25 m 소진 시 종료하는 점을 고려해, 정적 탐색 때 0.25 m였던 후륜 목표 깊이를 이 후보에서만 0.55 m로 연장했다. 경로 끝 또는 5초 뒤 정지는 **입구만 보는 시험 종료**이며 최종 경기 정책이 아니다. 진입 뒤 센서 자동 초기화나 운동 세대 변경은 시험을 중단시킨다. 중간 자세에서 갑자기 본선 조향으로 돌아가지 않으며 명시 reset으로 해제한다.

별도 ROS 실행점은 명시 시뮬 활성화·G1·영상 프로세스·절대 기록 경로를 요구한다. launch는 기본 false이며 새 공식 코스 단독·독립 보호·기록 구성에서만 허용한다. schema 6은 실제 영상 취득 시각/세대/ID, 스캔·운동 이력·명령을 함께 보존한다. 기존 본선 재생기는 이 기록을 자동으로 본선 입력으로 해석하지 않고 거부한다. `/drive → 독립 보호층 → /drive/safe`, MCU STOP, 센서·물성은 유지했다.

## 실제 제한 주행 1회

[등록](registered.json)의 소스·인자를 고정해 출발부터 입구 후 제한 정지까지 한 번 실행했다. 약 266초의 실제 시간이 걸렸으며 원 검증기 종료 코드는 1이다. [원 report](run1/report.json)의 `route_complete=false`는 본선 100 m 목표 미달이고 `g1_runtime_verified=false`는 기존 본선 G1과 구별되는 P22 실행 때문이다. 원 결과는 그대로 보존한다. [별도 평가](live_summary.json)는 등록한 입구 기준을 적용했으며 `limited_entry_passed=true`다.

| 제한 시험 결과 | 값 |
|---|---:|
| 첫 센서 기반 진입 허가 | 21.620 s |
| 차체 전체의 입구 통과 | 23.413 s (허가 뒤 1.793 s) |
| 경로 소진 종료 관측 | 23.976 s |
| 진입 후 차체-벽 겹침 / 최소 표본 벽 간격 | 0 / 0.169 m |
| 도로 밖 바퀴 최대 | 2개 |
| 새 입력 재생 | 833판단 불일치 0 |
| 실제 정지·MCU STOP·정상 종료 | 통과 |

전체 기록에서도 접촉·거짓 출발은 0이며 제어기/보호층은 센서 구독만 확인됐다. 기록 footer는 1,416개 제출/저장, 누락·실패·capture error 0이다. 입구 후 노면·벽 평가는 약50 Hz의 163자세 표본이고 바퀴 접지면은 명령 조향으로 계산했다. 실제 바퀴각의 연속 접촉 판정이나 실차 증명이 아니다. 현재 차체는 현가 없는 임시 모델이다.

## 실패와 한계 보존

첫 재생은 `LocalScene.epoch`를 잘못 참조해 실패했고 `source_epoch`로 고쳤다([원 실패](replay_v1.log)). 첫 경로 이송 검사 실패는 `add_mean_wheel`에 m/s를 rad/s처럼 넣은 시험 입력 단위 오류였다. 시험 입력만 바로잡고 생산 운동 환산은 바꾸지 않았다. 마지막 래치 수정 전 등록은 `registered_before_latch_fix.json`·`source_snapshot_before_latch_fix.zip`으로 보존했으며 실행하지 않았다.

신규 실제 경로에서는 117판단이 진입 후보였고, 이후 49판단은 경로 소진으로 0명령이었다. 이 의도적인 종료를 경기 중 정체 개선으로 해석하지 않는다. 본선 투영 진행량 26.86 m도 지름길의 실제 이동거리나 랩 성적으로 쓰지 않는다.

다음은 이번 진입 말기의 현재 센서로 좁은 통로와 출구 방향을 인식할 수 있는지 확인하고, 관측 경로의 연결·합류를 설계하는 것이다. 출구 근거가 부족하면 실패로 남기고 본선 전략을 유지한다. 같은 입구 주행을 무변경 반복하지 않는다.
