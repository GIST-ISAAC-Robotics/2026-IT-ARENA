# r50 출구 경로 연속성·중심 정렬 비교

원 r50은 출구 전환 때 잔여 입구 경로를 버리고 당시 차체 방향으로 직선을 생성했다. 현재 관측에서 오른쪽 벽과 왼쪽 벽은 차체축 대비 약−4.6°였고, 이송 경로 말단은 관측 중심에서 약49mm 벗어났다.

처음에는 입구 경로를 그대로 연장했지만 중심오프셋 조건으로 후보가 없어 실패했다. `extend_path_before_centering.py`·`probe_v1.log`를 보존한다. 후속은 시작 위치와 접선을 유지한 quintic 횡정렬을 잔여 경로에 적용했다. 생성 경로의 조향각·변화율을 확인하며 통과를 위해 물성이나 보호 여유를 바꾸지 않았다.

[저장 비교 v2](probe_v2.log)는24.02초에0.65m/s 첫후보, [사후 기하](geometry_summary.json)는203표본·최대두바퀴도로밖·최소벽간격0.171m·겹침0이다. 바퀴각은 경로접선에서 추정했다. 새 주행이 아니며 실제 경로 추종이나 본선복귀를 증명하지 않는다.

생산 연결은 [r51](../p22_exit_alignment_connected_v1/README.md)에 분리했다. `probe.py`는 r50 source snapshot 기준의 미연결 제안 비교 코드이며 현재 r51 재검증은 r51 `replay.py`를 사용한다.
