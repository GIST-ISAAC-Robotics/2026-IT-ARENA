# P22 진입 후 통로·출구 저장 관측

입구 한 번의 통과는 확인했다. 다음은 새 주행을 반복하기 전에 그 끝 구간의 현재 스캔에서 통로를 유지할 경로와 오른쪽 출구를 준비할 근거가 있는지 확인한다.

1. 새 P22 기록의 첫 진입 허가부터 센서 운동의 상대 회전을 누적한다. 70° 우회전 이후 장면을 추출한다. 평가용 차체 자세나 입구/출구 좌표는 이 선택과 명령 계산에 넣지 않는다.
2. 기존 LocalFollow를 그대로, 또는 알려진 지름길 단면(벽 간격0.60m·도로0.20m)에 맞춘 벽 거리0.30m·도로 반폭0.10m로 두고 양쪽 벽을 비교한다. 각 후보는 동일한 현재 입력을 순서대로 읽으며 기존 점유/관측 조건을 유지한다. 목표 상한은0.65m/s다. 이 비교 결과를 실제 주행 성적으로 쓰지 않는다.
3. 현재 스캔의 연결 직선 조각도 기록해 단순 폭 변경만으로 출구 연결이 가능한지 살핀다. 폭/경계 상태의 급변이나 좁은 코너 최소 반경 문제가 있으면 별도 전이 설계를 한다. 자동 채택·새 Gazebo는 하지 않는다.
4. 추출과 후보 계산을 고정한 뒤에만 사후 자세·월드를 대조하고 입구 주행을 시각화한다. 현재 기본 본선·P22 제한 실행은 바꾸지 않는다.
