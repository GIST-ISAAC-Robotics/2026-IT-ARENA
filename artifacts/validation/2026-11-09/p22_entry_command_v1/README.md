# P22 첫 진입 명령과 현재 관측 검사

[순서 판단](../p22_route_intent_v1/README.md)이 입구 검토를 제안한 시점의 [반경0.36 m 경로](../p22_entry_arc_probe_v1/README.md)를 기존 Pure Pursuit·광선별 점유 거리·반응/제동 이동 영역 검사에 넣었다. **두 저장 입력에서 각각 0.65 m/s의 첫 후보 명령이 허용됐다.** r27은 원 영상 시각 대신 상태 시각을 대입한 진단이므로 실제 마커 시간 검증을 대신하지 않는다.

| 입력 | 현재 측정 속도 | 첫 조향 | 기존 스윕 허용 거리 | 이동 영역 미관측 |
|---|---:|---:|---:|---:|
| r11 21.92초 | 1.301 m/s | +0.0016 rad | 1.16 m | 0 |
| r27 33.42초 | 0.650 m/s | +0.0794 rad | 0.80 m | 0 |

첫 명령은 현재 좌회전 조향을 풀며 앞으로 준비하는 부분이다. 이 숫자만으로 이미 오른쪽으로 돌았다는 뜻은 아니다. 목표 속도만 낮췄으며 이동 영역은 현재 속도도 포함한다. 원 물체 이동 상계0.5m/s·거리 여유55mm·독립 보호의 기존 입력 구조를 바꾸지 않았다. 구조 가림 표본은 기존 정책으로 평가하며 r11 473개/r27 870개, 측후방 외곽 침범 길이는 각각 약0.37/2.14mm였다. 점이 없는 곳을 자유 공간으로 채우지는 않았다.

현재 차체 앞 x=0.13m의 명백한 장애물 점을 별도로 넣은 기하 반례에서는 허용 거리가0으로 줄어 양수 속도가 거부됐다. 이는 점유 검사 연결의 반례이지 라이다 전체 노이즈나 실제 급정지 시험은 아니다.

입력 불변·실행 종료코드0. [기계 결과](summary.json)·[코드](probe.py)·[계획](PLAN.md). 첫 명령 이후의 갱신 관측·차체 추종 오차·좁은 통로·출구 합류와 랩 이득은 아직 미검증이다. 다음은 기본 주행과 분리된 **단독 제한 진입 후보**에서 경로를 측정 이동으로 옮기고, 매 호출의 현재 스캔을 다시 검사하는 연결이다. 준비 실패는 본선 유지, 진입 후 직접 장애물은 기존 정지/독립 보호를 유지한다.
