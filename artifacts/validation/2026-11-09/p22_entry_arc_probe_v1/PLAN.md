# P22 입구를 본 뒤 실제 차량 크기로 우회전을 시작할 공간이 있는가

두 저장 본선 주행의 오른쪽 간극 관측을 사용한다. 전체 랩에서 서로 다른 연속 2스캔(0.16초 이내)에 단일 간극이 보인 관측열마다 두 번째 스캔을 사용한다. 출구에서도 똑같이 후보가 나와야 하며, 이는 **주행 선택기**가 아니다. 원 영상·지도 좌표로 두 번째 스캔을 선별하지 않는다.

후륜 중심 기준으로 현재 스캔의 두 벽 끝 중점과 벽 방향에서 지름길 축을 정한다. 입력은 두 끝·바깥벽 방향·이전 실제 조향 명령·센서 속도에 한정한다. 전 조향에서 직진으로 복귀하고 현 진행 방향으로 접근한 뒤 오른쪽으로 돌고, 좁은 통로 중심 방향으로 조향을 풀어 벽선 너머 25 cm까지의 경로만 본다. 고정 반경 0.36/0.45 m, 조향 변화 상한 3 rad/s, 지름길 비교속도 0.65 m/s와 최초 측정 속도를 각각 유지한 공간 궤적을 비교한다. 조향 변화율 반영은 이상적인 운동학이며 실차·현가·제동 재현은 아니다. 지금 속도로부터 0.65 m/s까지 줄일 거리도 따로 표시한다(감속 2 m/s² 산술, 즉시 감속 성공으로 세지 않음).

입력 관측으로 생성한 모든 후보를 먼저 고정한 뒤에만 시작 자세와 SDF 차도·잔디·벽으로 평가한다. 벽과 조향 바퀴/차체가 겹치지 않고, 전체 경로에서 도로를 벗어난 바퀴가 최대 2개이며 나머지가 잔디인지 확인한다. 접지면 일부·중심·전체 해석을 구분한다. 참조 경로가 있어도 현재/미래 가림·타 차량과의 점유 검사나 실제 출구 합류·시간 이득을 대신하지 않는다. 고정 속도로 두 번째 검출 뒤 전방 준비 길이가 음수이거나 위 기준에 미달하면 그대로 기록하고, 억지 오프셋·물성 조정·무변경 Gazebo 재시도는 하지 않는다.
