# 회랑 후보의 합성 운동학 폐루프 비교

저장 입력 shadow 다음의 제한 비교이며 실제 ROS/Gazebo 주행에는 연결하지 않는다. 기존 `LocalFollow`와 `CorridorObserver`를 시험 스크립트 안에서만 조합한다. 기본 양수 출력과 경계 미확정 외의 HOLD는 유지하고, 짧은 면을 벽 기억에 넣지 않는다. 정답은 광선 생성·사후 평가와 시험 중단에만 쓴다.

사전 조건: 안쪽 반경 0.15 m·벽 간격 0.85 m·도로 0.45 m의 좌/우 원형 코스, 열린 코스/전방 20×15 cm 정지 상자, 기준/회랑의 8조건을 각 1회 최대 8초 수행한다. 100 Hz 운동학, 50 Hz 제어, 순차 500광선·10 Hz 스캔, 기존 후방 60도 마스크·운동 보정·1 m/s 상한·3 rad/s 조향·0.8/2 m/s² 가감속을 사용한다. 모터축 환산 평균 속도/자이로는 이상적 측정이며 28카운트 양자화·통신 지연·슬립·질량은 이번 비교에서 재현하지 않는다. 기본 차량 설정을 바꾸는 것이 아니다.

평가: 이산 차체 외곽의 도로 이탈/충돌·정지 상자 간격 0.15 m 미달·진행 중 모드 전환의 기존 0.08 m 경로 일치 실패 시 해당 조건을 즉시 중단한다. 열린 코스의 최소 반바퀴 진행과 막힌 코스 마지막 0.5초 대기를 따로 판정한다. 기준선도 실패할 수 있으며, 동작 실패를 도구 실행 오류/재시도 사유로 숨기지 않는다. 반바퀴는 공식 코스 완주나 실차 안전 증거가 아니다. 보호 계산을 재사용하지만 독립 ROS 보호층 프로세스 시험은 아니다.

실행 전 소스 ZIP/hash와 아래 명령을 보존한다. 단위 시험 실패 시 비교 실행 전에 중단한다. 실행 담당이 임계값/소스를 자동 수정하거나 재실행하지 않는다.
