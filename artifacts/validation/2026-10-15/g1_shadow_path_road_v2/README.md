# 동시 자세 미평가 보존과 앞뒤 기록의 민감도

v1은 14회귀 통과 후 여섯 장면 모두 동시 자세가 없어 **미평가**였다. 요약의 이탈/겹침 합계 0은 검사 표본 0에서 나온 값이며 무이탈 판정이 아니다. 원문/소스는 v1에 그대로 보존한다. v2는 미평가 집계값을 `null`과 `metric_available=false`로 명확히 한다.

원인 확인에서 판단 시각은 .320/.420 등의 초, 자세 기록은 .319/.321 등의 초였다. 다음은 **정확 시각 검사를 통과시키는 재실행이 아니라 민감도 검사**다. `--pose-mode bracket_sensitivity`에서 앞뒤 실제 기록만 각각 사용한다. 보간하지 않고, 중간 실제 자세·연속 운동을 감쌌다고 주장하지 않는다. 허용할 기록 간격은 2.1 ms 이하로 사전 한정한다. 이는 운영 시간 한도/안전 기준이 아니다.

각 시각의 앞뒤 두 pose로 동일한 센서 경로를 사후 평가한다. 같은 시각 pose가 없다는 `evaluated=false`는 유지하며, 민감도 결과는 별도 필드에 둔다. 결과가 모두 무이탈이어도 실제 추종·동시 정답·관측된 도로/주행 허가가 아니다. 제어/보호·기본값·센서/물성 변경 없이 1회 실행한다.
