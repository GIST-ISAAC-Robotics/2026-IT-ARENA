# 회랑 후보 추가 비용과 오후 전체 회귀

고정 원본 2,021호출을 한 번만 읽어 입력 복원·운동 보정·기존 판단·새 관측기의 비용을 따로 계측한다. native GC 유지, warmup/반복 0/1이며 JSON 파싱·결과 비교·독립 보호층은 비용 밖이다. 기존 출력과 앞서 저장한 관측기 전체 결과의 일치를 요구한다. 50 Hz의 20 ms 초과도 집계하지만 PC 1회 비용을 Jetson/실시간 마감 보장으로 해석하지 않는다. 설정/전원/GC/주행 활성화 변경 없음.

이후 오후 추가 코드 전체에 대해 pytest 1회를 실행한다. 오류/불일치 시 해당 단계에서 중단하고 실패 로그를 보존하며 자동 수정/재실행하지 않는다. 소스 ZIP/hash를 실행 전에 보존한다.
