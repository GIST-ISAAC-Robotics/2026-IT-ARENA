# 현재 자세 출발의 정곡률 외곽 대조

이전 가시성 감사는 추종 목표 경로에 차체를 즉시 정렬하는 이산 검사였고, 378 temporal 후보 중 126개만 경로 전체의 인접 광선 깊이 지지를 얻었다. 나머지 중 실제 개선 대상 대부분은 경로 시작점에서 수 mm 뒤로 놓인 외곽이 후방 마스크에 걸렸다. 이를 실제 전진 조향의 관측 실패로 바로 결론내리지 않는다.

이번에는 현행 swept_limit과 동일한 후륜축 운동식으로 현재 (x,y,yaw)=(0,0,0)에서 시작한다. 이전/새 조향각 각각의 이산 차체 외곽을 기존 광선 깊이 감사와 대조한다. 필요한 거리는 현행 정지식의 역산이며 명령 속도와 모터축 환산 속도 중 큰 값을 사용한다. 정지거리·100 ms 반응·시각별 여유·마스크는 변경하지 않는다. 실제 차체 속도·물리 제동을 보장하는 식이 아니다.

현재 차체 안 표본만 가시성 감사에서 제외하고, 이후 실제로 새로 진입하는 측후방 영역의 unknown은 그대로 실패로 남긴다. 4 cm 이산 거리이며 연속 외곽/중간 조향 응답/광선 사이 장애물 부재를 증명하지 않는다. 명령 발행·기본 채택 없이 temporal 후보 378호출의 비교만 1회 수행한다. 실패 시 보존/중단한다.
