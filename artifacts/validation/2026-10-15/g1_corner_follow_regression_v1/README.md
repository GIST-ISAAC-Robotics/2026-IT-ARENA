# 거리 코너 후보의 기존 앞차 회귀 — 조건부 등록

`g1_solo_lap_v4`가 완주/STOP/종료/재생/점유/도로 검사를 모두 통과한 경우에만 실행한다. 그 전에는 준비 파일일 뿐 완료 결과가 아니다.

**10/15 마감 상태: 미실행.** 선행 v4가 29.295430 m에서 완주 실패했으므로 이 조건은 성립하지 않았다. 후속 마무리 요청에 따라 새 실행 없이 보류했다. 다음 작업에서 등록 내용/선행 조건을 다시 확인하며 이 파일을 예약 실행 지시로 해석하지 않는다.

새 거리 기반 코너 경계가 기존 앞차 추종에 퇴행을 만들지 않는지 `config/tests/g1_traffic_extensions_v1.json`의 `first_curve`, seed 0 한 번으로 대조한다. 같은 앞차·0.35 m/s·35초·첫 U자/출구·0.15 m 간격·정지/종료 기준을 그대로 사용한다. 이번에 고친 19.7 m 부근의 급커브에 앞차를 새로 배치하는 시험은 아니며, 전체 다중 차량 코스 검증도 아니다.

주행 완료 후 STOP·정상 종료·원본 판단 재생·사후 v6·전량 점유/취득 나이 감사·후보 선택 횟수를 확인한다. 실패 시 자동 재실행하지 않고 원인 분석으로 돌아간다. 12:30 KST 이후 새 실행을 시작하지 않는다. 기본 모드·센서·물성·보호 한도는 유지한다.
