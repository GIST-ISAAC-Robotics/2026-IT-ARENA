# 관측된 곡선 길이의 조건부 하한 진단

정적 길이 대조만 수행한다. 런타임/기본값·0.65 m/0.3 s 기준은 변경하지 않는다.
이전 v4의 저장 관측 여섯 시각과 원형 코너 7반경, 짧은 주름 표면 반례를 대조한다.
점별 30 mm 오차 원판이 참이라는 조건하에 실제 순서상 표면 길이의 하한을 구한다.
같은 물체·정지·벽·자유 공간·주행 허가는 인증하지 않는다. 특히 짧은 물체의
복잡한 외곽도 긴 표면을 만들 수 있으므로 길이 하한만으로 기본 판정을 바꾸지 않는다.
입력/기존 원시 자료 불변, 실패 시 같은 폴더 자동 반복/덮어쓰기 금지.
