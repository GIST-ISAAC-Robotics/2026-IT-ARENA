# 제한 관측 기억의 기하 여지 — 운영 미연결

v4의 41.8~44.8초 저장 입력에서, 현재 근접 안쪽 성분과 0.3초 미만의 과거 근접 성분을 원래 엔코더/자이로 이력으로 이송한다. **모든 성분이 같은 정적 벽이라는 낙관적 가정** 아래 실제 반환점들의 최대 이격을 계산한다. 연결되지 않은 점을 벽으로 잇거나 자유 공간으로 인증하지 않는다.

목적은 새 추적기를 먼저 구현하지 않고, 기존 나이 한도를 유지한 관측 기억에 기하적 여지가 있는지 보는 것이다. 가까운 성분 선택은 물체 연관/정지 증명이 아니다. 지름이 0.65 m를 넘더라도 중간 관측·형상·연관·오차·경로 안전 검사를 통과했다는 뜻이 아니며 주행 허가와 무관하다.

- 같은 스캔을 새 관측으로 중복 저장하지 않는다. 원래 스캔 첫 취득 시각을 유지하고 `now-source_first >= 0.3`이면 제외한다.
- 세대/측면/시각 역전에서 캐시를 비운다. 기존 운동 이력이 없으면 무보정으로 대체하지 않는다.
- 최대점 이격은 잡음 호길이 합이 아니다. 저장 호출의 미래 입력/이전 조향은 바꾸지 않으므로 결과는 폐루프 가용성 검증이 아니다.
- 관측 이력이 있는 점만 사용한다. 지도·정답 자세·물체 ID·미래 시각은 넣지 않는다. 원본·설정·기본 제어는 변경하지 않는다.
