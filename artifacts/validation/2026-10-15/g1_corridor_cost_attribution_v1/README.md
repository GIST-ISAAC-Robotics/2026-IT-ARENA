# 추가 비용의 GC/CPU 구분

앞선 단일 PC 비교는 전체 20 ms 초과 18/2,021회, 운동 보정 단독 초과 8회였고 원인은 계측하지 않았다. 기존 후보 계산 두 개만의 최대값은 17.361 ms였다. 이를 새 회랑 알고리즘 문제 또는 GC 문제라고 단정하지 않는다.

동일 입력/판정으로 한 번만 추가 계측한다. native GC 정책·전원·소스 동작은 유지하고 관측 callback을 붙여 단계별 GC 시간 및 현재 thread CPU를 함께 기록한다. GC 시간을 실제 wall 비용에서 빼지 않는다. 이번 측정이 이전 실행의 원인을 소급 증명하지 않으며, 모든 스케줄링/할당 지연을 설명하는 도구도 아니다. 전체 회귀는 바로 직전 2,467통과를 재사용하고 변경한 계측기 관련 회귀만 수행한다.
