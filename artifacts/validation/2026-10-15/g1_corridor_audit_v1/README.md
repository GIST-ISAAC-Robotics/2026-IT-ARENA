# 회랑 shadow의 노면/물체 반례 대조

앞선 shadow 405개 고유 장면 중 기하 가설 160개를 저장 당시 노면으로 사후 평가한다. 정확한 동시 자세가 없으면 미평가를 유지하고, 최대 2.1 ms 간격 전후 실측 자세의 민감도만 별도로 산출한다. 실제 궤적·연속 외곽을 인증하지 않는다.

추가 정적 장면은 반경 0.15/0.30 m × 좌우 × 열린/중앙 봉쇄/옆 물체/안쪽 면 부재/짧은 대체 물체/전방 미응답 × 0/±30 mm 편향/seed 0 균등의 **96조건**이다. 500방향 첫 반환으로 가림을 만들며 센서 출력 뒤에 물체점을 덧붙이지 않는다. 정지 차량이 코너 방향으로 미리 조향한 조건이며 움직이는 회전 취득·물리 주행이 아니다. 해석용 원형 도로는 벽 사이 0.85 m, 도로 폭 0.45 m, 양쪽 여백 0.20 m다. 공식 반경이나 실제 트랙의 측정 결과가 아니다.

사후 평가만 도로/물체 형상을 알고, shadow에는 현재 센서 scene·속도 0·이전 조향만 전달한다. 20×15 cm 경로 접선 외곽이 노면 밖/물체와 겹치는지 별도로 센다. 잠정 진행 가능 결과에서 위반이 나오면 성공으로 숨기지 않는다. 이전 shadow/런타임은 수정하지 않고 1회 수행한다. 제어 연결/새 주행/안전 한도 완화/추월 없음.
