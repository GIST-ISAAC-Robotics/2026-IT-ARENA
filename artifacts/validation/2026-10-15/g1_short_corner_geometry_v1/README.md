# 짧은 관측의 경로 지지와 물체 정체성 대조

운영 미연결 진단이다. v4의 저장된 여섯 기하 장면에서 가까운 안쪽 실제 점들이 바깥 경로와 0.425±0.08 m·법선 30도 조건을 만족하는 연속 앞 구간을 계산한다. 선분 보간 없이 실제 표본점만 사용한다. 이 값은 원래 0.65 m 물체 길이 조건의 대체 허가가 아니다.

반례는 15×15 cm에 들어가는 원형 표면이다. 500방향 첫 반환에서 실제 보이는 가까운 점들과 해석적 바깥 경로를 대조한다. 같은 기하가 작은 정적 경계일 수도, 멈춘 작은 물체일 수도 있다는 문제를 검사한다. 차량 부품·폐루프·교통/도로 침범을 재현했다고 주장하지 않는다. 물체 label은 평가 설명에만 사용한다.

`run.sh`를 1회 실행한다. 주행·보호·0.65 m·0.3초·점유는 변경하지 않는다. 결과가 짧은 물체도 지지한다고 나오면 거리 관계만으로 벽 조건을 대체하지 않는다. 새 Gazebo 실행은 없다.
