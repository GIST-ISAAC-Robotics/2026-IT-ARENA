# 원형 안쪽 코너의 가시 길이 대조

운영/공식 트랙 변경 없는 정적 평가다. 안쪽 원 반경 0.10/0.15/0.20/0.30/0.40/0.60/0.80 m, 실제 센서 전방 0.06 m, 중심선–벽 이격 0.425 m, 500방향·후방 60도 마스크, 좌우/잡음 없음·±30 mm seed 0 균등 오차를 대조한다. 특정 공식 코너의 실제 반경을 이 값으로 확정하지 않는다.

연속 광선의 가시 원호 최대 점간 거리는 `2R sqrt(1-(R/d)^2)`다. 수학적 점 관측자/불투명 원/평면의 이상형이며 실제 반사율·물성·시점 운동을 모델링하지 않는다. 원/반환 label은 평가에만 사용하고 제어기에는 반환 전체와 시간 계약만 전달한다.

목적은 길이 조건이 작은 코너에서 기하적으로 성립하는지 확인하는 것이다. 결과를 성공시키기 위해 0.65 m·TTL·간격/거리 오차/보호 한도를 변경하지 않는다. 입력이 단순하다고 모든 열린 장면의 양수 출력을 요구하지 않는다. 주행 성공/허가가 아니며 새 주행은 사전 계획 없이 실행하지 않는다.
