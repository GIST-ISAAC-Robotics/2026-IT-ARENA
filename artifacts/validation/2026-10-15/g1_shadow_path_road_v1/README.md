# 경계 정체성과 경로 외형의 평가 분리

v4 저장 센서로 생성한 바깥 벽 경로를 짧은 안쪽 실제 점의 간격/법선 지지 prefix에서 자른다. 그 경로를 **평가 단계에서만** 같은 시각의 원시 ego pose로 월드에 옮겨 20×15 cm 차체 외형과 실제 노면/벽을 대조한다. 정답 pose/노면은 경로 생성·제어기 입력이 아니다.

1 ns 표현 오차 이내의 유일한 동시 자세가 없으면 그 장면은 미평가로 남긴다. 근처 자세 대체·보간은 하지 않는다. 경로의 각 표본 접선 방향으로 차체를 놓으므로 실제 Pure Pursuit 추종/조향 지연·연속 swept 범위·새 센서 시퀀스와는 다르다. 주행 허가/정체성 인증/기본값 변경은 없다.

`run.sh` 1회. 저장 장면이 실제 도로 위인지 확인하는 제한 자료일 뿐, 그 노면을 실제 센서가 확인했다는 증거로 사용하지 않는다. 모든 실패/원문·기존 0.65 m/0.3초/보호 기준을 보존한다.
