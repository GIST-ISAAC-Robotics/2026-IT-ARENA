# 거리 기반 코너 후보: 첫 전체 코스 폐루프 등록

v3의 직선 앵커 후보 실패를 보존한다. 이번 조건은 `corner_distance_candidate`만 변경한 새 후보이며 기존 v3를 성공으로 소급하지 않는다.

- 가설: 바깥쪽 긴 관측과 안쪽 실제 연결 성분까지의 거리·법선 방향으로 모서리를 대조하면, 안쪽 직선의 앞쪽 길이가 짧아져도 근거가 남는다. 전방 지지 경로와 실제 성분 길이는 각각 0.65 m 이상이며 미지원 꼬리는 실제 경로에서 제외한다.
- 사전 조건: 관련 회귀/기존 1,455판단 동일 재생, 정적 오차·나이·가림 160조건. 열린 장면의 정지는 가용성 한계로 따로 기록하고, 봉쇄/벽 부재/짧은 가짜 벽에서 비영 출력이 나오면 주행하지 않는다.
- 실행: v3와 같은 슬롯 3·공식 파생 코스·순차 C1 10 Hz·양쪽 운동 보정·모터축 28카운트/15:1/65 mm·G1 1.0 m/s 명령 상한·점별 나이 후보·방지턱 임시 해제·1랩 요청이다. 새 모드가 기존 단독/기본 G1 설정을 바꾸지 않는다.
- 주행 gate·밀집 STOP·정상 종료·입력/소스 무결성·점유/도로·판단 재생을 구별한다. 첫 실패에서 자동 재실행하지 않고 저장 입력 분석으로 돌아간다. 이번 후보는 최대 1회다.
- 12:30 KST 이후 시작하지 않는다. 커밋/푸시·Jetson·전원 변경은 하지 않는다. 성공해도 실물/다중 차량/모든 잡음에서의 검증이 아니다.
