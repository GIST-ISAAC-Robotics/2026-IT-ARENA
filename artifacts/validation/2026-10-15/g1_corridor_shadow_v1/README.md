# 의미 미확정 안쪽 표면 + 긴 바깥 관측의 shadow 비교

사용자가 별도 후보 설계·주행 미연결 비교를 승인했다. 현행 `corner_distance_candidate`의 기준/기본값/주행 출력은 변경하지 않는다.

1. 같은 스캔에서 기존 0.65 m 긴 관측·0.12 m 앵커 조건을 만족하는 바깥 경로가 있어야 한다.
2. 현재 안쪽 연결 조각의 실제 점만으로 0.425±0.08 m 이격·30도 법선·0.65 m 연속 경로·일관된 코너를 교차 확인한다. 안쪽 조각의 지름을 벽 정체성으로 바꾸지 않는다. 짧은 표면은 `boundary_surface`와 `other_occupied_object` 가설을 모두 남긴다.
3. 모든 반환을 기존 취득 시각별 여유/이전·새 조향 swept 검사에 남긴다. 기존 0.28 m 재출발 여유·간격/제동/속도 한도는 유지한다. 전방 unknown·오래된 관측·음수 운동은 진행 가설을 만들지 않는다.
4. 이는 stateless shadow다. 두 fresh 확인·기억 채택·경기 허가·실제 경로 가시성/노면 구분·폐루프는 미연결이다. 어느 결과에서도 `driving_authorized=false`다. 미관측 자유 공간/벽 분류/실물 안전을 인증하지 않는다.

관련 단위/첫 반환 반례 이후 기존 v4 2,021판단이 그대로 재생되는지 확인하고, 같은 입력의 고유 스캔별 shadow 결과를 1회 계산한다. 실패 시 추가 주행/기준 완화 없이 분석한다. 작은 원형 물체도 기하 지지를 줄 수 있다는 기존 반례를 실패로 숨기지 않고 의미 미확정 상태로 보존한다. 이전 조향·속도·미래 입력은 원래 실패 기록의 값이므로 새로운 주행 결과가 아니다.
