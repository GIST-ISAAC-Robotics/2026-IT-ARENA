# MCU 포팅용 PC 참조 벡터

운영 구동 계약을 수정하지 않고 현재 단일 모터축 28카운트·15:1·65 mm 구성을 명시하여 상태 전환 입력/기대 출력을 내보낸다. 19개 유한 사례와 독립적으로 작성한 상태/이유 checkpoint를 사용한다. 실제 MCU/핀/PWM/제동/실시간 주기/차체 정지의 검증이 아니다.

각 이벤트에는 정수 MCU 시각, 명령의 실제 프레임 hex 또는 카운트 입력, 호출 결과와 상태가 있다. 재부팅은 새 boot ID와 시계 원점이다. 0목표·STOP·CLEAR·ARM, 명령/엔코더/제어 작업 만료, 이전 세대/호스트, 모터축 모드·카운트 부호, 2^53 초과 정수의 보존을 비교한다. 부동소수 오차 허용치는 PC double 비교용 1e-9이며 실물 float32 계약은 아니다.

기존 보호/기본값/런타임은 변경하지 않는다. 관련 회귀와 내보내기/참조 재생을 한 번 수행하고 실패하면 그대로 보존한다. 자기 재생 일치는 이관 자료의 재현성이지 독립 펌웨어 검증이 아니다.
