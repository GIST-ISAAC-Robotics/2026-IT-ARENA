# 회랑 shadow의 스캔 간 확인

운영/기본 제어기를 바꾸지 않고 새 shadow의 시간축 계약을 검사한다. 현재 장면의 기하가 매 호출 성립해야 하며 과거 경로만으로 진행하지 않는다. 이전 경로는 모터축/자이로 이력으로만 이송하고 원천 나이 0.3초·기존 0.45 m 이송 한도·0.08 m 경로 일치 조건을 유지한다.

서로 다른 스캔 2개로 기하를 확인한 뒤 기존 방식처럼 두 fresh 진행 여유를 확인한다(처음부터 모두 양호하면 세 번째 스캔에 잠정 제안). 같은 스캔 재사용은 횟수를 늘리지 않고, 재적합된 경로가 달라지거나 현재 기하/운동이 부적합하면 폐기한다. epoch/선호 측 변경, 시각 역행, 음수 운동, 입력 공백, 점유 HOLD를 분리한다. 벽 분류·경계 기억 갱신·실제 명령 발행은 하지 않는다.

현재 소스/입력이 첫 shadow 때와 byte 동일한지 확인하여 그때의 2,021판단 baseline 재생을 재사용한다. 동일 baseline의 무의미한 반복은 하지 않는다. 새 시간축 코드/관련 회귀와 원래 입력 전체에 대한 shadow만 1회 실행한다. 실제 입력은 원래 실패한 궤적을 따르므로 완주/새 궤적 증거가 아니다.
