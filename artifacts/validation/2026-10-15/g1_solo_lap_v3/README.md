# 선택형 급커브 후보: 첫 폐루프

조건과 실패 중단 기준은 [v2 등록](../g1_solo_lap_v2/README.md)을 따른다. v2는 평가기 해시 후속 계약 누락으로 사전 검사에서 끝났고 Gazebo는 실행하지 않았다. 이 폴더가 `corner_anchor_candidate`의 첫 실제 전체 코스 요청이다.

현재 결과는 `run/report.json`과 `exit.txt`, 판단 재생/점유/도로 감사에서 각각 확인한다. 파일이 아직 없으면 해당 작업은 완료되지 않았다. 새 후보의 결과를 v1의 실패로 소급 적용하지 않는다.
