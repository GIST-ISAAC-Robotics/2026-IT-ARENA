# 미연결 관측기와 기본 출력 대조

순수 기하 모듈 다음으로 현재 기하·전점 점유·스캔 간 확인을 `CorridorObserver`로 분리한다. ROS/launch/LocalFollow에는 연결하지 않는다. 기존 prototype의 명령 의미를 변경하지 않으며 frame 변경/잘못된 이전 조향/더 짧은 설정 TTL은 명시 거절한다.

저장된 기본 출력 중 오직 `follow_boundary_unconfirmed` HOLD만 shadow 대조 대상이다. 점유 HOLD·역행·입력 고장·재출발 확인 대기 등은 제안이 있어도 대체하지 않는다. 기준의 양수 출력도 그대로 보존한다. `compare_boundary_hold`는 비교 dict를 반환하며 `/drive` 명령이 아니다. 기본 경계 기억에 회랑 경로를 쓰지 않는다.

새 모듈/보호 사유 회귀와 기존 2,021호출의 temporal 판정·확인 횟수·속도 동등성, 출력 대조 1회를 수행한다. 전환 동역학·실제 새 궤적/미래 입력은 미검증으로 남긴다. 실패 시 원본 보존 후 중단, 코드 자동 수정/반복 주행 없음.
