# 독립 ROSClock 모드·시간 변화 대조

설치된 Jazzy rclpy의 독립 `ROSClock`과 노드 없는 `TimeSource`에 7가지 시간축을 직접 제공한다. ROS 그래프/`/clock` 발행·구독·기존 노드·OS 시계·Jetson은 건드리지 않는다. 이는 합성 시계 사건이며 센서/MCU 시간 실측이 아니다.

각 조건은 3회 읽기만 수행한다. system 대응·활성화 후 미초기화 0·증가·정지·역행·활성/비활성 전환·읽기 안에서의 전환을 대조한다. 원문과 소스는 `probe/`에 보존한다. 읽기 사이의 모든 변화 감지, 다른 노드 `use_sim_time`, stamp 적용·구동 허가는 검증 대상이 아니다.

`run.sh` 1회 실행한다. 실패 시 같은 산출물에 덮어쓰지 않는다. 기존 500표본 PC 기록의 소스/결과는 이전 묶음에 보존한다. 이번 버전은 0 시각의 위치를 별도 목록으로 추가하며 기존 운영 코드·한도는 변경하지 않는다.
