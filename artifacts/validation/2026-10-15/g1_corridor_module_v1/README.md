# 회랑 기하 순수 모듈 준비

`corner_corridor.py`는 승인된 shadow의 기하 부분만 ROS/시험 스크립트 독립 모듈로 옮긴다. LocalFollow/launch/명령에는 연결하지 않는다. 현재 관측점·선호 측·기존 FollowConfig만 받는다. 시간축 확인·점유·제동/보호는 별도 의무이며 supported는 주행 허가가 아니다.

원형 좌우 fixture와 원래 고유 스캔 405개에서 지원 여부/거절 이유/경로/지지점 색인이 prototype과 동일한지 대조한다. 보고용 지름만 전체 O(n²) 정확 지름 대신 좌표 극점의 거리 하한으로 바꾸고 명칭에 lower_bound를 표시한다. 이 값은 채택 조건에 쓰지 않는다. 추가 포인트·관측 연결·임계값 변경은 없다. 이전 prototype/입력/실패는 보존하며 기존 baseline을 반복 실행하지 않는다.

모듈 연결 전 남은 의무: 현재 기하 매 호출 확인, 기존 원천 시각의 만료·서로 다른 스캔/운동 일치, 모든 점의 독립 점유, 기존 경계 기억으로의 무단 승격 금지, 기준 모드 동작 보존, 제한 폐루프와 실제 새 미래 관측. 이 준비를 운영/실차 완료로 표시하지 않는다.
