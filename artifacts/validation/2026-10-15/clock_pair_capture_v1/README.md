# PC 단조/ROS 시각의 읽기 구간 준비

계획된 C2 시간 연결의 원시 기록 준비다. 합성 계약 회귀 뒤 WSL의 독립 `rclpy.ROSClock`을
500회·요청 간격 20 ms로 **한 번** 읽는다. TimeSource/ROS 노드/토픽을 만들지 않는다.
따라서 다른 실행 노드의 `use_sim_time`, Jetson/MCU/센서 시각 확인이 아니다.
프로세스별 epoch 토큰은 운영체제 부팅 식별자를 확인한 것으로 취급하지 않는다.

읽기 전후 단조 시각을 보존하고 ROS 역행/정지/모드 변화와 일정 offset 가설의
양립 여부를 분리한다. 음성 결과도 원시 파일에 남기며, 읽기 사이 연속성·timestamp 변환·
자동 교정·구동은 승인하지 않는다. 중간값을 실제 취득 시각으로 쓰지 않는다.
실패 시 로그 보존 후 중단하며 임의 반복/덮어쓰기하지 않는다.
