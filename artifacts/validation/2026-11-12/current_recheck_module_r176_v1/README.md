# 현재 경로 재계산 공통 모듈 이관

2026-11-12, 구현 전 등록. PC 저장 입력만 사용한다. Jetson 접속·차량 구동·새 Gazebo 시험은 없다.

r174는16.39m에서 미완주했고 r175의 기존 공백 후보 비교는473개 전체 변화0이었다. 이 결과를 완료로 처리하지 않는다. 이번 묶음은 실물 실행 연결에 필요한 현재 재계산의 공통화다. 보존된 시험 폴더를 재귀적으로 가져오는 실행 구조를 `arena_autonomy.current_path_recheck`의 순수 함수로 옮긴다. 현재는 ROS 노드/기본 실행에 연결하지 않는다.

유지 대상은 원 r174의 우선순위와 범위다: SOLO 기본 경로, SOLO/GUARD 직선 차로 유지, 현재 옆차가 사라진 GUARD, RELEASED 기본 경로, 현재 옆차가 보이는 GUARD, RELEASED 직선 차로 유지. 각 진입 조건·현재 속도/시각·기억 앵커·점유/미관측 판단·독립 보호 필요 조건을 그대로 보존한다. unsupported는 `None`, 적용 후 거절은 0속도 결과로 구분한다. 상태 전이·발행·시계 갱신만으로 허가 재사용을 하지 않는다.

수용 기준은 보존 원 함수와 현재 모듈의 적용 범위/전체 반환 동일성, 실제 기록의 현재 재계산 결과 재현, 입력 불변, 원 기능 회귀다. 운영 연결·실시간 충족·지연 교통 완주는 별도다. 과거 실패와 원 파일을 덮어쓰지 않는다.

## 결과

서로 다른 네 기록의1,877개 판단에서 적용 범위가 동일하며, 실제/같은 시각/+20ms 현재 입력의 **2,414개 전체 반환이 원 r174 함수와 동일**했다. r174 실제 현재 재계산193개도 기록 그대로 재현했다. +40ms 등 운동 입력 만료는 분석 결과에서 별도로 남겼다. 입력/원시 trace는 불변이다. [전체 대조](comparison.json).

공통 진입점31검사와 기존 세 정책 반례42검사를 새 모듈에서 실행한 총73검사를 통과했다. 현재 입력의 새 장애물·epoch/조향/원 경로 만료·선택 경로 불일치·음수 피드백·보호 필요 조건을 유지한다. 최초 대조가 r152의 출발 전 환경 장애 기록(0바이트)을 잘못 선택해 실패한 로그를 보존했고, 실제 두 번째 주행 경로만 바로잡았다.

이관 모듈은 기본 ROS 실행에 아직 연결하지 않았으며 새 주행 성과나 실차 준비 완료가 아니다. 다음은 명시 선택형 실행 연결과 OFF 기존 동작/현재 재계산 결과를 실제 노드에서 확인하는 것이다.
