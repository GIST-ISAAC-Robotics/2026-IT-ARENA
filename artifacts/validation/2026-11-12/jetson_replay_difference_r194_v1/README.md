# Jetson 수치 차이 분리와 공통 선택 구성 CPU 비용

11/12 r193의 동일 소스/입력 재생이 Jetson에서 실패한 이유를 분리했다. ROS·센서 포트·모터는 사용하지 않았다.

## 원 대조 결과와 범위

원439판단 중357개가 전체 출력과 일치했고82개는 달랐다. 차이는12종 진단 경로의 질의/가림/미관측 표본 수이며 차이는−2~+3개다. **속도·조향, 상태·사유·위험/허용 판단은 기존1e-10 수치 비교에서 모두 일치**했다. 원 실패와 각 차이는 `summary.json`, Git 제외 `mismatches.jsonl`에 보존한다. 비교기의 허용치를 바꾸거나 표본 수를 무시하도록 공통 비교 함수를 수정하지 않았다.

첫 차이 seq401의 실제 두 운동 영역을 PC/Jetson에서 각각 추출했다. 표본 개수는7,764 대7,762/7,763개이나 양쪽 최근접 최대 거리는각각1.49×10⁻¹⁴m·1.91×10⁻¹⁴m였다. 미세하게 다른 좌표가 정확 일치 중복 제거에서 별개 점으로 남는 차이와 부합한다. 대표 한 호출의 진단이며82개 전체 원인을 단정하지 않는다. 제어 좌표를 반올림/축소/병합하지 않았다(`geometry_comparison.json`).

## Jetson 자체 기준 재현과 계산

원 파생 입력의82개 진단 출력을 실제 Jetson 결과로 교체한 **별도 비용 측정용 기준**을 만들었다. 입력/명령 동일·바뀐 경로가 위12종 정수 개수뿐임을 확인하고 원본/파생 해시를 `platform_reference.json`에 남겼다. 원 PC 기준 재생 실패는 여전히 실패다.

같은 Jetson·소스에서 파생 기준439판단 전부 재현 후1회 warmup/1회 계측을 수행했다. 입력과 계측 진입점의107개 필수 소스는 불변이다(묶음 전체의 정적 의존 파일112개와 구분).

| 단계 | 중앙(ms) | p95(ms) |
|---|---:|---:|
| 입력 이력 복원 | 1.916 | 2.006 |
| 원천 스캔 운동 투영 | 6.272 | 6.626 |
| 주행 판단 | 128.614 | 213.151 |
| 합계 | **136.598** | **222.395** |

이 장면에서는10Hz 스캔 간격100ms보다 중앙 계산이 길다. 20ms 수신/제어 주기나 실제 실시간 작동이 성립했다는 결과가 아니다. 실제 과거 r160과 입력·상태 구성이 다르므로129ms→136ms를 회귀율로 계산하지 않는다. 현재 재검사·ROS/영상/독립 보호·구동기·실물 취득시각은 제외했다. Python3.10.12/NumPy1.21.5/aarch64, GPU 미사용·전원/클럭 설정 변경 없음이다.

`profile/report.json`, `profile/source_snapshot.zip`, `platform_session.log`와 원 r193 원격 실패가 근거다. 다음은 이 고정 입력에서 비싼 함수와 반복 계산을 제한 표본으로 조사한다. 재생 일치를 얻기 위해 실제 제어의 관측/간격 조건을 낮추지 않는다.
