# C1 거리0 표기 수정의 실제 격리 수신

실행 전 등록: r201의 공통 변환만 새 격리 폴더에 가져와 실제 C1을20초 읽는다. 기존 r166b SDK 바이너리를 SHA 대조 후 그대로 사용한다. Standard/기본 회전수, 원 native 순서·각도·추정 시각, ROS domain216/localhost를 유지한다. 차량 모터·서보·ESP32 펌웨어·IMU·운영 launch는 변경하지 않는다. C1 장치 소유자가 있으면 시작하지 않는다.

SDK 거리0만 `+inf`, 양의 거리/품질0은 null로 구분하고 공통 decoder의 수신과 원시 배열을 대조한다. unknown을 자유 공간으로 바꾸지 않는다. `unverified_estimate`·미장착 frame·수신후 명목 시각/겹침 진단을 유지한다. 이 결과는 주행·취득시각 교정·최종 장착 검증이 아니다.

원시 실내 스캔은 Git 제외 build/와 새 원격 전용 폴더에 보관한다. 종료 코드·센서 회전 정지·장치 점유 해제·임시ACL 원복·소스 불변을 확인한다. 실패하면 원 실패를 보존하고 이유 없이 반복하지 않는다.
