# 좁은 무반환 검사 비용 분리

2026-11-12 실제 Jetson CPU 계측. r142 양수 7개를 cProfile로 조사했으며 프로파일러 오버헤드가 있는 시간과 원 측정 시간을 구분한다. 주요 누적 비용은 `_bounded_nonreturn` 약 203 ms/7회, 이동 영역 약 135 ms/7회, 측방 반환 분류 약 73 ms/7회였다.

첫 후보는 한 점씩 NumPy 배열을 만드는 각도/반경 계산을 32점씩 묶는다. 표본 축소·광선 보간·분류 기준 변경은 없으며 질의 순서·동률 선택·처음 거절 사유를 유지한다. 배열 메모리는 32광선 묶음이 아니라 **32질의×원 광선 수**로 제한한다.

52검사, r139 원 468판단과 r142 현재 37출력 전체의 동일성을 확인했다. 실제 Jetson의 같은 37입력도 모두 같았다. 실제 양수 7개의 전체 계산 중앙값은 62.57→56.14 ms, 재검사 부분은 55.53→49.09 ms였다. 순차 1회 비교이며 부하/클럭을 고정한 반복 성능 시험은 아니다. 7건 모두 20 ms를 초과하므로 50 Hz 달성으로 보지 않는다.

후보는 동결 소스 밖에 두고 Python 함수 참조만 해당 진단 프로세스에서 치환했다. 공통 소스와 실행 중인 r143에는 아직 반영하지 않았다. r143의 원 판단/소스 계약을 보존한 뒤 채택 여부를 결정한다. 실행 스크립트의 첫 셸 상태 변수 검사에는 인자 확장 오류가 있었으나 별도 로그로 52검사 통과와 468/37 동일 재생의 정상 종료를 확인했다. 이를 검사 실패를 무시한 성공으로 처리하지 않는다.

원시 프로파일 SHA256 `25be0ee48149f98a4a0fae6e7842fc956cbc40be9176f5827e43d47cd36ff6c9`. 후보 SHA256 `c38c7c6c64b13d4e93e7b3f7dbc90d437f83dae3d91bdd742786c7a6449ae4ea`. 근거: `verification.json`, `measurement.json`, `profile_summary.txt`.

후속: r143의 종료·원 소스 회수를 마친 뒤 [r147](../nonreturn_apply_r147_v1/README.md)에서 공통 코드에 반영하고 59검사·r143 원465/현재40 전체 동일 재생을 확인했다. 위 실측은 반영 전 별도 후보에서 얻은 값으로 보존한다.
