# r246 두 수치 커널 결합 비교

r245 광선 지지 후보에 `polygon_distance`의 점/변 거리만 추가한 독립 비교다. 면적의 NumPy 합산 순서·1e-15 경계는 Python wrapper에 그대로 남겼으며 CW/CCW·퇴화 다각형·원래 내부 판정을 유지한다. `fast-math`와 부동소수점 연산 결합은 사용하지 않는다. 공통 소스·기본값·보호 기준은 바꾸지 않았다.

PC22개 단위 비교에서0~16꼭짓점·퇴화/역순·변 근처·NaN/무한 입력과거리/면적 경계를 대조했다. 테스트 본문은22통과했으나 WSL 호출 바깥 반환은1이어서 해당 실행 완료 상태는 제한하여 기록한다. 후속 단순 namespace 명령은0이었다. 결과 로그는 보존한다.

실제 Jetson의22개 단위 검사와632동결 입력 비교를 마쳤다. 후보를 먼저/나중에 번갈아 호출했으며 같은 Jetson의 원래 구현과 후보는 전체 출력·명령 차이0, 소스 불변이다. 과거 PC 기록과의 진단45차이는 기존 r244와 같이 보존하며 후보가 만든 차이로 합산하지 않는다.

| 계획 계산 | 원래 NumPy | 두 커널 후보 |
|---|---:|---:|
| 중앙 |123.345ms|99.553ms|
| p95 |182.965ms|146.936ms|
| 최대 |296.762ms|230.325ms|
| 평균 |111.626ms|97.604ms|
|100ms 초과|398/632|290/632|

계획 p95는 약19.7% 감소했지만 **10Hz 계산 예산 확보는 미완료**다. ROS 수신·현재 재검사·IPC·영상·독립 보호를 포함한 종단 성능이 아니다. 이 결과를 근거로 다음 r247에서 명시 선택 자식 계산에만 공통 모듈을 연결한다. [원 계측](jetson/result/report.json), 실행/수신 receipt와 소스 bundle은 이 폴더에 보존했다. 센서 포트·전력 설정·모터 출력은 사용하지 않았다.
