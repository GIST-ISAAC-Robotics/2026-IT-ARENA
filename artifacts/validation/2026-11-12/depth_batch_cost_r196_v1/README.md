# 같은 깊이 표본의 행 묶음 크기 비교

r194 고정439판단을 재현한 뒤44판단에서 실제 사용된168깊이 함수 입력·248,247질의점을 보존해128/256/512/1024행 묶음을 비교했다. 광선·표본·판정식은 동일하며 결과 차이는0이다. 1회 warmup 뒤 순서를 바꾼2회 측정이다.

| 행 묶음 | 336함수 호출 합계(ms) | 중앙(ms) | p95(ms) |
|---:|---:|---:|---:|
|128 기존|3404.7|3.578|43.275|
|256|3098.2|3.644|37.339|
|512|2981.5|3.700|34.950|
|1024|3084.8|3.715|37.600|

512행에서 이 함수들의 합계는12.4% 줄었지만 작은 호출의 중앙은 소폭 증가했다. **전체 제어기12.4% 개선이 아니다.** 따라서512행을 후보로 원점/각도 경계 회귀와 전체 판단 재현·전체 비용을 대조한 뒤 채택 여부를 정한다. 표본 해상도·가림·관측 조건을 바꾸지 않았다. `compare.py`, `report.json`, `remote_session.log`가 근거다.
