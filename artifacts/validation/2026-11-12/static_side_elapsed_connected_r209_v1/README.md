# 측방 정지 물체 판단의 실제 경과 시각 연결

r203 지연 교통의 정체 원인을 r207에서 저장 입력으로 재현했다. 평가용 위치를 제어기 실행 후 별도로 대조한 결과, 반환378점은 ID20 지지 기둥과0.811mm 이내였다. 이 정답 대조는 원인 분석에만 사용했다.

기존 `StaticSideTracker`는 명령 예측용 `dt=0.1s`를 사용했으나 실제 판단 기준 시각 차이는0.1–0.4초였다. `advance_to(reference_s, speed)`를 추가하고 실행 선택기에서 사용한다. 양 끝 측정 속도의 사다리꼴 적분이며, 중복 시각은 다시 적분하지 않고 역행/음수·비유한 속도/기존0.25초 초과 공백은 정지 물체 근거만 초기화한다. 명령 예측 dt·정지 물체 판정 수치·독립 보호·속도·물성은 바꾸지 않았다. 예전 고정 간격 시험용 `advance`는 보존한다.

## 확인한 결과

- 단위 반례·관련 제어/보호/출처 검사 **171개 통과**. 실제0.2초 호출의 고정 기둥, 저속 이동 차량, 동일 속도/추월/접근 차량, 중복 시각, 속도 변화, 불연속 시각·역회전/무효 속도를 포함한다.
- r208 후보에서 r203 원469판단의 정지→진행56개, 새 정지0개, 주요52정지 중50개 진행을 확인했다. r206 원154판단에서는 정지→진행1개, 새 정지0개다.
- 공통 코드의 **623개 명령**과 변경 행의 상태/이유가 r208 저장 후보와 일치했다. 이는 새 궤적이나 모든 진단 필드의 동등성 증명이 아니다.
- 관련2패키지 빌드가10.1초에 완료됐고 시험 prefix 의존성과598개 지연 표본을 실행 전에 확인했다.
- 실행 소스는 `before_sources.zip`·`before.json`과 `config/tests/static_side_elapsed_r209_sha256.json`에 연결했다. 원 실패와 후보 산출물을 덮어쓰지 않았다.

이 구현은 실제 속도 이력을 전부 적분하는 운동 추정기나 물체 신원/정지의 증명은 아니다. 현재 동일 속도 표본과 판단 기준 시각에 대한 근사다. 새 폐루프 주행은 [r210](../static_side_runtime_r210_v1/README.md)에서 별도로 확인한다. 실물 전체 주행 승인은 아니다.
