# 통과 확인 뒤 낮은 목표 속도 비교

11/12 r187 저장 입력473개를 동일 재현하면서 원 상태/출력은 유지하고, 현재 경로가 완전히 관측된 RELEASED 정지108회에 기존0.35/0.25/0.15 m/s 목표를 비교했다. 실제 측정 속도·원 경로 조향·직전 조향·현재 반환과 가림 조건은 그대로 사용했다.

**현재 광선으로 이동 영역이 확인되어 허용된 경우는0개**였다. 속도 상한만 낮추는 대안은 채택하지 않으며 새 주행도 하지 않는다. 이 결과를 모든 저속 진행 가능성의 부정으로 확대하지 않는다. 알려진 가림/제한 공백에 대한 기존 위험 분류까지 새로 확장한 시험은 아니다.

`preview.py`, `result.json`, `preview.log`가 근거다. Jetson 접근·ROS 발행·운영 기본값 변경은 없었다. 이번 비교 뒤에는 임시 prefix에 흩어진 기존 정책의 공통 선택 연결을 먼저 정리한다. 미완주/기존 실패는 보존한다.
