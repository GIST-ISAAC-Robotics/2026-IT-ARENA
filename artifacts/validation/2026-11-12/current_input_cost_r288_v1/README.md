# 현재 경로 재검사의 입력별 PC 비용 r288

같은 r281 후보로 r279의 현재 입력 매10번째52개와 r282의54개를 번갈아 계산했다. 입력 복원·현재 scene 구성·현재 재검사·출력 변환을 포함하고, cProfile 계측 호출은 시간 표본에서 제외했다.

| 저장 입력 | 표본 | 중앙값 | p95 | 최대 |
|---|---:|---:|---:|---:|
| r279 정체/저속 공백 중심 | 52 | 21.167 ms | 27.780 ms | 37.520 ms |
| r282 직선 FOLLOW/병렬 중심 | 54 | 12.259 ms | 16.590 ms | 17.236 ms |

r282 선택54개는 기록된 전체 출력과 같았다. r279에는 후속 r281 정책을 적용했으므로 원 출력 일치를 조건으로 삼지 않았다. 원문과 후보 해시는 `report.json`에 보존한다. 복원/운동 보정 외에 현재 이동 영역·저속 공백의 질의 생성과 광선 대조가 비용을 차지한다(`top_profile.json`). 서로 다른 입력 집합의 비교이며 단일 알고리즘 변경의 효과가 아니다.

**이 PC 비율로 Jetson 비용을 환산하지 않는다.** r282의 고정81.304613ms는 r279 입력에서 얻은 Jetson p95를 매 호출에 적용한 스트레스 전제다. 모든 직선 입력의 실제 Jetson 비용이라고 표현하지 않는다. 해당 조건의 반복 명령 만료·실제 접촉 실패를 취소하거나 통과로 바꾸지도 않는다. 장비 재허용 후 대표 입력별 실제 비용과 동시 부하를 확인해야 한다.

첫 실행은 파일명 `profile.py`가 Python 표준 모듈을 가려 import 단계에서 실패했다. `first_import_failure.log`를 보존하고 이름을 바꿨다. 최종 실행은 정상 종료했다. Jetson·ESP32 접속/조작, 새 주행, 기본값/TTL 변경은 없다.
