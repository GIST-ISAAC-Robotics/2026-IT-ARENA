# 현재 영역 정책의 제한 지연 주행 r282

r279와 같은80초·0.8m/s 각본 상대2대·시설·ID20/30누락·native C1·81T 구동계로 한 번 실행한다. r278반대 벽 후보와 r274병렬 전달은 유지하고 r281현재 저속 영역 정책/동일 호출 중복 계산 제거를 현재 검사 자식에만 연결한다. 계획 최소 결과 나이146.7455ms는 유지하며 현재 검사 최소 나이는 r281Jetson p95인81.304613ms다. 전체IPC/센서/계획 동시 부하나 최악지연 재현은 아니다. 정책과 최소 지연이 함께 바뀌므로 단일 인과 A/B로 해석하지 않는다.

선행: r2817검사·PC/Jetson각518전후 전체동일·404저속 재개·PC/Jetson명령 대조. 실제spawn현재 검사4개(고속 거절·현재 공백 거절·저속2개) 동일/정상 종료. 최초 시험 표본4개가 모두 양수여서 양수/정지 혼합이라는 시험 전제가 실패했다. 실제 거절 표본79/85를 선택했으며 원 로그는 `process_selection_failure.log`로 보존했다. 제어기 조건은 바꾸지 않았다.

원1랩·진행·접촉/노면/간격·STOP/정상 종료 기준을 유지한다. 결과/현재정책 실제발동·현재 검사 전달/정지 이유·소스/입력 보존을 확인한다. 실패하면 원인을 분석하고 같은 실행을 성공까지 반복하지 않는다. `/drive`→독립 보호→`/drive/safe`, 원시 시각·기하500ms·currentraw300ms/명령200ms·물성을 유지한다. 기본 활성화·실물 구동은 하지 않는다.
