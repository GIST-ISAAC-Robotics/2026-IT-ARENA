# 현재 영역 재검사의 저속 정책 일관성 r281

r279의 새 반대 벽 후보는 발동0회였고548계획 OFF/ON이 모두 같았다. 정체는 현재 재검사의 추가 영역 검사에서 반복됐다. 원19.921초에는 측정속도0.367m/s이므로 기존 저속 공백 범위밖이며 정지를 유지한다. 정체 뒤54.172초에는 속도0·출력 후보0.15m/s이고 현재 차체 옆 최대7.969mm의 좁은 무반환/1cm 이하 장착 가림이 있었다. 같은 현재 광선의 기존 `released_body_gap.check`는 통과했지만 추가 영역 검사가 이를 적용하지 않고 일괄 거절했다.

추가된 영역 검사에도 이미 명시 선택한 RELEASED/ GUARD 저속 공백 정책을 같은 현재 입력으로 재실행한다. 원 양수 허가·점유·측방/상태 검사가 먼저 통과해야 하며 기존0.35m/s/1cm/광선 간격·이웃 거리/가림 규칙은 바꾸지 않는다. 미관측 개수는 그대로 기록하고 과거 허가를 재사용하지 않는다. TTL/물성/독립 보호 변경 없음.

우선 저장 현재 확인518개 원 재생과 후보 영향을 비교한다. 더 빠른 측정/앞 점유/넓은 무반환/새 측방 위협/선택 OFF의 반례를 기존 판정과 비교한 뒤 실제 연결 여부를 판단한다. 새 주행이나 공통 채택은 아직 하지 않는다. 원 접촉/정체 실패를 보존한다. 최초 진단 파일명이 Python 표준 `inspect`를 가려 import 실패했고 `inspect_region.py`로 바로잡았으며 원 오류 로그를 보존했다.
