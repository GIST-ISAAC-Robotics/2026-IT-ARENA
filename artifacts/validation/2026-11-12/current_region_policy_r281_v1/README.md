# 현재 영역의 저속 정책 일관성과 중복 계산 제거 r281

## 확인한 문제와 수정

r27919.921초의 실제속도0.367m/s는 기존 저속 범위 밖이므로 정지를 유지한다. 이후54.172초에는 실제속도0·목표0.15m/s이며, 미관측332표본이 차체 옆 최대7.969mm에 있었다. 현재 광선의 기존 좁은 공백 검사는 통과했으나 추가된 경로 영역 검사가 그 결과를 반영하지 않아 다시0으로 만들었다. [원 영역](current_query_region.png)·[분석](inspection.json).

현재 입력의 기존 `released_body_gap`/GUARD 저속 공백 판정을 추가 영역 검사에도 적용한다. 과거 허가·영역은 가져오지 않으며 미관측 개수/원 시각·실제속도·원 상한·점유 검사를 유지한다. 같은 호출에서 이미 계산한 결과와 동일 영역만 재사용한다. 후보는 별도 파일이며 공통 기본/실물에 채택하지 않았다.

## 저장 입력과 비용

- PC 원518현재판단 동일. 후보는404개를0→기존 저속 목표 이하 양수로 바꾸며 양수→0은 없다.
- 실제속도 범위 밖·넓은 공백·앞 점유·선택 OFF 등7검사 통과. 현재 검사의 허가 재사용 전후518전체 출력 동일, 추가 전체 검사404→38회.
- 다시 동일 호출의 영역 재계산을 생략했다. PC518/Jetson518출력은 각 플랫폼 안에서 모두 동일하다.
- 같은 입력 복원·현재 장면 구성·검사·결과 변환 전체 범위: PC 중앙24.64→20.17ms·p9529.22→23.75ms, Jetson 중앙88.52→71.03ms·p9599.72→81.30ms. Jetson 최대167.30→189.22ms로 최악값 개선은 확인하지 못했다.
- 앞선 허가 재사용 비교의 PC37.13→22.59ms는 핵심 함수만의 별도 범위다. 전체 비용/Jetson 수치와 혼합하지 않는다.

처음 Jetson 원 출력 대조는 정수 진단 개수 차이로 중단됐다. 원518개 중 전체501개 일치·명령/이유/시각518개 일치이며 불일치 원문을 보존했다. PC/Jetson 후보 전체 출력도 [별도 감사](cross_platform_audit.json)에서 비교한다. 극미한 부동소수점 차이로 질의 중복 제거 개수가 달라질 수 있으며 전체 같다고 요약하지 않는다.
