# 최신 미사용 스캔 제출 대조 r273

신규 계획과 현재 영역 검사를 두 프로세스에서 수행하고, 마지막 광선 이후25ms 창을 기다리는 `fresh`와 원 시각 예산 안의 최신 미사용 스캔을 제출하는 `latest`를 비교했다. 보관 경로 반복 발행은 사용하지 않았다. 현재 raw300ms/명령200ms, 기하500ms와 현재 영역 재검사는 같다. 기하500ms는 선택형 후보의 예산이며 기본값 변경이 아니다.

Jetson의 만료 구간 개수는45→56으로 늘었으나 갱신 자체도 늘었고 누적 만료 시간은 줄었다. 이는 같은 저장 궤적과 원 센서 값을 쓰되 운동 표본의 취득+20ms 도착을 가정한 결과다. 실측 수신 지연·실제 ROS·주행 증명이 아니다. 실제 비용/스케줄링 변동과 입력 선택의 영향을 포함한다.

PC/Jetson 각7개 제출 조건 검사를 통과했다. 회수 후 독립 감사에서 원 시각·현재 raw/명령/기하 예산, 최소100ms 제출 간격, 보관 경로 발행0, 네 실행의 자식 정상 종료를 확인했다. 소스 계보263개와 원 입력은 유지됐다. 실제 센서·펌웨어·전력은 사용하지 않았다.
