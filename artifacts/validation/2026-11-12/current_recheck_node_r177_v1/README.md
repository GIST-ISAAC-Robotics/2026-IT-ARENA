# 현재 경로 재계산의 명시 노드 연결

2026-11-12 실행 전 등록. r176 공통 모듈의2,414반환 동일/73검사를 바탕으로 `g1_current_path_recheck:=selected_v1`을 별도 선택할 때만 계산 결과를 현재 입력으로 다시 검사한다. 기본 `off`와 기존 inline/process_candidate의 기본 동작은 유지한다.

현행 G1/G2는 여전히 시뮬 전용·50Hz 수신부·기록 경로가 필요하다. 이 제한을 지워 실물 실행으로 바꾸지 않는다. Jetson 접근·Gazebo 주행·새 위험 분류·평가 지연 주입은 없다. 명령은 기존 `/drive`와 독립 보호를 거친다.

확인할 항목은 OFF 기존 명령/시각/trace 불변, ON 원 입력/현재 입력/재검사 출력 기록, 미지원·discard·STOP의 기존 처리, 현재 검사 실패의 0 명령과 실제 ROS 노드 종료다. 새 스캔에 맞춘 제출 정책과 옛 Jetson 비용 지연 주입은 아직 별도 시험 연결에 남으며 이번 수정에 포함하지 않는다.

## 결과

기존473판단의 OFF 출력/시각/기록 동일과 ON193개 실제 재검사 결과 동일을 포함한54검사를 통과했다. 후속 실제 노드 OFF/ON 생명주기·출처 검사는196통과/1실패였으며, `off`가 ROS CLI YAML의 bool False로 해석된 것이 원인이었다. launch에서 문자열 형식을 명시하고 직접 CLI 시험 인자도 문자열로 전달해 두 실제 노드의 STOP/RESET/계산 프로세스 종료를 재검사한2개가 통과했다. 실패 로그는 보존한다.
