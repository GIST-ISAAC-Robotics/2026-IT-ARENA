r219는80초 상대 이동64m가 옛1.2랩 감사 범위53.568m를 넘어서 주행 전 거절됐다. 해당 원 실패를 보존하고, 기존 평가기가 허용하는1.5랩 범위66.96m로 상대의 경로 감사 범위만 다시 등록한다.64m 전체를 도로/벽과1cm 간격으로 대조한다.
