# 통과 상태 저속 공백 보완의 지연 교통 시험

실행 전 등록: r187과 같은 공식 파생 코스·시설·두 상대 0.8 m/s·마커 20/30 누락·native C1·60초와 동일 지연 표본을 사용한다. 속도·간격·물성·독립 보호·노면/정지/종료 기준은 유지한다. 단일 모터축 28카운트·2.5×81/17 감속·65 mm 모델이다.

변경은 r199의 기본 OFF `g1_released_body_gap_trial:=true` 선택이다. 앞서 저장 재생과 실제 ROS 설정으로 확인한 공통 `selected_r181`/`selected_v1` 정책을 사용하고, r187의 평가용 지연 주입과 만료 경로 참조 보존만 prefix에 남긴다. 동일 GUARD 로직의 공통화와 깊이 행 묶음 변경은 r190–r197의 출력 동등성 근거를 따른다. 원 r187 실패나 원시 입력은 덮어쓰지 않는다.

같은 실패를 성공할 때까지 반복하지 않는다. 한 번의 대표 결과 뒤 실패 원인을 분리한다. 원34 m 갈림길에 도달하지 못하면 그 갈림길 수정은 미검증으로 남긴다. 이번 주행은 PC/WSL 전용이며 Jetson·실물 센서·모터를 사용하지 않는다. 실행·판정·정상 종료 결과는 아래에 추가한다.

## 결과와 남은 원인

60초에 **24.00 m·최장 저속11.417초로 미완주**다. r187의24.20 m/11.521초와 비교해 실질적인 진행 개선은 없다. 접촉/중첩·노면 이탈0, STOP 변위0.097 m·정착, 정상 프로세스 종료·고유 파티션 잔여0·입력/등록 소스와 ZIP 불변을 확인했다. 한 랩·지속 주행·최종 간격의 실패는 보존한다. 원34 m 갈림길에는 여전히 미도달했다.

새 후보는 실제1회만 적용됐다. 전체473판단을 그대로 재생해 내부 검사 이유를 관찰하니, RELEASED 공백 후보109회 중1회만 통과했다. 이어지는106회는 각 저속 목표에서 `unbounded_nonreturn`으로 거절됐다(318개 검사). 2회는 검사 전 범위를 벗어났다. 첫 허가 다음 스캔에서 공백 양쪽이 유효 반환으로 둘러싸인 조건을 만족하지 못했다. 원 저장 입력108정지 개선을 실제 궤적의 개선으로 확대할 수 없다는 사례다. 실제 차체 움직임이 달라졌으며, 과거 저장 입력의 원위치만 반복 검사해서는 이 차이를 알 수 없었다.

현재 입력 재검사는326회 중284회 양수이며 `guard_current_approach_not_observed`28회 등 거절도 남는다. 제어/관측 조건을 바로 낮추거나 같은 주행을 반복하지 않는다. 다음 주행 검토는 새 실패 입력에서 기존 장착 구조 인접 공백 범위가 해당하는지부터 분리한다. 단순 속도 축소는 r189에서 개선0이었으므로 다시 같은 접근을 반복하지 않는다.
