# r271 조건부 보조 검사 제출

r266은 실제 Jetson에서 새 계획 때문에64개 현재 검사가 폐기됐고 양수 출력과 최장 공백이 악화했다. 이번에는 경로/명령 판정을 바꾸지 않고 과거 계산 시간과 원 명령 시한으로 보조 검사의 제출 필요성을 비교한다.

- 기존 r266의500ms 기하 후보·현재 raw300ms/명령200ms·100ms 최소 양수 갱신 간격·새 계획/0/STOP 우선을 그대로 쓴다. 공통/ROS 기본에는 미연결이다.
- 직전32개 실제 회수 시간에서 계획p25·현재 확인p75를 사용한다. 각3개 이상 완료 전에는 보조를 제출하지 않는다. 계획이 일찍 완료될 수 있음을 보수적으로 고려한다.
- 보조가 발행 가능해지는 추정 시각이 새 계획 완료보다20ms 이상 앞서고, 정상 새 계획/확인을 기다리면 기존 명령 시한20ms 전까지 갱신하기 어려운 경우만 제출한다. 현재 입력/기하가 기존 예산 안에 적용 가능해야 한다.
- 이 예측은 계산 작업의 선택일 뿐이다. 정확하지 않아도 원 검증·현재 관측·STOP을 우회하거나 오래된 명령의 시각을 갱신하지 않는다.
- 저장 입력의 고정147/34ms PC 비교 및 추가 고정 지연 없는 Jetson 비교를 수행한다. 무조건 보조의 기존 실패는 보존하며, 새 실행은 new_only와 같은 입력·실제 프로세스로 대조한다.
- 채택 검토에는 보조 폐기 감소뿐 아니라 양수 갱신 수, p95/최장 공백, 원 시각 기준 만료 시간을 함께 본다. 양수 수가 줄거나 p95/최장 공백이 기준보다20ms 넘게 나빠지는 경우는 개선으로 채택하지 않는다. 단일 대조의 변동성과 저장 궤적의 한계를 남긴다.

실제 차량 반응·독립 보호/ROS 발행·접촉/정지 거리 증명은 아니다. 대표 결과가 나오면 실물 입력/운영 연결의 남은 P0로 이동하며 같은 실패를 무변경 반복하지 않는다.
