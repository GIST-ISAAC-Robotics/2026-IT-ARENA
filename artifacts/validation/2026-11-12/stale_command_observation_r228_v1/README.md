# 명령 만료와 센서 관측 기억의 분리 비교 r228

r225의 독립 보호층은 명령이 오래됐다는 이유로 유효 센서의 관측 갱신도 건너뛰고, 이후 이력 만료를 래치했다. 원 로그만으로 그 구간의 모든 센서 수신을 확인할 수 없으므로, 여기서는 **센서가 계속 유효한 경우**와 실제 센서 공백·이미 보인 물체의 소실을 분리한 노드 경계 합성 반례를 만든다.

사본 후보는 오래된 명령을 출력하지 않고 기존0을 유지하면서 센서/운동 검사를 통과한 관측 평가만 계속한다. 마지막 유한 명령은 기존 관측 외곽 검사의 속도/조향 인자로만 사용하며 새 구동 허가가 아니다. 실제 센서/운동의 신선도·장애물 기억·0.3초 이력 기준·독립 보호 출력 경계를 바꾸지 않는다. 운영 연결 전 비교이며 원r225 실패와 소스는 보존한다.

네 장면의10개 조건을 통과했다([결과](report.json)). 시각/전송 만료 두 장면의 원 함수는 새 명령 뒤에도 이력 만료 정지가 남았고, 후보는 새 명령에서0.2m/s로 복귀했다. 두 함수 모두 만료 명령 중0출력이며, 후보에서도 실제 센서 공백과 이미 관측한 근거리 점의 소실은 래치가 남았다. 합성 점군/입력이므로 r225의 전송 순서를 그대로 재생한 증거는 아니다. 원 함수는 [r229 변경 전 소스](../stale_command_observation_connected_r229_v1/before_sources.zip)에 보존했다.
