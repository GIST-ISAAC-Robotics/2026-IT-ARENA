# 선택형 병렬 ROS 연결 r274

- r273의 신규 계획만 사용한다. 보관 경로 반복 발행/조건부 보조는 미연결이다.
- 실제 ROS 현재 운동 이력으로 재검사한다. 저장 입력의20ms 도착 가정은 사용하지 않는다.
- 기본 런타임은 유지하고 단일 제어 노드의 명시 실행 prefix에서만 연결한다. 시뮬레이션 전용이며 Jetson 실물 구동에 연결하지 않는다.
- 두 프로세스의 완료를 수신하고 현재 영역/원시 시각/epoch/직전 실제 발행 요청각을 다시 검사한다. STOP·세대 변경은 진행 중 결과를 무효화한다.
- 현재 raw300ms·명령200ms·양수 갱신100ms와 r266 기하500ms 후보를 유지한다. 원 시각을 새로 붙이거나 미관측 영역을 자유로 채우지 않는다.
- r253과 같은80초·두 상대0.8m/s·시설·ID20/30 누락·native C1과 기존 접촉/노면/진행/STOP 기준을 사용한다. 계획146.7455ms/현재33.5631ms의 최소 결과 나이를 시뮬레이션 시계로 주입한다. 두 지연은 각각 p95이며 결합 p95/최악 조건이라는 의미는 아니다.
- 입력/출력 인계·STOP/늦은 결과·양쪽 완료 알림·종료 회귀 뒤 제한 실행1회. 근거 없이 성공할 때까지 반복하지 않는다. `/drive→독립 보호층→/drive/safe`는 그대로다.
