# 실제 센서 관측 실행의 재사용 연결 r280

r275/r276의 실제 센서/영상 관측은 작업별 절대 경로와 복사한 노드에 의존한다. 조립 전 같은 연결을 다시 사용할 수 있도록 공통 `probe_g1_hardware_shadow`에 명시 `--camera`를 추가하고 검증된 영상 발행기·제한 실행 감독을 공통 scripts로 옮기는 후보를 준비한다. 새 인식/시각 알고리즘이나 구동 권한은 추가하지 않는다.

기본은 카메라 미연결이고, `--camera`에서만 영상 프로세스를 시작한다. IMU 앱과 sensor_link 앱은 선택한 하나만 포트를 소유하며 sensor_link 선택은 관측 상태만 추가한다. 자동 flash/ARM/DRIVE/가상 엔코더는 없다. C1 SDK 해시와 포트 사용/권한을 확인하고 localhost domain216에서만 실행한다. 실물 영상 픽셀은 저장하지 않는다. `--plan-only`는 장치 접근 없이 명령을 확인한다.

r279 실행 중에는 공통 파일을 바꾸지 않는다. 후보 정적 검사 후 r279가 끝나고 소스 보존 확인을 마치면 공통 연결·출처 검증을 진행한다. 새 실제 수신은 재사용 실행 연결 검증 목적의 한 번으로 제한하며 기존 카메라 누락/시각 추정/엔코더 에지0 한계를 그대로 남긴다.
