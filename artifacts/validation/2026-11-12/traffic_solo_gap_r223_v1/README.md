# 교통 중 SOLO 상태의 좁은 공백 비교 r223

r220의 끝부분은 경로 예외가 아니라 `follow_lateral_metric_outside_trial`로 정지한다. 예시 마지막 입력은6개 무반환·공백 약4.392°이며 기존 고정0.6m 반경에서 양쪽 반환 사이 숨은 현이55.775mm로50mm 범위를 넘는다. 경로는1.8m 이상 관측되며 실제 옆차 `present/seen`은 모두false다. 이 사실은 무반환 안에 물체가 없다는 증명이 아니다.

단독 r69에서 확인한 `oblique_gap_trial`의 이동 반경/동일50mm·0.2m/s 요청·실제속도·이전 소실 위협 검사를 재사용할 수 있는지 저장 입력으로 비교한다. 선택기가 SOLO이고 양쪽 모두 seen/present=false인 호출에서만 기존 partial 정책의 해당 계산을 선택하고 원래 값은 즉시 복원한다. 원 교통 선택기·현재 관측·독립 보호·소실 기억은 유지한다.

현재는 시험 코드의 반사실 비교다. 공통 옵션/실제 주행으로 연결하지 않는다. 같은 호출에서 새 옆차가 나타날 수 있으므로 최종 선택 상태와 변경 명령을 별도로 확인하며, 이 결과만으로 교통에서 같은 잔여 위험이 수용됐다고 결론내리지 않는다. 원r220·r217 전체 출력 재현을 먼저 확인하고 변경한 출력의 상태/속도·새 정지를 비교한다.
