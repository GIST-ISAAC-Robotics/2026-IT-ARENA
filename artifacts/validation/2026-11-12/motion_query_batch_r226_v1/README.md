# 현재 재검사 원호 질의 일괄 생성 r226

r222의 Jetson 프로파일에서 현재 옆차 재검사 비용 중 이동 영역 질의 생성이 약1/3이었다. 현재 조향과 직전 조향의 차체 외곽을 각각 처리하는 대신 같은 자세들을 한 묶음으로 처리하는 저장 입력 전용 후보를 비교한다. 원호 길이·자세·바퀴 외곽·얇은 unknown 교차·질의 중복 제거·점유/여유 기준은 바꾸지 않는다.

r221의460개 현재 입력을 사용해 원 질의 배열의 완전 일치와 전체 재검사 출력을 대조한다. 비용은 준비된 입력의 재검사만 교대로 측정하며, 동시에 진행 중인 시뮬레이션의 영향을 받을 수 있다. 공통 코드/운영 연결·Jetson 하드웨어·구동은 변경하지 않는다. 유효한 비용 개선과 동일성 근거가 있을 때만 후속 채택을 검토한다.

## 결과

PC와 Jetson 각각460개 입력의 두 번 대조에서 전체 재검사 차이0, 실제 이동 질의26호출의 배열 차이0·최대 좌표 차이0이다. 원시 입력과 각 실행의 소스가 유지됐다. 전부 반환/전부 무반환·얇은 결측·혼합 결측, 같은/다른 조향과 거의 직선·정지/역방향/전진 속도를 대조한72검사도 통과했다.

| 재검사만 측정 | 원 중앙/p95 | 일괄 중앙/p95 |
|---|---:|---:|
| PC | 1.238 / 11.714 ms | 1.214 / 10.029 ms |
| Jetson | 4.493 / 41.402 ms | 4.454 / 36.704 ms |

각920표본이며 비용이 작은 다른 상태도 포함한다. 전체 ROS·점군 투영·입력 복원·독립 보호·계획기 비용을 포함하지 않으며, Jetson p95는 여전히20ms보다 길다. 두 번의 교대 측정에서 보인 감소를 최악 지연 보장이나 전체 제어율 달성으로 해석하지 않는다. PC에는 동시 시뮬레이션 부하가 있었다.

Jetson은 기존 r221 격리 worktree를 사용했다. PC의 후속 r224 SOLO 선택 파일과 일부 배포/launch 파일은 다르지만, 이 비교에 쓰인 이동 질의·현재 재검사 함수는 같다. 각 기기의 원 함수와 후보를 **같은 기기/입력/소스**에서 비교했다. 상대 기기의 세부 진단 개수와 직접 대조한 결과가 아니다. 센서/ROS/직렬 포트/차량 모터·전력 설정은 사용하지 않았다.
