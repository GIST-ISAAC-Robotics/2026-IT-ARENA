# RELEASED 차로 유지 현재 재계산의 제한 주행

2026-11-12, 실행 전 등록. Jetson 접근 없이 LOCALHOST/고유 파티션의 PC 시뮬레이션만 사용한다.

r171의20.27m·최장저속10.772초 미완주와 원 실패를 보존한다. 양수 출력 전체를 대조해 `RELEASED/parallel`166개가 현재 재계산에서 누락된 것을 확인했다. r173은 저장166개에서 같은 시각/+20ms 모두 현재 재계산을 수행했고 +40ms는 모두 운동 이력 만료로 거절했다. 이전r168의32개에서는 새 옆차3개를 각 시각에서 거절했다. 관련15개 반례를 통과했다.

이번 변경은 기존 선택 경로·1cm 횡이동 제한·실제속도·원 경로 시각을 유지한 r173 연결이다. 아울러 r172의 동등 연산 개선(미사용 최근접 거리 격자 생략)을 포함한다. 후자는 저장468개의 함수 반환 및 전체 제어 출력이 동일하며 현재 source 계약으로 구분한다. 원천 스캔 지연 하한은 이전 Jetson 계측에 기반한 동일 입력이며 실제 새 Jetson CPU 재현으로 설명하지 않는다.

60초·0.8m/s 두 앞차·시설/마커 가림·같은 속도/노면/물성/센서·명시 STOP/종료 기준으로 한 번 실행한다. 성공할 때까지 무변경 반복하지 않는다. 후보 기본 활성화·차량 구동·네트워크 Jetson 접속은 하지 않는다. 종료 후 전체 진행/접촉/주요 정체의 상태를 함께 본다.

## 결과

60초 제한 주행은 **16.39m·최장저속24.866초로 미완주**다. 접촉/겹침/노면 이탈 표본0, 명시 STOP·정상 종료·잔여 파티션 프로세스0을 확인했다. 원 최종간격·장기정체·전체 랩 실패를 보존한다. [기계 판정](two_actor_run1/combined_assessment.json), [주요 판단 분류](diagnosis.json).

현재 재계산193회 중189회 양수, GUARD 이동 영역 미관측2회·직선 차로 유지의 횡이동 한계2회가 0이었다. 이번 궤적에는 새로 연결한 RELEASED/parallel 양수 사례가 없었다. 따라서 연결 효과가 실주행에서 입증됐다고 보지 않는다. 전체473판단 중 경로 계산 자체가 0인 구간이 길었으며, RELEASED/parallel108회와 GUARD/parallel157회는 직선 유지 경로 부적합과 이동 영역 미관측이 함께 남았다. 같은 시점/궤적의 대조 실험이 아니므로 이전 주행보다 나빠진 수치를 한 변경의 인과 효과로 단정하지 않는다.

전체 `src/scripts/config` 보존 감사에서는 다른 하드웨어 작업의 `scripts/probe_bus_servo.py` 변경1개가 발견되어 **원 소스 불변 판정은 실패**다. 보존 ZIP은 불변이며 나머지 등록 파일은 동일하다. 이 파일은 본 시뮬 실행/현재 재계산의 진입점이 아니지만 원 감사 실패를 성공으로 덮어쓰지 않는다. 시험 당시 바이트와 변경 목록은 [소스 보존](two_actor_run1/extra_sources.zip)·[무결성](two_actor_run1/extra_integrity.json)에 남겼다.

후속은 새 주행 반복 대신 [r175 저장 비교](../path_gap_revisit_r175_v1/README.md)다. Jetson에는 접근하지 않았다.
