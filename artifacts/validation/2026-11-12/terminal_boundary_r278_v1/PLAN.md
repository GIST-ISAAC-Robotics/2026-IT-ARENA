# 후반 경계 소실 저장 비교 r278

r274 정체 관측54.025초는 선호 왼쪽 벽에 가까운 기준점이 없지만 오른쪽에는1.8m의 현재 관측과 적합 경로가 있다. 기존 저속 단일벽 재획득은 선호 벽만 허용하여 이 비대칭이 정체 원인인지 비교한다. 지도/정답이 아닌 원 sensor scene을 시각화했다.

후보는 이미 선택된 `standing_wall_reacquire`·측정속도절대0.10m/s 이하·유효 경로 기억없음·선호 벽 경로없음에서만, 반대 벽이 기존 길이/anchor 기준을 통과할 때 사용한다. 선호 측에 경쟁 경로가 보이면 선택하지 않는다. 점유/재개 확인/현재 영역/독립 보호는 유지한다. 반대쪽 미관측을 자유로 채우지 않으며 측정 저속을 실물 정지 증명으로 쓰지 않는다.

먼저 저장549계획의 기본 동일성과 후보 선택/정체구간 양수 여부, 짧은 반대 벽·앞 장애물·빠른 상태·경쟁 선호 경로 반례를 비교한다. 이 단계는 공통/ROS 미연결이며 새 실제 주행을 아직 등록하지 않는다. 결과에 따라 구현 여부와 제한 주행을 판단한다.
