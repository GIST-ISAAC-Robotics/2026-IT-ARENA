# MCU peripheral 결합 빌드 준비 r289

PC에서 r283계약/PI·r285주기 상태·r287비차단 서보와 기존 IMU를 한 ESP-IDF 앱에 연결하는 중이다. UART0 IA/IMU/원시 관측 프레임을 섞지 않고, PCNT4/5와 읽기 전용 UART1 서보 관측을 함께 준비했다. PWM15/DIR6은 초기화 후0만 유지한다. 운영 구동을 열지 않으며 코드에 `output_ready=false`를 고정했다. 실제 PCNT 관측도 에지/방향 미검증이므로 유효 속도 피드백으로 넣지 않는다.

**현재 전달 상태: ESP-IDF 전체 빌드 완료, 보드 미설치.** 이미지 크기 보고277,788B이며 `completed.txt`·소스 snapshot·펌웨어 해시를 보존했다. 실제 GPIO/동시 수신·제어 주기·구동/조향과 새 multiplexer의 호스트 회귀는 미검증이다. 이 preview를 운영 펌웨어 완료라고 부르지 않는다. 원시 관측 메시지 `runtime_observation_v1`은 진단 정보이며 ROS motion 입력이 아니다. 장비는 사용자가 엔코더 시험 중이므로 접속하지 않는다.

설계 자료가 전달되어 기둥/배선·센서 높이 반영으로 우선순위를 전환했다. 빌드 결과는 `completed.txt`·`size.txt`·`firmware.sha256`과 로그로 구분한다. 이후 [r293](../runtime_mux_r293_v1/README.md)에서 **같은 mux 바이트**의 호스트 경계/혼합·5초 통신 예산·Python 복원과sanitizer를 확인했다. 이는 위 빌드 시점의 미검증 상태를 소급해 바꾸거나 실제 주변장치 실행을 증명하는 결과가 아니다. 실제 엔코더 에지/부호 확인 뒤 속도 피드백 연결, 최종 조향 교정·PWM/제동 정책과 출력 감시를 갖춰 별도 운영 연결을 진행해야 한다.
