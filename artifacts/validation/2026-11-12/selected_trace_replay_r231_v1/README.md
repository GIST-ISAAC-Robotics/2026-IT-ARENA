# 선택 실행 구성의 일반 기록 재생 연결 r231

r218의 만료 경로 참조를 공통 실행에 연결한 뒤 개별 시험 재생은 해당 초기화 함수를 사용했지만, 일반 `replay_follow_trace.py`가 쓰는 `follow_trace.replay_events`는 새 감사 이벤트와 선택형 만료 초기화 의미를 아직 해석하지 않는다. 앞으로 다른 기기/세션에서 저장 기록으로 실행을 점검하기 위해 이 차이를 정리한다.

원r225 기록의632판단을 일반 재생기와 사본 후보로 비교한다. 후보는 감사 이벤트를 수용하고 명시 옵션/원 기록의 `decision_source_expired`인 경우에만 공통 참조 초기화를 사용한다. 정상 STOP/RESET·옵션 OFF는 기존 전체 초기화다. 지연을 다시 주입하거나 원시 입력/명령·실행 결과를 바꾸지 않는다. 일반 ROS/보호층/물리 재생을 뜻하지 않는다.

원 재생기는 `unknown trace event`로 실패했고, 사본은632개 전체 판단 동일·입력 불변을 확인했다([원 실패](baseline.json)·[사본 결과 요약·원본 해시](candidate_summary.json)). 주행 시험 중의 소스를 보존하기 위해 공통 반영을 보류했다. r230 종료 후 사용자가 중간 정리를 요청하여 **공통 연결은 아직 미실시**이며 다음 재개의 짧은 작업으로 남겼다. 코드 누락 때문에 실패한 원 기록을 입력 불량으로 해석하지 않는다.

전체 판단 `candidate.json`은 기존 상세 재생 기록 제외 정책에 따라 로컬에 보존한다. 공개 요약에서 일치 수와 원본 해시를 확인할 수 있다.
