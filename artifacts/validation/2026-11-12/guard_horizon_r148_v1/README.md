# 코너 미관측의 낮은 목표 속도 전체 재검사

2026-11-12 저장 입력 비교부터 진행한다. r143의 거절 사유를 다시 나누니 작은 차체 옆면 범위 밖인 경우가 216회였고, 양옆 반환이 없는 경우는 1회였다. 대표 seq605는 측정속도0, 목표0.35 m/s의 반응/제동 영역이 옆면 밖10.86 mm에 걸렸다. 기존 허용 폭10 mm를 늘리는 대신 더 낮은 목표에서 **같은 전체 검사**가 성립하는지 확인한다.

r139는 기존 좁은 무반환 검사가 이미 통과한 뒤 가림 꼬리 때문에 거절됐을 때만 0.25/0.15 m/s를 재검사했다. 이번에는 현재 새 경계·현재 옆차 없음·전방 기본 경로 승인·기존 몸체 후보 `outside_small_body_side`인 경우에 한정해 낮은 목표 전체 재검사를 비교한다. 실제 측정속도는 줄이지 않으며 점유·이전 조향·위협 쪽 누적 접근·원 경로 시각·기존 무반환/가림 분류를 모두 그대로 적용한다. 거절되는 방향을 관측됐다고 바꾸지 않는다.

먼저 r143 기준465판단 동일 재생과 후보 출력 비교를 수행한다. 기존 양수 명령을 바꾸는지, 낮은 목표도 다른 조건에 막히는지 따로 기록한다. 진행 명령 개선이 없으면 새 주행을 하지 않는다. 저장 궤적에서는 후보 명령이 다음 센서를 바꾸지 않으므로 개선 수를 완주 성능으로 해석하지 않는다. 제어 기본값은 변경하지 않는다.

## 저장 결과와 다음 구분

기준465판단은 전체 동일했다. 후보는 원 정지84개를0.15 m/s로 바꿨으며 기존 진행→정지/다른 진행 변경은0이었다. 216회 재검사 중 낮은 목표에서도132회는 `unbounded_nonreturn`에 막혔다. 최초 새 허가는51.02초여서 기존 긴 정체가 시작된 구간을 바로 해결하는 후보는 아니다. 이 결과만으로 같은60초 주행을 다시 시작하지 않았다.

대표 진행 사례에서 같은 사전 상태를 복사해 전방15 cm 반환·전방NaN·실측속도0.6 m/s를 각각 넣었을 때 모두0명령이며 새 후보가 적용되지 않았다. 원 입력/출력84개 개선과 이 반례는 저장 입력 범위이지 실차/폐루프 증명이 아니다.

seq605의0.15 m/s 거절을 직접 추적하면, 미관측3광선(117.51–118.95°)의 한쪽은 약7.08 m 실제 반환, 다른 쪽은119.67°의 **선언된 장착 마스크**였다. 검사 대상 위치는 차체 좌표 x13.46–20.67 mm, y75.81–83.43 mm다. 미관측을 구조물 안에 있다고 설명하지 않는다. 둘은 인접한 별도 영역이며 기존 양옆 반환 조건을 만족하지 않았다. 다음 비교에서는 선언된 구조 가림과 인접 무반환을 함께 묶었을 때 바깥 양쪽 반환·같은 국소 숨은 폭5 cm를 확인할 수 있는지 조사한다. 새 위험 분류의 후보 검토이며 마스크 각도를 늘리거나 미관측을 자유 공간으로 바꾸지 않는다.
