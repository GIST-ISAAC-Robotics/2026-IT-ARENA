# 실제 경과 시각 연결 뒤 Jetson 저장 계산

r209 공통 코드와 r186 시험용 만료 참조를 사용해 r203 원469판단을 재생한다. 입력은 미리 읽고 한 번 준비 계산 뒤 한 번 비용을 측정한다. 첫 계산의 속도/조향은 r208 PC 후보 명령과 기존 수치 허용으로 대조하고, 두 번째 계산의 전체 비교 대상 출력은 동일 기기 첫 계산과 대조한다. 원 r203 출력과 모두 같아야 하는 시험은 아니다.

170파일·입력과 소스의 해시를 확인한 새 Jetson 폴더에서 실행한다. ROS·직렬/센서 포트·모터 명령·서비스·전원 설정을 사용하지 않는다. 다른 하드웨어 작업의 firmware나 배선을 바꾸지 않는다. 소스 보관과 전송 묶음 해시는 `bundle_manifest.json`, 원격 실행은 `remote_run.py`에 남긴다.

전체 폐루프·현재 재계산·독립 보호·ROS/영상의 비용을 포함하지 않는다. r197은 다른439판단이므로 비용을 단일 변수 개선율로 비교하지 않는다.
