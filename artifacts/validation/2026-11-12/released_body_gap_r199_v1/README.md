# 통과 뒤 저속 차체 옆 공백 보완

r187의 정체를 저장 입력으로 분석한 r198을 바탕으로, 기존 GUARD의 제한된 차체 옆 무반환 검사를 RELEASED에도 선택적으로 적용했다. `g1_released_body_gap_trial` 기본값은 `false`이며 `selected_r181` 관측 정책을 함께 지정해야 한다.

현재 완전 관측 경로·새 옆차 없음·실제 속도 0.35 m/s 이하를 요구한다. 기존 목표/상한보다 높이지 않고 0.35/0.25/0.15 m/s 순으로 전체 이동 영역을 검사한다. 차체 옆 1 cm·후측방 100° 밖·최대 6° 무반환·외측 반환 0.6 m 이상·국소 폭 5 cm 이내라는 기존 제한은 그대로다. 일반 미관측을 자유 공간으로 바꾸거나 선택기 통과 상태를 초기화하지 않는다. 결과를 적용하는 현재 입력에서도 전방·새 측방 물체·같은 공백 검사를 다시 수행한다.

## 확인 범위

- 기존 r187 저장 473판단에서 옵션 OFF는 모두 동일하다.
- 옵션 ON은 기존 정지 108개를 저속 전진으로 바꿨고 새 정지·선택기 모드 변경은 0개다. 같은 현재 입력의 재검사도 108개 모두 양수다. **새 궤적이나 실제 시간 경과의 주행 결과는 아니다.**
- 최초 관련 검사 174통과/9실패를 보존했다. 8개는 시험 fixture가 읽기 전용 `mode`에 값을 대입한 오류였으며 실제 측방 상태로 바꿨다. 나머지는 아직 등록 전인 소스 변경의 계보 오류다. 수정 뒤 새 경계 21개와 실제 ROS 노드 8설정의 STOP/RESET·프로세스 종료 8개를 통과했다. 기존 관련 검사 중 계보 1개는 등록 후 따로 확인한다.

- 등록 후 전체 소스 계보202검사, 기존 실패했던 계보 검사를 포함한 연결30검사, `arena_autonomy`/`arena_bringup` 빌드가 통과했다. 연결30개 중8개는 r200의 실제 spawn·만료 사유 전달/명시 STOP 분리다.
