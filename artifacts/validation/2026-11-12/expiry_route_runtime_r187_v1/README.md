# 계산 만료 뒤 본선 경로 참조를 다시 확인하는 제한 주행

2026-11-12 실행 전 등록. r182와 같은60초·두 상대0.8m/s·시설/마커20·30 누락·native C1/동일 지연 주입·동일 구동/노면/STOP 기준으로 한 번 비교한다. PC LOCALHOST/고유 Gazebo 파티션만 사용하며 Jetson 접근은 없다.

r182는 지주 앞 정체를 지났으나34.00m에서 대각 갈림길 방향으로 이탈했다. r186 v2는 원439판단 동일 재현 후, 만료 결과 폐기 뒤 최근 관측 경로에 당시 선택 벽을 묶고 현재 다른 벽 후보에 기존 전방 호 일치를 요구했다. 저장 입력60.22–62.12초에서 오른쪽 본선 벽을 다시 선택했지만, 이후 저장 차체 자체가 이미 이탈한62.72초 이후는 정지했다. 실제 궤적 개선은 아직 확인하지 않았다.

이번 prefix는 source 만료 폐기의 원 명령을 그대로 버리고 그 사유를 다음 세대 첫 요청에만 전달한다. 다른 세대/시계/벽/이전조향 변경과 명시 STOP/RESET은 전체 reset을 유지한다. 최근 참조는 기존0.6초 현재 관측 비교에만 쓰며 경로0.3초 TTL·점유·미관측·속도/간격·물성·독립 보호는 그대로다. 초기 단순 참조 보존 실패와 한 번만 벽 정보를 남긴 r186 v1 실패를 보존한다.

연결 전8검사에서 사유1회 전달·STOP 뒤 사유 제거·다른 폐기 사유 제외·실제 spawn 계산의 참조 보존/STOP 폐기와 정상 종료를 확인했다. 공통 r184 새 회전 제출을 명시 선택하며 지연/참조 보존은 이번 평가 prefix에만 남긴다. 기본 활성화와 실물 구동 승인이 아니다.
