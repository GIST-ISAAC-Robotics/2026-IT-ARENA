# GUARD 재진입 가설의 저장 입력 진단

2026-11-12. r152 두 번째 실행의469판단을 변경 없이 동일 재생했다. 직전 선택이 `parallel`이라 `_guard_curve_at_cap`이 진입하지 않은11호출은 모두 기본 경로도 `follow_release_wait`·속도0이었다. 따라서 직전 선택만 GUARD로 유지하는 수정은 이 정체의 해법으로 채택하지 않는다. [진단](diagnosis.json)과 호출별 원시 기록을 보존한다.

최장 저속 구간의 다른 호출에서는 현재 경로가 존재해도 기본 관측 정책이 `unbounded_missing`을 반환했다. 대표seq635는전방±100° 안의 결측1점·0.684°였다. 이 점이 분석 범위 끝에서 잘린 것인지 실제 반환으로 둘러싸이지 않은 공백인지 후속으로 조사한다. 현재 문서 단계에서는 원인이나 수정 효과를 확정하지 않는다. 실주행·보호 기준 변경은 수행하지 않았다.
