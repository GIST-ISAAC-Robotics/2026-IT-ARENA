# 통과 뒤 정체와 기존 차체 옆 공백 분류 대조

r187 저장473판단을 원 상태/명령 그대로 재현하면서, RELEASED의 낮은 실제 속도·현재 완전 관측 경로·새 옆차 없음 조건에서 기존 GUARD의 제한 공백 검사를 대조했다. 기존 r189는 속도만 낮춰108정지 중 개선0이었으나, 이번에는 **108개 모두 기존 `bounded_low_speed_body_nonreturn_risk` 검사에 통과**했다. 장착 지주 옆 추가 분류는 이 성공에 필요하지 않았다.

해당 검사는 차체 옆1cm 이내·후측방100° 밖·최대6° 무반환·외측 반환0.6m 이상·국소 폭5cm 이내·실제/목표0.35m/s 이하라는 기존 범위를 유지한다. 미관측을 자유 공간으로 지우거나 상태를 SOLO로 바꾸지 않았다. 실제 새 주행/완주 개선은 아직 확인하지 않았다.

같은 제한을 별도 기본 OFF 후보로 RELEASED에 연결하고, 오래된 검사 결과를 재사용하지 않도록 현재 입력에서 전방·새 옆차·같은 공백 조건을 다시 대조하는 것이 다음 단계다. `compare.py`, `result.json`, `compare.log`가 근거다.
