# RELEASED 차로 유지 출력의 현재 재계산 누락

2026-11-12, 저장 비교 후보. Jetson·새 주행·운영 기본값을 변경하지 않는다.

r168 양수 판단 전체의 적용 분류를 확인하니, r170으로 관측 GUARD를 보완한 뒤에도 `RELEASED/parallel`32개가 적용 대상 밖이었다. 앞차 통과 뒤 원래 경로 중앙으로 즉시 복귀하기보다 현재 차로를 유지하는 기존 기능이며, 새 조향 기능은 아니다.

후보는 기존 parallel 재계산의 선택 경로 일치·직선 적합·1cm 횡이동 한계와 r167의 원 통과 상태/현재 전방·옆차 검사를 함께 적용한다. 상태를 SOLO로 바꾸지 않으며 순수 기하 helper의 분류 인자만 연결한다. 새 옆차·전방 결측·원 경로 불일치·시간/세대 오류는 거절한다. 명령 시각만 고치거나 옆차 통과 이력을 만들어 넣지 않는다.

## 저장 결과

[r168의32개/96조건](comparison.json) 중 같은 시각29개/+20ms29개 진행, 각3개는 현재 새 옆 반환으로 거절했다. +40ms32개는 운동 이력 만료다. 관련15검사에서 원 경로 불일치·측방 이동 후보·직선 범위 이탈·새 장애물·전방 결측·세대/시각 오류 거절을 확인했다. r171에서도 양수 RELEASED/parallel166개가 기존 연결 범위 밖에 남았으므로 후속 비교 근거가 있다. 실제 주행/실차 증명은 아니다.
