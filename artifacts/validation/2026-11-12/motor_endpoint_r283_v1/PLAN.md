# 운용 MCU의 통신·피드백·속도 주기 연결 r283

현재 `firmware_sensor_link`는 실제 IMU와 출력 비활성 계약만 제공한다. 별도 모터/서보 진단 성공은 운용 MCU 완료가 아니다. 먼저 기존 엄격 프레임 수신·임대/STOP·송신·단일 모터 속도 계산을 한 소유 작업에 연결하는 작은 실행 계층을 만든다. 기본 준비false, 외부 HAL의 현재 준비값을 매 호출에 받으며 직접 명령 주입 API를 노출하지 않는다. 모터축28counts·11.911764706:1·65mm를 사례에 사용한다.

이번 묶음은 실제 출력/새 펌웨어 업로드가 아니다. 합성 엔코더 입력은 호스트 검사에만 사용한다. 실제 엔코더0을 유효 정지로 만들거나 장착/서보 환산을 임의 채택하지 않는다. ARM→DRIVE,0→재개,STOP/CLEAR/ARM,음수 축에서 전진 의도,피드백/명령 만료를 통신 프레임부터 검사한다. 이후 실제PCNT/PWM·서보 어댑터와 독립 출력 차단을 붙일 연결점으로 사용한다.
