**19.87m에서 왼쪽 벽 경계를 확정하지 못해 정지, 전체 랩 실패다.** r292 첫12m 통과와 같은 차량/센서/시설/공통 제어기/STOP 조건으로46.64m를 목표로 삼았다. 최고2.826m/s, 벽/시설 투영 겹침 표본0이다. 실패 뒤 명시 STOP·248개 조밀한 자세 구간의 정지 확인·서버/자식 정상 종료·남은 시험PID0, 등록621개 소스 불변을 확인했다. [종료 감사](assessment.json), 원 판정은 `run1/report.json`에 남긴다.
