# 만료 참조 시험 후보의 None 경로 검사

r212의60.72초 `AxisError`가 r186 v2의 전방 경로 비교에 None을 넘기는지 같은466입력으로 재현한다. r186은 보존된 시험 prefix이며 공통 운영 코드가 아니다. 원본을 덮어쓰지 않고 이 폴더의 `candidate.py`에 `candidate is not None` 조건만 추가한다.

유효한 경로에 대한 비교·TTL·관측/점유·독립 보호·STOP은 바꾸지 않는다. 경로가 없는 경우는 원래도 현재 관측의 다음 대안을 검사해야 하며 예외로 전체 경로 참조를 버려서는 안 된다. 예외 stack과 원/수정 전체 대조는 `comparison.json`에 남긴다. 저장 입력 개선을 새 궤적/전체 완주로 표시하지 않는다.

## 결과

원466판단은 전체 비교 대상 출력이 일치했다.60.72초(seq775)의 stack은 r186의 `path_agrees_arc(candidate, recent)`→`ahead(None)`→`np.linalg.norm(..., axis=1)`로 이어졌으며 단일 예외의 전파17개 frame 기록을 보존했다. 이는 센서가 불량해서 생긴 거절이 아니라 **우리 시험용 참조 분기의 구현 오류**다.

None 조건을 추가한 저장 후보에서 입력 예외0·정지→진행70개·새 정지0개였다. 첫 명령 변화도 해당 seq775이며 그 이전 명령은 동일하다. 이후 현재 오른쪽 벽을 기존 조건으로 재확정했다. 만료된 경로 자체를 주행 허가로 되살리거나 잘못된 왼쪽 갈림길로 바꾸는 수정은 아니다. 입력 궤적은 원 실패 기록 그대로이므로 실제 완주 여부는 [r217 제한 주행](../expiry_null_runtime_r217_v1/README.md)으로 분리한다. 실행 연결의 source 만료/STOP/다른 세대8검사도 통과했다.
