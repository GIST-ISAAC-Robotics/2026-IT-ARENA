# 같은 호출 안의 중복 공백 검사 제거 비교

2026-11-12 저장 전용. r149가 같은 입력의 `bounded_body_nonreturn`을 다시 실행하던 부분을 분리했다. 방금 같은 함수 호출에서 계산한 결과만 넘기며 이전 시각·다른 경로의 허가는 재사용하지 않는다. 별도 함수의 독립 진입점은 기존 검사를 그대로 수행한다.

17개 후보 검사와 r150 입력의 baseline/후보 각465개 전체 기대 출력 일치를 확인했다. [결과](../adjacent_cost_r150_v1/pc_r154_summary.json)·[소스 불변](source_check.json). WSL 전체 중앙은47.29 ms로 r14946.80 ms보다 줄지 않았고, 재검사216개 중앙은53.75→52.49 ms 정도였다. 서로 다른 시점의 한 번씩 측정이므로 의미 있는 전체 성능 개선을 입증하지 못했다. 기본/주행 연결에 채택하지 않으며 이 미세 최적화를 계속 반복하지 않는다. 다음은 기능 주행과 Jetson 연결 복구 뒤 비용 확인이다.
