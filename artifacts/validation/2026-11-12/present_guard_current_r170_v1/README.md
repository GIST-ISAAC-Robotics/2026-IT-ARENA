# 관측된 옆차 GUARD의 현재 재계산

2026-11-12, 저장 입력 설계·비교부터 수행한다. Jetson 접근·기본 활성화·새 주행은 이 단계에 없다.

r168은21.51m·최장저속7.957초로 실패했다. 원 계획기는 실제속도가0.35m/s보다 높은 감속 중에도 실제속도에 맞는 이동 영역을 검사한다. 그러나 수신부 현재 재계산은 양쪽 옆차가 안 보이고 실제속도≤0.35m/s인 경우만 지원하여, 정상 양수 GUARD 결과가 오래된 명령으로 남았다.

이번 후보는 원 `guard_baseline` 양수·완전 관측 결과만 대상으로 원 경로를 현재 좌표로 옮기고, 실제속도/직전·현재조향의 이동 영역과 옆차 쪽 추가 접근을 다시 검사한다. 목표는 원 명령과 기존0.35m/s 상한 이하다. 기존 진입 기준과 옆차 이력은 보존하고, 새 쪽 위협·실제 점유·전방 결측·현재 관측되지 않은 추가 접근은 거절한다. 이미 관측한 옆차가 있다는 사실만으로 거절하지는 않는다. `observed_guard_approach`·`motion_region`·`region_blocked` 등 원 정책 함수를 재사용한다.

센서 세대·경로 나이·운동 이력·조향 결합은 기존 기하 helper가 검사한다. 현재 명령 기준만 재계산하며 원 경로 시각은 유지한다. 이전 자유 공간/허가를 복사하거나 미관측을 자유 공간으로 채우지 않는다. 독립 보호층도 그대로 필요하다. 실제 배송/새 주행 전에는 저장 비교와 현재 장애물 반례를 먼저 확인한다.
