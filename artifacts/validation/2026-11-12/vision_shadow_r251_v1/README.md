# r251 실제 카메라·C1·IMU와 공통 영상 처리 관측

r249의 실제 센서 수신 대표 다음으로, 기존 B0390 720p60 수신 경로를 공통 노드의 별도 영상 프로세스에 연결한다. 20초 원천 수신 동안 센서 수락·영상 처리 횟수/지연·명령 상태·프로세스 종료를 확인한다. 이 시험의 계산 자식은 운영 코드와 같지만 유효 엔코더/취득시각이 없어 경로 계획을 구동하지 않는다.

- r249 `hardware_shadow_v1`과 `/hardware_preview/drive`만 사용하며 `/drive`·`/drive/safe`·MCU 명령 발행은 없다.
- `vision_execution=process`·`official_4red_local_candidate`를 명시한다. B3 운영 허가/마커 가림 재출발의 전체 통합은 이번 범위가 아니다.
- 실제 실내 영상의 수신·처리 부하만 본다. 차량 장착/신호등/마커 정답이 없으므로 검출 정확도를 평가하거나 임계값을 조정하지 않는다.
- 영상 header는 appsink의 호스트 수신 시각이며 노출 시각이 아니다. 실내 픽셀은 저장하지 않는다. C1/IMU의 원천 시간 승인·장착 상태는 미확정으로 유지한다.
- 펌웨어/전력 설정 변경 없음. 기존 IMU/C1 앱을 사용하고 종료 후 센서 정지·포트 반환을 확인한다.

## 결과

실제 Jetson에서30.03초 관측했고 네 자식과 두 계산/영상 프로세스가 정상 종료했다. 펌웨어를 바꾸지 않았으며 IMU `X`/ODR OFF·C1 정지·카메라 NULL·포트 반환을 확인했다.

**카메라 무손실 기준은 통과하지 않았다.** 제한 latest-frame 영상 처리 대표에서 인식196회가 모두 채택됐다는 결과와 별도로 보존한다. 네 장 누락의 원인이 DDS/부모 처리/다른 스케줄링 중 무엇인지는 이번 기록만으로 확정하지 않는다. 원문 픽셀 대응은 기존 r94 검사 범위이며 이번에는 메타데이터만 비교했다. 검출 마커0은 실내 장면의 관측일 뿐 검출 정확도 결과가 아니다.

유효 엔코더/시각이 없어 **경로 계획 부하는 실행하지 않았다.** 따라서 이 결과와 r248 계획 비용을 단순 합산해 전체 실시간 합격으로 판단하지 않는다. 장착 후 실물 운동 입력·실행 허가와 결합한 검증이 남는다. 이번 영상 연결 대표는 여기서 마치고 진행 중인 r250의 주행 영향을 분석한다.
