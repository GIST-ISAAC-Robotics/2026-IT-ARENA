# 최근 경로 참조의 공통 선택 연결 r218

## 목적과 선행 조건

r217 제한 주행 결과를 회수한 뒤, r216 시험 prefix에 있는 최근 경로 참조를 공통 코드의 명시 선택 옵션으로 옮긴다. r186은 실행 중 함수 본문을 문자열로 바꾸고 프로세스 통신을 감싼다. 실제 이관에서 누락되기 쉽고 r215의 None 후보 예외도 이 경로에서 발생했다. 일반 코드 정리보다 선정 실행 구성의 재현과 연결이 목적이다.

## 설계

- 기존 기본값은 전체 초기화다. `expiry_route_reference_trial`은 명시 선택이며 `junction_continuity`가 필요하다.
- 일반 계획기의 최근 경로는 선택 시에만 선택 벽을 함께 보관한다. 새 후보가 없으면 비교하지 않는다. 다른 벽으로 바뀌면 기존 전방 공통 호 일치를 요구한다. 원 기간/거리/확인 횟수는 유지한다.
- 새 결과가 원천 시각 만료로 폐기됐다는 사실은 해당 세대의 첫 계산 요청에만 전달한다. 후속 STOP/RESET·센서/시계 변경은 이 힌트를 지우고 전체 초기화한다.
- 자식 프로세스는 명시 선택 + 원천 만료일 때만 정상 주행 참조/선택 벽/시각 경계를 보관하고 나머지 추종·우회·명령 상태를 초기화한다. 명령과 활성 경로는 재사용하지 않는다.
- 노드/launch는 명시 process/native 선택 구성에 연결한다. 평가 지연은 시뮬 전용에 남기며 실물 시각 승인·실차 구동을 허용하지 않는다.

## 수용 기준

1. r216 후보를 켠 저장 입력과 공통 선택의 전체 출력이 같다. 기본 OFF는 변경 전 출력과 같다.
2. 실제 spawn에서 원천 만료만 참조를 보존하고 STOP·다른 세대는 보존하지 않는다. None 후보 회귀를 포함한다.
3. 노드의 옵션 전달·기록·STOP/종료와 관련 기존 회귀, 변경 소스 계약, 필요한 빌드를 확인한다.
4. 주행 미완료가 남으면 원인을 별도로 남기고 이관 완료를 주행 성공으로 쓰지 않는다.

현재는 설계만 작성했으며 r217 실행 중 공통 소스는 변경하지 않았다.
