# 장착 가림 인접 공백의 기존 저속 검사 진입 누락

2026-11-12 저장 입력 비교 전 등록. Jetson·차량·새 Gazebo 실행 없음.

r174 정체 입력268개는 부분관측 판정 자체는 `fully_observed`였고 그 뒤 선택기의 이동 영역 검사에서 거절됐다. r148의 낮은 목표속도 재검사는 `outside_small_body_side`일 때만 적용된다. 뒤에 추가된 r149는 장착 가림과 인접한 공백에서 **현재/목표 모두0.15m/s 이하**를 요구하지만, 앞 단계의 목표0.35m/s가 남아 `adjacent_structure_outside_scope`로 거절된 경우에는 낮은 목표 검사에 진입하지 않는다.

이번 후보는 실제속도≤0.15m/s, 현재 원천의 정상 경로·부분관측 허가·현재 옆차 없음, 기존 r149의 위 거절 조합일 때만 기존0.15m/s 전체 GUARD 검사를 한 번 더 수행한다. 미관측 수치·주변 반환·앵커·이동 영역/접촉 조건을 바꾸지 않는다. 단순 목표속도 변경으로 허가하지 않고 `_guard_curve_at_cap`의 전체 판정을 통과해야 한다. 이미0.15m/s를 검사한 입력은 중복 실행하지 않는다.

원473판단 재현 뒤 속도/조향/새 정지와 현재 재검사 연결을 비교한다. 실제 구동/기본 활성화는 별도이며 기존 실패는 보존한다.

## 저장 결과

원473개 전체 판단을 동일 재현한 뒤, 누락된 저속 전체 검사를 연결하자142개가0→0.15m/s로 바뀌었고 새 정지는0이었다. 변경된155개 중 나머지13개는 실패 사유 진단이며 진행 허가는 추가하지 않았다. 원 기록은 불변이다. [원/후 비교](comparison.json).

공통 현재 검사에서는 처음141개만 진행하고 음수 모터 피드백1개를 거절했다. 이를 r179의 기존 부호 정책 일치로 고친 뒤142개 모두 같은 시각/+20ms에서 현재 검사를 통과했다. +40ms는142개 모두 기존 운동 이력 만료로 거절한다. [현재 검사](current_check.json). 새 실제 장애물·공백과 이미 수행한 저속 재시도·실제속도 상한 등의 반례는 r179 관련69검사에 포함했다. 저장 입력 결과이며 실제 궤적은 아직 미검증이다.
