# r242 — 현재 재검사 자식 연결

r235/236의 동일 입력·완료 알림 후보를 기본 OFF 실행 옵션으로 연결한다. 원 계획과 현재 재검사 모두 원 reference·원천 나이·센서/운동 세대·마지막 발행 조향·벽 선택을 회수 때 확인한다. `last_application`은 실제 발행 뒤에만 갱신한다. STOP/RESET은 두 단계와 준비 결과를 무효화한다.

완료 알림은 결과를 읽지 않는다. ROS guard 콜백이 결과만 먼저 회수한 뒤 기존 `control()` 전체 경로를 사용한다. 센서 불량 때도 pipe 완료를 회수하여 같은 알림이 반복되는 것을 피한다. 명령은 기존 `/drive`→독립 보호층을 통과하며, 대기 중 시각 갱신/보호 우회는 없다.

작업 순서: 순수 회수 계약·실제 자식 회귀 → 공통 노드의 명시 옵션과 종료 연결 → 필요한 빌드/ROS STOP·만료 확인 → 고정 입력/제한 주행 판단. r236 비용 결과를 실제 노드 성능으로 재사용하지 않는다. 기본 활성화·계획 주기/TTL 변경·실차 구동은 범위 밖이다.

이 문서는 진행 계획이며 완료 증거가 아니다. 앞선 UART r239 실패/r240·241 제한 수신과 원 앱 복구는 각 보고서에 보존한다.
