# 옆차가 사라진 GUARD의 부호 있는 모터 피드백

2026-11-12. r178의 새 저속 계획142개 중141개는 기존 현재 재검사를 통과했으나1개는 모터 피드백−0.061225m/s 때문에 거절됐다. 계획기는 기존 `forward_drive` 정책으로 전진 가속 경로를 계산했지만, 이전 r151에서 온 현재 검사에는 음수 일괄 거절이 남아 있었다.

이미 관측 GUARD에 적용한 `forward_planning_speed`를 옆차가 사라진 GUARD에도 적용한다. 원 부호 있는 운동 이력·좌표 이송·실측 기록은 그대로 두고 예측 크기만 기존 정책에 맞춘다. `legacy_hold`는 여전히 음수에서 0이며 실제/목표0.35m/s 상한·현재 점유/앵커/전체 이동 영역·독립 보호를 유지한다. 새 역주행 명령·타이어 슬립 추정·실차 안전 판정이 아니다.

원 r176 동등 이관/원 r177 기록은 당시 소스 결과로 보존하며, 이번 변경 전 공통 모듈 전체를 `before_sources.zip`에 보관했다. Jetson·차량·새 Gazebo 시험은 없다.

## 결과

네 기록2,414개 반환 대조에서 의도한 음수 GUARD7개만 달라졌다. 5개는 현재 전체 검사를 통과해 진행했고2개는 기존 이동 영역 거절로 계속0이었다. 나머지는 동일하며 r174 실제193개 현재 결과도 동일하다. [대조](comparison.json). 원 입력은 불변이다.

저속 후보/부호/공통 재계산/실제 노드 관련69검사, 후속 소스 계보179검사가 통과했다. r178 새 명령142개는 같은 시각/+20ms 현재 검사 통과, +40ms 운동 입력 만료 거절이다. 첫 시험은 이름이 다른 테스트 경로를 지정해 수집하지 못했고, 다음 Windows 실행은 ROS 메시지 패키지가 없어 수집 실패했다. WSL ROS 환경에서 수행한 위 검사를 성공 근거로 한다. 해당 로그는 보존했다.
