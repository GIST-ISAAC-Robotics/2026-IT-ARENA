# 선언된 장착 가림과 인접 무반환의 국소 위험 비교

2026-11-12 설계·저장 비교 완료, 실제 주행/기본 연결 전. r148의 초반 정체는 낮은 목표에서도 좁은 무반환 한쪽이 장착 마스크와 맞닿아 남았다. 서로 같은 영역이 아니므로 마스크에 포함됐다고 처리하지 않는다.

별도 후보는 실제속도/목표 모두0.15 m/s 이하·차체 옆면 밖10 mm 이내·현재 옆차 없음·새 전방 경로 승인 조건에서만 검토한다. 하나의 **명시된 장착 마스크**와 인접 +inf 구간을 합친 연속 성분의 바깥 양쪽에 실제 먼 반환이 있는지 확인한다. 알려진 구조 각도·raw 값·원시 시각은 변경하지 않는다. 넓은 후방 사각, 여러 마스크 사이 틈, NaN/너무 가까운 무효 거리, 가까운 실제 점유, 전방 구간은 제외한다.

무반환 자체의 각도 합6°·국소 합성 숨은 폭5 cm라는 기존 작은 위험 상계를 그대로 사용하되, 마스크 한쪽을 원래와 같은 유효 반환으로 간주하지 않는다. 따라서 이것은 기존 검사의 동등 최적화가 아니라 **별도 위험 분류 후보**다. 숨은 작은 물체·움직이는 물체 위험은 남고 `unknown_filled=false`를 유지한다. 기본/운영 채택 전 저장 비교·반례·필요한 제한 주행을 구분한다.

## 저장 입력 결과와 한계

- 기존 r143의 원래 궤적 465판단을 재생했다. baseline 전체 출력은 모두 일치했다. 후보에서는 정지→진행 196개, 진행→정지와 진행→다른 진행 명령은 각각0개다. 216호출에서 낮은 목표를 다시 검사했고 196개가 허용됐다. [기계 결과](comparison.json).
- 최초 변경은 seq605·36.02초의 목표0.15 m/s다. 앞선 r148만의 최초 변경 seq683·51.02초보다 앞서지만, **이후 센서 입력은 원래 정지 궤적에 고정**되어 있으므로 196개를 실제 연속 주행 시간이나 완주로 환산하지 않는다.
- 직접 후보 반례17개와 관련 검사59개를 합해76개가 Windows와 WSL에서 통과했다. 실제 저장 기하·속도 초과·NaN/음의 무한대/너무 가까운 무효값·마스크 불일치·가까운 바깥 반환·넓은 공백·큰 불확실성 범위를 포함한다.
- 최초 구현은 한 질의가 mask/unknown 경계를 걸치는 경우까지 즉시 거절했다. 이 실패와 소스는 `candidate_initial.py`, 로컬 `build/r149_windows_tests.log`에 보존했다. 한쪽 unknown을 기준으로 **전체 연결 성분과 실제 바깥 반환**을 끝까지 검사하도록 수정했으며 판정 상한은 변경하지 않았다.
- 생산 코드와 운영 기본값은 바꾸지 않았다. [r150](../adjacent_cost_r150_v1/)에서 Jetson CPU 비용을 먼저 비교한다. 현재 결과 적용부의 r142는 새 위험 분류를 재검사하지 않으므로, 실제 주행 전 현재 관측으로 같은 조건을 재검사하는 연결이 필요하다. 기존 허가를 단순 재사용하지 않는다.
