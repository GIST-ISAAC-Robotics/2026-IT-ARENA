# 11/12 소스 이력 연결 정정

기존 r130/r134/r138/r147 실행 등록은 당시 원문으로 보존한다. 누적 실행 등록은 선형 변경 이력이 아니므로 과거 부모 해시를 고쳐 쓰지 않는다. 네 제어/기록 소스와 r123 평가 스크립트의 실제 이전 바이트만 보존 ZIP에서 추출해 새 연결을 구성했다. `snapshot_sources.json`의 각 출처와 바이트를 대조한다. 주행 알고리즘이나 과거 실패 판정을 변경하는 작업이 아니다.

## 검증 결과

- 변경·관련54개 시험 파일의 넓힌 실행:1,128통과·출처 이력2실패. 최초939통과/5실패도 별도 로그로 보존했다.
- 두 실패를 만드는 r123 평가 스크립트 이력까지 보완한 뒤 관련231검사 모두 통과했다. 실행 알고리즘은 이 정정으로 바뀌지 않았다.
- 게시 전 관련 문서363개 로컬 링크 누락0, 소스/증거2,605개 작업파일·Git index 바이트 불일치0, 비밀값 점검 검출0. Git 제외인 원시 센서 기록은 공개하지 않는다.
- r156 후보의 전체 저장 비교는 정지→진행0·진행→정지1로 미채택이며 실행 원본을 복원했다. 이 검사 통과를 지연 교통 완주나 실차 안전으로 확대하지 않는다.
