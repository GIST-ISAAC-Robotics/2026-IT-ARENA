# 장착 구조 인접 공백을 일치시킨 제한 지연 교통

실행 전 등록: r200과 같은60초·공식 파생 시설 코스·두 상대0.8m/s·마커20/30 누락·native C1·같은 지연 표본과 속도/간격/물성/독립 보호/노면/STOP 기준으로1회 비교한다. 모터축28카운트·11.911764706:1·65mm 구성이다. PC/WSL 전용이며 실물 센서/모터 조작은 없다.

차이는 r202의 기본 OFF 통과 후보가 기존 GUARD와 같은 장착 구조 인접 검사도 사용하는 것이다. 기존 허용 폭·각도·외측 반환·실제/목표0.15m/s 조건을 그대로 유지한다. `g1_released_body_gap_trial=true`, `g1_guard_observation_policy=selected_r181`, 현재 재검사·새 회전 제출을 명시한다. 평가용 지연/만료 참조 prefix는 r200과 같다.

r200의24.00m/11.417초 미완주·원 실패·입력/소스를 보존한다. 저장106정지 개선만으로 이번 성공을 가정하지 않는다. 한 번의 새 궤적을 확인한 뒤 결과와 남은 원인을 분리하며 같은 실패를 근거 없이 반복하지 않는다.34m 이전에 멈추면 r182 갈림길 이탈 보완의 효과도 여전히 미검증이다.

## 결과

원 판정과 종합 판정은 **실패**다. 진행30.68m·최장 저속10.484초로 r200의24.00m·11.417초보다 더 진행했지만, 전체 랩·지속 주행·최종 간격 조건을 통과하지 못했다. 두 번의 폐루프 궤적은 다르므로 차이 전체를 결정론적 개선율로 설명하지 않는다. 접촉/차체 겹침/바퀴 노면 이탈은0이고, STOP 변위0.087783m·안정 도달·정상 종료·잔여 프로세스0을 확인했다. 원시 입력/소스/스냅샷 검사도 통과했다.

경기 구간456판단에서 새 통과 상태 공백 후보가12회 적용됐다. 현재 재검사388개 중371개가 양수였고, 남은17개는 새 측방 관측·현재 공백·경로 이동량 등의 이유로 거절됐다. 이는 계획 명령/현재 검사 수이며 실차 제어율은 아니다.

남은 주요 정체는 시뮬38.62–48.92초의 `guard_curve_rejected_toward_left` 52판단이다. 첫 표본은 이동 영역의 일반 unobserved가0이지만, 양쪽 측방 상태가 present이고 곡선에서 기존 측방 기준보다 가까워지는 부분의 현재 관측이 부족해 거절됐다. **앞선 무반환 공백과 같은 이유라고 단정하지 않는다.** 현재 진단만으로 반환 물체가 차량인지 벽/시설인지도 확정하지 않았다. 저장 입력의 측방 증거와 관측 범위를 분리할 후속으로 남긴다.
