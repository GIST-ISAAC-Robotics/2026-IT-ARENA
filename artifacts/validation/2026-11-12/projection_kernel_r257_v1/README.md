# r257 원천 측정 투영 수치 후보

r255에서 현재 재검사의 큰 비용이 원천 광선 좌표 생성임을 확인했다. 반복 Python scalar 루프를 같은 연산 순서의 C++ 함수로 묶는다. 공개 입력 검증·마스크/unknown·취득 순서/시각·운동 세대와 광선 객체 생성은 유지한다. `-ffp-contract=off -fno-fast-math`로 빌드하며 공통 소스에는 아직 연결하지 않았다.

PC와 Jetson에서 각각424/508/524/8192점·CW/CCW·마스크 경계·unknown·잘못된 기하·비연속 입력 배열 등35검사를 통과했다. 전체 장면을 기존 공개 생성자와 대조했다. 같은 Jetson의632계획/592현재 입력은 r248 native와 원/후 대조 모두 전체 출력 차이0·소스/입력 불변이다.

| 항목 | 원 계산 | C++ 투영 후보 |
|---|---:|---:|
| 계획 중앙/p95 |98.419/146.112ms|95.891/145.121ms|
| 현재 확인 중앙/p95 |13.357/24.843ms|11.065/22.852ms|
| 현재 확인 최대 |124.175ms|122.581ms|

별도 순차 재생으로 ROS/IPC/부모 콜백이 없는 비교다. 각1회이며 실행 순서/장치 상태의 분산도 포함한다. 계획 p95 개선은약1ms, 현재 확인은약2ms에 그쳐 명령 갱신 문제를 해결할 정도가 아니다. **공통 코드에는 채택하지 않고 여기서 비용 비교를 마친다.** 새 수치 커널을 계속 추가하기보다 실행 구조와 실물 연결의 미완료를 다룬다. 반환 시각/TTL·출력 조건을 바꾸지 않았다.

실행 결과는 `jetson/baseline/report.json`, `jetson/candidate/report.json`, 각 원 출력/비용에 보존했다. 원 출력과 상세 시각열은 Git 제외다. 완료 회수 묶음 SHA256은 `5dbc1e784624bb2bbf1d49d955fdc621926c546c188cd240b833b3e1f0b80535`이며, 모터/센서/ROS·전력 설정은 사용하거나 변경하지 않았다.
