# 새 CAD 장착·시설의 첫12 m 제한 주행 r292

**첫12.07 m·최고2.848 m/s, 등록 검사 통과.** r290의 차량 지주·전방4 mm 배선/C1 광축134.6 mm·카메라198.363 mm 프로필과 r291새 시설 mesh를 선택한 첫 단독 주행이다. 기본 프로필을 바꾸지 않았고 실제 장치는 사용하지 않았다.

범위는 첫12 m 또는45초 시뮬 제한이며 신호등 지주/초반 코너를 확인한다. ID20·30의 기하도 같은 실행 사본에 있으나 목표 구간은 그곳을 통과하지 않는다. 해당 마커 무늬는 가림 조건으로 두었다. 새 지지대와 기존 램프/마커의 정확한 조립 관계는 미확정이다. ID49 중심140 mm는 기존 시험값을 유지하여 새 C1을 가리는 상태다.

기존 단독 r77의 실행 인자를 출발점으로 **현재 공통 제어 코드**를 사용한다. r282의 별도 병렬/고정 Jetson 지연 후보는 연결하지 않았으므로 성능 차이의 인과 비교가 아니다. native10Hz·순차 취득/운동 보정·81T기어/단일28카운트·65mm바퀴·속도 프로필·독립 보호/STOP·물성은 유지했다.

시설은 실제 mesh로 물리/렌더링에 연결하고, 평가에서는 차체 높이32.5–92.5 mm의 재료 투영을 사용한다. 발판을 차체 전체 높이의 벽으로 취급하지 않으며 실제 시설 접촉 토픽을 별도로 회수한다. 시설 위치·정답은 제어기에 입력하지 않는다. 재현 명령/소스는 `registered.json`·`sources.zip`·`launch_extra.json`, 원 결과는 `run1/`, 접촉·소스 불변은 `fixture_execution.json`에 남긴다.

차체의 벽/시설 투영 겹침0표본, 신호 지지대 투영과 최소간격263.8 mm였다. STOP 후 변위217.2 mm·안정 정지·Gazebo서비스 종료·14자식 정상 종료·621입력 불변을 확인했다. native504/508/512점 취득과 독립 보호 연결도 통과했다. [원 판정](run1/report.json)·[독립 정리](assessment.json).

시설 물리 접촉 reader 세 개는 정상 종료했지만 모두 메시지0이었다. 실행 월드의 mesh/Contact plugin/센서 연결은 확인했으나 이 실행에서는 양성 접촉이나 heartbeat가 없으므로 **별도의 물리 무접촉 증거로 세지 않는다**. 위 겹침0은 평가 자세와 재료 투영의 결과다. r291격리 물리 검사의 양성/음성 대조는 따로 보존한다. ID20·ID30 최소거리3.01/6.88m로 아직 통과하지 않았으며, 후속[r294](../cad_facility_lap_r294_v1/README.md)의1랩 결과와 구분한다.
