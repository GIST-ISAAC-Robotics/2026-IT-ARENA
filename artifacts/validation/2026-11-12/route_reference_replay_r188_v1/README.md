# r187 경로 기억 후보 영향과 정체 구간 분리

11/12 PC 저장 재생이다. Jetson 접근이나 새 Gazebo 주행은 없다.

시험 당시 WSL 수치 환경에서 **473출력 전체를 동일 재현**했다. 같은 입력·reset 기록에서 경로 기억 후보를 제외한 대조와 비교하면 상세 출력163개, 실제 속도/조향7개가 달랐다. 새 정지0개, 기존 정지→양수5개였다. 이 대조는 고정 입력이므로 새 궤적이나 시간 단축 증명이 아니다.

가장 긴 저속 구간은 시뮬21.071–32.592초, 진행9.92m 부근이다. 표본 저속 길이11.521초는 등록된 고밀도 평가 값과 같았다. 이 구간의 계획107회는 RELEASED의 `large_motion_region_unobserved`로 멈췄다. 목표 갈림길은 이보다 뒤다. 비교 목록의0.217–8.101초 창은 출발 전 신호 대기를 포함하므로 경기 중 정체로 합산하지 않는다.

최초 Windows/NumPy 재생은 상세 결과113개가 달라 실패했다. 첫 차이는 같은 이동 영역의 표본 수1개(8,971 대8,972) 및 가림 표본1개(437 대438)였다. 전체 차이가 모두 이 원인이라는 주장은 하지 않는다. 원 `result.json`/`compare.log`/`first_difference.json`을 보존하고, 시험 환경의 `result_wsl.json`/`compare_wsl.log`에서 재현 성공을 확인했다. 원 실패를 덮어쓰지 않았다.

다음은 통과 확인 뒤 RELEASED의 같은 경로를 낮은 목표로 검사했을 때 현재 반환만으로 이동 영역이 확인되는지 비교하는 것이다. 관측되지 않은 영역을 자유로 바꾸거나 기존 간격·TTL·물성을 완화하지 않는다.
