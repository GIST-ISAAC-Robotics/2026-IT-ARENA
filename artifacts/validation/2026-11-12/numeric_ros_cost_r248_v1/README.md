# r248 공통 수치 커널·ROS 수신 부하 대조

공통 `TwoStageProcess`/완료 알림과 `numeric_execution=python|native_v1`을 실제 Jetson에서 각각 실행했다. 같은632저장 입력과592현재 재검사, localhost domain187의 합성200Hz IMU를 사용했다. 두 단계 계산을 비교하는 진단이며 실제 유효기간/명령 발행·센서 포트·모터·카메라·독립 보호는 포함하지 않는다.

## 결과

두 실행의 **전체 출력 차이0**, 명령 차이0, 입력/소스 불변, 자식/발행기 정상 종료다. 과거 PC 기록과의 전체54차이는 두 구현에 같았고 명령 차이는 없었다. 그 차이를 없애기 위해 원 기록을 수정하지 않았다.
