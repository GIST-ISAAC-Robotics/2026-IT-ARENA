# 통과 뒤 RELEASED 경로의 현재 재계산

2026-11-12. r165 양수447판단 중388개는 `RELEASED/baseline`이었으나 기존 현재 재계산 연결에서 빠졌다. 이 상태는 다른 차를 통과시킨 뒤 정상 본선 경로를 다시 쓰는 단계다. 이 누락과 입력 만료의 관련성을 저장 입력으로 대조했다.

기존 r152 계획기로 r165 저장467개 전체 출력이 동일했다(`replay.json`). 이번 작업은 계획기의 상태 전이나 경로 선택을 바꾸지 않는다. 원 양쪽 측방 상태가 확인된 통과/미관측전무 상태이고 현재도 전방 관측·새 측방 위협 없음·같은세대/조향/경로수명이 성립할 때만 현재 좌표에서 경로 추종과 점유/제동을 다시 계산한다. 원경로시각과 목표상한을 유지하며 TTL을 연장하거나 과거명령의 시각만 바꾸지 않는다.
