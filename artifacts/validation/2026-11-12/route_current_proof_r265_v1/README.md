# r265 최신 관측으로 경로 기하를 다시 검증하는 후보

r261에서 겹침만으로는 고정147/34ms 구간의5Hz·명령 공백이 남았다. 이전 계획을 그대로 반복 적용하는 대신, 계획과 현재 확인의 주기를 분리할 수 있는지 비교했다.

기존300ms 원 경로 수명 검사를 그대로 유지한 후보는 아니다. **원 경로를 장애물 허가가 아닌 선호 기하로 사용할 때만 최대100ms를 추가**하고, 현재 반응/제동 영역을 현재 관측만으로 다시 검사하는 별도 정책이다. 현재 raw 센서/명령 만료·epoch·실제 운동·0.45m 이관 한계·측방/간격/물성은 유지한다. `path_source_s`를 바꾸지 않으며 `current_route_proof`에 원 경로 나이, 새 근거 시각과 수락 여부를 따로 남긴다. 미관측을 자유로 채우지 않고 기존 작은 가림 꼬리 기준을 사용한다. 공통 코드/ROS/구동에 미연결이다.

r243/r253에서 원 계획보다 최소200ms 뒤의 실제 저장 입력을 골랐다. r243은 비교794개 중708개, r253은301개 중289개에 양수 후보가 나왔다. 나머지는 새 측방 물체·미관측·이관 운동/측방 운동 한계·점유 등으로 거절됐다. 원 기록의 궤적/센서 이력을 재사용한 민감도이며 이 후보로 그만큼 실제 달린다는 뜻이 아니다. 새 스케줄의 정확한247ms 시점 입력을 만들어낸 것도 아니다.

관련14검사를 통과했다. 기존 비만료 여섯 상태의 전체 출력 동일, 원 시각/입력 불변, 현재 전방 점유·unknown·새 epoch/side·400ms 경로 거절과 새0계획 미부활을 확인했다. 현재 입력의 유효성·독립 보호를 검사하지 않고 재발행할 수 있는 정책이 아니다.

다음 연결에서는 새 계획이 있으면 우선하고, 이전에 실제 발행한 경로만 보조로 재검증한다. 보조 재검증의 불성립은 새 양수 허가가 없다는 뜻이며 그 자체로 새 STOP 명령을 추가하지 않는다. 기존 명령/독립 보호의 만료·직접 점유·명시 STOP은 유지한다. 원 계획의 새0명령이나 상태 전환 뒤 이전 양수 경로를 되살리지 않도록 해야 한다. 다음 단계는 이 실행 순서와 로그를 연결한 제한 시험이며 기본 활성화는 아니다.
