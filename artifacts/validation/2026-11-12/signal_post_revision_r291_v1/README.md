# 제작측 새 신호등 STL 수신·초기 대조 r291

[공식 이슈 #3의 제작측 11/12 댓글](https://github.com/MOSW626/istech-it-arena/issues/3#issuecomment-6824443207)에서 새 ZIP을 받았다. 제작측은 **신호등 코드는 기존 코드 유지**라고 안내했다. 저장소 main은 당시 `2e41f5674a4c8a611bb65e966ea8827d41611017`이고 첨부 자료는 이슈 댓글에 있다. 댓글·commit·ZIP·STL을 원문 그대로 보존했다.

- ZIP 74,341 B, SHA-256 `91aab6ce84188b2af2dd20e5be85f9d0257ba4b4835be7892eecbeaa2a2384ec`.
- STL 374,884 B/7,496삼각형, SHA-256 `04f43b4499cd32b2bbb27b74eb14735df6ff9c069676157a58f33543d7b1856f`.
- 단위 mm·세로 raw Y는 이전 제작측 STL/치수와 동일하다는 해석이다. 설치 위치·도로에 대한 실제 중심/발판 고정까지 확인된 것은 아니다.
- 전체 외곽은 **약1006.36×542×420 mm(폭×높이×앞뒤)**로, 이전625×465×57.32 mm와 다르다. 앞뒤 대각 버팀대·상부 대각 보강·낮은 넓은 받침이 보인다. [정면/측면 대조](comparison.png)와 [전체 수치](geometry.json)를 참조한다.
- 134.6 mm 높이의 한쪽 지주/버팀대 점들 전체 외접 범위는 약24.32×303.48 mm다. **이 직사각형 전체가 막힌 재료가 아니다.** 분리된 버팀대 사이 빈틈을 충돌 상자로 채우거나 단순 수직15 mm 기둥으로 유지하지 않는다.
- 사용자는 **마커 시설도 신호등과 같은 기둥 배치/형상**으로 가정해 시험하도록 했다. 마커 지주의 동일 STL·정확한 설치 위치가 주최측에서 확정됐다는 뜻은 아니다. 차량 자체 CAD 지주와도 별개다.

## 선택형 시설과 물리 확인

`prepare_fixture.py`는 새 STL에서 기존과 동일한 광원 모듈7,033면을 제외하고 지지 구조463면을 미터 단위 mesh로 보존했다. 광원 모듈의 원 좌표/크기는 이전 STL과 같지만 새 발판 최저점이9 mm 달라, 바닥 기준 높이는9 mm 낮아진다. 현재 점등 패널/신호 코드/마커 위치를 이 수치만으로 옮기지는 않았다.

`supports_trial.sdf`는 신호등과 ID20/30의 세 지지 구조를 담은 **시험용 추가 모델**이다. 기본 월드나 공식 원본은 바꾸지 않았다. 신호등(9.8,6.145), ID30(2.48,3.505), ID20의 이전 임시 중심(6.5275,6.0)을 사용했다. 특히 ID20은 마커 판(6.155,6.0)과 중심이 다르고, 실제 고정 위치가 확인된 배치가 아니다.

| 확인 | 결과·범위 |
|---|---|
| 정적 설치 단면 | 신호등/ID30은 바닥 발판과50/75/134.6/198.363 mm 단면에서 도로 침범0·벽 겹침0 |
| ID20 기존 임시 위치 | 발판의 도로 겹침 약189.4 cm²,134.6 mm 단면 약4.86 cm². 새 버팀대를 옛 임시 좌표에 두었을 때의 결과이며 공식 설치 결함이 아님 |
| 상부350 mm | 세 위치 모두 기울어진 지주의 일부가 도로 위로 약11.83 cm² 들어옴. 현 차량 높이보다 높지만 도로 전체 높이가 비었다는 뜻은 아님 |
| 실제 mesh 물리 충돌 | 문 중앙20×15×6 cm 상자: 접촉0. 버팀대 사이6 mm 상자: 접촉0. 실제 지주와 겹친30 mm 상자: 접촉3,002표본. 삼각형 구조의 빈틈이 충돌 엔진에서 통째로 막히지는 않음 |
| 종료 | 격리 Gazebo 서버 정상 종료(returncode0), 강제 종료 없음 |

[배치 단면](placement_sections.png), [수치·변환·해시](fixture.json), [격리 물리 검사](mesh_collision/report.json)를 참조한다. 물리 검사는 구조의 통과 공간/재료 구분이며 차량 주행 증명이 아니다. ID20 위치는 확인 전까지 시험 가정으로 남긴다. 임의 이동으로 도로 침범 수치를0으로 만들지 않는다.
