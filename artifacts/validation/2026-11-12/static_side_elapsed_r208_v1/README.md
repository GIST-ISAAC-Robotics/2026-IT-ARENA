# 정지 물체 추정의 실제 경과 시각 후보

r207에서 r203의52개 곡선 정지 판단을 재현했다. 위협 반환378점은 ID20 지지 기둥 두 개와0.811mm 이내에서 일치하고, 각본 차량과는2.136m 이상 떨어졌다. 이동 영역 일반 unknown은 없지만 추가 접근의 장착 마스크 때문에 거절된 대표다.

기존 정지 물체 추정은 `speed × dt`로 자차 이동을 누적한다. 여기의 dt는 명령/조향 예측용0.1초이며 비동기 계산 사이 실제 시각과 다를 수 있다. 동일 시각의 반복에도 적분할 수 있다. 이번 저장 후보는 판단 기준 시각 차이와 양 끝 측정 속도로만 사다리꼴 적분하고, 중복 시각은 누적하지 않으며 역행/기존0.25초 공백/음수 속도에서는 정지 물체 근거를 새로 모은다. 제어 명령의 dt·속도·간격·관측·STOP 기준은 바꾸지 않는다.

원469판단을 먼저 재현하고 같은 입력의 양수/정지·상태·정지물체 근거를 대조한다. 실제 운동 이력의 전체 적분이나 물체 신원 증명으로 설명하지 않는다. 이 문단은 실행 전 후보 범위이며, 후속 공통 연결은 r209로 별도 보존했다.


## 저장 대조 결과

원 r203의469판단을 그대로 재현한 뒤 후보에서 정지→진행56개·새 정지0개, 주요52정지 중50개 진행을 확인했다. r206의154판단도 원 재현 후 정지→진행1개·새 정지0개다. 고정 물체/저속 이동 물체·시각·중복·역회전 반례12검사가 통과했다. 실제 주행 향상으로 확대하지 않는다.

후속 [r209](../static_side_elapsed_connected_r209_v1/README.md)는 공통 연결과 후보 명령 일치623개를 확인한다. 이 폴더의 비교 스크립트는 당시 r202 공통 소스를 기준으로 했으며 최신 r209 소스에서 기존 baseline 비교를 그대로 재실행하면 안 된다. 당시 소스는 r209 `before_sources.zip`에 보존했다.
