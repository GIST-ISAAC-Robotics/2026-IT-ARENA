# 깊이 계산512행 연결과 전체 비용 대조

r196의 함수 대조에 따라 `observation_support.depth_support`의128행 묶음을512행으로 바꿨다. 광선·점 개수·깊이/각도/인접/원점 경계·가림 조건은 그대로다. 원 소스는 `before_sources.zip`으로 보존하고 `config/tests/depth_batch_r197_sha256.json`에 등록했다.

- 원점·미세 각도·CW/CCW native·가림·질의 경계 관련242검사 통과.
- PC r182439판단 전체 일치. r187 기본473개·선택473개 전체 출력 SHA256도 r190과 동일하다.
- Jetson r194 기기별 기준439판단 전체 일치. 입력/107개 필수 소스 불변이다. 원 PC 기준의82개 수치 표본 차이는 r194에 보존하며 이 결과가 이를 없앤 것은 아니다.
- 최신 변경 계약과 전체 등록 소스 연결 검사 통과.

| 같은 입력의 전체 계산 | 기존 중앙/p95(ms) |512행 중앙/p95(ms)|
|---|---:|---:|
|PC WSL|32.417 / 51.053|31.402 / 51.515|
|Jetson|136.598 / 222.395|132.747 / 217.931|

Jetson 중앙 약2.8%·p95 약2.0% 개선이다. PC 중앙도 줄었지만 p95는 소폭 증가했다. 독립 반복 분산이나 최악 시간 보증은 아니며,10Hz 입력/20ms 제어 마감은 여전히 충족하지 못했다. 같은 내용을 더 잘게 반복 최적화하기보다 이 변경을 유지하고 실제 정체 원인 분석으로 이어간다. 새 Gazebo·ROS 구동·센서 포트·GPU·전원 변경은 없었다.

`tests.log`, `r197_original_r187.json`, `r197_selected_r187.json`, `pc/report.json`, `jetson_result/jetson/report.json`, `provenance.log`와 묶음/원격 로그가 근거다. 비용은 이력 복원·운동 투영·계획기만이며 현재 재검사·독립 보호·ROS/영상·구동기와 실제 센서 시각은 별도다.
