# GUARD의 현재 경로 재검사 저장 후보

2026-11-12. 원 양수 GUARD 기본 경로·통과/미통과 기억·원 경로 수명을 그대로 두고 현재 IMU/엔코더·스캔으로 경로 좌표, 점유/제동, 측방 접근과 이동 영역을 다시 검사했다. 새로운 측방 반환은 진행 대상으로 받아들이지 않는다. 기존에 허용된 좁은 공백도 현재 입력으로 다시 검사하고 미관측 수를 지우지 않는다. 독립 보호층은 계속 필요하다.

r139의 양수 GUARD 37건을 바로 다음 저장 입력에서 비교했으며 7건은 양수를 유지했다. 25건은 원 경로 수명 만료, 2건은 직전 조향 불일치, 3건은 현재 옆차가 이미 있는 원 판단으로 대상 밖이었다. 실제 도착 순간보다 늦은 다음 제출 입력이므로 이 개수를 실제 재검사 성공률로 해석하지 않는다. 저장 입력의 양수 7건은 현재/이전 조향·실제 속도·원 경로 300 ms·마스크 이동 1 cm 조건을 유지했다. WSL 비용 중앙 1.55 ms는 빨리 거절된 건들을 포함하며, p95 17.52 ms·최대 19.35 ms다. Jetson 전체 처리율 증명이 아니다.

15검사를 통과했다. 새 전방 근접 물체·새 측방 위협·넓은 후측방 무반환·NaN·경로 만료·음수/높은 실측속도·세대/직전 조향 변화·누적 측방 접근을 포함한다. 최초 검사에서 비유한 값 표식을 문자열로 쓴 2개 fixture 오류와 실제로 추가 접근이 없는 곡선 frame에 접근 거절을 기대한 1개 fixture 오류가 있었다. 원 `build/r142_tests_initial.log`를 보존하고 입력 형식과 기하 반례를 수정했다. 그 실패를 코드의 거절 조건을 낮춰 해결하지 않았다.

아직 발행·새 주행·기본 활성화는 아니다. 운영 제한 후보는 r143에서 원 판단에 이미 옆차가 있는 경우 기존 출력 경로를 유지하도록 범위를 한정한다. GUARD 상태를 SOLO로 전환하지 않는다. 내부 순수 기하 helper의 진입 분류를 바꿔 계산하더라도 결과를 바로 반환하지 않고 전체 GUARD 재검사를 추가한다.
