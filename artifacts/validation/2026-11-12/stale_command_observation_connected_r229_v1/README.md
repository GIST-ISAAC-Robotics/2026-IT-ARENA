# 만료 명령과 유효 관측 갱신 분리 r229

[r228 합성 비교](../stale_command_observation_r228_v1/README.md)의 후보를 독립 `LidarSafety.control()`에 연결한다. 명령이0.2초보다 오래됐거나 명령 수신이 만료돼도, 센서/운동이 유효하고 마지막 명령이 유한한 전진 명령이면 관측 기억 평가를 계속한다. **그 호출의 출력은 항상0**이며 새 유효 명령이 도착한 뒤에만 기존 관측/충돌 검사로 진행할 수 있다.

센서/운동 만료·음수/비유한/미래 명령·없는 명령은 그대로 차단한다. 실제 센서 공백에서의0.3초 관측 기억 만료와 이미 보인 근거리 점의 소실 래치는 그대로다. 보호 상태에 기준 시각과 명령 만료 여부를 넣어 다음 주행에서 이를 구분한다. 새 위험을 허용하거나 만료 명령을 재발행하는 변경이 아니다.

[변경 전 소스](before_sources.zip)·[기준 해시](before_manifest.json)·[출처 계약](../../../../config/tests/stale_command_observation_r229_sha256.json). 관련 노드/보호·공백·출처 회귀와 빌드 후 [r230 제한 주행](../stale_command_observation_runtime_r230_v1/README.md)을 수행한다. r228은 원 소스에 대한 사본 비교이며 이 보존본을 원 함수 근거로 사용한다.

관련357개 검사와2패키지 빌드를 통과했다([검사](tests.log)·[빌드](build.log)). 새 검사는 명령 시각/전송 만료 중0출력과 새 명령 복귀, 실제 센서 공백·소실 장애물의 정지 유지, 유효하지 않은 입력의 기억 미갱신을 포함한다. 실제 주행의 정체 개선은 r230 결과로 별도 판단한다.
