# r255 현재 재검사와 잔여 계획 비용

r253의 명령 만료를 다루기 위해, r248과 같은 Jetson 소스·native 수치 옵션·632계획/592현재 입력에서 함수별 잔여 비용을 확인했다. r244에서 정한67계획 표본과 그에 해당하는64현재 재검사만 cProfile로 계측했다. 실제 센서/ROS/출력은 사용하지 않았다.

계측 표본의 계획 누적12.469초 중 현재/부분 관측 계산4.726초, 선택기3.981초였고, 현재 재검사2.557초 중 장면 구성1.026초·입력 복원0.442초였다. 장면 내부 `_geometry`가0.727초를 차지했다. 상하 함수의 누적시간은 겹치므로 서로 더하지 않으며 cProfile 오버헤드/비싼 표본 선택을 포함한다. 이 값으로 새 주행 Hz를 주장하지 않는다.

`result/report.json`의 `command_differences` 필드는 이름과 달리 계획의 `comparable_decision` 진단까지 비교했다. 계획45개 차이와 현재 전체진단9개 차이를 보존하며, 이번 파일만으로 계획 속도/조향이 달라졌다고 해석하지 않는다. 현재 재검사의 속도/조향 차이는0이다. 후속 후보는 같은 Jetson의 전체 출력을 별도 기준선과 대조한다. 소스와 입력 해시는 전후 일치했다.

첫 실행은 `profile.py`가 Python 표준 모듈을 가려 import에서 실패했다(`attempt1.log`). `profile_cost.py`로 이름만 바꾼 다음 전체 실행은78.97초에 완료했다. 실행 중 먼저 만든 `r255_result.zip`은 미완성 회수본이라 사용하지 않았다. 완료를 확인한 별도 묶음 SHA256은 `06bf2ad23dd5261177be39634efe9188442fdf9e022066cda02fff31854a6834`다.

후속은 원천 측정 투영의 반복 scalar 계산만 동일 연산으로 묶는 제한 후보다. 기본 수치 정책이나 판단/수명 조건을 바꾸지 않는다. 주기 분리의 한계는 [r256](../recheck_cadence_r256_v1/README.md)에 따로 둔다.
