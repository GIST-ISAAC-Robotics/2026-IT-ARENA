# 선택 구성의 Jetson 함수 비용 분해

r194의 같은439입력·상태 순서를 재생하면서 호출 인덱스20개마다 처음2개, 총44판단만 cProfile로 계측했다. 전체439반환은 Jetson 기준과 일치했고 입력은 불변이다. 이 비용은 함수 계측 오버헤드를 포함하므로 r194의136.6ms에 직접 더하거나 빼지 않는다.

44판단의 전체 계측8.377초 중 제어 판단7.371초, 선택기4.244초, 이동 영역 검사2.711초, 깊이 관측 지지1.954초였다. 이들은 포함 관계여서 합산하면 안 된다. 깊이 관측 지지는168호출 안에서128행씩 나누어1,980회 계산했고, 해당 내부 계산 자체 시간이0.931초로 가장 컸다. 원천 기하의 반복 생성/배열 변환과 경로 계산에도 비용이 남는다.

다음 후보는 **동일한 광선/표본/판정식을 유지하면서 행 묶음 크기만 바꾸는 것**이다. 실제 입력에서 출력 일치와 함수 비용을 먼저 비교한다. 표본 생략·각도/관측 범위 축소·판정선 완화·GPU/전원 변경은 하지 않는다. 모든 병목을 한 번에 손대거나 이전 무주입 주행의 속도 수치와 섞지 않는다.

근거는 `profile_hotspots.py`, `report.json`, `remote_session.log`다. 새 주행이나 실물 센서 시험은 아니다.
