# 동일 무반환 연산의 공통 코드 반영

2026-11-12. [r145](../nonreturn_cost_r145_v1/README.md)의 32질의 묶음 연산을 `rear_fringe_trial.py`에 반영했다. 정지/허가 규칙·질의점·광선·동률 선택·첫 거절 순서·명령/경로 시각은 바꾸지 않았다. 선택형 주행 후보를 기본 활성화한 변경도 아니다.

- 실제 Jetson에서 동일 입력/출력과 62.57→56.14 ms 개선을 먼저 확인했고, 공통 반영 후 관련 **59검사**를 통과했다.
- 방금 끝난 r143의 **원 판단465개·현재 재검사40개 전체 동일**을 재확인했다. 원 주행의 9.97 m 정체·접촉 실패를 유지하며 새 주행은 실행하지 않았다.
- 이전 소스는 r145의 `rear_fringe.before.py`, 이번 변경의 해시는 [source_change.json](source_change.json)에 남겼다. 후속 실행 등록은 [새 계약](../../../../config/tests/nonreturn_batch_r147_sha256.json)을 사용한다. 원 실행 계약은 덮어쓰지 않았다.

약 10%의 제한 개선이며 50 Hz 처리·주행 실패 해결로 보지 않는다. [반영 후 재생](applied_replay.json)의 `computation_wall_ms`는 원 주행에서 기록한 비용이며 이번 반영 후의 새 성능 계측값이 아니다.
