# 저속 GUARD의 현재 검사 우선 비교

2026-11-12 계획/구현 단계. r149의 속도별 탐색 반복이 Jetson에서 중앙186.79 ms를 요구한다. 새로운 위험 수용이나 관측 보간 대신 후보 평가 순서를 비교한다. 직전 같은 세대의 r149가0.15 m/s GUARD를 허가했을 때 현재 G1 경로·전방 관측·측방 상태가 적합하면 동일0.15 m/s를 먼저 전체 재검사한다. 상향 탐색은 최대0.3초 뒤 수행한다. 기존0.35 m/s 상한 대비 최대0.06 m의 진행 이득을 탐색 구간 동안 포기할 수 있으므로 명령/연산/주행을 따로 평가한다.

현재 관측 전체 검사와 원천/명령 수명·독립 보호는 유지한다. 실제속도가0.15 m/s를 초과하거나 새 측방 위협·불완전 전방·기억 경로·시간/세대 변경이면 원 탐색을 사용한다. 현재 저속 검사 실패 시 그 결과를 허가로 재사용하지 않는다. 기본 운영 연결은 하지 않는다.
