# 짧은 운동 대기와 상대 양보 감속 연결

기존 노면 run1에서18.86초 역회전 대기 시 우회 경로는 보존되나 감속 상태가 지워지고19.52초 재개 때0.35 m/s로 돌아간 문제를 다룬다. 새 선택값 `bounded_relative_yield_v2`만 짧은 유효 운동 대기에서 감속 의도를최대1초 보존한다. 기존 전체5초 감속 예산은 연장하지 않는다. v1과 기본OFF는 유지한다.

역회전/재확인 대기의0명령은 그대로이며, 센서 세대/시각의 연속성·원래 보관 경로·유효 운동 대기 이유를 검사한다. 정상 재개 첫 호출은 현재 센서로 원래 후보/독립 보호 검사를 다시 통과해야 한다. 현재 상대 면/벽/너비/변위가 달라지면 감속 관측 연속성을 이어붙이지 않는다. 오래된 점유/자유 공간이나 진행 허가를 재사용하지 않는다.

아직 검증 중이다. 기존 실패 소스는 `g2_relative_yield_surface_v1/run1_sources.zip`과r2 소스 계약으로 보존한다. 이 연결을 고친 뒤 대표 주행/영상으로 종료하며 희귀 조건의 전수 검증으로 확대하지 않는다.


## 연결 검사와 저장 입력 대조

`tests1.log`:385검사 통과. `saved1/summary.json`: 기존v1의 평탄화2,305/기존노면2,565판단 모두 원본과 일치, 소스/입력 불변. v2의 평탄화 명령은 변화0건이고, 기존노면에서는 재개19.52–22.80초165명령이0.35→0.20 m/s로 바뀌었다. 첫 재개 호출에서 현재 면을 재확인했으며 두 기록 모두 음수 측정 중 양의 명령0건이었다. 원래5초 예산은 연장되지 않았다.

같은 센서 기록의 판단 대조이므로 새로운 궤적/물리 복귀를 증명하지 않는다. [v2 기존노면45초](../g2_relative_yield_pause_gazebo_v1/PLAN.md)에서 빌드 뒤 첫 실제 실행을 확인한다.
