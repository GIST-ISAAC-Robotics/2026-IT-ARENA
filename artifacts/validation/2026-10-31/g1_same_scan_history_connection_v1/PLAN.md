# 같은 스캔 대기의 이력 처리 수정 연결

저장 입력 후보의 19반례 검사·실패 입력3328호출 prefix·정상 입력7815호출 대조 이후, 운영 `SuspendedPassageSelector`의 같은 두 조건만 수정한다. 이미 선택형인 `traffic_path_recovery_trial` 내부 수정이며 기본 활성화·판정선·속도·물성 변경은 없다. 대기 중0출력과 새 스캔·현재 이동영역/장애물·고장 검사는 그대로다.

변경 전 소스와 SHA 체인을 보존한다. 후보와 두 조건이 같은지 직접 검토하고 실제 클래스를 쓰는 신규8반례와 기존 선택기/복구/G2/기록·출처 검사를 수행한다. 단일 파일의 동일 구현을 다시 별도 전체 저장 비교로 반복하지 않고, 통과 후 빌드·설치80파일 일치를 확인한 뒤 같은155초 실제 코스 시험으로 연결한다. 과거 실패 입력/소스를 최신 성공으로 소급하지 않는다.
