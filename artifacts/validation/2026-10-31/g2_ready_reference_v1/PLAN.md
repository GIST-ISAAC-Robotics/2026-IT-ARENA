# 초기 벽 기준 보완의 준비 상태 한정

10/31 재개. 이전 현재 반환 후보는 정지차 기록에서 우회 진입 판단을 만들었지만 정상1랩에561추가 감속/350추가0명령을 만들었다.504건은 기존 준비 판단에 이동 근거가 있는 동안 발생했다.

10/30의 거리 보존 전체 생략은 이동후정지 조건에서 진입 공간을 잃어 미채택이었다. 새 후보는 이를 반복하지 않는다. 기존 양벽 기준과 거리 보존은 그대로 유지하며, 원래 기준이 실패했을 때 추가하는 현재 반환 보완만 `observed && ready && !motion_evidence`인 호출에 한정한다. 낮은 이동은 물체 정지/신원 증명이 아니며 현재 연결 반환·원래 관측 범위와 모든 점유 검사도 계속 필요하다. 원래 기준이 성립하는 상황에는 후보를 적용하지 않는다.

## 비교와 수용 조건

1. 준비 미완료·이동 근거·현재 반환 없음에서는 원래 기준을 사용한다. 새 스캔 재사용·시간/출처 초기화·실패 시 별칭 복구는 기존 후보의 규칙을 유지한다.
2. 준비 유지40초 실패 입력2,041호출에서 이전 후보의 우회 진입이 유지되는지 확인한다.
3. 정상1랩7,815호출에서 기존 출력·내부 G1 상세를 대조한다. 추가 감속 감소가 실제 랩타임/정지 횟수 개선을 뜻하지 않는다.
4. 이전 실제 우회 전환1,057호출도 비교해 원래 성립했던 동작을 훼손하는지 확인한다.
5. 기존 출력 재생·입력/소스/종료 무결성을 확인한다. 결과가 지지할 때만 별도 후속 연결·폐루프를 설계하며 기본 활성화·월드/물성·독립 보호·정답 입력 변경은 하지 않는다.

후보는 저장 입력 전용이다. 새 명령 이후에도 이전 물리 궤적을 재사용하므로 통과·복귀·실차 안전을 판정하지 않는다. 모듈 별칭 치환은 이 단일 스레드 비교에 한정하고 운영 구현에는 사용하지 않는다.
