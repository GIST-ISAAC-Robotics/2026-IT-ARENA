# 기존 G1의 좁은 전방 결측 판단과 통과 후 보호의 결합 — 오프라인 후보

2026-10-31. 진행 중인 방향별G2 실제 시험의 고정67–76초 접두부를 읽었다.71.82초 새 관측에서 과거 통과 이력이 실제로 복원되어71.92초0.35 m/s를 냈으므로 이전 같은 스캔 이력 수정은 동작했다.73.62초에는 다른 조건이 막았다. 전체 시험/종료 판정은 아직 없으며 [접두부 원문 추출](../g2_directional_reference_effect_v1/prefix_67_76.json)을 보존한다.

기본G1은 좁은 정면 무반환1광선(0.72도), 이웃 반환7.605 m, 과거 장애물 위협0에서 `bounded_forward_missing`으로0.2 m/s를 허용했다. 그러나 통과 후 RELEASED의 추가 이동 영역 검사는 같은 경로 보완을 측방 결측에만 허용해 `partial_not_allowed`로 다시 정지했다. 초기G2 기준이나 양쪽벽 관측 문제가 아니다.

## 후보 범위

- 운영 소스는 아직 바꾸지 않는다. 기존 G1이 현재 장면에서 승인한 `bounded_forward_missing`에만 같은 명령 범위의 대조를 추가한다.
- 현재 시각/스캔, 이전·현재 조향, 차체 크기, 측정 속도, 원래 확인한 이동 외곽의 포함 관계 검사를 유지한다. 다른 경로에 승인을 옮기지 않는다.
- 목표≤0.2 m/s, 전체 무반환 셀≤1.5도, 실제 이웃 반환≥max(1 m, 기존 제동/이력 검사 거리), 현재 모든 반환의 점유 여유와 원시+inf 여부를 다시 확인한다. 기존 측방 규칙은 그대로다.
- 과거 장애물 래치·다른 스캔·다른 조향·큰 공백·NaN/최소거리미만·근접 반환·측후방 범위 밖은 거절한다. 미관측을 자유 공간으로 채우지 않는다.
- 이는 이미 선택된 부분 관측 정책을 같은/작은 명령에서 일관되게 적용하는 시험이다. 정면의 가늘거나 반사하지 않는 물체를 배제하지 못한다. 독립 보호/STOP·물성·센서 변경은 없다.

실제 시험 완료 후 고정 입력을 같은 코드로 정확 재현하고 후보와 비교한다. 후보로 생긴 양수 명령은 실제 차체 진행 증명이 아니다. 반례·기존 정상 기록 비간섭을 확인한 뒤 연결 여부를 결정한다.
