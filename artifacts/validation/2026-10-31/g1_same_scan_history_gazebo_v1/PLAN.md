# 같은 스캔 일시 대기의 이력 수정 — 동일 전체 코스

2026-10-31 실행 전 등록. [직전155초 주행](../g2_ready_reference_course_v1/README.md)은 실제 우회·복귀 뒤43.613 m에서 멈췄다.71.50초 같은 스캔 대기가 통과 이력을 삭제하는 경로를 [저장 입력에서 비교](../g1_same_scan_history_v1/PLAN.md)했고, 해당 대기는 계속 정지하되 기존 이력만 유지하도록 수정했다.

[실행 연결](../g1_same_scan_history_connection_v1/PLAN.md)의 관련 회귀·빌드/설치가 모두 통과한 뒤에만 이번1회를 실행한다. 설정은 직전155초와 같다. 제어 변경은 `traffic_path_recovery_trial` 내부의 두 대기 조건뿐이며 후보 코드와 실제 클래스의 AST가 이름 외 동일함을 확인했다.

- 앞차0.35 m/s×4초 뒤정지, 옆차0.35 m/s×15초 뒤정지,155초 창.
- 신호v2·그리드3·30 cm 카메라·방지턱ON·명목 센서·C1 순차10 Hz/운동보정·단일 모터축28카운트/15:1/65 mm 유지.
- 같은 G1/G2 명시 옵션과1/.35 m/s 상한, 도로/잔디 단차·마찰·토크·독립 보호·STOP 유지.
- 실제우회→`handoff_return` 복귀→연속FOLLOW5 m, 전체1랩, 접촉/겹침0, 세 접지면 해석 노외 바퀴≤2, 입력/소스/실행 계약, STOP/정상 종료, 전체판단동일재생을 요구한다.
- 원래G1 판정과 모든 과거 실패를 보존한다. 전체랩 통과와155초 내내 무정체·독립5대·실물 안전을 구별하며, 후반 정체가 남으면 별도로 기록한다.

새 스캔 전 진행, 새 위협·미관측 이동영역·시간/epoch 고장의 통과는 허용하지 않는다. 실패하면 첫 원인을 분석하고 근거 없는 반복을 하지 않는다. 현재 코스의0명령 정체를 헛돎으로 취급하지 않으며, 실제 헛돎 재발 때만 사용자 요청의 팀 단차 제거 비교를 진행한다.
