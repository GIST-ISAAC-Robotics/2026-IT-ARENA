# 방지턱 끝부분 진입과 편측 헛돎의 저장 기록 대조

2026-10-31 저녁 재개. 생산 제어기와 과거 기록을 변경하지 않고 세 주행의 실제 모델 자세·차량 충돌 치수·구동 진단을 대조했다. [분석기](analyze.py), [정정된 결과](run2.json), [실행 로그](run2.log). 원래 `run1`은 반복문 변수 때문에 세 사례의 이름이 모두 `rear_right`로 출력되는 표기 오류가 있었다. 수치는 개별 입력에서 계산됐지만 이름을 신뢰할 수 없어 원본을 보존하고 `run2`에서 이름과 입력 해시를 다시 확인했다.

## 무엇이 달랐는가

| 기록 | 방지턱 XY 투영에 처음 걸린 바퀴/시각 | 바퀴 평균–차체 종속도 차이가 처음0.2 m/s를 넘은 시각 | 25–30 s 바퀴/차체 종속도 적분 |
|---|---|---:|---:|
| 정지차 코스102 m 성공 | 앞왼쪽23.914 s·앞오른쪽23.935 s·두 뒷바퀴24.373 s | 24.102 s | 3.891 / 3.940 m |
| 재출발·원래 단차 | 앞왼쪽24.289 s, 나머지는21–45 s 창에서 없음 | 24.435 s | 1.390 / −0.118 m |
| 재출발·단차 제거 | 앞왼쪽23.331 s, 나머지는21–45 s 창에서 없음 | 23.477 s | 0.849 / −0.009 m |

현재 방지턱 폭은450 mm, 길이50 mm, 높이10 mm이며 실제 런타임의20조각 충돌 근사를 사용했다. 두 실패에서는 앞왼쪽 바퀴 중심이 방지턱 가로 좌표약−0.20 m, 앞오른쪽은약−0.33 m에 있었다. 즉 한쪽 앞바퀴만 방지턱에 들어가는 배치다. 성공 기록에서는 양쪽이 폭 안으로 들어왔다. 성공 기록은 앞차 일정도 다르므로 이 세 사례만으로 물리 형상의 단독 인과를 증명하지 않는다.

강체 자세와 원통 바퀴 치수로 계산한24.602 s 바퀴 최저점은 원래 단차에서 왼쪽 앞/뒤약11.0 mm·오른쪽약2.0 mm였다. 단차 제거에서는 왼쪽약6.82 mm·오른쪽약2.98 mm였다. 뒤왼쪽은 방지턱 이전 위치에 있었으므로, 평면 상면3 mm에 비해 계산상 틈이 생기는 자세다. **현재 기록에는 바퀴 접촉력 채널이 없어 실제 지지력이나 그 순간 어느 바퀴가 무부하였는지는 확정하지 않는다.** 강체/무현가 모델의 민감성을 의심할 근거이지 실차 설계 불가 판정이 아니다.

바퀴–방지턱 XY 투영 겹침은3차원 접촉 검출이 아니다. 바퀴 반지름·폭·조향·전체 자세를 반영한 투영 범위이며, 각도/위치 정답은 평가에만 사용했다. 종속도 적분은 코스 중심선 순진행과 다른 양이다. 세 원본의 입력 해시는 전후 동일했다.
