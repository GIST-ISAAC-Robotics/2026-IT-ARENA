# 같은 경로의 기존 정면 결측 판단 연결

2026-10-31. [후보](../g1_forward_same_path_v1/PLAN.md)의87검사, 실제 정체3604판단 정확 재현·324호출 양수 회복·추가0없음, 기존 정상7815명령 보존을 근거로 연결한다.

운영 수정은 `same_path_gap_trial.py` 한 파일이다. 기존 명시 `traffic_recovery_trial`의 호출 경로에서만 사용하며 기본 플래그를 활성화하지 않는다. G1이 먼저 승인한 `bounded_forward_missing`을 현재 동일/작은 이동 외곽에서 다시 확인하고, 목표0.2 m/s·무반환1.5도·현재 실제 이웃 거리·원시+inf·현재 점유와 이전 위협 조건을 유지한다. 다른 조향이나 측후방 승인으로 전파하지 않는다.

수정 전 소스는 before_connection.zip과 후속 해시 계약으로 보존한다. 후보 함수와 운영 함수의 AST 동일성을 검사하고 실제 운영 함수를 대상으로 반례·기존 측방·G1/G2 연결 회귀를 수행한다. 빌드/설치80파일 대조 뒤 같은155초 코스1회를 판단한다. 저장 입력의 명령 회복을 실제 완주로 소급하지 않는다.
