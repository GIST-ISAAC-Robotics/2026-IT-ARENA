# 명시 G1/G2 방지턱·교통 코스 1회

2026-10-31. [사전 계획](PLAN.md)의155초 각본1회를 수행했다. 기존 신호v2·뒤쪽30 cm 카메라·방지턱ON·명목 센서·앞차4–9초 정지/재개·잔디 쪽 상대차를 유지하고 명시 G1/G2 노드로 바꿨다. 일반 실행의 기본값은 바꾸지 않았다.

**별도 G1/G2 코스 판정은 통과했다.** 순진행52.1123 m, 최소 표본/연속 하한 간격359.673/359.672 mm, 접촉·겹침0, 접지면 세 해석 모두 노외 바퀴 최대0, 명령 상한 위반0이다. STOP·정상 종료와7,815/7,815판단 동일 재생, 실행/입력 소스 불변을 확인했다. 고정본1,123파일·설치 소스 대조·사전검사4건이 통과했다.

전환은 끝까지 FOLLOW였다. **이번 성공은 선택형 연결이 이 코스에서 추종을 유지한 결과이며, 코스 안에서 우회하고 돌아온 증명은 아니다.** [다음 정지 유지 각본](../g2_blocked_course_v1/PLAN.md)은 앞차가 계속 멈춰 실제 BYPASS→FOLLOW와 복귀 후 진행을 요구한다.

기존 G1 `report.json`은 모드 불일치와 `hold`·`final_gap` 실패로 exit1/실패다. 이를 덮어쓰지 않았다. 새 모드는 우회도 가능한 제어기이므로 별도 판정에서 실행 모드와 상한을 직접 확인하고,1랩·표본 무결성·접촉/겹침·노면·독립 보호·STOP 조건을 요구했다. 원래 G1의 정지시간·최종 추종거리·150 mm 판정은 비교값으로 보존했다. 실행 오류나 `evaluation.error`는 없었다.
