# 명시 G1/G2의 방지턱·교통 코스 1회

2026-10-31 사전 계획. 먼저 저장 입력 비교 결과를 검토하고 실행한다. 10/28 `bump_traffic_v1/run4`와 같은 공식 신호 v2·뒤쪽 30 cm 카메라·그리드3·방지턱 ON·명목 센서·앞차 정지/재개와 잔디 쪽 옆차의 155초 각본을 사용한다. G1 옵션·물성·속도·노면 단차는 유지하고 명시 G1/G2 자동 전환만 연결한다. 기본 실행에는 적용하지 않는다.

목적은 코너에서 부적절한 우회가 시작되는지, 우회 전환 후 코스 주행이 이어지는지 확인하는 것이다. 움직이는 상대차는 독립 자율차가 아닌 평가용 각본 상자다. 정답은 평가기만 읽는다. 코스에 우회가 반드시 발생해야 한다는 조건은 두지 않으며 전환이 없으면 우회 통합 입증이 아니라 해당 궤적의 비간섭 결과로 기록한다.

원래 G1 `report.json`의 13관문·150 mm 간격·뒤에 머무름·정지시간 판정은 보존한다. 새 G1/G2 판정은 별도 파일에서 실행 무결성·실제 schema5/명시 설정·상태별 명령 상한(FOLLOW 1, BYPASS/REACQUIRE 0.35 m/s)·1랩 순진행·전후 표본 연속성·벽/차량 접촉 및 겹침 없음·접지면 세 해석에서 잔디 바퀴≤2·STOP·정상 종료·동일 재생을 요구한다. 과거 G2와 같이 최소 차체 간격은 보고값이며 150 mm를 G2 통과선으로 쓰지 않는다. 옆차도 접촉·겹침·표본/명령 유효성은 확인하고 기존 간격 판정은 함께 보존한다. 이 변화는 우회를 허용하는 동작의 평가 범위이며 제어 보호층의 우회나 완화가 아니다.

새 case 이름을 만들지 않고 기존 `stop_restart_full_course`와 해당 acceptance 키를 사전 대조한다. 기존 원본 파일을 수정하지 않는다. 실패한 주행은 원인 변화 없이 재실행하지 않는다. 헛돎이 발생하면 사용자 요청에 따라 도로–잔디 단차를 제거한 별도 비교를 설계한다. 실제 트랙이 평탄하다는 가정으로 소급하지 않는다.
