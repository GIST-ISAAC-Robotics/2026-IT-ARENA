# 준비 완료 양벽 기준 보완의 명시 연결 검증

오프라인 준비 한정 후보는 정지차 입력의 진입 판단을 유지하면서 정상1랩의 추가 감속561→22, 추가0명령350→6으로 줄였다. 남은 변화는13.22–13.82초의 첫 앞차 대기 구간이다. 기존 우회 전환1,057명령은 동일했다. 실제 주행 개선을 뜻하지 않는다.

`initial_reference_policy=ready_current_pair_v1`, ROS `g1_g2_initial_reference`를 명시할 때만 초기 기준 공급자를 연결한다. 기본OFF·기존 schema5의 누락 필드는 원래 동작이다. 공급자는 준비·통로 계획·첫 양벽 확인·다음 스캔 여유 검사에 같은 호출의 현재 근거를 제공한다. 전역 함수 치환을 사용하지 않는다.

관련 기존 G2/기록/소스 계약 회귀와 새 현재 관측·준비 상태·고장/시각·정책/노드 기록 검사를 진행한다. 세 저장 입력에서 OFF의 전체 기존 판단, ON의 오프라인 후보 명령·내부 G1·상태 전이를 대조한다. 후보의 기록된 상세가 존재하는 호출은 그 상세도 대조한다. 입력·소스·footer 보존과 빌드·설치 사본을 확인한다. 원래 실패나 검사를 생략하지 않으며 실제 주행은 이 연결 검증 이후 별도 계획으로 진행한다.
