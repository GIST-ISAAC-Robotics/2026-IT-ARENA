# 현재 반환을 이용한 G2 초기 벽 기준 후보 — 저장 입력 비교

13.02–13.12초에는 기존 지역 경로 직선 잔차가 초기 기준을 거절하지만, 최근 양벽 기준 주변의 현재 연결 반환을 직접 적합하면 원래 공통 관측 범위가 성립했다. 13.22초 이후에는 왼쪽 벽 관측 하한이 뒷차축보다 앞으로 이동하므로 같은 방법도 거절해야 한다.

기억은 최근 1초의 탐색 선만 제공한다. 원래 양벽 기준으로 시작하며, 각 측면의 현재 연결 반환이 확인될 때만 해당 탐색 위치를 갱신한다. 같은 스캔 재사용은 기억 수명을 늘리지 않는다. 현재 두 벽의 공통 구간·방향/폭 합의, 모든 원래 점유 반환 및 독립 보호를 유지한다. 지도·물체 정답·과거 선만으로 자유 공간을 제공하지 않는다.

기존 명시 `bounded_hold_v1` 40초 실패 입력 전체와 정상 교통 1랩 입력 전체를 비교한다. 현재 원본 재생 일치, 내부 G1 상세, 첫 변경 명령, G2 전이·거절 원인을 기록한다. 변경 뒤의 저장 입력은 반사실 비교이며 실제 경로/완주를 증명하지 않는다. 기본값·ROS·월드·물성을 변경하지 않으며, 이 단계에서는 Gazebo를 시작하지 않는다.

실행 전에 출처/시각 변화, 기억 만료·미관측/한쪽 벽·범위 부족·합의 실패·재사용 입력·별칭 복구를 검사한다. 결과가 실제 진입 근거를 제공하지 못하면 같은 주행을 반복하지 않고 남은 거절 원인을 분석한다.
