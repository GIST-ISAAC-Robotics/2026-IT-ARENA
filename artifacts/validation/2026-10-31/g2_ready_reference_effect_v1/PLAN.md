# 실제 성공 기록에서 기준 보완의 작동 여부

40초 성공 run2의 진입 시점12.92초는 상세 기록에서 `current_two_wall_straight_reference`였다. 따라서 이 주행 성공을 새 보완 분기만의 효과라고 단정하지 않는다. 준비 중 공급자는 모든 호출을 상세 출력하지 않으므로 문자열 검색0건만으로 미사용이라 단정하지도 않는다.

새 주행 없이 실제 기록2067호출을 그대로 재생한다. ON 공급자의 반환을 변경하지 않고 원래 기준 실패→현재 양벽 보완 반환 횟수를 계측한다. 기록된 전체 판단과 일치를 필수로 확인하며 같은 입력의 옵션OFF 전체 판단도 대조한다. 입력·소스 SHA와 footer 무결성을 보존한다. OFF는 고정 입력 반사실 비교일 뿐 다른 궤적·폐루프 반복성 증명이 아니다.155초 주행을 방해하지 않도록 해당 시험 회수 후 실행한다.
