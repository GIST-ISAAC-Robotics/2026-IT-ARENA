2026-10-31. [계획](PLAN.md)에 따라 `g2_ready_reference_gazebo_v1/run2`의 원시 입력을 재생했다. [결과](run1/summary.json)에서 기록2067호출이 모두 동일했고, 기준 공급자 내부의 실제 보완 반환은0회였다. 같은 입력에서 옵션OFF도 전체2067판단이 동일했다. 입력·소스 불변과 정상 footer를 확인했다.

따라서40초 run2의 우회·복귀 성공을 새 보완 분기만의 효과라고 주장할 수 없다. 그 실행은 기존 양벽 기준만으로도 같은 저장 판단이 나오는 조건이었다. OFF를 실제로 다시 주행한 결과도 아니므로 폐루프 반복성/확률을 입증하지 않는다.

반면 이후 [155초 코스의 실제13.12초 진입](../g2_ready_reference_course_v1/run2_entry_reference.json)에는 종전 `straight_entry_only` 실패 대신 `current_tracked_pair_candidate`가 사용됐다. 이 코스는 우회·복귀 뒤43.613 m에서 다른 이력 처리 문제로 멈췄다. 구성의 동작, 보완 분기의 사용, 전체 완주를 구분한다.
