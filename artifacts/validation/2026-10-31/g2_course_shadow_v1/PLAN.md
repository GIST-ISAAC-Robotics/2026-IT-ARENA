# G1/G2 코스 연결 전 저장1랩 비교

2026-10-31. 사용자가 재개를 요청했다. 먼저 기존 방지턱·교통1랩 성공 run4의 저장 입력7801호출에서 현재 G1 재현과 명시 `corridor_local_v1` 자동 전환의 출력을 대조한다. 운영/물성/제어 설정은 바꾸지 않는다.

원래 판단 재현, 내부 G1 상세 보존, 준비 감속·공간 예약·우회 진입/복귀·처리 비용을 기록한다. 같은 실제 센서 기록에 다른 명령을 계산하는 비교이므로 **첫 명령 차이 이후의 상태를 실제 새 궤적이나 완주 예측으로 쓰지 않는다.** 원시 입력·출처·실패를 보존하며 결과를 검토한 뒤 별도 코스 주행을 등록한다. 제어기에 지도/차체정답/actor정답을 입력하지 않는다.
