# 상대 양보 감속의 제한 Gazebo 검증

[사전 계획](PLAN.md)에 따라 준비 중입니다. run2에서 첫 실제 주행을 완료했습니다. 생산 코드 기본값은OFF이며 방지턱을 유지하고 도로/잔디 높이만 같은 진단 월드로45초를 관찰합니다. 원래155초 전체랩 성공을 이 제한 판정으로 대체하지 않습니다.


## 최초 사전 검사 실패와 수정

빌드1은통과했고82개 Python 소스/설치 바이트와 기본OFF를 확인했다. run1은7검사·1,160파일 소스 고정까지 끝났지만, 전체 코스 검사기가 최소1랩의 앞차 이동 일정을 요구해45초 일정의 사전검사에서 실패했다. Gazebo는 시작되지 않았으며 STOP/재생 결과가 없다. `run1_preflight.log`와 `run1_sources.zip`을 보존했다.

후속 `partial_route.py`는 기존155초 전체 각본을 모두1cm 간격으로 검사하고, 실행할45초 일정이 정확히 그 접두 구간인지 추가 확인한다. 차량/경로/노면/벽 기준을 바꾸지 않으며 원래 전체랩 평가는 유지한다. 당시 실행 평가기만 이 함수를 쓰고 대회 제어기는 읽지 않는다. 별도 run2에서 사전검사 뒤 첫 실제 주행을 수행한다.
