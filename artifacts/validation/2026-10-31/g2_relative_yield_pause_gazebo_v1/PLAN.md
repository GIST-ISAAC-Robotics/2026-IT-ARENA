# 짧은 운동 대기 감속 연결 v2 — 같은 대표 장면 재확인

2026-10-31 실행 전 등록. [기존 노면 v1 실패](../g2_relative_yield_surface_v1/README.md)에서 확인한 감속 상태 초기화만 수정한 명시 `bounded_relative_yield_v2`를 시험한다. 같은 기존1 mm 도로/잔디 단차·방지턱·차량/센서·0–4초 앞차 진행/4–9초 정지/이후 재출발·잔디 옆차·45초 관찰을 유지한다. 토크·마찰·STOP·간격/노면 평가를 낮추지 않는다.

현재385회귀 통과 뒤 저장 입력의 v1 원본 일치와 v2 대기/재개 명령을 대조하고, 필요한 빌드와 설치 대조·사전 고정본 검사가 통과할 때 실제1회 수행한다. 기본OFF와 기존v1은 유지한다. v2는 유효한 signed 운동 대기0명령 동안 감속 의도만최대1초 보관하며 원래5초 감속 예산을 늘리지 않는다. 현재 면/벽 검사는 재개 때 다시 수행한다.

수용 조건은 직전45초 그대로다: 우회 중 실제 앞차 재출발·감속 사용·정상 추종 복귀 후3 m·접촉0·노외바퀴≤2(세 해석)·실제 STOP 안정·정상 종료·정확 재생·무결성. 원래 G1 판정은 별도 보존한다. 실패를 성공으로 바꾸지 않고 첫 결과의 직접 원인을 분석한다.

이 대표 문제가 해결되면 같은 구성의 공식 코스 주행과 가능한3인칭 영상을 준비해 종료한다. 희귀 형상/전수 경계 시험을 추가하는 계기로 삼지 않는다.
