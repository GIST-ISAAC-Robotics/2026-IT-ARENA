# 운동 대기 뒤 감속 의도를 잇는 v2 물리 시험

[사전 계획](PLAN.md)에 따라 준비했다. 저장 입력 대조가 끝나고 빌드/설치와 사전검사가 통과한 뒤 실제 주행1회를 수행한다. 현재 주행 미실행이며 기존 실패는 그대로 보존한다.


## run1 — 주행 기능 확인, Gazebo 정상 종료 실패

385회귀/저장입력 대조 후83파일 빌드/설치 일치·1,164파일 고정으로 실행했다. 우회13.72 s→재획득24.02 s→정상FOLLOW24.12 s, 앞차 실제재출발16.80 s였다. 총14.35823 m, 복귀후연속4.71926 m로 **이 제한 시험의3 m 기준은 통과**했다. 5 m는 별도로 보존한 원래 전체코스 판정이다. 감속95호출, 접촉/겹침0, 최소표본간격204.06 mm, 노외any/center/full 각각2, STOP명령·실제정지·2,316판단동일·원시/소스보존을 확인했다.

종합실패의 바깥 checks는 `shutdown_clean` 한 항목이다. Gazebo가SIGINT/SIGTERM에 응답하지 않아SIGKILL로 종료됐으며 잔류프로세스는0이다. 실제STOP은0.972초 내 안정 판정·약104.954 mm 이동·마지막0.5초최대0.00996 m/s였다. 원래G1 HOLD/전체랩 실패와 원래 전체코스 복귀후5 m 미달도 따로 보존한다.

앞바퀴좌우26.769 s,뒷바퀴좌우28.394 s에 방지턱과기하겹침이 시작됐다. 새운동대기 보관/재개 분기는이실행에서0회이므로 해당코드변경이직접복귀를만들었다고단정하지않는다. 효과는저장입력19.52–22.80초명령대조로한정한다. 동작확인후에는종료오류반복시험을늘리지않고 [대표코스+영상](../g2_relative_yield_course_video_v1/PLAN.md)으로진행한다.
