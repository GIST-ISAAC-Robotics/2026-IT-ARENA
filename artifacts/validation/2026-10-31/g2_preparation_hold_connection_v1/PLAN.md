# 준비 유지 후보의 명시 연결 검증

미연결 후보의17반례·저장 입력 비교를 마친 뒤 연결한다. 정지 유지 코스 초기1,354호출 중42개, 정상 코스7,815호출 중35개가 추가0명령이었고 모두 출발 직후 앞차 대기 구간이다. 기본 G1 내부 판단은 동일, 속도 증가0이었다. 실제 우회 개선은 미확인이다.

`HandoffExecutionConfig.preparation_hold_policy=bounded_hold_v1`과 ROS `g1_g2_preparation_hold`를 명시할 때만 최대1초 준비 유지 상태를 연결한다. 기본 `off`와 과거 schema5의 누락 필드는 기존 동작이다. 현재 조각·원호 검사, 모터축/IMU 이동 보정, 출처·나이·이동/교체/고장·음수 속도·모드 전환의 해제를 유지한다. 준비 기억만으로 우회 허가를 주지 않는다.

검증은 해당 경계 반례, 기존 G2/기록 관련 회귀, 원본OFF 판단 동일 재생, 미연결 후보와 ON 명령/내부G1/기억 상세 일치, 빌드·설치 대조다. 저장 입력 비교는 실패 코스35초 접두부·정상 코스 전체·기존 실제 우회 전환 기록을 구분한다. 이후 새 제한 주행을 별도 사전 등록한다. 기존 코스 실패·물성·보호·명시 STOP·전체랩 판정은 소급하지 않는다.
