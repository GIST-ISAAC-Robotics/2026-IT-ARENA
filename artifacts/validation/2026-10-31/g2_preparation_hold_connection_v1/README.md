입력·소스 불변을 확인했다. 접두부 이외의 두 입력은 footer까지 검사했다. `arena_autonomy`1패키지 빌드와79개Python 설치 사본의 바이트 일치, 실행 파일 존재를 확인했다. 빌드 경고는 현재 install underlay의 동일 패키지 재정의와 byte-compile 비활성 안내이며 빌드 실패는 아니다.

첫 검사에서는376통과·2실패였다. 새 코드 변경의 후속 SHA 계약을 아직 등록하지 않아 이전 소스 보존 검사가 거절했다. 변경 전 저장ZIP의 두 파일을 기존 계약 해시와 대조한 뒤 [후속 계약](../../../../config/tests/g2_preparation_hold_r1_sha256.json)을 추가했다. 과거 계약/실패 로그를 고치거나 검사를 생략하지 않았다. `tests1.log`는 실패 원본, `tests2.log`는 후속 통과다.

이는 새 궤적의 개선 증명이 아니다. 다음 [40초 진입/복귀 시험](../g2_preparation_hold_gazebo_v1/PLAN.md)에서 실제 공간 보존·우회·복귀를 확인한다. 기본 활성화·전체 코스 성공·실물 검증으로 확대하지 않는다.
