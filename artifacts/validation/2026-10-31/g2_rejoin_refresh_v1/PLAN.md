# 복귀 곡선의 조향 포화 — 비연결 비교

직전 주행은25.32 s signed 대기에서 재개했지만, 바퀴 헛돎과 실제 이동 차이 속에서 복귀 경로 추종 조향이 포화됐다. 이후 낮은 cap 3개도 각63호출에서 현재 점유 검사 때문에 진행하지 못했다. 기준 완화나 상한 하향만으로 해결할 근거가 없다.

후보는 **이미 복귀 중이고, 현재 외벽이 확인되고, 새 스캔에서 기존 경로의 요구 조향이 실제 최대각에 닿았을 때만** 현재 차체에서 같은 관측 중앙선으로 향하는 기존1.2 m 전이를 새로 제안한다. 현재 보인 벽 길이가 부족하면 제안하지 않는다. 조향 포화가 작아지지 않으면 기존 경로를 유지한다. 제안 뒤에는 원래 현재점유·명령 이동영역·측정속도·조향 변화율·signed 재개 확인·독립 보호가 그대로 적용된다. 도로 지도나 평가 정답을 쓰지 않는다.

기존 초기 진입/정상 비포화 복귀/같은 스캔/음수 및 고장에는 적용하지 않는다. 새 제안은 움직임 허가가 아니다. 저장 입력에서 원본 재현과 후보의 변화·거절을 확인한다. 추가로 닫힌 루프를 쓰기 전, 단순 운동 합성에서 재계획이 복귀를 계속 미루는지 확인해야 한다. 이번 단계는 실제 주행·기구 통과나 기본 채택을 뜻하지 않는다.
