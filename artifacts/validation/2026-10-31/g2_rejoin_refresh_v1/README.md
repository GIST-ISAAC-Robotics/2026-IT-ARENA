# 현재 벽 기반 복귀 경로 재제안 — 비연결

14개 단위검사와 저장 입력 재현을 통과했다. [후보 범위](PLAN.md), [입력/소스 해시와 결과](run1/summary.json).

| 저장 입력 | 원본 판단 동일 | 새 제안 | 속도·조향 변화 | 새 정지/진행 호출 |
|---|---:|---:|---:|---:|
| 최신 재출발 실패40초 접두부 | 1,603/1,603 | 3 | 130 | 0/0 |
| 기존 정지차 코스 성공 전체 | 7,804/7,804 | 0 | 0 | 0/0 |

실패 입력26.82/28.12/29.22 s에 기존 최대 조향0.371058 rad를 요구하던 복귀 경로 대신 현재 관측벽에서1.2 m 곡선을 제안했다. 새 Pure Pursuit 요구각은약0.079–0.087 rad다. 실제 출력은 저장 입력에 고정된 직전 조향과3 rad/s 변화율 제한을 적용하므로0.311058 rad였다. **고정된 과거 차체 운동을 바꾼 시험이 아니며, 이후 정체가 해결됐다는 뜻은 아니다.** 전체 최대 조향은 같았고 새 진행 호출도 없었다. 음수 입력 중 양수 명령0·원시입력/footer/소스 불변을 확인했다.

별도 [이상 운동 구성요소](../g2_rejoin_kinematic_v1/README.md)에서 분기가 작동한 뒤 복귀할 수는 있었으나 전체 센서 제어기·물리 시험은 아니다. 후보를 주행에 연결하지 않고 보존한다. 다음 실제 비교는 재제안을 추가하지 않은 최신 운동 대기 코드에서 도로–잔디 단차만 제거하는 것이다.
