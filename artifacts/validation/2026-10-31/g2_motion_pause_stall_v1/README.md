# 운동 대기 이후 정체의 내부 원인

새 주행의 절대40초까지1,603판단을 그대로 재현하며, signed 대기 전에 평가된 내부 후보386개를 회수했다. 출력·소스·입력 불변을 확인했다. [요약](run1/summary.json), [내부 비교](run1/inner.json), [시각별 전이](run1/events.json), [평가 전용 구동 대조](physics.json).

1. 유효 음수 대기는 더 이상 상위 전환을 초기화하지 않았다.25.32 s에는 서로 다른 두 스캔을 확인한 뒤0.35 m/s로 재개했고, 우회 경로가 남았다. 이번40초 접두부의 상한 초과 대기 사용은0회다. 따라서 새 복합 옵션의 두 분기가 모두 실제로 쓰였다고 하지 않는다.
2. 이 사이 방지턱 부근 헛돎으로 이동 추정과 실제 운동의 차이가 커졌다. 현재벽의 법선·방향 재정합은 있지만, 직선 벽을 따라간 이동량은 그 검사로 관측되지 않는다. 복귀 경로는 모터축 이동으로 계속 이송됐고,26초 이후 요구 조향이 최대0.371058 rad에 이르렀다. 이는 후속 복귀 경로 재검토의 근거이며, 물리 접촉 원인을 단독으로 확정하는 증거는 아니다.
3.29.50 s의 첫 후기 정지 뒤 잠깐 재개했고,29.54 s부터 다시0명령이었다.29.56 s의 음수 입력 뒤에는 경로를 유지한 signed 회복 대기였지만 내부 후보가`known_occupied_command_hold`로 막혔다.30.56 s부터는 현재 바깥 벽 자체를 확보하지 못했다.
4.24–32 s의 해당 대기63호출을 각각0.25/0.15/0.08 m/s 상한으로 별도 상태에서 비교했지만, 세 상한 모두 eligible0회였다. 원래 후보가 본 현재 점유 검사는 그대로였고, 낮은속도 대안을 원래 제어기 상태에 적용하지 않았다. 단순 감속 상한 조정이나 재개 확인 횟수 완화로 해결할 근거가 없다.

뒤로 밀리고 회전한 실제 차체와 센서 운동 추정의 차이는[물리 표본](physics.json)에 남겼다.29–32 s 차체 종속도 적분−0.32852 m를 중심선 진행으로 해석하지 않는다. 실제 차체 자세는 평가에서만 사용했다.

다음 비교는 **복귀 조향이 포화됐을 때만 현재 관측벽으로 복귀 곡선을 다시 제안하는 방식**이다. 초기 진입과 정상 비포화 복귀를 유지하고, 새 곡선에도 기존 점유·이동영역 검사를 적용한다. [후보 범위](../g2_rejoin_refresh_v1/PLAN.md). 저장 입력에서 달라진 명령은 실제 회복 증명이 아니며, 이상 운동 구성요소에서 복귀를 무한히 미루는지 별도로 확인한다.
