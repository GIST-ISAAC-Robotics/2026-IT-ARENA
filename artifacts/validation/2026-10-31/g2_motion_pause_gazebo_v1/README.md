# 운동 대기 연결 뒤 재출발 주행 — 실패

원래 도로/잔디 단차·방지턱·155초 상대차 일정에서 `bounded_motion_pause_v1`만 추가한 1회다. 사전 13검사와 1,148파일 고정·설치·실제 전체 경로 검사를 통과한 뒤 실행했다. 기본 옵션은 OFF다.

[등록 평가](run1_evaluation.json)와 원래 G1 판정은 모두 실패다. `post_restart_follow_progress_m=0`은 **정상 복귀한 FOLLOW 연속 진행이 없다는 뜻**이며 재출발 뒤 자차가 전혀 움직이지 않았다는 뜻이 아니다. 0.34685 m는 자차가 아니라 **앞차의** 약1초 이동이다. 중간 상태 메시지의 시각/진행량 대신 전체 원시 기록의 전이를 사용했다.

## 실패 구분

우회 상태는 유지됐지만 내부 동작이 `entry_reverse_recovery_wait`·`no_entry_command_candidate`로 대기했고 새 진행 확인이 쌓이지 않았다. 29.8–30.5 s의 [정지 요약](run1_handoff_pause_window.json)만으로 최초 정지 시각이나 전체 원인을 확정하지 않는다. [저장 입력 내부 후보 조사](../g2_motion_pause_stall_v1/probe.py)로 원래 후보를 재현하고, 낮은 명령 cap의 효과를 주행에 연결하지 않은 상태에서 분리한다.

[평가 전용 구동 대조](../g2_motion_pause_stall_v1/physics.json)에서23–29 s의 바퀴 표면속도 적분은1.78083 m, 실제 차체 종속도 적분은0.47045 m였다. 28.977 s에 좌/우 뒷바퀴 −3.176/49.828 rad/s, 바퀴 평균0.75810 m/s, 실제 차체 −0.12812 m/s가 관측됐다. 목표는0.35 m/s였다. **이 값은 헛돎·미끄러짐의 평가 증거이며 정답 차체속도를 제어기에 넣지 않았다.** 종속도 적분은 곡선 중심선 순진행과 다른 양이다.

29–32 s에는 바퀴 적분+0.18746 m와 차체 적분−0.32852 m가 반대 방향이었다. 이때 조향된 채 뒤로 움직이며29.878–30.851 s에 바퀴 중심3개 이탈이 발생했다. 이후 정지한 자차에 코스를 돌아온 각본 앞차가154.717 s부터 닿았다. 직전154.599 s 자차 명령/안전출력은0, 실제 종속도는약0이었다. 접촉 메시지632개를 독립 충돌632회로 해석하지 않는다. 상대는 정해진 위치를 따라 움직이는 모델이며 실제 회피하는 상대차가 아니다.

원래 G1 hold·최종간격·전체랩·노면·간격·겹침/접촉 실패와 원시 로그를 유지한다. 방지턱 분석 exit0은 분석 실행 성공이며 주행 성공이 아니다. 이전 정지차102 m 성공이나 단차 제거 실패를 이번 결과로 소급 변경하지 않는다.
