# 같은 경로의 정면 결측 연결 — 동일155초 교통 코스

2026-10-31 실행 전 등록. [직전 실제 코스](../g2_directional_reference_gazebo_v1/README.md)는 초기 우회·복귀에 성공했지만43.613 m의 같은 경로 정면 무반환 판단 불일치로 전체랩 실패였다. [후보 입력 비교](../g1_forward_same_path_v1/README.md)에서324정지 호출에 진행을 복원하고 정상7815명령은 유지했다.

[운영 연결](../g1_forward_same_path_connection_v1/PLAN.md)의 회귀·빌드/설치가 통과한 뒤1회 실행한다. 변경은 same_path_gap_trial.py의 기존 정면 결측 증거 연결뿐이며 설정·actor 일정·평가기 바이트는 직전과 동일하다.

- 앞차0.35 m/s×4초 뒤정지, 옆차0.35 m/s×15초 뒤정지,155초 창.
- 신호v2·그리드3·30 cm 카메라·방지턱ON·명목 센서·C1 순차10 Hz/운동보정·모터축28카운트/15:1/65 mm.
- G1최대1 m/s·G2최대0.35 m/s·정면 결측 목표최대0.2 m/s. 실제 측정속도는 자르지 않고 원래 이동 영역에 넣는다.
- 현재 방향별 기준 ready_directional_pair_v2·같은 스캔 이력 수정은 유지한다. 기본 활성화·도로/잔디 단차·마찰·토크·독립 보호·STOP 변경은 없다.
- 실제우회→정상FOLLOW복귀→연속5 m, 전체1랩, 접촉/겹침0, 세 접지 해석 노외 바퀴≤2, 입력/소스/실행계약, STOP/정상 종료, 전체판단 동일재생을 요구한다.

후반 새 분기의 실제 사용·진행과 초기 우회 결과를 구분한다. 실패를 보존하고 원인 변화 없는 반복은 하지 않는다. 이전같이0명령으로 정체한 것을 헛돎으로 해석하지 않는다. 실제 양수 명령/바퀴 회전 중 차체가 진행하지 않는 현상이 확인되면 사용자 요청대로 팀 파생본의 도로–잔디 단차 제거 대조를 판단한다.
