# C 증속 미적응 수정 후 공통 코드 비교

사용자 지적: C의 출발만 허용하고 전방 ±100° 전 광선 반환을 증속 전제로 남겨 둔 v3 비교로는 C의 조정 후 성능을 판단할 수 없다. 그 조건을 고친 뒤 속도·정지·불확실성을 비교한다.

- 수정: 명시적인 구조 적응 정책 + 부분 관측 검사 경로에서 전체 전방 반환 조건을 높은 **후보** 속도 계산의 전제로 쓰지 않는다. 후보를 만든 뒤 그 속도·현재/직전 조향으로 기존 그림자·숨은 관측 기억·예상 밖 결측을 평가한다. 실제 장애물·곡률·제동·경로 길이·독립 보호층은 유지한다.
- 실험: 이전과 동일한 프로필·광축 75 mm, ID49 하단 115 mm, 얇은 선은 뒤 지주 그림자에 포함. 같은 최종 런타임의 C50 → C30 → C65 → JR50 각 1랩. 성능이 나은 C와 JR50은 각각 1회 추가해 결과 변동과 정지 재현을 확인한다. 추가 반복·추월·최종 CAD의 광축 재시험은 이번 범위가 아니다.
- 지표: 실제 완주, 랩·최고·1초평균 속도, 1.2/2.0 m/s 초과 지속 시간, 증속 후보 허용과 최종 명령을 별도 기록. 초록부터 결승까지 명령0 구간과 첫 이동 이후 실제 속도 0.05 m/s 미만이 0.1초 이상인 정지 구간·재출발을 각각 센다. 충돌·노면 이탈·STOP·정상종료와 잔여 프로세스를 확인한다.
- 불확실성: 반복2회는 실패율/안전 보장이 아니다. 기존 구조 정책은 완전히 숨는 폭 5 cm를 잠정 허용하며, 그보다 가는 미관측 물체·그림자 안 이동물체·실차 타이밍은 미검증이다. 정지 감소를 위해 미관측 광선에 거리를 만들지 않는다.
- 보존: v2/v3 원본은 그대로 두며 v3 랩은 제한 미수정 상태의 참고값으로만 사용한다. 변경 전 소스 ZIP, 등록된 실행 인자·소스 SHA, 모델/로그/평가·종료 영수증을 남긴다. 최종 비교는 같은 런타임 코드의 실행만 묶는다.
