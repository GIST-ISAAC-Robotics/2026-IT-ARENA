# C 배치에 맞춘 수정 후 비교 — v2

사용자 지시: C가 기존 전방 관측 조건에 걸린다는 이유로 배제하지 않는다. C에 필요한 코드를 수정하고, 라이다를 전진시킨 C 및 JR과 성능·수정 비용을 비교한다.

- 기준: v1 이후 저장소와 같은 공식 파생 월드/속도 설정. C30·C65·JR50 모두 광축 75 mm, 표시 차체 윗면 65 mm, 같은 구조 적응 정책. 질량·충돌체는 바꾸지 않는다. 기존 95 mm C의 실패와 높이 차이를 결과에 혼합하지 않는다.
- 정책: 자기반환은 NaN 유지, 설명된 구조 각도만 일반 결측과 구별. 폭 5 cm를 넘는 먼 구조 그림자와 과거 관측했다가 가려진 점이 현재/직전 조향의 이동 외곽에 들어오면 제동 상한을 둔다. 지도/평가 정답 사용 없음, 독립 보호층 유지.
- 위험 범위: 5 cm는 기존 측방 결측 시험의 잠정 예산이며 규정/실물 안전값이 아니다. 숨은 가는 물체·움직이는 물체·부분 노출 표면의 미관측 부분은 보증하지 않는다. 현재 차체 보호 외곽 안 그림자는 새 진입 영역이 아니므로 가상 자기충돌 제한에서 제외하며 실제 관측 장애물은 제외하지 않는다.
- 단위 검증: 거리 생성 없음, 예상 밖 결측·메타데이터 오류·근거리 실제 반환은 유지, 회전 중 그림자/숨은 장애물 기억 제한, 기본 정책 불변.
- 실행 순서: 관련 회귀·빌드 → C30 단독 1랩(실패 시 원인 수정; 실패 원본 보존) → 같은 최종 빌드의 C30·C65·JR50 각 2회. C30 첫 실행이 같은 빌드에서 통과하면 첫 반복에 포함한다. 각 구성의 `close_cut_in` 교통 1회. 원본 평가기의 실패 판정은 그대로 보존한다.
- 지표: 출발·랩·정지명령 누적/사유·최고/1초 평균 속도·접촉·노면 이탈·STOP·정상 종료·잔여 PID·정책 시간/제한 사유·소스 동일성. 단회 차이를 일반적 성능으로 확대하지 않는다.
- 프로필은 시험 전용이며 기본값을 교체하지 않는다. 결과는 이 폴더 README 하나에 정리하고 현황·활동 기록은 링크와 핵심 결론만 갱신한다.
