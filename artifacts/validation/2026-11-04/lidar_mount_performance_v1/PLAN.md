# C1 장착 후보 주행 비교 계획 — 2026-11-04 (실행 전 등록)

## 목적

현행 실행 프로필 R(x=+60 mm, z=95 mm, 정후방 ±30° 마스크)과 11/3 [적층 비교](../../2026-11-03/lidar_mount_study_v1/README.md)의 기구 목업 후보 JR·비교안 C를 **같은 빌드·월드·속도 프로필·장면**에서 실제 폐루프 주행 성능으로 비교한다. 배치 결정(빠르면 11/5)·세부 설계(11/7) 전에 지금 개발을 계속할지, 임시 JR/C를 실행 구성에 넣을지를 판단할 근거를 만든다.

## 비교 구성(시험 전용 YAML, 기본 `b0183_c1.yaml` 불변)

| 이름 | 회전축 x / 광축 z | 스캔면 구조 | 마스크 |
|---|---|---|---|
| R(대조) | +60 / 95 mm | 없음 | 정후방 ±30° |
| JR | +50 / 75 mm | Ø7 지주 (+10, ±62), (−80, ±52) mm | 정후방 마스크 없음, 아래 두 처리 |
| C | +30 / 95 mm | Ø7 지주 (±80, ±62) mm | 같음 |

- **raw:** 지주를 Gazebo 표시 형상으로 넣어 실제 광선 자기반환을 만들고 그대로 처리한다.
- **unknown:** 같은 지주와 뒤 ID49 마커(현행 차량 설정의 z 65–115 mm, 두 스캔면 모두 통과)를 알려진 차체 고정 구조로 보고 해당 각도(기하 반폭+0.5°)를 반환이 있어도 unknown으로 둔다. 자유 공간으로 채우지 않는다.
- JR 75 mm에서는 단순 차체 **표시** 상자(윗면 92.5 mm)가 스캔면을 덮으므로 표시 상자 윗면만 65 mm로 낮춘다. 질량·관성·충돌체는 그대로다. 실제 차체 형상이나 낮은 구조의 가림을 대표하지 않는다.
- 바퀴 표시 원통 윗면은 65 mm다. 조향 바퀴·펜더·범퍼·배선·실제 C1 광학창 높이와 크기는 모델 밖이다.

## 실행(각 1회, 자동 재시도 없음)

1. 짧은 raw 단독(최대 시뮬 25 s): JR·C. 출발 거부 여부와 원인만 본다.
2. 단독 1랩: R·JR-unknown·C-unknown. 11/3 [선정 1랩](../../2026-11-03/solo_post_free_v1/README.md)의 등록 인자를 그대로 쓰고 `--local-sensor-config`만 다르다.
3. 교통: 11/3 오른쪽 후방 재접근 각본과 11/2 근접 끼어들기 각본, 현행 교통 옵션. R·JR-unknown·C-unknown.
4. 저장 입력 shadow 재생: 센서 x·지주 x/y·지름·여유각의 명목∪변동 마스크, 보정 오차(lidar_x_m ±5/10 mm), 자기반환 그대로 처리. 개루프 반사실이며 폐루프 랩 결과로 쓰지 않는다.

## 판정·기록

- 실측 지표: 출발 여부·첫 이동 시각, 진행/랩, 최고 속도, 0명령 시간과 사유, 보호층 사유 시간, 접촉/노면 이탈, STOP·정상 종료, 교통 최소 간격·상대 외곽 반환 수.
- **수용선:** 같은 빌드 R 대조와 명목 JR/C 각각의 실측 진행·접촉·정지·속도·랩. 막히면 원인 진단으로 끝낸다.
- 단회 차이를 장착 효과로 단정하지 않는다. 같은 조건 재실행 변동 폭이 없으면 1초 미만의 랩 차이는 판단 근거로 쓰지 않는다.
- 결과는 이 폴더 README에 남기고, 현황·활동 일지는 결론과 링크만 갱신한다.
