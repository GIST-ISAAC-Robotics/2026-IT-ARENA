# 구형 RWD 배치 STEP — 참고용 단면

사용자가 제공한 `IT_ARENA_RWD_150x200_배치어셈블_v1.step`(127,687,642 bytes, SHA-256 `a93d422d059e38846a3be11174f664cd3dbfc6b794022ea25373d6afbab8b69e`)은 구동계 미완성·방지턱 폐지 전·쇽 포함 버전이다. 팀 설계 원본은 저장소에 복사하지 않았다. 현재 주행 프로필이나 JR/C의 장착 좌표를 이 파일로 덮어쓰지 않는다.

STEP AP214를 로컬 Open CASCADE로 읽었다. [추출 스크립트](inspect_reference.py)와 [최상위 인스턴스 33개 및 선택 형상](assembly.json)에 원래 조립 좌표·mm로 기록했다. 이 CAD는 바퀴의 Z 최솟값이 0, 높이 방향이 Z다. 후면 마커가 −Y 끝에 있어 길이는 Y, 폭은 X로 읽었다.

| 확인한 구형 모델 형상 | 당시 CAD에 기록된 값 |
|---|---|
| 전체 33개 조립 외곽 (전장×전폭×전고) | **197.4×148.0×266.3 mm**. 앞뒤 끝과 좌우 끝은 타이어(한쪽은 상부 트레이도 같은 끝), 최상단은 C1 본체. 200×150 mm와 비교한 총 잔여는 길이 2.6 mm·폭 2.0 mm이다. 저장된 한 자세의 형상이며 조향 전 범위·배선·제작 공차를 포함하지 않는다. |
| 임시 차체 프레임의 수직 지주 | 중심 (X,Y)=(±46, ±66) mm 4곳. 좌우 간격 92, 전후 132 mm. Z=28…92 mm 구간은 외경 3.6/내경 3.2 mm이고, Z=93.6…134 mm 구간은 외경 4.0/내경 3.2 mm이다. 실제 제작품, 배선 포함 단면, 강도 보증이 아니다. |
| C1 | 유연 케이블 제외 본체의 조립 경계 Z=225…266.3 mm. 구형 배치 자체가 저상 C1의 성능 증거는 아니다. |
| PDB J01 / M01 | 각 인스턴스의 모델 외곽 100×141×30.5 mm. 각각 Z=89.5…120 / 131.5…162 mm. 명목 기판 크기·실물에 꽂은 플러그/케이블 공간과 구별한다. |
| 타이어+휠 | 모델 4개, 각 폭 26.1 mm·외경 64.4 mm. 전날 JR 가정의 임시 타이어 폭 12 mm와 다르므로 그때의 6 mm 지주 여유를 이 차나 최종 차에 적용할 수 없다. |
| 쇽·구동부 | 쇽 4개와 타워·임시 프레임·상부 트레이가 있다. 모터+엔코더 등 부품 인스턴스는 있지만 완성된 동력전달계로 보지 않는다. |

검토 목적은 현재 설계의 구성 범위와 **어떤 치수를 최종 CAD에서 다시 읽어야 하는지** 확인하는 데 있다. 광축 높이, 축–지주 상대 위치와 실제 광학창 높이의 최대 단면(와이어 포함), 타이어·조향 돌출을 최종판에서 재확인한다.

재현: Python 3.12 가상환경에 `cadquery-ocp-novtk==7.9.3.1.1`을 설치한 뒤 `python inspect_reference.py <STEP 경로>`. 조립 배치를 보존해 프레임 솔리드의 축 방향 원통면과 외곽을 측정하며, STEP 형상을 축소하거나 시뮬에 이식하지 않는다.
