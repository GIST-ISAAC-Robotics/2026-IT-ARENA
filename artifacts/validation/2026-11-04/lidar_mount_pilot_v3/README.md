# C 전진량과 JR: 후방 중앙이 열린 단독 주행

**후속 정정:** 이 비교는 C의 증속 전제(±100° 전 반환)를 수정하지 않아 **C 조정 후 성능과 배치 추천 순위를 판단하기에 불완전했다.** 아래는 당시 측정값이며 취소·교체하지 않는다. 사용자 지적에 따른 수정과 같은 코드 재시험은 [v4](../lidar_mount_speed_v4/README.md)에서 구분한다.

2026-11-04. [기구 실장·배선·상면도](../lidar_packaging_v3/README.md)와 이 주행 시험은 서로 다른 질문을 다룬다. 단독 주행은 광축 75 mm에서의 지주 위치 비교이고, 하부 부품 재배치 예는 102 mm, 실제 목업 제안은 105~110 mm이다. 실장 후의 저상 상대차 검출·추월 성능은 여기서 측정하지 않았다.

조건: 같은 트랙·출발칸·G1 제어/독립 보호층·주행 속도 프로필·센서 획득 주기. [v2의 C용 구조 적응](../lidar_mount_adapted_v2/README.md)을 공통 사용한다. 별도 시험 프로필로 ID49 판 중심을 지상 140 mm에 놓아 하단 115 mm가 광축 75 mm보다 40 mm 높게 했다. 판/가로벽은 레이저를 가리지 않고 정후방 중앙에 마스크가 없다. 좌우 뒤 Ø7 지주와 같은 중심에 가상 Ø2 선을 놓아 같은 4개 방위만 가리는 간소화다. 마스크 여유는 양쪽 0.5°. 실장 분석의 외경 9.4/10.5 mm 관이나 실제 타이어·변속기를 주행 모형에 넣은 것이 아니다. 차량 외곽·질량·보호 정지는 원래 시험과 같다.

JR50도 충돌 표본 0, 실제 정지·정상 종료였다. 직선 증속 조건은 **1,539/1,561회** 열렸다. JR은 C50보다 17.66초, C65보다 16.19초 빨랐다. 각 한 번의 시뮬레이션 결과다. 정면 시야가 코드의 증속 조건을 충족하는지가 드러났으며, 구조 자체의 최고 속도나 새 속도 정책을 작성한 뒤의 차이를 규정하지 않는다.

C30도 충돌 표본 0, 정지·종료 정상으로 완주했다(증속 0/2,505회). C30→C50은 0.714초, C50→C65는 1.468초 짧았다. C50을 목업 기준으로 삼는 이유는 전방 연속 시야가 C30보다 약 25° 넓으면서도 본체 앞 22.2 mm를 남기기 때문이다. C30은 앞 공간 우선 시 가능한 대안이고 C65는 속도 상향을 해결하지 못하면서 7.2 mm밖에 남기지 않는다. +55/+60은 구멍 또는 슬롯 조절 후보이지 직접 달린 위치가 아니다. 각 배치 1회뿐이라 C 안에서의 1~2초 차이를 반복 가능한 효과나 최적점으로 확정하지 않는다.

C50과 C65는 각각 한 번 완주했고, 두 실행 모두 실제 정지·정상 종료, 충돌 표본 0이었다. 이번 C65의 랩이 1.468초(2.9%) 짧았으나 반복 시험이 아니다. C65에는 전방 결측으로 독립 보호층이 제한한 구간 약 0.092초가 있었다. 두 안의 [속도 게이트와 구간별 시간](../lidar_packaging_v3/drive_diagnostics.json)을 보면 직선 증속 허용은 C50 0/2,429회, C65 0/2,361회였다. 현재 [직선 증속 조건](../../../../src/arena_autonomy/arena_autonomy/local_follow.py)은 전방 ±100°가 모두 반환이어야 한다. 지주가 가린 각을 NaN으로 유지하는 C에서는 경로를 추종하며 완주해도 이 조건이 닫힌다. **이는 C 하드웨어의 속도 한계가 아니다.** 기둥이 가린 공간을 자유로 간주하지 않으면서 속도를 높이는 경로별 조건은 별도 개발 범위다.

초기 C50은 전선 좌표가 지주보다 좌우로 10 mm 안쪽이었다. [원래 입력](profiles/c50_initial_wire_misaligned.yaml)·[등록](c50_1_registered.json)·[평가](c50_1_eval.json)·[종료](c50_1.exit)를 보존했다. 이 별도 조건에서 48.853초, 1랩·충돌 표본 0이었다. 후처리 후 셸 마지막 줄의 CRLF 오류는 실제 시뮬 종료 0과 구별해 보존했다. 초기 C50은 동일 배치 반복도, 정렬한 후속 시험 결과도 아니다. [이전 C30 15.998 m](../lidar_mount_adapted_v2/README.md)는 판이 가렸던 다른 조건이다. [v1 JR의 33.853초](../lidar_mount_performance_v1/README.md)도 여기서 측정한 랩처럼 섞지 않는다.
