# 두 앞차·지주·마커 누락·비정형 상대의 결합 대표

2026-11-10 준비·실행 완료. [시설 두 앞차](../facility_traffic_stability_v1/README.md)에서 실제47.90m 한 랩과 접촉0을 확인했고, 같은 문서의 C7과 기존 중속 상대에서는 오목한 옆면을 따로 확인했다. 저장 입력의 결합 설정1,800판단도 기존 명령과 같았다. 아래 한 번의 실행에서 이 요소들이 함께 있을 때 주행이 유지되는지 확인했다. 원 실패를 지우거나 독립5대 경기로 해석하지 않는다.

- 앞차 두 대0.8m/s,60초, 전체 신호/마커 지주, ID20/30 영상 누락, 기존 노면·차량·센서·상태/속도·독립 보호를 유지한다. 카메라 최종 높이 시험은 아니다.
- **주 상대의 라이다에 보이는 옆면만** 기존 `recessed_sides`로 바꾼다. 원 외접 충돌 상자·동역학은 유지하며 두 번째 상대는 기존 상자다. 형상의 종류를 무한히 추가하지 않는다.
- 원래 시설 판정(거리44.64m 이상, 최장저속2.5초 이하, 상대0.08m, 최대두바퀴잔디, 시설/차량접촉0, STOP·정상종료·소스/입력 불변)을 그대로 재사용한다. 원report의 실패 항목은 별도 보존한다.
- 실제 C1 오목면 반환2개·스캔2개 이상, 원 상자 중앙면보다 많은 반환, ±10ms 자세 시각 대조·원 비시각/충돌 구성 보존을 기존 형상 평가기로 확인한다.

직전 r61 코너 결과를 먼저 검토한다. 그 결과와 별개로 유효한 코드 상태가 확보된 뒤 실행하며, 코너 실패를 덮기 위한 다른 시험으로 취급하지 않는다. 이 대표가 성립하면 시설/형상의 동일 장면을 반복하지 않고 운영 재개·상대 감속 등 아직 부족한 실제 상황과 실물 이관 준비를 비교해 다음 순서를 정한다.

**실행 준비 검토:** r61 코너는 실제채택0·9.95m 실패로 남았고 효과 없는 연결을 r62로 제거했다. `run.py`는 현재 선택기가 실제 C6의r60 바이트와 같은지 확인한다. 형상 정적 검사에서는 움직임·충돌·센서/비시각 설정 불변, 주상대3시각도형·추가상대1도형을 확인했다([정적 결과](setup_check.json)). 추가상대가 주상대의 윤곽 설정을 상속하지 않도록 명시 `box`를 사용한다. 복원 관련검사 후 같은1회 대표를 실행한다.

## 실제 결과

복원 관련64검사 뒤 60초 주행에서 **47.84 m·거리 한 랩·접촉/노면 이탈0**을 확인했다. 출발 후 최장0.05m/s 미만 구간은0.201초였고, 시설/차량과 겹친 표본은0이었다. 실제 주행 시각은7.401–67.401초이며 67.4초를 주행 시간으로 세지 않는다.

- 상대 최소 표본/스윕 간격0.7237/0.7224m, 지주/발판 중 최소간격은 ID20 발판 약0.2204m다. 시설 동일성·마커20/30 누락·실제 영상 출발과 전체 시설 대표 평가를 통과했다.
- 실제 C1 오목면 반환812개/139스캔, 기존 상자 중앙 옆면 반환0개, ±10ms 대조 유지와 비시각/충돌 구성 불변을 확인했다. 비정형 옆면 한 종류이며 실제 차량 전체 형상의 보장이 아니다.
- 명시 STOP 정착0.958초·변위0.1292m, 모든 STOP 검사·정상 종료·원 소스/추가 소스 불변·잔여 프로세스0이다.
- **원 report는 최종 앞차 간격 항목 실패**로 남고 실행기 종료값도1이다. 별도 시설/주행 대표 통과로 원 판정을 바꾸지 않는다.

대표를 마쳤으므로 같은 시설/형상 한 랩을 반복하지 않는다. 짧은 정지0.201초와 0.3초 창의 속도 손실(최대 약0.691m/s)은 남아 있으며, 모두 위험이 없는 감속이라고 단정하지 않는다. 다음은 [실제 앞차 정지·재출발과 시설의 결합](../restart_recessed_facility_v1/README.md)에서 필요한 제동과 지속 정지를 분리한다. 별도 코너 병렬 실패도 미해결로 유지한다.
