# 코너에서 실제 동행하는 상대 — 제한 대표 준비

2026-11-10. 시설·비정형 상대 묶음 뒤 이어갈 미완성 대표다. 추가 증속이나 빠른 추월의 개발이 아니라, 현재 속도에서 옆차와 함께 도는 동안 접촉·불필요 정지가 발생하는지 확인한다. 제어기는 r60 그대로다.

## 이전 결과와 다른 점

[r48](../../2026-11-08/observed_corner_continuity_r48_v1/README.md)은 코너 출구까지 진행했고 접촉이 없었지만, 실제 동행은0.301초로 사전0.5초 조건에 미달했다. 바깥 상대는 반경0.845m의 긴 경로를0.15m/s로 돌고 자차는 더 짧은 안쪽 경로에서 약0.3–0.5m/s로 움직여, 상대가 뒤로 빠졌다. 당시 실패를 성공으로 바꾸지 않는다.

새 상대는 직선0.33m/s에서 코너0.50m/s로 고정 각본에 따라 변속한다. 0.1초마다 약0.04–0.05m/s씩 전이하고 위치·방향은 연속이다. 현재 자차를 따라 움직이도록 평가 정답을 제어에 주지 않는다. 상대 자체는 기존처럼 `set_pose`로 움직이는 강체 상자이며 실제 상대 차량 제어/가속 동역학은 아니다.

기존 자차 기록에 새 상대 각본을 겹친 **사전 만남 분석**에서 직선0.30/0.33/0.35m/s를 비교했다. 선택한0.33m/s는 동행0.805초·코너 차체 간격 최소0.151m였다. 새 자차는 센서 입력에 따라 달리 움직이므로 이것은 실제 동행/비접촉 증명이 아니다. 앞선0.6m 출구 초안은 `preview_*.json`으로 보존했고, 실제 시험은 출구 진행 확인을 위해 기존 허용1.2m 안의1.1m 출구를 사용한다. 초안으로 시뮬레이션을 수행하지 않았다.

## 실행 전 고정 범위

- 기존 오른쪽 배치(-0.34m)·초기 종방향(-0.15m), 첫90°코너, C1/B0390/JR60P20, 교통1.5m/s 설정, 노면·동역학·독립 보호·STOP은 유지한다.
- 평가 상대의 경로는5mm 간격으로 벽 접촉 없음·최대두바퀴잔디를 검사한다. 평가용 가상 바퀴 위치이며 실물 타이어 검사가 아니다.
- r48의 코너 평가기 원본을 해시 확인해 그대로 사용한다: **20–70° 코너에서0.5초 이상 실제 동행**, 출구/방향·10.5m 진행, 출발 이후 최장저속2.5초 이하, 간격0.08m 이상, 접촉0·최대두바퀴잔디·명시STOP·정상종료·소스불변.
- 기존 원 추종 평가도 보존한다. 상대 뒤 유지/15cm 등과 다른 별도 목표를 통과해도 원 실패를 덮어쓰지 않는다.
- 이번 코너 구성에는 새 임시 기둥·마커 누락을 추가하지 않는다. 시설 대표는 앞선 별도 시험이고 모든 조건의 동시 검증은 아니다.

`run.sh`로 **한 번** 실행한다. 실제 동행이 다시 성립하지 않으면 그 실패를 남기고 각본을 성공할 때까지 반복 조정하지 않는다. 접촉·긴 정지 등 실제 제어 문제이면 해당 센서/판단 기록을 분석한 뒤 수정 필요성과 우선순위를 정한다. 신호 카메라의 최종 높이·배치는 이번 범위가 아니다.

기하 검사·실행기 문법 검사 뒤 GPT-6 Luna가 등록된 한 번 주행을 실행·회수했다. [설정](new_track_course.json)·[기하/저장 궤적 대조](geometry.json)·[직전 시설 묶음](../facility_traffic_stability_v1/README.md).

## 실제 결과: 코너 중간 정지·출구 실패

원 report와 별도 코너 평가는 모두 실패다. **9.91m 진행, 최종 코너 회전 약47°, 출구 미도달, 실제 동행0초**였다. 코너에 도달하지 않은 시험은 아니다. 진입 전 짧은 정지들이 생겼고, 마지막에는 코너 중간에서 멈춰 상대가 먼저 떠났다. 사전 저장 궤적의 동행0.805초를 실제 결과로 쓰지 않는다.

- 출발 후 최장0.05m/s 미만2.313초. 등록2.5초 이하 항목만 통과했고 코너/진행/실제동행 항목은 실패다. 시험 종료까지 멈춰 있었으므로 긴 정지가 해결된 것으로 해석하지 않는다.
- 차량 표본/스윕 간격 약0.100000/0.099999m, 접촉·겹침0, 바퀴 노면이탈0.
- 명시 STOP 정착0.5초·변위0.000081m, 정상 종료·소스/사본불변·잔여 프로세스 없음. 이미 정지한 상태에서의 STOP이며 제동 성능의 개선을 뜻하지 않는다.

근거: [원 report](run1/report.json)·[별도 평가](assessment_run1.json)·[연속성](continuity.json)·[실제 동행 좌표](corner_pairs.json). 같은 각본을 반복하지 않고 정지 원인을 분석한다.

### 첫 분석과 다음 확인

34.7–37.1초에는 경계 미확정과 측방 경로 거절이 번갈아 나타났다. 38.82초 이후에는 오른쪽 상대 통과/측방 해제 상태가 이미 성립했고 현재 G1 경로도 양수였으나, 선택기의 큰 이동 영역에서 미관측이 남아 `large_motion_region_unobserved`로 정지했다. 39.32초에는 현재 경로1.08m, 검사거리0.312m, 미관측615표본이었다. 독립 보호층은 `clear`였지만 이것만으로 그615표본을 안전하다고 지우지는 않는다.

`probe_release_region.py`는 원명령을 그대로 재현하면서 더 낮은 목표0.35/0.20m/s의 동일 영역 검사를 별도로 수행한다. 실제 측정속도·조향·가림/점유 판정은 유지한다. 낮춘 목표에서도 막히면 그 근거를 확인하고, 관측된 짧은 진행이 성립할 때만 후보 구현을 검토한다. 아직 생산 코드 변경이나 후속 주행은 하지 않았다.

**낮은 목표의 결과:** 원1,732명령 일치·소스 불변이며35개 스캔의70후보 모두 미관측 거절이었다. 첫38.82초의 미관측은 차체 후반 왼쪽 옆면 밖 약0.54mm, 정지 뒤39.82초는 최대4.50mm였다. 0.20m/s로 낮춰도 같은 종류의 영역이 남는다. 이 크기만으로 안전하다고 채택하지 않는다. 현재 점유 팽창·광선 이웃 상태·기존 후반 무반환 제한을 분리한 읽기 전용 진단 결과는 아래와 같다. [1차 영역 대조](release_region_probe/summary.json).

**광선/상태 분리 결과:** [광선 진단](released_sweep_probe/summary.json)은70후보 중68개가 기존3° 무반환 범위를 초과했다. 나머지2개는 실제 속도가0.35m/s를 넘어1cm 후보에서는 거절됐지만, 기존1mm 후반부 검사의 실제 측정속도 기반 영역은 통과했다. 그 결과와 [확정 통과 shadow 비교](confirmed_fringe_probe/summary.json)는 원1,732명령 불변이며38.82/38.84초 두 판단만 기존1mm/3° 조건을 통과했다. 후반 넓은 결측은 여전히 거절이다.

통과 직후에만 허용하던 기존1mm 검사를 더 확실한 통과 상태에도 적용하는 [r61 연결·검증](../confirmed_passage_fringe_r61_v1/README.md)을 수행했다. 같은 코너1회에서 새 분기 채택0·출구 미도달로 실패해 r62에서 현재 코드의 해당 분기를 제거했다. 이 보고서의 실패·원시 입력·사본은 수정하지 않는다. 목표를 낮추기만 해서 통과한 것으로 해석하지 않는다.

### 이전 광선 지지와 더 작은 조향의 읽기 전용 확인

[이전 광선 대조](recent_rear_support_probe/summary.json)는 원1,732명령을 그대로 재현했다. 최초 미관측 정지의6개 스캔에서 후반부 질의는 모두 기존1cm 범위였고, 현재 가까운 점유 반환은 없었다. 일부 시각에는 과거 실제 광선이25–475표본을 지지했지만, 과거 unknown/masked 영역에서 현재 질의까지 기존 이동 상계로 접근할 가능성을 제거할 수 없어 **최종 지지0**이었다. 가까운 물체를 실제 검출했다는 뜻과 구별한다. 현행 검사상 이전 관측만으로 정지를 해소할 근거는 없다. 원시 입력과 생산 소스는 불변이다.

`probe_alternative_steering.py`의 [읽기 전용 결과](alternative_steering_probe/summary.json)는 원1,732명령을 그대로 재현했다. 원 조향의100/75/50/25/0%와 목표0.2m/s를 대조했으며, 움직이는3스캔에는 대안이 없었다. 모터축 속도0인3스캔에서는 별도로 바퀴를 직진각으로 정렬했다고 가정한 경우만 이동 영역·경로 기하·바퀴 외곽 검사를 통과했다. 실제 이전각을 함께 검사하면 모두 거절됐다. 실제 차체 정지·서보 정착이나 새 명령의 허가가 아니며, 생산 코드·코너 주행은 바꾸지 않았다. 해당 가설 구현보다 별도 앞차 재출발 결합 시험에서 발견한 약10초 정체를 우선 분석한다.
