# 측방 감지 순간의 고정 저속 상한 — 저장 입력 비교

2026-11-10 읽기 전용 설계·스크립트 준비까지만 완료했다. 시설+C1 시험 뒤 사용자 중단 요청에 따라 **미실행**으로 남겼다. 결과 폴더나 재생 통과 근거는 없으며 생산 코드·새 주행 명령은 변경하지 않았다. 재개 시 먼저 시설+C1의 약20m 정체를 검토하고 이 비교의 우선순위를 판단한다.

[시설 합류 대표](../cut_in_recessed_facility_v1/README.md)는 접촉과 정지 없이 추종했지만, 측방 감지 순간 명령이1.5→0.35m/s로 바뀌어0.302초 동안 차체속도1.430→0.400m/s가 됐다. 독립 보호는 `clear`였고 평행추종의 고정0.35m/s 상한이 첫 감속 명령을 결정했다. 더 낮은 최소간격이나 unknown 허용으로 해결하지 않는다.

현재 경로가 있고 정상적으로 선택된 평행추종·GUARD·측정속도0.45m/s 초과에서만 기존 `measured_parallel_speed_trial.proposal`에0.5/0.7/1.0m/s 상한을 대입한다. 해당 함수의 현재/직전 조향·전체점유/시차팽창·1cm 횡변위·제동/간격 제한을 유지하고, 실제 측정속도와 목표 중 큰 값의 이동영역 관측·노면/측방 기하를 별도로 검사한다. 목표는 원 G1의 양수속도와 설정 최대속도를 넘지 않는다. 원 선택이 정지이면 후보를 내지 않는다.

결과는 **같은 저장 상태에서 여유가 있었는가**이며 더 빠른 출력을 실제 채택하거나 전체 궤적/제동 안전을 증명하는 것이 아니다. 코너·입력고장·가까운 앞차·미관측 때문에 막히는 상태의 보호를 완화하지 않는다. 성립 후보가 있더라도 실제 연결 전 상대 횡방향 접근과 긴급 제동을 포함한 별도 설계·회귀가 필요하다. 목표는 최고속도 상향이 아니라 관측 근거가 충분한 감속의 연속성이다.
