# 앞차 정지·재출발과 시설의 결합 대표

2026-11-10 실제 1회 실행. **앞차 재출발 후에도 우회 도중 정지해 실패**했다. 추가 증속보다 현재 속도에서의 비접촉과 불필요 정지 감소를 우선한다.

[기존 재출발](../../2026-11-08/rear_face_restart_v1/README.md)의 중앙 앞차 0.50 m/s → 3–8초 정지 → 0.50 m/s 재출발, 총 18초를 그대로 사용한다. 최신 제어기에서 신호·마커 지주와 ID20/30 누락, 앞차의 오목한 시각 옆면을 함께 적용한다. 원래 외접 충돌 상자와 속도·센서·노면·독립 보호층은 유지한다. 여러 변경을 결합한 대표이므로 이전 결과와의 차이를 특정 변경 하나의 효과로 주장하지 않는다.

- 이전 재출발 평가기의 관측된 실제 정지·재출발, 재출발 후 2.5초 이내 진행, 이후 1 m 이상 진행, 최장 저속 2.5초 이하, 마지막 2초 0.5 m 이상 진행, 본선 복귀·FOLLOW·비접촉·최소 0.08 m 간격·최대 두 바퀴 잔디·STOP·정상 종료 기준을 재사용한다.
- 실행 월드의 신호 지주·발판 4개와 임시 마커 지주의 동일성, 고밀도 자차 자세의 시설 겹침 0, 원시 입력/추가 소스 불변을 확인한다. 짧은 직선 장면이므로 먼 갈림길 마커 앞까지 통과했다는 뜻은 아니다.
- 앞차의 C1 오목면 반환과 원래 비시각/충돌 구성 보존은 기존 형상 평가기로 확인한다. 최소 반환 2개·서로 다른 스캔 2개·기존 상자 중앙면보다 많은 반환·±10 ms 대조 기준도 유지한다.
- 감속 구간은 당시 실제 간격·판단 이유와 함께 기록한다. 앞차의 실제 정지에 따른 필요한 제동과, 앞차가 다시 진행하는데도 지속되는 불필요 정지를 구분한다. 상대는 각본으로 위치를 갱신하는 모델이며 실차 급제동 동역학 재현이 아니다.

`run.sh` 한 번만 실행하며 실패하면 원인과 증거를 남긴다. 이전 원 report의 HOLD·15 cm·도로 안·뒤 유지 등 실패를 덮어쓰지 않는다. 새 보호 조건이나 기본값 변경은 없다.

## 실행 결과와 진단

[결합 평가](moving_stop_restart/assessment.json)에서 진행은 2.417 m, 최종 BYPASS였다. 앞차는 예정대로 녹색 이후 약 8.019초에 다시 움직였으나 자차의 이후 진행은 0.0052 m, 재출발 후 최장 저속은 9.908초였다. 전체 최장 저속은 11.120초다. 복귀·FOLLOW·재출발·진행 목표를 실패로 유지한다. 마지막 20개 차체 표본은 도로 밖 부분이 있었으며, 바퀴 기준은 최대 두 바퀴 잔디 이내였다.

접촉·시설 겹침은 없고 상대 최소 간격은 표본 0.47624 m/스윕 0.47622 m였다. 원시·추가 소스 불변, 신호/마커 지주 동일성, 실제 B0390 신호 출발, STOP·정상 종료를 확인했다. STOP은 이미 멈춘 상태에서 수행했으므로 제동 성능의 증거가 아니다. 오목면 반환은 33개/21스캔, 원래 상자 중앙면 반환0이며 ±10 ms 대조도 통과했다. 원 평가의 실패를 보충 검사 통과로 덮지 않는다.

정지 중 제어기는 우회 `entry` 단계에 머물렀다. 정상 G1은 경계 미확정, 우회 경로는 현재 점유 여유 0.04 m 때문에 속도0을 냈다. 측정 속도나 미관측 공간을 바꿔 해결할 상황으로 보지 않고, `probe_blocking_path.py`에서 실제 제동 반환점과 현재 외벽으로 만든 중앙 복귀 후보를 저장 입력으로 비교한다. 당시 코드의 복귀는 목표 편이에 도달하고 방향을 맞춘 뒤에만 시작한다. 이 선행 조건이 시설 앞 우회 중 재출발에 맞지 않는지 조사 중이며, [반환점 대조](blocking_path_probe/summary.json)에서 지배 반환점의 평가 세계좌표는 x=10.16–10.18m/y=6.137–6.146m로 오른쪽 신호 지주에 일치했다. 원926명령은 그대로 재현했다. [복귀 띠 비교](return_band_probe/summary.json)에서도 원926명령 불변과12.32–13.02초의8스캔에서 현재복귀띠 지지를 확인했다. 생산 코드 변경과 새 주행 결과는 [r63](../observed_entry_return_r63_v1/README.md)에 따로 남긴다.
