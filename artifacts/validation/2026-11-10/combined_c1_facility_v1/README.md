# 시설·두 앞차·오목면·마커 누락과 기존 C1 오차의 결합

2026-11-10 실제 1회와 후처리를 마쳤다. **20.21 m·최장 저속 10.464초로 한 랩/지속 주행에 실패했다.** 사용자 중단 요청에 따라 추가 재생·수정·재실행은 하지 않았다.

[같은 시설 결합 대표](../combined_recessed_facility_v1/README.md)는 추가 거리 오차 없이47.84m·최장저속0.201초·접촉/노면이탈0을 확인했다. 현재의 시설 앞 복귀 코드에도 실물에 가까운 대표 오차가 영향을 주는지 확인하기 위해 [이전 r38 시험](../../2026-11-08/masked_motion_speed_v1/README.md)의 **균등 ±3cm·추가지연50±20ms·seed23**만 적용한다. 새로운 극단 잡음 종류나 계수를 추가하지 않는다.

기준 두0.8m/s 각본 상대·60초·상대 시각 형상·610mm 코스·임시 신호/마커 지주·ID20/30 영상누락·노면·감속비·보호·속도는 유지한다. 최신 r65는 r63 실행 바이트이고 시설 앞 조기 복귀를 포함하므로, 이전 주행과 완전한 단일변수 성능 비교로 부르지 않는다. 원 report는 보존하고 기존 별도 목표(44.64m 이상, 출발 뒤 최장저속2.5초 이하, 최소간격0.08m, 접촉/겹침0, 최대두바퀴잔디, STOP/정상종료/소스불변)를 그대로 재사용한다.

추가로 실제 주입 설정·오차/지연 범위·취득과 수신1:1·판단 기록 완결성과 형상/시설 일치를 확인한다. ±3cm 오차는25mm 오목면 차이보다 크므로, 기존8mm 분류기로 얻는 오목면/옛상자면 반환 수는 **진단으로만 보존하고 형상 관측의 새 성공 근거로 쓰지 않는다.** 이 시험의 형상 조건은 실행 SDF·원래 충돌 상자 일치이며, 명확한 오목면 관측은 앞선 무주입 대표 근거와 구별한다. 현재 센서로 길을 못 찾는 실패가 나오면 원인을 남기고, 같은 실패를 성공할 때까지 반복하거나 새 속도 상향을 섞지 않는다. 아직 실물 각도·회전율·IMU 오차와 독립5대 경기를 검증하는 시험은 아니다.

## 실제 결과와 중단 지점

- [원 report](two_actor_run1/run1/report.json)와 [결합 평가](two_actor_run1/combined_assessment.json)는 실패다. 60초 동안 20.21 m를 진행했고, 한 랩·정체·최종 간격 목표를 충족하지 못했다. 접촉/겹침·벽 바퀴·차체/조향 노면 이탈 표본은 0이다. 최고속도는 1.556 m/s다.
- [연속성 기록](two_actor_run1/continuity.json)의 가장 긴 저속은 시뮬 42.887–53.351초, 진행거리 약20.05 m 부근의 10.464초다. 해당 구간 독립 보호는 `clear`였고, 529판단 중 517개가 0명령이다. 주요 원인은 출력상 `parallel_hold_baseline_unavailable`과 `parallel_hold_reference_not_straight`로 구분된다. 현재 경계 확보와 측방 상태의 관계를 아직 재생으로 분석하지 않았으므로 이를 곧바로 기둥 충돌 위험이나 거리 오차 하나의 원인으로 확정하지 않는다.
- 주입은 최대 절댓값 0.0299999 m, 추가 지연 32–70 ms로 기존 범위 안이다. 시험 창 내 2,991판단·599스캔의 취득/수신 대조와 기록 완결성을 확인했다. 첫 광선 취득부터 판단까지 나이는 중앙값0.197초·p95 0.257초다. 전체 기록에는 창 밖 취득 대조 누락2개가 별도로 남아 있으며 시험 창의 불일치0과 혼동하지 않는다.
- 실행 시설·ID20/30 누락·상대 시각 형상/원 충돌상자 일치를 확인했다. 잡음이 포함된 오목면 분류126반환/67스캔은 진단값일 뿐, 8mm 분류기의 형상 인식 성공으로 세지 않는다.
- 명시 STOP의 0.5초 정착 창은 67.82–68.32초, 최대속도0.0014m/s·변위0.000469m다. STOP/정상종료·모든 자식 exit0·잔여 ROS/Gazebo 프로세스 없음이 확인됐다. 실행기 종료1은 주행 실패이며 종료 실패가 아니다.

**기록 무결성 주의:** [원 추가 무결성](two_actor_run1/extra_integrity.json)은 README 한 파일 변경을 기록했고 시설 평가의 `source_unchanged`는 false다. 준비 문장을 진행 중 문장으로 갱신한 차이이며 이를 없애거나 성공으로 고치지 않았다. [종료 대조](closure_review/integrity_review.json)에서 추가 등록953개 중 차이는 README뿐이고, 원 실행 등록197개 소스는 모두 같다. 보관 ZIP도 불변이다. 변경 전후 README·diff를 보존했으며 파일 수정 시각만으로 변경 순서를 추정하지 않는다. 아래 결과 정리는 시험 종료 뒤 추가한 것이다.

다음 재개에서는 이 기록의 약20m 경로 미확정/측방 상태를 먼저 분리한다. 원인 변화 없는 동일 주행 재시도는 하지 않는다. 별도로 준비한 [고정 측방 감속 상한 비교](../guard_deceleration_probe_v1/README.md)는 사용자 중단 시점에 미실행이었으며 그대로 보류했다. 이번 실패는 이전 무주입 시설 한 랩이나 r38의 다른 시설 조건 오차 한 랩 성공을 소급해서 바꾸지 않는다.
