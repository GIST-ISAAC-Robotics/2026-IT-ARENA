# 코너 복구 후보의 자동 연결 복원

2026-11-10 r64는 실제 코너1회에서 후보 채택0·지속성/병렬 실패였다. 후보는 연구용 함수와 검사로 보존하고 `local_follow.py`와 `pass_release_trial.py` 실행 바이트는 r63 시점으로 복원한다. 별도 속도·보호·물성 변경은 없다. r63의 시설 앞 조기 복귀는 유지한다.

[r64 조건 감사](../released_straight_recovery_r64_v1/activation_audit.json)는1,745명령 불일치0·소스/입력불변이다. 후보 호출은 정상 연결되어 있었다. 39.42초에는 측정속도0.813m/s가 범위 밖,39.52초에는0.244m/s에서 직전 조향의 이동영역이 미관측이었고 정지 전이 조건에도 해당하지 않았다. 40.82초 정지 시점에는 기본 경로가 `follow_release_wait`로 바뀌어 후보 범위 밖이었다. 정상적인 전진/통과 확인 조건을 넓혀 이 실패를 억지로 통과시키지 않는다.

복원 전 바이트는 `before_r65.zip`, 후속 해시 계약은 `config/tests/released_straight_restore_r65_sha256.json`에 둔다. r64의 첫 실험·저장 재생·후보 테스트를 삭제하거나 성공으로 바꾸지 않는다. 연결만을 시험하던 테스트는 복원 전 사본에 보존했고 순수 후보의 관측/점유/정지 경계 검사는 유지한다.

관련 회귀와 실행 바이트 동일성을 확인한 다음, 같은 코너를 다시 돌리지 않고 준비한 시설·비정형 상대의 전방 합류 대표로 진행한다. 코너 병렬의 현재 경로 확보와 지속성은 미해결이며, 빠른 추월·P21·실물 과제도 유지한다.

복원 뒤 [관련 회귀](tests.log)는414개 통과했다. 실행 바이트는 r63 보관본과 같고, 이후 시설·비정형 합류1회에서 접촉0·지속추종·STOP/정상종료를 확인했다. 해당 합류의 사전 강도 조건 미달은 별도 실패로 유지한다.
