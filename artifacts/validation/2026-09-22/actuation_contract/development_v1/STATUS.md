# 최초 실행의 미완료 기록

2026-09-22. 고정 시간 10조건 JSON은 생성됐고 개별 판정은 통과했다. 이어 Windows `multiprocessing.Pipe()` 생성에서 `PermissionError: [WinError 5]`가 발생해 별도 프로세스 시험과 전체 보고서 생성이 완료되지 않았다.

실제 모터/보드/네트워크를 사용한 실행이 아니며, 이 오류는 로컬 IPC 생성 권한 오류다. 도구를 수정해 이후 초기화 실패도 결과에 보존하도록 했다. 재실행 v2 이후 숫자 입력 예외까지 보완한 최종 판정은 [windows_v3/report.json](../windows_v3/report.json)을 사용한다. 이 폴더를 최종 소스의 전체 통과 결과로 표현하지 않는다.
