# 구동 계약 A1-1 검증

2026-09-22. 실물/코스가 아닌 **PC 참조 프로토콜·단순 종방향 모형** 검증이다.

- [최종 windows_v3](windows_v3/report.json): 11/11조건 통과. 단위 검사 38개·WSL 전체 회귀 340개, 별도 프로세스 정상 종료·잔존 없음.
- [검사 요약](windows_v3/regression_summary.txt), [설계/해석](../../../../docs/hardware/ACTUATION_CONTRACT_2026_09_22.md).
- `windows_v2/`: 큰 정수 입력 예외 보완 전 37개/11조건/전체 339개 통과 기록. 최종 파일 해시와 구분한다.
- `development_v1/`: 결정론적 10조건 뒤 Windows IPC 초기화 권한 오류가 발생한 최초 기록. 전체 시험 완료가 아니며 삭제/덮어쓰지 않았다.

각 조건 JSON에는 시간·상태·원시 엔코더 카운트·목표/모형 속도·정규화 출력·명령 거절과 상태 전환을 보존한다. `report.json`은 소스 SHA-256과 임시 설정을 포함한다. 단순 모형의 제동/속도 값을 실차 성능으로 사용하지 않는다.
