# r502 옆차 주행의 동일 경로 주시거리 보완

2026-11-14. r499의 실패는 관측 불확실성이 아닌 **긴 주시거리로 만든 현재 조향 원호가 신호등 지주의 반환점과 만난 경우**였다. 실제 저장 입력126개를 원 순서/generation으로 재생해 기존126판단을 먼저 재현했다. 171개 현재 외벽 반환으로 기억 경로 자체는 재확인됐으나, 최초 정지의 충돌점5개는 평가상 신호등 지주에 속했다. 상대 actor 정답은 원인 분류에만 쓰고 대회 제어기에 입력하지 않았다.

## 변경

`MovingPassGuide`의 현재 선택 정책에서 점유 제동 때문에 감속하는 경우에만 같은 관측 경로의24cm 목표점을 한 번 더 비교한다. 원 경로의 길이/곡률 상한, 실제 직전 조향의 변화율, 모든 점유 반환/팽창 여유와 제동식은 유지한다. 현재 경로 자체나 목표 편이를 옮기지 않고 더 높은 양수 명령이 실제 비교를 통과한 경우만 선택한다. 기존 속도가 충분하거나 현재 벽 기준이 없거나 복귀 추종 간격이 적용 중이면 이 비교를 하지 않는다. 18/12cm 추가 탐색과 정지 상태의 가상 조향 정렬은 연결하지 않았다.
