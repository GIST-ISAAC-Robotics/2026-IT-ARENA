# 실측 서보 범위 반영 후 단독 코너·랩 확인

사용자11/14 서보 실측 범위 반영 요청에 따라 r541의 실제 count 선택과 r542의 CAD 파생 차량 설정을 사용한다. 바퀴각 실측은 아니다. 기존 대칭 인터페이스에서 중앙 명령상한 약16.315도이며 이전 완주r475 양수 표본486개 중95개가 이를 넘었다. 단순 포화가 완주를 유지한다고 가정하지 않는다.

r539의 동일조건 교통 비교를 회수한 후 r534 준비 레시피를 새 실측 조향 파생 설정에 연결해 단독1회를 수행한다. 첫 직선의 굴곡·틈, 속도/물성/제동, 원 판정과 STOP/정상 종료는 유지한다. 실행 전 최종 소스와 모델을 동결한다. 결과가 없을 때 통과나 코너 실패로 단정하지 않으며, 실패 시 원인을 분석하고 같은 조건을 무작정 반복하지 않는다.

현재 실행0. 상대/신호/물리장치/Jetson 접속0이며 source-only 준비다.
