# 경기 종료 저장소 정리 검증 — 2026-11-14

## 사용자 결정과 변경

경기 당시 MCU가 없고 Jetson 장치도 연결되지 않아 움직임이 없었다는 사용자 보고를 기록했다. 공식 판정·고장 인과관계는 추정하지 않았다. 대회용 최종 기준은 기존 ESP32 버전이며 UNO Q는 미사용 대체안, 후속 시뮬레이션은 별도 개발 이력이다. 세부 후기는 빈 항목으로 남겼다.

현재 코드·설정·미게시 시험 근거를 보존하고 탐색 경로를 정리했다. 실행 중단 상태를 새 개발 지시로 바꾸지 않았으며 장치 접속·flash·MCU 출력·빌드·ROS/Gazebo·주행 시험은 하지 않았다. 이번 검사 결과를 실제 차량의 안전/작동이나 새 전체 회귀 통과로 해석하지 않는다.

## 범위와 한계

공개 색인은 기존 추적 파일과 이번 선택 파일의 목록이다. 로컬 전용 목록은 이번 정리에서 새로 제외한 프로젝트 자료만 다루며 전체 디스크·이전부터 제외한 원시 bag·WSL 환경의 백업이 아니다. ESP32 최종 ZIP은 source-only/install_pending이며 실측 PI·보드·포트 입력이 미완료다. 예전 r387 BIN을 이 ZIP과 동일한 최종 바이너리로 표시하지 않는다.

원시 고빈도 로그·재설치 의존성·임시 pytest 작업 폴더/심볼릭 링크·원시 UART·대용량 CAD는 삭제 없이 로컬에 남겼다. GitHub에서 전체 원시 재생이 가능하다고 표시하지 않는다.
