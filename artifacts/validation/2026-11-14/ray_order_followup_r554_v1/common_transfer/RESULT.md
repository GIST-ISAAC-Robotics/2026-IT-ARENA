# r554 추월 최초 벽 기준의 광선 방향 연결

r553 정상 종료·WSL 반환 후 공통 `observed_straight_wall` 한 곳에 stage 변경을 반영했다. 실제 반환점과 같은 순서의 방향을 만들고 같은 부분집합 마스크를 적용한다. 원시 점유·UNKNOWN·상대 구조를 지우지 않는다. 현재 추월 진행 중의 별도 tracked-wall 함수는 변경하지 않았다.

[stage 원점/전방66mm 비교](../STAGE.md), [공통 SHA](manifest.json)를 보존했다. 실제 ROS 환경의 관련219검사 중 **217통과·2실패**다([원 JUnit](junit.xml)). 새 artifact 독립2대표, 진입·현재외벽·추월·복귀 검사들은 통과했다.

남은2실패는 기존 `G1G2Node`의 수동 `__new__` fixture에 `decision_delivery`가 없다는 오류와 현재는 override된 `control`이 옛 부모 메서드와 동일해야 한다는 기대다. 두 node/launch 파일은 이번 변경 대상이 아니며, 실제 현재 ROS 연결 검증과 오래된 fixture 기대를 구별한다. 원 실패를 지우거나 전체219통과로 기록하지 않는다. 이관 근거는 이번 함수에 대한 stage 비교와 관련217검사이며, ROS 전체 기능 통과나 새 교통 주행 결과가 아니다.

다음은 r555 희소 상부 상대 OFF 대표1회다. r553 단독 실패는 별도로 보존하며, 이번 변경을 r553에 적용한 것으로 기록하지 않는다. 장치 접근·설치·flash·커밋·푸시0이다.
