# r509 잔디 사용 선호 검토 — 현재 코드 변경 보류

2026-11-14. **현재는 잔디 관련 공통 수정 없이 보류를 권고한다.** 기존 순위에 작은 편이 선호가 이미 있고, 확인한 r499/r503 저장 후보에서 이를 앞당겨도 선택은 같았다. 현재 시설 앞 정체 수정을 우선한다.

**최신 사용자 정정:** 잔디는 사용해도 되며, 가능한 경로가 여럿일 때 덜 사용하는 쪽을 후순위로 선호한다. 회전/진행 중 잔디 때문에 정지시키지 않는다. 따라서 hard road cap·잔디 veto·추월 진입 강제 금지·새 정지 조건은 제안하지 않는다. 최초 검토의 도로 내 진입 제한 방향은 철회했다. 기존 유효 후보 fallback·점유/보호·벽 피팅·추월 상태기계를 유지한다.

## 실제 연결과 최소 변경 지점

검토 원문은 r507 동결본과 검토 시작 당시 공통의 SHA가 같은8파일이다([계보](source_reference.json)). 이후 root의 r512/r513 수정은 이 검토의 실행 근거에 섞지 않았다.

1. `BypassHandoffFollow.command()` → `MovingPassAdapter.command()` → `MovingPassGuide.evaluate()` → `available_pass_offsets()` → `EntryGuide`/`_compare_entries()` → `EntryIntent.select()` 순서다. 진입 전 후보가 없으면 `MovingPassAdapter.command()`의 기존 `_base_command()` 결과를 반환한다. 이미 추월 중의 유효 후보 소실 처리는 별도 상태이며 이 검토에서 바꾸지 않는다.
2. `local_follow.py`는 현재 관측 벽에서 `wall_offset_m`만큼 안쪽 경로를 만든다. 저장 설정은 벽 offset0.505m·도로 반폭0.305m다. 도로색/잔디를 검출하는 기능은 아니다.
3. `moving_pass.py:239–265`의 `available_pass_offsets()`는 벽↔앞차 간격과 기존 측정/시차 여유의 중앙에서 좌우 편이를 제안한다. `road_half_m`는 여기서 사용하지 않는다. `_compare_entries()` 역시 `road_surface_verified=false`를 명시한다. 별도 M3/측방 경로의 `surface_check()` 및 `two_wheel_grass` 설정을 MovingPass 전 구간의 도로 검증으로 해석하면 안 된다.
4. **가장 작은 수정 가능 지점은 `bypass_entry_trial.py:413–415`와 `467–469`의 후보 순위 키뿐이다.** 현재는 `진행거리2cm등급 → 반환점 여유5mm등급 → 작은 |offset| → 전이길이`다. 같은 진행거리 등급에서 작은 편이를 반환점 여유보다 먼저 비교하는 순서 변경은 가능하다. 기존 `eligible` 집합을 그대로 두므로 잔디를 이유로 후보를 제거하거나 속도를0으로 만들 필요가 없다. 다만 이것은 도로 중심 선호의 대리값이며 실제 잔디 접촉량 계산이 아니다. 공용 G2 비교에도 영향을 줄 수 있어 효과 근거 없이 지금 반영하지 않는다.

## 기존 저장 후보 2개 비교

새 제어 실행·상태 재생·경로 생성·시뮬 없이 각 기록의 첫 실제 진입 `seq537`에 이미 저장된 유효 후보 순위만 대조했다([수치](comparison_summary.json)).

| 사례 | 기존 선택 편이/전이 | 현재 반환 기준 전방 진행거리 | 작은 편이를 여유보다 먼저 비교 |
|---|---|---|---|
| r499 | +0.162505m / 1.2m | 직진0.557m, 편이1.553m | 선택 동일 |
| r503 | +0.162682m / 0.9m | 직진0.559m, 편이1.518m | 선택 동일 |

편이 후보들은 같은 측방값에서 전이길이만0.6/0.9/1.2m로 달랐다. 직진 후보는 현재 점유 기준 진행거리가 짧아 같은 진행거리 등급이 아니었다. 후속 추월 중에는 기억한 경로의 후보가 하나로 좁혀져 순위 변경으로 고를 대안도 없다. 따라서 이 작은 수정으로 시설 앞 점유 간섭·외벽 길이 부족 정체가 해결된다고 볼 근거가 없다.

기존 사용자2바퀴 허용과 새로 전달한 얇고 짧으며 고정이 약한 인조잔디 조각은 별개다. 전자는 허용 범위이고 후자는 사용자가 전달한 현장 위험으로, 실제 사진·고정력·마찰 측정은 하지 않았다. r503은 바퀴중심 도로밖0이지만 기존 평가기의 접지 근사(any)에서는 앞왼쪽1개가0.086초 걸쳤다. 이 평가는 제어 입력이 아니며 실제 접지/심판 판정도 아니다. 단순 편이0.163m가 직진 차체 한계0.230m보다 작다는 것만으로 회전 중 바퀴가 도로 안이라고 단정할 수 없다.

**보류 범위:** 새 잔디 비용 모듈·도로 경계 추정 확대·편이 clamp·벽 offset 재설정·주행 중 도로 veto는 만들지 않는다. 현장 도로폭/벽 간격이 저장 사양과 다르거나 벽 관측이 부족하면 도로 중심 해석도 불확실하다. UNKNOWN을 자유 공간으로 바꾸거나 지도/잔디 경계 정답을 입력하지 않는다. 추후 같은 진행능력의 서로 다른 편이 후보가 실제 기록에 나타나면 기존 두 순위 키의 작은 변경만 재검토할 수 있다.
