# r508 공통 이관

같은 운동 callback/검증으로 대기 표본을 먼저 소비하는2ms/64개 제한 drain을 G1·독립 guard 제어 진입에 연결했다. 제어 now는 소비 뒤에 읽고 원 stamp/순서/잔여 표본을 유지한다. 마지막 callback만큼2ms를 초과할 수 있으며 계측 최대는 약2.25ms다.

현재 경로의 기하·전체 점유·전방 반환 검사를 이미 마친 양수 결과가 실행 소비자에 필요한 current_route_proof를 누락하던 계약도 연결했다. 원 경로/현재 관측 시각을 새로 만들거나 만료 기준을 늘리지 않았다.

후보4파일 SHA 일치, 신규11개를 포함한 관련196고유검사를 확인했다. 첫134통과/62실패는 기존 guard 시험용 MotionInput에 drain_pending이 없어 발생했으며 fixture만 보완한62개 재검사가 통과했다. 최초 원 로그를 보존한다. SHM16은 이 코드 패치에 포함되지 않으며 실행별 선택이다. 현재 공통 전체를 실물 ROS에 설치·주행한 증거는 아직 아니다.
