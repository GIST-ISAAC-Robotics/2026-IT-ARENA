# 대회장 Wi-Fi 도구 공통 이관

11/14 r478 소스 동결 회수 후 신규 Wi-Fi 진입3파일과 기존 SSH의 선택형 stdin 전달4줄을 공통에 이관했다. 원본 SHA와 stage SHA를 먼저 대조했으며 [변경 파일](common_integration.json)에 이관 해시를 보존했다.

공통 경로로 import하는 기존 집중14검사가 모두 통과했다(0.034초). 이는 저장/복귀예약/명시확인과 비밀 전달의 모의 검사이며 실제 네트워크 전환 성공을 뜻하지 않는다. 이미 확인한 핫스팟 수동 접속과 이 새 도구의 실기 검증은 구분한다. Jetson 계산 시험과 겹쳐 네트워크 설정을 바꾸지 않았다.

사용법은 [접속 안내](../../../../../docs/hardware/JETSON_ACCESS.md#대회장-wi-fi를-노트북에서-등록전환)를 따른다. 현재 출력되는 등록·예약·확인 결과를 구별하고, 새 망에서 명시 확인하기 전까지 기존 핫스팟을 켜 둔다. 실제 대회장 AP 인증/단말 격리와 timer 복귀 실증은 후속이다.
