# r486 공통 이관

11/14 주 담당이 현재 관측의 중심 복귀 후보와 추종 간격 적용을 검토한 뒤 `moving_pass.py`, `bypass_entry_trial.py` 두 파일을 공통에 이관했다. 현재 타깃이 앞에 관측되고 기존 편이 경로가 실제 점유 제동에 제한될 때만 새 중심 경로를 비교한다. 실제 측정 속도와 원 점유·이동 영역 검사를 유지하며, 수락 시 경로와 복귀 상태를 함께 갱신한다. 원 판정의 임계값을 바꾸지 않았다.

같은 공통 생산 파일을 실제 import한 WSL/native 회귀 **185개가 통과**했다. 기존 moving-pass/medium/faster/entry/entry-guide와 저장 입력19·대형 trace가 필요 없는 신규4개를 포함한다. [실행 근거](../native_v1/receipt.json)와 원 로그를 보존했다. 신규4개를 `tests/test_moving_pass_current_return.py`로 이관했으며 테스트 내용은 통과한 stage와 byte 동일하다.

공통 변경 전 바이트·SHA와 적용 뒤 SHA는 [적용 기록](applied.json)에 남겼다. 기존 CRLF를 보존했다. 저장 입력에서 두 호출이 .35m/s로 복귀한 것은 실제 연속 복귀 성공이 아니며, 뒤 저장 입력의 거절도 보존한다. r478 동일 조건의 실제 교통1회는 r490으로 분리한다. r485의 별도 독립 보호 정지 문제는 r489에서 다룬다.
