# r528 실제 소실점 기억을 보존하는 독립 guard 저속 후보

2026-11-14. **stage 구현과21검사를 완료했다.** 선택된 현재 명령 보호 정책에서 `previous_point_in_missing_sweep` 래치 때문에만 차단된 경우, 전체 원 기억은 보존하면서 현재 자차좌표의 실제 기억점과 현재 raw 점유를 다시 검사한다. 미관측 기억이 남으면 목표 최대0.10m/s이며, 원 점 모두가 기존 실제 재관측 근거로 raw 점유에 인계된 경우에만 기존 요청속도 상한으로 복귀한다. 공통 소스에는 반영하지 않았다.

## 변경 범위

`candidate.patch`와 `integration_manifest.json`은 다음5파일의 최종 동결 후보를 담는다.

- 신규 `guard_memory_command.py`: 원 관측점·시각과 현재좌표 복사본, 명령별 두 조향/제동 검사.
- `traffic_recovery_trial.py`: 실제 최초 위협집합의 별도 기억 생성, 래치가 유지되는 동안 새로 소실된 원 반환의 추가 보존.
- `partial_observation.py`: 이미 래치 중인 경우 새 위협을 넘기는 작은 hook. 기본 구현은 no-op이므로 기존 비선택 정책은 바꾸지 않는다.
- `lidar_safety.py`: 현재 명령 정책이 선택됐고 특정 known-obstacle 래치일 때만 차단 직전 후보를 검사한다. 기존 최종 raw swept·제동·마커 점유·STOP/입력 차단은 후속에 남는다.
- 신규 `test_guard_memory_command.py`: 의미 있는 기능·정지·재관측·연속 상태 반례21개.

큰 추적기·물체 신원/속도 추정·새 전역 설정은 없다. 기존 `swept_limit`, `braking_speed`, `transport_points`, `front_evidence`, `short_observed_surface`를 재사용한다. 공개 구현/문서는 모델·도구 이름 외 개인 호칭을 포함하지 않는다.

## 허가 범위와 보존 조건

- 기존 `command_observation_priority=True`, 실제 `latched=True`, 래치 원인 `previous_point_in_missing_sweep`, 현재 partial 결과 `known_obstacle_latched`에만 적용한다. 이 외 관측/운동 오류나 다른 래치는 새 허가 대상이 아니다.
- 원 래치·`latch_evidence`·최초 원 위협점/기준시각은 그대로다. 현재좌표 복사본만 검증된 자차 운동으로 연속 운반한다. 알려지지 않은 공간을 free로 바꾸거나 가상 반환을 만들지 않는다.
- 래치 중 **새로 소실된 실제 반환도 보존**한다. 같은 원 scan/source-index만 중복 등록하지 않으며, 임의 FIFO/TTL 삭제나 넓은 거리 병합은 하지 않는다.
- 현재 실제 반환이20mm 이내이거나 기존20–40mm+짧은 실제 표면 근거를 만족하면 활성 계산만 현재 raw 점유 검사로 인계한다. 원 관측 증거는 별도 배열에 남는다. 새로 소실되면 기존 소실 hook으로 다시 등록된다.
- 옆/뒤에 있다는 이유만으로 기억을 제거하지 않는다. 미관측 활성 기억이 하나라도 남으면 저속 상한을 유지한다. **전부 실제 재관측된 경우만** `retained_memory_all_reobserved`로 구분하여 정상 상한을 복귀시킨다. 공식 래치 상태와 원 증거는 이때도 변경하지 않는다.
- source frame/epoch 변경, 시간 역행, 운동 이력 reset/공백/부족, 잘못된 원시 배열, 전방 반환 전체 소실은 허가되지 않는다. 입력 경계·기존 reset 계약을 유지한다. 명령0은0이며 만료/없는 명령/STOP을 새 양수로 만들지 않는다.

## 실제속도와 충돌 여유

새 목표를0.10m/s로 낮추더라도 외곽 계산에는 `max(|실측속도|, 목표속도)`를 사용한다. 기존2m/s² 제동식·반응시간·60mm 여유·40mm swept 표본 간격을 재사용하여 실제 속도에서 멈출 수 있는 범위를 검사한다. 높은 실측속도를 이유만으로 무조건0으로 만들지는 않는다.

- 현재 조향과 직전 조향을 모두 검사하며 현재 raw 점유와 현재좌표의 기억점을 별도로 계산한다.
- 현재 간섭 또는 실제속도에 필요한 제동 여유 부족이면 새 허가를 거절해0을 유지한다.
- 실제속도0.5m/s이고 여유가 충분한 반례에서는 목표0.1m/s를 허용했다. 같은 실측속도에서 기억점이 전방0.35m에 있는 반례는 제동 여유 부족으로0을 유지했다.
- 기존 StructureAware의 실제 숨은 기억 cap도 보존한다. 기반 래치 때문에 그 cap이 partial 최상위에 합쳐지지 않았던 경우까지 별도 참조하여, cap0을 새 저속 허가가 우회하지 않게 했다.
- 기억점의 과거 전체시간×2m/s 도달집합을 현재 실제 점유로 간주하지 않는다. **소실 물체가 보이지 않는 동안 독립적으로 움직이는2m/s 전체 도달집합 보장은 아니다.** 이 잔여 위험을 `unresolved_dynamic_motion=True`, `full_2mps_reachable_set_guaranteed=False`로 명시하는 저속 운용 후보다.
