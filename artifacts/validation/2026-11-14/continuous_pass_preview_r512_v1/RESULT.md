# r512 횡이동 중 일정한24cm 주시거리 후보

r502/r503은 지주 간섭으로 이미 감속한 뒤만 짧은 목표를 비교해 실제 정체를 해결하지 못했다. r503은2.52m·정체6.874초/접촉0이며 원 실패를 보존한다. r510의 별도 정상추종도 동일 입력에서 경계 미확정으로 정지를 해소하지 못했다.

이번 후보는 기존 유효 횡이동 경로를 처음부터24cm 주시거리로 추종한다. 실제 점유/제동·조향변화율을 다시 통과한 후보만 사용하며, 해당 후보가 불가하면 기존 유효 명령을 그대로 유지한다. 기억 경로 자체·편이·여유/물성/독립 보호·복귀 추종 간격은 바꾸지 않는다. 일반/default 정책·추월 전 admission·follow_headway 복귀는 동일하다. r502의 제동 시점 전용 분기 조건을 제거했고 더 작은18/12cm 탐색은 없다.

r503의125저장계획 중13명령이 바뀌었다. 순번85~97에서 횡이동 추종을 먼저 시작하도록 조향을 바꾸고, 같은 점유/곡률 식에서 일부 목표는.9→.744~.873m/s로 제한됐다. 기존 양수→0은0이며 이미 가까워진후반83정지는 원 입력에서 유지한다. 이 결과는 저장 입력에서 목표를 비교한 것이며 실제 경로 오차/완주 개선은 아직 미확인이다.

기존 관련114검사와 최종신규11검사를 통과했다. [검증](validation.json)·[재생](candidate_replay.json)·이전moving_pass/test 사본을 보존했다. 최종선택은 r513 동일조건1회 뒤 판단하며 r507 설치후보는 r502시점 소스여서 아직 설치하지 않는다.
