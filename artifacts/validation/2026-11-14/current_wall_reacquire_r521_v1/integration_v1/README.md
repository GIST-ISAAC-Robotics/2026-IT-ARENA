# 현재 벽 저속 재획득 공통 이관

기억한 외벽과 현재 관측이 맞지 않는 경우, 현재 관측점으로 짧은 경로를 새로 계산하여 최대0.10m/s로 진행하도록 공통 연결했다. 정상 기존 양수와 실제 점유/시각/입력 오류의 정지는 유지한다. 점유를 삭제하거나 UNKNOWN을 자유 공간으로 바꾸지 않는다. 선택된 current_route_priority 정책 범위에서만 적용한다.

- LocalFollow의 경계 미확정0 분기와 MovingPass의 기억/현재 경로 기하 실패0 분기에 연결했다. 현재/직전 조향 양쪽 원시 점유·per-ray 오차·마커 점유·기존 제동/간격을 검사한다.
- 기존 handoff 객체를 공유하고, 새 정상 FOLLOW 경로가 확보되면 기존 reset/복원 계약으로 복귀한다. 통합된 LocalFollow도 저속 후보를 낼 수 있으므로 **저속 후보 자체를 정상 경로 획득으로 오인하여 인계하지 않는 조건**을 추가했다.
- 미래 우회 예약만으로 인계 직후0이 되는 경우 reset을 미루고 현재 저속 경로를 다시 검사한다. 실제 충돌0을 우회하지 않는다.
- [기존 회귀](existing_tests.log)220개와 [신규 기능·반례](focused_tests.log)11개가 WSL에서 통과했다. 신규 검사는 실제 공통 모듈을 사용하며 artifact 입력 의존이나 전역 NumPy 교체가 없다.
- stage Windows 검사 시 NumPy2.5의 기존2D cross 비호환은 생산 코드 변경 없이 WSL의 실제 실행 환경에서 검증했다. stage 최초 실패/원시 근거는 상위 폴더에 보존한다.

[소스 해시](source.json)와 `before/`에 변경 전2파일을 보존했다. 폐루프 효과는 별도 r520 파생코스 실행으로 확인하며 이 회귀 결과를 실제 주행 증명으로 확대하지 않는다.
