# 저속 재획득의 관측 점유 기준

r553 단독은 실측 서보 상한으로 이전19.56·25.81m 정체를 통과했지만25.94m에서 다시 정지했다. 후보 계획은 계속0.1m/s였고 발행 직전 current 재검사가0으로 바꿨다. 같은 scan에서2ms 경과로 이동 불확실성 반경이1mm 커져 현재 차체 검사 영역과 겹친 것이 원인이다. 상세 수치와 원본은 [원인 분석](NOTE.md) 및 [r553 결과](../measured_steering_radial_lap_r553_v1/RESULT.md)에 보존한다.

## 선택과 한계

- 요청 상한≤0.1m/s, 현재 측정 속도≤0.2m/s의 현재벽 재획득에 한해 실제 반환점과 고정 여유 `.025 + measurement_padding_m`를 쓴다. 현재 설정은55mm다.
- 표시값은 `fixed_box_low_speed_observation`이며, 취득 이후 상대 이동 상계를 적용하지 않았다는 진단도 남긴다. 실제/직전 조향 두 경로, 원시 점유, 기존 정지 간격·제동·시간/epoch 계약을 유지한다. 정상 경로·고속 후보는 기존 계산을 유지한다.
- current와 retained 재검사도 새 측정 속도를 확인한다. 절대 측정 속도0.2m/s 초과 시 최신 취득 시각으로 원판 운동 여유를 다시 적용한다. 이전 clearance·age·허가를 복사하지 않는다.
- **관측 이후 상대 물체가 접근한 최악의 경우에 대한 보수성을 줄이는 주행 정책 변경이다.** 독립 guard가 이 운동 상계 보장을 대신 제공하는 것은 아니다. 사용자가 지시한 불확실성 정지 축소와 현재 관측 경로의 저속 진행을 반영하며, 실제 점유 충돌·STOP은 유지한다. 미관측을 자유 공간으로 기록하지 않는다.
- 차체·마찰·토크·실측 서보 상한과 `/drive→독립 보호층→/drive/safe`를 바꾸지 않는다. 실차 안전 또는 전체 완주 증명은 아니다.

## 확인한 범위

- r553 첫 정지의 실제 저장 plan/current를 명시 stage3모듈로 복원: 이전 current0 → 후보0.1m/s, 현재 여유0.92m. 새 주행이 아니다.
- 신규8검사 통과: 속도 경계, 실제 앞 장애물, 현재·직전 조향, 오래된 입력/STOP, 원시 입력 보존, radial 복귀.
- 공통3파일 이관 뒤 관련 **215검사 통과(14.76초)**. 기존 radial전용 fixture는 실제 측정 속도0.200001로 해당 정책을 선택하게 했으며 원본도 보존했다.
- `integrated_manifest.json`이 이관5파일(소스3·시험2)의 SHA 기준이다. `original/`에 이전 소스/fixture, stage 결과·공통 JUnit/로그를 분리 보존했다.

후속 r560 교통 대표는 사용자 중단까지 약4.69m(원 평가기 기준) 진행·관측 접촉0·최소 간격0.2965m를 기록하고 STOP/정상 회수했다. 예정12sim초 통과는 아니다. r558 단독은 사용자 중단으로 미실행이다. 따라서 이 정책의 전체 단독 완주 결과는 없다. Jetson/ESP32 접속·설치·flash는 수행하지 않았다.
