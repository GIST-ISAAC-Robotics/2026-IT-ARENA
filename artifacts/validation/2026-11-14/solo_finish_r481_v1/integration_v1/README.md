# 공통 이관 확인

11/14 주 담당이 r481 v2의 현재 경로 우선 판단과 기존 관측 기억 갱신 보존를 검토하고 공통에 이관했다. [적용 파일 SHA](applied.json)의 원본은 이관 전 각 기준 사본과 일치했다. 기존 실패·stage 결과는 덮어쓰지 않았다.

두 수정을 함께 둔 공통 소스 실제 import에서 **29검사 통과, 변경 범위 밖 launch 문항1개 제외**를 확인했다. 단독 관측/STOP9개와 current-lane/재사용20개다. [검사 로그](../../solo_finish_r481_v1/integration_v1/tests.log)와 XML을 보존했다. 생성 bash의 CRLF로 첫 진입이 실패한 기록은 별도로 보존했고, LF만 수정한 뒤 검사를 실행했다. 알고리즘/시험 판정은 바꾸지 않았다.

새 폐루프 확인은 r477과 같은 출발 변형의 r485 한 번으로 분리한다. 통합 회귀나 Jetson 저장 계산으로 실제 완주/실차 준비를 대신 판정하지 않는다. 센서/출력 장치는 사용하지 않았다.
