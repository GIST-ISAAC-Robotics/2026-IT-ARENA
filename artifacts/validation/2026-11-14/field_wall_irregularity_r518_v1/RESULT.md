# r518 현장 S자 벽·연결 틈 민감도와 제한적 연결 후보

2026-11-14. **현재 직선벽 적합이 실제 벽의 작은 틈을 원 광선 번호 단절로 분리하면, 짧은 조각의 방향 변화가 추월 경로 정합 거절로 확대되어 정지할 수 있다.** 좁은 연결부만 경로 기준에서 잇는 stage 후보로 합성 정지 5개 중3개를 복구했다. 큰 굴곡·복수 틈·밀리는 벽 전체를 해결한 결과는 아니다. 공통 소스에는 반영하지 않았다.

## 현장 관측과 합성 가정

- 사용자 전달: 단단한 벽이 부족하여 부드러운5T 벽 비중이 높고 대부분 약한 S자 형태다. 조각 사이 약10mm 틈이 있으며 이후 굴곡·틈이 더 클 수 있고 차량·잔디 접촉으로 벽이 밀릴 가능성도 전달됐다.
- **5T는 재료 두께다. 굴곡 진폭은 실측하지 않았다.** 5/10/20/30mm는 민감도를 보기 위한 가정이다.
- 실제 반환으로 이미 확인된 왼쪽 벽 한 면에 공간적으로 연속인 사인형 굴곡을 적용했다. 각 원 광선과 굴곡 면의 교점을 풀고 기존 측정 잔차를 보존했다. iid 거리 잡음을 굴곡으로 부르지 않았다.
- 기본 파장0.8m와 관측 벽 길이 안에서1.5주기가 되도록 정한 약1.37m 파장을 비교했다. 반복 연결부 간격0.6m도 미실측 가정이다.
- 틈은 선택된 벽점 중 폭10mm 안에 들어가는 반환만 `unknown`으로 바꾸는 **무반환 틈 가정**이다. 3개 대표 입력당20조건, 총60개 단일 입력 비교다. 일부 틈은 광선 사이에 놓여 제거된 반환이0개였으며 해당 수를 JSON에 기록했다.
- 기존 차량/장애물/비선택 벽 반환, 광선 방향·취득시각·엔코더/gyro 이력은 모두 불변이다. 지도·Gazebo 정답 위치/자세를 입력하지 않았다. 원시 자료 SHA256 불변을 확인했다.
- **틈 뒤 배경의 먼 실제 반환이 보이는 경우는 위 무반환 합성과 다르다.** 후보는 이를 unknown으로 바꾸거나 실제 반환을 지우지 않으며, 뒤 배경 반환 반례에서 새 연결을 하지 않는다.

## baseline과 현재 문턱

- 원 r513 입력124개에서 r514 이전 `moving_pass.before.py`로 원 상세 출력124/124가 일치했다. 원 실패는 그대로 보존된다.
- 현재 r514에서는 저장 `candidate_replay.json`의 속도·조향124/124 일치했다.
- stage 후보 전후 비변형124개 **상세 출력 전체가124/124 일치**했다. 세 대표 입력의 identity 재생도 모두 상세 일치했다.
- Windows에는 Linux native 확장이 없어 이 진단 프로세스에서만 표준 Python 수치 경로를 썼다. NumPy2.5.4의2D `cross`는 기존2D 행렬식으로 프로세스 안에서만 호환했다. 위 전체 baseline 대조는 해당 실행 차이도 포함한다. 실행시간을 Jetson 성능으로 해석하지 않는다.

| 코드/조건 | 현재 수치 | 의미 |
|---|---:|---|
| `local_path.py` 조각 연결 | 0.10+0.035×거리 m | 거리0.5/1.0/1.8m에서117.5/135/163mm. 10mm 틈보다 크다. |
| `bypass_wall_fit.py` 조각 분리 | 원 광선 번호가1씩 이어져야 함 | 실제10mm 틈에 광선1개가 빠져도 조각이 나뉜다. |
| 추월 현재 벽 대응 범위 | 60mm | 기존 기억벽 주변 현재 반환만 찾는다. 벽이 크게 밀리면 대응 자체가 달라질 수 있다. |
| 추월 직선 적합 | p80≤30mm, 최대≤60mm | 재료 두께와 별개인 현재 측정/적합 허용량이다. |
| 경로 reanchor | 회전≤2°, 법선 이동≤30mm | fit에 통과해도 기억벽 방향과의 차이로 정지할 수 있다. |
| LocalFollow 곡선 경로 | cubic 적합 p80≤60mm | 현재 관측의 곡선 경로가 있으며, 추월용 직선 재정합과 구별된다. |

## 대표 비교

세 종류는 r513 seq60(기본 FOLLOW),90(추월 진입),99(r514에서 현재 경로가 복구된 입력)이다. 모두 현재 비변형 기준은 양수다.

| 입력·가정 | 비변형 속도 | 현재 코드 | stage 후보 | 원인 |
|---|---:|---:|---:|---|
| seq60, 모든 가정 | 0.500 | 0.500 | 0.500 | 이번 기본 FOLLOW 입력은 양수 유지 |
| seq90,20mm/0.8m+단일10mm틈 | 0.810 | 0 | 0.810 | 짧은 fit 조각의 reanchor 거절 해소 |
| seq90,30mm/0.8m+단일10mm틈 | 0.810 | 0 | 0.810 | 같은 원인 |
| seq90,20mm/1.5주기+반복10mm틈 | 0.810 | 0 | 0.674 | 현재 연결 fit으로 양수 복구 |
| seq90,30mm/1.5주기+반복10mm틈 | 0.810 | 0 | 0 | 최대 직선 잔차70.404mm>60mm |
| seq99,30mm/1.5주기+반복10mm틈 | 0.900 | 0 | 0 | 기억벽대비회전2.1315°>2° |

단일 S자 굴곡만으로 이번 세 입력이0이 되지는 않았다. 다만 seq99의30mm·1.5주기에서는0.900→0.333m/s로 낮아졌다. 위 표의 정지는 실제 점유 충돌 판정에 도달하기 전 fit/reanchor에서 발생한 것이다. 이를 실제 벽 접촉이나 안전한 폐루프 주행으로 해석하지 않는다.

잔여 두 실패를 분리하면 다음과 같다.

- seq90: 현재138점, x범위1.696864m가 있고 p80잔차19.397mm는 통과한다. 최대잔차70.404mm가60mm를 초과해 `tracked_wall_current_line_unconfirmed`다. 파장1.377872m 가정.
- seq99: 현재111점, x범위1.656331m, p80잔차24.532mm·최대57.894mm로 fit은 통과한다. reanchor 회전−0.0372012rad(−2.1315°)가2°를 넘는다. 법선 이동22.006mm는30mm 안이다. 파장1.366218m 가정.

## stage 최소 후보와 회귀

`bypass_wall_fit.candidate.py`/`candidate.patch`는 공통 `bypass_wall_fit.py` 한 파일의 후보다. 각 틈 양쪽의 기존 실제 조각이12점·x범위30cm 이상이고, 양끝 실제 반환 사이 전체 현이 기존 측정여유30mm 안이며, 중간 원 광선이 모두unknown일 때만 후보 연결을 만든다. 근처 두 면의 방향차20°/법선잔차30mm 이내를 확인한다. 이후 원래 직선fit 잔차·범위·현재 점유·이동 영역 검사를 그대로 거친다.

추가 조건은 **기존에 끊겼던 부분을 새로 연결할 때만** 검사하며 기존 성공 경로에 새 정지 조건을 넣지 않는다. 광선 번호를 무제한 무시하지 않고, masked·실제 장애물·뒤 배경 반환을 새 helper가 건너뛰지 않는다. 연결은 경로 fit 용도이며 점유·unknown·센서 장면은 바뀌지 않는다.

독립 반례7개 통과: 작은 틈 연결, 실제 장애물 반환, 뒤 배경 반환, masked, 진짜 벽끝, 큰 벽 결손, 매3광선 결손. 실제 장애물의 경우 기존 `narrow_occluder_bridge`가 원래 수행하던 reference 연결은 유지되지만 후보 전후fit/상세결과와 scene/실제 점유가 같음을 확인했다.

기존 pytest3파일은 Windows에서 `shapely`/`rclpy`가 없어 collection에 실패했다. **해당 회귀 통과를 주장하지 않는다.** 기록은 `pytest_collection_failure.txt`와 `pytest_exit.json`이다. 통합 담당이 WSL에서 `tests/test_bypass_wall_fit.py`, `tests/test_moving_pass_wall_padding.py`, `tests/test_moving_pass.py`를 실행해야 한다.

## 권고와 한계

이 좁은 후보는 확인된 작은 무반환 연결부의 불필요한 정지를 줄이는 보조 개선이다. 큰 S자·큰 틈·밀리는 벽에서는 고정 직선벽의 범위/방향 가정 자체가 병목이므로, **현재 관측으로 만들 수 있는 짧은 곡선/조각 경로를 낮은 속도로 추종하는 회복 경로**를 별도로 다루는 것이 우선이다. 모든 fit/정합 문턱을 넓히는 방식을 권하지 않는다.

이번 비교는 동일 baseline 상태의 한 scan에 변형을 넣었다. 변형 벽을 연속 주행하며 기억을 갱신한 결과가 아니며 폐루프/실물 증거도 아니다. 시작부터 변형된 벽, 밀림의 시간 변화, 복수 벽, 코너, 뒤 배경 반환과 가려진 면의 재노출은 별도다. root의 실제 파생 벽 주행과 최종 통합 검토가 필요하다.
