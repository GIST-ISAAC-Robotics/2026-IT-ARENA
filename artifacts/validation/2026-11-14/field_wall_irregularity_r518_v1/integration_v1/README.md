# r518 공통 이관

현재 벽의 작은 무반환 연결부만 경로 적합에 연결하는 후보를 `bypass_wall_fit.py`에 이관했다. 원시 점유/unknown/시각은 변경하지 않는다. 후보의 원 상세124판단 동일·독립 반례7개를 소스 해시와 함께 확인했고, WSL 관련84검사를 통과했다.

최초 회귀에서는 기존 테스트 fixture가 `source_angles_rad` 속성을 누락해15개가 실패했다. production 검증을 완화하지 않고 fixture에 기존500광선 계약인 `None`을 명시한 뒤 통과했다. 처음 실패 요약과 후속 원 로그를 보존한다. 큰 굴곡/벽 이동과 실제 주행은 r521/r520 후속 범위이며 이 이관만으로 검증 완료라 하지 않는다.
