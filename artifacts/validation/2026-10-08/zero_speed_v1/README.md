# 0속도 출력 의미와 제동 모델 분리 시험

2026-10-08 04시 예약 재개. 기존 [A/B 대조](../braking_ab_v1/README.md)의 기본 구동 식·32점 입력을 보존한다. 구현·분석은 GPT 주 에이전트, 빌드/회귀/시뮬 실행·대기는 GPT-6 Luna가 맡는다.

## 실행 전 등록

비영점 목표에서는 기존 PI·토크 외피·40 ms 응답·증속 램프를 그대로 사용한다. 아래 모드는 플러그인 `evaluation_zero_speed_mode`의 평가 전용 선택이며 기본은 `legacy`다. 차량 설정/공식 코스·마찰/질량/토크·상위 제어·모터축 28카운트·15:1·65 mm는 바꾸지 않는다.

| 모드 | 정확히 0목표일 때만 달라지는 것 |
|---|---|
| `legacy` | 기존 수식, 변경 없음 |
| `reset_integral` | 계산 전 적분을 0으로 만들고 영점 동안 누적하지 않음. 40 ms 토크 응답 유지 |
| `no_lag` | 적분·포화 로직 유지, 0목표에서만 요구 토크를 지연 없이 적용 |
| `passive_damping` | 적분 0, 기존 Kp로 `τ=clip(-Kp × 평균 바퀴 선속도, ±기존 제동 상한)`를 즉시 적용. 같은 계산 시점의 `τ×ω≤0` |

`passive_damping`은 수동적(passive) 저항 근사이며 사람의 수동 조작을 뜻하지 않는다. 전기 회로·전류·인덕턴스·회전자 반사 관성·정지 유지·실제 MD20A를 재현하지 않는다. 상한이나 Kp를 개선 결과에 맞춰 조정하지 않는다. 같은 평균축에만 토크를 걸므로 두 바퀴가 반대로 돌면서 평균이 0인 상황까지 억제하지 않는다.

현재 수식의 0목표에서 이 근사는 적분 초기화와 지연 제거를 함께 적용한 결과와 같다. 기본/적분만/지연만/둘 모두의 네 조건을 비교한다. 비영점의 공식은 동일하나 이전 영점 동안 바뀐 내부 상태의 영향은 이후에도 남을 수 있다.

정상 감속은 0보다 큰 감소 목표, 0속도 대기는 신선한 0목표로 구분한다. 명시 STOP은 MCU 고정 상태·후속 DRIVE 거절이라는 별도 계약이다. 하위 모터 플러그인은 이 이유를 전달받지 않아 모두 0목표로 보며, 이번에도 STOP 계약을 임의로 바꾸지 않는다. 실물 출력 매핑은 별도다.

### 판정과 횟수

1. 기존 기본식과 보존 헤더의 무작위 50,000step 출력 완전 일치, 비영점 모드 동일성, 수동 모드 동력/토크 한계, 실행 XML 변화 범위, 기존 회귀·C++ 시험·플러그인 빌드를 확인한다.
2. 같은 이전 입력·슬롯 3·센서/보호/MCU로 단일 평면에서 `legacy`, `reset_integral`, `no_lag`, `passive_damping` 각 1회. 입력·STOP·종료 실패면 다음 실행은 중단하고 원인을 확인한다. 추가로 수동 모드의 분할 노면 1회까지 허용하며 이번 최대 5회다. 재시험 필요 시 무효 실행/원인을 보존하고 별도 이름으로 등록한다.
3. 제동 창 1.75~2.85초를 유지하고, 적용 목표가 최초 0이 되는 시점을 기준으로 **0명령 전** 불일치와 **0명령 후** 불일치를 분리한다. 양의 출력은 토크 계산 전 동시각 축속도와의 곱으로 새로 계측한다. 기존 PostUpdate 속도×직전 토크와 구분한다. 매 물리 step의 0목표 양의 일 누적도 평가용으로만 기록한다.
4. 실제 적용 명령·차량/월드 차이·단일 축·시각 coverage를 감사한다. 정지거리/바퀴 역회전·소스·종료 결과는 보존한다. 시험 유효성 통과를 슬립 해결이나 G1 성공으로 바꾸지 않는다. 개선만으로 기본 모델에 채택하지 않는다.

오른쪽 가림/G2/고속·Jetson·전원·게시 작업은 범위 밖이다. 기존 고빈도 원시 로그 제외 정책을 유지한다.

## 해석 시 주의: 수치 적분과 반사 관성

실행 차량의 후륜 각 회전 관성은 `2.1125e-5 kg·m²`다. 접촉·차체·모터 반사 관성을 모두 제외한 두 바퀴 스칼라 모형에서는 `J=4.225e-5`, 수동 캐리어 저항 계수 `Kp×radius×ratio=0.04875 N·m/(rad/s)`여서 비포화 시정수 `J/b≈0.867 ms`가 된다. 기존 물리 step은 1 ms다. 이는 실제 접촉계의 수치 불안정이나 실차 응답을 증명하지 않지만, 동시각 수동성만으로 step 독립성·연속계 재현을 보장하지 못한다는 경고다. 성공 여부와 무관하게 이 근사를 기본 모델로 자동 채택하지 않는다. 후속 채택 검토에는 step 민감도와 근거 있는 반사 관성/실물 출력 모델을 검토해야 한다. 이번에는 어느 값도 조정하지 않는다.

## 실행 결과와 마감

다섯 등록 실행 모두 입력·모드·소스·실제 정지·명시 STOP·정상 종료를 통과했다. 단일 평면의 제동 창 최대 평균 바퀴–차체 속도 차이는 `legacy` 0.707520, `reset_integral` 0.659829, `no_lag` 0.442960, `passive_damping` 0.415015 m/s였다. 이번 조건에서는 적분보다 40 ms 잔류 토크가 더 크게 기여했다. 그러나 수동 근사의 분할 노면에서도 최대 0.612975 m/s, 최종 0목표 전부터 0.592516 m/s 차이가 남았다. 기본 구동식은 유지하며 G1 가림 실패를 해결한 결과로 해석하지 않는다.

사전 회귀 54개·패키지 빌드·CTest 1개 통과. 최초 마감 회귀는 685 통과/1 실패로, G0 검사의 이전 launch 해시 참조를 후속 계약에 연결한 뒤 **686개 통과(75.10초)**했다. 실패 로그·기존 계약을 보존했고 런타임 구현이나 판정선을 바꾸지 않았다. 새 기본 차량 SDF는 이전 A/B 차량과 byte 단위로 같으며, 비교별 20 ms 간격 275표본의 요청/safe/MCU 목표 속도·조향 차이가 0이었다. 샘플 사이의 모든 콜백 시각까지 같다는 뜻은 아니다.

이번 STOP은 정상 0목표 감속 뒤 수행했다. 움직이는 차량의 비상정지 시험이나 실물 MD20A 시험은 아니다. 후속 범위는 수동 근사의 한정된 물리 step 민감도 확인 뒤 동일 왼쪽 가림 대조이며, 오른쪽/G2/고속화로 확대하지 않는다.
