# r22 경로 표현 전환 진단

r22 실제 주행은18.98 m에서정지했다. 저장입력2,019판단과신규스캔21개의계측은기록출력과모두일치했다. 새실제시험은하지않았다.

43.82초양쪽경로는piecewise_corner이며 path_anchor_error_m이존재한다. 44.02초부터선호왼쪽이일반매개곡선으로바뀌어새필드가없고, 44.22/47.92초에는양쪽모두일반곡선이다. 이때실제경로최근접거리는좌우모두약5 cm이며, 네비교프레임에서좌우경로형상일치는true였다. r22가한모서리표현에만지표를넣어,같은길을다른형식으로표현할때옛벽좌표검사로돌아간누락이다.

근거: probe_result.json·geometry.json·anchor_geometry.png 및 각exit/log. 다음r23에서는기본OFF선택형경로의일반매개곡선에도같은원점–경로선분거리계산을적용하는방향이다. 12 cm허용량이나경계/점유/STOP은바꾸지않는다. 정지중양수명령이실제통과증명은아니므로후속폐루프검사가필요하다.
