# r48 코너 정체 개선 — 지속 병렬 조건은 미충족

2026-11-08 설계·연결, 11/9 00시경 실제 시험 종료. [같은 감속 상대 원본](../corner_slowing_actor_v1/README.md)의 36.863초 각본·코스·평가·속도·물성·독립 보호를 그대로 두고 한 번 실행했다. GPT가 설계·구현·결과 검토를, GPT-6 Luna가 검사·재생·시뮬 실행과 회수를 맡았다.

**이전 9.45 m·최장 저속 6.442초에서 14.50 m·0.303초로 개선됐고 코너 출구를 통과했다.** 접촉·바퀴 노면 이탈은 없었다. 하지만 실제 코너 병렬 구간은 0.301초로 사전 0.5초 기준에 못 미쳐, 보충 평가 전체는 실패다. 기준을 낮추거나 전체 병렬 대응을 완료로 처리하지 않는다.

## 변경과 실제 사용

- 현재 짧은 코너 벽이 유효한 직전 경로와 일치하면 그 관측으로 지지되는 길이까지만 경로를 이어 쓴다. 벽 길이와 오프셋 경로 길이는 다르므로 경로를 실제 벽 관측 길이까지 제한한다. 최초/만료 이력은 이 방식으로 확보하지 않는다.
- 측방 GUARD의 과거 기준 1 cm 초과만으로 막힌 경우, 현재 경로와 전체 이동 영역 검사를 통과하고 **옆차 방향으로 추가 접근하는 모든 표본이 현재 자유 관측된 경우**에만 기존 저속 상한으로 진행한다. 옆차 위협 상태를 지우거나 미관측 공간을 자유로 바꾸지 않는다.
- 실제 주행에서 짧은 코너 선택은 2판단(35.62–35.72초), 현재 관측된 측방 접근은 40판단(35.52–36.50초)에 사용됐다. 따라서 사본 재생에만 나타난 분기는 아니다. 개별 수정 효과를 분리한 주행은 아니며 두 수정의 결합 결과다.

생산 변경은 `local_follow.py`·`pass_release_trial.py` 두 파일이다. [직전 사본](before.zip)과 [출처 계약](../../../../config/tests/observed_corner_continuity_r48_sha256.json)을 보존했다. 기존 선택형 정책 안에서만 작동하며 기본값·STOP·독립 보호 경계는 유지한다.

## 판단과 다음 범위

이 장면의 긴 정체를 개선했으므로 같은 각본을 성공할 때까지 반복하지 않는다. 지속 코너 병렬은 **짧은 동행·출구 통과 확인, 0.5초 지속 조건 미검증**으로 남긴다. 다음 주행 보강에서는 실제 상대와의 동행이 성립하는 배치/속도 조건을 먼저 고정해야 한다. 단순 실행 시간 연장이나 판정선 축소로 대신하지 않는다.

다음 묶음에서는 단독 고속 STOP의 기존 기록을 분해해 명령 전달과 실제 감속을 구분한다. 빠른 상대 추월·P21/P22 실제 진입·최신 Jetson/실물 이관은 계속 미완성 목록에 유지한다. 이 결과는 실차나 독립 다중 차량 경기의 보장이 아니다.
