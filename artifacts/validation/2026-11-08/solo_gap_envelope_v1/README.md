# 단독 후반 무반환 폭과 제동 외곽 — 저장 비교만

r19의 최종 7개 무반환은 원시 38.16–42.48° 방향의 +inf이며 양끝 반환은 약10.0/10.3m다. 뒤쪽 구조물이 만든 NaN과 구별되지만, 먼 끝의 반환만으로 중간 공간을 비었다고 채우지는 않는다.

현재 별도 보완은 실제 속도가 0으로 내려가도 반경0.6m에서 50mm보다 작은 공백만 허용한다. 이 반경은 저속일 때에도 제동거리보다 길 수 있다. 저장 비교 후보는 같은50mm 허용 폭·전체6°·현재/예전 가까운 물체 소실·현재 반환/독립 보호 검사를 유지하면서, 폭을 재는 반경만 차체/센서 외곽과 현재 지연·제동거리의 큰 값으로 계산한다. 새 작은 고정값을 찍거나 +inf를 자유공간으로 바꾸지 않는다. 이 반경은 관측된 자유공간의 증명이 아니라 기존 제한 위험을 평가하는 운용 근사다.

제어기에 연결하지 않는다. 원 r19 고정 입력의 원 출력 재현부터 확인하고, 후보가 실제 진행 명령까지 도달하는지 본다. 결과가 있어도 경로가 바뀐 실제 주행·독립 보호 일치·작은 물체 반례가 미확인인 상태다. 그리드 출발 시험을 이 분석 때문에 중단하지 않는다.
