# r17 정지차 우회의 복귀 상태 전달

r16은 차를 앞질렀지만2.490m에서 BYPASS/HOLD로 남았다. 실제 내부 단계는 `rejoin`인데 현재 벽이 후륜축까지 닿지 않으면 HOLD 출력에서 `entry_phase`가 사라졌다. 기존 `observed_rejoin_v2`는 현재 G1의 경로·점유·측방 검사를 통과하더라도 그 누락 때문에 인계하지 못했다.

저장 입력1029판단 동일 재현 후 두 후보를 비교했다. 앞쪽 벽 범위를 인정하는 후보는217개, 실제 복귀 단계만 기존 인계에 전달하는 후보는183개0→양수였다. **더 작은 상태 전달 수정만 선택**했다. 명시 `rear_wall_witness` 실행에서 누락된 단계는 실제 guide 상태를 사용한다. 입력/시간 고장은 기존 reset이 `entry`로 돌린다. 현재 G1 경로·양수 출력·미해결 측방 위협·서로 다른 두 스캔 조건은 모두 유지한다. 벽 길이·점유 여유·물성은 바꾸지 않는다. 기본 옵션 OFF는 그대로다.

별도 저속 정체도 남아 있다. r16의13.5/16/20초 시작 자세 간섭점은 우측 뒤 x=-0.25~-0.11m·y≈-0.22m의 실제 반환이었다. 구조 가림 뒤 짧은 면이라 정적 벽으로 분류되지 않고0.146~0.149m의 이동 여유가 붙었다. 차체와 실제 점이 겹친 것은 아니다. 이 수정은 해당 여유를 줄이지 않으며, 새 실제 시험에서도0.05m/s 미만 정체 기준을 그대로 평가한다.

관련 회귀·저장 입력 연결 검사 후 동일20초 장면1회를 마쳤다. `before.zip`과 r17 출처 계약은 변경 전 단일 제어 파일을 보존한다. 같은 결과가 나오도록 반복하지 않으며 완전 교착과 남은 저속 손실을 구분해 다음 대표 기능으로 이어갈지 판단한다.

관련214회귀 통과, 실제 연결한1029명령은 앞서 비교한 상태 전달 후보와 모두 수치상 같았다(변화183개). 기본 이동차749판단 전체도 동일했다. 2패키지 빌드 후 동일20초1회 등록/실행을 마쳤다.

## 실제20초 결과

초록 뒤13.042초에 정지차를 앞질러 최종 FOLLOW로 복귀했다. 총4.484m, 마지막2초1.974m(그 창의 차체 전부 도로 안), 최고1.563m/s다. r16의 영구적인 복귀 HOLD는 이 대표1회에서 해소했다. 다만0.05m/s 미만 최장구간9.210초(그 동안 약0.340m 기어감)로 **`no_long_stall` 실패는 남았다**. 우회 기능 전체 목표를 통과로 올리지 않는다. 재획득만의 효과와 옆 벽 조각 이동 여유에 따른 손실을 구별한다.

최소 표본/연속근사 간격0.128054/0.128052m·접촉/겹침/벽바퀴0·최대2바퀴잔디, STOP 조밀 표본 최대0.00791m/s·명시 MCU STOP·정상 종료를 확인했다. 등록873입력은 불변이고 실행 프로세스는 없다. 원 검사기의 HOLD/approached/15cm/차체도로안/앞차뒤유지 실패와 경기목표 정체 실패를 원문으로 보존한다.

다음은 새 직선 앞차 정지/재출발 대표다. r17로 일반 주행 복귀가 가능해졌으므로 그 연결을 확인하면서, 짧은 후방 벽 조각 때문에 생기는9초 저속 손실은 교통 속도 보완의 우선 미해결로 유지한다. 이를 해결된 것으로 분류하거나 단독 증속·빠른 상대·운영을 계획에서 삭제하지 않는다.

### 저속 손실을 다시 볼 때

현재 실제 간섭점은 구조 가림 뒤의 짧은 우측 후방 면이다. `rear_wall_witness`는 그 면을 경로 방향에만 쓰고 정적 점유로 합치지 않으므로 이동 여유가 유지된다. 기존 `bypass_corridor_trial.BoundaryMonitor`는 현재 연결된 **안쪽** 면의 서로 다른5스캔/0.4초 접근률과 시작 가속 가정으로 제한된 여유를 계산하지만 이 외곽 조각에는 적용하지 않는다. 후속에는 같은 조건으로 현재 외곽 조각의 움직임을 확인할 수 있는지 먼저 저장 입력에서 비교한다. 짧은 면을 무조건 고정 벽으로 합치거나 모든 점의 여유를 줄이지 않는다. 반대로 이9초 손실을 드문 세부 오차로 간주해 영구 보류하지도 않는다. 상대 재출발/측방 대표 결과와 함께 우선순위를 정한다.
