`right_parallel_first_curve/assessment_run1.json`은 출구/진행/실제병렬 실패다. 원시15cm/끝까지뒤따름 판정 실패도 그대로 남겼다. STOP6·정상종료14·잔여PID없음·888등록입력불변을 확인했고 재실행하지 않았다. 실행헤더의 `traffic_boundary_refresh_trial=true`를 확인했다. build/등록 exit0, harness/assessment exit1, 벽시계457초다.

[저장 입력](../side_corner_diagnosis_v1/README.md)에서는0명령137→87개로 줄었지만 폐루프 주행에서는 이득이 없었다. 관련256회귀와기본OFF1,618판단 동일은 **기존 행동 보존/한정 반례** 근거이며 실제 성능 개선의 근거가 아니다.

현재 교통 후보는 r27을 유지한다. 이 옵션은 기본OFF 연구 후보와 실패 당시 소스로만 남긴다. 다음에는 코너에서 옆차에 가린 벽 구간과 현재 경로 후보의 실제 센서 기하를 확인한다. 시간을 늘리거나 상대 배치를 바꿔 같은 시험의 성공을 만들지 않는다. 미해결 지속코너병렬·더 빠른 추월·교통 운영재개·실물 이관은 전체 계획에서 유지한다.
