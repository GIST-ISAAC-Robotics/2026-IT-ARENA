# 0.8 m/s 앞차 두 대 — 새 코스 한 랩 실패

60초1랩은 **23.09 m에서 장기 정체해 실패**했다. 기존0.5 m/s/96초와 같은 상대 이동48 m를0.8 m/s/60초로 비교했다. 명령갱신은100 Hz이며 차량/센서/선택형 제어의 속도 및 추월 상한은 바꾸지 않았다. 앞차에 비해 속도 차가 불리할 때 추종도 정상 목표다.

- 원시/보충 평가 실패: 한 랩 미달, 앞차가 움직일 때 최장정지30.94초, 최종간격5.958 m. 자차 최고1.570 m/s, 원시 뒤따름 유지 참.
- 주 상대 표본/쓸림 하한 간격0.6992/0.6980 m, 추가 상대1.6806/1.6806 m, 접촉/겹침0.
- 상대실행·수신/표본·입력885개 불변은 유효하다. 노면33,368표본에서 차체이탈/바퀴벽침범0. STOP·정상종료·14개 자식 종료·잔존PID0을 확인했다.
- 약36초부터 상위 경로가 경계 미확정0명령을 냈다. 독립 보호는clear, 관측 정책은fully_observed이며,37.02초에도 왼쪽에서3.09 m 앞의 경로 후보가 계산됐다. 반대 벽과의 초기 재획득 일치 조건을 통과하지 못했다. 음수모터축 표본이 있었지만 정체가 계속되는 조건은 유효속도0에서도 같은 경계 미확정이었다.
- 당시 standing_wall_reacquire=false이다. [기존 선택형 재획득의 저장 입력 비교](../traffic_faster_reacquire_v1/PLAN.md)를 먼저 수행한다. 이 후보를 켰을 때 실제로 진행하는지는 아직 확인하지 않았다. 새5랩은 선행조건 실패로 미등록·미실행이다.
