# r46 코너 경계 전환 감사

2026-11-08. [r46 실제 실패](../retained_corner_agreement_r46_v1/README.md)의 후반 경계 상실을 저장 센서로 재현했다. r45 감사 스크립트를 경로와 관측 시점에 맞춰 적응했으며 제어기·센서·판정선은 바꾸지 않았다.

먼저 원 명령의 동일 재현과 소스 불변을 확인한 뒤 36.52–38.62초 주요 스캔의 좌우 전체/지지/돌출 제외 경로를 비교한다. 현재 관측 길이·앵커·x구간/호길이 일치·기억의 시각을 구분한다. 실제 상대 위치는 평가에만 쓰며 병렬 성공으로 확대하지 않는다.

**1,635명령 모두 원 출력과 일치**, 생산 소스 불변, 85스캔·417호출 캡처 뒤 주요 13스캔의 62후보를 비교했다. [재생 요약](summary.json)·[현재 경로 비교](path_comparison.json)가 기준이다.

| 시각 | 왼쪽 현재 경로 | 오른쪽 현재 경로 | 전환 의미 |
|---|---|---|---|
| 37.42 s | 관측 0.634 m, 공통 호길이 불일치 | 관측 1.474 m, 공통 호길이 일치 | 기존 오른쪽 갱신 |
| 37.52 s | 관측 0.651 m·앵커 6 mm, x 비교 실패·호길이 일치 | `wall_shape_uncertain` | 충분한 왼쪽 현재 경로가 있으나 기존 x 비교에서 탈락 |
| 37.62 s | 관측 0.754 m·앵커 7 mm, 호길이 일치 | 관측 1.516 m·앵커 11 mm, 호길이 일치 | 이전 경로 시각 37.303 s의 기억은 0.317초로 만료. 이 표의 운반 경로는 진단용이며 사용 가능한 기억으로 세지 않음 |
| 37.72–38.12 s | 코너 경로는 있으나 유효 이력 없음 | 형태 불명확 | 경계 재획득 대기 |
| 38.52–38.62 s | 짧은 코너 구간 | 긴 현재 경로 재관측 | 양측 확인 뒤 재출발 |

기존 r46은 **같은 오른쪽 벽 유지**에만 호길이 비교를 적용했으므로 37.52초 왼쪽 현재 후보에는 적용되지 않았다. [현재 후보 비교 사본](../current_corner_agreement_probe_v1/README.md)에서 선호/지지/돌출 제외 경로의 일치 검사에도 같은 선택형 비교를 적용한다. 관측 길이·앵커·80 mm 일치 오차·TTL은 그대로이며 실제 점유/독립 보호는 별도 유지한다.

실제 병렬 0초는 정지시간만의 문제가 아니다. 평가 자료에서 20–33초 상대는 자차 기준 전방 약 0.46 m·오른쪽 약 0.33 m에 있었고, 자차가 약 18° 회전한 38초에는 상대가 전방 0.75 m·상대방향 약 72°였다. 따라서 이 장면은 가까운 앞·옆 차량으로 인한 코너 가림을 진단하지만, 지속 병렬을 입증하려면 그 조건이 실제 만들어지는 별도 대표가 필요하다. 기존 병렬 0.5초 판정을 바꾸지 않는다.

첫 실행은 생성 Bash의 CRLF 때문에 Python 전에 실패했다. LF 교정 뒤 첫 캡처는 초기 `path_source=None` 계측 오류로 중단됐다. 두 실패를 보존하고 계측값만 null로 고친 v2가 성공했다. 제어기 실패나 원 주행 변경으로 분류하지 않는다.

Claude는 이번 새 호출에서 `five_hour` 100% 요청 거절로 읽기 조회 이후 종료됐다. GPT가 분석 구현을 인계했고 실행·결과 회수는 GPT-6 Luna가 맡는다. 이 호출의 제한을 주간 경고로 분류하지 않는다.
