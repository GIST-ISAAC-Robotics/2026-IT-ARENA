# 현재 전방 횡단면을 사용한 직각 접근 감속 — 저장 입력 후보

편측 접촉 메시지가 끊긴 33–35 m 구간의 속도 손실을 겨냥한다. 지도나 바퀴 정답을 제어에 쓰지 않고, 실제 양쪽 차폭을 가로지르는 연속 라이다 반환의 거리를 사용한다. 기존 속도가 1.2 m/s를 넘는 단독 증속 설정에서만 기존 명령을 낮추는 후보로, 조향/STOP/독립보호·물성을 바꾸지 않는다. 도로 좌표는 사후 변화 위치 설명에만 사용한다.

임시 설계값은 기준 코너 속도 1.2 m/s, 완만한 감속 1.5 m/s², 직각 벽 앞의 전환 거리 2×공식 벽 오프셋이다. 직선 끝을 조기에 관측했을 때만 사용하며 무응답을 벽으로 간주하지 않는다. 단독 실제 입력 세 개에서 (1) 문제 구간 제동 전부터 명령이 낮아지는지, (2) 다른 구간에서 10 km/h 지령 기회를 모두 없애지 않는지, (3) 기존 낮은 명령을 올리지 않는지 비교한다. 효과가 없으면 채택/새 주행 없이 다른 접근으로 전환한다. 아직 제어기 연결·주행 결과가 아니다.

## 저장 입력 결과

| 입력 | 호출 | 낮춘 명령 | 문제 구간 첫 변화 | 문제 구간 최대 감소 | 10 km/h 이상 지령 유지 |
|---|---:|---:|---:|---:|---:|
| 새 접촉 계측 |1,544|343|32.33 m|0.387 m/s|72/72|
| 기존 r14 |1,243|354|32.24 m|0.387 m/s|54/54|
| 앞선 직선 증속 |1,807|435|32.40 m|0.396 m/s|74/74|

세 비교 모두 exit 0. 지령 유지 횟수는 독립 프레임 수나 실제 달성 시간과 다르다. 근거가 있어 [r19 선택형 연결](../solo_corner_approach_connected_v1/README.md)의 회귀·실제 비교로 이어간다.
