# r39 뒤 통로 편이·전이·시차 여유 비교

2026-11-08. 운영 재출발은 r39에서0.852m 진행했으나 미완료다. 기존27cm 상한만 늘리면 불리했던 [r33 비교](../corridor_width_probe_v1/README.md)를 재검토하고 새0.7m 전이와 함께 분리했다.

- r39 첫 진입까지205판단을 재현했다. 상한0.305/0.31m만 바꾸면 전이가0.75m로 늘고 원시 점유의 경로 여유는 오히려 줄었다. 이 단순 변경은 채택하지 않는다.
- r39 후반1,306판단을 재현했다.35.00초에는 현재 차체 위치 자체가 지연에 따라 팽창한22개 반환점과 겹쳤고, 최대 측면 겹침은28.36mm였다. 새 스캔35.02/35.04초는0.35m/s를 허용했다. 원호 표본4cm를 세분하는 것만으로 해결할 상황이 아니다.
- 원시 점유와 현재 긴 외벽 가정을 구분했다. 실제 명령 검사가 이미 고정 외벽으로 보는 반환을 초기 경로 순위에서만 이동 물체로 팽창시키면 비교 결과가 달라진다. 새 가정/센서점 제거 없이 기존 `current_outer_wall_padding`을 순위에도 적용했다.
- 기존 편이27cm, 관측 통로 중앙(도로반폭30.5cm 이내), 그 사이 중간값만 같은 전이로 비교했다. 이 장면의28.75cm/0.7m는 실제 조향0.33056rad로 한계 안이며 현재 경로 여유27.81→38.69mm, 기존 같은 스캔 재사용0.08초 뒤 여유-12.19→+3.87mm였다. 이는 현재 반환에 대한 **경로 순위**이며 미래 자유 공간/실차 보장이 아니다.
- 사본11검사에서 양방향·앞길 침입·조향/관측 끝·도로반폭·기존27cm 설정 불변을 확인했다. 첫 좌우 반사 시험은 광선 취득 순서를 뒤집지 않아 source 검사에서 거절됐다. 올바른 양의 회전 순서와 새 취득 시각 순서로 만든 좌측 장면에서 다시 확인했다.
- 실제 연결 예정 사본은 원 r39의208판단과 대조했고 첫 실제 명령 차이는13.08초다. 그 뒤의 고정 센서 입력을 새 주행으로 세지 않는다.

기본OFF인 기존 `adaptive_entry_preview` 안에서만 연결을 검토한다. 일반 `EntryConfig`의27cm 상한은 유지하고, 이 선택형의 최대 표현은35cm·실제 새 목표는 관측 통로 중앙 및 도로반폭 이내다. 속도 상한·STOP·물성·원시 점유·독립 보호를 바꾸지 않는다. 이동 중 이미 선택한 경로를 임의로 옮기지 않는다. 실제 주행 결과는 별도 r40에 남긴다.
