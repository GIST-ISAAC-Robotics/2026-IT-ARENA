# 코너에서의 현재 관측 기반 접근 검사

짧은 현재 경로를 유지해도 과거 측방 기준에서1cm 이상 접근한다는 GUARD 거절이 남았다. 읽기전용 감사에서48개 고유 스캔의 해당 추가 접근 표본17–129개 모두가 기존 거리/시차 여유를 포함한 현재 자유 관측으로 확인됐고 전체 이동검사도 차단되지 않았다.

새 미연결 후보는 기존 기준을 유지하고, 이를 넘은 경우에만 현재 스캔에서 갱신한 기본 경로·기존 전체 이동검사·위협 방향 추가 접근 표본 전부의 현재 자유 관측을 함께 요구한다. 마스크/무반환/막힌 표본은 대체 근거로 쓰지 않는다. 통과 상태·과거 위협·독립 보호·속도 상한은 바꾸지 않는다. `traffic_recovery_trial`이 꺼졌거나 현재 경로가 기억뿐이면 기존 거절이다.

양방향·미관측·장착 마스크·반환 장애물 반례와 원 입력 비교 뒤 연결을 판단한다. 단순1cm 임계값 확대가 아니며, 저장 입력 개선을 새 주행 성공으로 취급하지 않는다.
