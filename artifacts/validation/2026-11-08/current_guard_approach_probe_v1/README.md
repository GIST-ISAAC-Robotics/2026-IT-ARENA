# 현재 관측된 측방 접근 후보 — 미연결 비교

[짧은 현재 코너](../traffic_corner_prefix_probe_v1/README.md)와 결합한 사본을 원1,891입력에서 비교했다.33초 이후0명령은 원438회·짧은 경로만275회·결합87회였다. 전체 명령361회가 달라졌고 최초 변경은35.52초다. 생긴 양수 명령이 실제 차량 진행으로 이어지는지는 별도 주행에서 확인해야 한다.

표적6검사 뒤 호출부5검사를 추가했고 최종11검사 통과를 확인했다. 중간5실패는 네 건의 읽기전용 `mode` 속성 대입과 한 건의 `FollowConfig` 필수 조합 누락이었다. 후보 자체를 바꾼 것이 아니라 fixture를 바로잡았으며 `tests_v2.log`·`tests_v3.log`를 보존한다. 최초/기억 경로·정책OFF·차단/미관측/마스크·양측 확인·HOLD/평행 양수 우선·GUARD 위협 상태 보존을 확인했다.

생산 소스가 바뀌지 않은 사본 비교 후 [r48](../observed_corner_continuity_r48_v1/PLAN.md)로 연결했다. 관련 회귀·원 명령 비교·같은 장면 실제 실행을 거쳐야 한다. 이 보고서는 미연결 사본의 근거만 기록한다.
