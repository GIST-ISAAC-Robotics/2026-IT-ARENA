# P21: 본선 저장 센서에서 진입 신호가 언제 보였나

**결론:** ID30 후 왼쪽 직선과 약45° 사선이 이어지는 형태는 실제 저장 센서에서 관측됐지만, 이 둘을 본 순간에 바로 조향하는 전략은 빠른 본선 주행에 늦다. 다중 차량 주행과 본선 속도 개발을 중단해 지름길부터 켜지 않는다. 제한 속도의 관측 전용 후보로 이어 비교한다.

r11의 중복 없는 현재 스캔334개를 한 랩 전부 조사했다. 각 스캔에서 운동 보정된 실제 반환과 연속 광선 번호만으로 왼쪽 두 직선의 적합 잔차·진행 방향·공유 모서리를 검사했다. 시간·마커·지도·정답 자세로 후보를 생성하지 않았다. 후보를 고정한 뒤 평가 전용 궤적으로 주최측 P21 입구 전2.2m~후0.4m와 대응시켰다. 인접한 후보 번호 선택, 양쪽 선분 길이와 잔차 한도는 이 진단의 가정이다.

- 해당 접근 창13스캔에서 후보1개. 본선 s≈30.14m에서 좌벽까지 약0.49m, 앞쪽 교점 x≈0.223m, 방향 변화45.2°, 두 면 길이0.397/0.794m, 최대 잔차4.4mm였다. 이미 영상에서 ID30을 봤다.
- 전 랩 후보12개 중 나머지11개는 s≈32.20–32.42m의 더 먼 벽(횡거리1.09–1.38m)에 생겼다. 전부 ID30 이후였으므로 **ID30을 봤다는 사실과 45° 두 직선만으로 실제 입구를 정할 수 없다.** 이 숫자는 한 랩/한 감지 후보의 사례이며 실제 오검출율이 아니다.
- 가장 가까운 평가 자세에서 차체속도2.52m/s, 입구까지 본선거리 약0.175m, 같은 속도라면 약69ms다. 축거135mm·조향0.37rad의 후륜 최소반경으로 45°를 잇는 이상 원호만 해도 모서리 전 약0.145m가 필요하다. 남은 차는 약3cm/12ms에 불과하다. 벽 교점과 후륜 경로 교점은 같지 않고 휠베이스·가속·서보 응답/자세 오차도 있으므로 이 숫자를 실제 전환 타임스탬프로 쓰지 않는다.
- 첫 ID30은 입구 약2.55m 전이었다. 향후 선택한다면 이때 **제한 속도와 준비 상태**만 만들고, 감속한 상태에서 인접 좌벽과 사선의 시간 연속 관측·진입 가능한 차체 외곽·출구 복귀 조건으로 판단해야 한다. 실제 주행, 지름길 시간 이득, 양산 제어 연결은 아직 없다. 이 진단은 본선에서 실제로 관측된 입력이며 미주행한 지름길 내부를 복원하지 않는다.
