# 코너 병렬 평가 상대 준비

2026-11-08. 교통 경기5랩 대표를 마친 뒤 지속 코너 병렬을 확인하기 위한 평가 전용 r28이다. 자차 제어기·속도·센서·보호·차체 물성은 바꾸지 않았다.

기존 중심선의 자세에 옆 간격을 그대로 더하면 직각에서 법선이 갑자기 바뀌어 상대차 위치가 뛴다. 새 장면의0.34m 오른쪽 오프셋을100Hz로 계산하면 위치차/시각차 최고48.33m/s가 나왔다. 실제 상대의 가속이 아니라 꺾인 기준선의 이동 기하 문제다. 기존 중앙 앞차 결과를 이 값으로 소급 무효화하지 않으며, 새 코너병렬에 이 경로를 쓰지 않는다.

`side_first_curve`를 명시한 장면만 직선→접선 원호→직선으로 움직이게 한다. 첫 왼쪽90도 코너의 중심 원호0.505m, 오른쪽0.34m 상대는0.845m 반경이다. 실제 이동거리당0.35m/s로 계산하며 방향 변화율 최고0.4142rad/s, 위치 연결이 연속임을 확인했다. 동역학 차량이 아니라 정적 충돌체를 위치 지정으로 움직이는 각본 상자라는 한계는 남는다.

0.28m 오른쪽 초안은 actor 자체 기하와 관련138검사를 통과했지만, 실제 grid3 자차가 도로 중심보다 오른쪽0.09m에 있어서 시작 간격이약40mm였다. 실행 전에 미채택했고 `initial_280mm_not_selected.json`으로 보존했다.0.34m 최종 후보는 실제 시작 간격약100mm,5mm간격2,241개 노면/벽 표본에서 최대두바퀴 잔디·벽 비침범이다. 변경한 기하와 시작간격9개 검사를 따로 통과했다.
