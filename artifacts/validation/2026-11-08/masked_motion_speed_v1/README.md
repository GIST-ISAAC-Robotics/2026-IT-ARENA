# r38 후방 가림 거부의 감속 진행 연결

2026-11-08. [설계·저장 장면](../released_masked_speed_probe_v1/README.md) 뒤 실제 소스에 적용했다. 기존 선택형 `traffic_recovery_trial`의 RELEASED 분기 안에서만 작동하며 설정의 기본 활성화는 바꾸지 않았다. [동일 B 시험 기준](PLAN.md).

- 부모 r37의3,041판단 전체를 동일 재현했다. 사본은32.78초에서 처음 정지0 →0.15 m/s로 바뀐다. 실제 센서 입력이 같아지는 지점까지만 비교했으며 이후 주행 성공으로 세지 않는다. 무주입A3,051판단은 전부 같다. [재생](../released_masked_speed_probe_v1/replay_result.json).
- 표적20검사와 기존 선택기·곡선 보호·측방/관측·출처의 **403관련 검사 통과**. 기존보다 작은 설정 상한을 넘어 재검사하지 않는 조건을 추가했다. 이 조건은 재생에 쓰인 기본0.35 m/s 상한에서는 결과를 바꾸지 않는다. [회귀](regression_result.json).
- 실제 import21항목을 확인했고, 같은 B 인수/원본 월드/actor를 유지한908입력의 등록 전 검사를 통과했다. GPT-6 Luna가 같은 B 실제1회를 완료했고 GPT가 원판정/보충판정/입력 무결성과 후보 적용 기록을 별도로 대조했다.
- PC WSL 저장 장면3개·각3회에서 추가 재검사만 **53.7–58.6 ms**였다. 전체 제어기/Jetson 지연값은 아니며 동시에 회귀가 실행될 수 있는 환경이다. 실물 처리율 한계로 남긴다. 기존16표본 거부 도구를 앞에 붙여 본 별도 비용 실험은55.5–75.0 ms로 개선되지 않아 적용하지 않았다. [원 비용](cost_result.json), [미채택 비용 비교](cost_sampled_result.json).

원시 r37 실패/등록물은 수정하지 않는다. 높은 측정 속도에 낮은 명령을 내렸다는 이유로 제동 외곽을 작게 만들지 않고, 일반 미관측/전방 가림/실제 GUARD는 이 후보의 대상이 아니다. 불필요 정지 대신 현재 관측 범위에서 가능한 낮은 명령을 선택하는 변경이다.

## 실제1회 결과

17:28:40–17:41:43 KST.60초 조건에서 **48.09 m·거리 한 랩·최장저속0.401초**, 최고1.569 m/s, 최소간격0.8503 m(이동 외곽0.8483 m), 접촉/노면 이탈0을 확인했다. 취득 대응/완전한 판단 기록·±3 cm/32–70 ms 주입·STOP/정상 종료·908입력 불변·잔여0도 통과했다. 보충 평가의 모든 게이트는 통과했지만 **원 평가의 최종간격은 실패**로 남고 HARNESS_EXIT=1을 유지한다.

새 후보는 실제12판단에서 모두0.15 m/s로 적용됐다. 당시 원래 목표는0.4–0.7 m/s급이었고, 측정속도는그대로 유지했다. 이 호출 수는 실제 저속 지속 시간이나 개별 수정의 인과효과가 아니다. 같은 seed의 실행들이 동일 센서 기록은 아니지만 새 분기가 실제 사용됐고 대표 한랩의 장기정체를 벗어났음을 확인했다. [평가](B_c1_injection/assessment_run1.json)·[후보 기록](actual_retry_summary.json).

대표 오차 조건 결과를 확보했으므로 같은 장면을 반복하지 않고 교통 속 STOP/START의 미완료 기능으로 이동한다. 실물/각도·회전율/IMU 전체 오차나 모든 주행 조건의 검증으로 확대하지 않는다. 대상 표본을 바꾼 추가 거부 샘플링 비용 비교도75–80 ms로 개선되지 않아 적용하지 않았다.
