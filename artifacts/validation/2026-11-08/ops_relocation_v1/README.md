# 재배치 뒤 START 취소 — 첫 시험

새 코스의 시험용 도로 중앙(s=12 m)에서 재개하지 못했다. RGB 출발과 첫 STOP은 정상, 버튼 후 1.060초에 연속 0.5초 정착(최대 0.0496 m/s, 변위 2.13 mm)을 확인했다. 기존의 조기 판정 직후 첫 창은 최대 0.0639 m/s로 여전히 실패했다. 정차 RESET 한 번 후 처음과 반대 방향의 새 자세를 확인하고 같은 물리 시각에 START를 한 번 눌렀다. 이후 약 0.114 시뮬레이션 초(실제 경과 1.153초)에 정책에서 운영 연결 단절로 취소했다. 이후의 전진과 두 번째 STOP은 실행하지 못했다.

[HTTP 상태 표본](link_timeline.json)에서 버튼 뒤 +0.129~+0.934 실제 초 동안 약 5 Hz로 같은 운영자가 상태를 받았으나, 제어기 주기 상태의 시각은 10.86에 머물렀다. 다음 상태는 이미 종료를 보고했다. 기존 어댑터는 정책 수락을 받아도 주기 상태에 같은 대기 요청이 나타나야 연결 신호를 보냈다. 1초 연결 감시보다 두 상태 사이가 길면 실제 운영자가 접속 중이어도 취소된다. 당시 센서 준비 목록에 scan이 남았다는 것은 이 취소 원인이 라이다 고장이었다는 뜻이 아니다.
