# 중속 상대 추월의 첫 확장 준비

현재 단계는 **저장 입력 조사·설계**이며 중속 추월을 구현하거나 주행한 결과가 아니다. `survey.py`는 새 코스 r13의 최초 저속 추월 진입에서 실제 순차 LiDAR·운동 이력을 복원한다. 기존 `solo_straight_budget.wall_run`으로 같은 각도 순서로 이어진 외벽의 관측 길이를 구하며 미반환/가림 뒤의 별도 선분을 합치지 않는다. 벽을 봤다는 사실을 빈 통로로 바꾸지 않는다. 상대속도 비교 중 가상 값은 측정값과 구별한다.

## 이어서 구현할 범위

1. 기존 저속 프로필(자차0.65 m/s·상대 관측상한0.50 m/s)을 보존하고 중속 시험 프로필을 별도 명시 선택한다. 첫 실제 상대는0.50–0.60 m/s 범위에서 **등록 직선 길이와 시험 시간**이 성립하는 값으로 고른다. 자차는 약1.0–1.1 m/s 범위를 검토한다. 기존1.5 m/s 교통 본선 가속과 추월 중 상한을 구별한다.
2. 진입 때 상대 관측속도뿐 아니라 실제 선택된 후보의 속도 이점과 외벽 관측 길이를 대조한다. 앞면 관측점만으로 상대 앞 범퍼를 단정하지 않고 현 규격의 대각선 상계를 사용한다. 필요한 상대 진행거리/속도 차로 병렬 시간·복귀까지의 전진 거리를 추정한다. 현재 속도에서의 가속 소요도 포함한다. **예상 완료 가능성의 선별**이며 상대의 미래 가속·통로 전체 안전 보장이 아니다.
3. 실제 명령은 기존 경로 곡률·조향·전후 스윕·점유·현재 관측·독립 보호를 계속 적용한다. 긴 벽 관측을 속도나 자유 공간의 무조건 허가로 쓰지 않는다. 상대 가속으로 추월 이점이 없어지면 현재 옆 경로를 유지하면서 뒤로 합류하는 기존 연결을 사용한다. 현재 하드코딩된0.50 m/s 포기 기준과0.75 m/s 대응 탐색도 선택 프로필에 맞춰 함께 검토한다.
4. 저속 기본 출력 동일성, 유리한 직선의 진입 후보, 속도 차 부족/코너가 가까운 경우의 추종 유지, 현재 뒤쪽 관측 전 복귀 불가를 관련 회귀로 확인한다. 새 프로필의 대표 실주행1회를 시행하고 진입→옆→앞→복귀 뒤 전진과 추종 대비 이득을 구별한다. 접촉·노면·정체·STOP을 함께 측정한다.

원래14초에 상대속도만 높이면 상대가 첫 코너를 지나 '직선 상대' 전제를 깨뜨릴 수 있다. 기존 평가기의 경로 검사를 먼저 확인하고 필요한 시험시간은 **실행 전** 등록한다. 성공 장면만 잘라 실패를 감추지 않는다. 중속 대표 결과가 확보되면 빠른 상대·정지차/피추월/운영 미완성도를 비교해 다음 작업을 정하며 이 프로필의 세부 예외만 반복하지 않는다.


## 11/8 저장 입력 조사에서 제외한 단순 방안

실제 저속 추월 진입에서 긴 외벽의 연결 관측은3.735m였다.0.65m/s 상한과 상대 관측상한0.388m/s로 복귀까지를 산술 계산하면 약5.01m,1m/s² 가속 가정을 더하면5.25m가 필요하다. 그런데 이 장면은 이후 새로운 센서 입력을 받으면서 실제 추월·복귀했다. 따라서 **첫 스캔에 추월 완료까지 전 구간이 보여야 한다는 조건을 새 필수조건으로 넣으면 이미 성립한 주행까지 막는다.** 이 단순 전구간 관측 조건은 채택하지 않는다.

중속1.1m/s·상대상한0.70m/s를 가정한 경우 복귀 포함 예상6.33m,0.85m/s이면9.72m였다. 이 중속 수치는 저장 입력의 실제 상대속도가 아니다. 상대와 속도 차가 작을 때 진입을 피하는 데 활용하되, 관측 외 구간을 비었다고 만들거나 미래 완료를 보장하지 않는다. 기존처럼 현재 관측을 계속 갱신하고, 코너/통로가 짧아지면 새 진입을 보류하며 이미 진입한 차의 현재 경로와 양보/합류 가능성을 따로 판단한다. 정확한 프로필과 실행 연결은 미완료다.

근거: `survey.json`, `survey.py`, 가속/정속 산술과 별도 수치 적분 대조 `closure.py`. 이 분석 때문에 단독 증속 실패나 기존 대표 교통 성공을 소급 변경하지 않는다.


## 첫 중속 프로필의 코드 연결 검토

`EntryGuide.evaluate`는 실제 입력 속도가 `FollowConfig.max_speed_mps`(현재1.0)를 넘으면 초기화한다. 상한만1.1로 바꾸면 이 검사에 걸려 멈출 수 있다. 따라서 첫 명시 중속 장면은 **상대0.50m/s·추월 중 상한0.90m/s**부터 연결하는 방향이다. 실제 선택된 후보가 상대 관측상한보다0.20m/s 이상 빠른지 확인하고, 추정상한0.70m/s를 넘으면 진입을 보류한다. 원래0.65/0.50 저속 프로필은 보존한다. 이 값들은 아직 구현·실제 시험하지 않은 설계값이다.

진입뿐 아니라 상대 가속 시 포기 기준(현재 코드0.50), 대응 탐색0.75, 복귀/양보 속도와 상태 초기화도 같은 프로필로 묶는다. 새로운 프로필만 명시 선택하며 기존 저속 출력은 동일 재생으로 확인한다. 상대0.50m/s×14초는7.0m로, 현 등록 시작s43.26에서 첫 코너s51.34까지8.08m보다 짧다. 실제 도로/벽 경로 검사는 등록 때 다시 수행한다.

장기 목표인 더 빠른 상대 추월은 이0.90m/s 장면의 통과만으로 완료되지 않는다. 다음 속도 단계에서는 실제 입력 속도 한도·가속/조향·관측/복귀를 함께 확대해야 한다. 단순히 새 프로필을 또 하나 만들어 숫자만 키우지 않는다.
