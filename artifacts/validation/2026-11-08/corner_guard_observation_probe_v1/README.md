# 측방 접근 거절의 현재 관측 감사

짧은 코너 후보의 명령을 그대로 둔 읽기전용 계측이다. 원 입력1,891회에서 후보 명령과 차이0·생산소스 불변을 확인했다.

`guard_curve_rejected_toward_right`가 발생한48개 고유 스캔에서, 기존 거리/시차 여유를 적용한 **추가 접근 방향 표본17–129개가 모두 현재 자유 관측**으로 분류됐다. 기존 전체 이동영역 검사도48개 모두 차단하지 않았다. 과거 측방 기준에서1cm를 넘는다는 조건이 별도로 거절하고 있었다.

이 사실은 옆차 전체의 미래 움직임이나 가림 안의 안전을 보장하지 않는다. 다만 현재 관측까지 갖춘 후보를 같은 이유로 무조건 정지시킬 필요가 있는지 판단할 근거다. 현재 경로/전체 이동영역 검사와 추가 접근 표본 전부의 현재 관측을 함께 요구하는 [선택형 보완](../current_guard_approach_probe_v1/PLAN.md)으로 이어간다. [요약](summary.json)·[스캔별 근거](captures.json)를 보존한다.
