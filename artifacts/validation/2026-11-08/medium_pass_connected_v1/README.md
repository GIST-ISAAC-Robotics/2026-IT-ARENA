# r15 중속 상대 명시 추월 프로필

[설계·기존 범위](../medium_pass_design_v1/README.md)를 따라 `medium_v1`을 별도 연결했다. 기본 `slow_v1`의 자차0.65/상대 관측상한0.50/속도 이점0.15/대응탐색0.75m/s는 보존한다. 중속은 각각 **0.90/0.70/0.20/1.00m/s**이며 실제 선택된 경로의 명령에도0.20m/s 이점을 요구한다. 불리하면 정상 추종을 유지한다. 관측된 상대 가속 시 포기 기준도0.70에 맞추고 기존 완만한 양보·현재 후방 관측을 통한 복귀를 재사용한다.

현재 통로/점유·동일 스캔 확인·상대 모호성·구조 가림·독립 보호는 유지한다. 첫 스캔에서 추월 완료까지 모든 구간이 보여야 한다는 새 조건은 넣지 않는다. 현재 직선 경로·스윕을 계속 검사한다. 더 큰 대응 탐색은 다른 물체를 혼동할 가능성이 있으므로 기존 복수 후보 모호성 거절은 그대로다. 상대 신원을 확인하거나 미래 속도를 보장하는 기능은 아니다.

`--moving-pass-profile medium_v1`은 명시 `--moving-pass-trial`과 함께 써야 하며 ROS와 판단 헤더까지 기록된다. 기본 OFF인 추월 자체를 자동 활성화하지 않는다. 모터축 단일28카운트·8.970588:1·65mm, B0390·C1 순차10Hz·JR60P20, 현행 독립 보호·STOP은 같다.

등록 장면은 새 코스 grid3, 오른쪽12cm·등속0.50m/s 상대14초다. 상대 이동7m는 시작s43.26부터 첫 코너s51.34까지의8.08m 안이며 실제 평가기의 경로 검사를 수행한다. 이전 교통과 같은 명시 평탄 잔디 파생본이다. 단독 원래1mm 노면 증속에서 나타난 편측 제동 실패와 분리하며 그 실패를 고쳤다고 부르지 않는다.

**수용:** 진입→옆→앞→현재 관측 복귀→0.50m 이상 전진, 접촉0, 최대두바퀴잔디, 지속정체0.50초 이하, 명시STOP/정상종료/해시불변. 기존 원시 추종 판정(끝까지 앞차 뒤,최종 간격 등)은 별도로 보존한다. 한 장면의 실제 결과만으로 빠른 상대/독립5대/실차를 완료 처리하지 않는다. 아래 대표 실제 결과를 확인했다.

변경 전6파일은 `before.zip`, 출처계약 `config/tests/moving_pass_medium_r15_sha256.json`. 기존r13 저속 전체 판단을 별도로 재생해 기본 유지 여부를 확인한다. 대표 결과 뒤 정지차·정지/재출발·측방 대응/운영의 새 코스 연결을 우선순위와 비교하며 한 속도 단계의 희귀 예외만 계속 늘리지 않는다.

상대0.70m/s는 관측 오차를 포함한 **진입 추정상한**이며 실제0.70m/s 상대를 검증했다는 뜻이 아니다. 첫 실제 명목 상대는0.50m/s로 기존 공통 물체 이동 여유0.50m/s 범위에 둔다. 더 빠른 상대 단계에서는 공통 점유 시차 여유와 후방 외곽 갱신까지 함께 검토해야 한다. 대응 탐색1.00m/s는 물체 운동 보장값이 아니다.

## 실행 전 검증과 등록 도구 수정

관련270검사 통과, 기본 저속r13의749판단 전체 동일 재생,2패키지 빌드 통과다. 최초 등록은 쓰는 중인 `register_v1.log`를 해시 입력에 포함해 실행 전 거부했다. Gazebo는 시작되지 않았다. `registration_attempt1/`에 당시880입력·snapshot·거부/무결성 근거를 보존했다. 등록 helper를 실제 실행 스크립트/시나리오로 명시해 생성 로그를 제외했다. 소스·설정 무결성 검사를 없애거나 실패를 통과로 고친 것이 아니다. 동일270검사/빌드를 반복하지 않고 새 등록부터 진행한다.


## 실제 결과 — 등록 직선 한 상대1회

수정 등록868입력 불변으로14초 주행했다. **11.190m, 초록 뒤9.119초에 추월/복귀 확인, 복귀 후2.008m 전진**이다. 추월 중345판단의 명령 상한은0.90m/s이며 같은 구간 평가 차체 최고는0.923m/s였다. 전체 최고1.554m/s는 복귀 후 일반 주행이므로 추월 속도로 쓰지 않는다. 첫 움직임은 초록 뒤0.684초, 진행 뒤0.05m/s 미만 최장0.101초였다.

최소 표본/스윕 간격 약0.211m·접촉0·최대같은쪽2바퀴잔디·벽바퀴0이다. 명시 STOP/밀집 정지(최종 구간 최고0.006614m/s)/MCU 정지/정상 프로세스 종료를 확인했다. source/hash와 실제 `medium_v1`·B0390·새 단면/직각 옵션이 모두 일치했다. 근거는 `straight_moving_lead/assessment_run1.json`, `surface_run1.json`, `run1/report.json`이다.

원 검사기의 최종 간격·차체 전체도로 안·끝까지 앞차 뒤 판정은 실패이며 run exit1로 보존한다. 실제 추월 목적의 사전 보충 판정은 모두 통과했다. 최종 `final_relative` 횡좌표1.513m는 첫 코너를 돈 차를 출발 직선 좌표로 표시한 값이며 실제 도로 이탈 거리와 다르다. 실제 도로 다각형/바퀴 판정은 위 노면 결과를 쓴다.

이 결과는0.50m/s 등속·오른쪽12cm·한 상대의 제한 장면이다. 다른 상대 속도/중앙 막힘/후방 급접근/독립 다중차량/실차를 완료로 보지 않는다. 같은 속도 단계의 미세 손실을 반복 보강하지 않고 새 코스 중앙 정지차 우회 등 남은 기본 기능으로 이어간다. 고속 상대는 공통 점유 시차/입력 속도/상대 추적과 함께 후속 검토한다.
