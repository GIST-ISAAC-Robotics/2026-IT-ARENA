# r37 후방 가림의 감속 진행 비교

2026-11-08. r37 C1 주입 주행은20.22 m·최장저속34.456초로 실패했다. 접촉/노면 이탈0, STOP/정상 종료,906입력 불변을 확인했다. r37에서 고친 후방 무반환 범위 분기는 이번 기록에서 활성화되지 않았다. 같은 seed라도 시뮬레이션 실행의 시작·취득·주행 입력이 동일하다는 뜻은 아니므로, r35의42.55 m와 차이를 그 분기 수정의 성능 저하로 단정하지 않는다.

이번에는 코너에서 일시적인 측방 반환을 위협으로 본 뒤, 통과가 확인된 RELEASED에서도 높은 목표 속도의 후방 가림 꼬리 범위가10 mm를 넘어서 평행 경로로 전환했다. 평행 경로는 곡선에서 성립하지 않아 장기 정지했다. 위협 반환을 실제 차량 또는 벽으로 단정해 제거하지 않는다.

33.06/40.02/65.00초 저장 장면의 기존 이동 영역을 정확히 재구성했다. 실제 측정 속도는0이며 기존 목표0.75/0.60/0.70 m/s였다. 목표만0.35 또는0.25 m/s로 낮추면 가림 꼬리10.08–11.38 mm로 여전히 거부되지만,0.15 m/s에서는7.65–9.31 mm이고 일반 미관측/전방 가림은0이어서 **같은 보호 기준으로 양수 명령 후보**가 된다. 실제 주행 결과는 아니다.

별도 사본은 기존 경로가 `fully_observed`이고 오직 후방 꼬리 가림으로 거부된 RELEASED에서만0.35/0.25/0.15 m/s 중 원래 목표보다 낮은 값으로 재검사한다. 최대세 후보이며 첫 통과값을 쓴다. 실제 측정 속도·현재/직전 조향·입력 시각·점유·1 cm 기준은 그대로다. 낮은 목표를 냈다고 측정 속도를 낮추지 않는다. 일반 미관측·전방 가림·실제 측방 GUARD·STOP·정지 목표를 이 경로로 풀지 않는다. 실패하면 원래 결과를 유지한다.

표적20검사는 통과했다. 세 실제 장면과 같은 장면의 측정 속도를0.9 m/s로 둔 거절 대조도 포함한다. 부모3,041판단 동일, 사본 최초32.78초의 정지→0.15m/s, 무주입A3,051판단 동일을 확인한 뒤 [r38](../masked_motion_speed_v1/README.md)로 연결했다. 실제 결과와 처리 비용은 연결 문서를 따른다. `build_candidate.py`는 실제 src를 바꾸지 않는다.
