# 실행 전 셸 스크립트 실패

상대20cm 배치는 701도로 표본에서 도로안/벽침범0·최소도로가장자리30mm를 확인했고911입력을 등록했다. 그러나 run.sh의 Windows CRLF로 Bash heredoc 끝이 인식되지 않아 구문 오류로 종료했다. runtime 검사/시뮬레이션/주행은 시작되지 않았다. run1은 없으며 원 등록·스크립트·실패 로그를 보존한다. [v2](../faster_onroad_space_v2/PLAN.md)에 동일 파일을 LF로 복사하고 bash -n 선검사 뒤 새 등록으로 진행한다. 제어기·시험·판정은 변경하지 않는다.
