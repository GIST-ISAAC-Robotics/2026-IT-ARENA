# r40 통로 편이를 기존 실행 여유에 맞춰 비교

2026-11-08. [저장 입력 분석](../entry_width_transition_probe_v2/README.md) 후 r39를 부모로, 기본OFF인 기존 `adaptive_entry_preview` 안에서 최초 가까운 우회의 편이만 비교한다. 일반27cm 설정과 속도·노면·물성·점유·STOP·독립 보호는 그대로다.

사본11검사와 원 r39의208판단/첫 명령 차이13.08초까지 확인했다. 같은 스캔을0.08초 더 쓰는 기존 기준과 긴 현재 외벽 가정을 경로 순위에도 적용하여, 이 장면에서는27→28.75cm 편이를 제안했다. 실제 운전 허가는 기존 검사 전체가 별도로 한다. 좌우 반사 기하와 광선 취득 순서를 혼동하지 않았다.

[사전 계획](PLAN.md)대로 같은 정지차 STOP→RESET 없는 START1회로 실제 진행1.2m/25초·정착·접촉/노면·정상종료를 확인한다. 적용 후 관련385검사와 실제 실행 환경의28항목 import/설정 연결 대조를 통과했다. 다음은 동일 운영1회이며 아직 새 주행 성공이 아니다. `run.sh`가 등록부터 실행까지 수행하므로 별도 등록하지 않는다. 원 r33/r36/r39 실패는 보존한다.

## 실제 운영 대표1회 — 통과

18:27경–18:33경 실행. 재개 요청에서0.408초에 허가됐고, RESET 없이 같은 경기로16.318초에 기준방향1.200206m를 진행했다. 전체 재개 후 최대투영1.218838m·최종1.217493m·이동궤적1.266206m는 서로 다른 지표다. 두 연속0.5초 STOP 정착창의 피크는0.03918/0.01280m/s, 변위4.026/1.496mm였다. 첫/마지막 정착까지0.676/0.698초이며 실패 정리STOP은 없었다.

접촉0·최소표본간격96.64mm·최대두바퀴잔디·바퀴벽0을 확인했다. 차체도로밖 표본3,805개는 보존한다. 노면 평가는0/±0.45rad 조향의 이산표본이며 실측 조인트 시계열은 아니다. 등록919입력불변·snapshot불변·실제import28항목·정상종료·잔여PID0, 실행/전용평가 종료코드0이다. 관련385검사 통과와 이전 r33/r36/r39 실패를 보존한다.

13.06초 최초 비교는0속도 호출에서28.75cm 편이를 선택했고,13.12초에는 실제 선택이`offset_m=-0.2875, transition_m=0.7`인 상태에서0.35m/s·-0.06rad를 출력했다. 이후 반복 메타데이터730행 중 같은 편이의 양수선택574행이 기록됐다. 이는574번 새로 계획했다는 뜻이 아니다. 별도의 짧은 목표점 보조1회 통계와 편이 선택을 혼동하지 않는다. `permission_granted/control_authorized=false`는 제안 단계의 계약이며 최종 보호층 발행 불허라는 뜻이 아니다.

원 `run1/report.json`의 `passed=false`는 공용 실행기가 초기화한 뒤 갱신하지 않는 필드다. 이 시나리오는`completed=true`, 오류 없음이며 사전 등록된 전용`assessment.json`의21개 조건과 후보2조건이 모두 통과했다. 원 보고서를 수정하지 않았다. [독립 검토](review_result.json)는 실제 투영과 최초 양수선택을 다시 대조했다.

이 대표를 확보했으므로 추가 운영 미세조정보다 미완료 코너 병렬로 이동한다. 동적 상대 속 STOP/START·모든 배치·공용망·실물 성공으로 확대하지 않는다. 이 결과 문단과독립검토 도구는919입력 무결성 확인 뒤 추가한 문서/분석이다.
