# r40 가까운 정지차의 통로 편이 비교 연결

2026-11-08. [저장 입력 근거](../entry_width_transition_probe_v2/README.md)를 바탕으로, 기존 선택형 안에서 첫 진입 목표만 현재 통로 여유를 더 고르게 쓰도록 비교한다. r39 실패0.852m를 보존한다.

같은 r33/r36/r39 시나리오1회: 정지차43.26m, STOP42.26m, RESET/재배치 없이 START 허가3초, 재개 전 방향으로1.2m/25초, 연속0.5초 정착, 접촉0, 최대두바퀴잔디, 원시실패/정상종료/입력불변. 실패 시 그대로 반복하지 않는다. 과거 기준을 낮추지 않으며 제어기에 정답 자세/actor 상태를 넣지 않는다.

적용 후 관련 회귀와 실제 import/소스 계약을 확인한 뒤 실행한다. 기본OFF·기존 속도·물성·원시 점유·독립 보호를 유지한다. 테스트 당시 소스와 실행 이후 문서 갱신을 구별한다.
