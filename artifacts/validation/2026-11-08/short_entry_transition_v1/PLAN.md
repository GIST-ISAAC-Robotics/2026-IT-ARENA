# 가까운 정지차 재개: 최초 전이 후보 r39 준비

2026-11-08. r38 C1 주행을 완료·검토한 뒤 적용했다. 관련 회귀와 같은 운영1회 실행을 준비한다. 등록 이후 해당 입력을 동결한다.

원 r36 STOP→START는0.527 m 진행하고 멈췄다. 저장 입력에서 먼저 움직이기 전의 짧은 경로 후보를 비교한다. 기존 `adaptive_entry_preview`가 ON이고 관측 앞 간격에 맞는 등록 전이가 없을 때만, 기존 최소/선택 전이 사이 중간값 하나를 대조한다. 실제 관측 벽 구간·기존 조향 한계·원시 광선별 시차 여유와 기존 진행20mm/점 간격5mm 순위를 사용한다. 선택은 제안이며 기존의 점유/반응/제동/관측/독립 보호를 통과해야 구동한다. 이동 중 경로를 임의 재설정하지 않는다.

사본11검사, 원 r36의1,370판단 동일재현, 최초 실제 조향 차이13.16초까지 비교했다. 현재0.8m 전이 대신0.7m가 관측된 장애물 간격에 유리한 대표를 확인했지만 아직 실제 재출발 성공은 아니다. [근거](../entry_preview_continuity_probe_v1/README.md).

연결한다면 r33/r36의 같은 운영 시나리오를1회 사용한다. 정지차 위치43.26m·첫 STOP42.26m·RESET/재배치 없음·START 허가3초 이내·재개1.2m/25초·연속0.5초 정착·접촉/최대두바퀴잔디·정상종료/입력불변 기준을 유지한다. 첫 STOP와 진행실패 시의 정리 STOP를 기대 시나리오 완료와 구분한다. 실패하면 같은 조건을 반복하지 않는다.

r38도 부모에 포함되므로 r36 대비 결과가 이 경로 수정 하나의 인과효과라고 단정하지 않는다. 기본 OFF와 기존 미완료 교통/코너/속도 과제를 유지한다.
