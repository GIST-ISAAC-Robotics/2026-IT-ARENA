# C1 잡음 뒤 통과 상태의 관측 범위 대조

2026-11-08. r35 실제 주행은42.55m에서 멈췄다. 첫코너 모서리 실패는 개선됐으나 사례끝까지6.764초 정체했으며 실패 판정을 보존한다. 현재 결과는 저장 입력 분석·별도 사본이고 새 주행/생산 반영이 아니다.

## 원인

`probe.py`는60.36/60.60/64.00/67.00초 입력으로 기록된 `selector_region` 전체를 정확하게 재구성했다. 정지의 직접 조건은 RELEASED 선택자의 `large_motion_region_unobserved`이며, 독립 보호층은 clear였다. 지속 patch는 정적 벽과 겹쳤지만 그 patch가 현재 STOP을 직접 일으킨 것은 아니다.

실제 미지지 질의148/159/440/733개는 차량 전방 x=0.100–0.211m, 왼쪽 y=0.041–0.155m에 있었다. 실제 필요한 광선은 약42–50도이며 기존 원시 +inf·양옆 반환·3도 공백·전체6도·현재 점유 팽창 검사는 통과한다. 그러나 `same_path_gap_trial.scope_check`는 질의와 관계없는 정후방 약175–180도(index0) 무반환까지 검사해 측방 증거를 취소했다. 후방 unknown을 자유로 바꾸자는 의미가 아니다.

## 별도 후보

기존 같은-경로 검사가 각도 범위에서만 실패한 경우에 한정한다. 현재 증거 시각/조향/속도/원래 확인된 이동영역은 먼저 그대로 확인한다. 전방30도 이내 결측은 여전히 측방 증거와 모순으로 거부한다. 실제 **전체 이동 질의**가 원래 원시+inf·반환·점유·각도 검사를 모두 통과하고, 이 질의에 사용된 모든 무반환 묶음이 기존30–100도 측방 범위 안일 때만 해당 증거를 유지한다. 다른 방향으로의 이동 허가나 센서 채우기는 없다. 범위 밖 후방 질의가 실제 필요하면 그대로 거부한다.

표적29검사는 관계없는 후방 광선, 실제 후방/전방 질의, 가까운 반환, NaN/음수무한대/최소거리 이하, 넓은 공백, 명령/시각 불일치, 기존 장면 출력 불변을 포함한다. `candidate_manifest.json`에 현재 생산 before와 사본 after를 기록했다. 생산 소스는 진행 중인 r36 실제시험 때문에 동결 중이다.

고정4장면 대조는3개가 지역 증거를 회복했다. 60.60초는 `different_or_larger_motion`으로 계속 거부됐다. 처음4개 모두 양성을 기대한 검사는 실패했으며 `candidate_first_four_positive_expectation_failed.json`에 보존했다. 이 조건을 완화하지 않고 해당 장면의 거부 유지도 확인하는 것으로 검사를 바로잡았다. 실제 이력 재생과 주행은 별도다.
