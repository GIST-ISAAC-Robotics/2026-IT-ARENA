# 빠른 뒤차 피추월 r24: 실제 비교

2026-11-08. [같은 r23 기준선](../rear_overtake_fixture_v1/README.md)과 동일한 6.8초·뒤 -1.10 m·왼쪽 280 mm·100 Hz·최고 1.8 m/s 평가 상대를 한 번 실행했다. **피추월 구간의 0명령 10개→0개**, 차체 속도 표본 최소 **0.118→0.241 m/s**였다(초록 후 4.1–5.4초 동일 창). 옛 측정속도 1 m/s 거부가 실제로 없어졌으며, 목표 0.35 m/s 제한은 남는다.

뒤→옆→앞과 통과 뒤 **1.304 m 전진**, 총 **6.342 m**, 접촉/노면 이탈 0, 간격 하계 **0.1304 m**, STOP/정상 종료·883개 입력 불변을 확인했다. 첫 움직임 이후 0.05 m/s 미만 표본은 두 실행 모두 0이다. 원 평가의 최장 저속 **0.506초는 최초 초록 뒤 출발 전 구간**이며, 주행 중 다시 멈춘 시간으로 해석하지 않는다. [수치·구간 대조](comparison.json).

사전 등록 보충 목표 12개·장면 성립 6개는 통과했다. **원시 검사기 exit 1과 15 cm 간격·앞차 뒤 유지·최종 간격 실패는 보존**한다. 상대를 앞차로 유지하는 원 판정과 뒤차가 추월하는 목표를 구분한다. 80 mm 대표 목표를 사후 완화하지 않았다. [원 보고](left_rear_overtakes/run1/report.json)·[보충 판정](left_rear_overtakes/assessment_run1.json).

이 장면은 대표 피추월이 성립한 단계이며 고속 병렬·코너 병렬·모든 방향·실차 검증은 아니다. 측방 저속 상한을 높이는 작업은 후속으로 남기고 단독 증속 후반 미완주를 먼저 보완한다. 현재 옵션의 기본 OFF와 독립 보호 경계를 유지한다.
