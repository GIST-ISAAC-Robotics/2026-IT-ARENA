# 코너 병렬 장면의 시간 배치 대조

2026-11-08. 실제 주행 전 평가 배치 검토다. r46 기록의 자차 자세는 고정해 두고 상대 초기 종방향 위치만 −0.15/−0.45/−0.65/−0.85 m로 바꿔 같은 원호에서 대조한다. 각 후보의 상대 노면/벽·초기 외곽 간격·기록 자차와의 가상 간격·코너 병렬 구간을 계산한다.

원 r46의 32초 실패와 판정선은 바꾸지 않는다. 뒤쪽에서 출발하는 후보는 같은 코너 출구까지 더 긴 거리를 달리므로, **새 배치 설계에 한해** 상대 경로 길이로 종료 시간을 산출한다. 그 시간을 원 r46의 성공으로 소급하지 않는다.

자차는 새로운 상대 배치를 관측하면 다르게 움직일 수 있다. 따라서 저장 자차와 가상 상대가 나란하다는 결과는 실제 병렬 성공이 아니다. 적합한 후보가 없으면 배치만 억지로 바꿔 계속 반복하지 않고 근거를 남긴다. 모든 정답 위치는 평가기에만 있다.

네 후보 모두 정적 노면/벽을 통과했으나 기록 자차와의 병렬은0초였다. 기존 자차 자체가20–70°인 연속표본은 r46 0.403초, r47 0.302초여서 출발위치만 바꿔 해당기록에서0.5초를 만족시키는 것은 불가능하다. r45는0.504초였지만 상대가 이미앞에 있었다. 시작위치 탐색을 더늘리지 않는다.

다음 기하 비교는 출발위치가 아니라 **코너에서 감속하는 상대**다. 기존 일정속도 원호·평가용 각본 인터페이스를 그대로 쓰고, 상대 경로 구간별 속도로 출구까지의 새 시험 시간을 사전 계산한다. 실제로 병렬관계가 생기지 않으면 그 자체를 미성립으로 남긴다.
