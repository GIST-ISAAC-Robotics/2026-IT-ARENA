# 후방 면 연속 관측 연결 r18 — 정지차 대표 완료

정지차 r17의9.210초, 정지/재출발의5.164초 저속 손실을 줄이기 위한 선택형 연결이다. [v2 저장 입력](../rear_face_motion_shadow_v2/README.md)에서 각각90/51개 0→양수 명령을 확인했다. 동일20초 대표에서 아래 실제 결과를 확인했다.

현재 긴 벽과 알려진 구조 가림 양쪽의 실제 짧은 후방 면을0.8초/9개 서로 다른 스캔에서 대조한다. 기존 접근/끝점 오차와3m/s² 가속 가정은 유지한다. 짧은 면을 정적 벽으로 합치거나 자유 공간으로 채우지 않는다. 같은 스캔 재사용·현재 면 손실·시각/세대 변경·새 접근은 관측을 대신하지 않는다. 이동 여유 조정은 차체 뒤끝보다 뒤인 실제 해당 광선에만 적용하며 전방 점은 보존한다. 실물 운동 상계 증명이 아니다.

기존 `--handoff-wall-witness` 선택에 연결하며 기본false는 유지한다. 기존 벽 기준 출력과 이동차 명령을 대조한다. 관련 회귀→두 저장 입력 수치 대조→동일 정지차20초 대표1회 순서로 진행한다. 원 판정/노면/STOP/종료 기준은 바꾸지 않는다. 이후 현재 결과를 기록하고 측방 대표·운영·증속 순서로 이어가며 한 후보를 무기한 다듬지 않는다.

변경 전 소스는 `before.zip`, 변경 계약은 `config/tests/rear_face_motion_r18_sha256.json`이다. 등록·실행 증거는 `persistent_block/`에 보존한다.

## 회귀 중 발견한 기존 검사 불일치

첫 회귀는273통과·1실패다. 실패 검사는 launch에 `g2_corridor_policy` 문자열 자체가 없어야 한다고 가정했지만, HEAD에서도 이미 명시 평가 분기 안에 존재했다. 실제 기본 `evaluation_handoff_reserve=off`·독립 보호 경계를 검사하고 해당 정책이 `reserve != off` 분기 안에서만 설정되는지 대조하도록 검사만 수정했다. 제어기 기본값을 바꾸지 않았다. 이전 검사 원본은 `before_test_v1.zip`에 보존했다. 첫 exit파일0은 실패 요약과 불일치하므로 실행 종료 코드 증거로 사용하지 않는다. 후속 실행은 파일형 bash에서 코드별 종료값을 보존한다.

## 연결 검증 완료·실행 중

첫273검사 통과 뒤 수정한 기본 설정 검사1개도 통과했다. 정지차1,058·재출발959개 수치가 v2후보와 일치하고(변경90/51개), 기존 이동차749개 전체 판단도 일치했다. 후속 각 실제 종료 코드는0이다. `run_live.sh`로2패키지빌드·기하·등록·동일 정지차20초1회를 완료했다.

저장 입력 호출의 host wall시간은 정지차 중앙50.8ms/최대180.7ms, 재출발48.6/179.0ms다. 기존 구현과 동일 조건의 비용 차이는 아직 측정하지 않았으며 이 값은50Hz 실시간 처리나 Jetson 통과를 의미하지 않는다. 최신 통합 입력/비용 검증 과제에 남긴다.
