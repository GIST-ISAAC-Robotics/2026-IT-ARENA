# r46 현재 코너 경로의 공통 구간 일치

2026-11-08. [전환 감사](../corner_r45_transition_audit_v1/README.md)와 [사본](../retained_corner_agreement_probe_v1/README.md)을 따른다. 기존 선택형 `traffic_boundary_refresh_trial`·직각 경로 안에서만 이미 채택한 벽의 현재 긴 관측을 갱신할 때 호길이 비교를 재사용한다.

현재 긴 벽·앵커·유효한 기억이 먼저 있어야 하며, 기존 x좌표 비교를 우선한다. 그 비교가 실패하고 현재 모델이 `piecewise_corner`일 때만 동일80 mm/공통0.25 m/5점 기준의 기존 `path_agrees_arc`를 사용한다. 경로 길이가 다른 코너 출구 때문에 공통 부분이 탈락하지 않게 하며, 먼 미관측을 자유로 바꾸거나 기억 유효기간을 연장하지 않는다. 나머지 경계 선택·속도·점유·독립 보호는 유지한다.

사본8검사 통과 뒤 r45의1,644판단 중45출력이 바뀌었다. 최초36.42초, 새호길이비교6회이며33초이후 경계미확정0명령45→25·재출발대기20→15회다. 이는 저장 입력이며 실제 주행 증명이 아니다.

생산 연결 뒤 관련회귀와 사본명령 일치·기존 빠른FOLLOW/중속 불변을 확인하고, r45/r41과 동일한32초코너 장면을1회 실행한다. 기존진행10.5m·출구/헤딩·코너병렬0.5초·접촉0·80mm 보조간격·최대두바퀴잔디·STOP/정상종료/입력무결성을 유지한다. 원150mm 등 실패도 그대로다. 실패 시 시간을 늘려 성공시키거나 같은 시험을 반복하지 않는다. 기존 기본OFF를 유지한다.
