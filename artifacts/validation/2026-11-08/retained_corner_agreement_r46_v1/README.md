# r46 현재 코너 경로의 공통 구간 일치

2026-11-08. [계획](PLAN.md)·[사본 비교](../retained_corner_agreement_probe_v1/README.md)를 따라 현재 긴 반대 벽의 유지 분기에만 기존 호길이 비교를 재사용했다. 다른 벽 선택·속도·TTL·점유·독립 보호·기본 OFF는 유지했다.

관련 **357검사**를 통과했다. r45 저장 입력의 **1,644명령은 r46 사본과 일치**했으며, 기존 빠른 FOLLOW 548명령과 중속 추월 753명령은 불변이었다. 1,644명령이 수정 전 r45 출력과 같다는 뜻은 아니다. [재생 요약](replay_summary.json)과 원시 로그를 보존한다.

실제 실행 경로 29항목 확인 뒤 r45와 동일한 32초 장면을 한 번 실행했다. **진행 9.90 m, 최장 저속 1.007초, 코너 병렬 0초로 실패**했다. 요구한 출구·방향 전환·10.5 m 진행을 달성하지 못했다. r45의 10.01 m·0.703초보다 실제 주행이 개선됐다고 할 수 없다.

접촉 0·약 100 mm 표본/보간 간격·최대 두 바퀴 잔디·STOP·정상 종료를 확인했다. 80 mm 보충 간격은 통과했지만 원 150 mm 간격 등 원시 실패도 유지한다. 등록 입력 927개와 스냅샷이 불변이며 자기 시험 프로세스는 남지 않았다. GPT가 등록 해시와 평가·판단 원본을 별도로 대조했다.

현재 두 면 코너 지지는 15판단, 전경 가림 근거는 2판단에서 사용됐다. 후반 37.62–38.50초에 경계 미확정으로 0명령이 이어졌고 38.62초부터 다시 진행했다. 주행 창 밖의 최종 STOP은 이 집계에 섞지 않았다. [판단 검토](decision_window_review.json)·[보충평가](assessment_run1.json)·[무결성](postflight_integrity_run1.json)을 참조한다.

같은 시험을 반복하거나 평가 시간을 늘려 통과시키지 않는다. [r46 경계 전환 감사](../corner_r46_transition_audit_v1/README.md)에서 현재 관측·경로 일치·기억 만료를 분리한 뒤 다음 설계를 결정한다. 실제 지속 코너 병렬 기능은 미완료다.
