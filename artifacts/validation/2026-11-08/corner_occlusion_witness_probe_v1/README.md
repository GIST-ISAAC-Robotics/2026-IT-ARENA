# 코너 뒤쪽 벽의 현재 가림 증거 — 미연결 후보

[원인 감사](../corner_r41_cause_audit_v1/README.md) 뒤0.5m 제한에 걸리는 far-face 구간을 현재광선으로 비교한다. 두 실제직선면과 유효한직전코너라는 기존조건은 유지하고,0.5m를 넘는구간은 실제벽반환 또는 그벽보다가까운 전경반환으로 설명될때만 경로가설을 제안한다. 추가범위는1.2m 이내, 대상5광선이상·80%이상설명·전경3광선이상/벽투영폭0.1m이상, 예상벽뒤모순반환0을 요구한다. 이 수치는 비교용 설계값이며 실제벽 존재나 통과안전의증명이 아니다.

현재/직전센서시각·미관측·점유·독립보호·속도·TTL은 변경하지 않는다. 생산소스는변경하지 않았고, `original.py`에비교원문을보존했다. 고정 입력·반례 12검사를 통과했다. 35.72/35.82초는 기존 경로와 같고 35.92초는 검사 광선32개 모두를 설명했다(전경29개·반박0). 근거/유효기간 제거 반례에서는 거부했다.

전체 r41 저장1,628판단을 재생하자 최초차이는35.92초였고214명령이 달라졌다.33초 이후 경계가 없어서 나온0명령은215→6회, 측방 방향 제한0명령은20회로 같았다. 실제 새 가림 근거는2스캔에서 사용했다. 원래 실행궤적을 계속 공급한 반사실 비교이므로 실제 주행 성공이 아니다. [replay_summary.json](replay_summary.json)에 소스불변을 보존했다.

후속 생산 연결은 [r45](../corner_occlusion_connected_r45_v1/PLAN.md)로 분리한다. 이 폴더의 후보/원문과 결과는 시험 당시 사본으로 보존한다.
