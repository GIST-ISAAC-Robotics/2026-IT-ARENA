# r14 사선 좁은 공백의 선택형 저속 연결

[저장 입력 원인·비교](../solo_straight_gap_v1/README.md)에서 원본1,807명령 동일 재생, 정지 전 변화0, 정지 뒤367호출의 양수 후보를 확인했다. 해당 고정 피드백 비교는 실제 탈출 증명이 아니다.

`FollowConfig.oblique_gap_trial`·ROS `g1_oblique_gap_trial`·단독 CLI `--oblique-gap`으로 명시 선택한다. **기본 false**, 단독 `bounded_local_v4` 조건이 필요하다. 계획기와 독립 LiDAR 보호층은 각자의 객체·입력·이력으로 검사하며 `/drive`→보호층→`/drive/safe` 연결은 유지한다.

기존 v4의 사선 공백 최소각60°를30°로 확장하는 운용 후보다. 현5cm·실제/요청속도0.6m/s 이하·명령0.2m/s 이하·유효 이웃1m 이상·현재 점유·이력과 가까운 물체 소실 검사는 유지한다. 무반환을 반환/빈 공간으로 채우지 않는다. 작은 물체가 공백에 숨는 위험은 남으므로 완전한 관측이나 실차 안전으로 부르지 않는다.

변경 전7파일은 `before.zip`, 해시는 `before_sha256.json`, 후속 계약은 `config/tests/oblique_gap_r14_sha256.json`이다. 옵션OFF의 과거 출력·기본 정책은 보존한다. 관련251회귀 통과·옵션OFF 원본1807명령일치, ON 변경372/정지후양수367을 확인했다. 재생 근거는 `replay_comparison.json`·`replay_changed.json`이다. 실패했던 증속 코스에 이 옵션 하나를 추가한 실제 비교1회는 아래처럼 더 앞에서 실패했다. 재생 결과로 실제 탈출을 단정하지 않는다. 원래1mm 노면·차량·속도·기어비·조향·정지/노면 판정은 그대로다.

실제 주행이 성립하면 이번 미관측 조건의 더 드문 조합을 반복하지 않고 중속 상대 추월과 미완료 교통/운영으로 이어간다. 실패하면 첫 중요한 원인과 원시 근거를 남기고 r11 성공 기준선을 유지한다. 같은 실패를 변경 근거 없이 반복하지 않는다.


## 실제 비교 결과 — 새 후보 미호출 상태의 선행 실패

**35.15m·0랩·최고2.879m/s, 미완주**다. 약23.698초에 중심선 오차0.400m로 평가를 종료했다. 접촉 메시지는0이지만 최대4바퀴 노면 이탈·이탈1.214초·패널티 사건0.509초를 기록했다. `comparison.json`의 짧은 종료 시간은 완주 시간 개선이 아니다.

옵션/헤더는 ON이지만 safety partial 688표본이 모두 `fully_observed`였다. 기존42.68m의 무반환 지점에 도달하지 않았으며 **r14 저속 보완의 탈출 성능을 확인하지 못했다.** 실패 결과를 보완 효과나 원인으로 돌리지 않는다. 입력866개 해시 불변, STOP/밀집 정지와 정상 프로세스 정리를 확인했다. 최종 MCU `software_stop`·목표0·바퀴0이지만 `stationary_ready=false`였던 차이는 보존한다.

[사후 진단](departure_diagnosis.json)에서 제동 중 오른쪽 바퀴는 차체 약2.06m/s에 맞춰 회전하는 동안 왼쪽 바퀴가 거의 멈추거나 역회전했다. 모터축 환산값은 두 바퀴 평균이므로 약0.73–1.22m/s를 보고했지만 차체는 약2.06m/s로 계속 움직였다. 이어서 경로가 불성립하고 도로를 벗어났다. 같은 위치의 r11은 양 바퀴/차체가 함께 약1.2m/s로 감속했다. 차체 높이·피치·롤의 큰 변화는 없었다. **편측 바퀴와 차체 속도 불일치는 확인했으나 접촉력 자료가 없어 마찰/접지 원인을 확정하지 않았다.** 옛 양바퀴 엔코더로 돌아간 것이 아니며 정답 차체 속도를 제어기에 넣지 않는다.

증속 후보는 미완성으로 남기고 r11 기준선을 보존한다. 다음 속도 작업은 이 제동/접지 차이를 분리하는 것으로, 무반환 각도만 계속 바꾸거나 같은 전체 랩을 반복하지 않는다. 현재는 독립 진행 가능한 중속 상대 추월 프로필 연결로 넘어간다. 관련 차체/노면 문제를 해결하지 않았다고 명시한 채 기능별 기본 수준을 채운다.

후속 [정적 노면 대조](road_support.json)에서는 진행33.0–34.8m의 양쪽 뒷바퀴 중심이 같은0.003m 상면 도로 박스에 놓였다. 이 다섯 자세의 기하만으로 실제 접촉력을 알 수는 없지만, 잔디 단차 때문이라고 단정할 근거는 없다. 도로/잔디 높이 또는 마찰을 이 결과만으로 변경하지 않는다.
