# 후방 짧은 외곽 면의 현재 운동 근거 — 저장 입력 비교만

정지차 r17의9.210초, 앞차 정지/재출발의5.164초 저속 손실을 비교한다. 제어 소스/기본값/실제 주행에는 아직 반영하지 않았다. 같은 저장 입력을 기존 구현으로 전부 재현한 뒤 후보 출력을 비교한다.

후보는 기존 `BoundaryMonitor`의 서로 다른5스캔/0.4초 창·현재 면 연속성·접근량3cm·평균오차6cm·시작가속3m/s² 가정을 재사용한다. 이 가정은 실측 타차 운동의 상계가 아니다. 현재 긴 외벽에 정렬되고 설명된 구조 가림 너머에 실제12반환/20cm 이상으로 보이는 조각 중 **차체 뒤끝 뒤**에 있는 점만 대상으로 삼는다. 짧은 면을 정적 벽으로 합치지 않는다. 전방·안쪽 상대·미관측/마스크·독립 보호/STOP은 그대로이며, 조각이 사라지거나 시각/연결이 깨지면 창을 버린다. 내부운동/기어비와 정답입력 경계도 같다.

증거 수집용 `rear_wall_witness`는 경로가 이미 후륜축까지 보여도 후방 조각을 확인하도록 조기 반환 하나만 제거해 복제했다. 원 좌표/각도/광선/5cm 가림 폭 검사는 바꾸지 않았다. 복제 원문 해시를 결과에 기록한다. 이는 저장 입력 후보이며 코드 채택/실제 주행 개선 증명이 아니다. 판정선을 낮춰 원 실패를 통과로 바꾸지 않는다.

완료 JSON의 baseline은 정지차1058/재출발959판단 전체 동일이다. 후보는 정지차 변경0, 재출발11개0→양수다. 정지차 래퍼 오류로 실제 Python exit는 미확인(빈 exit파일 보존), 재출발은exit0. 면의 안정 근거는 성립했지만0.4초 창의 평균오차항 때문에 출력 개선은 부족했다. v2에서 후방 면에만 더 긴0.8초/9스캔 근거를 한 번 비교하고, 부족하면 값맞추기 반복 없이 다음 대표로 이어간다.
