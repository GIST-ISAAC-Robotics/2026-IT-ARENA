# 새 코스 교통 경기 거리 — 5랩 주행

2026-11-08. [r27 한 랩](../traffic_faster_reacquire_live_v1/README.md)의 제어기·센서·두 상대·간격/물성/STOP을 유지하고 비교 창만300초로 늘려1회 실행했다. 평가 프로세스에는 보존된1/5랩 경로 검사만 연결했다. 정답 위치·지도·상대 각본은 평가용이다.

**240.14m 진행·거리5랩 통과**, 출발 후0.05m/s 미만 최장0.403초, 접촉/바퀴 이탈0이다. 최고1.570m/s는 교통 주행 피크이며 평균 추종 속도나 단독10km/h 속도와 구분한다. 두 상대는0.8m/s 각본 차량이다.

이는 grid3에서의 연속거리 기준이다. 공식 계시선 판정, 자체5랩 종료, 독립5대 자율주행 경기나 실차 시험은 아니다.

최소 표본/스윕 간격은0.60678/0.60544m, 추가 상대 최소1.64225/1.64143m였다. 상대 최대 추적오차0.0112m, 원시 pose 최대 간격0.01초를 확인했다. 노면150,805개 표본에서 세 해석 모두 이탈 바퀴0·벽 바퀴0이었다. STOP6항목·정상종료14개 프로세스·잔여PID없음·등록888입력 불변이 통과했다. STOP 정착 표본 최고0.00926m/s·변위0.00498m를 기록했다.

원 검사기의 **최종 간격1.25091m > 1.2m**만 실패했다(`HARNESS_EXIT=1`). 원 나머지12개 판단은 통과했고, 사전 보충12목표도 통과했다(`ASSESSMENT_EXIT=0`). 이 원 실패를 통과로 고치거나 목표를 조정하지 않는다. 실행 벽시각3297초와 시뮬레이션300초를 구분한다.

## 남은 범위와 다음 작업

이 대표에서는 반복 코너의 장기 정체 없이 경기 거리를 주행했다. 공통 점유 시차의0.5m/s 가정과 상대 전진 관측은 별개이므로0.8m/s의 모든 방향 운동을 보장하지 않는다. 공유망/Jetson 실물, 지속 코너 병렬, 더 빠른 상대 추월, 교통 속 운영 재개는 남는다. 원 종료 간격 약5cm만 줄이는 시험을 반복하지 않고 다음 미완성 기능으로 넘어간다.
