# 빠른 추월의 측방 비접근·가변 속도 (미연결)

[계획](PLAN.md), [첫 사본의 출력 변화 0](../faster_departure_stage_v1/README.md), [현재 속도를 자르지 않은 두 번째 비교](summary.json). 기존 r32 저장 입력 527판단에서 0명령은 268→170, 새 0명령은 없었다. 바뀐 98개 명령은 모두 0.207~0.230m/s였고, 최초는 13.24초다. 하지만 연속 양수는 최장 **3판단(20ms 제어 주기에서 약60ms)**뿐이다. 스캔 한 주기마다 명령이 끊겼고, 최대 연속 0명령도 253→84판단으로 남았다. 상대가 관측 범위를 벗어난 뒤에는 사용하지 않았다. 따라서 98개 해제를 실제로 부드러운 주행이라고 보고하지 않으며 **시뮬 주행에 연결하지 않는다**.

속도를 낮추어도 34개는 기존 이동 영역이 관측되지 않았고, 33개는 측방 비접근 식 자체가 성립해도 다른 반환의 제동 간격이 0이었다. 4개는 현재 측정 속도만으로 1cm 횡이동을 초과했고 1개는 반응·제동 거리 창 밖이었다. 원 자기 자세에서 벽은 전방으로 약 -0.12 기울어져 있어, 직전 조향을 무조건 0으로 두는 비교는 사용할 수 없다.

다음 방향은 멀어지는 앞차를 향해 계속 바깥 편이로 진입하는 대신, 정상 추종이 안전하게 가능할 때 추월 시도를 보류·취소하는 것이다. 측방 공간 확인 없이 옆차 쪽으로 복귀하지 않는다. 거리/속도 추정에는 실제 모터·IMU/C1 입력만 사용한다.
