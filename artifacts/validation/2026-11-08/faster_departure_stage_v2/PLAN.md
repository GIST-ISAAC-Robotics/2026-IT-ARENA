# 빠른 추월 편이 경로의 제한 전진 (저장 입력 우선)

**목적:** 움직이는 앞차를 추월하려다가 현재 바깥벽의 측방 시차 여유 때문에 멈춘 r32에서, 같은 조향으로 반환에 더 접근하지 않는 짧은 전진을 확인한다. 후보가 추월을 보장하는 것은 아니다. 고정 벽 신원 분류, 신호/마커 인식이나 상대차 정답은 사용하지 않는다.

- 처음 편이를 선택할 때, 이미 옆에 선 대상, 뒤로 돌아가는 복귀 단계, 현재 추적에 실패한 상대에는 적용하지 않는다. 기존 추월 경로가 있고 현재 상대의 후단 하계가 자차 앞보다 충분히 앞이며, 바깥벽이 두 스캔 이상 일치해야 한다.
- 원 경로와 직전 조향의 원 점유 검사에서 실제 전진 여유가 0인 경우만 대조한다. 겹친 모든 현재 반환이 실제 바깥 기준면과 일치하는지 검사한다. 측방 시차 겹침 외에 앞·안쪽 반환이나 고정 여유 침범이 있으면 승인하지 않는다. 모든 반환의 1.2m/s 시차 여유와 독립 보호를 유지한다. 제한 전진의 점유 검사에만 기존 피추월의 비접근 해석을 재사용한다.
- 기존 경로의 실제 조향/점유·0.4m 비접근 창, 0.025m+거리오차의 고정 여유, 0.01m 횡이동, 측정 속도의 반응·제동 거리와 열린 이동 영역을 모두 확인한다. 속도는 0.35m/s 이하이며 직전 조향을 0으로 대체하지 않는다. 움직이는 물체의 미래 접근을 보장하지 않는다.
- v1에서 0.35m/s 후보를 매번 사용해 136개가 횡이동 기준에 걸렸다. v2는 동일한 1cm까지 허용되는 속도만 이분 탐색한다. 실제 측정 속도가 이미 넘으면 새 전진을 주지 않는다.
- 승인 기준: 원 r32 고정 입력에서 의미 있는 연속 양수 명령 발생(한두 프레임만 해제하면 폐기), 새 정지0, 원본·반례 보존. 적용 시 독립 보호/STOP과 중·저속 기본 재현을 유지한다. 조건이 성립하면 같은 0.70m/s·10초 대표를 한 번만 실행하여 r32의 실제 추월·복귀·노면·개입 기준을 그대로 비교한다. 한 회의 정체 원인 변경 없이 반복하지 않는다.
