# r47 현재 벽 갱신 실패 뒤 코너 대안 연결

2026-11-08. [r46 감사](../corner_r46_transition_audit_v1/README.md)와 [v2 사본](../current_corner_fallback_probe_v2/README.md)의 연결이다. 현재 유지 벽을 먼저 갱신하고 실패한 경우에만 충분히 긴 현재 선호 코너를 같은 유효 이력의 공통 호길이와 비교한다. 기본 OFF·관측 길이·앵커·TTL·점유·독립 보호·속도는 불변이다.

v1의 조기 벽 전환은 경계 미확정 0명령45→50으로 나빠져 미채택했다. v2는 7표적검사 뒤 r46 저장 1,635판단에서20명령이 바뀌고 최초37.52초, 경계 미확정0명령45→30이다. 이는 저장 입력 개선이며 실제 주행이 아니다.

관련 회귀·사본 명령 일치·기존 빠른 FOLLOW/중속 추월 불변·실제 실행 경로를 확인한 뒤 동일32초 장면을1회 실행한다. 진행10.5m·코너 출구/방향·병렬0.5초·접촉0·80mm 보충간격·두바퀴잔디·STOP/정상종료/무결성 기준을 유지하며 원150mm 실패도 보존한다. 같은 코너에서 앞차가 먼저 빠져나가는 관측 한계가 있어 출구 개선과 실제병렬 성립을 따로 보고한다.

재실행으로 성공시킬 때까지 반복하거나 시간을 늘려 기존 실패를 덮지 않는다. 이번 연결 결과 뒤에는 같은 장면의 미세한 정지시간만 더 줄이기 전에 실제 병렬 장면의 성립 여부와 아직 미완성인 빠른 추월·지름길·최신 이관의 경기 영향을 비교한다.
