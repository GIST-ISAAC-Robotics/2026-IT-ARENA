# 피추월 측정속도 보완 r24 연결

2026-11-08. [오프라인 후보](../rear_overtake_continuity_review_v1/README.md)를 기존 선택형 평행 경로에 연결했다. 기본 OFF, 목표 최대 0.35 m/s, 측방 이동·현재 점유·독립 보호·두 fresh 재확인은 유지한다. 명령 상한을 넘는 측정값은 그대로 사용하여 반응·제동 거리와 현재 경로/관측 범위를 확인한다. 과거 1 m/s 실험 상한만 넘었다는 이유로 즉시 정지하지 않는다. 실물 제동 보증은 아니다.

관련 회귀 **343개 통과**. 기존 기록 376판단·377reset 재생은 기록 대비 178개 전체 출력 차이가 있지만, **시험해 둔 오프라인 후보와 연결 후 재생 행 전체는 동일**하다. r23 기준 자체의 원 기록 대비 6개 차이와 후보의 실제 10개 명령 변경을 구분한다. [연결 대조·PC 계산 비용](connection_review.json), [원 재생](replay_connected_result.json).

[전후 스냅샷](before.zip)과 [r24 변경 계약](../../../../config/tests/parallel_measured_continuity_r24_sha256.json)에 제어기 한 파일과 평가 경로 두 파일을 기록했다. 과거 계약을 수정해 실패를 덮지 않는다. 새로운 side_two_wheel_straight는 평가 상대 바퀴 중심 최대 두 개 허용을 명시할 때만 사용하며 기존 완전 도로 경로는 그대로다.

다음은 [r23 실제 기준선](../rear_overtake_fixture_v1/README.md)과 같은 6.8초·좌280 mm·100 Hz 상대를 [r24](../rear_overtake_measured_v1/PLAN.md)로 한 번 비교한다. 저장 입력 개선만으로 실제 정지 감소를 주장하지 않는다.

실제 같은 배치 비교는 [r24 결과](../rear_overtake_measured_v1/README.md)를 따른다. 피추월 구간 0명령 10→0개·최소 속도 표본0.118→0.241m/s. 새 계산의 PC 비용 중앙13.35→15.58ms·p95 22.78→49.27ms로 증가했다([대조](cost_comparison.json)). 다른 시각의 1회 재생이므로 정확한 증가율/Jetson 마감 보증은 아니나, 높은 측정속도의 관측 외곽 검사를 추가한 비용은 다음 통합 연산 점검에 남긴다. 단독 경로에는 이 평행 선택기를 쓰지 않는다.
