# r43 동일 판정 계산 최적화

2026-11-08. [r41 비용 분해](../r41_cost_breakdown_v1/README.md)를 근거로 GPT가 범위를 설계하고 Claude가 구현했다. 5시간 사용량 경고 뒤 GPT가 인계·최종 검토, GPT-6 Luna가 전체 재생·회귀를 수행했다. 인계 당시 미완료 상태는 [HANDOFF](HANDOFF.md)에 그대로 보존한다.

## 변경

- `scene_from_scan`: 같은 마스크 설정을 첫 광선에서 한 번 해석한다. 공개 API와 잘못된 입력·빈 스캔의 예외 순서는 보존한다.
- `threat_view`: 같은 호출의 반환 요약을 `ObservationGrid`에 복사 재사용한다. 장면·설정 객체와 반환점/나이가 맞을 때만 적용하며 시각 사이 캐시는 없다.
- 격자 밖에서 버려질 광선 표본은 보수적인 교차 구간으로 미리 제외한다. 원래 정수 표본 번호·좌표 식·FREE/OCC/EGO 적용 순서는 같다. 경계 밖 한 칸과 추가 표본을 포함하고 불확실한 큰/비유한 입력은 원래 전체 계산을 쓴다.

센서·물성·판정 기준·경로·속도·독립 보호를 변경하지 않았다. [r43 계약](../../../../config/tests/grid_cost_r43_sha256.json)은 r42의 후속이며 이전 소스는 [before.zip](before.zip)에 보존했다. 이전 계약을 다시 쓰지 않았다.

## 실제 검증

관련 회귀 **479통과**([로그](checks/pytest_related_1.log)); 먼저 실행한 대상 108검사와 오류 변이 검사도 보존했다. 잘못된 변이 3종이 38/17/34개 검사에서 검출되며 원본 대비 오라클 차이는 계측/이름 변경뿐이다. 최초 변이 판정기 오류는 실패 원본으로 남겼다.

[전체 재생](summary.json)은 이전→현재→현재→이전 순서로 각 두 번, 전수 계측은 별도로 한 번 했다. r25 1,540·r41 1,628·오목 0.50m/s 추월 **753**, 총3,921판단의 명령·기록 해시가 모두 같았다. 인계 문서의 오목1,137은 판단 횟수가 아니었으며 실제 call은753이다. r25/r41은 r42 기준 명령과도 같다.

격자1,252개, 위협 뷰2,113개, 장면3,921개의 전수 비교에서 차이0이다. 격자는 상태 전체·반환·나이·compact·observed_free·크기를 비교했고 공유 입력 변형도0이었다. 자유 표본은147,233,957→95,332,550으로 **35.3% 감소**했으며 격자 안 실제 표본94,797,847개는 모두 보존했다. 실제 import 출처와 변경 전후 해시 검사는 모든 단계에서 통과했고, GPT가 계약·현재3파일·ZIP 원본 해시를 다시 확인했다.

| PC WSL 입력 | 처리시간 중앙값 before→after | p95 before→after |
|---|---:|---:|
| 단독 r25 | 11.674→10.471 ms | 18.380→19.166 ms |
| 코너 교통 r41 | 27.789→23.791 ms | 45.370→43.710 ms |
| 오목 상대 추월 | 16.543→14.694 ms | 56.194→55.579 ms |

표는 각각 두 실행의 분위수 평균이다. 계측 실행 시간은 성능 표에서 제외했다. 코너 중앙값 약14.4% 감소가 있지만 **20ms 이내 처리 확보는 아니다**. 코너에서20ms 초과는 평균1,376→1,329.5판단으로 남았다. 단독p95는0.786ms 증가했고, 판단부 자체의 꼬리 비용은 개선되지 않은 항목도 있다. 모든 상황이 빨라졌다고 해석하지 않는다. 명령이 같은 CPU 최적화로 채택하되 이 PC의 실행 변동·향후 실제 Jetson 성능은 구별한다.

## 범위와 후속

- 새 Gazebo 주행은 하지 않았다. 수학적으로 같은 입력 결과를 검증한 변경이며 주행 실패를 고쳤다는 의미가 아니다.
- Jetson/ARM·ROS/영상 병행 마감은 미검증이다. r42 v3 패키지는 당시 코드 보존본으로 유효하지만 **현재 r43을 포함하지 않으므로 다음 실제 이관 때 새 묶음을 만들어야 한다**.
- 같은 작은 최적화를 반복하기보다 빠른 추월의 진입 후 정체와 지속 코너 병렬 등 남은 주행 기능으로 돌아간다.
