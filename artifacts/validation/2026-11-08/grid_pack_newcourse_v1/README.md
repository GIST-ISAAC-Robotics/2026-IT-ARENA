# 공식 다섯 차량 그리드 출발 — 제한 대표 성립

기존 G1/G2를 바꾸지 않고, 공식 교통 실행기의 복수 상대 제한을 새 코스의 명시 등록에서만 열었다. 관련 회귀 **161개 통과** 후 [사전 계획](PLAN.md)의 1회만 실행했다. Grid3 자차와 공식 grid4/0/1/2의 네 상대가 출발했다. 상대 높이180mm는 카메라 가림을 고려한 시험 가정이지 실제 팀 차량 치수는 아니다.

- 실제 RGB 초록 확인 뒤 출발을 허가했고, 자차가 0.10m/s 이상 움직이기 시작한 때는 초록 뒤 **1.802초**였다. 출발 신호 확인은 0.278초였다. 둘을 하나의 지연 수치로 합치지 않는다.
- 8초 장면에서 **3.41m 전진**, 움직인 뒤 0.05m/s 미만 정체 구간은 없었다. 접촉·겹침·벽 바퀴 표본은 0이다.
- 움직인 뒤 네 상대에 대한 최소 외곽 간격은 약 **0.322/0.790/1.282/0.570m**, 보수적 이동 사이 하한도 각각 0.321/0.789/1.281/0.569m였다.
- 노면8,478표본에서 최대 두 바퀴가 잔디였다. 조금이라도 걸친 정의의 잔디 시간6.316초, 바퀴 중심 기준1.794초, 바퀴 전체 기준1.244초다. 도로를 전혀 벗어나지 않은 주행은 아니다.
- 명시 STOP, 0.5초 조밀 정지(최대0.00809m/s), 자식14개 정상 종료·잔여 PID0·880개 입력 불변을 확인했다. 추가 차량마다 실제 자세·명령·접촉 경로를 독립 확인했다.

**원 평가 전체는 실패로 보존한다.** 최상위의 차체 완전도로 안 기준이 실패했고, 추가 grid0 상대의 전체 최소 간격도 출발 전 약30mm 때문에 원80mm 기준에 미달했다. 사전에 구분한 *이동 후* 간격과 두 바퀴 잔디 허용을 사용한 별도13조건은 통과했다. 원 report의 실패를 덮지 않았다. [보충 판정](five_vehicle_grid/assessment_run1.json)·[원 report](five_vehicle_grid/run1/report.json).

실제5대 장면의 초기 주행 연결은 확인했다. 높은 상대 모델을 넣었다는 사실만으로 '카메라 전체 가림 후 지연 출발' 성공이라고 할 수는 없으며, 이 실행은 RGB 이미지 가림률을 저장·판정하지 않았다. 모든 그리드 위치·서로 다른 출발 속도·급정거·경기 거리·실차 검증은 아니다. 다음은 같은 제어 조합의 새 코스 **교통이 있는 한 랩**을 확인하고, 단독 증속/피추월의 미완료로 돌아간다.
