# 현재 관측 코너의 경로 일치 비교

2026-11-08. **미채택.** [r46 원인 감사](../corner_r46_transition_audit_v1/README.md)의 37.52초 왼쪽 경로는 현재 0.651 m를 관측하고 앵커 6 mm·직전 경로 호길이 일치를 만족했다. 오른쪽 관측은 해당 스캔에서 형태 불명확이었다.

현재 생산 소스의 사본에서 선호 현재 경로·지지점 재적합·돌출 제외 재적합의 일치 검사 세 곳에 기존 `retained_boundary_agreement`를 재사용한다. x 비교를 먼저 하고, 기존 선택형 교통·직각 옵션과 `piecewise_corner`일 때만 동일 오차의 공통 호길이를 비교한다. 충분한 길이·앵커·유효 이력·재획득 조건과 이후 점유 검사는 그대로다. 기본 OFF이며 생산에 아직 연결하지 않았다.

원 실제 스캔의 왼쪽/좌우 반전, 옵션 OFF, 다른 표면/모델, 짧은 공통 구간을 검사한 뒤 r46 전체 센서 입력으로 연속 재생한다. 저장 입력 개선이 새 주행 개선을 보장하지 않는다.

7검사는 통과했으나 1,635판단 재생에서 20명령이 바뀌었고 최초 변경은 **37.22초**였다. 33초 이후 경계 미확정 0명령은45→50회로 늘었다. 현재 오른쪽 벽이 유효할 때 선호 왼쪽을 먼저 고르는 영향이 있어 이 사본은 연결하지 않는다. [v2](../current_corner_fallback_probe_v2/README.md)는 기존 벽의 갱신을 먼저 시도한 뒤 실패했을 때만 같은 현재 코너 비교를 사용한다.
