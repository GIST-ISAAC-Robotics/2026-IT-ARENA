# 새 코스 앞차 정지·재출발 대표 — 실제 연결 시험

r17에서 일반 주행 복귀와 남은 저속 손실을 확인한 뒤 진행하는 다음 장면이다. 정적651자세의 도로/벽 검사(이탈·겹침0)를 통과했고 실제1회를 마쳤다. 제어 소스는 r17과 같아 재빌드하지 않는다. 앞차는 중앙1.6m 전방에서0.50m/s로3초 진행,3–8초 정지,8초부터0.50m/s로 재출발한다.18초의 실제 actor 이동은6.5m이며 새 코스 첫 직각 코너1m 전 제한을 기하 검사한다. 현재 r17 제어·B0390·JR60P20·평탄 잔디·같은 속도/노면/STOP을 사용한다.

원 검사기의 HOLD·간격·차체 도로 안 기준을 보존하고, 별도 경기 목표는 접촉0·최소간격0.08m·최대2바퀴잔디·상대재출발 뒤2.5초 내 진행·그 뒤1m이상·최종FOLLOW/도로안·마지막2초0.50m이상·STOP/정상종료다. 관측된 우회가 가능하다면 반드시 정지해야 한다고 요구하지 않는다. 옛 U자150°·출구 좌표는 직선 장면에 적용하지 않는다. 실제 각본의 정지/재출발도 평가로 확인하며 배우 정답은 제어기에 주지 않는다.

## 실제1회 결과와 평가 교정

총5.063m·최종FOLLOW/도로안·상대 재출발 뒤2.012m·마지막2초1.148m, 최고1.395m/s를 확인했다. 재출발 직후0.037초에 움직인 표본은 있었지만, 이후0.05m/s 미만5.164초가 있어 지속성은 실패다. 우회를 시도하다 상대가 재출발했고 실제 순서 역전 없이 복귀했다. 최소표본/연속근사간격0.131117/0.131116m·접촉/벽바퀴0·최대2바퀴잔디, 명시STOP·조밀정지·정상종료·873입력불변을 확인했다.

초기 `actor_advanced=false`는 평가 방법의 오류다.50Hz 각본 위치 갱신을100Hz 자세 표본의 순간 차분 최솟값으로 검사해1100구간 중588개 반복 위치를0속도로 셌다. [actor_motion_review.json](actor_motion_review.json)은 동일0.45m/s 기준을 유지하고, 원시x/y의1초 이동량20창/표본 누락을 검사했다.0.49355–0.50540m/s로 각본 성립을 확인했다. 원 `assessment_run1.json`·`run1_goal.json`·등록 helper는 덮어쓰지 않았다. 사후 분석이며 사전 등록 결과를 소급 변경하지 않는다. 이동여유/정체 목표는 수정하지 않았으므로 교정 뒤에도 전체 실패다. numpy bool이0.0으로 직렬화된 원 정체 gate도 사후 산출물에서는 bool로 명시했으며 의미는 같다.

현재 명령을 보면16/18/20초의 우회 후보가 `known_occupied_command_hold`였고22초에는 복귀를 진행했다. r17 정지차와 함께 후방 짧은 외벽 조각의 이동 여유를 원시 점/현재 관측으로 비교한다. 이 공통5–9초 손실은 미세한 경우가 아니므로 한 번 보완한 뒤 측방/피추월 대표와 증속 과제로 이어간다.
