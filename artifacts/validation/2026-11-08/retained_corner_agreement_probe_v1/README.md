# 관측된 같은 코너의 공통 구간 비교

2026-11-08. [r45 전환 감사](../corner_r45_transition_audit_v1/README.md) 뒤의 미연결 사본이다. 현재 충분히 긴 오른쪽 벽과 기억 경로가 같은 코너인데, x좌표 창 안에 놓인 코너 출구의 서로 다른 길이 때문에 기존 대칭거리 비교가 실패했다.

`traffic_boundary_refresh_trial`·`piecewise_wall_trial`이 모두 켜지고, 현재 채택 벽을 계속 유지하는 분기의 새 관측 모델이 `piecewise_corner`일 때만 기존 `path_agrees_arc`를 재사용한다. 기존 x비교를 먼저 하고 실패한 경우 공통 호길이 0.25 m·5점/80%·동일80 mm 허용오차를 대조한다. 현재 긴 관측·앵커 조건과 유효한 기억은 호출부에서 그대로 요구한다. 점유나 미관측을 고치지 않고, 새 방향/새 벽을 임의로 채택하지 않는다.

원본은 `before_local_follow.py`, 설계 사본은 `candidate_local_follow.py`에 보존한다. 8개 정책 반례와 r45 전체 저장입력의 명령/원인 비교를 준비했다. 생산 코드와 실제 실행은 아직 변경하지 않았다. 최초 테스트 fixture에 선택형 교통 프로필의 종속 설정이 누락돼7건이 설정 생성에서 실패했다. 실제r45 헤더를 사용하는 fixture로 고쳤으며 원래 로그를 보존한다.


8검사와 연속1,644판단 재생을 완료했다. 최초차이는36.42초,45명령이바뀌었고 공통호길이비교6회였다.33초이후 경계미확정0명령45→25,재출발대기20→15회로줄었다. 생산소스전후불변을확인했다. 모든경계상실을해결한결과는아니다. 후속생산연결은 [r46](../retained_corner_agreement_r46_v1/PLAN.md)로분리한다.
