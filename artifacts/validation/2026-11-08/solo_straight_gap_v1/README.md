# 새 직선 증속 주행의 마지막 코너 미관측 정지

원 실패는 [증속 비교](../../2026-11-07/solo_straight_newcourse_v1/README.md)에 보존했다. 이 폴더는 저장 입력 원인 분석이며 새 주행 결과가 아니다.

## 직접 확인한 원인

첫 지속 정지 호출36.92초에는 원시 각도40.32–44.64°의7광선이 `+inf`였다. 운동보정 후에는36.03–40.48°다. 양쪽 반환은9.23/10.69m, 기존0.6m 평가반경의 결측 현은6.03cm로5cm 조건을 넘었다. 이는 알려진 지주 가림을 제외한 실제 원시 무반환이다.

44.44초의 정지 상태에는 원시36.72–39.60°의5광선이 `+inf`였다. 양쪽 반환은11.885/8.577m, 현4.52cm·현재 속도0이었다. 이때는 현 폭과 저속 조건 안이지만 v4의 최소60° 조건으로 계속 거부됐다. 경로 후보는 남아 있었다. 정답 차체 속도는 이 판정에 넣지 않았으며 센서 이력으로 운동보정을 복원했다.

미반환의 양옆에 먼 벽이 있다는 사실만으로 가운데 가까운 장애물이 없다고 할 수는 없다. 벽/노면 기하에서 왜 해당 광선이 최대범위를 넘었는지까지의 별도 광선 추적은 아직 하지 않았다. 실제 C1의 무반환·잡음과 완전히 같다는 의미도 아니다.

## 저장 입력에서 비교하는 후보

기본 코드/정책은 바꾸지 않고 별도 프로세스에서 v4의 최소각60°를30°로 바꾼다. **기존 현5cm·실제/요청속도0.6m/s 이하·결과속도0.2m/s 이하·양옆 반환1m 이상·시간/이력·소실 장애물 검사를 유지**한다. 원시 광선/점유는 수정하지 않고 제한된 숨은 물체 위험을 명시한다. 차체 정면의 큰 공백이나 단순 무응답 전체를 허가하는 후보는 아니다. 현재 유효 반환의 충돌 검사는 별도로 남는다.

이는 범위가 달라지는 운용 후보이므로, 기본 활성화나 실차 안전 보장으로 해석하지 않는다. 먼저 기존 출력의 동일 재생과 직접 반례를 확인하고, 실제 출력이 개선되는 근거가 있을 때만 별도 명시 시험 연결을 검토한다. 같은 실패를 그대로 재실행하지 않는다. 사선 공백 비교를 이유로 중속 추월·기타 미완료 과제를 누락하지 않는다.

현재: `diagnose.py` 1회 정상 실행. `test_candidate.py` 및 `compare.py`는 실행 담당에게 전달했으며 결과 대기 중이다. 결과 없이 시험 통과·정지 해결로 표시하지 않는다.
