# 빠른 추월의 제한 전진: 첫 미연결 대조

r32의 실제 정체 입력에 기존 피추월 비접근 검사를 대조한 [기하 진단](../faster_wall_persistence_probe_v1/README.md)에서는 257개 중147개가 가능해 보였다. 그러나 실제 빠른 추월 상태기의 요구(계속 추적되는 앞차의 후단 여유, 확인된 바깥벽, 기존 편이 경로, 현재 속도, 코너 횡이동 1cm, 이동 영역)를 모두 적용한 [527판단 재생](summary.json)에서는 **출력 변화 0**이었다. 136판단에서 최대 0.35m/s 후보의 횡이동 창이 컸다. 이 결과는 저장 입력의 기하만 점검한 것을 실제 명령으로 확대하면 안 되는 예다.

다음 사본은 1cm 기준을 그대로 두고 기존 피추월과 같이 가능한 속도까지 낮춘다. 측정 속력만으로 기준을 넘으면 거절한다. v1은 주행에 연결하지 않고 보존한다.
