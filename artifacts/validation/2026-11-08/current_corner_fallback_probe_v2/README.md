# 현재 벽 유지 뒤 코너 후보 비교

2026-11-08. 선택형 연결 후 검증 중. [v1의 조기 벽 전환](../current_corner_agreement_probe_v1/README.md)은 미채택했다. 이번 미연결 사본은 원 비교 세 곳을 그대로 두고, 현재 따라가는 반대 벽의 갱신까지 실패한 경우에만 충분히 긴 현재 선호 코너와 유효 이력을 기존 호길이 기준으로 대조한다. 그 뒤에도 같은 벽이 현재 관측되면 동일 기준으로 유지할 수 있다.

왼쪽/오른쪽을 무조건 바꾸거나 유효기간을 연장하지 않는다. 기본 선택형 옵션·현재 관측 길이·앵커·공통 구간·점유·독립 보호는 유지한다. r46 실제 센서 1,635판단에서 최초 변화와 정지 원인을 비교한 뒤 생산 연결 여부를 정한다. 저장 입력 결과를 실제 주행으로 확대하지 않는다.

7표적검사·1,635판단 재생에서20명령이 바뀌고 최초37.52초였으며 경계미확정0명령45→30으로 줄었다. 이를 [r47](../current_corner_fallback_r47_v1/PLAN.md)에 연결해365관련검사·사본명령일치·기존빠른548/중속753명령불변을 확인했다. 실제주행 결과는 별도다.
