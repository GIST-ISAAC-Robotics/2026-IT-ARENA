# r44 빠른 추월 진입 일관성

빠른 추월 최초 편이에서만 고정 벽 여유를 사용해, 실제 추월 중 짧아진 뒷벽을 확인할 때 유지하지 못하는 경로를 선택한 문제가 있었다. 같은 동적 외벽 여유로 최초 편이를 제안하고 불가능할 때 기존 FOLLOW 명령을 그대로 사용한다. 중속/저속과 이미 진행한 추월의 검사·복귀·보호는 바꾸지 않는다.

1. 좁은 고정 여유 전용 공간 거부, 넓은 관측 공간의 후보 유지, 실제 FOLLOW 양수/0명령 보존과 관련 회귀를 확인한다.
2. r32·오른쪽20cm 저장 입력을 미연결 사본 결과와 대조한다. 중속·오목 중속·저속 기존 명령은 그대로여야 한다. 원래 추월 경로로 수집된 입력을 대안 실제 주행으로 해석하지 않는다.
3. 통과하면 r32와 같은 상대0.70m/s·오른쪽12cm·10초 장면 1회. 기존 전체 추월 평가는 그대로 남긴다. 별도 **추종 지속 평가**는 공통 실행/접촉/노면/STOP 기준 모두 유지, 상대 뒤 유지, 실제 진행≥6m, 출발 후 최장0.05m/s 미만≤0.5초, 최종 상대 중심 종방향 간격≤1.2m로 사전 고정한다. 단순히 추월을 안 했다는 이유만으로 성공은 아니다.

추종 대표가 성립해도 빠른 추월 완료로 표기하지 않는다. 관측 근거 없이 짧은 벽의 운동 여유를 지우거나 이미 벗어난 차를 무작정 중앙으로 돌리는 변경은 하지 않는다. 새 환경에서는 실패 원인을 보존하고 자동 반복하지 않는다.
