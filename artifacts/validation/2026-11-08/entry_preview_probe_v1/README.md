# 정지차 진입의 짧은 목표점 — 별도 구현 사본

2026-11-08. 실제 제어 소스에는 아직 반영하지 않았다. C1 거리 오차·지연 시험의 정체가 확인되어 그 원인을 우선 조사하며, 이 후보는 재개 가능한 상태로 남긴다.

- 같은 기억 경로에서 목표 거리만 0.24/0.18/0.12 m로 대조한다. 기존 양수 명령과 정상 주행은 먼저 그대로 사용한다. 연속 0축속도 0.20초의 경우에만 전진 없이 조향을 정렬할 수 있다. 이후 양수 명령에는 실제 직전 조향을 다시 사용한다.
- 최초 사본과 계산 비용을 보완한 최종 사본 모두 OFF 입력 **1,054판단 동일**(최종 비교는 r35 부모 포함). ON은 저장 입력 17.38초에서 처음 정지 조향만 달라졌다. 이후 센서가 같을 것이라고 가정하여 주행 성공으로 계산하지 않았다.
- 저장된 30초 장면에서 정렬된 각도 -0.3164 rad는 같은 점유·관측 검사로 0.35 m/s 후보를 만들었다. 앞쪽 가까운 반환 41개를 추가하거나 오른쪽 159광선을 미관측으로 바꾸면 전진·정렬 후보 모두 거부됐다.
- 새 보조 함수의 표적 **18검사 통과**. 부분 관측 검사 12장면/명령 대조에서 빠른 거부가 성립한 경우는 모두 원 전체 검사도 거부했다. 일부 표본 통과는 허가가 아니며 전체 검사를 계속한다.
- 처음에는 미관측 반례에서 추가 비교에 약 1.31초가 걸렸다. 이미 점유 때문에 거부된 0명령의 관측 계산을 생략하고, 같은 이동 영역의 최대16표본 중 명백한 반례가 있으면 조기 거부하도록 정리했다. 최근 단일 측정은 원 장면 약58 ms, 가까운 물체 약11 ms, 미관측 약49 ms다. PC의 단일 호출 실제 시간이며 Jetson 처리율이나 최악 시간 보장은 아니다. 최초 사본과 결과는 `before_cost_prune/`에 보존했다.

근거: [설계](PLAN.md), [OFF/최초 ON 대조](replay_overlay.json), [같은 장면의 조향 순서](sequence_result.json), [점유·관측 반례 및 전체 검사 대조](counterexample_probe.json), [사본 해시](overlay_manifest.json).

다음 적용 때는 `overlay_manifest.json`의 before 해시를 현재 src와 대조한다. C1 수정이 먼저 들어가면 이전 사본을 덮어쓰지 말고 같은 변경을 새 부모에 다시 적용해야 한다. 생산 코드·ROS 옵션·출처 사슬 등록, 동일 STOP/START 실제 1회는 아직 하지 않았다. 최종 사본 OFF 재생은 끝났고, ROS 연결 사본과 실행 도구는 [별도 준비](../entry_preview_wiring_v1/README.md)했다. r33의 0.506 m 실패는 그대로다.
