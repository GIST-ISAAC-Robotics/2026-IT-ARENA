# 교통 속 STOP/START 연결 대표

v2026.11.06·B0390·JR60P20·기존 선택형 G1/G2 paced/slow·road_level·1.5 m/s 일반 상한을 유지한다. 빠른 추월 r31/r32·코너 r29/r30은 끈다. 제어 코드를 바꾸지 않는다.

- 공식 grid3에서 RGB 출발. 도로 중앙 s43.26에 규격 20×15 cm 정지차 한 대를 둔다. 평가 좌표만 사용한다.
- s42.26에서 HTTP STOP. 1.6초 내 0.5초 연속 정착(최대 0.05 m/s·변위 0.02 m·최대 표본 틈 0.12초)을 확인한다.
- 같은 세션·경기에서 RESET/재배치 없이 START 한 번, 허가 3초 이내, 정착 위치 초기 방향으로 1.2 m 전진 후 STOP. 최초 거부 START는 기존 운영 검사에 포함한다.
- 접촉 원시 토픽·실제 상대 자세·차체 자세·센서 판단·운영 명령을 회수한다. 접촉0, 최소 표본 외형 간격 양수, 최대 두 바퀴 도로 밖·벽 바퀴0, 정상 종료·잔여 PID0·입력 불변을 판정한다.
- 상대가 정지해 있으므로 이동차 추종 재개/공유 Wi-Fi/실차의 증명이 아니다. 수용 기준을 바꾸며 자동 반복하지 않는다.
- 실제 조향 관절 로그가 없으면 바퀴 노면은 중앙 조향 0,±0.45 rad 세 표본의 가장 나쁜 값을 보고한다. 이는 연속 각도 전체 증명이 아니다. 차체 전체 도로 포함은 별도 보수 지표로 남긴다.
