2026-11-08. 기본 같은-경로 관측 옵션 안의 범위 오류를 수정했다. 실제 같은 B 조건1회까지 완료했으나 완주는 실패했다. [사전 기준](PLAN.md)·[원인/사본/재생](../c1_release_observation_probe_v1/README.md).

- 현재 부모로 r35의3,040판단 전부를 재현했고, 후보는60.36초에서 처음 변경됐다. 무주입A3,051판단은 모두 같다. 이후 고정입력을 새주행으로 취급하지 않는다.

- r37 출처는r36에연결된다. 변경runtime은`same_path_gap_trial.py` 하나다. 현재원시반환/점유/전방범위/기존명령크기/STOP/독립보호를유지한다. 모든실제이동질의가원래반환검사를통과해야한다.
- 같은C1 ±3cm·추가지연30–70ms 조건1회를등록한다. 진행44.64m·최장저속2.5초·접촉/노면/종료조건을그대로둔다. r35의42.55m 실패는보존한다. 시뮬1회·한seed이므로실차/각도/IMU전체강건성으로확대하지않는다.

## 실제 실행 결과

16:59:31–17:12:34 KST,60초 조건에서20.22 m·최장저속34.456초·최고1.566 m/s로 실패했다. 접촉/겹침/노면 이탈0, 최소간격0.805 m, STOP/정상 종료,906입력 불변과 잔여 프로세스0을 확인했다. C1 ±3 cm/추가지연32–70 ms와 취득 대응도 검증됐다. 원판정과 보충판정 모두 실패이며 결과를 덮어쓰지 않는다.

이번 정체는 RELEASED의 후방 가림 꼬리 검사에서 발생했고, r37의 query-local 범위 분기는 기록에서 사용되지 않았다. r35와 동일 seed여도 동일 센서 입력 재생은 아니므로 진행량 차이를 해당 분기의 회귀로 단정하지 않는다. [저장 입력 감속 비교](../released_masked_speed_probe_v1/README.md)에서 높은 목표 거부를 곧바로 정지에 연결하는 부분을 별도 검토한다.
