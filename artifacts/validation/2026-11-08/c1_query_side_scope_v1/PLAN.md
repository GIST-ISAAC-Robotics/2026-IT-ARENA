# C1 오차·지연 같은 조건 재시험 r37

2026-11-08. r35는42.55m에서6.764초 정체해44.64m/저속2.5초 기준에 미달했다. 같은 순차10Hz·±3cm·추가지연50±20ms(seed23), 원노면·0.8m/s각본앞차2대·60초를 유지한다.

변경은 같은-경로 측방 증거의 적용 범위다. 전방 약42–50도의 실제 이동 질의를 검사할 때 필요하지 않은 정후방 무반환까지 전체 증거를 취소하던 조건을 고친다. **실제 전체 이동 영역**의 원시+inf·양옆 반환·점유 팽창·기존 좁은 공백 한도·원래 검사한 명령/시각/차체·전방 범위는 그대로다. 후방 질의가 필요하면 측방 증거로 허용하지 않는다. 미관측 공간을 채우거나 속도·물성·간격·STOP 기준을 낮추지 않는다.

부모는r36이며 r36의 `adaptive_entry_preview`는 이 시험 인자에서 OFF다. r35저장3040판단을 부모로 재현하고, 새 후보는 최초 출력 변경까지만 비교한다. 무주입A3051판단 동일과 관련 회귀를 완료한 뒤1회 실행한다. r35원시 결과를 바꾸지 않는다.

판정은r35와 동일한 사례창 스캔 출처·주입범위·진행44.64m·최장저속2.5초·접촉/겹침·간격·노면·STOP/종료·입력불변이다. 원시최종간격 판정도 별도로 남긴다. 첫실패 지점이 달라지면 근거를 회수하고 동일 무변경실행을 반복하지 않는다. 한seed결과를 실차 또는IMU/회전율 오차 전부의 증명으로 확대하지 않는다.
