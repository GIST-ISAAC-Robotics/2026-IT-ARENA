# 단독 마지막 공백: 평가 반경 반례 준비

r19의 정지 원인인 사선 7개 무반환을 정지 뒤에도 0.6 m 반경에서만 재는 문제를 이어 검토한다. [기존 저장 비교](../solo_gap_envelope_v1/README.md)의 후보는 제동·차체 외곽에서 같은 50 mm 폭을 평가한다. 현재 src에는 연결하지 않았다.

대회 제어기와 독립 보호 모두 같은 정책을 사용해야 하며, 실제 이동 외곽·기존 가까운 점 소실·정면/넓은 결측을 구분한다. 통과를 위해 결측을 자유 공간으로 만들지 않는다. 표적이 관측되지 않은 위험이 남는 저속 운용 근사라는 범위는 유지한다. 기준점0.6m를 줄여 허용되는 범위가 넓어지는 것은 명시하며 증명된 자유 공간으로 설명하지 않는다.

합성 반례24개가 통과했다. 최초 회전 반례는 부호를 반대로 넣어 전방이 아닌 바깥쪽으로 공백을 옮겼으므로 실패 원본과 당시 코드를 보존하고, 실제 변환 각도를 확인하는 양쪽 회전 시험으로 고쳤다. 테스트 후 현재 r24와 후보를 동일 입력으로 비교하고, 운영 연결 전 기존 교통 및 기본 OFF 영향 범위를 확인한다.

후속 운영 연결은 [r25](../solo_gap_envelope_connected_v3/README.md)에서 수행한다. 이전 오프라인 후보는 당시 소스 문자열을 사용하므로 이전 before.zip/시험시점 소스로 재현해야 하며 현재 파일에 무조건 다시 실행하지 않는다.
