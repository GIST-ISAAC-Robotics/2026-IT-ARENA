# 새 코스 대표 재배치·즉시 재개와 정지 정착

이전 제자리 STOP→START는 성립했지만 두 차례 정지에서 첫 0.5초 최대 속도가 0.063/0.065 m/s여서 정지 유지 평가가 실패했다. 조밀 자세를 대조하면 최고점은 기존 평균 기반 stopped() 선언 후 약 30 ms이고, 마지막 100 ms는 0.0013 m/s 이하다. 처음 0.5초 창의 실패를 보존하고 STOP 버튼→제동→실제 연속 정착을 분리한다. 물성·모터 제어·START 허가 로직을 바꾸지 않는 평가 전용이다.

기존 한계를 올리지 않는다. 첫 0.5초 창을 함께 기록하고, STOP 버튼 시각부터 **1.6초 이내** 최대 0.05 m/s·0.5초 이상·변위 최대 0.02 m를 실제 연속 자세로 확인한다. 1.6초는 팀 시험용 상한으로 규정/실물 보증이 아니다. 못 하면 실패다. 중간 자세 속도를 평균으로 감추지 않는다. MCU stationary_ready와 software_stop·물리 정착은 별개로 기록한다.

RGB 최초 출발 뒤 HTTP STOP, 완전 정착 뒤 RESET 1회. 심판이 차를 옮긴 상황을 평가 전용 서비스로 재현한다. s=12 m 도로 중앙은 **시험 위치이지 공식 세이브포인트 좌표가 아니다**. 시작 직선과 진행 방향이 반대이며 새 방향으로 최소 1.2 m 전진해야 한다. 실제 배치 자세 확인 직후(0.3초 이내) START 1회, 3초 내 permitted, 같은 경기/세션 유지, 다시 STOP·0.5초 정착. 위치 정답은 평가기에만 전달하며 순간 이동 거리를 주행 진도로 더하지 않는다. 브라우저·Jetson·공용망·교통 배우는 사용하지 않는다.

실제 주행 한 번 전 사전 기하/평가기 반례를 확인하고, 종료에 원시/소스 불변·도로 안·신호 및 운영 흐름을 기록한다. 실패 시 무변경 반복하지 않는다.

## r26 동일 배치 비교

이전 시험의 STOP·RESET·배치는 성공했지만 접속 중인 운영자의 재출발이 0.114초 뒤 operator_link_lost로 취소됐다. 정책 수락과 첫 상태 사이의 요청별 연결 신호만 보완한다. 위와 같은 배치·평가를 한 번 실행하며, 실패도 그대로 기록한다. 마커/센서/물성과 MCU 허가·STOP·워치독은 바꾸지 않는다.
