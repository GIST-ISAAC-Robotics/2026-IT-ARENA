# 새 코스 끼어들기 1차: 앞쪽 시험 장면 불성립, 뒤쪽 접촉 발생

v2026.11.06 B0390/JR60P20·선택형 G1/G2, 고정 경로 상대 한 대를 한 번 실행했다. 상대가 4.5초까지 기다리던 예전 코스 각본을 그대로 옮겼더니 자차가 그 전에 먼저 지나갔다. 중앙 횡위치에 겹친 초록 후 5.238초의 차체 종방향 간격은 −0.740 m, 자차 속도는 0.327 m/s였다. 이때 상대는 뒤에 있었다. **원래 목표인 전방 근접 끼어들기 대응은 검증하지 못했으며, 실제 뒤쪽 접촉은 별개의 실패로 보존한다.**

첫 접촉은 초록 뒤 6.456초. 전체 663개 접촉 메시지·334개 외형 겹침 표본·최소 간격 0 m였다(663번의 충돌이라는 뜻은 아니다). 충돌 직전 자차가 0명령으로 감속했고 평가 상대는 계획대로 진행했다. 무한질량 상대가 자차를 통과하는 구간을 실제 상대의 사고 반응이라고 해석할 수 없다. 자차 진행 5.209 m·최장 저속 1.722초·최종 FOLLOW, STOP/종료·895입력 불변. 원 판정과 보충 모두 실패이며 평가 실행 exit 0은 주행 합격이 아니다.

기존 앞쪽 장면 판정은 종방향 간격에 상한만 있었다. 다음 [전방 합류 시험](../cut_in_early_newcourse_v2/PLAN.md)은 양수 간격을 명시하고, 첫 실행의 저장 궤적에서 2.4초 합류 시작이면 약 +0.60 m/+1.51 m/s일 것으로 예상된다는 근거로 시점을 정했다. 이 값은 고정 자차의 사전 추정이고 실제 대응은 새 실행에서 재평가한다. 또 1차 직선 검사에 남은 옛 s5.30은 새 s6.70보다 **엄격한 평가기 좌표**여서 이번 경로가 지나치게 길어지지는 않았다. 소스나 평가를 소급 수정하지 않는다. 근거: `geometry.json`, `close_cut_in/run1/report.json`, `close_cut_in/run1_goal.json`, `close_cut_in/assessment_run1.json`.
