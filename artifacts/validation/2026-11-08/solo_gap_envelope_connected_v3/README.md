# 단독 사선 결측의 감속 외곽 반경 r25

2026-11-08, 연결·재생 및 실제 단독 한 랩 확인. 단독 증속 r19은 최고2.877m/s까지 갔지만 42.66m에서 사선7개 무반환으로 멈췄다. 원시+inf를 거짓 거리로 채우는 대신 이미 존재하는 저속 사선 위험 허용의 평가 거리를 차량 운동에 맞춘다.

이전에는 정지해도 최소0.6m에서 공백 폭을 쟀다. r25는 명시 oblique 옵션에서 차체 외곽·센서 오프셋·반응/제동 거리 D를 더하며, 차체 중심의 회전 이동도 D×abs(tan(조향))/2 상계로 포함한다. 기존 예측 여유0.06m와 외곽50mm를 유지한다. 50mm 공백·전체6도·목표0.2m/s·측정0.6m/s 한계, 가까운 물체 소실/정면 결측/현재 점유·STOP은 그대로다. 기본 OFF는 이전 계산 그대로다. 이는 작은 미관측 물체의 잔여 위험을 제한해 저속 진행하는 운용 근사이며 자유 공간 증명이 아니다.

[보존한 원 시점 저장 비교](../solo_gap_envelope_v1/README.md)는1889판단 원 출력 재현·365변경이다. 현 r24는 후속 경로 수정이 있으므로 같은 r19 기록과 완전 일치한다고 가정하지 않는다. [반례 준비](../solo_gap_envelope_review_v2/README.md)는24개 통과했고, 회전 부호를 잘못 넣은 최초 시험실패도 보존했다. 연결 후에는 독립 보호의0.2m/s/0명령 유지와 실제 차체 모서리 이동이 반경 안에 드는지도 검사했다. **관련 회귀360개 통과**, [r24/r25 같은 저장 입력](comparison.json)에서 옵션 OFF 단독1,889·교통398판단은 전체 출력 불변이다. ON에서는 38.54초부터만 실제 명령374개가 달라졌다. 원시 r19 대비 전체 불일치512→877은 이전 경로 변경과 이번 의도된 동작 차이가 섞여 있으므로 r24/r25 직접 대조와 구분한다.

## 실제 주행 결과

**원 보고 passed=true, 거리 1랩·46.67m·최고 2.862m/s(10.30km/h)**, RGB 출발 기록에서 목표 도달 마지막 표본까지 29.228초였다. 원1mm 노면이며 차체/바퀴 이탈0(19,435표본), 접촉0, STOP 안정/정상 종료·881개 등록 입력 불변이다. 영상은 [3인칭 주행](run1/local_pursuit_third_person_drive.mp4), 수치는 [원 보고](run1/report.json)와 [후속 집계](live_summary.json)를 따른다.

- 진입 후반 약42.75m에서 차체속도0.05m/s 미만 표본3개가 남았다. **한 번도 감속/정지하지 않은 주행이 아니다.** r19처럼 그 자리에 계속 서 있지 않고 재가속해 완주했다. 10km/h 이상 표본 간격 합계 약1.15초이며 모든 구간의 속도가 아니다. 평가 코너 중앙속도1.159m/s, p10 0.898m/s다.
- 실제 주행에서 기존 고정0.6m 폭으로 환산하면50mm를 넘는 사선 공백을 현재 반경으로 허용한 판단2개가 있었다. 두 호출의 최종 속도 명령은 다른 재확인 조건 때문에 여전히 0이었으므로, 이 2개 호출이 직접 재출발을 명령했다고 단정하지 않는다. 이후 관측·자세가 달라졌으므로 r25 함수만으로 전체 랩 단축분을 설명하지 않는다.
- **명시 STOP 뒤 안정까지1.446초·변위0.945m**다. 마지막 조밀0.5초는 최대0.0097m/s로 통과했다. 고속 주행 성공과 즉각 제동 능력은 별개이며 실제 제동거리로 쓰지 않는다. 실차 첫 연결은 실제 모터/노면에서 제동을 측정해야 한다.
