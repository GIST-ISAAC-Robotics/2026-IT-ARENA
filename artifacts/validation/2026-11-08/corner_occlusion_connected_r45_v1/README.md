# r45 코너 가림 연결 결과

2026-11-08. [계획](PLAN.md)·[미연결 사본](../corner_occlusion_witness_probe_v1/README.md)에 따라 현재 전경 반환으로 가림을 설명하는 코너 보완을 기존 선택형 기능 안에 연결했다. 기본값은 OFF다. GPT가 설계·구현·검토, GPT-6 Luna가 회귀·재생·Gazebo 실행과 회수를 맡았다. Claude는 읽기 검토 후 실제 5시간97% 경고로 인계했고 생산 파일을 수정하지 않았다.

## 연결과 검증

- `corner_boundary_support.propose`에 현재 장면을 전달한다. 기존 0.5 m 이내 경로와 기억 TTL·두 면 일치·점유·독립 보호는 유지한다. 추가 가림 근거는 경로 가설이며 자유 공간이나 실제 센서 점으로 사용하지 않는다.
- 새 19검사와 기존 관련 329검사, 합계 **348개 통과**. 첫 실행의 7실패는 새 시험 fixture에서 튜플을 배열로 다루지 않은 오류였다. 시험만 수정해 새19개를 다시 통과했고 첫 실패 로그도 보존했다. 최초 연결 준비의 원문 비교에는 LF/CRLF 차이가 있어 텍스트 동일성을 확인한 뒤 생산 원본 바이트를 ZIP에 보존했다.
- 사본과 코너 **1,628명령 동일**. 최근 빠른 FOLLOW **548명령**, 오목 상대 중속 추월 **753명령**은 기존 기록과 같았다. 중첩 증거의 광선 번호 배열은 일반 판단 로그에서 제외하고 시험 원문에는 보존했다.
- [r45 출처 계약](../../../../config/tests/corner_occlusion_r45_sha256.json)·`before.zip`·[재생 요약](replay_summary.json)·`tests_v1.log`/`tests_v2.log`에 근거가 있다. 실제 실행 import 등29항목도 확인했다.

## 판단과 다음 확인

긴 정체를 줄이는 효과는 있었지만 지속 코너 병렬은 미완료다. 36.82–37.20초, 37.62–38.10초에 경계가 다시 미확정됐으며 이후 현재 벽을 재획득해 계속 움직였다. 원래 의심한 누적 측방 접근 제한은 이번 주행의 주요 정지 사유가 아니었다. 시간을 늘리거나 같은 장면을 반복하지 않고 [실제 코너 전환 입력](../corner_r45_transition_audit_v1/README.md)에서 벽 갱신/재획득을 먼저 분리한다. 더 빠른 추월·본선 속도 유지·지름길·최신 Jetson/실물 연결 과제는 계속 유지한다.
