# 첫 코너의 오른쪽 병렬 상대 — 1회 계획

r27 제어기/센서/선택값을 유지한다. 평가용 상대는 오른쪽0.34m·뒤0.15m,0.35m/s32초이며 첫 왼쪽90°코너를 반경0.845m의 연속 원호로 돈다. 도로 중심 원호0.505m와 옆 간격을 분리한다. 기존 꺾인 중심선에 옆 간격을 붙일 때 생기는 위치 도약을 쓰지 않는다. 상대는 질량/타이어 동역학이 없는 각본 상자다.

초안0.28m 간격은 grid3 자차가 중심선보다 오른쪽0.09m에서 시작해 실제 초기 간격이 약0.04m였다. 사전80mm 목표를 충족하지 않아 미채택으로 보존했다.0.34m는 약0.10m 간격을 확보하고 상대가 최대두바퀴 잔디를 사용하는 배치다. 상대 원호를5mm마다 도로/벽과 대조한다.

사전 목표: 실제 첫코너 출구 s7.5 통과·방향60°이상변화·10.5m이상진행, 자차가20–70°회전한 구간에서 상대의 전후차0.30m이하/측방0.15–0.55m/상대각도30°이하로 최소연속0.5초, 접촉0·현재80mm 간격·최대두바퀴잔디·출발뒤0.05m/s미만최장2.5초이하·STOP/정상종료/입력불변. 상대 실제운동과 원시 추종/15cm/차체도로 목표는 별도 유지한다.

상대가 너무 먼저/나중에 지나가면 실제 코너병렬은 미확인이다. 시간을 길게 돌렸다는 이유로 코너병렬 성공으로 처리하지 않는다. 최초1회 결과를 보존하고 같은실패 자동반복은 하지 않는다. 지도를 제어기에 주거나 보호/물성을 변경하지 않는다.
