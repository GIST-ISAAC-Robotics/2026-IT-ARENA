# 정지차 앞 운영 재개: 정지 중 조향 정렬 r33

2026-11-08. 같은 경기에서 RESET 없이 STOP → START를 연결한 제한 시험이다. **조향 정렬 뒤 우회 진입은 성립했으나, 재개 후 목표 1.2 m 진행에는 실패했다.** 기본 활성화하거나 교통 속 재개 완료로 분류하지 않는다.

`assessment.json`의 `completed`, `progress`, 계획의 두 정지창을 요구하는 `dense_stop`은 실패다. 실패 정리 STOP을 계획된 성공 STOP으로 바꾸지 않는다. 실제 목표에 도달한 `post_resume_progress` 이벤트가 없다는 것은 전혀 움직이지 않았다는 뜻이 아니다. 위 0.50553 m는 저장된 `ego_poses.jsonl`에서 재개 시점 방향의 투영거리로 계산했다.

후반 30초 입력은 기억한 우회 경로에 대해 `known_occupied_command_hold`가 발생했다. 후보 조향 -0.1345 rad, 현재 점유·시차 여유를 반영한 명령 원호의 진행 여유 0.04 m로 양수 속도가 나오지 않았다. 현재 벽은 다시 관측됐으므로 최초 조향 문턱과 다른 실패다. 어떤 반환점·경로 형상이 이 정체를 만드는지는 별도 센서 기하 대조 대상으로 남긴다. 여유를 일괄 축소하거나 원인을 확인하지 않은 채 같은 주행을 반복하지 않는다.
