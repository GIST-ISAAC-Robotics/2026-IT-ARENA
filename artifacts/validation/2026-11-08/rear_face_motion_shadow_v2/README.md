# 후방 현재 면0.8초 비교 — 저장 입력 후보

v1의0.4초/5스캔은 실제 면을 지속 관측했지만 평균 오차항0.225m/s가 남아, 정지차1058명령은 그대로였고 재출발959명령 중11개만0→양수였다. 실제 주행 효과를 주장하거나 연결하지 않는다. v1 정지차 Python은 완료 JSON을 남겼지만 셸 래퍼가 종료 코드를 비워 실제 exit는 미확인, 재출발은exit0이다.

후방 면에만 더 긴0.8초/9스캔 창을 비교한다. 같은6cm 끝점오차/3cm 접근량을 더 긴 실제 연속 관측으로 나누며, 기존 안쪽 면·가속3m/s²·고정여유·반환·마스크·독립 보호는 바꾸지 않는다. 반응이 늦어지는 대신 최근 접근/연결 손실은 그대로 창을 취소한다. 평균 변화량은 순간 속도 보장이 아니므로 실제 차체/타차 가속 조건 검증은 남는다. 두 창 비교에서 효과가 부족하면 값을 계속 낮춰 맞추지 않고, 원인/한계를 남겨 측방 대표부터 진행한다.

v1의 기본 구현 전 판단 동일성은 입력 로그 해시와 시험의 등록 소스873개가 현재와 동일한지 확인한 뒤 재사용한다. v2 후보만 실행하며 실제 Python exit는 저장한 bash 래퍼로 기록한다. 아직 제어 코드/주행에 연결하지 않았다.
