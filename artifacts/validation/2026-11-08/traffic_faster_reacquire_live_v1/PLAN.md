# r27 빠른 앞차 동일 한 랩 — 기존 정지 재획득 선택

[원 실패](../traffic_faster_follow_v1/README.md)의0.8m/s 두앞차·60초·초기1.6/7.6m·100Hz·평탄교통 노면·B0390/C1 배치를 그대로 쓴다. 제어 알고리즘 수정 없이 기존 standing_wall_reacquire=true만 선택한다. 긴 현재 선호벽/앵커/서로다른스캔·점유·재개/독립보호를 유지한다. 원시/보충간격·정지·노면·한랩 판정은 그대로다.

[저장 입력](../traffic_faster_reacquire_v1/PLAN.md) OFF는0~40초1,621판단/376reset 전부 원출력 일치, ON은36.42초부터만 달라졌다. 최초조향36.72초·첫양수목표36.82초였다. 저장 이전조향/움직임이 고정된 반사실 비교이며 실제 재출발 증명이 아니다.

관련회귀와 실제헤더ON 확인을 거쳐1회 실행한다. 전체60초결과를 남기고, 같은위치 통과만으로1랩성공으로 부르지 않는다. 실패하면 증거를보존하며무변경재시도하지않는다. 5랩은이조건이유효하게성립해야검토한다.
