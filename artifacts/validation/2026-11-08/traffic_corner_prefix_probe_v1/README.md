# 짧은 현재 코너 경로 인계 — 미연결 비교

코너 감속 상대의 저장 입력1,891회에서 원래33초 이후0명령438회가 후보275회로 줄었다. 경계 미확정365회는 사라졌지만 측방 선택기의 접근 거절이 남아 전체 정지는 해결하지 못했다. 최초 명령 변경은39.06초였고, 현재 경로 인계는 그보다 앞선35.62초부터 발생했다. 실제 주행 결과가 아니다.

표적9검사 통과·생산 소스 불변을 확인했다. 첫 검사의 두 실패는 구별한다. 하나는 벽 관측 길이0.510m를 오프셋 경로 길이1.31m와 혼용한 후보 설계 오류였으며, 현재 벽 지지 길이까지만 경로 앞부분을 남기도록 고쳤다. 다른 하나는 추가한 반례 광선의 시각과 장면 끝 시각이 다른 fixture오류였다. 최초 후보·검사와 `tests_v1.log`를 보존했다. 수정 뒤 `tests_v2.log`, `replay_v2.log`, `replay_summary.json`을 참조한다.

기억이 없거나 만료된 경우, 다른 형상, 공통 관측 부족, 실제 가까운 장애물의 거절을 확인했다. 다음 [현재 측방 관측 후보](../current_guard_approach_probe_v1/PLAN.md)와 함께 연결을 검토하며 이 비교를 폐루프 성공으로 확대하지 않는다.
