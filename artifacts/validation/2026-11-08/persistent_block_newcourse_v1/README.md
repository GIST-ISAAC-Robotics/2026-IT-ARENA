# 새 코스 중앙 정지차 대표 연결

이전11/2의 정지차 우회 기능을 v2026.11.06·B0390·JR60P20·직각 옵션에서 다시 확인한다. 새 중속 프로필은 사용하지 않고 r13의 기본 저속 프로필을 유지한다. 움직이는 차 추월이 성립해도 정지차 뒤 교착이 남으면 본선 완주를 방해하므로 별도 대표 장면으로 남긴다. 아래 실제1회 결과는 미통과다.

- 상대는 출발 전부터1.6m 앞 중앙에서20초간 정지. 실제 상자 배우의 현재 센서 반환만 제어기에 전달한다.
- 자차가 실제 BYPASS를1초 이상 실행하고 상대를 지난 뒤 FOLLOW로 복귀하며 창 끝2초 동안 도로 내에서0.50m 이상 전진해야 한다. 중앙 상대 뒤에서 멈춰 있으면 실패다.
- 접촉/겹침/벽바퀴0, 두 바퀴 이하 잔디, 최소 표본·스윕 간격0.08m, 정체2.5초 이하, STOP·정상종료·입력무결성을 확인한다. 원 검사기의 HOLD/최종간격/차체도로 밖 판정은 원본으로 남긴다.
- 이전 교통처럼 명시 평탄 잔디 파생본. 1mm 원래 노면과 전체 경기/실물 증명이 아니다. 단일 모터축28카운트·8.970588:1·65mm를 유지한다.

`goal_eval.py`는11/2 검토한 평가기를 보존 복사하고 새 산출물 경로/실행유효/복귀후 전진 조건을 명시했다. 기존 원본은 수정하지 않는다. 배우 정지·최종 실행 모드·현재 도로 다각형을 실제 로그로 대조한다. 제어기 수정 없이 먼저1회 이관하며, 다음은 정지/재출발·측방/피추월·운영 결합의 미완료 정도로 정한다.


## 실제 결과와 현재 조사

20초 대표 실행은 **1.554m 진행 뒤 BYPASS 상태 교착**, 상대 통과/본선 복귀에 실패했다. 실제 우회 시작은 초록 뒤1.519초, 최장 정체14.454초다. 최종2초 진행은0.000212m, 최종 횡위치약-0.283m였다. 최대2바퀴잔디·간격하계0.1319m·접촉0·STOP/정상종료·870해시불변은 확인했지만 주행 목표를 달성한 결과가 아니다. 원시HOLD/접근 판정 통과와 실제 우회 실패를 구별한다.

마지막 제어 출력은0이며 `entry_guide_current_wall_too_short`가 지속됐다. 단독 증속의 편측 바퀴/차체 불일치와 다른 원인이다. 현재 이동차용 `rear_wall_witness`가 정지차용 `ForecastGuide`에는 연결되지 않은 차이를 저장 입력에서 조사한다. 해당 근거로 재사용 가능한지 먼저 비교하며, 미관측 영역을 비었다고 바꾸거나 벽 점유를 지우지 않는다. 이 대표 교착이 남은 상태를 기본 우회 완료로 넘기지 않는다.
