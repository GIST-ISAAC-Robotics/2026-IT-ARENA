# 중앙 정지차 S자 합류 — 제한 Gazebo 1회

2026-10-30. [직전 자동 전환](../g2_handoff_corridor_gazebo_v1/README.md)의 센서·물성·구동·공식 신호v2·30cm 카메라·방지턱OFF·20초 창을 유지한다. 기존 명시 `corridor_local_v1`/`corridor_v2_signed_hold`이며 기본 활성화나 새 회피 로직은 없다.

상대20×15×12cm 상자는1.2m 앞 중앙에서 대기한다. **평가기만** 정답 자차 중심이 초기 위치에서1.15m 진행했음을 관측하면 상대를 출발시킨다. 후륜 축 기준 반경0.35m·우/좌각0.6rad의 S자, 가속1m/s²·최대0.5m/s·총2.5m·5.5초 뒤 정지다. 곡률 전환은 순간적이며 동역학/자율 경쟁차가 아닌 각본 물체다. 이전 합성의 나란한 합류에서28.34mm 최소 간격이었으므로 물리 응답을 별도 확인한다.

- 사전 검사: 직전 실행과 제어·물성·센서 오차·설치 코드 동일, 실제 월드에서 상대 궤적551표본의 벽/통로·첫커브 전 범위, 평가 콜백의 시각·좌표·재호출, 모드별 출력 상한을 확인한다. 입력 누출/하네스 오류면 주행을 시작하지 않는다.
- 원래 G1 판정은 그대로 남긴다. 새 별도 평가는 움직이는 상대의 같은 시각 자세를 쓰며 정지 상자의 중앙값/통과 기준을 재사용하지 않는다. 추적 오차 분류만 실제 S자 일정의 속도로 바꾼다. 명령 ACK·최대간격0.1초·이동 추적35mm/정지5mm·STOP·입력 경계는 기존 기준이다.
- 주 관문: 상대 출발과5.5초 운동 완료, 실제 이동>0.1m, 합류 시작 후 자차 진행≥0.5m, 시작 전BYPASS→시작 후FOLLOW 복귀, 접촉/겹침/벽충돌0, 접지면 세 해석 모두 잔디 바퀴≤2, 실제STOP·정상종료·동일 판단 재생. 합류후 두번째우회 완수나 전체랩은 요구/주장하지 않는다.
- 차체 간격·정지/재개 시각·종료시 상태·모터축과차체차이·계산 비용은 별도 보고한다. /drive→독립보호→/drive/safe를 유지하고 음수 측정을0으로 자르지 않는다. 제어기는지도/actor정답/신호정답을받지않는다.
