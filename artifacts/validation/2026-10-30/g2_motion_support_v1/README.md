# 이동 반환과 개방형 부품 교체의 저장 입력 분석

2026-10-30. [앞선 추가 예약 생략 후보](../g2_moving_reserve_v1/README.md)는 계속 이동·재출발의 진행량을 늘렸지만, 이동후정지 조건에서 우회 진입을 잃었다. 이 실패를 보존하고 운영에 연결하지 않는다.

이번에는 이미 저장한 5조건의 서로 다른 순차 스캔만 분석한다. 모터축·gyro로 과거 실제 반환점을 현재 좌표로 옮긴 뒤 조각 중앙값 이동, 전방10% 분위값 이동, 60 mm 안에 그대로 남는 반환의 수를 함께 기록한다. 60 mm는 기존 ±30 mm 차이 여유를 사용한 진단값이며 새 허용 거리나 신원 증명이 아니다. 0.2/0.4/0.6/0.8초 간격은 분석용 비교창이다.

정지/이동 구간의 라벨은 기존 평가 각본에서 결과 해석에만 쓰며 제어기에 전달하지 않는다. 중앙값이 움직였더라도 공통 부품의 반환이 남아 있으면 부분 가림·기둥 교체를 의심할 근거다. 반대로 겹치는 반환이 없다는 사실만으로 같은 차가 이동했다고 확정하지 않는다. 아직 새 제어 정책이나 주행 시험은 아니다.

## 분석 결과와 한계

5기록의 고유 스캔을 분석했고 입력 footer/SHA-256·소스 보존을 확인했다. 추가 예약 생략이 나온 고유 스캔 중, 중앙값은60mm 이상 움직였지만 가까운 반환이양쪽2개 이상 남은 경우는 정지복합18/22, 정지후33회중23회였다. 그러나 **실제 이동 조건에서도72/73회**로 나타나 이 겹침만으로는 이동/부품 교체를 구분할 수 없다. ‘정적 지지’라는 분석 필드 이름을 정지 물체 증명으로 해석하지 않는다. [결과](analysis1/report.json).

전방10% 분위값을0.4·0.6·0.8초의 운동 이송 반환과 비교하고60mm를 뺀 가장 작은 양의 속도를 진단한 경우, 저장 명목/복합 정지에서는 양수0회였다. 계속 이동의 비교 가능114스캔은114회양수였고, 이동후정지에서는2.5–2.7초의 과거 움직임3스캔까지만 남았다. 이는 같은 저장 궤적의 탐색 분석이며 모든 차체·가림의 이동 추정기가 검증된 것은 아니다. 특히 앞면이 통째로 가려져 뒷기둥만 보이면 이 추정도 잘못 양수가 될 수 있다.

따라서 새 후보는 추정으로 예약을 해제하지 않는다. [제한 이동 보상 v2](../g2_motion_credit_v2/README.md)에서 기존 예약식에 준비 상한 이하의 속도만 더하고, 공간 부족 항을 유지한다. 알려진 가림 반례와 정지·재출발 손익을 함께 확인한다. 기존 v1은 운영에 연결하지 않는다.
