# 중앙 정지차의 편이 후보 간격 대조

2026-10-30. [저장 점유 분석](../g2_center_width_v1/README.md)에서 새 스캔 직후 고정 평행 통과 폭이 약0.250–0.267m 또는0.255–0.266m에 놓였다. 등록된0.24/0.27m가 양쪽으로 벗어나 있어, 그 사이0.26m가 선택될 경우 달라지는지 한 번 비교한다. 지난 초기 전이 순위/팽창 도형 변경과 구분한다.

후보는 기존9개 편이 중±0.27을±0.26으로 바꾼다. 기존 최대 범위 안이며 폭·물성·차량·조향·점유 여유·독립 보호·STOP을 바꾸지 않는다. 나머지 편이와0.6/0.9/1.2m 전이는 그대로다. 제어기에 표적 위치나 정답 자세를 주거나0.26을 강제로 선택하지 않는다. 기존 순위/의도/경로 유지가 실제 선택한 값을 기록한다.

현재 소스로 기존/후보 각각 중앙 정지차·복합센서 seed17·10초+STOP을1회 실행한다. 원시 센서·판단·보호 출력을 별도 오프라인schema907로 기록하고, 같은 입력에서 전체 판단(벽시계 비용 제외)과 독립 보호를 재생한다. 합성 sequential LiDAR+이상 bicycle이며 실제 동역학/ROS/Gazebo/실차 증명이 아니다.

새 스캔 사이의 오래된 장면에서는 고정 평행 공간 자체가 없었으므로 후보 간격 하나로 해결된다고 전제하지 않는다. 실패하면0.25/0.265등으로 반복 탐색하지 않으며, 선택 변화·최초 정지·관측 근거를 남기고 다음 설계를 판단한다.

## 결과: 새 후보가 선택되지 않음

기존/후보 모두0.835314m·횡0.200049m에서 `entry` 단계로 정체했다. 최소 차체간격0.126476m·접촉0·잔디바퀴최대2·STOP명령0·최종속도0, 각531호출의 전체guide/독립guard 재생이 같고 소스는 불변이었다. 첫 우회는 양쪽 모두0.6초의+0.24m/1.2m였다. **0.26은 선택되지 않았으므로0.26경로의 폐루프 실패를 검증한 결과가 아니다.** [비교](comparison1/report.json).

현재 `EntryGuide`는 처음 선택한 편이를 유지하며 현재 외벽에 경로를 다시 맞춘다. 외벽을 따라 같은 편이선을 연장하지만, 중간에 관측된 좁은 통과 폭으로 편이를 다시 고르지는 않는다. 후보 목록만 바꿔서는 이 경우의 막힘을 바꾸지 못했다.

다음 설계는 새 스캔에서 현재 경로의 명령 여유가 부족할 때, 같은 우회 방향의 작은 외측 경로만 현재 센서로 다시 비교하는 것이다. 반대 방향·중앙 복귀·미관측 공간 허가를 함께 열지 않는다. 먼저 저장 입력과 거절 반례로 다루며, 새 후보가 실제 선택되고 현재/직전 조향·독립 보호 검사를 통과하는지 구분한다. 아직 이 설계를 운영에 연결하지 않았다.
