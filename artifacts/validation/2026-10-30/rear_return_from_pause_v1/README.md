# 오른쪽 옆차 정지 뒤 재출발 — 별도 재접근 장면

2026-10-30 사전 등록. 옆차0.15 m/s 조건에서는 현재 팽창·반복 정지 때문에 옆차가 먼저 앞으로 나가 후방 소실 처리를 시험하지 못했다. 그 원래 실패는 유지한다. 이번은 경기 중 옆차가 잠시 정지했다가 다시 움직이는 별도 상황이다.

- 옆차는0–7초 정지,7–12초1 m/s로 재출발한다. 나머지 배치·앞차0.35 m/s·자차/센서·물성·속도 상한·오차seed17은 기존 합성과 같다.
- 실제 연결 코드 `observed_fresh_v2`와 기본 상태/보호 함수를 사용하고 정상 schema1 기록을 생성한다. 별도 제어기 대체나 재생 헤더 위장은 사용하지 않는다.
- 합성 명목/복합 오차를 각1회 실행한다. 이전 정지차 우회가 아닌 **옆차가 후방으로 사라진 뒤 돌아오는 전이**를 평가한다. 같은 기준으로 전이 성립·진행·정체·측방 여유·접촉·바퀴 이탈·STOP·동일 재생을 보고한다.
- `scenario_realized=false`이면 같은 실행을 반복하지 않는다. 성립하면 그 조건에 한해 Gazebo 확인의 실익을 검토한다. 기존 움직이는 옆차의 실패 해결이나 모든 후방 상황 검증으로 바꾸어 쓰지 않는다.

실행: [run.sh](run.sh). 아래 결과는 실물·Gazebo 주행 증명이 아니다.
