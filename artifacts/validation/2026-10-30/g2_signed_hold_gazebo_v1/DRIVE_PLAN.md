# signed 대기 후보 복합 오차 주행 등록

2026-10-30. [최초 복합 오차 실패](../g2_center_stress_v1/README.md)와 [저장 입력 비교](../g2_signed_hold_v1/shadow2.json)를 근거로 새로운 제한1회를 등록한다. GPT가 설계·구현·분석을, GPT-6 Luna가 실행·회수를 맡는다.

- 기존 초기 배치·중앙 정지 표적·공식 신호 시험본·20초 창·software_stop·평가 기준을 유지한다. 명령 상한0.35 m/s, 물성, 단일 모터축28카운트/15:1/65 mm도 그대로다.
- 변경은 명시 `g2_corridor_policy=corridor_v2_signed_hold`다. 음수 속도는0으로 자르지 않으며 그 순간 전진 명령을 내지 않는다. 유효한 동일 시간축의 기하만 signed 운동으로 이송한다. 정상 입력 이후 현재 외벽·관측·점유 검사와 두 개의 다른 스캔 확인을 거쳐야 재개한다. 현재 불허 틱은 항상0이고 기억만으로 진행하지 않는다.
- `off`와 `corridor_v1` 의미는 유지한다. 공간/운동 여유·표면 정렬30 mm·관측 항0.225 m/s·가속3 m/s²는 이전 시험 그대로다. 이들은 시험 가정이며 물리적 보장이 아니다.
- 복합 오차도 이전과 같다: 균등 거리±30 mm(seed17), 물리 LiDAR yaw−0.5°, gyro sigma0.02 rad/s·z편향+1°/s, 추가전송지연0. 실제 주입/취득 감사와 보정값 불변을 확인한다. 동일 난수 시드라도 달라진 궤적·ROS 일정의 동일 센서값을 뜻하지 않는다.
- 새 코드의 관련 회귀·기존 기록 동일·오프라인/런타임 동일·빌드/설치 확인이 끝난 뒤 실행한다. src의 기존 코드 변경은 후속 계약에 등록된 `bypass_entry_follow.py`와 새 `bypass_signed_hold_trial.py`뿐이다.
- 주행은1회이며 실행 중 값 변경이나 실패 뒤 무근거 재시도는 하지 않는다. 우회/복귀·접촉·바퀴 이탈·STOP·정상 종료·입력/소스 무결성·판단 재생을 각각 보고한다.
- 실제 반응이 달라지면 최초0명령·음수 피드백·재개·현재 점유/관측 사유를 분석한다. 기본 활성화·실차 위험 수용·측방 침범 대응 완료는 아니다.
