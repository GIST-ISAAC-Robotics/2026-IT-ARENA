# G2 signed 대기 후보의 복합 오차 Gazebo 시험

2026-10-30. GPT가 설계·구현·분석·최종 검토, GPT-6 Luna가 실행·대기·회수를 맡았다. [사전 등록](DRIVE_PLAN.md)에 따라 새로운 1회만 실행했다. [앞선 실패](../g2_center_stress_v1/README.md)는 그대로 보존한다.

## 변경과 실행 범위

명시 `corridor_v2_signed_hold`를 사용했다. 실제 음수 모터축 속도를 보존하고 그때는0명령을 내되 유효한 기하를 signed 운동으로 이송한다. 정상 입력이 돌아와도 현재 관측·점유·외벽 검사와 서로 다른 두 스캔의 확인 전에는 전진하지 않는다. 기본 `off`와 기존 `corridor_v1`은 그대로다. [연결 검사](../g2_signed_hold_connection_v1/README.md)의326회귀·과거 재생·오프라인/런타임 일치·빌드/설치 뒤 실행했다.

20초 제한 창·중앙20×15×12 cm 정지 상자·0.35 m/s 상한·공식 신호 시험본·방지턱OFF·가상 MCU와 단일 모터축28카운트/15:1/65 mm를 유지했다. 거리 균등±30 mm(seed17), 물리 LiDAR yaw−0.5°, gyro sigma0.02 rad/s·z편향+1°/s, 추가 통신 지연0도 실패한 이전 시험과 같다. 동일 시드는 달라진 궤적·실행 일정에서 동일 센서열을 뜻하지 않는다.

## 역방향 피드백과 보호 분석

[회복 분석](run1_recovery_analysis.json)의 활성 창989호출 중 음수 피드백22호출이 있었고, 그동안 양수 명령은0건이었다. 녹색 후4.606·5.606·7.406 s에 각각 두 확인을 거쳐0.35 m/s 후보를 재개했다. STOP 뒤28.42 s의 내부 회복 후보1건은 실제 출력이 아니다.

바퀴 역회전은 남았다(왼쪽 최소−19.078, 오른쪽−23.263 rad/s). 이번 변경은 물리 역회전을 없앤 것이 아니라 그때 경로를 잃지 않고 정지·재확인·재개하도록 한 것이다. 정답 차체 속도나 좌우 바퀴 속도는 평가에만 쓰고 제어기에는 넣지 않았다.

[보호 함수 재계산](run1_analysis.json)은1,041호출·양수863·독립 보호 감소0·`clear`1,041이었다. 이는 기록된 입력의 함수 대조이며 ROS 토픽 전달 재생을 의미하지 않는다. 실제 주행의 `/drive`→독립 보호→`/drive/safe` 연결과 분리해 기록한다.

## 한계와 다음 작업

한 개 시드·한 배치의 중앙 정지 상자 결과다. 왼쪽 통로, 측방 침범, 복수 물체, 편향된 벽 관측, 불규칙 형상, G1 추종→G2→G1 자동 전환과 실물 성능을 증명하지 않는다. 표면 정렬30 mm·관측 항0.225 m/s·가속3 m/s²의 시험 가정과 기존 반례는 유지한다. 기본 활성화·보호 여유·마찰·토크·평가기 변경은 없다.

다음은 새 정책을 명시 선택하는 자동 전환 경로의 조건·관측 이력 수명을 검토한다. 현재 성과를 반복 확인하기 위한 동일 주행은 추가하지 않는다. 커밋·푸시·외부 게시·Jetson 및 전원 변경은 없다.
