# observed_measured_v1 Gazebo 제한 1회 — 사전 등록

10/29 [v3 `observed` Gazebo](../../2026-10-29/rear_lane_preference_gazebo_v1/README.md)는 진행·접촉·STOP·재생은 통과했지만, 12.94 s에 모터축 환산 측정 1.0210176 m/s가 평행 후보의 `speed <= 1` 검사에 걸려 선호가 풀렸고 최소 옆차 간격은 50.34 mm였다. [v4 오프라인](../../2026-10-29/rear_lane_preference_shadow_v4/README.md)은 측정값을 자르지 않고 기존 2.5 m 스윕 범위·측정속도 정지공간·해당 경로 관측으로 판단한다. 10/30 [연결 묶음](../rear_lane_measured_v1/README.md)에서 목표 상한 경계를 고친 뒤 별도 정책 `observed_measured_v1`로 연결했다.

## 조건(10/29 v1과 동일)

- 12초·공식 시작 직선·3번 슬롯·공식 v2 신호·뒤쪽 30 cm 카메라·방지턱 OFF. 주 앞차 0.35 m/s, 왼쪽 옆차 0.15 m/s로 7초까지 → 이후 1.0 m/s. `left_config.json`/`left_overlay.json`은 v1 바이트 그대로이며 [복사 대조](copied_from_v1.json)에 해시를 남긴다.
- C1 순차 10 Hz·모터축/gyro 보정·단일 모터축 28카운트/15:1/65 mm·가상 MCU·독립 보호층(`/drive`→`/drive/safe`)·센서/물성/정지 판정·`g1_compare_1mps` 상한은 그대로다. 별도 센서 잡음 프로필은 넣지 않는다.
- 바뀌는 실행 입력은 `g1_rear_lane_keep_policy='observed_measured_v1'` 하나다(`run_trial.py` 차이는 정책 값과 설명뿐). ON만 1회 실행한다. 기준 OFF(4.67951 m·50.156 mm)와 v3 ON(4.63952 m·50.343 mm)은 별개 실행이며 난수·시작 시각이 같은 쌍 실험이 아니다.

## 등록 관문(10/29 v1과 동일, `summarize_runs.py`)

실제 옆→뒤 관측→사각→재접근 전이, 진행 ≥ 2.5 m, 앞차 이동 중 최장 정체 ≤ 2.5 s, 접촉 이벤트 0, 도로 밖 **바퀴 중심** ≤ 2, 표본 겹침 0, 벽 표본 0, STOP·14개 정상 종료, 실행 유효·입력 무결성, 실제 판단 헤더의 정책·소스 불변, 동일 판단 재생, 전이 자세 범위 유효.

## 별도 보고(관문과 섞지 않음)

- **원래 G1/측방 150 mm 판정**: 과거 비교선으로 그대로 계산·보존한다. 사용자 고정 규정이 아니며 이번 등록 판정과 구분한다.
- **간격 개선의 진단 기준**: 최소 옆차 표본 간격 ≥ 80 mm(기존 약 50 mm보다 30 mm 이상)일 때만 "이 1회에서 개선이 관찰됐다"고 쓴다. 1회 실행이므로 반복성·분산은 주장하지 않는다.
- **선호 유지/해제**: 시험 구간의 원시 `speed_mps`, 선호 적용 구간, 해제 시점과 이유, 측정값 > 1.0 m/s 호출에서 평행 후보 결과(`measured_region_unobserved`/`measured_stop_space_insufficient` 등)를 `analyze_preference.py`로 분리한다.
- **노면**: 등록 관문은 바퀴 중심 도구(`audit_wheel_centers.py`)다. 접지면 any/center/full 세 해석(`scripts/surface_contact_eval.py`)은 진단으로 따로 남기며 서로 대체하지 않는다.
- 실제 횡이동(중앙 쪽 최대 변화), 진행, 정체, 접촉, STOP 이동, 정상 종료, 판단 재생을 각각 보고한다.

## 실패 처리

장면 미성립·실패 시 원시 증거를 분석해 원인과 재개점을 정리하며 같은 실행을 성공할 때까지 반복하지 않는다. 물성·센서·속도 상한·판정선을 통과 목적으로 바꾸지 않는다. 이 1회 결과는 전체 랩·오차 조합·독립 상대차·실차 보장이 아니며 기본값(OFF/`timed`)은 바꾸지 않는다. 새 G2·고속화·전체 랩으로 확장하지 않는다.
