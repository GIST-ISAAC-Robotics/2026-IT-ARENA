# 현재 측방 불확실성의 비접근 기하 비교

2026-10-30. 운영 미연결·저장 입력 분석이다. [직전 중앙 경로 후보](../g2_outward_replan_v1/README.md)의 실패에서, 늦은 스캔의 이동 가능 범위가 현재 차체와 겹침을 확인했다. 같은 편이·경로 후보를 반복 조정하는 대신 진행 방향과 위험 변화의 관계를 비교한다.

현재 측정점의 고정 여유 55 mm는 모두 유지한다. 동적 팽창과 **이미 겹친** 점 중 고정 여유 밖이며 측방 이격이 종방향 이격보다 큰 점만 별도 분류한다. 현재보다 그 점의 팽창 경계에 더 접근하는 표본은 거절한다. 나머지 점에 새로 생기는 겹침과 고정 여유 안의 겹침도 거절한다. 기존 현재/직전 조향의 반응·제동 거리와 원시 관측 검사를 그대로 대조한다.

기존 531호출 중 점유 정지 호출만 본다. 가정 저속 0.10 m/s와 현재 조향·직진·기존 추종 조향·변화율 경계의 최대 5개 조향을 비교한다. 속도 0.10 m/s는 이 가설의 분석값이며 운영 채택/실물 최소속도가 아니다. 기존 기준 판단을 먼저 동일 재생하며 이후 움직임이나 새 스캔은 생성하지 않는다.

이 검사는 차체 극점과 1 cm 이내 자세 **표본**이다. 연속 시간이나 다른 물체의 미래 운동을 증명하지 않으며, 팽창 겹침이 없다고 표시하지 않는다. 쓸 만한 방향이 없으면 시험 범위를 늘리지 않는다. 있다면 연속 기하·독립 보호·STOP의 영향을 검토한 뒤에만 별도 실행을 판단한다.

## 결과: 측방 비접근 예외는 미채택

기하 반례 15건과 기존 531판단 재현을 확인했다. 최초 [analysis1](analysis1/report.json)은 반응·제동 거리를 썼지만 `braking_speed`의 추가 60 mm 잔여를 포함하지 않아 그대로 실행 근거로 쓸 수 없었다. 최초 76개 결합 후보는 모두 현재 팽창 겹침이 **없는** 호출이었다. 미계산 항목을 보존해 [analysis2](analysis2/report.json)에 60 mm 잔여를 포함했다.

| 비교 | 원래 점유 정지 | 현재 조향 후보만 가능 | 현재+직전 조향 모두 가능 | 현재 겹침이 있는 호출 중 가능한 후보 |
|---|---:|---:|---:|---:|
| 반응·제동 표본만 |272|99|76|0|
| 기존 60 mm 잔여 포함 |272|72|0|0|

두 번째의 ‘현재 조향만 가능’ 72건은 모두 현재 겹침이 **없는** 호출이다. 전체 272건 중 현재 겹침 호출도 우연히 72건이지만 서로 다른 집합이다. 회수 메시지에서 이 둘을 같은 집합으로 잘못 설명한 것을 원시 행 교차 집계로 정정했다. 표는 원시 행의 집합별 결과다.

따라서 현재 겹침을 유지하면서 더 접근하지 않는 새 예외를 채택하지 않는다. 다만 겹침 없는 호출에서, 다른 조향이면 기존 제동 여유를 확보하지만 **직전 조향을 계속 유지하는 원호**는 여전히 거절되는 경우를 분리했다. 정상 0속도 대기 중에도 이전 조향을 붙잡는 출력 구조가 원인에 기여하는지 다음 후보에서 살펴본다. 먼저 방향을 조절하는 0명령과 이후의 진행 명령을 구분하며, 현재/직전 조향 검사를 같은 호출에서 임의로 삭제하지 않는다.

새 주행·운영 출력은 없었다. 두 분석 모두 입력·소스 불변이며 반례나 비교 결과를 연속시간 안전으로 확대하지 않는다.
