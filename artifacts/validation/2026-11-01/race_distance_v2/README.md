# 선택한 교통 구성의 경기 거리 유지력

[78초 비교 후보](../released_rear_sweep_v1/README.md)의 실제 정체 개선·한 랩·접촉·노면·STOP이 확인된 뒤에만 등록할 300초·5랩 시험이다. 이전 [미실행 준비본](../race_distance_v1/README.md)은 덮어쓰지 않는다.

앞차는 0–4초에 0.35 m/s, 4–9초 정지, 9–20초에 0.55 m/s, 20–300초에 0.825 m/s로 달린다. 기존 옆차도 유지한다. 78초 뒤 같은 주행을 연장하며 자차 1.5 m/s 상한·센서·물성·2×5 신호·방지턱 OFF·선택형 후반부 후보는 같다. 상대 이동 238.45 m, 필요한 자차 순진행은 233.1645 m다.

[판정 계획](trial_plan.json)은 완주·접촉·최대 두 바퀴 잔디·10초 정체·명시 STOP을 본다. 기존 HOLD·15 cm·뒤 유지 실패도 보존한다. 제어기에 지도·상대 정답·그리드·신호 상태를 넣지 않는다. 경기 랩 종료는 평가기가 판단하며 차량 자체 인식이 아니다.

긴 주행의 첫 결과가 나오면 새로운 드문 반례를 추가하기보다, 같은 구성의 영상과 실제 실패·실물 미확인 항목을 정리한다. 미완주면 최초 진행 손실 원인을 검토한다. 완주해도 실차·방지턱·실제 독립 상대차를 검증한 것은 아니다.

선행 한 랩의 정체가 9.935→1.026초, 랩 시간이 73.515→67.863초로 개선됐고 접촉·노면·STOP을 확인한 뒤 실행했다. [기하](geometry.json)는 앞차 23,846개 표본·옆차 526개 표본, [등록](registered.json)은 선택 구성과 원본 소스를 고정했다.

## 300초 실행 결과

**평가 거리 기준 5랩을 마쳤으나, 영상 기록기 시간 초과로 전체 실행 판정은 실패다.** [원시 보고서](run1/report.json)의 `run_valid=false`, `passed=false`, 종료 코드 1은 그대로 보존했다. [독립 재검토](independent_review.json)는 주행 증거와 기록 실패를 구분한다.

| 항목 | 결과 |
|---|---:|
| 300초 각본 종료 시 순진행 | 237.784 m (5랩 요구 233.1645 m) |
| 5랩 거리 최초 도달 | 녹색 확인 후 294.478초 |
| 각 랩 시간 | 68.629 / 56.626 / 55.821 / 57.077 / 56.325초 |
| 고밀도 자세의 5 cm 이내 진행 최장 | 1.165초 |
| 접촉 이벤트·표본 중첩·벽 충돌 표본 | 모두 0 |
| 앞차 최소 간격 | 표본 0.116636 m / 구간 사이 보수 하한 0.116619 m |
| 각본 종료 시 앞차 간격 | 2.029 m |

고밀도 진행 평가는 녹색 7.695초부터 STOP 요청 308.101초까지 146,945개 자세를 사용했다. 최대 간격은 0.004초, 중심선 투영 점프는 0이다. STOP 요청까지의 진행 237.944 m와 300초 종료 시 237.784 m는 평가 구간이 다르다. [노면 사후 평가](run1_surface.json)에서 두 바퀴 잔디의 연속 구간은 8.014초, 바퀴-벽 표본은 0이었다. 실제 타이어 접촉력이나 공식 심판 판정을 뜻하지 않는다.

원래 추종기의 `hold`, `final_gap`, `sampled_gap`, `swept_gap`, `ego_stays_behind` 판정은 실패했다. 정지차 뒤에 대기하고 15 cm 이상을 확보하며 끝까지 뒤를 유지하는 기준과, 이번 우회·양보 후 주행을 구분해서 읽는다. 이 실패를 삭제하거나 새 성공으로 덮어쓰지 않았다.

## 영상과 실행 종료의 한계

[영상 검사](video_audit.json)에서 MP4 4,122프레임 전체를 디코드했다. 960×540, 20 fps, 재생 길이 206.1초이며 이미지의 마지막 시뮬레이션 시각은 209.35초다. 따라서 **5랩 전체 영상은 아니다.** [남은 3인칭 영상](run1/video/chase_raw.mp4)은 앞부분만 보여 준다.

기록기는 실제 시간 2,400초 한도에 도달해 `recording wall deadline`로 먼저 종료했다. 제어·시뮬레이션은 계속 진행했고, 평가기는 전체 각본·STOP까지 기록했다. 종료 감사는 기록기의 사전 오류 때문에 실패했으며, 나머지 자식 프로세스는 종료되고 남은 시험 PID는 없었다. 실제 한도는 [기존 기록기](../../2026-10-31/g1_continuous_prefix_course_v1/record_chase.py) 안의 고정 2,400초이며, 이 시험의 [실행 진입점](course.launch.py)은 별도 값을 전달하지 않았다. 다음 긴 녹화에는 새 실행용 기록기에서 주행 시험의 실제 시간 한도와 정리 시간을 함께 지정해야 한다. 과거 실행에 포함된 기록기와 등록 해시는 수정하지 않는다. 영상만 채우기 위해 같은 5랩을 즉시 다시 돌리지는 않는다.

원본을 보존한 채 [시뮬레이션 시간 1배속 영상](run1/video/lidar_third_person_simtime_1x.mp4)을 별도로 만들었다. [타이밍 검사](run1/video/video_timing_audit.json)는 20 fps·4,187프레임·209.35초이며, 수신 공백의 65프레임은 직전 이미지를 유지한다. 누락된 마지막 약 100초를 생성한 영상이 아니다. [60초](review_frames/frame_060.png), [140초](review_frames/frame_140.png), [198초](review_frames/frame_198.png) 프레임도 추출해 3인칭 시점을 육안으로 확인했다.

이는 방지턱 OFF, 앞차와 옆차의 고정 각본, 한 번의 선택형 구성 시험이다. 독립적으로 반응하는 상대 5대, 실차, 차량 자체의 랩 종료를 검증한 결과가 아니다. 기본값 승격 없이 결과를 보존하며 다음 작업은 단독 고속 실패의 [마지막 코너 진단](../qualifying_corner_diagnosis_v1/README.md)으로 이어간다.
