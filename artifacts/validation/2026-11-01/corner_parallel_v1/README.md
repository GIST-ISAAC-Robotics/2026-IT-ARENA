# 첫 코너의 오른쪽 동행 배치 — 준비 단계 보류

실제 주행은 하지 않았다. 현재 공식 3번 출발칸은 중앙선 대비 오른쪽 약 90 mm다. 처음 설정한 상대 오프셋 -180 mm는 초기 자차와 겹쳤다. [최초 소스](prepare_attempt1.py), [오류](prepare.log)를 보존했다.

[정적 배치 비교](placement_probe.json)에서 -250 mm는 초기 차체 사이가 약 10 mm이고 상대의 두 바퀴가 계속 잔디에 놓였다. -300 mm는 네 바퀴가 도로 밖이었으며 -350/-400 mm에서는 벽과도 겹쳤다. 간격이나 벽 판정을 낮추지 않고 이 배치를 보류했다. 상대가 조금만 오른쪽에 있으면 안 된다는 일반 결론이 아니라 **현재 출발칸과 일정한 코스 횡편이**의 조합 문제다.

다음은 [왼쪽 동행 배치](../corner_parallel_v2/README.md)다. 오른쪽 사각 재접근의 미해결을 대신하지 않으며 자차 초기 위치나 공식 월드는 바꾸지 않는다.
