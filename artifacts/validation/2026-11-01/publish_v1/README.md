# 11/1 작업 게시 정리

코드·설정·문서·실패 및 성공 요약·사진·주행 영상을 함께 보존한다. 기존 정책대로 원시 센서 bag·고빈도 JSONL·상세 수신 기록은 Git에 넣지 않는다. 추가로 호출별 결과가 포함된 큰 재생 JSON 5개는 로컬에 보존하고 [파일별 SHA-256과 판정 요약](local_replay_manifest.json)을 게시한다. 기존 파일은 삭제하거나 덮어쓰지 않았다.

최신 단독 실행은 [코너 끝 경로 연결](../solo_corner_handoff_v1/README.md)의 35.281초 한 랩이며, 교통 5랩과 별개다. 사용자의 최종 정리 요청에 따라 새로운 주행이나 기능 개발 없이 검토·기록·게시만 수행했다.

게시 전 확인에서 기본 LF 정규화가 12개 소스/시험 입력의 기록된 CRLF 바이트를 바꾸는 것을 발견했다. 기존 저장소의 증거 보존 방식에 따라 .gitattributes에 해당 경로와 11/1 산출물의 바이트 보존 규칙을 추가했다. 실행 내용이나 과거 해시는 바꾸지 않았다. 로그·패치·기록된 EOF 공백도 소급 정리하지 않는다. 로컬 문서 파일 링크 938개는 누락이 없었다.
