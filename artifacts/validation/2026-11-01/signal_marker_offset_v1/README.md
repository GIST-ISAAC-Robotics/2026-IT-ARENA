# 신호는 제자리에, ID45만 옆으로

[10/29 제작측 설명을 적용했던 팀 시험본](../../2026-10-29/signal_spec_1029_v1/README.md)을 기준으로 **2행×5열 신호의 설치 위치·높이·기울기는 그대로** 두고 ID45 표지판을 진행 방향 오른쪽으로 0.20 m 옮겼다. 공식 설치 확정값이 아니라 팀 시험값이다. 도로 폭 0.45 m, 판 너비 0.10 m여서 새 판은 도로 가장자리 위에 걸친다. 높이·각도·PNG·충돌 형상은 그대로이며, 위치를 바꾼 링크 한 줄 외에는 월드가 바이트 단위로 같다. [월드](fixture/world.sdf), [배치 정보](fixture/scene.json), [재생성 방법](prepare.py). 공식 ZIP과 예전 시험은 수정하지 않았다.

6개 그리드에서 등에 9개씩 찍은 시선 표본으로 판 가림만 비교했다. 뒤쪽 높이 30 cm 카메라에서는 변경 전 6칸 중 5칸에서 판이 광원 일부를 가렸다. 변경 후에는 **여섯 칸 모두 ID45 때문에 가린 표본이 0**이었다. 전방 높이 14.5 cm 카메라도 이 판 때문에 가린 표본은 0이지만, 선두 쪽 2·5번에서는 여전히 신호가 카메라 수직 화각 밖이다. 높은 앞차에 의한 가림도 남는다. [좌표와 시선 비교](geometry.json)는 단독 정적 기하이며 RGB 검출, 동적 출발 또는 실제 시설 검증이 아니다. 속도·추종 비교에 쓰는 기존 임시 신호를 이 수치로 소급 평가하지 않는다.
