# M2 전방 합류 차량 시험 — 10/26 재개

새벽 정리 때는 순수 경로 helper 초안에서 중단했다. 오전 재개 뒤 평가용 주 actor의 명시 `merge_straight` 경로를 시험기에 연결하고, 관련 회귀와 공식 도로 감사 뒤 제한 주행을 진행한다. 제어기·보호·기본 모드는 바꾸지 않는다. M3 옆차 대응이나 추월 기능을 구현한 결과가 아니다.

## 준비한 범위

- [`traffic_merge.py`](../../../../scripts/traffic_merge.py)는 평가용 앞차가 고정 직선 기준에서 횡위치를 바꾸는 quintic 공간 경로다. 종방향 진행이 멈추면 횡이동과 회전도 멈추며, 후륜 경로에서 차체 중심 자세를 계산한다.
- 끝점의 기울기·곡률을 0으로 하고 등가 조향의 해석 상한을 계산한다. 도로·벽은 회전된 차체 전체를 최대 5 mm 간격으로 검사하도록 준비했다. 이는 차량 동역학이나 연속 무접촉 증명이 아니다.
- [`test_traffic_merge.py`](../../../../tests/test_traffic_merge.py)는 끝점·정지·후륜 접선·좌우 대칭·잘못된 입력·도로/벽 반례를 다룬다. 아래 최소 검사는 준비 코드의 상태 확인이며 공식 경로 검증과 구별한다.

## 시험안과 등록

기존 M2 `stop_restart`의 센서·속도·독립 보호와 차간격 0.15 m 판정을 유지한다. 앞차는 초기 횡위치 +0.13 m에서 종방향 0.35 m 진행 후 0.8 m에 걸쳐 중앙으로 합류한다. 기존 0–4 s 주행, 4–9 s 정지, 이후 재출발 일정을 사용하고 자차보다 앞에서 진입하는 한 조건이다. [사전 등록](PLAN.md)과 `config/tests/m2_merge_stop_restart_v1.json`에 범위·실제 합류/방향 관문을 고정했다. 초기 횡투영은 자차 폭과 일부 겹치므로 완전히 옆 차로에서 들어오는 시험은 아니다. 센서 잡음·추가 actor·M3·운영 STOP 시퀀스를 동시에 추가하지 않는다.

## 재개 순서

1. 순수 검사 결과와 입력 검증 범위를 검토한다. 시험안의 실제 공식 도로·벽·차체 여유, 완결된 합류와 종방향 위치를 오프라인으로 감사한다.
2. 기준 소스·설정을 보존하고 판정 조건을 사전 등록한다. 원래 M2의 HOLD/재개/간격/최종 거리와 실제 합류 완료를 분리해 요구한다.
3. 그 뒤에만 primary actor용 명시 옵션을 시험기에 연결한다. 추가 actor에 프로파일을 잘못 적용하지 않고, 기존 경우의 출력·초기 배치·예상/실제 actor 자세 비교를 회귀로 확인한다.
4. 필요한 빌드/설치 확인 후 근거가 갖춰지면 제한 주행 한 번을 수행한다. 실패하면 원본을 보존하고 원인부터 분석한다.

평가 정답은 제어 입력에 넣지 않으며 `/drive → 독립 보호층 → /drive/safe`, STOP·단일 모터축 28카운트/15:1/65 mm를 유지한다. 보호 판정선·물성·기본 모드는 변경하지 않는다.

## 마감 검사

[run1_pure](run1_pure/)는 WSL 실행 단계에서 `Wsl/E_ACCESSDENIED`가 발생해 **pytest 미실행(`NOT_STARTED`)**이다. 코드 테스트의 통과/실패 결과가 아니며 자동 재시도하지 않았다. 두 파일의 전후 SHA-256은 동일하다. 오류·상태 기록을 보존했고 실행 담당자의 최종 Windows 프로세스 조회에서는 관련 시험이 검출되지 않았다. 앞선 M4 run5의 14/14 정상 종료·잔존 0 근거는 별도로 유지한다.

당시 초안은 최소 회귀도 미검증 상태로 중단했다. 다음은 오전 재개의 별도 결과이며 기존 기록을 성공으로 바꾸지 않는다.

run3/4는 경로 불합격이나 제어기 실패가 아닌 실행 준비 오류다. 고정 셸에서 ROS setup 전 `set +u`, Python `-B`와 명시 경로만 사용하도록 정리했다. 기존 실패 로그는 보존한다. [run6 고정 명령](run6_trial.sh)은 설치본/소스 확인·Gazebo 한 번·정상 종료 감사·판단 재생·노면 후처리를 순서대로 실행한다.

run6의 전체 진행은 4.280 m, 최종 앞차 간격은 0.615644 m다. 상대차는 실제 +0.13 m에서 약 0 m로 이동했고, 1,500개 합류창 자세에서 방향 오차 최대 0.009274 rad·도로/벽 겹침 0을 확인했다. 최종 STOP은 0.5 s 정지창의 최대 속도 0.00981 m/s·공백 3 ms, 14/14 자식 정상 종료·잔존 0이다. 설치 8모듈의 소스 일치와 실행 전후 91개 보존 파일 불변을 확인했다. 9,709개 노면 표본에서 차체/바퀴 도로 이탈·벽 겹침과 패널티 사건은 0이다.

이번 묶음은 완료한다. 이미 일부 횡폭이 겹치는 앞차의 얕은 합류 한 조건이며, 별도 차로에서의 갑작스러운 끼어들기·M3 피추월·고속·전체 랩·실차 증명이 아니다. 같은 조건을 성공할 때까지 반복하지 않았다. 이후에는 현재 미해결 M3의 계산 비용을 저장 입력에서 분해하되 관측·간격 계약을 바꾸지 않는다.
