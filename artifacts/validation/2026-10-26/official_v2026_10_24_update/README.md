전체 회귀는 기존 C++ 대조 바이너리를 해시 및 원본 불변 확인 후 재사용했다. 실제 Jetson/MCU·전체 랩·방지턱 통과 시험은 아니다. 실행 담당 GPT-6 Luna가 run1 뒤 사용량 한도로 중단되어 이후 검증은 GPT 주 에이전트가 수행했다.

`upstream/`은 고정 커밋·릴리스·이슈 댓글 조회 원문이다. `previous_runtime.zip`은 갱신 전 실행본이고, `builder_before.py`는 당시 HEAD 생성기다. `m5_publication_before*.zip`은 파일별 이전 바이트를 모은 출처 대조 자료이며 단일 시점의 실행 소스가 아니다. 실패 당시 잘못 연결한 후속 JSON은 run4/run5에 보존하고, 최종 후속 기록은 `config/tests/m5_publication_r0_sha256.json`이다. 과거 실행 결과를 최신 판본의 성공으로 바꾸지 않는다.

`preexisting_accidental_hash_manifest.json`은 기존 저장소 루트의 `--help`라는 파일을 내용 변경 없이 옮긴 해시 목록이다. `local_only_inventory.json`의 상세 센서/판단 로그·소스 압축은 기존 정책에 따라 로컬에 남으며 삭제하지 않았다. `publication_audit.json`은 게시 후보의 고확률 비밀키/토큰 패턴 검사 결과다. 요약·실패·사진·공식 원본은 게시 범위다.

일회 편집·등록 Python 파일은 당시 작업 재현 근거다. 여러 번 실행하면 중복 편집하거나 이미 존재하는 자료 때문에 실패하도록 되어 있으므로 일반 실행 진입점으로 쓰지 않는다. 트랙은 `python3 scripts/build_official_track.py`, 검사는 `--check`를 사용한다.
