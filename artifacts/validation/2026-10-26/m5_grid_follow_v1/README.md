# M5 정지 그리드 첫 경로: 신호 시야와 별개의 출발 제약

[사전 범위](PLAN.md)의 16개 정지 장면을 G1과 현 선택형 M3에 입력했다. 새 Gazebo·ROS launch·실제 출발은 없고, 계산된 명령은 어디에도 발행하지 않았다. **진단 완료와 출발 기능 통과는 별개다.**

## 입력과 판정 경계

현재 실행본의 공식 그리드 registry와 벽 visual 상자 694개의 수평 단면을 사용했다. 다른 차량은 명목 20×15×12 cm 정지 상자다. C1은 전방 60 mm·높이 95 mm·후방 가림 60°·500광선·10 Hz·.05–12 m를 유지한다. 가장 가까운 표적이 최소거리 안이면 NaN으로 남기며 뒤 벽을 대신 반환하지 않는다. 벽 외 시설·자체 부품은 현재 후방 마스크 외에는 재현하지 않았고 실제 반사율·노이즈·영상·광학도 제외했다.

4 fresh scan을 50 Hz로 20회 호출했고, 자차·상대차는 계속 정지한다. 합성 정지 운동 입력과 `LocalScene`만 제어기에 주며 지도·슬롯·상대차 이름/속도 정답은 주지 않는다. M3는 현재의 command fallback·observed release·small center straight·straight surface commitment 선택 조합이다. 순수 제어기 진단이고 독립 보호층/MCU는 실행하지 않았으므로 양수 계획 명령도 출발 허가가 아니다.

## 실패와 수정

첫 [run1](run1/probe_stderr.txt)은 관련 31회귀 뒤 분석 도구에서 실패했다. 보존된 예전 메시 벽을 읽던 `wall_geometry`를 현재 개별 상자 visual 월드에 적용한 오류다. 월드나 주행 제어의 실패로 세지 않는다. 실패 원문·[당시 소스 ZIP](run1_failure_sources.zip)·[해시](run1_failure_sha256.json)를 보존했다.

새 평가 스크립트에만 box visual의 model/link/visual pose 합성·측정면 교차를 추가했다. 실제 현재 파일, 기울어진 pose·mesh·잘못된 크기·측정면 밖의 거절을 검사한 [run2](run2/tests_stdout.txt)는 **관련 36회귀 통과**, 진단 exit 0, 소스 53파일 불변·stderr 없음·관련 잔존 0이다. 기존 helper와 월드·제어·보호 기준은 바꾸지 않았다.

## 결과

[요약 표 원본](run2/data/summary.json), [입력 광선·20호출 진단 전체](run2/data/report.json). 그리드 번호는 공식 `index`이며 예선 순위를 뜻하지 않는다.

| 3대 | 2 | 0 | 0 | 위와 같은 간격/측방 후보 거절 |
| 3대 | 5, 1 | 0 | 0 | 경계 미확인 |

다중 배치의 10개 자차 위치는 양 모드 모두 20호출 전부 0요청이다. 첫 칸 2는 경로가 형성되지만 옆 물체를 포함한 점유 팽창에서 진행 여유가 0이 된다. 2대 조건 마지막 호출의 M3 직진/hold 후보 측방 잔여 여유는 약 −72.6 mm이며, 양보 후보도 약 −77.0 mm다. **3 cm라는 초기 기하 간격을 그대로 측방 위험 예산의 여유로 사용할 수 없다**는 현재 계산이다. 다른 칸은 경계 경로를 먼저 확보하지 못해 M3 측방 후보까지 가지 않는다.

이는 신호 허가·차량 출발 시차·다른 차량의 움직임을 넣지 않은 첫 .4초 정지 비교다. 실제로 앞차가 먼저 움직였을 때 관측이 복구되는지, 계속 교착하는지, 출발 중 조향/충돌이 어떤지는 확인하지 않았다. “공식 그리드가 잘못됐다”거나 “대회에서 절대 출발할 수 없다”는 결론이 아니다.

## 마감과 다음 재개

사용자 정리 요청으로 이 진단까지만 마친다. M5는 **공식 신호 시야 + 출발 전 경계 확보 + 밀집 배치의 초기 동작**을 함께 해결해야 하며, 첫 두 문제를 신호등 위치 변경이나 간격 상수 축소로 숨기지 않는다. 다음은 저장된 광선으로 경계 미확인 원인을 좁히고, 처음부터 차로 중앙으로 합류하지 않는 출발 후보가 기존 관측/정지 경계 안에서 가능한지 설계하는 것이다. 지도·공식 칸 번호를 제어 입력으로 주는 방식은 사용하지 않는다. 실제 장착/시설 자료는 병행 요청 자료로 남긴다. 새 주행·기본 활성화·센서 변경은 하지 않았다.
