# 다음 구현 범위: 관측 증거와 복귀 출력의 분리

이 문서는 10/26 미연결 시제품의 다음 구현 수용 조건이다. 운영 연결 승인·주행 성공 보고서가 아니다. 최신 결과·판정은 [E3 §8.28](../../../../docs/autonomy/MULTI_ACTOR_E3_2026_10_24.md#828-1026-gpt-인계-검토--전제-채택-보류와-실제-가림의-영향)을 따른다.

## 1. 원문 한 회전 metadata부터 보존한다

현재 `LocalScene`에는 변환된 각 광선과 원본 인덱스는 있지만, 원문 `angle_min`·`angle_increment`·끝점 포함 방식이 없다. 현재 시제품은 원문을 `scene_from_scan`으로 해석하는 시점에 별도 `CycleScene`으로 묶는다. 투영된 방향만으로 인덱스 0과 마지막이 이웃이었다고 추론하지 않는다.

- 우선 대상은 끝점 중복 없는 정규 한 바퀴다. `(N−1)×간격=2π`인 끝점 중복 입력, 부분 회전, 하나 빠진 배열은 별도 계약 전까지 순환 인접성을 주지 않는다.
- 후속 시제품은 `max(1e-9, 2π×float32 eps)`로 원문 각도 metadata의 누적 반올림을 허용한다. 180/500/513/720/1440/8192광선 정상 입력을 받고 한 광선 누락·끝점 중복은 거절한 관련 회귀까지 확인했다. 끝점이 중복된 배열의 다른 시각·다른 반환은 임의로 합치지 않는다.
- 새 증명은 원래 장면 객체에만 유효하다. 재투영·필터링·일부 잘라내기·다른 세대의 장면에는 자동 이월하지 않는다. 같은 source index라는 사실만으로 새 시각의 동일 광선이라고 보지 않는다.
- 공간적 이웃이어도 취득 시각은 그대로 둔다. 양쪽 반환 상태·실제 각도 간격·원점·거리·점별 취득 나이 여유를 모두 검사한다. `unknown`·`masked`를 채우지 않는다.
- 공식 C1 드라이버의 정렬/반전/복제/호스트 시각 문제는 이 기능으로 해결되지 않는다. 실물 `timing_verified`를 켜는 근거로 쓰지 않는다.

## 2. 합집합 기록은 별도 상태 표현으로 평가한다

목표는 이전 물체를 새 반환으로 덮지 않으면서, 동일 통과 차량의 매 스캔을 독립 기록으로 쌓아 1초/16기록에서 잠기는 문제를 줄이는 것이다. 표현을 바꾸는 것과 후방 위험을 면제하는 것은 다르다.

- 기존 같은 측면 두 차량·운동 이력 단절·시각 역행·전부 무응답·상한 초과 반례를 먼저 고정한다.
- 공통 기준 시각의 가능 영역 합집합에서 양의 관측 자유만 제거한다. 개별 물체 연관, 최소 단면, 관측하지 못한 후방 부재를 가정하지 않는다.
- 영역이 완전히 확인된 경우에도 fresh 확인 횟수·새 결측 발생을 구분한다. 상한 초과를 자동 해제/영역 삭제 사유로 쓰지 않는다.
- 셀 표본화를 바꿀 때 포함 관계를 검사한다. 단순 중복 제거가 서로 다른 격자의 가능 영역을 줄이는 근사가 되지 않도록 한다.
- 현재의 20초 수명 상한·32,768셀은 시제품 관리 한계다. 실시간 비용을 재기 전에 유효한 복귀 조건이 성립하는지 확인하고, 전제가 없는 후보를 성능만 최적화하지 않는다.

## 3. '기본 G1 복귀' 대신 실제 다음 출력의 보호를 유지한다

현재 `release_to_baseline`은 해제 뒤 기본 G1에 맡기며 측방 예산을 계속 적용하지 않는다. 복귀 시점의 옆차가 회랑 밖이었다는 조건은 다음 곡선·다른 움직임에서 간격을 보장하지 않는다.

- 상태 기억의 확인과 실제 속도·조향 명령 허용을 분리한다. 이전 기록이 관측으로 확인됐더라도 다음 기본 경로의 실제 발행각/이전각·제동 외곽·측방 점유를 검사하는 상태를 둔다.
- 먼저 저장 입력에서 기본 경로와 현 측방 후보를 동시에 평가하는 미연결 비교를 한다. 출력·기본값을 바꾸지 않고 어느 단계가 막는지 기록한다.
- 기본 경로 거절 때 새 후보·직진·HOLD 중 기존 관측으로 지지되는 것만 선택한다. 미관측을 채우거나 '이전 기본 모드도 위험했다'는 이유로 새 외곽을 허용하지 않는다.
- 실제 사각 안의 물체를 계속 배제할 근거가 없다면 미해결로 남긴다. 순환 인접성 구현이나 실제 가림 자료 수령만으로 현재 70 mm 측방 간격 미달·M1 전체 완주가 해결됐다고 하지 않는다.

## 4. 다음 한 묶음의 종료 조건

원문 metadata 보존 후보를 명시 선택형 모듈로 정리하고, 기본 OFF 동일성·순환 경계 반례·시각 보존을 확인한다. 이관 결과가 현재 마스크에서 아무 출력을 바꾸지 않으면 같은 공식 주행을 다시 돌리지 않는다. 이후 '관측 기록 확인 뒤에도 실제 출력 보호 유지'의 저장 입력 비교로 넘어간다. 새 장착 자료가 도착하면 가림 각도를 갱신한 별도 시험을 등록한다. 본선 전체 성공이나 실차 안전으로 확장하지 않는다.
