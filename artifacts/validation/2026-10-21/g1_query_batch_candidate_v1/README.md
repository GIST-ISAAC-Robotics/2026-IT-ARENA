# 외곽 조각 필요조건의 묶음 계산 후보

운영 적용 전 후보 `candidate.py`를 1회 검증했다. 관련 272회귀, 저장 판단 2,615개 일치 후 실제 6호출의 12함수 입력을 회수했다. 각 버전 240표본의 AB/BA에서 생성 질의 좌표와 얇은 교차 개수는 정확히 같았다.

| 함수 | p50 ms | p95 ms | 최대 ms |
|---|---:|---:|---:|
| 기준 | 2.517323 | 2.997652 | 3.334653 |
| 32조각 묶음 후보 | 1.881385 | 2.216428 | 2.484071 |

광선 교차 가능성의 필요조건만 같은 수식으로 묶어서 계산한다. 실제 clipping과 몸체 제외·결측/후방 조건은 유지한다. 입력/소스 전후 불변·종료 0. 후보 검사 당시 소스는 `run/source_snapshot.zip`에 보존하며 이후 전체 운영 검증과 구분한다.
