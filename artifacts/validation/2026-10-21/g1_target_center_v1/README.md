# 원판 가장자리 접촉·속도 변화 상계 — 단일 출처

관련 47회귀·2,615판단 일치·입력/소스 불변·종료 0. 모든 중심 탐색이 목표 거리 오차 0.1 mm에 도달했다. 지름 100/150 mm는 각각 현재 출처 25질의를 반박했고 과거 출처 200질의는 미결정이었다. 5~50 mm는 전부 미결정.

원래 점형 반례가 사용한 **한 출처씩만** 비교한 결과다. 미결정은 실제 궤적이나 장애물의 존재를 증명하지 않는다. 다음 두 출처 결합과 구별하며 원래 소스는 `run/source_snapshot.zip`에 보존한다.
