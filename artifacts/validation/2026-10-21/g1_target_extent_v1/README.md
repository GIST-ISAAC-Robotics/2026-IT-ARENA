# 고정 점형 반례의 유한 원판 대조

평가 전용. `run.sh` 1회는 관련 16 pytest·2,615개 저장 판단 일치·입력/소스 불변·정상 종료 0으로 마감했다. `run/report.json`과 `run/source_snapshot.zip`을 보존한다.

225개의 원래 점형 반례를 같은 등속 중심 궤적의 원판으로 키웠다. 지름 2 mm 이상은 모두 기존 첫 반환 선분과 모순되지만, **다른 중심/속도/형상·실제 표적의 관측 가능성을 전수 검증한 결과가 아니다.** 운영 판단·주행 허가는 바뀌지 않았다.
