# 유한 원판 — 현재/최근 출처 결합

`run.sh` 1회: 관련 47회귀·2,615판단 일치·입력/소스 불변·정상 종료 0. 모든 225질의×6지름의 셀 탐색이 목표 거리 오차 0.1 mm를 충족했다.

- 지름 100/150 mm: 각각 225개 모두 현재 중심 영역 반박.
- 지름 5/10/20/50 mm: 각각 225개 미결정. 실제 움직임 존재를 입증하지 않음.
- 100/150 mm 미결정이 없어 대표 등속 궤적 구성은 **미실행**했다(`trajectory_samples=[]`).
- 원형 단면·첫 반환·명목 운동·0.5 m/s 상한의 조건부 모형이다. 차량 외형과 라이다 단면은 다르므로 운영 연결/기본값 변경/주행 허가는 없다.
