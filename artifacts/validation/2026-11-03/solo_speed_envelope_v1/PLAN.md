# 단독 직선의 속도 근거와 근거리 조향 분리

11/2 같은 월드의 완주/미완주 기록에서 선정 프로필은 그대로 두고 검토한다. 먼저 저장된 시각별 비교와 두 실제 궤적을 구분해 [구간 수치](regional_comparison.json)를 남겼다. 43–44 m에서는 먼 벽 연결로 증가한 부모 속도 명령이 없었지만 조향은 달라졌다. 실제 통과 시각·속도도 달라서 조향 하나만으로 정지를 설명할 수는 없다.

**가설:** 단독에서 원래 경로와 조향은 유지하면서, 길게 나란히 보이는 양쪽 벽의 현재 반환을 속도의 거리 근거로만 쓰면 직선에서 이득을 얻을 수 있다. 지도상 직선이나 진행 거리로 작동을 결정하지 않는다. 무반환·코너 정지 해제 로직은 건드리지 않는다.

1. 독립 자료에서 원래 선정 단독의 실제 판단에 적용 가능성을 계산한다. 완전 관측·현재 경로·양수 주행에서만 검토한다. 기본 경로가 현재 차체의 직진 방향을 벗어나거나, 양쪽 벽의 연속 반환이 근거리에서 이어지지 않으면 원래 결정을 그대로 쓴다. 이 검토에서 얻는 것은 두 벽이 실제로 보인 종방향 길이이지 점유 해제나 새 경로가 아니다.
2. 원래 경로의 근거리·예견 곡률 상한과 기존 제동/차간/점유 한도를 보존한다. 원래 발행각·직전각에서 증속 때문에 필요한 거리까지 차체가 벽 범위를 벗어나지 않아야 한다. 복잡한 새 경로·두 번째 전체 제어기는 피한다.
3. 판단 출력의 새 0명령·조향 변경, 코너에서의 부적절한 증속, 원래 램프 뒤 속도 이득과 계산 부담을 확인한다. 추가 이득이 작거나 필요한 관측을 확보하지 못하면 프로필을 늘리지 않는다. 실제 속도·랩·접촉은 저장 입력으로 판정하지 않는다. 같은 센서·원래 보호·STOP을 쓰는 1랩 실행은 준비와 근거를 갖춘 뒤 별도로 등록한다.

현재 경기 거리 주행의 등록 소스·설정은 변경하지 않는다.
