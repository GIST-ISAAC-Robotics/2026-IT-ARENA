## 실제 반환 확인

[반환 대조](run1_outline_returns.json)는 원시 C1 광선의 취득시각과 평가용 자세를 사용해 점을 상대 좌표로 옮겼다. 정지 상대의 **오목 중앙 반환592개/고유 스캔31개**, 폭을 유지한 앞뒤 옆면 반환139개를 확인했다. 옛 상자 중앙 옆면 위치에 해당하는 반환은0개였다. 단순히 모델 파일만 바뀌고 센서는 여전히 상자를 본 결과가 아니다. 정답 자세는 이 사후 평가에만 썼다.

투영은 렌더 취득·자세 표본의 근사를 포함한다.25mm 형상 차이를8mm 구분 여유로 비교한 것으로, 회전 보정 정확도나 실물 거리 오차를 측정한 결과는 아니다. [분석기](../../../../scripts/audit_actor_outline_returns.py)의 합성 대조2개는 옛box 반환을 오목 외형으로 잘못 인정하지 않는지 확인했다.

[관측 윤곽·충돌 외곽·실제 반환 비교 그림](run1_outline_returns.svg)을 함께 보존했다. 그림의 점은 같은 사후 대조의 반환이며 도식용으로 만든 센서 데이터가 아니다.
