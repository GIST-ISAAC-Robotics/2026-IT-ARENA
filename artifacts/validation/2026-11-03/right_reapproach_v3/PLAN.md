# 오른쪽 재접근 v3: 현재 차선 선호의 폐루프 대조

v2에서 사각 뒤 재접근 장면은 성립했으나 중앙 복귀 뒤 측면 접촉했다. 원본 실패를 보존한다. 이번에는 **scenario.json의 바이트를 v2와 같게 유지**하고 기본 OFF `--current-lane-preference-trial`만 명시해 1회 비교한다. 센서·초기 위치·상대 속도/100Hz 갱신·차체·물성·마찰·노면·독립 보호·STOP는 그대로다.

후보는 세계에 정지한 듯한 측방 반환을 차량 부재로 해석하지 않고 어느 쪽에 있었는지만 기억한다. 현재 완전 관측 직선의 검사 완료 평행 경로로 진행할 수 있으면 불필요한 중앙 복귀를 늦춘다. 반대쪽 현재 근접 물체·코너·벽 선택 변경 시 원래 판단으로 돌아간다. 과거 점을 장애물로 삽입하거나 미관측을 자유로 채우지 않는다. 더 빠른 평행 진행은 현재 점유·제동·관측 영역을 재검사하며, 속도 여유는 실행 감속비/28카운트/65mm/표본율의 1카운트분으로 전달한다. 옛 15:1 상수를 쓰지 않는다.

## 유지하는 판정

- 초기 관측 2스캔 → 전체 후방 마스크/반환0 1스캔 → 오른쪽 재접근 2스캔의 실제 성립.
- 진행 ≥2.5m, 움직인 뒤 연속 저속정체 ≤2.5초, 표본/연속 이동 하한 간격 ≥80mm, 접촉·겹침0.
- 최대 두 바퀴 잔디·벽0, RGB 최초 출발, 입력/소스/옵션 기록, 명시 STOP/MCU 정지, 정상 종료.
- 원시 옛150mm/HOLD/앞차뒤 판정과 별도 목표를 구별한다. 실패하면 원인 분석으로 돌아가며 같은 조건을 성공까지 반복하지 않는다.

사전 근거는 ../rear_lane_continuity_v1/에 있다. 원본344판단 일치, 후보 첫 중앙 조향1건을 평행 양수로 변경, 비사각형1,100판단 변화0·합류1,222판단 중16건 차선 유지/감속·새0명령0이다. 저장 입력의 고정 궤적 대조이며 충돌 해소 증명은 아니므로 이번 실제 실행에서 확인한다. 전체 경기/실차 보장이 아니다.
