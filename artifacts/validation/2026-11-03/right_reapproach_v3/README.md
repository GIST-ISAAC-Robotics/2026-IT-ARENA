## 무엇이 달라졌는가

약 1.719초에 원래의 중앙 방향 정지 조향 대신 이미 확인한 평행 진행을 택했다. 후보 적용은 총 125판단(표본 시간 2.50초)이다. 3.21초에 상대 축 기준 양 차량 **중심**의 횡거리는 v2 약144mm, v3 약235mm였다. v3는 재접근 중에도 약235mm를 유지했다. 상대가 앞서간 뒤에는 이 거리가 다시 줄었다. 차체 폭을 포함한 실제 최소 **외곽 간격**은 위 표의 84.966mm다. [판단·두 궤적 비교](../rear_lane_continuity_v1/closed_loop_comparison.json)는 평가 자세만 사용한다.

저장 입력 시제품에서 가정한 20ms와 실제 시뮬 엔코더 설정 100Hz(10ms)는 다르다. v3 판단 header의 평행 속도 여유는 **0.0812988m/s**로, `2π×0.0325m ÷ (28×8.970588) × 100Hz`와 일치한다. 제어 호출 50Hz와 엔코더 표본율을 구별한다. 실물 표본율·정지 거리·센서 오차 검증은 아니다.

더 짧게 멈추고 접촉을 피했지만 같은 5.9초 동안 진행이 약0.520m 줄었다. 이 장면 하나로 모든 옆차·코너·실차나 다른 교통에서의 속도 손실까지 결론내리지 않는다. 다음은 저장 입력에서 실제로 선택이 달라졌던 우회 중 앞차 재출발·합류의 대표 장면을 확인한다.
