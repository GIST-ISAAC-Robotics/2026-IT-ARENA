# 좁은 정지 옆차 출발: 연결·후방 분류·경로 선택

**기본OFF 선택형 후보**다. 실제 관측된 옆차와85mm 간격은 있으나 시차 팽창으로 현재 위치부터 겹치는 경우, 고정55mm 여유와 현재/직전 조향의 비접근 이동을 확인해 최대0.4m의 저속 창을 허용한다. 다른 점의 시차 팽창·완전 관측·두 fresh 확인·독립 보호·STOP는 유지했다. [가정/범위](PLAN.md)와 [후방 분류 수정](PLAN2.md)을 따른다.

| 실제 시험 | 결과 | 한계 |
|---|---|---|
| run1 / r1 | 신호후0.685초에0.1m/s 도달했으나 **0.060m에서 재정지**. 접촉/겹침/노면이탈0·최소84.98mm·STOP/종료 확인 | 진행 목표 실패. 실제 반환이뒤쪽으로 넘어가면 abs(x) 분류가 제외한 것이 원인 |

두 실행 모두 run_valid=true였다. 원시 평가기는 옛 slow_lead 진행·150mm·앞차 뒤 조건 때문에 exit1이며 그대로 보존했다. 별도 사전 출발 목표 분석은 run1 exit1, run2 exit0이다. run2 소스175파일 불변·신호입력·독립 보호 연결과 실제 후보82회 적용을 확인했다. 모든 시험 프로세스는 종료했다.

## 실제 실패에서 바꾼 부분

- 최초 후보는 측방점 x를 앞뒤 똑같이125mm로 제한했다. run1 첫 거절은x=-127.63mm, 마지막8점도 모두뒤쪽이었다([좌표](run1_side_points.json)). 뒤로 넘어간 점도 비접근/고정 여유 검사를 그대로 받게 하고 앞 모서리 제한만 유지했다. 점을 삭제하거나 뒤 공간을 자유로 채우지 않았다.
- run2의 남은0.5초정지2회는 물체가 정지한 듯하다는 근거로 선택기가SOLO로 바뀌면서, 진행 가능한 평행 후보 대신 막힌 중앙 경로0명령을 선택한 결과였다([전이](run2_continuity.json)). r3는 **명시 출발 옵션·확인완료 양수 평행 후보·중앙0**인 경우만 평행출력을 유지한다. 새 관측 기억·물체 분류를 추가하지 않는다. 정상 중앙출력·입력거절·기존 음수 처리·기존 보호는 유지한다.

## 검사와 저장 입력

초기 관련309검사 중2개는 실제로 접근하지 않는 차체중앙 점을 접근 반례로 둬 실패했다. 원본을 보존하고 실제 접근하는 앞옆 점으로 수정한11개 재검사는 통과했다. 빌드2패키지 완료. 후방수정 관련116개, 선택수정 관련182개는 각각 통과했다. 숫자를 합쳐 전체 독립 검사 개수로 표시하지 않는다.

실제r1 연결은 초기 실패 입력284판단의0명령 표본2.08→0.78초, 단독1,849판단OFF보존, 비사각형1,100/합류1,222판단ON명령변화0이었다. r2는 run1 저장입력의215개0명령을 해제했고 다른 두 교통 입력의 변화0이었다. r3는 run2 저장입력273판단 중50개0명령을 해제해0명령 표본1.18→0.18초, 다른 두 입력변화0이었다. 이 수치는 **원래 입력/궤적의 대체 판단**이며 새 실제 주행 결과가 아니다.

[replay.json](replay.json)·[rear_replay.json](rear_replay.json)·[selector_replay.json](selector_replay.json), 원시 실패로그와 `.exit`, 실제[run1 목표](run1_goal.json)·[run2 목표](run2_goal.json)·[run2 표면](run2_surface.json)을 구분한다. 과거 합류의새 `entry_path_conflict` 무거절 진단42건과 표면정합 벽시계 비용은 명시적으로 구별했다. 그밖의 기존 제어/상태 차이는 허용하지 않았다.

r3의 실제 후속인 [오른쪽 재접근v2](../right_reapproach_v2/README.md)는 출발과 사각 뒤 재등장이 성립했으나 중앙 복귀 후 측면 접촉으로 실패했다. 좁은 출발 개선과 재접근 대응 완료를 구분한다. 기본 활성화는 하지 않았고, 미래 측방 접근·후방 사각과 실물 제동/센서 오차의 한계는 남는다. 이전 소스와 r1/r2/r3 계약은 before ZIP·runtime ZIP과 `config/tests/side_departure*_sha256.json`에 보존했다.
