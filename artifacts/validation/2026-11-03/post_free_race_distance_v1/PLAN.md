# 기둥 없는 월드·현재 교통 후보의 경기 거리

오른쪽 사각 재접근에서 새 후보가 측면 접촉을 피했고, 우회 중 상대 재출발/합류의 기능도 유지됐다. 한 장면에서 속도를 낮춘 대가가 300초 경기에서 정체·거리 손실을 만드는지 확인한다. **새 대표 경기 거리 1회**이며 성공까지 반복하지 않는다.

11/2 `official_race_distance_v2`의 등록 SHA256과 일치하는 `course.json`·`actor_overlay.json`·`trial_plan.json`을 사용한다. 앞차와 오른쪽 옆차의 각본, 진행 5랩·10초 미만 정체·접촉/겹침/벽0·양수 간격 하한·최대 두 바퀴 잔디·명시 STOP·입력/정상 종료 판정은 그대로다. 장면용 80mm와 기존 150mm를 전체 경기의 새 임계값으로 섞지 않는다. 원시 HOLD/간격/뒤 유지 결과도 보존한다.

달라진 것은 기둥 제거 월드, 그동안의 제어기 수정, 명시 `--side-departure-trial --current-lane-preference-trial`이다. 기존 기둥 포함 293.576초와의 차이는 단일 옵션의 인과 효과가 아니다. 실제 옵션/엔코더 설정과 계산된 평행 후보·최종 FOLLOW에 반영된 경우를 구분해 기록한다. 상대는 고정 각본 2대이며 독립 다섯 대 경기/실차 시험이 아니다.

이전 같은 길이 시험은 실제 약58분 걸렸다. 실행 담당만 감시한다. 사용자가 정리를 요청하거나 외부 실패가 생기면 새 실행을 시작하지 않고 당시 진행·STOP/프로세스 상태를 보존한다. 이번에는 녹화를 추가하지 않는다.
