# 현재 차선 선호와 우회 중 재출발·합류

같은 정지 옆차가 뒤에서 다시 접근한 대표 직선은 통과했다. 저장 입력 중 제어 변경이 있던 다른 장면인 `restart_during_bypass`를 현재 기둥 없는 월드, 새 명시 옵션 ON으로 1회 실행한다. 11/2 r1과 각본·속도·기본 목표는 같으나 기둥 제거와 후속 코드가 함께 있으므로 당시 기록과의 시간 차이 전부를 차선 선호 효과로 보지 않는다.

기존 23.5초 각본, 선행차의 3.0–7.5초 정지·0.825m/s 재출발, 1.5m/s 교통 상한과 원래 평가기를 유지한다. 앞차 재출발 시 아직 지나치지 않았고 실제 BYPASS가 진행 중이어야 한다. 본선 복귀·첫 U자 출구·마지막 FOLLOW·최장 정체 2.5초 이내, 최소 표본/스윕 간격80mm·접촉/겹침/벽0·최대두바퀴잔디·명시STOP·정상종료를 확인한다. 원시 옛 HOLD/도로/간격 판정도 보존한다.

추가로 새 옵션/설정값과 적용 횟수, 진행/속도 회복을 확인한다. 후보가 실제 호출되지 않았다면 해당 주행에서의 공존만 확인한 것으로 기록한다. 새로운 독립 상대나 모든 합류의 보장이 아니다. 조건 변경 없는 재실행은 하지 않는다.
