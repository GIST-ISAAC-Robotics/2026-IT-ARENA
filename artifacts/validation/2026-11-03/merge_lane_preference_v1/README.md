# 우회 중 앞차 재출발: 본선 복귀 유지

현재 기둥 없는 월드에서 `restart_during_bypass` 23.5초를 1회 실행했다. 좁은 출발과 현재 차선 선호 옵션은 ON이었다. [등록 목표](PLAN.md)·[결과](review.json)·[노면](run1_surface.json)을 구분한다.

- 상대는 출발 후 7.519초에 다시 움직였고 자차는 아직 앞서지 않은 BYPASS 상태였다. 상대 재출발 뒤 약 3.0초에 우회를 끝냈고 첫 U자 출구를 지나 최종 FOLLOW로 복귀했다.
- 진행 **15.902 m**, 최고 차체 속도 **1.569 m/s**, 최장 정체 1.010초, 최소 표본 간격 150.764mm·연속 보수 하한 150.345mm였다. 접촉·겹침·벽 바퀴 표본 0, 노면 15,981개 표본에서 최대 두 바퀴 이탈이다.
- 등록한 합류 목표와 옵션/소스170개 대조, 명시 STOP·정상 종료는 통과했다. 원시 `hold`와 `inside_road`는 실패(exit1)이며 도로 밖 차체 표본 2,290개를 지우지 않았다. 노면 분석 exit0, 별도 목표/검토 exit0이다.
- **현재 차선 선호 실제 적용은 0회**였다. 이 주행은 옵션을 켜 둔 상태에서도 우회·복귀·속도 회복이 이어진다는 증거다. 새 선호가 합류를 개선했다거나 활성 중 손실이 없다는 증거는 아니다. 옛 입력에서 16판단이 달라진 결과와도 구별한다. 계산된 속도 여유는 이번 100Hz 엔코더 설정의 0.08130m/s였다.

이전 11/2 실행과 각본은 같지만 월드·후속 소스도 달라 성능 차이를 한 정책에 돌리지 않는다. 실제 정책이 적용된 장면은 [오른쪽 후방 재접근](../right_reapproach_v3/README.md)이다. 다음은 [300초 경기 거리](../post_free_race_distance_v1/PLAN.md)에서 진행 손실과 정체를 확인한다.
