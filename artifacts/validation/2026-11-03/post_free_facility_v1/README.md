# 기둥 없는 팀 시험본 — 선두 출발·본선 진행

사용자가 실제 트랙 안에는 기둥이 없다고 확인했다. 공식 ZIP은 보존하고 팀 생성 프로필에 `remove_track_post: true`를 명시해 `tl_post` 링크의 시각·충돌을 함께 제거했다. 신호 패널·가로대·광원·마커·도로·물성·차량 제어기는 바꾸지 않았다. [계획](PLAN.md), [변경 전 23파일](before.zip), [기하 대조](geometry_audit.json), [소스 계약](../../../../config/tests/post_free_facility_r1_sha256.json).

정규화 SDF 대조에서 제거 링크는 `tl_post` 하나, 추가 링크0, 다른 변경 링크0이었다. 공식 원본 ZIP 해시 검증과 파생 월드 기록도 통과했다.

첫 관련 검사는 105통과·2실패였다([원본](tests.log)). 두 실패는 이전 기둥 존재와 충돌 개수3710을 고정한 기대값이었다. [검사 수정 전](test_expectations_before.zip)을 보존하고 명시적 기둥 부재 및3709로 바꿨다. 다른 형상의 보존 검사는 유지했다. 두 번째는 **107통과·exit0**([로그](tests_attempt2.log), [종료 코드](tests_attempt2.exit)), `arena_gazebo`/`arena_bringup` 빌드도 **exit0**([로그](colcon.log), [종료 코드](colcon.exit))다.

선두index2·B0183상향20°·기존1.5m/s 후보로 **한 번** 실행했다. 이전 기둥 대응 제어 소스는 그대로다. RGB 최초 출발은 sim12.24초, 본선 기준38.0141m 도달은 sim50.16초였다. ID0·20·30·45를 모두 관측했고 지름길 표본은0이었다. 차체 최고1.551m/s는 이 저속 확인 구성의 결과이며 고속 구성의 성능과 비교하지 않는다. [등록](run1_registered.json), [소스 확인](run1_source_audit.json), [사후 평가](run1_analysis.json).

실제 브라우저에서 출발 준비와 STOP을 눌렀다. STOP은 정책 수락과 가상 MCU `ESTOP_LATCHED`를 확인했으며 자동 평가 STOP이 먼저 들어가지 않았다. 다만 버튼 시점에 짧은 `same_scan_missing_wait`의0명령도 겹쳤으므로 **버튼만으로 제동한 독립 시험은 아니다**. [출발 준비 화면](browser_prepared.png)·[주행 화면](browser_driving.png)·[STOP 화면](browser_stop.png).

원본 실행 exit0, 원본 사후 분석 exit1이다. 실패 두 가지를 숨기지 않는다.

- `stopped`: 실행기가 처음 속도1cm/s 미만을 관측한 시점의 **직전**0.2초에는 제동 꼬리(최고0.02222m/s)가 남았다. [보충 분석](run1_supplement.json)은 **동일한1cm/s·연속0.2초** 기준으로 sim53.349–53.549초에 처음 정지를 확인했고 이후55.113초까지 유지됐다. 최초 STOP 래치 로그53.04초부터 연속 정지 확인까지0.509초다. 기존 판정선과 원본 실패는 바꾸지 않았다.
- `sample_coverage`: 운영 로그가 약0.20–0.22초 간격이라 평가기의0.2초 조향 나이 검사에서1,344자세가 걸렸다. 차체 자세의 큰 기록 공백은 없었다. 조향을 보간하거나 누락을 정상으로 바꾸지 않고, **모든 조향각의 접지면을 포함하는 사각 외곽**으로20,338자세를 보충 평가했다. 가능한 도로 밖 바퀴·벽 겹침 표본은0이다. 이는 기존 임시 바퀴 접지 기하의 보수 평가이며 실제 관절각·접촉력·실물 안전 증명이 아니다.

서버 정상 종료·잔여 시험 PID0·시험 소스 불변을 확인했다. 이 결과는 **상향20° 후보의 선두 한 칸에서 본선38m 진행**이며 전체 랩·다른 선두 칸·높은 앞차 가림·실물 장착 검증은 아니다. 기록 보충 때문에 시뮬레이션을 다시 돌리지 않았다. 기둥 대응 변경의 주행 손실은 [별도 대조](../post_change_audit_v1/README.md)에 정리했다.
