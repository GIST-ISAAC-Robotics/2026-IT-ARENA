# 정지 옆차 통과 후 차선 유지

[오른쪽 재접근 v2](../right_reapproach_v2/README.md)는 전체 후방 사각 뒤 재접근이 실제 성립했으나 접촉했다. 세계에 정지한 듯한 측방 반환을 분류하면서 위협 이력을 지워 중앙 복귀한 점을 먼저 분리한다. 현재 직선의 진행 가능한 차선을 유지하는 후보이며 후방 차량 부재를 증명하는 기능이 아니다.

## 기존 옵션 비교

같은 실패 입력 344판단에서 원본 r3는 모두 재현됐다. 다음 숫자는 **고정된 입력/원래 궤적에서의 대체 판단**이며, 새 경로의 주행 성적이 아니다.

| 구성 | 명령/상태 변경 | 새 0명령 | 0명령 표본 시간 |
|---|---:|---:|---:|
| 원본 | 0 | 0 | 0.98초 |
| 정적 측방 해제 OFF | 60 | 45 | 1.86초 |
| 기존 `observed_fresh_v2` 차선 유지 | 112 | 65 | 2.08초 |
| 두 변경 결합 | 177 | 110 | 2.98초 |

기존 fresh 평행 후보에는 이번 좁은 출발 처리가 들어 있지 않아 초기 출발부터 막혔다. 정적 분류를 끄는 비교는 중앙 조향이 시작된 이후 원래 입력의 이전 조향/운동을 계속 받으므로, 그 뒤의 정지 증가를 새 궤적에서 그대로 발생할 결과로 단정하지 않는다. 단순 옵션 전환을 채택하지 않았다. `comparison.json`과 각 정책별 판단 기록을 보존했다.

## 새 후보와 범위

`candidate.py`에서 정적 측방 반환을 본 방향만 별도로 기억한다. 현재 완전 관측 직선에서 기존 평행 후보가 검사·확인을 마치고 진행 가능하면, 그쪽으로 불필요하게 중앙 복귀하는 대신 평행 출력을 택한다. 중앙 경로가 출발 확인을 기다리는 중에도 이미 확인한 평행 양수 출력은 이어갈 수 있다.

반대쪽 현재 점유·코너·경로/벽 맥락 상실이면 기존 판단으로 돌아가며 새 STOP를 만들지 않는다. 빠른 평행 출력은 기존 목표 상한 안에서 현재 점유·제동·이동 영역을 다시 검사한다. 옛 후보의 15:1 고정 엔코더 값을 재사용하지 않고 시제품 재생에서는 현재 28카운트·8.970588:1·65mm와 20ms 표본 가정으로 약0.04065m/s를 썼다. 실제 v3 실행은 차량 설정의 엔코더 100Hz(10ms)를 읽어 약0.08130m/s를 썼고 50Hz 제어 호출과 구분했다. 둘 다 실물 표본율 확정값이 아니다.

실패 입력의 첫 중앙 조향에서 1판단을 0.35m/s 평행 진행으로 바꿨고 새 정지는 없었다. 원래 궤적은 그 직후 이미 중앙으로 회전했으므로 이후 판단을 새 후보의 실제 궤적으로 해석하지 않는다. 비사각형 1,100판단은 명령 변화0, 합류 1,222판단은16회 차선 유지/감속·새0명령0이었다. 합류 첫 변경은1.5→0.95935m/s이며 약0.32초 표본에 해당한다. 합류의 역사 진단 추가42건은 기존과 같이 비거부 `entry_path_conflict`였고 실제 명령 차이와 구분했다.

정책 반례15개는 통과했다. 첫 검사는 시험 fixture에 필수 v4/corner-distance/per-ray 설정이 없어15개 모두 구성 단계에서 실패했으며, 원본 fixture ZIP과 로그를 보존하고 해당 설정을 추가했다. 시험 통과를 센서 인식/실차 증명으로 확대하지 않는다.

## 연결 상태

`current_lane_preference_trial` 기본값은 false다. 명시 좁은 출발·정적 측방 분류·기존 경로 복구와 함께만 선택할 수 있다. 실행 launch에서 실제 설정의 엔코더 분해능/표본율로 속도 여유를 전달하고 판단 header에서 옵션과 값을 확인한다. 이전 소스 `runtime_before.zip`, 현재 격리 소스 `runtime_source.zip`/`runtime_sources.json`, 후속 계약 `config/tests/current_lane_preference_r1_sha256.json`을 보존했다.

관련223회귀와 ROS 2패키지 빌드, 연결 코드 격리 재생의 원본344판단 일치/시제품과 같은 첫 변경을 확인했다. [동일 각본 v3 실제 결과](../right_reapproach_v3/README.md)는 최소84.97mm·접촉0으로 별도 목표를 통과했고 원시 옛 간격/뒤 유지 실패는 보존했다. 최고속도·진행 손실과 일반 교통에서의 영향은 별도로 판단한다. 기본 채택/전체 경기/실차 검증은 아니다.
