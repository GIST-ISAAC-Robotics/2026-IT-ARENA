# 후방 재접근 전 차선 유지의 저장 입력 비교

`right_reapproach_v2`의 측면 접촉을 분석한다. 새 보호 기준이나 제한 완화에 앞서 이미 구현한 선택형 정책이 정지 옆차 통과 이력을 어떻게 다루는지 확인한다.

현재 r3 격리 소스와 같은 센서 입력에서 원본 일치를 확인한 뒤, 정적 측방 해제 OFF, 기존 후방 차선 유지 ON, 두 옵션의 결합을 비교한다. 오래된 후보의 15:1 엔코더 여유 값 등은 그대로 운영 채택하지 않는다. 비교 결과는 입력 고정 판단이며 바뀐 궤적/충돌 해소의 증거가 아니다.

첫 비교는 대표 실패 입력 1개이며 명령·상태·정지 증가·복귀 조향·선택 이유를 회수한다. 기존 후보가 적용되지 않거나 진행을 과하게 막으면 그 이유를 남긴 뒤 최소한의 수정 후보를 설계한다. 지도·상대 정답·미관측 자유 공간은 제어기에 넣지 않는다. 새 Gazebo 시험은 이 비교 결과를 검토한 뒤에만 계획한다.
