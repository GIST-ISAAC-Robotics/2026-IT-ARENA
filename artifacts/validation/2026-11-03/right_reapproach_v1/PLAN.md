# 오른쪽 후방 사각 뒤 재접근: 실제 장면 성립 확인

11/3 실행 전 등록. 기존 10/30 오른쪽 시험은 상대가 먼저 앞으로 나가 사각→재접근을 시험하지 못했다. 이번은 같은 실행을 반복하지 않고, **왼쪽 후열grid0의 자차와 오른쪽 도로 안 정지차**로 시작하는 별도 각본이다.

- 자차: 현재 선정 교통1.5m/s·paced/관측 이동/후방 sweep 후보, 기둥 없는 공식 파생 월드·실제 RGB 출발. 제어기·센서·구동·보호 수치는 바꾸지 않는다. 후열grid0은 시험 출발 위치이며 실제 센서 위치 변경이 아니다.
- 상대: 중심선 오른쪽14.5cm, 자차와 같은 종방향 위치에서0–1.6초 정지. 1.6–1.8초0.8m/s, 1.8–2.0초1.6m/s, 2.0–4.3초2.4m/s로 다시 따라온다. 시험창4.3초. 실제 차량 가감속 모델이 아닌50Hz 자세 명령 각본이며 사전 도로/벽 검사를 통과해야 한다.
- 초기 두 차체는 같은 도로 안에 있고 표준20×15cm 외형을 사용한다. 좁은 측방간격은 숨기지 않는다. 별도 평가의8cm 간격은 이전 경기 목표 대조값이며 실차 안전거리 보장이 아니다. 기존 원본15cm/앞차 뒤 추종 판정은 그대로 남긴다.
- 장면 성립: 광선별 시각·평가 자세로 상대 외형 반환을 대조한다. 고유 스캔2개 이상에서 각각3점 이상 관측→스캔 처음/끝 모두 상대 전체가 후방60° 마스크 안에 든 스캔1개 이상→이후 고유 스캔2개 이상에서 각각3점 이상 재관측의 순서가 필요하다. 외형 대응20mm는 렌더/자세 보간 구분 여유이며 제어기 인식 임계값이 아니다. 실제 반환과 사각 기하를 구별한다.
- 주행: 2.5m 이상 진행, 최초 이동 뒤0.05m/s 미만 최장2.5초 이하, 접촉/겹침/바퀴-벽0, 세 접지 해석 모두 잔디 최대2바퀴, 명시STOP·정상 종료·입력/소스/각본 유효성 확인. 기존 원본 판정은 별도 보존한다.
- 한 번 실행한다. 장면 미성립이나 동작 실패를 성공으로 바꾸기 위해 시간/간격을 사후 조정하지 않는다. 결과에 따라 원인을 조사하고 후속 작업을 정한다. 지도·상대 정답은 평가만 사용한다.

이번 묶음에서는3인칭 영상을 새로 촬영하지 않는다. 다음 녹화 구도 요청은 현행 계획에 보존했다.
