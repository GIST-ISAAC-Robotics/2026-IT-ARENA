# 기둥 대응 변경의 속도·계산 영향 점검

사용자는 기둥 대응을 추가하면서 불필요하게 느려진 부분도 확인하도록 요청했다. 이번 대조는 11/2 관련 변경 네 가지로 한정한다. 원시 실패·새 옵션·현재 소스를 보존하고 실제 파일을 되돌리지 않는다. [계획](PLAN.md), [격리 비교 도구](compare.py), [두 소스 복사본](source_snapshots.zip), [해시](snapshot_manifest.json).

| 변경 | 코드상 작용 범위 | 속도 손실 가능성에 대한 사전 판단 |
|---|---|---|
| 반대 벽으로 확인한 현재 경로의 단독 고속 허가 | `solo_route_only`이며 현재 스캔·전방 반환이 확인된 경로 | 1 m/s 제한을 넓히는 수정. 감속 조건 추가는 아님. 기존 35.606→34.451초의 제한 실제 주행 기록이 있음 |
| 현재 반환과 깊게 겹친 우회 경로의 진입 제외 | 명시 `entry_motion_gate`, 우회 준비/진입 후보만. 겹침은 기존 측정여유30mm보다 깊은 경우 | 경로 선택을 미루고 계산을 늘릴 수 있음. 진행 중 우회에 새 STOP을 붙인 것은 아님. 기둥뿐 아니라 실제 벽/다른 차와 겹친 경로에도 적용되므로 대표 교통 대조 필요 |
| 정지 중 현재 경로 조향 유지 | 명시 `standing_wall_reacquire`·현재 경로·측정속력≤0.1m/s | 이미 속도0인 상태에서 조향을 남기는 수정. 순항 상한을 낮추지 않음. 새 출발 결과에서 실제 필요성과 사용 여부 확인 |
| 막힌 평행 후보 대신 관측 경로 GUARD 검사 호출 | 명시 재획득·현재 경로·저속 시작 또는 같은 GUARD 지속 | 이전에0을 유지하던 분기에서 기존 검사 후 진행을 허용. 호출될 때 계산은 늘 수 있음. 신규 감속 상한/정지 판정선은 추가하지 않음 |

이 표는 코드 검토이며 실제 주행 손익의 확정이 아니다. 현재/수정 전 비교 복사본은 일반 교통 기능·물성·하드웨어 값을 유지하고 이 네 변경만 제외했다. 같은 저장 입력의 최초 제어 차이 이후를 실제 대안 주행으로 주장하지 않는다. 시간 측정은 Gazebo 종료 뒤 교차 순서의 로컬 판단 함수 비용만 비교하며 센서 입력·ROS 전체/Jetson 지연과 구분한다.

## 결과

[실행 로그](compare.log)·[실제 종료 코드0](compare.exit). 전후 소스는 별도 복사본에서 import했고 실제 주행 소스를 되돌리지 않았다. 제어 출력이 처음 달라진 뒤의 입력은 대안 주행으로 해석하지 않는다.

| 저장 입력 | 현재/변경 전 출력 비교 | 현재 중앙/p95 ms | 변경 전 중앙/p95 ms |
|---|---|---|---|
| 정상 정지차 우회 | 1,059판단 속도·조향·모드 동일 | 11.79/29.07, 12.24/27.34 | 11.31/27.34, 10.79/27.15 |
| 우회 중 상대 재출발·합류 | 1,222판단 동일 | 10.92/26.32, 10.73/25.33 | 10.50/25.88, 11.32/26.10 |
| 기둥 없는 선두 출발 | 2,040판단 동일 | 7.50/10.41 | 7.38/9.83 |
| 선정 단독 고속 | 현재1,860판단 재현. 변경 전은80번째(sim9.82초)에서2.562→1.0m/s로 처음 차이 | 호출 범위가 달라 비용 직접 비교하지 않음 | 같은 이유로 제외 |

우회 진입의 반환 겹침 검사는 정상 우회45회, 재합류42회 호출됐다. 전체 판단 시간의 **0.205–0.233%**, 호출 최대1.22–1.77ms였다. 총 중앙값의 작은 증감을 모두 이 함수의 영향으로 단정할 수는 없다. Gazebo 종료 뒤 제한 교차 순서의 PC 재생 비용이며 ROS 전체 마감이나 Jetson 측정은 아니다.

**결론:** 비교한 교통·기둥 없는 출발 입력에는 감속/정지 증가가 없었고, 단독 변경은 고속 허가를 늘리는 방향이었다. 기둥 문제에서 추가한 네 변경이 주행을 전반적으로 느리게 만들었다는 근거는 이 범위에서 발견하지 못했다. 실제 벽/다른 차와 겹치는 우회 진입을 제외하는 일반 기능은 유지한다. 기둥 전용 추가 개발은 중단한다. 정지 조향·GUARD 재획득은 명시 후보에 남기되, 기둥 없는 출발에서 필요했던 기능이라고 주장하지 않는다(전후 출력이 같았다). 기둥 없는 실제 출발 주행은 [별도 묶음](../post_free_facility_v1/README.md)에 있다.
