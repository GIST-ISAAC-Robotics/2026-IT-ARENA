# 오른쪽 후방 사각 뒤 재접근 v2

기존v1의 재접근 미성립/평가상대55.5mm 지연 실패를 보존한다. 좁은 출발 후보r2는1.080m 진행했으나 중앙 복귀 선택에서0.5초정지2회가 남았다. r3는 이미 검사한 평행 양수 경로를 유지하는 선택만 보완하며 저장입력/반례로 먼저 확인한다.

이번에는 후열grid0·같은 초기 오른쪽 상대 위치(몸체간 약85mm)·현재교통1.5m/s·순차10HzC1·독립보호/STOP를 유지한다. 상대는3.2초정지,0.2초0.8m/s,0.2초1.6m/s,이후2.4m/s로5.9초까지 전진한다. 총진행6.00m로 첫커브 전에 끝나는지 도로 사전검사한다. 충분한 초기 정지는 출발병목을 해결한 다음 뒤 사각을 실제로 만들기 위한 새 장면이며 이전v1의 성공으로 소급하지 않는다.

평가 상대 명령은50→100Hz로만 변경한다. v1의 실제 명령나이 최대23ms×2.4m/s=55.2mm였으므로 갱신 주기를 줄여 근사 오차를 줄인다. 기존35mm 이동추종오차 기준은 유지한다. 상대는 정적모델 위치갱신 방식이며 독립차량 물리/충돌반응의 검증이 아니다.

## 사전 목표와 실행 상한

- 초기 실제반환≥3점인 서로다른2스캔 → 상대 전체 외곽이후방60°마스크 안인1스캔 이상(취득구간5시점확인,표적반환0) → 뒤에서0.2m이상 접근한 우측 표적의 실제반환≥3점인2스캔. 빈 구간을 관측으로 채우지 않는다.
- 진행≥2.5m, 움직인 뒤 연속저속정체≤2.5초, 최소 표본/연속하한 몸체간격≥80mm, 접촉/겹침0, 최대두바퀴잔디·벽0, 실제RGB출발·입력/출처·명시STOP·정상종료.
- 원본150mm/앞차뒤/HOLD등 평가와 이 목표를 구분한다. 실패하면 원인을 회수하며 통과할 때까지 조건을 바꾸어 반복하지 않는다. 이번 준비/시험1회가 범위이며 경기 전체/실차 보장은 아니다.

첫6.2초안은 실행 전 기존 직선 종료 여유1m를 만족하지 못해 준비 단계에서 거절됐다(end51.566m, 코너51.933m). 원본설정/계획은 preflight_6p2_rejected.zip과 prepare.log/.exit에 보존했다. 직선여유는 유지하고 상대 마지막2.4m/s구간을2.3초로 줄인5.9초안을 등록한다. 실제 Gazebo 실행 전의 시나리오 조정이다.
