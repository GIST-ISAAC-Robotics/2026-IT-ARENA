# 밀집 출발: 신호가 화면에 들어오는 것과 불빛이 보이는 것은 다르다

**현행 월드의 세로 기둥은 없다.** [현행 출발 사진(그리드 3)](../solo_post_free_v1/run1/signal_green.png)과 [시설 변경 대조](../post_free_facility_v1/README.md)를 기준으로 본다. 아래 *이미지 합성*에만 11/2의 기둥 포함 고정 카메라 사진(그리드 0)을 재사용했다. 두 사진은 같은 그리드의 전후 대조가 아니다. 신호판·광원·좌우 마커 기하는 두 월드에서 같다.

## 카메라 시야와 앞차 가림

[현행 월드 기하](geometry.json)에서 앞쪽 다섯 칸을 채웠다. 앞에서부터 그리드 2·5·1·4·0이다. 상대를 지면에서부터 빈틈없이 찬 20×15 cm 직육면체, 카메라 중심을 공칭 14.5 cm로 둔 정지 배치다. 상향 20°면 다섯 칸 모두 10개 광원이 화면 안에 들어온다. 수평이면 앞의 두 칸에서는 광원 전체가 보이는 개수가 0이다.

| 우리 그리드 | 앞의 차체가 빨강 8개를 모두 가리기에 충분한 높이 | 초록 2개도 모두 가리기에 충분한 높이 |
|---|---:|---:|
| 2·5 | 이 배치에서 광원 중심과 앞차 수평 외형이 겹치지 않음 | 같음 |
| 1 | 26.2 cm | 26.2 cm |
| 4 | 24.0 cm | 24.0 cm |
| 0 | 21.9 cm | 21.9 cm |

높이는 광원을 둘러싼 작은 상자의 모서리까지 가리는 [충분조건](audit.py)을 mm 단위로 올림했다. 차체가 실제로 이 높이의 막힌 판이라는 뜻은 아니다. 카메라 중심이 그대로면 피치를 올려도 앞차 너머로 보는 시선은 바뀌지 않는다.

## 빨간불이 가려졌다가 초록만 드러날 때

[저장 이미지 합성](image_sequence.py)에서 그리드 0 바로 앞 차를 높이 22.5 cm로 두고 신호 전후 이미지를 비교했다. 빨간불에 해당하는 547픽셀과 초록불 138픽셀이 모두 가려졌다. 앞차를 16 cm 앞으로 옮기자 초록 138픽셀과 ID 0·45가 모두 보였다. [같은 인식기에 넣은 결과](sequence.json)는 다음과 같다.

- 가림 없는 빨강→초록: 출발 허가.
- 빨강을 전혀 못 본 뒤 초록이 드러남: **대기 유지**. 앞차가 움직여 소등된 판만 드러난 경우도 출발하지 않았다.
- 이 비교는 고정 렌더 프레임에 가림을 합성한 것이다. 서로 다른 시각을 부여한 반복 이미지이므로 실제 차량 동작이나 카메라 처리율 시험이 아니다.

현재 인식기는 빨간 네 열을 두 프레임 확인한 뒤 마지막 빨강에서 0.8초 이내에 초록 세 프레임을 확인한다. 이 관측 이력은 **팀 정책**이다. [공식 ZIP](../../../../assets/track/official/v2026.11.01/README.md)의 `output_final/traffic_light.py`는 빨강 네 세트 뒤에만 초록을 약 5초 켠다. 팀의 [시뮬 점등](../../../../src/arena_gazebo/scripts/traffic_light_controller.py)은 오출발 검사를 위해 순서 앞에 초록 시험 점등을 따로 두고 마지막 초록은 계속 유지한다. 따라서 다음 늦은 출발 검증에는 공식 5초 소등 경계도 필요하다. 저장한 그리드 0의 시험 초록과 실제 출발 초록 PNG는 **파일 해시까지 동일**하다(`c415a71a…6734132`). 두 마커로 위치를 잡더라도 한 장의 색만으로 두 시점을 구분할 수는 없다.

## 신호 인식을 다시 다룰 때

ID 45(왼쪽)·0(오른쪽)은 선택적으로 탐색 영역을 좁히는 단서로 쓸 수 있다. 현재 [영상 처리](../../../../src/arena_autonomy/arena_autonomy/vision_process.py)는 두 ID를 별도로 읽고, 신호 검출은 광원 배열로 영역을 정한다. 한쪽 마커가 가려졌다고 기존 출발 경로까지 막지 않는다. 빨강 이력을 놓쳤을 때 사용할 **늦은 시각 출발**은 아직 구현하지 않았다. 공인된 경기 준비 시점·실제 점등 절차와 RGB 증거로 판단하고, 앞차 이동·마커만으로 허가하지 않는다.

대회 배경은 모델보다 복잡하다. 기존 배열·시간 검사와 판 밖의 빨간 차체 제외는 사람·복장·피부·휴대폰 불빛에 대한 검증이 아니다. 후속에는 **배경만 변하거나 사람이 지나가는데 신호는 소등인 장면**과 **같은 배경에서 올바른 순서로 실제 불이 켜지는 장면**을 한 쌍으로 본다. 판 앞의 일시 가림, 조명·자동 노출로 인한 밝기 변화는 점등과 구분한다. 피부색을 따로 분류하거나 색상 목록을 늘리기보다 판의 위치·광원 배열·시간 변화를 먼저 사용한다. 실물 설치·노출이 정해지면 대표 동영상으로 확인한다.
