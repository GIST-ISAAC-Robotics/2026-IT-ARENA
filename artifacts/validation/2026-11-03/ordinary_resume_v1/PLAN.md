# 제자리 STOP 뒤 START 조작 정리

일반 정지는 별도 RESET 버튼 없이 START 한 번으로 다시 준비한다. 같은 경기의 출발 사실·기준 벽은 유지하고, START가 원래 수행하던 새 입력 경계·경로 재확인·MCU 재ARM을 그대로 거친다. 재배치·고장 복구의 명시 RESET과 새 경기는 유지한다. RESET 버튼을 생략하는 것이 옛 센서/경로를 그대로 재사용한다는 뜻은 아니다.

변경은 B3 운영 후보의 명시 STOP 뒤 재개 자격과 화면 안내에 한정한다. 고장·물리 정지·최초 신호 없는 출발·새 STOP/연결 상실·늦은 입력 거절은 기존 처리로 확인한다. 기본 제어 모드나 순항/보호 조건은 바꾸지 않는다. 단위/노드 검사 뒤 자동 HTTP 명령을 사용하는 제한 실제 ROS/Gazebo 정지·재개 장면으로 연결을 확인하며 일반 시험에 브라우저를 강제하지 않는다.

현재 동작과 원본 소스는 `before.zip`·`before_sha256.json`에 보존했다. 사용자 요청은 전체 개발 계속이며 이 묶음만 끝내고 작업 종료하지 않는다.
