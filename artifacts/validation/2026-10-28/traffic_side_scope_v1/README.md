# 같은 경로에서 측방 결측 범위 일치

2026-10-28. [직전 주행](../traffic_positive_clearance_v1/README.md)은43.373 m에서27.43초 정체했다. `bounded_side_missing`은 허용됐지만 선택기의 `unknown_outside_side_scope`가1,395회 남았다. 종료 요청 뒤 브리지exit -11은 별도 실행 오류이며 원래 `run_valid=false`를 보존한다.

## 근거와 변경

[실제 방향 대조](../traffic_positive_clearance_v1/run1_scope_audit.json):130.82초에는 무반환 취득62.64–64.08°/현재60.34–61.80°로 통과했다.130.84초에는62.64°가 자차 회전으로59.43°가 되어 보조 선택기의60° 하한에 걸렸다. 정지 뒤131.5/135초에는 원시53.28/54°도 같은 이유로 막혔다. 기본 부분 관측 정책은 정면30° 밖의 이 좁은 공백을 기존 위협 검사로 허용했다.

같은 명령·같은 센서 증거의 선택형 후보에서만 현재 광선의 하한을 기본 정책의정면30°+광선 셀 반폭 밖으로 맞춘다.60°가 필요한 더 넓은 v4 측방 공백은 원래 proof에서 그대로 검사한다. 이 변경은 허용 범위를 실제로 넓히므로 단순 표기 수정으로 설명하지 않는다. 기존 승인된 좁은 측방 정책과의 일치를 근거로 한 개발 선택이며 기본 활성화나 실물 안전을 뜻하지 않는다.

동일 속도/목표·현재/이전 조향·시간·차체 외곽 증거와0.35 m/s 후보 상한, 정면/후방 결측 거절, 현재 실제 점유·연속 무반환 폭·양옆 유효 반환 검사를 유지한다. 다른 경로로 허가를 옮기거나 무반환을 측정 자유 공간으로 만들지 않는다. 가까운 장애물·넓은 결측·다른 조향·정면 경계 반례를 새 범위에서 검사한다.

각도 범위 관련54검사를 통과했다. 이전 주행의130.20–131.0초 저장 입력을 분기한41호출 대조에서 원래 입력은4개 양수 안전 명령(최대0.35 m/s)이 나왔고, 전방 점유·정면 결측·gyro 이력 단절·명시0명령에서는 모두 양수 안전 명령0이었다.
