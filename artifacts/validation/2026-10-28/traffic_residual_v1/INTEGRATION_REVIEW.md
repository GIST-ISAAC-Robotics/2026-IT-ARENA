# 결합 후보를 실행에 연결하기 전 확인할 범위

2026-10-28. 현재는 격리 재생 단계이며 아래는 구현·시험 설계다. 43.173 m 실패를 해결로 바꾸거나 후보를 기본 활성화하지 않는다.

## 세 변경의 역할

1. **점별 시각의 위협 영역:** 옛 반환 취득→결측 취득→현재의 시간을 나누어, 같은 가능한 위치가 결측 광선과 감속 차체 양쪽에 속하는지를 검사한다. 기존 2 m/s 이동 가정·3 cm 거리 여유를 유지한다. 속도 추정의 실물 오차나 미래 모든 cut-in을 보장하는 계산은 아니다.
2. **래치 근거의 재관측:** 전체 위협 근거가 보존된 경우에만 정합을 시도한다. 두 새 스캔에서 옛 점이 다시 대응하고, 현재 입력을 별도로 다시 검사한 뒤에만 회복한다. 실패한 정합·시간 만료는 해제가 아니다. 정적 배경 가정과 동행 물체 모호성을 명시한다.
3. **측방 통과 이력과 실제 이동 영역:** 이미 확인한 통과 이력을 유지하더라도 현재 점유/이동 영역 검사는 계속한다. 좁은 무반환 위험을 허용하는 범위는 같은 센서·현재 시각·같은 조향·검사한 속도 이하의 원래 경로로 한정한다. 다른 횡이동 경로에 승인을 복사하지 않는다.

각각만 바꾸면 저장된 목표 정체 구간에서 명령이 회복되지 않았고, 결합 사본에서 처음 회복됐다. 따라서 하나의 함수가 성공했다고 전체 실행에 연결하지 않는다.

## 다음 수용 조건

- 독립 보호 객체는 계획기와 기억·래치를 공유하지 않는다. 계획기의 reset도 보호층 reset으로 쓰지 않는다. 현재 준비된 비교는 실제 ROS 콜백 이력을 갖지 않으므로 함수 대조라는 한계를 유지한다.
- 보호층은 명령보다 큰 속도나 반대 방향 명령을 만들지 않고, 명령0·낡은 입력·프레임/시각 오류·운동 입력 부재·가까운 실제 점유에서 정지한다. 회복 후보가 해제되더라도 `swept_limit`/`braking_speed`를 그대로 거친다.
- 사라진 독립 물체를 벽으로 대체하는 반례, 움직이는 배경 모호성, 새 옆차 재접근·경로 소실·넓은 공백을 보존한다. 움직이는 배경을 완전히 구별할 수 있다고 주장하지 않는다.
- 실제 실행용 구현은 `inspect`/문자열 교체로 모듈을 만드는 진단 사본과 분리한다. 명시 선택형 설정, 기록 가능한 구성, 두 프로세스의 독립 상태, 기본 OFF 동일 재생을 갖춘다.
- 현재 격리 사본의 최대 비용 약105 ms는 50 Hz 합격이 아니다. 대상 구간 프로파일에서 병목을 찾고, 수치/정지 의미를 보존하는 수정만 적용한다. Gazebo 동시 실행과 프로파일 계측 중 수치를 Jetson 성능으로 확대하지 않는다.
- 연결 뒤 첫 교통 시험은 기존 각본·속도·물성·원래 판정을 유지한 별도 실행 한 번이다. 소스·명령·판정 기준을 먼저 보존한다. 실패하면 근거를 회수하며 성공할 때까지 같은 실행을 반복하지 않는다.

공식 출발/방지턱의 단독 통합 결과는 별도 축이다. 이것이 교통 정체의 독립 보호·폐루프 검증을 대체하지 않는다.
