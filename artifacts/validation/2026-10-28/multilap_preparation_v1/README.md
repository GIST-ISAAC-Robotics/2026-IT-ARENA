# 다랩 통합 시험 준비

2026-10-28. **실행 전 설계**이며 5랩 완료 기록이 아니다. 회전 오차 run4와 방지턱 교통의 유효한 결과를 확인한 뒤, 같은 후보를 장시간 연결하기 위한 범위다.

## 기존 시험과 달라지는 것

- 현행 코스 길이는 평가용 `scene.json` 기준46.6329 m다.5랩 순진행은233.1645 m이며 단순히 시작선을5번 넘는 것과 구별한다. 현재1랩 시험도 출발 위치 때문에 시작선을 먼저 지날 수 있다.
- 현재 `g1_course_eval.check_full_course`는1랩·앞차1–1.5랩 범위만 허용한다. 설정 파일의 `minimum_laps`만5로 바꾸면 안 된다. 명시 다랩 경로 검증과 연속 진행 누적을 함께 확인해야 한다.
- 앞차0.35 m/s·초기5초 정지 조건을 유지하면5랩에 필요한 각본 시간은 대략671초 이상이다. 시작 간격·최종 추종 간격을 고려한 종료 여유는 실행 등록 시 정한다. 예상 시간은 성공 기준이 아니며 자차 실제 순진행으로 판정한다.
- 공식4-red/green·고정 카메라·공개 방지턱·동일 제어 후보를 유지한다. 첫 장시간 통합에 새 센서 오차나 속도 증가를 동시에 추가하지 않는다. 각본 상대차의 반복 조우이며 독립 자율차5대 경기 검증은 아니다.

## 실행 전에 확인할 사항

1. 같은 입력의 평가를1랩 결과와 대조해 기존 판정을 유지한다.5랩 합성 자세열, 반대 방향·시작선 왕복·표본 도약·상대차 누락 반례로 단순 누적 오류를 검사한다.
2. 기존 전체 코스 경로를 반복할 때 앞차와 정지한 옆차의 실제 재조우가 평가에 남도록 한다. 상대차·벽 접촉, 바퀴 중심 이탈, 앞차 정지/재개, 정체 시간을 랩별로 분리한다. 지난 랩의 통과 기억이 다음 조우의 현재 관측을 대체하지 않는지 확인한다.
3. 기록 용량·실제 시간 제한·정상STOP 뒤 actor 수신 마감이 장시간 자료에도 맞는지 확인한다. 시간 한도 도달·기록 손실·비정상 종료는 미완료로 보존한다. 실제 시간이 오래 걸린다는 이유로 센서/물리 시간을 바꾸지 않는다.
4. 제어기의 종료 판단과 평가기의 종료 요청을 구분한다. 이번 목적은 동일 구성의 연속 주행 내구성이다. 평가용 지도/랩 수로 마지막에 STOP을 요청한 결과를 차량 자체의5랩 인식·경기 운영 완료로 쓰지 않는다.
5. 과거1랩의 간격·STOP·정상 종료·노면 기준을 유지하고, 변경이 필요하면 실행 전에 이유와 범위를 기록한다. 실패 후 결과에 맞춰 판정선을 바꾸지 않는다.
