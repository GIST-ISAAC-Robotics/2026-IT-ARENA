# 현재 관측 정책과 통과 선택기의 결합 후보

2026-10-28. 운영 코드 연결 전의 저장 입력 비교 계획이다.

1. 소실 검사의 이전 기준 시각을 점별 취득 시각으로 바꾼 격리 사본을 만든다. 옛 반환→현재 결측 취득→현재 판단을 분리하고, 이전의 독립적인 두 근접 조건 대신 같은 가능 위치를 검사한다. 모든 이전 점을 계산하며 기존 개략 필터에 걸린 네 점만 고르지 않는다. 입력 점 순서·변환 좌표·취득 시각이 맞지 않으면 비교를 중단한다. 원본, 소스 사본, 전체 변경 내역을 남긴다.
2. 과거 통과 확인을 이력으로 유지하되 현재 유효 경로가 없으면 출력을 허용하지 않는다. 경로 소실만으로 과거 이력을 삭제하는 것과 시각/세대 단절·실제 측방 위협의 재출현을 구분한다. 후자는 기존대로 통과 상태를 취소한다.
3. 이력을 유지하는 동안 작은 움직임도 현재 차체 이동 영역을 검사한다. 일반 미관측은 그대로 거절한다. 현재 G1에서 승인한 좁은 측방 무반환을 동일한 조향·더 작거나 같은 속도/범위에서 다시 만난 경우에만 별도 위험 후보로 연결한다. 관측되지 않은 띠를 자유 관측으로 표시하지 않는다. 같은 스캔·시각·경로/차체 범위를 실제로 대조하고, 평행 이동한 다른 경로로 승인을 복사하지 않는다.
4. 반례: 실제 가까운 반환, 넓은 결측, 다른 위치의 추가 결측, 가림 마스크 경계, 입력 시각/순서 불일치, 재접근, 유효 경로 소실, STOP 및 음수 모터 피드백. 원래 정지 조건이 필요한 사례에서는 양수 명령이 없어야 한다.
5. 먼저 저장 입력에서 원인과 명령 차이를 확인한다. 효과가 있어도 새 주행/안전 성공으로 쓰지 않는다. 새로운 운영 후보를 연결할 때에는 독립 보호층에도 같은 시각 계약을 적용하고 반례·회귀를 거친다. 기본 활성화·물성/간격 완화·정답 입력은 하지 않는다.

현재 기하의2 m/s 상대 이동·3 cm 반경과 감속 외곽은 기존 시험 가정이다. 미래에 새 물체가 들어오는 경우나 실제 센서 오차 전체를 보장하지 않는다. 목표는 서로 다른 검사 사이의 불일치를 줄이는 것이며, 원하는 주행 결과가 나올 때까지 숫자를 낮추는 것이 아니다.
