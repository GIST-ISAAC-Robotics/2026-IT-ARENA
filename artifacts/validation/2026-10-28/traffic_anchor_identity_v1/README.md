2026-10-28. [감속 재검사 실제 주행](../traffic_speed_contract_v1/README.md)은129.88초에 위협1점이 래치된 뒤43.193 m에서 정체했다. 이 폴더는 그 원인을 구분하는 **읽기 전용 저장 입력 진단**이다. 판정·제어기·보호층을 바꾸거나 새 주행을 실행한 결과가 아니다.

## 보정 없는 대조

원래129.72초 기준의 실제 반환점과 배경 전체를 모터축/gyro 이력으로만 현재로 운반했다. 위협 증거의 운반 좌표와1 nm 이내 일치를 확인해 해당 원래 점을 찾았다.129.88–130.92초의 서로 다른12개 스캔에서 기존 거리/짧은 연속 표면 조건을 모두 충족하지 못했다. 최근접 거리는26.99 mm에서353.61 mm로 늘었다. 따라서 정합을 생략하고 즉시 해제할 근거는 없다.

- [재현 코드](probe.py), [진단 결과](identity_comparison.json), 실행 `probe.log`/종료코드 보존.
- 원시 입력 SHA-256: `34b53cbaee109b7a85f56a057dcded0965ed4c4de595fb6de03dae9aedb236e9`, 실행 전후 불변. 발췌 원시 입력은 Git 제외·로컬 보존한다.
- 뒤쪽10개 표본의 정합 함수는 수락되지만, 실제 재관측 상태기는 그 이전에 이력 만료로 끝났다. 개별 함수 수락을 당시 상태기의 해제 성공으로 쓰지 않는다.

## 움직이는 표면과 옛 위치의 반환

[주변 반환 그림](local_correspondence.png)에서는 같은 위치의 벽과 별도로 짧은 면이 이동한다. 정합을 억지로 적용해도 처음 세 표본의 최근접 거리는26.68/64.35/101.11 mm이며 짧은 표면 대응은 모두 실패했다. 따라서 개선율 조건을 낮추는 방향은 채택하지 않았다. 평가 전용 자세 대조에서 원래 점은 시험 앞차의 뒤쪽 모서리 근처였다. 이 정답은 진단에만 썼으며 제어기 입력이나 물체 신원 판정으로 쓰지 않는다. [주변 형상](geometry_comparison.json), [평가용 좌표와 미연결 후보](clearance_comparison.json).

미연결 후보는 옛 점을 다시 같은 곳의 물체로 찾는 대신, **그 옛 위치 주변에 현재의 유효 반환 광선이 장애물 없이 도달하는지** 비교했다. 원래 점 주변30 mm의53개 표본 모두에서 양옆 인접 유효 광선, 기존30 mm 여유+취득 후2 m/s 이동 여유, 가까운 실제 점유 부재를 요구한다. 무반환/마스크는 인정하지 않으며 기존 표면 정합이 거절되면 후보도 거절한다. 원래1초 이력 범위만 비교한다.

최초 지지는130.22초, 서로 다른 스캔의 연속 두 번째 지지는130.32초였다. 이는 당시 제어에 연결하지 않은 입력 대조다. 현재 모터축/gyro 좌표와 정적 배경 가정에 의존하고,53개 표본은 연속 공간 인증이 아니다. 옛 위치가 비었다는 증거와 움직인 물체가 다른 가림 안에 없다는 증명은 다르다. 현재 모든 점유·좁은 결측 정책의 재검사와 별도 보호층을 생략할 근거로 쓰지 않는다.

후속 작업은 가까운 점유·가림·다중 위협·시간/좌표 오류 반례를 먼저 대조하고, 타당하면 기본OFF인 교통 후보 내부에서 서로 다른 두 스캔의 확인 후 현재 입력을 다시 검사하는 방식으로 제한 연결하는 것이다.
