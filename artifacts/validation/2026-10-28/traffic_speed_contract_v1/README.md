# 통과 후 같은 경로 후보의 감속 연결

2026-10-28. [직전 실행](../traffic_anchor_set_v1/README.md)은43.014 m에서28.942초 정지했다. 실제 기록7,790판단의 읽기 전용 계측은 모두 원래 출력과 같았고, 선택기의1,444회 거절은 전부 목표 속도가같은 경로 결측 후보의0.35 m/s 상한보다 크기 때문이었다.129.42초 예에서는 기본 경로/부분 관측 검사가0.45 m/s를 허용했으나 선택기는 이를 제한 속도로 다시 검사하지 않고 거절했다. [원시 입력·값 대조](../traffic_anchor_set_v1/run1_motion_contract.json).

## 변경 범위

`traffic_recovery_trial`을 명시한 RELEASED 상태에서, 허용된 측방 부분 관측과 실제 이동 영역의 미관측이 겹칠 때만 목표를기존0.35 m/s로 제한해 다시 검사한다. 이미 전부 관측된 원래 경로·옵션OFF·기본값은 그대로다. 실제 측정 속도와 현재/이전 조향, 원시 반환과 부분 관측의 시간/운동 증거는 유지한다. 낮춘 목표에서도 가까운 점유·넓은 결측·다른 조향/더 큰 실제 운동·영역 밖·큰 후방 마스크는 계속 거절한다. 미관측을 자유 공간으로 표시하지 않는다.

이 변경은 높은 목표를 허용하는 문턱 완화가 아니라 **기존 저속 후보를 구성해 전체 이동 영역을 다시 검사하는 연결**이다. 정적 배경·숨은 물체/후방 위험 등의 기존 한계는 남는다. 기본 채택·실물 안전을 뜻하지 않는다.

## 검증

- 관련211검사 통과(`static_v2.log`). 초기174통과/1실패는 새 코드의 후속 출처 계약 등록 전 기존 해시 검사였으며 원본 로그를보존했다. 과거 실패 실행 소스는 `before_source.zip`과 이전 전체 실행ZIP에 남는다.
- 새 계약은 `config/tests/traffic_speed_recheck_r1_sha256.json`이며 이전 계약·판정값을 덮어쓰지 않는다.
- 전체7,790저장 입력/191 reset의 비교에서 명령 변화1,444회는 최초129.42초 이후였다. 기존0을0.35 m/s 후보로 재검사했고 별도 보호함수도 허용했다.130–154초1,201호출의 기존 양수0·후보/보호각1,158, 후보0요청567회는 보호에서도0이었다. 입력·소스 불변과 옵션OFF 기존7,790판단 일치를 확인했다. 비용 중앙14.40 ms/99백분위70.42 ms/최대83.99 ms는 오프라인값이다.
- 빌드 후 같은155초·seed0 실제 주행1회를 완료했다. **43.193 m에서28.543초 정지하여 전체 랩·최종 앞차 간격은 실패**했다. 실제 명령 연결은 바뀌었지만129.88초에 새 위협1점이 래치되어 후속 재관측을 통과하지 못했다.
- 접촉·표본 바퀴 중심 이탈0, 최소 표본/연속 차체 간격약358.9 mm, STOP 뒤 이동0.0191 mm를 기록했다.14/14프로세스 정상 종료·잔여 프로세스0, 소스1,007파일 불변·기존7,791판단 동일 재생을 확인했다. 표본 바퀴 중심은 실제 타이어 접지 판정이 아니다. [원래 실행 판정](run1_course/report.json), [후속 요약](run1_diagnostics.json), [재관측 진단](run1_anchor_audit.json).

## 새 정체와 다음 분석

계획기 재관측은 `surface_rejected`2회, 같은 스캔5회, 이력 만료1회 뒤 종료 상태가 계속됐다. 두 표면 정합은 잔차가작았지만 이동 보정에 따른 개선율을 충족하지 못해 `weak_improvement`로 거절됐다. 이것만으로 실제 장애물이 사라졌다거나 안전하게 해제할 수 있었다고 결론 내리지 않는다. 보호층의 상태 기록은 비동기 표본이므로 그 표본에 없는 호출을 미실행으로 해석하지 않는다.

다음은 원래 위협점·원래 스캔을 그대로 유지한 [읽기 전용 재관측 대조](../traffic_anchor_identity_v1/README.md)다. 정합을 하지 않아도 실제 반환에 다시 대응하는지 먼저 확인한다. 개선율·이력 수명·보호선을 통과만을 위해 완화하지 않는다.

저장 입력 대조와 실제 주행 결과를 구별한다. 이번 실패는 그대로 보존하며 원인 변화 없는 동일 주행을 반복하지 않는다.
