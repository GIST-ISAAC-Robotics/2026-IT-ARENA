# 공식 신호와 같은 교통 후보의 통합 검증

2026-10-28. 이전 단독·밀집 출발의 공식 신호/카메라와 최신 교통 회복 후보를 한 실행 구성으로 연결했다. **run1은37.474 m 정체로 실패했고, 경로 원점 계산을 수정한 run2는53.272 m·교통1랩·기존 판정·STOP·정상 종료를 통과했다.** 아래 준비·실패 기록과 마지막 후속 결과를 구분한다. [측방 결측 범위 후보](../traffic_side_scope_v1/README.md)의 임시 신호 교통1랩53.272 m는 당시 조건의 성과로 보존한다.

- 기준은 `g1_traffic_full_course_v1.json`의155초·seed0·앞차 정지/재개와 옆차 각본이다. 속도·물성·간격·STOP·도로 판정은 그대로 유지한다.
- 달라지는 것은 공식4-red/green 시각 신호·지역 신호 검출 후보와 기존 v2 고정 카메라(-75,0,300 mm)다. 방지턱은 우선OFF다. 신호 시설의 좌표·높이 해석은 기존 v2의 팀 가정이며 공식 설치 실측이 아니다.
- G1 v4·평행/통과/GUARD·교통 회복/경로 재획득을 함께 명시한다. 어댑터는 요청된 모든 추가 옵션을 실제 launch 설정과 대조하며 누락·충돌·알 수 없는 옵션을 거절한다.
- 평가기 사본은 공식 배열에 없는 노랑 요구만 제외한다. 신호 발생기 오류/초록 미관측은 실패로 기록한 뒤 기존 명시STOP 경로로 이동하며 성공 판정으로 바꾸지 않는다. 원본 코드는 그대로 보존한다.
- 준비/실행 소스와 diff를 별도 보존하며 새 출력 폴더만 사용한다. 정답 신호 상태·actor·지도는 평가기에만 남고 제어 입력은 RGB/C1/IMU/모터축 피드백이다.

밀집 그리드 출발·5랩·실차·실제 설치 신호를 검증하는 시험이 아니다. 최신 교통 시도 결과가 나오기 전에 이 준비를 완주로 기록하지 않는다.

준비 검사에서는 실제 요청과 launch 사이의 누락/중복/변경, 신호 판정 사본의 수정 범위 등5개 검사가 통과했다. 후속 실제 헤더·70개 신호ACK 검사까지6검사 통과했다(`adapter_contract_v3.log`). 초기 후속 검사는 구형 신호 발생기 결과를 v2의 ACK 구조로 검사해1실패했으며, v2 실제 입력으로 고친 뒤 통과했다. 실패 로그는 보존한다. 서로 다른 과거 헤더/ACK를 함수에 넣은 계약 검사이므로 통합 주행 결과가 아니다. 이는 당시 준비 단계 결과이며 아래 후속 실행과 구분한다.

`run1_trial.sh`는 선행 주행 종료 뒤 한 번만 실행하는 진입점이다. 새 소스ZIP·고정 설정을 준비하고 실제 판단기 옵션, 모든 신호ACK, 기존 주행 판정·STOP·종료·바퀴 중심·재생을 회수한다. 이 파일의 존재나 정적 검사는 실행 승패를 뜻하지 않는다.

후속 검토에서 판단 기록 헤더에는 출발 영상 모드가 없다는 점을 확인했다. 평가 어댑터가 실제 `/autonomy/status`에서 영상 프로세스·출발 모드·운영 감독 유무의 작은 필드를 보존하고, 모든 상태에서 예상한 모드인지 검사하도록 보완했다. 누락/빈 입력·임시3등 모드·다른 운영 모드 반례를 포함한6검사를 통과했다(`adapter_contract_v5.log`). v4의 파일 닫기 경고도 수정했으며 원래 로그는 보존한다. 제어기·주행 판정에는 변경이 없다.

카메라 비교의 기준으로 기존 기본 카메라 교통 실행의 상태 기록을 요약했다(`baseline_marker_status.json`). ID0/45/20/30은 각각10/26/36/33개의 상태 표본에 나타났고96.04초에ID30으로 왼쪽→오른쪽 벽 선택이 바뀌었다. 같은 영상 결과가 여러 상태 표본에 남을 수 있으므로 프레임별 검출률·인식 거리로 해석하지 않는다. 새 카메라 결과는 아래 실제 실행에 별도로 기록한다.

## 통합1회 실행 시작

같은 후보의 임시 신호 교통1랩 통과 후 전체 회귀의5개 출처/fixture 문제를 수정하고276영향 검사·어댑터6검사를 확인했다. 주행 `src/`238파일은 성공한 교통1랩의 소스와 모두 같으며, 평가기 보존 목록만 갱신됐다. 새 `run1_course`로 공식 신호/카메라 통합을 실행·회수한다. 실제 결과가 나오면 원래 판정·70ACK·영상 모드·STOP/종료·마커 상태를 분리해 기록한다.
