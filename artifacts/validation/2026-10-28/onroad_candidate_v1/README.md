2026-10-28. 저장 입력 대조와 좌우 각각 제한 주행1회까지 완료했다. 왼쪽 뒤 일시 중단했고, 사용자 재개 요청 후 오른쪽을 확인했다.

직전 교통1랩은 잔디 쪽 옆차(+0.32 m)를 포함했다. 도로 안 가까운 피추월까지 완료한 것으로 확대하지 않기 위해, 과거 run17/21의 좌우 입력을 현재 통합 G1 구성으로 재계산한다. 원래 약69.8 mm 간격 실패·당시 소스·판정은 보존한다. 과거150/97 mm는 역사적 비교선이며 현행 사용자 결정의 고정 최소 간격이 아니다.

`compare_saved.py`는 저장 입력의 순서/footer/누락을 확인하고 당시 운동 설정·스캔·직전 조향·벽 선택을 그대로 사용한다. 새 구성은 `traffic_side_scope_v1/run1_course` 헤더의 전체 G1 설정이다. 원본 M3 출력과의 분기, 진행 명령/정지, 측방 모드 전이만 비교한다. 새로운 명령으로 차량이 움직이지 않으므로 실제 진행·접촉·간격·독립 보호층·신호/카메라 검증이 아니며 동일 재생 통과율로 표현하지 않는다.

현재 공식 신호 교통 실행의 소스를 변경하지 않고 별도 산출물에 준비했다. 긴 계산은 해당 실행 회수 뒤 GPT-6 Luna가 맡는다. 결과를 확인한 뒤 필요한 좌우 대표 폐루프의 조건과 판정을 별도로 정한다. 원인이 달라지지 않은 실패 반복은 하지 않는다.
