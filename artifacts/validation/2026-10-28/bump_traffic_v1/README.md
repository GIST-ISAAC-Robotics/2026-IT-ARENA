## 종료 수신 불일치와 수정 범위

STOP 결과 계산 중 자차가 조금 더 수집된 뒤 gate를 닫고 ROS spin도 멈춰 상대차 큐의 끝이 뒤처진 구조다. `validate_g1_traffic.py`에 정상 STOP 뒤 자차 수신을 먼저 고정하고 **같은 끝 시각까지 실제 상대차 메시지를 최대1초(실제 시간) 회수**하는 절차를 추가했다. 자료를 생성·외삽하거나 자차 끝을 잘라내지 않는다. 수신 실패는 기존coverage 실패로 남기며 고장/중단 경로에는 기다림을 추가하지 않는다. 제어기·물성·판정선은 변경하지 않았다.
