- [편집 가능한 SVG](candidate_overlay_id30_150cm.svg): 원본 PNG 바이트를 그대로 내장한 벡터 도식입니다. 생성 이미지나 가상의 후보 좌표가 아니며, 밝기·마커 무늬를 보정하지 않았습니다.

## 대조 원칙

`detector_probe.json`의 `raw_route`와 `face_detector_probe.json`의 PNG/도형 대조군을 사용합니다. 원본 장면과 지지대 포함 장면은 별도로 표시합니다. 각 24개 위치 × 3개 장면 × 4개 기준값 = 288개 반환 ID 목록이며, 0.05/0.02의 144개는 `aruco_internal_trace.json`의 설치 검출기 및 내부 추적 목록과 다시 대조합니다. 같은 ID가 여러 번 반환돼도 임의로 하나로 줄이지 않습니다.

그림은 원본 `id30_150cm.png`에서 각각 검출된 후보 2(A), 3(B), 0(C), 6(D)를 사용합니다. **A·B·C·D 모두 같은 그룹에 포함되며, 그중 가장 큰 후보 6(D)가 최종 선택됩니다.** D는 그룹화 전부터 있던 후보이지 다른 후보의 윤곽을 합쳐 만든 결과가 아닙니다. 그림에는 A–B·B–C·C–D의 연결을 표시하며, C–D의 꼭짓점 RMS 거리는 1.50 px로 기준 7.90 px보다 작습니다. 원본 영상 속 60×60픽셀 영역은 `(385,72)`부터이며 확대 전후 이미지 내용은 동일합니다.

거리 단위는 본선상 마커 위치까지의 진행 거리이고 실물 직선거리 측정이 아닙니다. 정지 사진에서의 후보 회복을 연속 주행·실물 성능으로 확대하지 않습니다. 전역 오검출률을 평가한 실험도 아닙니다.

## 재생성·확인

저장소 루트에서 Python 표준 라이브러리로 실행합니다.

```text
python scripts/prepare_issue12_reply_assets.py
python scripts/prepare_issue12_reply_assets.py --check
```

생성기는 초안의 `BEGIN`/`END` 구간 안에 있는 표만 기계적으로 갱신하며 본문을 작성하거나 변경하지 않습니다. SVG는 표준 SVG 렌더러로 PNG 변환합니다. 번들 `sharp`/librsvg로 PNG를 만들었으며, 문답식 마지막 설명을 뺀 현재 크기는 1500×990픽셀입니다. 사진은 리터치하지 않고 SVG 도식의 화면 표현만 래스터화합니다.

승인 후 게시할 때는 원본 사진 2장과 도식 PNG를 실제 첨부하고 회신의 로컬 주소를 첨부 주소로 바꿉니다. 이 폴더나 초안을 만들었다는 것만으로 외부 게시가 완료된 것은 아닙니다.
