대상: 공식 `v2026.09.01`의 벽 평행 PNG 마커. 당시 저장 RGB를 재사용했습니다.
실행: 사용자가 준비된 스크립트를 실행한 후 결과를 재조회·검증했습니다.
보고서 생성 시각: `2026-09-15T16:02:50 UTC`(한국 시각 9월 16일 01:02:50 무렵).

## 결론

**이번 과거 영상에서는 `minMarkerDistanceRate`를 0.05에서 0.02로 낮춰도 검출 거리가 늘어나지 않았습니다.** 49장 모두 반환 ID 목록이 그대로였고, 0.01까지 낮춰도 새 목표 검출 표본은 없었습니다. 최신 갠트리 마커에서 확인한 0.02의 효과를 과거 벽 평행 마커에도 적용된 것으로 볼 수 없습니다.

이는 해당 계수 조정으로 과거 미검출이 복구되지 않았다는 결과입니다. 실패 원인이 전부 설치 각도였다는 증명은 아니며, 과거 영상의 후보 생성·그룹화·해독 내부 추적은 이번에 수행하지 않았습니다. 이전 사진은 비스듬한 마커가 좁은 폭으로 보이는 모습과 일치하지만, 각도·명암·픽셀 해상도·그 밖의 검출 설정의 기여도를 분리한 실험은 아닙니다.

## 조건과 재현 확인

- 기본 표본 12장: ID 0/20/30/45 × 본선 진행 거리 1.5/1.0/0.75 m.
- 추가 거리 표본 37장: ID 0/45 각 9장, ID 30 19장. ID 20의 촘촘한 거리 자료는 이 집합에 없습니다.
- 총 49개 저장 프레임 × 네 계수 = **196조건**. 같은 거리의 기본/추가 촬영은 별도 프레임이며, 독립적인 49회 실차 주행이 아닙니다.
- OpenCV **4.6.0**, `DICT_4X4_50`. 원본 BGR→회색조 변환 후 `minMarkerDistanceRate`만 변경했습니다. 리사이즈·밝기 보정·투시 보정·재렌더링은 하지 않았습니다.
- 기본값 0.05의 재검출은 당시 결과와 **49/49 일치**했습니다. 매개변수를 생략한 기본 호출과 명시한 기본 호출도 49/49 일치했습니다.
- 원본 PNG 49장과 새 사본 49장, 보고서 원본/사본, 실행 스크립트의 SHA-256 일치를 확인했습니다. 기존 파일을 덮어쓰지 않았습니다.
- 세 마커 자료 집합을 비교했던 최신 갠트리 시험과 달리, 이번 대상은 9월 1일 벽 평행 공식 PNG의 당시 촬영본뿐입니다. 팀 임시 각도 변경/도형 마커 영상은 포함하지 않았습니다.
