# 현재 경로 전이 폐기 원인 계측 r329

r325 실제 Jetson의 첫 약590ms 양수 명령 공백에서 현재 검사5개가 새 계획 전이 때문에 폐기됐다. 정확히 어떤 필드/감속 때문에 폐기됐는지 기존 로그에는 없어, 같은 코드/입력의3초만 사유를 추가 기록한다. 정책·시한·출력은 바꾸지 않는다. 저장 입력, delay20 가정, 실제 계산 하한0이며 실물 포트/구동/ROS는 없다. 이 진단은 성능 통과 재시도가 아니다.

## 확인

24번 전이 중 활성 확인 없음9, 호환 양수 전이8, **새 목표속도가 더 낮다는 이유만의 거부7**이었다. 나머지 FOLLOW/벽/선택 모드/epoch 조건은 그7건에서 같았다. 예를 들어0.50→0.45m/s인 새 계획에도 현재 확인을 폐기한다. 이는 r325의 모든 공백 원인이 같다는 증명은 아니며, 이번3초 진단의 관측이다. 원142소스/정책 불변·자식 정상 종료를 확인했다.

바로 감속 요청을 무시하거나 옛 큰 속도를 발행하지 않는다. 후속 개선은 새 감속 의도를 유지하면서 현재 확인 결과를 쓸 수 있는 조건이 있는지 검토해야 한다. 실제 측정 속도/새 목표가 만드는 이동 영역·조향·새 관측·STOP/상태 전이를 함께 대조해야 하므로 단순히 비교 부등호를 제거하는 수정은 하지 않았다.
