# Jetson 현재 입력별 판단 비용 r296

장비 재허용 뒤 r288에서 미리 고정한 매10번째 입력을 동일 순서로 측정했다. 130개 실행 소스/입력 해시는 실행 전후 유지했다. 새 전력/클럭 설정이나 센서/MCU 조작 없이 별도 폴더에서 수행했다.

| 저장 입력 | 수 | Jetson 중앙 / p95 / 최대 | PC 중앙 / p95 / 최대 |
|---|---:|---:|---:|
| r279 |52|69.39 /80.77 /105.40ms|21.00 /25.06 /31.99ms|
| r282 |54|45.63 /57.98 /105.83ms|12.35 /16.58 /34.81ms|

106개 모두 명령·이유·시각 등 운영 필드가 기존 기대와 같았다. 전체 출력은 Jetson99개, PC106개 일치이며7개의 진단 차이는 [대조 원문](cross_platform.json)에 남긴다. 입력 복원·현재 장면·현재 경로 재검사·결과 변환 범위이고 센서/IPC/ROS/동시 계획 부하는 제외했다. 20ms 마감이나 최악 시간 보장이 아니다.

r282에 사용했던 고정81.30ms는 r279 입력 집단의 Jetson p95였다. 이번 결과는 r282 입력도 항상81ms가 걸린다는 해석을 반박하지만, 최대105.83ms와 별도 부하를 무시한 채 지연 주입을 일괄58ms로 줄일 근거는 아니다. r282의 접촉/미완주 원 실패는 유지한다. 다음 실행 비용 비교는 입력별 측정 범위·동시 계획/센서 부하를 구분한다.
