# SOLO 현재 검사와 기존 저속 공백 검사의 연결 후보

r345에서 확인한 연결 차이를 시험용 후보로 보완했다. 실제 속도0~0.15m/s·FOLLOW/SOLO·새 관측 경로·원 부분관측 허가가 있는 경우에만, 같은 조향의0.15m/s 목표를 현재 좌표/점유와 기존 `released_body_gap.check`로 다시 확인한다. 기존1cm/6도/5cm 기준과 전방 제외·STOP·다른 상태·독립 보호층은 바꾸지 않았다. 미관측 표본 개수를 지우지 않는다.

- 경계 회귀20통과. 원r344 현재416판단을 ROS 인계 후 감속 상한 단계까지 동일 재현했다.
- 같은 입력의r344에서272판단만0→0.15로 바뀌고24개는 재검사 후 계속 거절됐다. 나머지는 기존과 같다. 이는 저장 입력 결과이며 새 주행 개선 증명이 아니다.
- 기존r343으로 이미 출발 허가가 나는r338의234개는 전체 출력 동일. 과거r279의52개도 동일. r282는54개 중 같은 조건의6개가0→0.15로 바뀌므로 과거 전체 불변이라고 쓰지 않는다.
- 최초 비교 실패는 기록에 붙는 `new_plan_deceleration_cap`을 순수 함수 재생에서 빠뜨린 검사기 오류였다. 원 실패/소스·mismatch를 보존하고 기존 r334의 발행 후 상한 단계만 재현해 전체 일치를 확인했다. 판단값을 임의로 지우지 않았다.
- 기본/ROS/실물에는 미채택. 확정 CAD 수신으로 새 주행 전에 형상 대조를 우선한다. `sources.zip`·`report.json`은 비교 소스/입력을 고정한다.
