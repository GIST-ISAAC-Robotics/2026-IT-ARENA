# 정지 근처 SOLO의 0.10m/s 재검사 후보

현재 측정 속도0–0.15m/s·새 FOLLOW/SOLO·현재 벽 확정 상태에서만 검사한다.
0.15m/s 재검사까지 측방 자체 마스크 이유로 거절된 경우, 동일 조향/시각/측정 속도와
원 전체 현재 영역 검사로0.10m/s를 한 번 더 확인한다. 일반 미관측·전방 가림·앞차/GUARD/STOP은 이 후보로 풀지 않는다.
가림 허용량·충돌/속도/시간 기준은 바꾸지 않으며 현재 실제 속도를 낮춰 넣지 않는다.

23경계검사 통과. 첫 테스트는 helper 이름 `setup`을 pytest가 모듈 초기화로 오인해23오류였고
`make_case`로 수정했다. 원 로그/파일은 보존했으며 제어기 실패와 구분한다.
r349 원600전체 출력 재현 후152판단이0→0.10m/s로 바뀌었고, 과거 r279 52개/r282 54개는 전체 동일하다.
같은 입력의 조향/시각 불변·전체 영역 통과도 검사했다. PC r349 중앙10.94→13.21ms로 추가 비용이 있으며
Jetson 실시간 이득이나 실제 정체 탈출을 증명하지 않는다. 원135mm 기하의 저장 비교다.
실제 새 기하 연결은 [r353](../final_geometry_crawl_drive_r353_v1/README.md)에서 분리한다.
