# 현재 영역 거절에서 작은 양수 목표 비교 r342

r338은 원 경로 계산이 양수여도 현재 조향의 자체 마스크 꼬리가 기존10mm를 조금 넘어 모두 정지했다. 허용량을 늘리는 대신 **같은 계획의 목표속도 상한만 낮춰 기존 전체 현재 재검사를 다시 수행**한다. 실제 측정 속도·조향 입력/기하·시각·영역 분류·독립 보호를 그대로 둔다. 원r338의 균등한12개 저장 입력에서0.45/0.35/0.25/0.15m/s를 비교하며 실제 주행에 연결하지 않는다.

원 출력과 재계산의 일치를 먼저 대조하고, 목표속도 감소로 실제 조향이 달라지면 따로 기록한다. 고속 측정값을 낮게 꾸며 통과시키거나 음수/STOP를 양수로 바꾸지 않는다. 결과가 있어야만 좁은 선택형 구현을 판단하며 단독 예외를 무한히 늘리지 않는다.

## 결과

원234개 중 균등12개의 원 명령/거절 이유/시각을 재현했다. 원 목표가 이미0.45인 입력은0.45비교를 생략했다.0.45는0/9,0.35는0/12,0.25는4/12,0.15는12/12에서 양수 현재 검사를 통과했다. 모든 상한 비교에서 조향은 원래 값 그대로였고 측정속도는0이다.0.15의 대표 가림 꼬리는7.72mm로 원10mm 안에 들어왔으며 미관측/전방 가림은0이다.

후보 한 번의 전체 현재 재계산은 PC 중앙5.88ms·최대8.58ms였다. Jetson/동시 부하 수치가 아니다. 최초 비교는 원 목표0.45보다 엄격히 작은 상한만 비교한다는 검사에 걸렸고, 해당 입력에서0.45를 생략하도록 시험만 고쳤다. 초기 로그/소스를 보존했다.

다음은 정지 근처의 SOLO·현재 자체 가림만 있는 실패에서 **0.15m/s 한 번만 전체 재검사**하는 선택형 후보를 확인한다. 원 판단을 더 낮은 목표로 다시 만족시키는 것이며 관측 허용량/STOP/TTL/물성을 완화하지 않는다. 정상 속도 전체를0.15로 제한하거나 앞차/일반 미관측 정지를 진행으로 바꾸지 않는다. 실제 중앙 복귀 후 증속·주행 이득은 미검증이다.
