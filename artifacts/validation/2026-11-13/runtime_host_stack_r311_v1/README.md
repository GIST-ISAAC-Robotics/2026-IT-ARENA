# 비구동 MCU 혼합 송신과 운영 관측 호스트 r311

r305에서 검증한 동일 출력 비활성 앱을 임시 설치하고, 기존 공통 감독기의 sensor-link 선택으로 C1·IMU·MCU 상태·선택 RGB를20초 함께 수신한다. 원 PCNT0은 유효 모터 속도가 아니며 가상 엔코더를 넣지 않는다. 운영 구동이나 장착 검증은 아니다.

포트/카메라 비점유·펌웨어 SHA·기존 app 백업/읽기 일치를 확인한다. 출력 앱은 PWM/DIR0·output_ready=false이며 호스트 마지막 STOP만 허용한다. ARM/DRIVE를 보내지 않는다. 성공/실패 뒤 원 app1MiB를 복원하고 readback·inactive/포트 반환을 확인한다. 픽셀/원시 UART·세부로그는 Git 제외다. 결과는 후속 기록한다.

## 결과와 미해결

출력 비활성 MCU·C1·IMU·RGB를20초 함께 연결했다. C1 183배열/93,204점의 시각·길이·식별 메타데이터가 공통 노드와 일치했다. UART11,960프레임에서 CRC/순번/수신 큐 폐기 오류는0이지만 자이로 ROS 발행3,747개 중 공통 콜백 수락은3,634개였다. 거절0이고113개의 누락 위치는 당시 콜백 기록이 없어 미확정이다. **입력 전달 완전성은 실패로 보존한다.**

RGB1,201장 중1,196장을 수신했고 영상 결과196개·처리중앙32.21/p9543.78ms였다. raw MCU관측985개·상태발행972개이나 공통 상태 수신은 이 시험에서 별도 기록하지 않았다. 모든 원 관측은 출력/엔코더 유효성false·PCNT0·PWM/DIR0이다. ARM/DRIVE 없이 최종STOP1회와ACK1회를 확인했다. 원 앱SHA복원/readback·inactive·포트반환·네 자식 정상종료·155소스불변을 확인했다. 유효 엔코더/실제 경로 계산이 없는 비구동 관측이므로 주행 중 전체 연산 성능의 증명이 아니다.

후속 r312는 실제 콜백 기록을 추가한다. 시작 부하 또는 지속 처리 문제라는 설명은 아직 가설이다.
