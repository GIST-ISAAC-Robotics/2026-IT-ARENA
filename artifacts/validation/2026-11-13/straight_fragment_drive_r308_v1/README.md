# 실제 직선 조각 경로 후보 제한 주행 r308

프린팅 전 카메라 대표 r307 완료 후, r306 저장 검증의 동일 후보를 r304와 같은 CAD·시설·0.25배 시계 조건에서1회 주행한다. 후보는 실제 관측 조각의 직선 적합만 추가하며 점유/unknown/보호층은 유지한다. r306의38검사와 저장 r294/r304 원 코드 동일 재현을 선행 근거로 삼고 동일 후보 바이트를 복사했다.

46.64m·최대90초의 등록 시험이다. 시간 목표만0.25배이며 물리 간격·속도·주기·TTL은 동일하다. 결과를 실시간·실차·교통 검증으로 확대하지 않는다. 현재 카메라 높이는198.363mm로 유지하고, r307의 높이 개선안은 자동 채택하지 않았다. 실행 결과는 후속 기록한다.

## 결과

**20.23 m·최고2.835 m/s, 미완주**다. r304에서 멈춘 신호 지주 구간은 통과했지만 ID20 코너에서 경계 미확정이7초 지속됐다. 독립 보호층은 현재 관측을 clear로 평가했고 제어기가0명령을 선택했다. 평가 겹침0·STOP/정상 종료·잔여PID0·628입력 불변을 확인했다. 물리 접촉 토픽은0메시지이므로 무접촉의 독립 증명으로 합산하지 않는다. [판정](assessment.json).

저장 센서에서 오른쪽 실제 코너는 보인다. 지주가 있는 원 입력의 오른쪽 경로는 차량 원점에서약80 mm 떨어진 지점부터 시작하고, 평가용으로 지주 반환만 제외한 진단에서는약6 mm다. 원 점은 제어기에 그대로 유지한다. 이 차이가 벽 적합 또는 관측 창/원호 자르기에서 생기는지 분리하고, 판정 허용량을 늘리지 않는 보완을 검토한다. [그림](sensor_path_diagnosis.png)·[진단](inspection.json).

이번 후보는 실제 직선 지주 구간에는 도움이 됐지만 전체 코스 완료로 채택하지 않았다. 새 코너 원인을 확인하지 않은 같은 주행 반복은 하지 않는다.
