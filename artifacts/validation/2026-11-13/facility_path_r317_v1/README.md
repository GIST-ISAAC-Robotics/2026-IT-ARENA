# 시설 경로 이동 자문·저장 비교 r317

Fable5.2/high 자문([원문](ADVISORY.md))은 첫 정지의 벽 경계 탈락과 정지 뒤 경로/기둥 간섭을 분리했다. GPT가 r314 입력에서 21.22초 경계 미확정과 21.8초 이후 같은 점유 여유의 반복을 다시 확인했다. 기둥을 지운 경계 대조는 아직 하지 않았으므로 경계 탈락의 정확한 기하는 미확정이다.

r316은 저장 양수 명령 증가가 있었으나 저속 조향 wrapper 추가·120ms float 경계 실패·진입 경계 소실 미해결로 주 해법에 채택하지 않는다. 실패 코드/결과는 보존한다.

## 후보와 범위

r306/r309 경계 처리를 보존한 단일 baseline 함수에서 PP 앞 실행 경로만 선택한다. 실제 반환이 원 경로를 침범하고 원 PP호의 여유도 부족할 때 최대60mm 평행 경로 중 가장 작은 이동량을 고른다. 반대 벽/별도 물체의 최악 경로 여유가 줄면 거절하며 최종 원 점유/직전 조향/관측 검사는 그대로다. 경로 선택으로 기존 속도 상한을 높이지 않는다. 벽 이력은 원 경로를 유지한다.

선택 비용은 마지막 광선 뒤120ms(10Hz 갱신+20ms 제어)의 가정 예산으로 맞춘다. 실제 나이가 더 크면 그 나이를 사용하고, 실제 최종 점유/TTL은 원 나이와 원 조건을 유지한다. 미래 스캔을 가정한 허가나 미관측 자유 공간 생성이 아니다. 시험 설치 파일은 한 baseline을 구성하며 r313/r316 PP wrapper를 쌓지 않는다. 공통 기본에는 미연결이다.

## 검증

- 후보19 + 이전178 =197검사 통과. 최초 교통 fixture 구성 실패와 PYTHONPATH 덮어쓰기로 xacro 수집이 실패한 기록은 보존했다. 검사 조건은 완화하지 않았다.
- r310 원1,195판단 전체 동일 재생. 후보 최초 적용 전674판단은 추가 진단을 제외하고 동일했다.
- 후보156선택, 양수729→730, 명령148차이. 실제 이전 조향과 차체 궤적은 고정돼 있으므로 재개 성공이 아니다. 경계 미확정19회는 그대로다.
- r314 21.8~23.0초 기하에서는 주로 바깥3cm 경로가 선택돼 PP각 약0.32→0.24rad, 선택 여유0.12~0.16→0.28m 이상을 보였다.
- PC 비용 중앙8.55→13.53ms/p95 19.78→19.20ms로 중앙 비용이 증가했다. 통제된 연산 벤치마크나 Jetson 실시간 증명이 아니다. 필요 시 계산은 새 경로 선택 주기에 배치하되 아직 최적화하지 않는다.
