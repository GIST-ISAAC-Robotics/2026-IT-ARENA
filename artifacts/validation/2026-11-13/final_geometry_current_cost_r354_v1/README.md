# 확정 기하 현재 검사 비용 — PC/Jetson

r353의 현재 검사220개 중 매10번째와 상태/이유 조합 최초를 포함한26개를 동결했다.
단일 프로세스의 저장 입력 계산으로 실제 센서·ROS·동시 계획 부하나 주행 시험은 아니다.
실물 포트/구동/펌웨어/전력 설정을 변경하지 않았다.

| 플랫폼 | 입력 복원 중앙 ms | 현재 검사 중앙/p95/최대 ms | 합계 중앙/p95/최대 ms |
|---|---:|---:|---:|
| PC |2.19|14.65/28.08/37.80|17.48/30.28/40.02|
| Jetson |8.64|51.43/110.27/136.03|61.56/118.89/144.52|

PC26개 전체 출력 일치. Jetson 전체19/26일치로 원 비교 명령은 실패했다.
7개 차이는 `queries`와 `masked_left/right` 개수의1~2개 차이이며 속도/조향/판정·이동 거리·미관측/꼬리 범위는 같다.
원 실패/결과를 `jetson_initial`에 보존한다. 표본 위치 정렬의 플랫폼 수치 차이를 전체 동등성으로 바꾸지 않는다.
항목별 차이는 [후속 비교](platform_comparison.json)에 원 출력 해시와 함께 남겼다. 비교 허용 오차는 기존 `equal_output`의1e-10이며 주행 판정선을 바꾸지 않는다.
소스737개를 기반으로 새측정파일/선택 입력을 포함한 동결 소스의 변경은0이다.
이 비용은100ms 주기의 전체 예산에 비해 크므로 현장 주행 성능 확보 완료로 볼 수 없다.
후속 r355는 느린3개 판단만 진단 프로파일하여 비용의 위치를 찾는다.
