# GPIO8 유지형 STOP 입력 준비 r315

11/13 조립 문서의 GPIO8–TGND 두 선·내부 풀업·I=도통/O=개방 방침을 r305 출력 비활성 결합 앱에 연결한다. 실제 스위치 배선/부팅·리셋 전압/모터 정지/규정 인정은 미검증이다. **보드 설치·출력 허용 없이** 호스트 상태 전이와 ESP32-S3 빌드만 확인한다.

입력은 main task 매 순회에서 명령 수신/제어 호출보다 먼저 읽는다. 개방/HIGH(또는 유효하지 않은 읽기 값)는 기존 physical_stop 래치를 건다. LOW로 복귀해도 래치는 유지되며 기존 정지 피드백·명시 CLEAR→ARM 조건이 남는다. 입력이 변할 때만 기존 상태 갱신 API를 호출해 매1ms마다 같은 정지의 세대 번호를 증가시키지 않는다. 접점 바운스로 자동 재출발하지 않으며, 읽기 사이에 끝나는 펄스/MCU 정지는 이 소프트웨어 입력의 검증 범위가 아니다.

합성 엔코더·구동 허가는 호스트 검사에만 쓰며 실제 앱의 output_ready=false/PCNT 원시 관측은 유지한다. 새로운 독립 차단 회로나 실물 정지 인증으로 부르지 않는다.

## 검사 결과

실제 계약 endpoint를 사용한 합성 입력에서 개방/도통 부팅, 계속 누른 동안 세대 불필요 증가 방지, ACTIVE중 개방→목표0/제동, 개방 중 CLEAR거부, 복귀/바운스 중 자동 재출발 금지, 명시 CLEAR→ARM→DRIVE, 비정상 읽기값의 정지를 확인했다. 최적화 및 Address/Undefined sanitizer 실행이 통과했다. ESP-IDF6.1/ESP32-S3 전체 앱 빌드278,528 B·main 정적stack frame768 B다. 실제 task 최소 여유/핀 레벨/제동 시간은 미측정이다.

사용자가 현재 회로도 확정을 재확인했다. 핀/전원 재선정 없이 그 결선을 따른다. 이 후보는 조립 후 실물 스위치·출력 검사에 사용할 준비본이며 현재 Jetson/ESP32 앱을 바꾸지 않았다. 원 IMU 앱과 비활성/포트 반환 상태는 r312 종료 기준으로 유지된다.
