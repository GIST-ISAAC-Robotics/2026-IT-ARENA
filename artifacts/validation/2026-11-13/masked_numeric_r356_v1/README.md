# 자기 가림 분류 수치 커널

현재 이동 외곽 검사에서 `masked_only`의 같은 양옆 광선·원 순서 동률·비순환 인접·반환 거리/여유를 C++로 계산한다.
표본·가림 범위·관측/STOP 기준을 바꾸지 않는다. 명시 `native_v1`에서만 사용하며 기본 Python 경로는 유지한다.
구버전 컴파일 모듈이면 묵시적으로 사용하지 않고 rebuild 오류를 낸다. ABI1의 기존 메서드는 유지한다.

PC 관련194검사·Jetson 가림 경계64검사 통과. r353의 전체 현재 검사220개에서 각 플랫폼의 전/후 전체 출력이 모두 같다.
PC는 원 기록220/220일치, Jetson은 전/후 모두168/220일치이며 기존 플랫폼 표본 수 차이를 보존한다.

| 현재 검사 비용 ms | NumPy 분류 | C++ 분류 |
|---|---:|---:|
| PC 중앙 / p95 |16.80 / 29.78|16.42 / 29.29|
| Jetson 중앙 / p95 |60.20 / 108.80|57.01 / 97.26|
| Jetson 최대 |137.73|127.12|

Jetson 중앙 약5.3%·p95 약10.6% 감소다. 입력 복원/계획/ROS/센서 동시 부하는 제외했으므로 실시간 완료는 아니다.
`before_sources.zip`은 수정 전4파일, `sources.zip`은 전/후 대조의 고정 소스/입력이다.
기존 깊이 지지와 가림 분류가 일부 같은 광선 각도를 다시 계산하는 비용은 후속 후보로 남는다.
하드웨어 포트·펌웨어·전력 설정은 변경하지 않았다.
