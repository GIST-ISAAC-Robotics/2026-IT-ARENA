# 확정 CAD 지주/배선 정지 렌더 검사

r347의 최종 두 지주 + 앞면6mm 배선 + 마스크 움직임3mm 여유를 사용한다.
후면 ID49 140mm를 명시한다. 이동 명령과 실물 장치는 사용하지 않는다.
snapshot 원 광선의 자기 반환과 거리 한정 마스크, 멀리 있는 트랙 반환 보존을 확인한다.
실제 순차 수신·주행·최종 차량 전체 기구 검증은 별도다.

- 정지 스캔15개·500광선에서 다섯 자기 구조 구간을 모두 관측했다(한 표본4/4/11/11/23점). 거리 한정 자기 반환 제거와0.3m 밖 원 반환 보존을 확인했다. 평면 변위는 수치 오차 수준이었다.
- 원 `passed=false`를 보존한다. 촬영 브리지는 SIGTERM 정리가 필요했다. Gazebo 서버와9개 launch 자식은 정상 종료했고 후속 `/proc` 확인에서 촬영 브리지 PID1338도 소멸했다. 촬영 브리지 종료 실패를 렌더 성공으로 덮어쓰지 않는다.
- **노면 인자 주의:** 정지 스크립트가 `grass_alignment:=road_level`이라는 잘못된 launch 이름을 사용했다. 실제 연결 이름은 `evaluation_grass_alignment`여서 이 정지 시험은 원 노면 높이다. 움직이지 않은 센서/마스크 확인에만 사용하며 평탄 노면 주행 증거로 쓰지 않는다. 후속 r349는 검증기의 기존 `--grass-alignment road_level` 연결을 사용한다.
