# 확정 CAD 센서 구조·움직임 여유·실장 보정 후보 준비

[하드웨어 기준 보고서](../../../../docs/hardware/PACKAGING_FINAL_2026_11_13.md)를 따른다. r344/r346 당시 입력은 보존하며 새 원본은 사용자 확정 SHA-256 `c9c203b5…edbfce6`이다.

- 새 두 구조 mesh·공칭 단면으로 nowire/front6mm/inboard6mm 세 프로필을 생성했다. 모두 추가 장착 움직임3mm를 명시하며 실측치는 아니다. 기존 프로필은 기본0 여유 추가로 결과를 보존한다.
- 관련 CAD/기존 구조40검사, 실장 후보/장착 관련37검사, 노면6검사를 통과했다. 검사 집합이 겹치므로 합쳐 고유83개라고 세지 않는다.
- `audit.json`에 출처/새 프로필·동일 센서 위치·마스크를 보존했다. 기둥4개의 마스크 각도 합은 nowire30.42°/front6mm41.15°/inboard6mm42.11°이며 물리 차폐와 구별한다. 추가 여유를 포함한 각도 합이지 실제 불투명 면적이나 전방 시야 전체의 손실률이 아니다. 후면140mm ID49는 별도 다섯째 구간이다.
- `*_nominal_mask.json`은 거리 한정 보정 입력이다. `review_c1_self_returns.py`는 실측 스캔을 보정 후보로 정리할 준비이며 합성 입력/CLI/원본 보존·다른 물체 반환 유지까지 확인했다. 실물 취득·운영 자동 적용은 아직 없다.
- `grass_above_3mm`는 사용자 전달 높이의 선택형 강체 비교다. 기준 주행은 `road_level` 유지. 원본·마찰·다른 링크 불변을 확인했으며 새 주행·실제 눌림/접촉 검증은 하지 않았다.

전체 기구·축거/윤거·유효 바퀴 반경·무게중심과 장착 calibration은 별도다. 이 결과를 최종 차량 완주/실차 안전으로 확대하지 않는다.
