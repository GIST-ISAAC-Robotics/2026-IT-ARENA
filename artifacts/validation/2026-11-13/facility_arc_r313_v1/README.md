# 시설 반환 옆 조향 후보 기하 비교 r313

r310 저장 입력에서 현재 Pure Pursuit 조향과 가까운 조향을 비교한다. 원 점유·광선별 이동/측정 여유·기존 정지/재개 거리·경계 일치 폭을 유지한다. 짧은 조향 궤적이 같은 관측 경로 주변에서 기존 점유 검사를 통과할 수 있는지 먼저 확인한다.

구동에 연결하지 않는다. 점유점과의 비충돌만으로 미관측 공간을 자유로 취급하지 않으며, 가능 후보가 있더라도 관측 검사·조향 전이·재개 확인·독립 보호는 별도다. 전체 코스/실차 증명이 아니다.

## 저장 비교와 회귀

21.8/22/24초 입력에서 기존 조향을 약2–4° 줄이는 후보가 기존 점유 여유와 경로80mm 일치 조건을 만족했다.26/30초 자세에서는 둘을 동시에 만족하지 못해 후보를 거절했다. 후보는0–0.25m/s·현재 관측 경로·per-ray 점유 조건만 대상으로 한다. PP 상한·발행 조향 변화율·현재/직전각 점유 검사·재개 확인·원 부분 관측 검사를 그대로 거친다. 점유 여유나 미관측 허용 변경은 없다.

최초 연결은 r306 직선 처리 함수를 놓친 wrapper 오류로10.22초부터 원치 않은 차이를 만들었다. 실제 주행 전 발견하여 `initial_wiring_failure/`에 보존했고 기존 후보를 감싸도록 수정했다. 수정 후 원1,195판단 동일 재현·최초 후보 선택 이전 판단 불변을 확인했다. 후보 선택301회, 양수 명령729→734이며 저장 입력에는 원래의 직전 조향이 그대로 들어오므로 새 궤적/정체 해소를 뜻하지 않는다. 후보13검사와 이전 연결178검사, 합계191개가 통과했다. PC 전체판단 중앙8.62→9.09/p9519.62→20.96ms이며 통제된 연산 비교나 Jetson 성능 결과는 아니다.

다음은 같은 시설/센서/마커누락/0.25배 시계의 제한 주행 r314 한 번이다. 기본 연결이나 실제 출력 채택은 하지 않는다.
