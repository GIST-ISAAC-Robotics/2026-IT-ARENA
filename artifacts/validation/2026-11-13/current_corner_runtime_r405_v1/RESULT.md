# r405 공통 runtime 후보 이관

첫 검사에서는 필수 G1 설정을 생략한 시험 fixture 때문에46개 중2개가 실패했고223입력 비교는 시작하지 않았다. 원 `verify_v1`을 보존했다. `revision_fixture_v2`는 해당 fixture에 기존 `handoff_baseline()`을 사용한 한 파일 수정이며172개 중 제어 알고리즘·원 입력·원 기대 결과는 변경하지 않았다.

수정판은46검사·skip0,223개 baseline/candidate 전체 exact,3개 반례를 통과했다. 원 양수119→213·후보94회·비대상129불변을 공통 패키지 실행에서도 재현했다. 입력시각 미검증 반례는 명시적 환경 관문에서 계산 전에 거절되며, 실제 STOP/주행으로 해석하지 않는다. 소스172개·준비파일 불변, 외부 프로젝트 import0, 자기 자식 정상 종료를 확인했다.

주 에이전트가 기존4파일·helper4파일과 수정판 검사1개를 공통 소스로 이관했다. `integration.json`에 실제 파일 해시와 검증 결과 경로를 남겼다. `g1_current_corner_budget=r396_v1`은 검증된 시뮬레이션 시각·명시 native 두 계산 정책에서만 가능하고 기본은 off다. 거리 제안1회·추가 현재 계산1회·관측 성분 검사만 추가하며 시각·경로를 새로 쓰지 않는다. 실물 `host_estimated_v1` 실행에는 연결하지 않았다.

원 r396의 동결 뒤 보고필드 변경 이력은 보존한다. 이번 기대값은 감사로 식별한 실제 수정판 실행이며 원 동결판이었다고 바꾸지 않는다. 저장 입력 결과를 코너 탈출/전체 완주/실물 출력으로 확대하지 않으며, r406의 제한 주행에서 실제 적용과 효과를 확인한다.
