# 확정 CAD 센서/배선과 SOLO 현재 저속 재검사 연결

r346 저장 입력 후보를 r336의 실제 ROS 발행 경계에 연결한다.
r347 확정 두 지주/전방배선6mm/추가 움직임3mm 프로필을 명시한다.
road_level·신호 구형610 지주·마커20/30누락·10Hz native·상대220mm 두 대·80초를 유지한다.
새 센서 형상과 현재 검사 연결이 함께 바뀐 대표이며 r344와 단일 요인 대조가 아니다.
축거/윤거135/135mm·상자 차체/질량은 기존 근사다. 최종 차량 전체 완주로 쓰지 않는다.
한 번 등록하고 원 접촉/진행/노면/STOP/정상 종료 판정을 보존한다.

## 실행 결과

첫 코너를 지나36.15m까지 진행했지만 오른쪽 자체 마스크 쪽 회전 거절로 다시 정지했다.
같은 정지 반복을80초까지 기다리지 않고 명시 disable/STOP 후 회수했다. **원 전체 실패**,
80초 구간 미충족·상대 궤적/간격 실패를 그대로 보존한다. 최고 자세 속도1.548m/s는 부분 궤적 결과다.
현재 검사600회 중 오른쪽 마스크 거절153회, 기존0.15m/s 재검사 적용3/거절152회다.
r346 공백 재검사는 실제 적용0회이므로 첫 코너 통과를 그 후보의 효과로 단정하지 않는다.

생성 월드는 `road_level`이다. 이탈 바퀴 중심0/평가 겹침0은 기존135mm 기하의 회수 구간 증거다.
STOP 뒤0.5초250구간 최고0.000762m/s·변위0.000258m,14자식 정상 종료·잔여PID0,
730입력/소스 보존을 확인했다. native 완성696스캔 일치·추가 취득 유실0이나 실물 취득 시각 증명은 아니다.
원 데이터·판정은 `run1/report.json`, 요약은 `summary.json`, 당시 소스는 `sources.zip`이다.
