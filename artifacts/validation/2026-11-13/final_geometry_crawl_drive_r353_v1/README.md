# 확정 차량 기하와 저속 재검사 연결 — r353

한 번 등록하는 제한 주행이다. 확정 축거128mm·윤거123.9mm·폭26.1mm/공칭65mm 타이어,
비대칭199.7mm 차체/X+3.65mm 및 대칭207mm 계획 외곽을 물리·계획·보호·평가에 연결한다.
질량2kg 근사·접지·조향 한계·모터축28count·2.5×81/17·원 속도/판정선은 유지한다.
확정 센서 지주/전방배선6mm·움직임3mm, native10Hz, ID49 Z140mm,
구형610 신호/지주·ID20/30 누락·220mm 상대 두 대·road_level·80초를 명시한다.
r352는 r346 뒤 같은 SOLO/현재 관측·조향에서0.15m/s도 거절될 때0.10m/s로 한 번 더 전체 검사한다.
독립 보호층/STOP을 유지하며 실제 속도나 시각을 낮춰 속이지 않는다.
여러 변경이 함께 있으므로 r349와 단일 원인 대조가 아니며 실시간/전체 실차 증명이 아니다.
RTF 목표0.25이고 실행 지연 주입은 없다. 실패하면 원 판정과 당시 소스를 보존한다.

## 결과

**18.58m 부분 진행 뒤 실패**다. `RELEASED`에서 현재 이동 외곽의 일반 미관측 때문에 기본 경로가 거절됐고,
대체 평행 경로도 직선 기준을 만족하지 못해0명령이 반복됐다. 정체 증거를 회수한 뒤 조기 STOP했다.
계획의 `parallel_hold_reference_not_straight`는 최종 출력 이유이며 그 앞의 `large_motion_region_unobserved`도 함께 봐야 한다.
r352 추가0.10 재검사는 적용0회다. r349의36.15m보다 짧아진 결과를 숨기지 않으며 여러 기하 변화가 있어 단일 원인 대조는 아니다.

실제 생성 SDF/제어기 header/소유 독립 보호 프로세스의 설정에서 새 기하가 일치함을 확인했다(`runtime_geometry_audit.json`).
원 진행/전체 랩/구간 부족/상대 궤적 등의 실패는 `run1/report.json`에 유지한다.
STOP0.5초250구간 최고0.001532m/s·변위0.000303m,14자식 정상 종료·잔여PID0,
737입력/보관 ZIP 불변, native485완성 스캔 일치를 확인했다. 평가 겹침0·바퀴 중심 노면 기준 통과는 회수 구간만이다.
실제 타이어/잔디 눌림·현장 주행을 검증한 것은 아니다. `road_level` 조건을 유지한다.
