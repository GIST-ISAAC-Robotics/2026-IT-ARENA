# 같은 가림 판정의 일회 순회 제한 주행 r310

r308과 같은 CAD/시설/원시 C1/기어비/마커 가림·0.25배 시계·46.64m/90초 조건에서 r309의 좁은 가림 후보 순회만 교체한다. r306 직선 조각 후보는 유지한다. 거리·폭·깊이·원 번호 연속 판정과 원 점유/독립 보호는 변경하지 않는다. r309 관련252검사와 r308/r304/r294 원 판단 동일 재현을 선행한다.

12번 재탐색 제한에서 남은 좁은 반환 때문에 코너 관측이 잘리는 사례를 대상으로 한다. 최초 후보를 기존 우선순위로 한 번 순회하고 원시 점 번호가 연속인 구간만 분리한다. 원 입력 자체는 그대로다. 저장 입력의 진전이 새 궤적의 성공을 뜻하지 않으므로 한 번만 등록해 실행한다.

실시간·다중 차량·실차 검증이 아니다. 물리 접촉 메시지가 없으면 평가 겹침0과 별개로 독립 무접촉 증명은 미완료로 남긴다. 결과/원시 실패를 보존한다.

## 결과

20.26 m·최고2.842 m/s에서 `FOLLOW_STEER_IN_PLACE`가 지속돼 미완주했다. 평가 겹침0, STOP/정상 종료·630입력 불변을 확인했다. 시설 접촉 토픽의 메시지는0이므로 독립 물리 무접촉 증명으로 확대하지 않는다.

이 상태는 서보가 목표각에 도착하기를 기다리는 상태가 아니다. `stop_analysis.json`에서 현재/직전 조향의 차체 궤적과 원 반환의 충돌 예측이 원인임을 확인했다. 26–30초 부근에는 약12 cm 전진 지점의 안쪽 반환에 약139.5 mm의 측정/이동 여유가 적용돼 계산 여유 거리가80 mm로 제한됐다. 실제 좌우 조향은 단일 명령과 Ackermann 관계에 부합하는 범위였으며 서보 고장으로 분류하지 않는다. 경계 복구와 점유 회피는 별개다. 여유/정지 임계값을 낮추거나 시설 반환을 삭제하지 않았다.

다음은 저장 입력에서 현재 경로의 시설 점유와 기존 회피 경로 선택을 대조한다. 근거 있는 변경 전 같은 주행을 반복하지 않는다.
