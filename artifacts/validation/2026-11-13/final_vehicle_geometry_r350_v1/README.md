# 확정 CAD 주행 기하 후보 — 공통 연결·실행 전 검사

`prepare.py`는 확정 입력 SHA와 뒤 타이어 두 경계 상자를 확인하고 `vehicle.final.yaml`을 별도 생성한다. 아직 기본 모델·실행에 채택하지 않았다.

- 축거128mm, 윤거123.9mm, 바퀴 폭26.1mm. 바퀴 지름은 CAD64.4mm와 구분해 구매 공칭65mm를 유지한다. 실장 유효 구름 반경은 미측정이다.
- 축간 중점 기준 외곽−96.2~+103.5mm를 충돌 상자 길이199.7mm·중심X+3.65mm로 표현할 후보다. 원점·센서 xyz·뒷축 좌표를 옮기지 않는다.
- 제어기가 현재 대칭 외곽만 지원하므로 계획용 길이207mm로 같은 원점에서 이 외곽을 덮는다. 실제 차량의 검차 길이를207mm라고 계산하거나 차체를 줄이는 뜻이 아니다. 후면 마커/케이블의 최종 외곽은 별도다.
- 질량2kg 근사·접지/마찰·토크/제동·조향 한계·감속비·모터축 엔코더는 유지한다. 상부 전체를199.7×150×256mm의 거대한 충돌 상자로 채우지 않는다.

충돌/표시 상자X offset, 계획기와 보호층의 동일 계획 외곽, 평가기의 자차 간격·노면 바퀴 중심을 공통 경로에 연결했다.
`--vehicle-config`로 명시 선택하며 기본 `vehicle.yaml`은 변경하지 않았다. 기본값으로 과거 평가 기하는 유지한다.
관련136검사와 실제 ROS 노드/두 자식의 기하 전달·STOP·RESET·정상 종료1검사를 통과했다.
원 파일은 `connection_before.zip`, 변경은 `connection.diff`/`connection_applied.json`에 보존한다.
새 주행은 [r353](../final_geometry_crawl_drive_r353_v1/README.md)이며 이 검사를 완주/실차 증명으로 쓰지 않는다.
