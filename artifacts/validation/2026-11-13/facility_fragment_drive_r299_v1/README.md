# 새 시설 벽 조각 연결의 제한 주행 r299

**출발 전0m에서 MCU command_expired로 실패했다.** WAIT_GREEN 상태였고 판단 기록에는 실제 call이 없어 경로 후보의 폐루프 효과를 평가하지 못했다. r294 실패와 달리 시설에 도달하지 못한 실행 연결 실패다. STOP/정상 종료·남은PID0을 확인했다. 원인 변화 없이 반복 실행하지 않고 시작 구간의 전달 기록을 먼저 확인한다.

r294와 같은 새 CAD/시설·속도·물성·STOP으로 r297의 단독 벽 조각 선택만 명시 prefix에 연결했다. 실제 prefix 실행은 simulation.log의 r299 표식으로 확인했다. 원 센서 점유/미관측·독립 보호를 유지하며 시설/지도 정답을 제어기에 입력하지 않는다. 목표46.64m/최대90초였다. 공통 기본 코드는 바꾸지 않았다.
