# 전체 배선을 한 장으로 재배치 — 2026-11-13

[배선도 HTML](../../../../docs/hardware/schematics/esp32_gpio_wiring_v1.html) · [SVG](../../../../docs/hardware/schematics/esp32_gpio_all_v1.svg) · [PNG](../../../../docs/hardware/schematics/esp32_gpio_all_v1.png) · [검증·해시](validation.json)

사용자 가독성 피드백에 따라 기존 신호/전원 두 그림을 부품별 한 장으로 다시 배치했다. 부품12개는 각각 한 번만 표시하고 ESP32를 중심으로 신호·전원·분기를 직접 연결했다. 교차선은 흰 틈, 실제 접속 분기는 ●로 표시했다. HTML은 전체 보기/원본 크기 버튼을 제공한다.

전기적 JSON은 직전 구성과 동일하고 GPIO·헤더·분배점 검사를 통과했다. 한 장2740×1930 렌더와 텍스트 경계/겹침 검사를 확인했다. 첫 검토의 Jetson 설명·하단 각주 겹침은 위치를 수정했다. 기존 두 그림은 비공개 build에 보존하고 현재 문서 링크를 교체했다.

문서 표시 변경이며 장치 접속·펌웨어 업로드·구동은 없다. 하네스 실물 검증을 뜻하지 않는다.
