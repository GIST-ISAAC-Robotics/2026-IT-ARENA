# 선택형 차량 마커 관측 r340

사용자는 시간이 부족하므로 캘리브레이션은 추후 다른 담당자가 수행하고, 낮은 상대 차량 대응을 현장에서 선택할 수 있도록 준비하기를 요청했다. 첫 단계는 **기본 OFF인 관측 기능**이다. 현재 속도/조향에는 연결하지 않으며 이 상태를 충돌 방지 기능 완성으로 설명하지 않는다.

`vehicle_marker_observer_enabled:=true`, `vehicle_marker_ids:="12,13"`처럼 **실제 참가 차량으로 확인한 ID**를 명시한다(12/13은 예시). `vision_execution:=process`가 필요하다. 코스0/20/30/45와 자차49는 거부한다. 남은 ID 전체를 차량으로 추정하지 않는다. 기존 한 번의 ArUco 검출에서 좌표를 재사용하고 작은 관측만 부모에 전달한다. OFF에는 추가 검출·관측 추적이 없다.

`/autonomy/status`의 `vehicle_markers`에 원 영상 시각·정규화 중심/변 길이·연속 관측 수·크기 증가율을 기록한다. 같은 ID의 크기가 다른 중복 후보, 영상 세대 전환, 소실·간격·해상도 변경에서 이력을 끊는다. 역 증가율은 영상 확대의 시간 척도이며 **미터 거리나 검증된 충돌까지 시간(TTC)이 아니다**. 회전·마커 자세·가림도 크기를 바꾼다. 중심 영상 위치만으로 같은 주행 경로를 보장하지 않는다.

후속은 저장/합성 영상의 직선 앞차·옆차·커브·중복·소실에서 감속 후보를 비교하는 것이다. 자동 조향·차량 없음 판정·마커 소실에 따른 진행 허가는 추가하지 않는다. 실물 마커 크기/인쇄·ID 목록·실제 영상이 필요하며, 정밀 거리 추정은 별도 교정 뒤에 다룬다.

## 확인한 범위

관련153검사에서 기존 신호/마커 역할·실제 OpenCV 합성 ArUco 픽셀의 OFF/ON ID·신호 판정 동일, 단일 검출 재사용, 중복/가림·해상도 변경·시각/세대 경계를 확인했다. 실제 ROS 노드의 옵션OFF/ON2사례는 상태 기록·0명령 유지·RESET·영상 자식 정상 종료를 통과했다. 최초 노드 시험은 필수 `lidar_compensation=both` 인자 누락으로 생성 전 실패했고 원 로그/시험 소스를 보존했다. 시험 인자만 보완했다.

Jetson 전체 주행 부하나 실제 인쇄 마커의 검출 거리를 측정하지 않았다. 이후 소스 계보는 `source_manifest.json`/`source.zip`으로 보존하며 이전 주행을 이 새 옵션의 검증으로 재분류하지 않는다.
