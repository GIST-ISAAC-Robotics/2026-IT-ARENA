# 관측 반환 기반 경로 이동 제한 주행 r318

r310/r314와 같은 CAD·새 STL 지주·native10Hz·81T·ID20/30 패턴 가림·0.25배 시계에서 r317 경로 이동 후보를 선택한다. 목표46.64m/최대90초 한 번이며 원 속도/물성/독립 보호·STOP·종료 판정을 유지한다. r313/r316 조향 wrapper는 연결하지 않는다.

원 반환과 경로의 침입을 확인할 때만 최대60mm 평행 이동 후보를 선택한다. 선택 비용에는 10Hz 갱신+20ms 제어 간격의120ms 예산을 더하나, 실제 점유/관측/TTL/현재 및 직전 조향 검사와 벽 이력은 유지한다. 새 입력 수신을 가정해 주행을 허가하지 않는다. 기본 채택·다중 차량·실시간·실차 증명이 아니다.

수용 기준은 기존 전체 랩, 접촉/노면, 정상 STOP/종료다. ID20 통과 여부와 경계 미확정/조향 재개 반복을 별도로 보고한다. 성공할 때까지 같은 시험을 반복하지 않고 원 실패와 소스를 보존한다. 물리 접촉 토픽 무메시지는 독립 무접촉 증명이 아니다.

## 결과

20.17m·최고2.844879m/s에서 경계 미확정이 지속돼 실패했다. 후보 경로 이동의 실제 적용은0회다. 따라서 r317 경로 이동이 주행에 도움이 됐거나 악화시켰다고 판단할 수 없다. 경계 미확정393회·정상 주행639회·재개 대기15회였으며, 기존 저속 조향 간섭에 도달하기 전의 경계 생성/재획득 문제가 남았다.

평가 겹침0, 명시 STOP/촘촘한 자세 정지 검사·정상 종료·잔여 시험PID0·633입력 불변을 확인했다. 물리 접촉 토픽은0메시지여서 독립 무접촉 증명은 아니다. 원 궤적·판정·소스를 보존하며 후보를 기본으로 채택하지 않는다. 같은 주행을 반복하지 않고 현재 시설 위치 가정과 경계 소실을 미해결로 남긴 뒤 운영 연결 준비로 이동한다. 저장 입력 r317의3cm 여유 개선은 이 실패를 대체하지 않는다.
