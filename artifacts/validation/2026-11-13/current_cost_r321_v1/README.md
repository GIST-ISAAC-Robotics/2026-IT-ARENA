# 현재 경로 재검사 프로파일 r321

r296의 r279/r282 대표106입력을 같은 native_v1 코드로 계측했다. 원130소스 SHA256 불변,106전체 출력 동일이다. cProfile 계측 총2.590초는 계측 오버헤드를 포함하므로 실시간 처리율로 쓰지 않는다.

상위 누적 비용은 현재 영역 검사0.926초, 장면 투영0.549초, 좁은 무반환 검사0.434초다. 각 비용은 호출 관계상 중첩되므로 합산하지 않는다. `profile.txt`, `result.json`, `measure_profile.py`가 근거다.

후속 r322는 새 CAD 거리별 가림을 포함한 투영 커널을 비교했지만 Jetson 절감이약2.5ms에 그쳐 미채택했다. 과거 r257과 같은 규모의 효과이므로 추가 수치 커널의 연속 개발로 확대하지 않는다. 다음은 원 명령의 유효기간을 유지하며 갱신 공백을 줄일 실행 순서/계산 범위다.
