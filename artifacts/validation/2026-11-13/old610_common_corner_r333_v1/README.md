# 구형610 공통 코너 연결 주행 r333

r332는 시험용 하위 launch 파일 누락으로 노드가 시작되기 전에 실패했다. 원 표본0/소스 불변/잔여PID0을 보존하고, r328과 같은 하위 launch 파일 세 개를 모두 포함했다. 제어/시험 조건 변경은 r332 등록 계획과 동일하다. r331의 공통 연결 수정만 적용하고 r306/r309/r317 시설 후보는 사용하지 않는다. 결과는 실행 후 기록한다.

## 결과

**46.77m·1랩·차체 최고2.836m/s(10.21km/h)**를 기록했다. 실제 초록8.05초 뒤8.415초에 출발했고 목표 도달 마지막 표본은41.029초다. ID20/30 검출 없이 본선을 돌았으며 평가 충돌/정지 중 겹침 표본0, 중앙선 오차 최대149.5mm다. STOP 후0.5초 연속 정착·ESTOP_LATCHED·14자식 정상 종료·635입력 불변·잔여PID0을 확인했다. STOP 정착 변위0.992m와 교통·실시간·실차 검증은 남는다. 물리 접촉 토픽은0메시지이므로 별도 접촉0 증명으로 사용하지 않는다.

원 전체 `passed=false`의 원인은 입력 수집의 무손실 조건이다. 첫 완성 스캔의 누적 원천 유실은 이미1건이었고(첫 발행0.122초, 출발8.415초), 전체425기록에서 끝까지1로 유지됐다. 이후 유실 증가는0이고 완성 스캔 간격 최대0.10000000000000142초·취득 오차 최대약1.992ms였다. 기존의 원천 유실0 요구는 실패로 보존하며 원 보고를 수정하지 않는다. `assessment.json`은 주행·정지·정상 종료와 수집 무손실을 분리한 후속 감사다.

단독 반대 벽 코너 갱신 연결은 이 대표에서 기존35.18m 정체를 넘어 완주했다. 이 기능을 더 작은 예외마다 반복 보강하기보다 계획의 실행 지연/실물 연결로 돌아간다. 기본 월드 원본이나 신호 실제 설치 좌표를 확정했다고 주장하지 않는다.
