# 발행 확인 뒤 경로 보관 후보의 ROS 주행 연결 r337

공통/운용 기본은 유지하며 `r336` prefix를 명시한다. 두 0.8m/s 상대·80초·기존 간격/노면/겹침·STOP·완주 판정을 사용한다. 원 r282와 달리 현재 CAD 센서 배치와 확정 구형610 지주를 넣으며, 상대 높이는 우리 차량과 비슷한 **220mm 시험 가정**이다. 더 낮은 차량은 별도다. 광원2×5/ID20·30 미검출, 단일모터28count·2.5×81/17·65mm, 독립 보호층을 유지한다.

PC 실제 계산·RTF0.25·지연 무주입으로 **ROS 인계와 제한 교통 동작**을 확인한다. Jetson 실시간/실차 검증 또는 r282와 한 변수만 바꾼 성능 대조가 아니다. 실행 전 입력을 보존하며 원 판정이 실패하면 그대로 남긴다. 결과가 나쁘다는 이유만으로 같은 시험을 반복하지 않는다.

실행 결과: 시설 model 이름을 `trial_*`로 전달하여 평가 actor의 `eval_*` 계약에 거부됐다. 시작 자식0·주행/센서 표본0이며 제어기 결과가 아니다.705입력 불변·보존 archive 동일, 원 `passed=false`/`harness_valid=false`를 유지한다. r338은 시설 이름만 평가 접두사로 변경한 별도 실행이다.
