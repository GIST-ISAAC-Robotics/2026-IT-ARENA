# 정지 근처 낮은 양수 현재 검사 — 제한 연결 r344

r338과 같은 현재 CAD/확정 구형610 시설·220mm 두 상대·기존 속도/물성/독립 보호·80초 조건에서 r343의 좁은0.15m/s 재검사만 명시 연결한다. 관측 영역 허용량·TTL·원 판정선은 유지한다. 마커 관측 옵션은 OFF이고 새 희소 상부 모델은 이 주행에 섞지 않는다. 두 원인 변경을 한 번에 효과로 해석하지 않는다.

실제 ROS 노드·두 spawn 자식·STOP/RESET·정상 종료1검사 뒤 주행한다. 신규 prefix의 `current_low_solo_policy` 출처를 기록하며, 첫 전진뿐 아니라 이후 정상 증속/추종·정지 반복·연산 시간·원 전체 평가 결과를 확인한다. 실패하면 원 증거와 종료를 남기며 같은 조건으로 성공할 때까지 반복하지 않는다. RTF0.25/지연 무주입이므로 Jetson 실시간 또는 실차 검증이 아니다. 기본 채택/장치 변경 없음.

## 결과

- 출발 후10.03m·최고1.5413m/s. 낮은 양수 재검사로 초기 정체는 해소했으나 첫 코너에서 `route_current_large_motion_region_unobserved`가299회 발생해 정지했다. 현재 검사 전체416회다.
- 진행하지 않는 상태를 확인해 약49.4초에 운영 disable/STOP을 요청했다. 예정80초의 완료가 아니며 원 `passed=false`/`run_valid=false`를 유지한다. 원 상대 궤적 추종/간격·구간 부족 실패도 보존한다.
- STOP 응답·출력0과 평가기의 밀집 정지0.5초를 확인했다. STOP 변위0.0000319m, 정지 구간 최고0.000567m/s. 이번에는 평가기에SIGINT를 보내지 않고 원 STOP/종료 절차를 기다렸다.
-14자식 정상 종료·남은 소유PID0·715입력/보관 ZIP 불변. 완성 native503스캔은 모두 일치했으나 초기 유실 누계1건과 원 감사 실패는 남는다.
- 평가 겹침/바퀴 이탈0. 접촉 토픽0메시지는 연속 물리 무접촉 증명이 아니다. 실패는 [r345 고정 입력 분석](../current_corner_audit_r345_v1/README.md)으로 분리한다.

`early_stop.json`은 이번 의도적 조기 회수와 서비스 응답, `run1/report.json`은 원 평가, `integrity.json`은 소스 보존 결과다. 제어기 기본값과 실제 장치는 변경하지 않았다.
