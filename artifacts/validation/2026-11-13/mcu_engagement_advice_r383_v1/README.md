# 운영 서보·모터 연결 자문 r383

2026-11-13. Claude Fable 5.2/high에 운영 연결의 제한된 설계 검토를 요청했다. 관련 portable 코드와 preview 앱을 읽었으며 구현·빌드·장치 실행은 하지 않았다. [원 자문](ADVICE.md)과 모델/완료 확인의 공개 가능한 [receipt](receipt.json)를 보존한다. 자문은 실제 펌웨어 성능이나 물리 동작 검증이 아니다.

## 채택한 방향과 보완

- 준비 증거 `ready`와 이번 ARM 세대의 서보 활성화 완료 `engaged`를 분리한다. 유효 구성·위치 모드·신선한 위치를 확보한 뒤 ARM을 수신하고, 현재 위치 유지 목표의 ACK와 torque1 ACK를 순서대로 확인한다. 준비 중 모터 출력은 억제한다.
- ARM에 남은 조향값을 곧바로 적용하지 않는다. 이번 세대의 실제 DRIVE 수신을 별도로 확인한다. 목표속도0의 DRIVE도 유효한 조향 요청이다.
- STOP 이후 보내지 않은 목표는 버리고 이미 시작된 전송은 마무리한다. 과거 세대의 ACK가 새 활성화 허가가 되지 않게 한다. 자동 중앙 복귀·자동 토크 해제는 추가하지 않는다.
- 준비 중 PI 포화만으로 충분하다는 제안은 채택하지 않았다. 실제 출력이 억제된 동안 적분이 쌓이지 않도록 [r385](../runtime_preparation_r385_v1/README.md)에 적분 초기화를 넣고 검사했다.
- 20ms 엔코더 차분 등은 양자화와 갱신 지연의 절충 후보다. 실장 확인 전 운영 계수로 확정하지 않는다. ACK는 통신 성공이며 물리 조향 완료가 아니다.

## 서보 속도 단위 확인

자문의 raw speed400≈35°/s는 모든 ST 서보 설정에 공통인 수치가 아니다. [제조사 ST 메모리 표](https://docs.waveshare.com/Memory_Map_Explanation/ST_Servo_Memory_Map_Explanation)에서 속도 단위는 Phase의 bit2에 따라 0.732 또는 0.0146RPM이며, bit3은 speed0의 의미를 정한다. [11/12 실물 기록](../../../../docs/sensors/ST3215_HS_HARDWARE_2026_11_12.md)에는 Phase12·resolution1이 저장되어 있다. 그 설정을 표에 대입하면 raw400은 약35.04°/s이며 speed0은 최대속도다. 이는 레지스터의 명목 환산이고 장착 상태의 실제 응답 속도는 아니다. EEPROM은 변경하지 않았다.

후속 순서기는 raw speed/acceleration을 명시 구성으로 받는다. 과거 무부하 시험 값을 운영 기본값으로 자동 채택하거나, 공칭 환산으로 조향 완료 시간을 보장하지 않는다. 장착 중립·끝단·모터 방향/엔코더 부호·출력 상한과 실제 응답 확인은 별도다.
