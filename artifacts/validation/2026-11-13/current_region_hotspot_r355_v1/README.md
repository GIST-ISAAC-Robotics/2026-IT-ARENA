# 현재 이동 외곽 검사 비용 분해

r354 Jetson에서 느린37/70/80호출을 동일 입력의 cProfile로 분해했다. 프로파일 오버헤드가 있으므로
실제 비용은 r354 비계측 값을 쓰며 이 수치를 추가 실행 지연 측정으로 쓰지 않는다.
`motion_region`이 약103–121ms를 차지했다. 대표80호출에서 깊이 지지42.3ms,
자기 가림 원인 분류28.7ms, 이동 표본 생성31.0ms이며 호출 상하관계로 단순 합산하지 않는다.
후속은 가림 원인 분류의 NumPy 임시 배열/반복을 같은 판정의 수치 커널로 줄일 수 있는지 확인한다.
관측 표본을 줄이거나 미관측을 자유로 바꾸는 후보는 아니다. 원 실패·모든 입력/반환 상태는 유지한다.
