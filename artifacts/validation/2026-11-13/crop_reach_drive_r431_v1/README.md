# r431 사용자 중단 주행의 동일 조건 후속 1회

r428은 사용자 중단으로 종료돼 코너 통과 여부를 판단하지 못했다. 원 기록과 실패 판정은 보존하고 새 경로에서 한 번만 끝까지 확인한다. 성공할 때까지 반복하지 않는다.

r428에서 성공한 colcon 빌드를 재사용한다. src/scripts/tests 공통 소스 전체와 빌드 증거 해시가 같은 경우에만 freeze를 허용하며 재빌드로 기록하지 않는다. r429/r430 변경은 별도 stage에 머문다.

128 mm 축거·123.9 mm 윤거·65 mm 바퀴·native C1 10 Hz·4mask·old610 시설·두220 mm 상대·ID20/30 누락·road_level·80 sim초·RTF0.25와 기존 속도/물성/노면/독립 보호 경계를 유지한다. r426의 현재 crop reach 후보만 기존과 동일하게 명시한다. 기본off/실물off다.

순서: root source 검토/동결 → 16개 preflight → 제한 주행1회. 이전313개 저장정책 검사와 빌드를 반복하지 않는다. 실행/STOP/회수는 r428 README와 동일하며 8 sim초 무진행·접촉/이탈 또는 원 종료 조건에서 소유 stop_owned.py를 호출한다. 전체1500 wall초/STOP120 wall초를 유지한다. run1 및 registered가 생기면 재실행하지 않는다. STOP 요청과 원 evaluator 판정을 분리하고 원 실패를 덮지 않는다.
