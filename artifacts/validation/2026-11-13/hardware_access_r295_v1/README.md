# 장비 재사용 허가 뒤 현재 앱 확인 r295

11/12 말 사용자 재허용 뒤 Jetson·ESP32·IMU 접근을 재개했다. 기존 엔코더/모터 시험의 원문과 복구본은 유지한다.

SSH 접속과 세 포트의 소유자 없음 확인 뒤 기존 IMU 도구 가상환경으로 3초 수신만 수행했다. 일반 Python은 pyserial 미설치로 장치 열기 전에 실패했으며, 이미 설치된 가상환경을 사용했다. 패키지 설치·flash·모터/서보 명령은 하지 않았다.

18프레임 중 메타데이터3·상태3에서 WHO_AM_I=108(0x6C), Flash16MiB/PSRAM8MiB, inactive를 확인했다. 센서 측정 스트림을 시작한 시험이 아니며 포트 재개방 시 MCU 리셋 가능성은 남는다. UART 쓰기0·포트 close, 원문1908바이트는 Git 제외다. 근거는 `summary.json`이다.
