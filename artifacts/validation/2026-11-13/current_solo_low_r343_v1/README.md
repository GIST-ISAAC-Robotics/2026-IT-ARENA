# 정지 근처 SOLO의 제한 전진 후보 r343

r342의 원 입력 비교에 따라, 기본/운용 미채택 선택 후보를 구현한다. 원 계획이 양수이고 FOLLOW/SOLO이며 현재 측정속도0–0.15m/s일 때, **현재 재검사의 자체 측방 마스크 거절만** 대상으로0.15m/s를 한 번 다시 검사한다. 일반 미관측·전방 가림·앞차/점유 정지·STOP·음의 측정속도/고속·GUARD/RELEASED는 기존 결과 그대로다.

목표 상한 외 모든 입력/원 경로/시각을 유지해 기존 함수를 전체 재실행하며 같은 조향·현재 시각을 확인한 양수만 반환한다. 원10mm/TTL/물성/독립 보호를 바꾸지 않는다. 정상 주행을0.15로 제한하거나 반대 방향을 새로 선택하지 않는다. 후보 효과와 부작용은 원r338234개+과거 교통106개 현재 입력에서 비교한 뒤 제한 ROS 시험을 판단한다. 실물 또는 전체 운용 채택을 의미하지 않는다.

20경계 검사를 통과했고, r338234개가 모두 원0→0.15로 바뀌었다. 같은 조향/시각과 전체 현재 영역 통과를 확인했다. 과거 r27952개+r28254개는 출력 전체가 그대로다. 최초 시험 보조 함수 이름이 pytest의 구형 `setup` hook으로 해석된 오류는 로그/원 소스를 보존하고 `make_fixture`로 수정했다. 원 정책 실패나 주행 실패가 아니며 시험 수정을 제어기 개선으로 세지 않는다. r344에서 기존80초 제한 교통 조건으로 연결을 확인한다. 기본/실물은 미채택이다.
