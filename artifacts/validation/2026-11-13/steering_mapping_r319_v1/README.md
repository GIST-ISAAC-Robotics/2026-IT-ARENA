# 장착 조향 환산 연결 준비 r319

확정 회로도를 바꾸지 않고, 공통 차량 조향각(rad)을 ST3215의 RAM 목표 위치(count)로 넘길 준비를 한다. 서보 자체 회전각과 양 앞바퀴가 만드는 차량 조향각을 같은 값으로 취급하지 않는다. 조립 뒤 측정표를 받아야 하며 실제 중립/한계값을 추정해 채우지 않는다.

`Mapping`은 최대17개 측정점의 단조 보간표다. 실제 직진0rad 지점과 좌/우 측정 범위를 요구하고, 비대칭 링크·반대 방향 장착을 지원한다. 측정 범위 밖의 조향을 외삽하거나 임의로 끝단에 붙이지 않는다. 제어기의 좌/우 최대 조향 범위를 표가 덮는지 `covers`로 따로 확인한다. 이 제한은 시뮬 제어기에 새 정지를 추가한 것이 아니며 공통 기본에 미연결이다.

보간 결과만 기존 비차단 `Transaction.goal`의 RAM 목표 프레임으로 넘긴다. 토크 ON·EEPROM·물리 UART 송신·모터 출력·실제 제동 정책은 이 함수의 기능이 아니다. 예제의 위치/각도는 전부 합성값이며 운영 설정으로 복사하지 않는다. 현재 ESP32 앱은 변경하지 않는다.

## 조립 뒤 필요한 입력

1. 실장 직진 상태의 서보 위치와 좌우 여러 작은 조향에서의 바퀴 각도를 기록한다. 기계적 끝단보다 안쪽의 사용 범위를 정한다.
2. 실제 차량 기하에 맞는 공통 차량 조향각으로 정리한다. 단순 서보 각도 환산이나 시뮬 축거를 실측 대용으로 쓰지 않는다.
3. 그 표가 제어기 요구 범위를 덮는지 확인하고, 낮은 출력에서 목표/실제 위치와 지연·유격을 확인한다. 단순 보간 성공을 기구 교정 완료로 보지 않는다.

검사 결과는 호스트 합성 표/기존 직렬 프레임 수준이다. 실제 조향/주행·RAM 목표의 안전한 통신 취소/독립 출력 감시/MD20A 음수 effort의 전기 제동 매핑은 별도 후속이다.

## 검사 결과

측정점/비대칭 보간·반대 방향·미확정 표·범위 밖/NaN 거부·기존 RAM 프레임까지 합성8사례를 최적화 및ASan/UBSan에서 통과했다. ESP32-S3 도구체인 object 컴파일은1,007B text이며 전체 앱 링크/보드 실행을 뜻하지 않는다. 실제 수치는 여전히 미입력이다.
