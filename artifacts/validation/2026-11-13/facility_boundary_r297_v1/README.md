# 새 시설 가림의 기존 벽 조각 경로 재사용 r297

r294 실제 기록1031개를 원 설정으로 모두 동일 재생했다. 기존 교통용 실제 벽 조각 가설을 단독·narrow_occluder_bridge 선택에도 연결하는 격리 후보는410개 판단을 바꾸었으며, 원 정체 이후346개는 모두 진행 후보가 됐다. 원 입력/시설 점유를 지우지 않는다. [대조](comparison.json)·[격리 연결](candidate.py).

기존 직선 조각의 정렬·근처 가림 반환·코너/앵커가 필요하며 미관측을 자유로 바꾸지 않는다. 관련42개 검사는 정면 장애물 정지·넓은 전방 미관측/오래된 입력·선택 OFF·잘못된 조각·기존 교통 갱신을 포함한다. 최초 비교에서는 교통 옵션을 단독에 켜려다 구성 계약이 거절했다. 그 계약을 풀지 않고 실제 가설 생성 부분만 후보로 분리했다. 첫 새 합성 검사는 raw scan 없는 장면에 bounded 정책을 사용해3개 실패했고 strict 합성 계약으로 고쳤다. 원 실패 로그는 보존했다.

저장된 정지 궤적에서의 진행 후보이며 실제 전진/완주 증명이 아니다. [r299](../facility_fragment_drive_r299_v1/README.md)의 제한 주행은 신호 대기 중 MCU 명령 만료로0m에서 종료되어 경로 개선을 평가하지 못했다. 공통 기본 코드는 변경하지 않았다.
