# 실제 직선 조각 경로 후보 r306

r304 신호 지주의 가림에서는 기존 벽 조각 가설이 실제 코너를 요구해 경로를 만들지 못했다. 같은 근거리 anchor·앞쪽 정렬 조각·가까운 가림 반환·최대 gap 조건을 유지하면서, 관측한 두 조각 전체가3cm 내 직선이고 전방 관측 길이가 충분한 경우에만 평행 직선 경로를 추가했다. 관측 끝을 넘어 외삽하지 않고 시설/차량 점유나 unknown을 지우지 않는다. 단독+narrow_occluder_bridge의 격리 후보이며 공통 기본 코드는 미변경이다.

관련38검사에서 좌우 대칭·입력 불변·가림 증거 없는 경우/다른 선/anchor 없는 경우/실제 코너를 잘못 펴는 경우·전방 점유/unknown/오래된 입력/선택OFF를 확인했다. 저장 r294 1,031판단/r304 498판단의 원 코드 동일 재현을 먼저 확인했다. 후보에서 양수 명령은 각각634→1,019개와105→488개였다. [재생 수치](replay_summary.json)·[검사](tests.log).

새 궤적의 실제 진행/완주·센서 잡음 전 조건·교통 성립을 뜻하지 않는다. 사용자가 프린팅 전 카메라 전 그리드 시야 확인을 우선 요청하여 **이 저장 검증까지 정리하고 실제 r306 주행은 아직 하지 않았다.** 이후 동일 후보를 선정한 제한 주행에서 확인한다. r294/r299/r304 원 실패는 유지한다.
