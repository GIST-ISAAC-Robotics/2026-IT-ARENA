# 저속 가까운 조향 후보 제한 주행 r314

r310과 같은 CAD·새 STL시설·C1 native10Hz·기어비·마커20/30누락·0.25배 시계에서 r313 가까운 조향 후보만 추가한다. 최대90초/46.64m 목표 한 번이다. 원 점유/관측·정지/재개 거리·속도/물성/독립 보호를 유지한다. 후보13+이전178검사, 원1,195판단 재현·최초 선택 전 불변을 선행했다.

r310의20.26m 정체에서 경로를 찾고도 PP 조향이 안쪽 반환의 여유 안으로 들어가는 문제를 대상으로 한다. 기본 적용/교통/실시간/실차 승인이 아니며 실패 때 결과와 정상STOP/종료를 회수한다. 물리 접촉 토픽 무메시지는 평가 겹침0과 구분한다.

## 결과

20.22m·최고2.845m/s에서 재개 대기/전진 보류가 지속돼 미완주했다. 평가 겹침0·STOP/정상 종료·631입력 불변이다. 물리 접촉 메시지0은 독립 무접촉 증명이 아니다.

저장 판단에서 새 스캔 첫 호출은 원 PP조향0.32rad에 여유0.92m를 계산해 복귀하지만 같은 스캔의 나이가 늘면 여유가0.24→0.20m로 줄어 후보0.29/0.28rad로 다시 바뀐다. 다음 스캔에서 다시0.32rad로 돌아가 재개 확인이 끊긴다. 원 가림/경계 실패와 별개인 후보 선택의 시간상 불안정이다. 이 후보를 공통 기본으로 채택하지 않는다. 다음 비교는 한 스캔 동안의 점유 여유 증가를 조향 선택에서만 미리 살피되 실제 관측·원 점유·STOP/재개 판정은 그대로 유지하는 방법이다.
