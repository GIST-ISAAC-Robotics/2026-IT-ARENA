# r359 최신 계획 계산의 제한 진단

원격 main `a120e91a`의 우선순위와11/13 사용자 보완을 반영한다. 필수 회귀/통합 확인은 유지하고 이미 끝난 센서별 진단은 반복하지 않는다.

r358에서 현재 검사 공유의 효과는 확인했지만 계획 중앙약132ms와 명령 공백이 남았다. 이번에는 r358 동결 코드와 r353 원 입력 순서·reset을 재사용해 **계획**의 상위 비용을 구분한다.16개 이하의 간격/상태 표본만 cProfile을 적용한다. 계측 비용이 포함되므로 마감/처리율 기준 수치로 쓰지 않는다. 기존 출력과 명령을 대조한다.

Jetson의 이미 검증한 동결 루트에 새 진단 스크립트와 출력 디렉터리만 추가한다. 센서 포트·MCU·모터/서보·펌웨어·전력 설정은 변경하지 않는다. 공통 코드 수정 전에 원인을 확인하는 단계다. 새 수치 커널을 무작정 추가하지 않으며 대표 근거를 얻으면 비구동 센서/운용 통합으로 이어간다.
