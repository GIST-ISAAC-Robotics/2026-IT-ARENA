## 최초 직렬 비교의 한계

이 call 로그를 계획 자식의 전체 계산 순서로 간주할 수 없다. 399개 call 중 고유 계획 결과는397개이며 폐기된 계산과 실제 자식의 상태 전환을 모두 재현한 것은 아니다. 따라서 이 직렬 비교를 커널 동등성 통과나 실제 실행의 속도 오류로 단정하지 않는다. 위3개 차이의 완전한 원인 분리는 미완료다.
