# r404 최신 운영 노드의 실제 센서 입력 결합

준비 중, 미실행. r401 profile·r403 원 C1 frame 계약이 확인된 뒤 한 번 실행한다. 현재 ESP32는 기존 비구동 IMU 진단 앱을 그대로 사용한다. r394 운영 host·flash·ARM·모터/서보 출력은 실행하지 않는다.

새 Jetson 복사본에 공통 코드를 동결하고 native 확장을 빌드한다. 20초 동안 C1/IMU/B0390 입력을 G1G2 두 계산 자식·영상 자식과 독립 보호층에 연결한다. 카메라 취득60Hz·ROS 전달20Hz, C1 tracking 추정·원 frame과 시각을 유지한다. IMU는 기존 preview 토픽에서 명시 remap으로 소비하며 기존 진단 앱의 S/X와 비활성 응답을 확인한다.

실제 엔코더가 없으므로 0속도를 합성하지 않는다. 양수 주행이나 최신 전체 계획의 CPU 부하 성능을 이 시험으로 입증할 수 없다. 각 노드의 실제 센서 수신, `/drive`와 `/drive/safe` 양쪽 0명령, 보호층 입력/상태, STOP/자식 종료·센서 비활성·포트 반환을 확인한다. 원시 센서 자료는 Git 제외한 remote_result에 보존한다.

실행은 root가 source manifest/번들 SHA를 고정한 뒤 지정 담당자만 수행한다. import/build 실패에서는 센서를 시작하지 않는다. 데이터·정상 종료 기준 실패 시 원로그를 회수하고 같은 실행을 자동 반복하지 않는다. 다른 Jetson/WSL 성능 시험과 겹치지 않는다.
