# 저속 조향 선택의 스캔 주기 안정성 r316

r314에서 새 스캔은 급한 PP조향, 같은 스캔 말미는 완만한 대체 조향으로 되돌아가 재개 확인이 끊겼다. r313과 같은 원 점유·경로 일치·조향 후보를 쓰되, **조향 선택에서만** 실제 한 스캔 길이(상한100ms) 뒤의 기존 물체 이동 여유를 더해 비교한다. 기존 실제 점유 검사와 관측/정지/재개/TTL은 변경하지 않는다. 새 자료 도착이나 자유 공간을 보장하는 예측으로 사용하지 않는다.

선택된 저속 대체 조향의 속도 요청은0.25m/s로 한정한다. 원 상한보다 낮은 조립 전 후보이며 구동/기본 연결은 아니다. 목적은 기존 급한 조향으로 매100ms마다 돌아가는 반복을 피하는 것이다. 범위는 현10Hz·0~0.25m/s·현재 관측 경로이며 다른 스캔 길이/원거리 미관측/경로 불일치에 임의 적용하지 않는다.
