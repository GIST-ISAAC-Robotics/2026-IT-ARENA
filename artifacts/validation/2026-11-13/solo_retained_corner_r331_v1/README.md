# 단독 반대 벽 코너 갱신 연결 r331

r330의 원 r328 저장 입력에서31.04초에는 현재 오른쪽 벽의 전방 관측3.977m·앵커 오차10.9mm가 확보됐다. 기존 X 구간 비교는 실패하고 기존 호길이 비교는 통과했다. 그러나 반대 벽의 호길이 갱신 호출부가 교통 옵션만 허용해 단독 옵션에서는 이 관측을 갱신하지 못했다.31.14초에는 이전 경로와의 차이가 커져 호길이 비교도 실패했고 정지가 시작됐다. 이는 현재 관측이 없는 곳을 자유 공간으로 해석하는 문제가 아니다.

공통 `local_follow.py`에서 해당 호출부에도 기존 `solo_route_only && corridor_arc_agreement`를 연결했다. 이미 선택한 같은 반대 벽·현재 충분한 관측/앵커·유효 이력·기존 형상 오차 조건을 유지한다. 초기 획득이나 이력 만료 뒤 재획득 조건, 실제 점유·부분 관측·독립 보호는 바꾸지 않았다. 새 설정이나 임계값을 추가하지 않았다.

## 검증

- 관련106검사 통과.11/1 저장 입력을 현재 공통 코드로 재현하는 기존 검사1건은49명령 불일치로 실패했다. 수정 전 소스를 별도 프로세스에 로드해 같은49불일치를 확인했다(`prior_failure.log`). 이를 새 수정 성공으로 덮거나 검사를 지우지 않았다.
- 이번12검사는 좌우 대칭·옵션 OFF·짧거나 다른 벽·만료/없는 이력·앵커 초과·정면 장애물의 정지를 확인한다.
- 원 r328의1,525저장 판단에서 명령26개가 달라졌다. 최초 차이는20.64초의 같은 갱신 사례다.31.04초에 현재 오른쪽 벽을 갱신했고, 원 정지 이후15호출에서 진행 명령을 유지했다. 원 궤적은 이미 정지하는 궤적이므로 실제 완주 개선으로 해석하지 않는다. 변경 후 진행1,144/0명령381이다.
- 신형 기둥 전용 r306/r309/r317은 적용하지 않았다. 이전 전체 묶음과 공통 코드의 원 명령 동일 결과는r330에 보존한다.

수정 전 소스는 `local_follow.before.py`, SHA는 `source_change.json`, 저장 비교는 `common_report.json`·`transition.json`에 보존한다. 새 주행은 별도 r332에서 같은 시설·속도·센서·평가 기준으로 한 번 수행한다.
