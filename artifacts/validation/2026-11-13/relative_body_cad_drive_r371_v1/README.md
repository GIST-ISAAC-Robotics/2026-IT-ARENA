# 최종 CAD 조향·현재 코너 후보 주행: 10.13m 정체

[사전 조건](PLAN.md)대로 r361 계획, r370 현재 SOLO 저속 공백 검사, 최종 CAD 조향을 함께 명시해 공식 코스·두 상대 조건을 한 번 실행했다. **10.13m 진행 뒤 8초 무진행으로 STOP·종료했다. 완주나 개선 성공이 아니다.** CAD 조향도 함께 바뀌었으므로 r364와 한 변수 비교로 해석하지 않는다.

- 현재 검사217회는 RELEASED162·SOLO43·GUARD12회다. 실제 r370 현재 프로세스 설치·정상 반환을 [영수증](worker_policy_receipts/)에서 확인했지만 새 상대거리 저속 후보 적용은0회였다.
- 마지막 계획은 RELEASED의 약0.08946m/s·조향0.22006rad였다. 현재 검사가 `route_current_large_motion_region_unobserved`로0명령을 반환했다. 차체 옆 초과5.54mm는 기존10mm 범위 안이지만 이웃 반환의 고정0.6m 조건에서 거절했다.
- r370은 SOLO 분기의0.15m/s 재시도 이후에만 연결되어 있어 이 RELEASED 사례에는 적용되지 않는다. 알고리즘이 실행되지 않은 문제와 적용 범위 밖 문제를 구별한다. 해당 이웃 거리 판단의 RELEASED 확장은 아직 구현/검증하지 않았다.
- 실제 생성 SDF의 `steering_model=fusion_cad_2026_11_13`, 축거128mm·윤거123.9mm, 기어비11.911764706·65mm를 확인했다. 물성·정지선은 바꾸지 않았다.
- 명시 MCU STOP·촘촘한 실제 정지 표본·차체 안정은 통과했다. 다만 STOP 전 MCU latch 없음 조건은 실패다. 접촉 이벤트/겹침 표본·노면 이탈은0이나 조기 종료로 전체 기간·상대 움직임 평가도 실패했다. 따라서 전체 시험 유효/통과로 표시하지 않는다.
- 실행 자식14개 정상 종료·잔여 시험 PID0·강제 회수0이다. 입력1,342개와 실행 소스 archive 불변을 확인했다. 제어기에 정답 위치나 상대 정답을 넣지 않았다.
