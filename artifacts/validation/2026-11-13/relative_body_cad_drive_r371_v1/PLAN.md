# 최종 CAD 조향·상대 거리 공백 검사 제한 주행

r364의 저장 현재 검사249개를 전체 재현했다. 그중110개는 r370의 같은 조향0.10m/s·현재 관측/오차 범위 기반 이웃 검사에서 통과했고 과거 교통106개는 변하지 않았다. 기존 바퀴 최대각 대신 사용자가 요청한96행 CAD 조향/최대각 프로필을 함께 선택한다. 단일 수정의 인과 비교가 아니며 두 변경을 포함한 기능 연결 대표다.

원 두220mm 상대·확정 센서/배선·구형610기둥·ID20/30 미검출·road_level·80sim초·RTF0.25를 유지한다. /drive→독립 보호→/drive/safe와 기존 정체·접촉·노면·STOP 판정선은 그대로다. 목표는 원 코너 정체를 지나며 주행하는지 확인하는 것이고 성공할 때까지 반복하지 않는다. 지속 정체 또는 위험이 확인되면 소유 시험에 STOP을 요청하고 실패 원문을 회수한다. 서보/모터 실물 명령·전력 변경·커밋/푸시는 없다.
