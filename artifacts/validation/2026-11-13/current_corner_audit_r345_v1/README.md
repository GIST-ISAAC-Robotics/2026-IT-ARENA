# r344 코너 정체의 고정 입력 분석

r344 현재416검사 중 일반 미관측 거절299개에서 균등12개를 골랐다. 원 출력 전체12개를 동일 재생했으며 새로운 주행은 하지 않았다.

첫 거절은 실제 속도0.551m/s로 기존 저속 공백 범위 밖이다. 정지 뒤11개에서 목표만0.35/0.15/0.08m/s로 낮추어도 r343의 기존 현재 검사는 일반 미관측을 거절했다. 별도로 기존 `released_body_gap.check`를 그대로 적용하면0.15는9/11,0.08은11/11에서 작은 차체 옆 무반환 위험 검사를 통과했다. 0.35는 차체 옆1cm 범위 밖으로 거절됐다.

원인은 이 저속 검사가 현재 RELEASED/GUARD에 연결되어 있고 SOLO에는 연결되지 않은 차이이다. 현재 반환이 없는 영역을 자유 공간으로 바꾼 결과가 아니다. 통과한0.15 표본도 실제 미관측 질의 개수244~342개를 유지하며, 좁은 광선 간격·주변 반환·전방 제외·실제 저속 등 기존 조건으로 위험을 한정한다.

r346은 같은0.15 상한과 기존 검사를 조건에 맞는 SOLO에 연결하는 **별도 후보**로 검토한다. 새0.08 상한 채택·기존1cm/각도/물성/TTL 완화는 하지 않았다. 확정 CAD 수신에 따라 현재 저장 비교까지만 마치고 새 형상 대조를 우선한다.
