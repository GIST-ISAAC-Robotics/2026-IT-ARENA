# RELEASED 자체 가림 꼬리의 제한 저속 재검사 — r361

**r353 저장 입력의 마지막 정체173회 중168회가0→0.10m/s로 바뀌었다.**
새 후보의 일반 미관측·전방 마스크는 모두0이고 가림 꼬리 최대8.4874mm로
기존10mm 기준을 지켰다. 나머지231판단은 원 재생과 전체 출력이 같았다.
Python/native 두 계산 경로의399개 비교 기록은 서로 완전히 같다.
이는 저장 입력의 계획/현재 검사 결과이며 **실제 정체 탈출·한 랩·실시간·실차 통과는 아직 아니다.**

## 원인 정정과 원문 보존

[r353 원 README](../final_geometry_crawl_drive_r353_v1/README.md)는 지속 정체를
`large_motion_region_unobserved`로 설명한다. 원 파일/판정은 수정하지 않았다.
원 `run1/follow_decisions.jsonl`의399개 계획 호출을 직접 집계하면 다음과 같다.

- 마지막173회(seq804–976, t30.32–47.52초)는 모두
  `RELEASED → large_motion_masked_toward_right → parallel_hold_reference_not_straight → 0명령`이다.
  일반 미관측·전방 마스크는173회 모두0이다.
- 기존0.35/0.25/0.15m/s 재검사를 모두 수행한170회에서,
  0.15 후보의 가림 꼬리는11.5136–11.7559mm로10mm를 넘었다.
- 평행 후보의 직선 적합 잔차는165.95–215.76mm다. 직선 기준10mm를 완화하지 않았다.
- 일반 미관측 거절은 seq584·594·595·612(t19.32·19.82·19.92·20.72초)의4회뿐이다.
  그 뒤 진행했으므로 마지막 지속 정체와 구분한다.
- 원 trajectory의 t30.647–47.557초169표본은 독립 보호 `clear`, MCU `ARMED`,
  `/drive`·`/drive/safe` 모두0, 보호층 간격0.88m다. 이 구간의 직접 원인은 계획0명령이다.

확정 기하128mm 축거·계획 외곽207×150mm, native C1 10Hz, r347 장착,
구형610 신호·ID20/30 누락·road_level 입력을 유지했다. r349의36.15m/구기하 결과와 합치지 않는다.

## 선택형 후보

[`candidate.py`](candidate.py)는 import만으로 동작하지 않는다. `enabled()`를 명시한
단일 Python 과정에서만 `PassReleaseSelector._select`를 감싸며 종료/예외 때 복구한다.
공통 src와 실행 기본값은 바꾸지 않았다.

RELEASED/non-retained·현재 측방 위협 없음·현재 양수 G1 경로/fully_observed·
원 측정속도0–0.15m/s에서 기존0.35/0.25/0.15 후보가 모두 자체 가림 꼬리 때문에
거절됐을 때만, 같은 경로와 현재/직전 조향으로0.10m/s를 한 번 더 전체 검사한다.
일반 미관측·전방 가림·10mm 초과 꼬리가 남으면 계속0이다. 원 속도/시각을
0.10 또는 최신 시각으로 바꾸지 않으며 통과 이력·상태·unknown 분류를 수정하지 않는다.

기존 `forward_drive`는 음수 센서 속도의 절댓값을 전진 계획에 사용할 수 있다.
후보는 상위 `BypassHandoffFollow.command`의 원 측정값을 별도로 보존하여 음수에는
새 허가를 적용하지 않는다. 기존 signed 이력/정책은 유지한다.

마지막173회 중 제외된5회는 초기 retained/고속 seq804–806과 음수 seq807·860이다.
첫 적용은 seq808(t30.72초)이다. 기존 HOLD 조향−0.350389rad를 그대로 복사하는 대신,
**검사한 원 G1 후보 조향−0.373176rad**를 사용한다. 후보를 통과시키려고 새 각도를 만들지 않았다.
그때0.10 후보의 요구 이동 거리는34.3mm이고 가림 꼬리는8.4141mm다.

r352는 SOLO/current 전용이며 양수 계획 출력도 요구한다. 이번에는 계획부터0이므로
r352의 SOLO 조건만 확대해서 해결할 수 없다. 이번 후보는 앞선 계획 선택 단계에만 붙인다.
