# 실물 신호 교정 없이 남는 광학 민감도 r339

사용자가 실제 신호등 촬영/HSV 조정 시험을 하기 어렵다고 전달해 기존 구형610 시설의18개 정지 RGB를 사용한다. 원본 밝기, 단일 노출 gain3개, 색조±8(OpenCV H단위), 채도0.6, 흐림1px를 각각 비교한다. 조합을 무제한 늘리지 않으며 현재 검출기를 먼저 측정한다. 같은 정지 그림에 서로 다른 가상 시각을 준 검사이므로 실제 영상 연속성/LED PWM/노출 조절/현장 오작동률의 증거가 아니다.

녹색 점등 영역에 RGB(0,V,0)의 유색 소등 렌즈를 가정한 V100/150/200 반례도 별도로 본다. 이 밝기가 실제 소등 렌즈 값이라는 뜻은 아니다. 배열/마커/연속 프레임만으로 분리할 수 있는 범위를 확인하고, 실패를 발견해도 색 임계값 하나를 낮춰 해결했다고 선언하지 않는다. 실물 캘리브레이션·기본 검출기 변경·새 주행은 하지 않는다.

## 결과

원 검출기와 마커 기반 늦은 출발 후보 모두 원본17/18, 밝기0.60배0/18, 밝기0.75/1.25배·색조±8·채도0.6·흐림1px는 각각17/18이었다. 해당 정상 시퀀스의 조기 출발은0이다. 원 실패1개는230mm 앞차의 가림 사례다.

소등 렌즈 가정108사례에서는 정상 빨강→초록 모드의 오출발0, 늦은 출발 후보의V200에서12건 오출발을 확인했다(V100/150은0). 따라서 단순 임계값 완화나 연속 프레임 수 증가만으로 해결했다고 할 수 없다. 실제 렌즈 밝기와 현장 오출발 확률을 측정한 결과가 아니다. 기본 검출 정책은 유지하며 점등 전 기준/신호 전이 등 추가 근거가 없는 늦은 초록 허용을 완료 기능으로 취급하지 않는다.

54개 원 PNG의 SHA256은 `report.json`에 있다. 새 운용 계수·실제 카메라 시험·동적 주행을 추가하지 않았다.
