# 구형610 시설·공통 코너 연결 주행 r332

사용자 확정 `signal_610_old_style.stl` 지지 구조를 r328과 같은 임시 설치 좌표에 둔다. 광학부/카메라 가정·native C1 CW10Hz·단일 모터28카운트/11.9118:1/65mm·기존 속도·독립 보호·노면/접촉·STOP 판정은 유지한다. 계산 지연과 기하를 분리하는0.25배율도 동일하다. 실제 장착이나 실시간 성능을 증명하지 않는다.

변경은 r331의 단독 반대 벽 호길이 갱신 연결이며, r330에서 명령 영향0을 확인한 r306/r309/r317 시설 후보를 빼고 공통 제어기만 실행한다. 노드에서 등록된 공통 코드 SHA를 검사한다. 단독46.64m 목표/최대90초, ID20/30은 가림을 대신한 패턴 공백 조건이다. 실패 시 원인 변화 없이 재시도하지 않는다.

등록·소스 보존 후 실행하며 결과는 이 문서에 정리한다. 실제 기둥 위치와 B0390 화각/광축 교정은 남아 있다.

## 결과

하위 `launch/local_pursuit.launch.py` 누락으로 실행 전 실패했다. 센서/명령/pose 표본0·633입력 불변·자식0·잔여PID0이다. `requested_laps=1` 등은 요청값이며 달성 랩이 아니다. 소스 묶음과 원 실패 보고를 보존하고 누락 파일을 포함한 r333으로 이어간다.
