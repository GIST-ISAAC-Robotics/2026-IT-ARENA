# r358 두 프로세스 시간 재생 비교

r357 분리/공유 계산을 같은 r353 최종 기하 기록으로 비교한다. r334 감속 인계·r353/r352 현재 검사와 r278 계획 정책을 양쪽에 동일하게 연결한다.

- 31초, split/shared/shared/split 순서 각 1회. 인위 계산 지연 0, 센서 운동 취득+20ms 도착 가정은 기존 비교와 같다. 실제 수신 시각의 복원은 아니다.
- 원 저장 call에 200ms 공백 두 곳이 있다. r325의 조밀한 입력 전제에 해당하지 않으므로 새 시험으로 분리한다. 빠진 스캔을 생성하거나 보간하지 않는다. 현재 원천 기한 300ms·명령 기한 200ms와 새 상태/0/epoch 취소는 그대로다.
- 출력은 파일에만 기록한다. 차량 운동은 원 기록이며 이번 출력에 반응하지 않는다. ROS 콜백·실물 구동·완주·정지 거리 증거가 아니다.
- 시간과 동시에 양수 발행 수·갱신 간격·만료 구간·계획/현재 계산 비용·정상 종료·원 입력 해시를 기록한다. 타이밍에 따른 경로 선택 차이는 그대로 남긴다.
- 대표 결과를 얻으면 미세 최적화를 계속 반복하지 않고 조립 전 운영 연결/남은 교통 기능으로 이동한다.
