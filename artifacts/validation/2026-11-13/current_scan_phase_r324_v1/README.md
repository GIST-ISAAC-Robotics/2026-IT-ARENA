# 완료 스캔에 맞춘 두 단계 제출 r324 — 미채택

기존25ms fresh 창을 계획과 현재 확인에 적용했다.20관련 검사를 통과했다. 같은15초·취득+20ms 도착 가정·계획146.7455/현재81.3046ms 최소 비용의 새계획 전용과 비교했다.

- 계획은 양쪽75회 제출로 약5Hz가 되었고, 양수는71→69회였다.
- 보조 경로 확인 양수는0회였다. 현재 원천 만료는 없었지만 기하500ms 만료40회·새계획 선점26회가 남았다.
- 명령 만료 합계는6.793→5.916초, 발행 간격 중앙은 약200ms로 지속 명령에 부족했다.
- 두 자식 정상 종료, 기본/ROS/실물 미연결이다. 기록 차량은 새 출력에 반응하지 않는다.

엄격한 fresh 창만으로 해결되지 않아 채택하지 않는다. 계산80ms가 끝나기 전에 새 스캔이 오면 다음25ms 창을 놓치거나,500ms 경로 수명 안에 보조 결과가 돌아오지 못한다. 다음 r325는 새 스캔 여부를 강제하기보다 남은 원천/명령 예산으로 제출 여부만 고른다. 원 판정선/시각은 보존한다.
