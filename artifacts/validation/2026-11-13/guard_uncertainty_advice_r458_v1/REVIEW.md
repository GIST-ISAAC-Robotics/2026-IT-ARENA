# r458 — 관측 불확실성 정체 설계 자문과 채택 범위

2026-11-13 Claude Fable 5.2/high 어드바이저와 두 차례 논의했다. 코드/시뮬 변경은 자문에 포함하지 않았고 구현·최종 판단은 GPT가 맡았다. 첫 답변 때 5시간 사용량 경고가 있었으나 사용자가 초기화한 뒤 두 번째 논의를 완료했다. 자문 완료와 구현/주행 검증 완료를 구분한다.

## 확인한 원인

[r456 실제 입력](../guard_crawl_entry_r456_v1/pinpoint_v1/approach_geometry.json)의 seq573은 같은 이동 표본을 두 단계에서 다르게 취급했다. 전체 `motion_region`은 기존1cm 자기 가림 꼬리 범위로 .1/.15m/s를 허용했지만, `observed_guard_approach`는 추가 측방 접근이 모두 직접 자유 관측이어야 한다며 거절했다. .1의 실패304표본은 모두 자기 가림이고 일반 미관측은0이다. 작은 속도 후보나 진입 조건만 추가해도 해결되지 않는다.

과거 GUARD anchor는 현재 다시 적합한 경로 좌표와 비교된다. 누적1cm 초과 자체는 실제 충돌 확인이 아니므로, 현재 관측/이동 영역 검사를 다시 요구하는 방아쇠로 사용하고 이후 분류를 일관되게 하는 방향을 채택했다. 과거 측방 상태를 지우거나 정적 물체로 임의 분류하지 않는다.

## GPT 채택 설계

- 공용 접근 함수는 명시 `region`/정책/차량 크기 근거가 제공될 때만 제한 자기 가림 예외를 허용한다. 기존 호출은 strict 동작을 유지한다.
- 일반 미관측0·전면 가림0·기존 꼬리 예산 통과를 확인하고, 실제 추가 접근 표본의 옆면 깊이/차체 길이 안 위치를 다시 대조한다. 옆면 방향 span은 기존 `ACCEPTED_HIDDEN_WIDTH_M` 5cm를 보수적 상한으로 재사용하되 서로 다른 기하의 한도임을 명시한다. 실측 분해능/안전 인증값으로 취급하지 않는다.
- 각 접근 측면에 직접 자유 관측이 적어도 하나 있어야 한다. 이는 전수가림을 제외하는 조건이며 전체 접근구간이 관측됐다는 증명은 아니다. `currently_observed`, 예산으로 허용한 가림 수, 일반 미관측 수·깊이·span을 분리한다. 가림을 자유 관측 수에 더하지 않는다.
- plan과 실제 선택 runtime의 current 검사가 같은 분류를 사용하도록 연결한다. absent current에서는 기존 현재 측방 present 거절, 시각·현재 점유·coverage·fringe 순서를 유지한다. anchor 즉시거절만 수집한 뒤 region과 접근을 검사한다. 기존 저속 재시도 gate가 보는 실패 reason의 의미도 보존한다.
- 새로운 속도 단계·새 측방 상태 해제·지도/기둥 정답·반복 재시도는 추가하지 않는다. 명확한 전방/측방 점유와 운영 STOP을 유지한다.

## 수용하는 위험과 정정

차체 옆 얇은 가림 띠에 통째로 숨은 물체·뾰족한 돌출부·측정 평면 밖 물체는 놓칠 수 있다. “옆차라면 인접 광선에 반드시 걸린다”는 보장은 사용하지 않는다. 사용자 최신 지시인 명확한 충돌 방지 유지와 불확실성 때문에 생기는 영구 정지 감소 사이의 제한된 위험 선택이다.

첫 자문의 가림 폭1.2–1.8cm 추정은 두 번째에서 정정됐다. 원 섹터 전폭 약14.5°와 대표 표본 거리로 추정한 폭은 약2.4cm·옆면 방향 약2.9cm이며, 이 추정 수치를 구현의 추가 임계값으로 사용하지 않는다. 실제 query 좌표를 사용한다.

GPT는 `local_scene.py`가 return/unknown/masked 이외 상태를 생성 시 거절함을 확인했다. `_native/depth_kernel.cpp`의 masked와 결합 분류는 Python의 unknown 제외·한쪽 이상 mask·반환 거리/padding 조건과 정적으로 일치한다. 이 검토는 부동소수 경계의 전수 동등성 시험이 아니다. 새 kernel 변경은 필요하다고 판단하지 않았다.

## 후속과 한계

r459 독립 stage에서 전체381입력의 원본 재현과 수정 후 정체108개/이전273개의 변화, 실제 근접 측방·전방 장애물과 일반 미관측 반례를 비교한다. 함수·저장입력 통과만으로 완주를 선언하지 않는다. r457 완전 단독 전체랩을 먼저 분리해 준비하고, 실제 주행에 적용되는지 확인한 뒤 출발 위치/방향·벽 형상 차이와 교통 대표로 이어간다. r452는 교통 actor 두 대가 있는 시험이며 단독 증거가 아니다.

자문이 새 정책의 실차 안전이나 전체 코스 성공을 보장하지 않는다. 현재 구현·채택·실행 결과는 후속 산출물과 현재 현황을 따른다.
