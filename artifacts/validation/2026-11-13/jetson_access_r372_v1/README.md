# Jetson 이름·동적 주소 접속과 유휴 GUI 확인

사용자 요청으로 `jetson-orin`을 **`isaac-jetson`**으로 변경했다. 기존 SSH 키를 보존한 채 새 이름을 로컬 키 목록에 연결했고 비공개 DPAPI 프로필의 호스트명만 바꿨다. 바탕화면 `ISAAC Jetson 접속.cmd`와 SSH 별칭 `isaac`를 준비했다. [사용법·복구·한계](../../../../docs/hardware/JETSON_ACCESS.md).

원 장애는 공유기 일반 DNS의 이전 `.local` 이름 응답이 외부 주소였지만, 같은 Wi-Fi mDNS에서는 실제 장비 주소가 나온 경우다. 키 일치와 인증까지 확인했으며 정확한 공유기 내부 원인이나 이름 충돌은 확정하지 않았다. 접속기는 mDNS→기존 호스트 키 대조→SSH 순서이며, 숫자 주소 지정도 키 검증을 유지한다. 대회장 AP의 장비 격리/멀티캐스트 차단은 별도 현장 확인이 필요하다.

- 새 이름 발견·기존 키 일치 및 자동 접속 `hostname=isaac-jetson`을 확인했다.
- 관련8검사: 이름·주소/응답 범위·압축 DNS·잘린 패킷·다른 장비 키 거절·미등록 키 거절 등. PowerShell3파일 구문 검사 통과.
- IP/라우터·호스트 키/인증·센서/전력은 변경하지 않았고 재부팅하지 않았다. 변경 전 파일은 장비와 노트북 비공개 경로에 보존했다.
- 원격 화면 연결은 하지 않았다. [유휴 측정](headless_idle.json)은 GDM/Xorg/GNOME/NoMachine의10.06초 CPU·PSS 및 GPU5표본이다. 한 코어 약0.994%, PSS545.5MiB, GPU0%였으며 전체 시스템 가용 메모리는약4.71GiB였다.
- 가짜 EDID 자체 외에도 GUI 프로세스의 메모리 부담은 존재한다. 원격 화면 전송 때 비용·서비스 OFF 비교·주행 개선은 미검증이다. 현재 설정은 유지하며 주행 중 불필요한 NoMachine 세션을 끊는 운영을 권한다. SSH와 웹 조작 화면 사용을 중단하라는 뜻이 아니다.
