# 구형610 연장 시설 단독 주행 r328

r318과 같은 CAD 센서·81T·native10Hz·ID20/30 패턴 가림·r306/r309/r317 선택형 제어기·0.25배 시계에서 시설만 r326으로 바꾼다. 기존910mm 가로대는 실행 사본에서 제거하고760mm STL 가로대로 대체한다. 신호 패널/광원·실제 위치 가정은 유지한다.

목표46.64m/최대90초, 원 접촉/노면/STOP/종료 판정이다. 기하 대조이며 실시간/교통/실물 증명이 아니다. 과거 r318실패는 보존한다. 출발광원 인식 시험과 주행 시험을 구분한다. 새 시험은 한 번만 하며 결과에 따라 원인을 분석한다. 현재 준비/실행 중이다.

초기 r327은 평가 모델 이름에 필수 `eval_` 접두사가 없어 launch 단계에서 거부됐고 센서/주행 표본0이었다. 실패와 소스를 보존하고, 이 실행에서는 평가 시설 이름만 수정했다. 주행 실패를 반복해 통과시킨 시험이 아니다.


## 결과

**35.18m·0랩으로 실패**했다. 같은 제어기 신형 시설 r318의20.17m보다 진행했지만 뒤쪽 코너에서 경계가 미확정돼 정지했다. 최고2.838958m/s, 평가 겹침0이다. r317 경로 이동의 적용은0회이며, 형상 변경의 결과를 그 경로 후보의 성과로 계산하지 않는다. `follow_boundary_unconfirmed`385판단, 정상`local_follow`1,129판단이다.

실패 정리 STOP은 수락됐고0.5초 촘촘한 자세 표본의 최대0.000526m/s로 정착했다. 입력640개 전후 해시 동일·잔여 시험PID0이다. Gazebo 종료 지연/launch SIGTERM으로 정상 종료는 실패했다. 물리 접촉 토픽은0메시지여서 평가 겹침0을 독립 물리 무접촉 증명으로 확대하지 않는다.

31.14초 최초 지속 정지의 후보는`wall_segment_short`, 조각 근거는`expected_wall_folded`, 코너 근거는`observed_supported_prefix_short`였다. 정지 자세는대략(2.664,1.041)m/yaw−1.262rad이다. 기둥 침범이 남아서 멈췄다는 결론은 아직 아니다. [r330 저장 비교](../old610_corner_r330_v1/README.md)에서 신형 대응 후보 묶음을 빼고 같은 입력을 비교한다.

기둥 형상은 실행 준비 중 후속 사용자에게 확정 전달받았다. 기존 위치/광학 근사·0.25배 시계 범위는 그대로이며 실제 설치 위치와 Jetson 실시간 성립은 별도다.
