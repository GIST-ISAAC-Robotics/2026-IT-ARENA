- 외부 기어비: `81/17 = 4.764705882...`
- 최종 감속비: `2.5 × 81/17 = 11.911764706... : 1` (12:1로 반올림해 구현하지 않음).
- 좌우 평균 바퀴1회전당 모터 엔코더 환산: `28 × 11.911764706... = 333.529411765... counts`. 직진·무슬립에서 양쪽 바퀴 회전이 같을 때의 환산이며, 디퍼렌셜이 있는 한쪽 바퀴의 회전을 단일 모터 엔코더로 독립 측정하는 것은 아니다.
