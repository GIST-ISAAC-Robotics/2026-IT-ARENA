# ISTech IT Arena 트랙 맵 패키지 — 후보1 통합 코스 (A+B)

`track_gen.py` 하나가 유일한 원본(single source of truth)입니다. 이 스크립트를 실행하면
`output/` 아래 모든 산출물이 재생성됩니다. 트랙은 조직위원회가 확정한 코스 이미지
("후보1 통합 코스 A+B": A의 롱 스트레이트·헤어핀·에세스 + B의 직각 시케인)를 그대로
재현하되, **홀이 이미지보다 세로로 긴 비율(11.0 x 14.5 m)**이라 전체 레이아웃을 90도
회전시켜 배치했습니다 (섹터 순서·형상·상대적 비율은 그대로 유지). 조직위 최종 변경사항인
**출발 그리드(6대, 2열 지그재그)**가 추가되었고 **피트레인은 제거**되었습니다.

```bash
pip install --break-system-packages numpy matplotlib opencv-python-headless ezdxf pyyaml shapely
python3 track_gen.py                       # 기본값으로 output/ 전체 재생성
python3 track_gen.py --bump-height high --resolution 0.01 --scale 1.0 --grid-cars 6
```

## 4. 시뮬레이터별 사용법

| 시뮬레이터 | 사용 파일 | 방법 |
|---|---|---|
| F1TENTH gym | `map.png` + `map.yaml` (+ `centerline.csv`) | `map.yaml`을 gym 맵 설정에 지정, 레이스라인 필요 시 `centerline.csv`를 waypoint로 로드 |
| ROS map_server / Nav2 | `map.yaml` | `ros2 run nav2_map_server map_server --ros-args -p yaml_filename:=map.yaml` |
| Gazebo Sim (gz) | `world.sdf` | `gz sim output/world.sdf` (플러그인 없이 로드됨, 정적 모델) |
| 커스텀 시뮬레이터 | `scene.json` | JSON 직접 파싱: 홀 크기, 섹터/게이트 s-range, 갈림길 branch/merge s, 그리드 슬롯 pose, 노면변화/협로 구간 등 포함 |
| 신호등 연동 (모든 시뮬레이터 공통) | `traffic_light.py` | UDP(포트 47810)로 JSON 브로드캐스트, 각 팀 스택에서 소켓 수신만 하면 됨 |
| 현장 시공 | `venue_layout.dxf` | CAD에서 1:1로 열어 벽/마커/범프/그리드 위치 실측 시공 |

## 5. 파라미터 (CLI)

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `--bump-height` | `mid` (0.010 m) | `low`=0.005m, `mid`=0.010m, `high`=0.015m, 또는 미터 단위 실수 직접 입력 |
| `--resolution` | `0.01` (m/px) | 점유격자 맵 해상도 |
| `--scale` | `1.0` | 전체 치수(트랙, 벽, 잔디, 범프, 마커, 그리드 크기 등)에 곱해지는 전역 축척 |

## 8. 재생성 방법

전체 파이프라인은 `python3 track_gen.py` 한 번으로 끝나며, 실행 시 자동으로:

1. 센터라인/경계선/갈림길(대체경로) CSV 생성
2. 점유격자 맵 PNG + YAML 생성 (일반/잔디표시 2종, 갈림길 2개 모두 자유공간 포함)
3. Gazebo `world.sdf` 생성 (램프, ArUco, 범프, 그리드 라인, 노면변화 패치 포함)
4. 현장 시공용 `venue_layout.dxf` 생성 (ezdxf로 재검증, GRID/FORKS 레이어 포함)
5. ArUco 마커 PNG + 인쇄용 PDF 생성
6. `traffic_light.py` 컨트롤러 파일 생성
7. 기하 검증 실행 (회전반경/협로폭/클리어런스/자기교차/랩 길이/그리드-벽 겹침/홀 여유마진)
8. `scene.json` 통합 씬 데이터 생성 (검증 결과 포함)
9. `preview.png` 렌더링 (한글 라벨 + 치수)

파라미터를 바꾸고 싶으면 CLI 인자만 조정해서 재실행하면 됩니다 (예: 대회 당일 범프 높이를
`high`로 바꾸거나, 참가 대수가 달라져 `--grid-cars 8`로 그리드 크기를 조정, 또는 현장이
좁아져 `--scale 0.9`로 전체 축소).

## 9. 원본 이미지 대비 재현 방법 메모

조직위 확정 이미지("후보1 통합 코스 A+B")는 가로로 넓은 레이아웃(약 590x404px, 종횡비
≈2.16:1)이지만, 대회장 홀은 세로로 긴 11.0 x 14.5 m(종횡비 ≈0.76:1) 입니다. 이미지를
그대로 축소하면 홀 폭(11m)에 막혀 트랙이 실제 사용 가능한 세로 공간(14.5m)의 절반도 못
쓰게 됩니다. 따라서 이미지를 **90도 회전**하여 이미지의 가로축(직선 구간이 늘어선 방향)을
홀의 세로축(14.5m, 더 긴 변)에 맞추고, 이미지의 세로축을 홀의 가로축(11.0m)에 맞췄습니다.
섹터 순서, 형상(헤어핀·협로·직각시케인·에세스·시케인·롱스위퍼), 갈림길 위치, 상대적
비율은 모두 원본 이미지에서 좌표를 직접 추출(픽셀 단위 트레이싱)하여 그대로 재현했으며,
회전 외에는 형태를 임의로 바꾸지 않았습니다. 출발선 앞 그리드 연장(2.0m)만 조직위의
최종 변경사항으로 추가되었습니다.
